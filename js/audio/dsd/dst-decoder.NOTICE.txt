Modifications by Yoshiyuki Kobayashi, 2026-11-01:
- Adapted the frame decoder to freestanding C compiled to WebAssembly,
  returning interleaved DSD bytes through a small JavaScript wrapper.
- Replaced FFmpeg bit-reading and arithmetic helpers with bounded equivalents.
- Added frame-size, coefficient and truncated-bitstream validation.
- Implemented the implicit probability-128 table when its encoded length is one.
- Packed the 128-bit predictor history into two unsigned 64-bit words while
  retaining the byte lookup order and bit-exact lossless reconstruction.
- Removed FFmpeg allocation, codec registration and PCM conversion; the
  existing EffeTune converter performs the DSD-to-PCM stage separately.

Supported compressed frames use a single shared segment layout, as in the
upstream decoder. Filter/probability mappings may differ. Uncoded DST frames
are also supported. Other segment layouts return an unsupported-format error.

The preferred editable source is distributed alongside the application at
js/audio/dsd/dst-decoder.c and dst-decoder.js, including in the Web/PWA and
desktop packages. dsd-kernels.c supplies the separately MIT-licensed PCM
conversion kernels; the combined WebAssembly module is LGPL-2.1-or-later.
The full application and build source is available at
https://github.com/Frieve-A/effetune (use the source for your application version).
The dedicated module is generated by scripts/build-dsd-wasm.mjs (included
with the application) using the Clang/wasm-ld in Emscripten 6.0.13. Set EMSDK
to that SDK root, then run npm run build:dsd from the source checkout. The
module has no Emscripten runtime, libc, WASI or other imported dependencies.
Install the package.json/package-lock.json dependencies with npm ci and run
node scripts/build-playback-decoder-vendor.mjs to rebuild the Worker bundle.
Replace js/vendor/rolling-pcm-decoder-worker.mjs with the generated file.
