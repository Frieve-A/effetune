# EffeTune — 日本語 Store 掲載原稿

## 短い説明

リアルタイムの音声エフェクト、イコライザー、音の可視化で、音楽再生を自分好みに調整できます。

## 商品説明

EffeTune は、音楽をじっくり楽しみたい方のための音楽プレーヤー兼リアルタイム音声エフェクト処理アプリです。再生しながら音を調整し、ドラッグ＆ドロップでエフェクトを組み合わせて、気に入った設定をプリセットに保存できます。

手元の音楽ファイルを再生するほか、Music Library で選択したフォルダーの曲を探したり、デスクトップ版の Browser で対応する Web サイトの音声にエフェクトをかけたりできます。イコライザーでは周波数帯域ごとのバランスを調整でき、ダイナミクス系エフェクトでは音量の変化を制御できます。ビジュアライザーで信号の状態を確認することもできます。

まずは音楽ファイルを開き、イコライザーを一つ追加してみてください。エフェクトのオン・オフで変化を聴き比べ、また使いたい設定をプリセットとして保存できます。選択した音声ファイルにエフェクトをかけ、処理結果をファイルに保存することも可能です。

必要に応じてローカルネットワーク機能を有効にすると、対応する OpenHome コントローラーから再生を操作したり、ペアリングしたブラウザーからエフェクトを調整したりできます。使わないときは無効にできます。

外部 Web サイトの再生は、そのサイトのログイン方式、再生条件、コンテンツ保護方式に左右されます。音楽配信サービスの契約は含まれず、すべてのサービスでの動作を保証するものではありません。別のデスクトップアプリの音声を処理する場合は、音声の経路を設定する追加ソフトウェアが必要になることがあります。

## 主な機能

- ドラッグ＆ドロップによるエフェクトの並べ替えと、バイパスによる聴き比べ
- イコライザー、ダイナミクス処理などの音声エフェクト
- 音楽ファイルの再生、フォルダー・曲情報からの検索、プレイリスト
- 対応する Web サイトの音声を処理するデスクトップ版 Browser
- プリセット、リアルタイムの可視化、音声ファイルの一括処理
- OpenHome による再生操作と、ペアリングによるエフェクトの遠隔操作
