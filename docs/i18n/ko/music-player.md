# 음악 플레이어

EffeTune에서 음악 파일을 열면 현재 이펙트 체인을 거쳐 들을 수 있습니다. 플레이어 컨트롤로 일시 정지, 재개, 재생 속도 조절을 할 수 있습니다.

## 음악 파일 열기

- **음악 파일 열기**(헤더의 폴더 버튼)를 클릭하거나 음악 파일을 창으로 드래그합니다.
- **데스크톱 앱:** **파일 > 음악 파일 열기...**를 선택하거나, OS에서 음악 파일을 EffeTune으로 엽니다.
- **모바일 레이아웃:** **음악 열기**를 탭합니다.

음악 파일 플레이어로만 사용할 때는 **오디오 설정**에서 **입력 장치:**를 **없음(음악 파일 플레이어 전용)**으로 설정하면 EffeTune이 실시간 오디오 입력을 사용하지 않습니다.

## 재생 컨트롤

- 일시 정지, 재개, 또는 **×**로 플레이어를 닫을 때는 클릭 노이즈를 막기 위해 짧은 페이드를 적용합니다.
- **셔플** 옆의 재생 속도 버튼을 클릭하면 9가지 프리셋 중 하나를 고르거나 `0.25x`부터 `4x`까지 원하는 속도를 `0.01x` 단위로 설정할 수 있습니다. **피치 유지**는 기본적으로 켜져 있어 속도를 바꿔도 피치가 그대로입니다. 끄면 테이프나 레코드처럼 속도에 따라 피치도 오르내립니다.
- 데스크톱 앱에서는 **보기 > 미니 플레이어**(`Ctrl/Cmd+Shift+M`)를 선택하거나 플레이어의 미니 플레이어 버튼을 클릭하면 작은 창으로 전환됩니다. 핀 버튼을 클릭하면 항상 맨 위에 표시됩니다.

## 갭리스 재생

**오디오 설정**의 **갭리스 재생**은 기본적으로 켜져 있으며, 호환되는 로컬 곡을 곡 사이 공백 없이 재생합니다. 다만 지원 범위는 제한적이며 파일 형식과 브라우저 또는 앱 환경에 따라 달라집니다. 지원되지 않는 형식과 일부 모바일 환경에서는 메모리를 아끼는 안전한 대체 방식을 사용하므로 짧은 공백이 남을 수 있습니다. 끄면 짧은 공백이 생길 수 있는 대신 적은 메모리 사용량과 안정성을 우선하며, 설정을 바꿔도 재생 중인 곡은 중단되지 않습니다. 갭리스 재생은 1x 속도에서만 동작하며, 갭리스 재생 중에 속도를 바꾸면 잠시 끊긴 뒤 같은 위치부터 다시 재생됩니다.

## 동영상 {#video}

동영상은 플레이어의 아트워크 영역에 표시됩니다. 데스크톱 레이아웃에서는 동영상 재생을 시작하면 플레이어 패널이 자동으로 펼쳐집니다. 현재 동영상을 재생하는 동안 다시 접을 수 있습니다. 동영상 위에서 포인터를 움직이거나 탭하면 확대 버튼이 나타나며, 잠시 조작하지 않으면 사라집니다. **⛶**를 선택하면 앱 화면 전체에 표시되며, 동영상 위에서 포인터를 움직이거나 탭하면 하단에 재생 컨트롤이 나타납니다. Visualizer에 **Video** 아이템을 추가할 수도 있습니다. 음악 라이브러리에 동영상 파일을 포함하는 방법은 [음악 라이브러리 가이드](music-library.md#availability)를 참조하세요.

모바일 레이아웃에서는 회전했을 때 동영상을 화면에 더 크게 표시할 수 있으면 확대된 동영상과 컨트롤이 함께 회전합니다. **설정 > 구성... > 표시**의 **모바일에서 확대된 동영상 회전**은 기본적으로 켜져 있으며, 화면을 회전하지 않으려면 끄세요. 작은 플레이어로 돌아가면 원래 표시로 복원됩니다. 데스크톱 레이아웃이나 기기의 화면 방향 설정은 바뀌지 않습니다.

Mini Player를 제외한 화면에서는 동영상이나 주변의 검은 여백에서 다음 동작을 사용할 수 있습니다.

- **마우스:** 클릭하면 재생하거나 일시 정지합니다. 더블 클릭하면 재생 또는 일시 정지 상태를 유지한 채 동영상을 확대하거나 원래 크기로 되돌립니다.
- **터치:** 탭하면 컨트롤이 표시됩니다. 확대된 상태에서 왼쪽 절반을 두 번 탭하면 10초 뒤로, 오른쪽 절반을 두 번 탭하면 10초 앞으로 이동합니다. 작은 미리 보기에서는 두 번 탭해도 재생 위치가 바뀌지 않습니다.

버튼과 슬라이더는 평소와 같이 작동합니다.
