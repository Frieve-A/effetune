# 음향 특성 측정

주파수 응답, 임펄스 응답, 왜곡, 감쇠를 측정하고 필요에 따라 보정 EQ를 만들 수 있습니다.
1. [음향 특성 측정](https://effetune.frieve.com/features/measurement/measurement.html)을 열거나, **설정** 메뉴에서 **음향 특성 측정**을 선택합니다.
2. 안내에 따라 측정용 마이크와 출력 장치를 설정합니다.
3. 한 곳 또는 여러 청취 위치에서 시스템의 주파수 응답을 측정합니다.
4. EffeTune으로 바로 가져올 수 있는 파라메트릭 EQ 보정을 생성합니다.
5. 보정을 적용해 더 정확하고 중립적인 재생음을 얻습니다.

## 출력 채널

**출력 장치 채널 수**를 출력 장치에 맞게 설정하세요. 5.1은 **6**, 7.1은 **8**입니다. 출력 채널과 채널별 대역폭은 이 범위 안에서 선택할 수 있습니다. 테스트 신호와 측정에는 항상 이 채널 수를 사용하므로, 5.1 장치에서 Ch 3(센터)과 Ch 4(서브우퍼)만 측정할 때도 **6**으로 두세요.

다중 채널 시스템에서는 모든 출력을 함께 측정하려면 **모든 채널**을 선택하고, 하나씩 측정하려면 개별 **출력 채널**을 선택합니다. **고급 설정**에서 스윕 대역폭으로 **끔**, **모든 채널에 동일하게 적용**, **채널별** 중 하나를 선택합니다. **채널별**에서는 **설정할 채널**을 사용하여 선택한 각 출력 채널의 주파수 범위를 설정합니다. 레벨 조정 중 **채널 모드**는 처음에 **자동 순환**으로 시작합니다. 필요하면 테스트 신호 채널을 선택하거나 **수동**을 선택합니다.

## 임펄스 응답 가져오기

임펄스 응답 WAV 파일이 이미 있다면 **가져오기**를 선택해 파일을 지정하세요. EffeTune은 WAV의 각 채널을 측정 결과로 저장하며, 이 결과는 **Room EQ** 등 측정 결과를 사용하는 기능에서 쓸 수 있습니다.

## 오디오 인터페이스 보정

오디오 인터페이스 자체의 응답을 제거하려면 출력을 입력에 직접 연결하고, 이 루프백을 임펄스 응답이 포함된 일반 미보정 측정으로 저장합니다. 스피커를 측정할 때는 인터페이스, 채널, 샘플링 주파수, 입출력 게인 설정을 그대로 유지한 채 **오디오 인터페이스 보정**에서 저장한 측정 지점을 선택합니다. 루프백 보정 없이 측정하려면 **없음(미보정)**을 선택합니다.

## 결과 보기 및 내보내기

결과는 다섯 개의 탭으로 나뉩니다. 주파수 응답은 여러 측정 지점이나 출력의 평균을 표시할 수 있으며, 임펄스 응답·왜곡·Waterfall은 저장된 지점 하나와 출력 하나를 분석합니다. 평균 보기에서 전환하면 마지막으로 사용한 유효한 개별 선택을 복원하고, 없으면 첫 번째 사용 가능한 기록을 선택합니다. 주파수 응답으로 돌아가면 해당 탭의 선택이 복원됩니다. 모든 출력을 동시에 재생한 측정은 그 출력들을 합친 응답입니다.

- **주파수 응답**에서는 측정 응답, 보정 EQ, 보정 후 예상 응답을 비교합니다. 주파수와 dB 범위, 표시 평활화, 상대 정규화 또는 기준 레벨, 표시할 곡선을 조절할 수 있습니다. 평활화 폭은 가우스 분포의 σ입니다. 평활화 없음은 추가 처리를 하지 않는 설정으로, 저장된 응답에 이미 적용된 처리를 되돌리지는 않습니다. IR이 있는 개별 기록에서는 저장 응답을 보거나, 시작점 전후의 창 길이와 모양을 지정하여 IR을 다시 분석할 수 있습니다. 분석하는 시간 구간이 달라 결과가 다를 수 있습니다. 표시 설정은 저장된 측정값이나 보정 EQ를 바꾸지 않습니다. 보정 설계, 복사, TXT/CSV 내보내기는 보정 영역에서 합니다.
- **임펄스 응답**은 부호가 있는 진폭 또는 진폭 절댓값의 dB를 표시합니다. 시간과 진폭 범위, 확대·축소와 이동, 피크 정규화, 표시 시간 원점, 창의 전후 길이와 모양을 조절합니다. 겹쳐 표시된 창은 분석 구간을 나타냅니다. 시간 0은 감지된 시작점이며, 원점을 옮겨도 표시만 바뀔 뿐 측정된 소리의 전달 시간은 바뀌지 않습니다. 가져온 WAV나 재생 시각 기준이 없는 녹음으로는 절대 전달 지연을 알 수 없습니다. WAV 내보내기는 표시 창이나 배율에 관계없이 저장된 선형 응답 전체를 정규화하지 않고, 저장된 샘플링 주파수의 모노 32비트 부동 소수점 오디오로 출력합니다.
- **왜곡**은 기본 주파수에 대한 H2, H3, THD를 표시합니다. 주파수와 세로축 범위, % 또는 dBr 단위, 표시 차수, THD에 포함할 최고 차수, 분석 창을 조절합니다. 비율이 클수록 고조파 왜곡이 많으며, %와 dBr은 같은 비율의 다른 표현입니다. THD는 선택한 차수를 합산하며 모든 차수가 유효한 대역에만 표시됩니다. 빈 구간은 데이터가 없다는 뜻이지 왜곡이 0이라는 뜻이 아닙니다. 결과에는 재생부터 녹음까지의 전체 경로가 포함되며, 인터페이스의 선형 보정으로 그 왜곡을 제거할 수는 없습니다.
- **Waterfall (3D)**에서는 **Waterfall**과 **Burst Decay** 분석을 선택할 수 있습니다. 표면 높이와 히트맵 색은 동일한 상대 dB 레벨을 나타내며, 색상 눈금과 위치 판독값으로 레벨을 확인합니다. 등고선은 dB 레벨이 같은 지점들을 연결합니다. 주파수 눈금선은 축의 눈금 위치에서 표면을 따라 표시됩니다. **정규화**에서 **없음**은 원래 레벨을 유지합니다. **전체 피크 = 0 dB**는 표시된 주파수 대역과 사용 가능한 시간 전체의 최대 레벨을 0 dB로 맞추고 레벨 차이를 유지합니다. **주파수별 피크 = 0 dB**는 각 주파수에서 사용 가능한 시간 중 최대 레벨을 0 dB로 맞춰 감쇠를 비교하기 쉽게 합니다. 이 피크가 반드시 0 ms에 있는 것은 아닙니다. 기본 시점에서는 깊이 0이 뒤쪽에, 이후 값이 앞쪽에 놓입니다. 주파수·dB 범위와 첫 번째·마지막 슬라이스를 설정하세요. 시점 조절부에서 회전·고도·확대율을 조절하거나, 드래그하여 회전하고 휠 또는 + / −로 확대·축소할 수 있습니다. **시점 초기화**는 분석 설정을 바꾸지 않고 시점만 되돌립니다. **Waterfall**의 깊이는 ms 단위 시간이며, 창 길이·상승 시간·창 모양·평활화를 조절합니다. 창이 길면 가까운 주파수를 구별하기 쉽지만 시간 변화는 흐려집니다. 상승 구간도 시간 해상도에 영향을 미칩니다. 저장된 응답 안에 창 전체가 들어가는 구간만 표시됩니다. **Burst Decay**는 대역폭이 1/3옥타브로 고정된 가우스 형태 톤 버스트의 포락선을 표시합니다. 깊이 축은 ms 단위 **시간** 또는 **주기 수**로 선택하며, 초기 주기 범위는 0–30입니다. 주기 수로는 진동이 몇 주기 동안 지속되는지 비교할 수 있습니다. 1주기는 100 Hz에서 10 ms, 1 kHz에서 1 ms이므로 같은 주기 수라도 경과 시간은 다릅니다. 버스트 자체의 길이도 표시되는 감쇠에 포함됩니다. 이 추정은 첫 저장 샘플 이전을 무음으로 가정하면서 시작점 이전에 저장된 샘플은 유지합니다. 후반의 빈 영역은 녹음된 꼬리가 부족하다는 뜻이며, 무음을 뜻하지 않습니다.
- **측정 상세 정보**에서는 취득 방법, 보정, 샘플링 주파수, 시간 기준, 저장 길이, 사용 가능한 분석을 확인합니다. JSON 내보내기도 여기서 합니다. 임펄스 응답을 포함하면 사용 가능한 고조파 데이터도 포함됩니다. 포함하지 않은 JSON에는 주파수 결과가 남지만 시간 응답이나 왜곡 분석은 복원할 수 없습니다.

범례와 위치 읽기로 마우스·터치·키보드에서 값을 확인할 수 있습니다. 자동 범위와 초기화를 사용하면 보기 편한 화면으로 돌아갈 수 있습니다. 표시 레벨은 상대값이며 보정된 음압 레벨이 아닙니다. 주파수 판독값에는 15°C·1기압의 건조한 공기에서 음속 340.3 m/s로 계산한 한 파장의 길이도 λ로 표시되며, 단위는 m입니다.

네 그래프 위에 있는 카메라 아이콘(**이미지 복사**)을 사용하면 고해상도 PNG를 클립보드에 복사하여 프레젠테이션이나 블로그 편집기에 붙여넣을 수 있습니다. 현재 시점과 테마, 제목, 선택한 측정, 표시 중인 범례와 색상 눈금이 포함되며, 커서와 설정 조작부는 포함되지 않습니다.

새 측정에는 지수 사인 스윕(ESS)을 사용합니다. 낮은 출력 레벨에서 시작해 클리핑이 생기지 않도록 조절하세요. 왜곡 분석에는 해당 측정의 유효한 고조파 데이터가 필요합니다. 가져온 WAV나 주파수 응답·선형 IR만 있는 측정으로는 구할 수 없습니다. 필요한 데이터가 없으면 해당 응답이 포함된 측정 파일을 가져오거나 새로 측정하세요. 사용 가능한 범위는 스윕 대역과 녹음 길이에도 영향을 받습니다. 고조파를 분리하기 위해 요청한 스윕 길이보다 길어질 수 있습니다. 매회 감쇠를 기다리는 2.5초도 포함됩니다. 대역 제한이 Off이면 ESS는 실제 샘플링 주파수가 허용하는 범위에서 20 Hz~20 kHz를 사용합니다.

현재 파이프라인의 Frequency, Phase, Min Group Delay, Excess Group Delay, Impulse 응답을 선택한 최대 네 개의 출력과 필요에 따라 저장된 스피커 응답까지 포함해 확인하는 방법은 [Pipeline Analyzer 가이드](pipeline-analyzer.md)를 참조하세요.
