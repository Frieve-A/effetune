# 컨트롤러 매핑

화면의 컨트롤을 드래그하지 않고도 이펙트 파라미터를 조절할 수 있습니다. EffeTune에 포커스가 있는 동안 MIDI 컨트롤러, 게임패드 또는 키보드를 사용할 수 있으며 변경 내용은 화면에도 반영됩니다.

## 매핑 추가

1. **Settings**에서 **컨트롤러 매핑...**을 엽니다.
2. **추가(Learn)**를 선택하고 컨트롤을 움직이거나 키 또는 게임패드를 조작합니다.
3. 대상 이펙트, 인스턴스 규칙, 파라미터를 선택합니다.
4. 필요하면 Min, Max, Sensitivity, 방향, 입력 모드를 조절합니다. 변경 내용은 즉시 저장됩니다.

증가와 감소를 별도 버튼이나 키에 지정하려면 매핑을 두 개 만들고 하나는 **+**, 다른 하나는 **−**로 설정합니다. EffeTune 단축키와 겹치면 경고가 표시되며 앱에 포커스가 있을 때는 컨트롤러 매핑이 우선합니다.

버튼 매핑에서는 **버튼 모드**를 선택합니다. **토글**은 누를 때마다 상태를 바꾸고, **순간 동작**은 누르고 있는 동안에만 활성화됩니다.

## 시간 또는 무작위 변화 자동화

물리 컨트롤러 없이 숫자 파라미터를 바꾸려면 **자동화 추가**를 선택하세요. 새 매핑은 안전한 1초 간격의 **타이머**로 시작합니다. **시계**에서는 **시**, **분**, **초** 중 하나와 **상승**, **사인**, **코사인** 파형을 선택합니다. 현재 지역 시간을 1초마다 읽어 최소와 최대 사이에 적용합니다.

타이머에서는 **간격(초)**을 1 이상으로 설정합니다. **지정한 양만큼 변경**은 이벤트마다 **변화량**을 더하거나 빼고, **범위에서 무작위 값**은 최소와 최대 사이에서 새 값을 고릅니다. **현재 값에서 무작위로 한 단계**는 현재 값에서 변화량만큼 위나 아래로 이동합니다.

**일정**에서 **간격**, **한 번**, **매일**을 선택할 수 있습니다. 간격은 1~2,147,483.647초이며 앱이 실행되는 동안의 경과 시간을 잽니다. 실행이 늦어지면 한 번만 변경하고 그 시점부터 다음 간격을 다시 세며, 놓친 이벤트는 반복하지 않습니다. 한 번은 현지 **날짜**와 **시간**을 사용하고, 매일은 현지 시간을 사용하며 오늘 시간이 지났다면 다음 날까지 기다립니다. 두 방식 모두 컴퓨터의 현지 달력과 시계를 따르므로 수동 시각 변경과 일광 절약 시간제도 반영하며, 매일은 같은 현지 날짜에 최대 한 번만 실행됩니다. 지난 한 번 일정은 **만료됨**으로 표시되고 나중에 실행되지 않습니다. 날짜나 시간을 미래로 바꾸면 다시 대기합니다.

시계와 타이머 자동화는 이펙트의 숫자 파라미터에만 사용할 수 있으며 Enabled, 목록, Master Bypass, A/B Toggle에는 사용할 수 없습니다. 숫자 파라미터에 매핑한 물리 버튼이나 키에서도 무작위 동작을 선택할 수 있습니다. 앱이나 컴퓨터 때문에 타이머 이벤트가 늦어지면 재개할 때 한 번만 변경되며 놓친 이벤트를 되풀이하지 않습니다. 같은 설정을 반복해도 같은 무작위 순서가 재현되지는 않습니다.

**첫 번째**와 **마지막**은 일치하는 첫 번째 또는 마지막 이펙트를 선택합니다. **모두**는 모든 일치 항목에 같은 값을 적용하며 상대 조작의 시작값은 첫 번째 항목을 사용합니다. **Enabled**는 이펙트를 켜거나 끄고 **전체**에는 Master Bypass와 A/B Toggle이 있습니다. Min과 Max는 범위를 제한하며 해당 파라미터에 표시된 단위로 입력합니다. 서로 바꾸면 방향이 뒤집힙니다. Sensitivity는 먼저 1로 사용해 보세요.

## 입력 종류

- **MIDI:** Web MIDI를 통해 CC, 노트, 피치 벤드를 지원합니다. CC는 절대값이 기본이며 엔드리스 인코더에는 맞는 상대 모드를 선택합니다. Chromium과 Firefox는 Web MIDI를 지원하지만 Safari는 지원하지 않습니다. OS가 MIDI 포트로 제공하면 BLE-MIDI와 네트워크 MIDI도 사용할 수 있습니다.
- **Mackie Control(MCU):** protocol을 **MCU**로 선택합니다. 모터 페이더와 터치, V-Pot과 LED 링, 버튼 LED를 지원합니다. LCD 문자, 미터, 시간 표시, 핸드셰이크는 지원하지 않습니다. Generic과 MCU를 바꾼 뒤에는 다시 Learn하세요.
- **게임패드:** 버튼은 단계 이동이나 토글에 사용하며 연속값과 목록은 길게 눌러 반복할 수 있습니다. 축은 자동으로 중앙에 돌아오는 스틱에 알맞은 상대 모드가 기본입니다. 중앙에 돌아오지 않는 컨트롤에는 절대 모드를 사용하세요.
- **키보드:** EffeTune에 포커스가 있을 때만 작동하고 텍스트 입력 중에는 작동하지 않습니다. 토글은 OS 키 반복을 무시하지만 증가와 감소는 길게 눌러 반복할 수 있습니다.

## 연결 및 문제 해결

장치를 분리해도 매핑은 저장되며 같은 이름의 장치가 다시 연결되면 작동을 재개합니다. OS나 드라이버 변경으로 이름이 바뀌면 해당 매핑을 다시 Learn하세요. 같은 게임패드는 매핑을 공유하며 이름이 같은 MIDI 포트는 연결 순서로만 구분됩니다.

MIDI 장치가 나타나지 않으면 EffeTune의 MIDI 접근을 허용한 뒤 창을 다시 여세요. Safari에서도 키보드와 게임패드는 사용할 수 있습니다.
