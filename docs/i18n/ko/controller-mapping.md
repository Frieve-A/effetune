# 컨트롤러 매핑

컨트롤러 매핑을 사용하면 화면의 컨트롤을 마우스로 드래그하지 않고도 이펙트 파라미터를 조절할 수 있습니다. EffeTune에 포커스가 있는 동안 MIDI 컨트롤러, 게임패드, 키보드 키를 사용할 수 있으며, 변경 사항은 이펙트 UI와 동일한 파라미터 범위를 사용하고 화면에도 즉시 반영됩니다.

## 매핑 추가

1. **설정**을 열고 **컨트롤러 매핑...**을 선택합니다.
2. **추가(Learn)**를 선택합니다.
3. MIDI 컨트롤을 움직이거나 키를 누르거나 게임패드 버튼 또는 축을 조작합니다.
4. 대상 이펙트, 인스턴스 규칙, 파라미터를 선택합니다.
5. 필요에 따라 최소, 최대, 감도, 방향, 입력 모드를 조절합니다. 변경 사항은 즉시 저장됩니다.

증가와 감소를 별도의 버튼이나 키로 나누어 쓰려면 매핑을 두 개 만드세요. 하나는 **방향**을 **증가 (+)**로, 다른 하나는 **감소 (−)**로 설정합니다. 학습한 키가 기존 EffeTune 단축키와 겹치면 대화상자에 경고가 표시되며, 앱에 포커스가 있는 동안에는 매핑이 우선 적용됩니다.

버튼 매핑에서는 **버튼 모드**를 선택합니다. **토글**은 누를 때마다 상태를 전환하고, **순간 동작**은 컨트롤을 누르고 있는 동안에만 활성화됩니다.

## 조작 대상 선택

- **첫 번째**는 현재 파이프라인에서 첫 번째로 일치하는 이펙트를 조작합니다.
- **마지막**은 마지막으로 일치하는 이펙트를 조작합니다.
- **모두**는 일치하는 모든 이펙트에 같은 값을 보내며, 상대 조작 시 시작값은 첫 번째 이펙트를 기준으로 삼습니다.
- **활성화**는 이펙트를 켜거나 끕니다.

**전체**는 개별 이펙트 대신 앱과 음악 플레이어를 조작합니다: **마스터 바이패스**, **A/B 전환**, **재생/일시 정지**, **정지**, **다음/이전 트랙**, **10초 앞으로/뒤로**, **재생 속도**, **피치 유지**, **반복**, **셔플**, **다음/이전 프리셋**.

- **다음/이전 트랙**, **10초 앞으로/뒤로**, **다음/이전 프리셋**에서는 **방향**으로 **증가 (+)**(앞으로) 또는 **감소 (−)**(뒤로)를 정합니다. 엔드리스 인코더나 조그 휠은 돌리는 방향을 따릅니다.
- **재생 속도**는 페이더나 노브로 조작할 때 연속으로 바뀌며(중앙이 `1x`), 버튼이나 키에 매핑하면 표준 속도를 한 단계씩 이동합니다.
- **다음/이전 프리셋**은 사용자 프리셋을 이름순으로 순환하며 전환합니다.
- 플레이어 동작은 음악 플레이어가 열려 있어야 작동합니다. 브라우저 자동 재생 규칙 때문에 오디오 시작이 차단된 경우 먼저 플레이어 UI에서 재생 버튼을 한 번 눌러 주세요.

**최소**와 **최대**는 파라미터의 작동 범위를 해당 파라미터 단위로 제한하며, 두 값을 서로 바꾸면 조작 방향이 반전됩니다. **감도**는 상대 조작의 단계 크기를 조절합니다(`1`부터 시작해 보세요).

## 시간 기반 또는 무작위 자동화 추가

물리 컨트롤러 없이 숫자형 이펙트 파라미터를 자동으로 변화시키려면 **자동화 추가**를 선택하세요. 먼저 대상 이펙트와 파라미터를 고른 뒤 다음 항목을 설정합니다:

- **입력**: **타이머**(기본값, 1초 간격) 또는 **시계**를 선택합니다.
- **시계**: **시간 단위**에서 **시**, **분**, **초**를 고르고, **파형**에서 **상승**, **사인**, **코사인**을 선택합니다. 현재 로컬 시각을 1초마다 읽어 **최소**와 **최대** 사이의 값으로 매핑합니다.
- **타이머**: **일정**에서 **간격**, **한 번**, **매일**을 제공합니다. **간격**은 `1`~`2,147,483.647`초 범위의 **간격(초)**을 사용합니다. **한 번**은 지정한 로컬 **날짜**와 **시간**에 작동하며, **매일**은 달력 날짜마다 지정한 로컬 **시간**에 한 번씩 작동합니다.
- **동작**(타이머 및 숫자형 버튼/키 매핑): **지정한 양만큼 변경**은 매번 **변화량**을 더하거나 빼고, **범위에서 무작위 값**은 **최소**와 **최대** 사이에서 새 값을 고르며, **현재 값에서 무작위로 한 단계**는 현재 값에서 **변화량**만큼 무작위로 위나 아래로 이동합니다.

시계 및 타이머 자동화는 숫자형 이펙트 파라미터에만 적용되며(**활성화**, 목록형 파라미터, **전체** 조작에는 적용 불가), 최대 1초에 한 번 실행됩니다. **간격** 타이머 실행 시점에 앱이나 컴퓨터가 일시 정지 또는 절전 상태였다면, 다시 깨어날 때 한 단계만 적용한 뒤 그 시점부터 다음 간격을 새로 셉니다. EffeTune이 닫혀 있는 동안 예정 시각이 지난 **한 번** 일정은 **만료됨**으로 표시되며, 미래의 **날짜**나 **시간**으로 다시 설정하면 재활성화됩니다.

### 설정 예시

- Vinyl Simulator의 Radius: **타이머**를 선택하고 **간격(초)**을 `1`로 설정한 뒤 **지정한 양만큼 변경**을 고릅니다. **방향**을 **감소 (−)**, **변화량**을 `1 mm`, **최소**와 **최대**를 `60`과 `146 mm`로 설정하면 바늘이 바깥쪽 가장자리에서 안쪽 홈으로 이동한 뒤 **최소** 위치에서 멈춥니다.
- 시간대에 따른 음색 변화: **시계**에서 **분**과 **사인**을 선택해 Radio Simulator의 숫자 파라미터를 **최소**와 **최대** 사이에서 부드럽게 왕복시킵니다.
- 느린 무작위 드리프트: **타이머**의 간격을 길게 잡고 **현재 값에서 무작위로 한 단계**를 선택한 뒤, 작은 **변화량**부터 시작하면 변화가 완만하게 이어집니다.
- 예약 변경: 특정 로컬 날짜와 시각에 한 번만 바꾸려면 **한 번**을, 매일 같은 로컬 시각에 바꾸려면 **매일**을 선택합니다.

## 입력 종류

### MIDI

EffeTune은 Web MIDI를 통해 MIDI CC, 노트, 피치 벤드를 지원합니다(Chromium 브라우저, Firefox, 데스크톱 앱에서 사용 가능하며 Safari는 미지원). 일반 장치는 절대값 CC 입력이 기본값이며, 엔드리스 인코더는 알맞은 상대 모드를 선택하세요. BLE-MIDI와 네트워크 MIDI도 OS에서 MIDI 포트로 인식되면 사용할 수 있습니다.

### Mackie Control(MCU)

호환 컨트롤 서피스는 장치 프로토콜을 **MCU**로 설정하세요. 모터 페이더, 페이더 터치, V-Pot 입력, LED 링, 버튼 LED를 지원합니다(LCD 텍스트, 레벨 미터, 타임코드 표시, 장치 핸드셰이크는 사용하지 않음). 장치를 **Generic**과 **MCU** 사이에서 전환한 뒤에는 매핑을 다시 학습(Learn)하세요.

### 게임패드

버튼으로 파라미터를 토글하거나 단계별로 조절할 수 있으며, 누르고 있으면 반복 작동합니다. 스틱 축은 손을 떼어 중앙으로 돌아와도 변경된 값이 그대로 유지되도록 상대 모드가 기본값이며, 위치가 고정되는 스로틀 형태 축에는 절대 모드로 전환해 사용하세요.

### 키보드

키보드 매핑은 EffeTune에 포커스가 있는 동안 작동하며 텍스트 입력란에 글자를 입력할 때는 무시됩니다. 토글 매핑은 키 반복 입력을 무시하고, 증가/감소 매핑은 키를 누르고 있으면 OS의 키 반복 속도에 맞춰 반복됩니다.

## 연결 및 문제 해결

각 MIDI 장치 이름 아래에는 **연결됨** 또는 **연결 끊김** 상태가 표시됩니다. 컨트롤러 연결을 해제해도 매핑은 그대로 저장되며, 동일한 MIDI 포트 이름이나 게임패드 이름을 가진 장치가 다시 연결되면 자동으로 복구됩니다. 드라이버나 OS 업데이트로 장치 이름이 바뀌었다면 해당 매핑을 다시 학습(Learn)하세요. 이름이 같은 게임패드는 매핑을 공유하며, 이름이 같은 MIDI 포트는 연결된 순서로만 구별됩니다. MIDI 장치가 나타나지 않으면 MIDI 권한을 허용한 뒤 **컨트롤러 매핑...**을 다시 여세요. Safari에서도 키보드와 게임패드 매핑은 사용할 수 있습니다.
