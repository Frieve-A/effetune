# Visualizer

Visualizer는 EffeTune에서 처리된 오디오를 원하는 구성의 화면으로 시각화합니다. 파형, 스펙트럼, 시간순으로 흐르는 스펙트로그램, 스테레오 이미지, 음표 스펙트로그램을 앨범 아트, 동영상, 곡 정보와 함께 배치할 수 있으며, 화면 설정을 바꿔도 소리는 변하지 않습니다.

## 열기와 표시

PC에서는 **Effect Pipeline**과 **음악 라이브러리** 옆의 **Visualizer**를 선택하고, 모바일에서는 오른쪽 상단의 **Visualizer** 아이콘을 탭합니다. 데스크톱 앱에서는 **보기 > Visualizer** 메뉴로도 열 수 있으며, [브라우저 확장 프로그램](browser-extension.md)에서는 Pipeline Editor 헤더의 **Visualizer**를 선택합니다. **설정 > 구성...**에서 Visualizer를 시작 시 표시할 화면으로 지정할 수도 있습니다. Visualizer를 선택하고 **시작 시 앱 창 가득 표시**를 켜면 다음 실행부터 Visualizer가 앱 창을 가득 채워 열립니다.

먼저 기본 내장 프리셋을 선택해 시작해 보세요. 프리셋은 16:9, 21:9, 4:3, 1:1, 9:16 비율별로 묶여 있으며, 현재 앱 창의 가로세로 비율에 가까운 그룹부터 위에 표시됩니다. 프리셋을 선택하면 현재 레이아웃이 대체됩니다. 그래프에는 활성화된 모든 이펙트를 거쳐 출력으로 나가기 직전의 오디오 신호가 표시됩니다.

모든 화면 비율에서 공통 프리셋 11가지를 사용할 수 있습니다:
- **Mastering Console**: 좌우 채널을 겹친 스펙트럼, 스펙트로그램, 스테레오 표시, 라우드니스 미터, 세그먼트 레벨 미터를 어두운 패널 위에 배치합니다.
- **Spectral Studio**: 큼직한 고해상도 스펙트로그램과 세로 막대 스펙트럼을 함께 배치합니다.
- **Harmony Lab**: 감지된 음을 피아노 롤 형태로 보여 주고, 음이름(피치 클래스) 분포를 크로마 스파이럴로 표시합니다.
- **Phosphor Scope**: 아날로그 CRT 모니터 같은 녹색 잔광으로 오실로스코프와 스테레오 표시를 그립니다.
- **Hi-Fi Deck**: 클래식 하이파이 오디오의 형광 표시관(VFD) 스타일로 세그먼트 스펙트럼과 레벨을 표시합니다.
- **Vintage VU**: 월넛 베젤과 은은한 조명이 비치는 크림색 문자판을 갖춘 VU 미터로 좌우 채널을 표시합니다.
- **Now Playing**: 흐리게 처리한 아트워크 배경 위에 앨범 아트, 곡 정보, 스펙트럼 막대를 배치합니다.
- **Neon Pulse**: 반사 효과가 있는 네온 막대 스펙트럼과 저음에 맞춰 고동치는 배경을 결합합니다.
- **Phase Galaxy**: 위상 맵을 빛나며 회전하는 별처럼 표현합니다.
- **Chroma Mandala**: 크로마 스파이럴을 만화경처럼 표현합니다.
- **Groove Lounge**: 앨범 아트와 곡 정보에 감지된 코드와 조성, 연주에 맞춰 빛나는 드럼 세트를 함께 표시합니다. 차분한 청록색과 금색을 사용하며, 은은한 스펙트럼과 재생 버튼, 탐색 막대, 경과 시간도 볼 수 있습니다.

가장 잘 어울리는 화면 비율에 맞춰 추가 프리셋 9가지도 제공됩니다:
- **Fretboard**(21:9, 9:16): 감지된 음을 기타 넥 위에 비트 표시와 함께 보여 주며, 21:9 레이아웃에서는 넥 위에 피아노 롤 보기가 추가됩니다.
- **Power Amp**(21:9, 16:9): 검은색 앰프 전면 패널에 푸른빛 VU 미터를 나란히 배치합니다.
- **Round Dials**(1:1, 9:16): 황동 테두리에 담긴 원형 VU 미터입니다.
- **Beat Stage**(16:9, 9:16): 저음에 반응하는 커다란 비트 원 안에 감지된 템포를 표시하고 네온 스펙트럼 막대를 곁들입니다.
- **Lyric Stage**(16:9, 9:16): 저음에 반응하는 아트워크 불빛 위에 동기화된 가사를 표시하고 현재 줄을 단어 단위로 채워 나갑니다(가사가 없는 곡에서는 차분한 아트워크 화면으로 표시).
- **Cinema Strip**(21:9): 화면 전체 폭을 가로지르는 스펙트로그램, 10초 파형, 가로 스크롤 가사를 배치합니다.
- **Meter Bridge**(21:9, 4:3): 레벨 미터와 파형 띠 위에 True Peak, VU, 느린 RMS, 라우드니스 미터를 나란히 배치하여 같은 음악에 각 미터가 어떻게 반응하는지 비교할 수 있습니다.
- **Counter Gallery**(16:9): 기계식, LED, VFD, LCD, 도트 매트릭스, 플립, 닉시관 스타일의 카운터 8개가 함께 움직입니다. 30 fps로 계산한 프레임 표시도 포함됩니다. 움직임을 비교하거나 감상하고, 원하는 Counter만 자신의 레이아웃에 복사할 수 있습니다.
- **Listening Room**(16:9): 큰 앨범 아트와 곡 정보에 재생 버튼, 탐색 막대, 경과 시간, 은은한 스펙트럼 띠를 더한 레이아웃입니다. 짙은 흑연색 배경에 따뜻한 색조를 조합했습니다.

화면에 포인터를 올리거나 탭하면 **⛶** 버튼이 나타납니다. 선택하면 지정한 화면 비율을 유지한 채 앱 창을 가득 채우며(가장자리가 일부 잘릴 수 있음), **⛶**를 다시 누르거나 **Esc** 또는 모바일 뒤로 가기를 누르면 원래대로 돌아옵니다. 데스크톱 앱에서 Visualizer가 열린 상태로 미니 플레이어로 전환하면 재생 컨트롤 위에 화면이 표시됩니다.

디스플레이가 두 대 이상 연결된 데스크톱 앱에서는 **보기 > Visualizer 클린 피드**를 사용해 선택한 디스플레이에 창 테두리나 조작 버튼 없이 Visualizer를 전체 화면으로 띄울 수 있습니다. 레이아웃 비율은 그대로 유지되며 남는 공간은 검은 여백으로 채워집니다. 클린 피드가 켜져 있는 동안에는 앱 안의 Visualizer 미리보기도 피드 해상도에 맞춰 렌더링되어 두 화면이 일치합니다. 다른 앱이 활성 상태일 때(같은 메뉴에서 **비활성 상태에서도 표시**를 켠 경우 제외), 메인 창이 해당 디스플레이와 겹칠 때, 또는 이중 맹검 테스트 중에는 클린 피드가 자동으로 숨겨집니다. 중지하려면 **끄기**를 선택하거나 피드 화면을 클릭한 뒤 **Esc**를 누르세요. 디스플레이가 한 대뿐이면 이 메뉴는 비활성화됩니다.

## 레이아웃 편집

**Edit**을 선택하면 레이아웃을 직접 꾸밀 수 있습니다. 변경 사항은 즉시 반영되며 다음에 EffeTune을 열 때도 복원됩니다. 편집만으로는 저장된 프리셋이 덮어써지지 않으므로, 이름을 붙여 보관하려면 프리셋 대화상자에서 **저장**을 사용하세요.

편집 모드에서는 왼쪽 패널에 전체 장면 설정과 항목 목록 및 **화질**이 표시되고, 가운데에 캔버스, 오른쪽에 선택한 항목의 세부 컨트롤이 표시됩니다. 숫자 설정은 슬라이더로 조절하거나 값을 직접 입력할 수 있습니다.

정밀하게 배치하려면 캔버스 도구 모음의 **−**와 **+**를 누르거나 **Ctrl+스크롤**(Mac에서는 **Cmd+스크롤**)로 포인터 위치를 기준으로 확대·축소(10~400%)하세요. **전체 보기**를 누르면 프레임 전체가 중앙에 맞춰집니다. 마우스 휠이나 트랙패드로 화면을 이동할 수 있으며(**Shift**를 누르면 가로 스크롤), 마우스 가운데 버튼 또는 **Space+왼쪽 드래그**로도 자유롭게 이동할 수 있습니다. 캔버스에 포커스가 있을 때 **+**와 **−**는 중앙을 기준으로 확대·축소하고 **0**은 전체 보기로 맞춥니다. 화면 이동과 확대·축소는 **실행 취소** 단계에 기록되지 않습니다.

항목을 프레임 밖으로 옮기거나 크기를 키워 넘치게 하면 편집 화면과 일반 화면 모두에서 프레임 가장자리에 맞춰 잘려 보이지만, 편집 영역에서는 선택 핸들을 그대로 조작할 수 있습니다. 예를 들어 **Shape**의 일부를 프레임 바깥에 걸치도록 놓으면 화면 가장자리에 딱 붙는 패널을 만들 수 있습니다.

- 화면 비율, 배경색 또는 배경 이미지를 선택합니다(큰 이미지는 자동으로 축소됨). **테마 색상**에서는 그래프 선 색상 팔레트는 유지한 채 이 레이아웃의 그래프 기본색, 옅은 그래프 채움, 보조·주요 격자선, 그래프 레이블, 축 제목, 미터 눈금 색상을 바꿀 수 있습니다. 변경하지 않은 색상은 EffeTune UI 테마와 관계없이 기본 다크 테마를 따릅니다. 초기화하려면 **기본 색상 사용**을 클릭하세요.
- **그래프 스케일**(×0.50~×3.00, 기본값 ×1.00): 그래프는 작은 창부터 4K까지 화면 크기에 비례해 그려집니다. **그래프 스케일**은 레이아웃 전체의 선, 눈금, 피크 표시, 그래프 레이블을 한꺼번에 키우거나 줄이며, Title, Album, Artist, Text는 고유 글자 크기를 유지합니다.
- **Oscilloscope**, **Spectrum**, **Spectrogram**, **Stereo**, **Level Meter**, **Analog Meter**, **Notes**, **Drums**, **Guitar**, **Chroma Spiral**, **Phase Map**, **Rhythm Analyzer** 그래프나 **Lyrics**, **Artwork**, **Video**, **Title**, **Album**, **Artist**, **트랙 정보**, **Playback Control**, **Seek Bar**, **Counter**, **Key**, **Chord**, **Text**, **Shape**를 추가할 수 있습니다. 항목을 드래그해 이동하고 핸들을 드래그해 크기를 조절합니다(**Shift**는 비율 유지, **Ctrl**/**Cmd**는 중심 기준 크기 조절). **격자에 맞추기**로 정렬하거나 드래그 중 **Alt**를 눌러 스냅을 일시 해제할 수 있습니다. **위로 이동**, **아래로 이동**, **맨 앞으로 가져오기**, **맨 뒤로 보내기**로 레이어 순서를 조정합니다(목록 아래쪽에 있을수록 화면 앞에 표시). **Ctrl+D**(Mac에서는 **Cmd+D**) 또는 **Alt+드래그**로 선택한 항목을 복제할 수 있습니다.
- 캔버스나 목록에서 **Shift+클릭**(목록에서는 **Ctrl/Cmd+클릭**도 가능)하여 여러 항목을 선택하거나, 빈 캔버스에서 선택 상자를 드래그합니다(**Shift+드래그**는 선택에 추가). 항목이 겹친 곳에서 **Ctrl+클릭**(Mac에서는 **Cmd+클릭**)하면 포인터 아래의 뒤쪽 항목들을 순서대로 선택합니다. **Ctrl+A**(**Cmd+A**)는 전체 선택, **Esc**는 선택 해제입니다. 이동, 삭제, 복제, 잘라내기, 복사, 붙여넣기는 선택한 모든 항목에 함께 적용됩니다. 선택한 항목이 모두 같은 종류이면 오른쪽 패널의 편집 내용과 가장자리·중앙 정렬 버튼이 전체 선택 항목에 일괄 적용됩니다.
- **실행 취소**와 **다시 실행**(**Ctrl+Z** / **Ctrl+Y**, Mac에서는 **Cmd**)으로 현재 세션 동안의 레이아웃 편집, 프리셋 불러오기, 링크 가져오기를 되돌리거나 다시 적용할 수 있습니다. **항목 잘라내기**, **항목 복사**, **항목 붙여넣기**(**Ctrl+X**, **Ctrl+C**, **Ctrl+V**)로 클립보드를 통해 항목을 옮길 수 있으며, **항목 붙여넣기**는 클립보드에 복사된 Visualizer 공유 링크도 바로 가져옵니다. **Delete** 키로 선택 항목을 삭제하며, 캔버스를 우클릭(또는 길게 누르기)하면 이러한 명령을 빠르게 실행할 수 있습니다.
- 각 그래프는 기본적으로 출력 채널 1–2를 표시합니다. 단일 채널을 선택하면 그래프 전체에 해당 채널을 그리며(Level Meter와 Analog Meter에서는 단일 막대/미터로 표시), 가로축이나 세로축을 반전할 수도 있습니다.
- **색상 모드**: **단색**은 단일 색상 선택기를 사용하며, **그라데이션**은 편집 가능한 색상 지점과 24가지 프리셋을 제공합니다(프리셋 선택 후 **적용** 클릭). **그라데이션 반전**은 색상 지점 순서를 뒤집습니다. **Hue**는 시간에 따라 색조를 순환시키고 **Scroll**은 그라데이션을 이동시키며, **속도**와 **색상 움직임 반전**을 조절할 수 있습니다.

**Title**, **Album**, **Artist**마다 글꼴, 크기, 가로/세로 정렬, 자간, 대소문자, **굵게**, **기울임꼴**, **외곽선**, **그림자**를 개별 설정할 수 있습니다. **Artwork**와 **Video**에는 **둥근 모서리**를 적용할 수 있습니다.

**트랙 정보**를 추가하면 현재 파일이나 네트워크 곡에서 제공하는 태그와 오디오 형식을 표시할 수 있습니다. AirPlay에서는 송신 기기 정보, 수신 코덱, 수신 PCM 형식, 송신 기기 음량도 제공되는 경우에 표시합니다. 없는 항목은 표시하지 않습니다. 글자 모양은 Title과 같은 설정으로 조절합니다. **Title**, **Artist**, **Album**, **Artwork**에도 AirPlay 송신 기기에서 보낸 정보가 표시됩니다.

고정 라벨이나 청취 공간 이름을 표시하려면 **Text**를 추가하세요(최대 4096자, 여러 줄 지원). Title과 동일한 타이포그래피, 외곽선, 그림자 컨트롤을 사용할 수 있습니다.

**Playback Control**을 추가하면 레이아웃에 플레이어 버튼을 배치할 수 있습니다. **동작**에서 **재생 / 일시 정지**, **정지**, **이전 곡**, **다음 곡**, **셔플**, **반복**을 선택하고 원하는 버튼마다 아이템을 추가하세요. **Edit** 밖에서 버튼을 클릭하거나 탭하고, 또는 **Tab**으로 포커스를 옮긴 뒤 **Enter**나 **Space**를 누르면 조작할 수 있습니다. 플레이어가 열려 있을 때 사용할 수 없는 버튼은 흐리게 표시됩니다. 한 곡 반복 중에는 셔플을 사용할 수 없습니다.

- **모양**의 **미니멀**, **유리**, **입체**를 기본으로 원하는 스타일을 만들 수 있습니다. 동작과 배치는 바뀌지 않습니다. **버튼 모양**은 **둥근 직사각형**이나 **타원**을 선택합니다. 타원의 너비와 높이를 같게 하면 원이 됩니다. **채우기 색상**과 **채우기 불투명도**로 배경을, **테두리 색상**과 **테두리 두께**로 테두리를 조정합니다(두께 0은 테두리 숨김). **모서리 반경**은 직사각형의 모서리를 둥글게 합니다. **표면 입체감**을 높이면 음영이 강해지고, 0으로 설정하면 평평해집니다.
- **표시 내용**은 **아이콘**, **아이콘과 라벨**, **라벨** 중에서 선택합니다. **아이콘 크기**로 기호의 크기를 조정하고, **사용자 지정 라벨**을 비워 두면 동작 이름이 자동으로 표시됩니다. 라벨을 표시하는 모드에서는 일반 텍스트 스타일도 사용할 수 있습니다. 팔레트로 아이콘과 라벨의 색상을 설정하며, **활성 색상**은 켜진 셔플과 반복을 강조합니다. 기존 아이템 효과도 함께 사용해 레이아웃과 어울리게 꾸밀 수 있습니다.

**Seek Bar**를 추가하면 가로 재생 위치 막대를 배치할 수 있습니다. **Edit** 밖에서 클릭하거나 드래그해 위치를 선택하고 놓으면 해당 위치로 이동합니다. **Tab**으로 포커스를 옮긴 뒤 화살표 키, **Home**, **End**로도 조작할 수 있습니다. 현재 곡의 재생 위치를 변경할 수 없으면 막대가 흐리게 표시됩니다.

- **모양**의 **슬림**, **클래식**, **굵게**를 기본으로 스타일을 조정할 수 있습니다. **막대 색상**, **막대 불투명도**, **막대 두께**로 배경 막대를 조정하고, **둥근 끝**으로 양 끝을 둥글게 만듭니다. 재생된 부분의 색상은 팔레트로 설정합니다. **손잡이 표시**로 재생 위치 표시를 켜거나 끄고, **손잡이 크기**와 **손잡이 색상**으로 모양을 조정합니다. **손잡이 모양**은 **원**, **정사각형**, **마름모**, 세로 **막대** 중에서 선택합니다. **손잡이 테두리 두께**와 **손잡이 테두리 색상**으로 윤곽선을 추가하며, 두께를 0으로 설정하면 테두리가 숨겨집니다. 기존 아이템 효과도 적용할 수 있습니다.

플레이어가 일시 정지 또는 정지 상태여도 Playback Control과 Seek Bar는 표시됩니다. 열린 플레이어가 없으면 Clean Feed를 포함해 **Edit** 밖에서는 둘 다 숨겨집니다. 에디터에서는 계속 설정할 수 있습니다.

**Counter**를 추가하면 내장 플레이어의 현재 재생 위치를 표시하며 일시 정지와 탐색을 반영합니다. 외부 입력에서는 Counter를 추가하거나 현재 세션에서 레이아웃을 불러온 시점부터 경과 시간을 세며, Visualizer를 숨겨도 계속됩니다. **Edit** 밖에서 클릭하거나 탭하면 해당 Counter의 외부 입력용 시간만 0으로 돌아갑니다. 플레이어 재생에는 영향을 주지 않습니다.

AirPlay 수신 중에는 송신 기기에서 곡의 재생 위치를 보내면 **Counter**와 **Seek Bar**에 표시됩니다. 송신 기기의 알림에 따라 갱신됩니다. 탐색과 지원되지 않는 재생 조작은 사용할 수 없습니다. **정지**를 누르면 현재 수신이 끝납니다. 설정과 오디오 형식은 [네트워크 음악 가이드](openhome.md)를 참고하세요.

- **재생목록 번호**, **시간**, **분**, **초**, **초 미만**를 각각 표시하거나 숨길 수 있습니다. 기본 표시는 `hh:mm:ss.mmm`이며 번호는 숨겨집니다. 플레이어 재생목록 번호는 1부터 시작하고 외부 입력에서는 00입니다. 표시되는 가장 큰 정수 시간 단위에 누적 시간을 표시합니다. 시간을 숨기면 총 분, 시간과 분을 숨기면 총 초가 됩니다.
- **소수 자릿수**(1–4, 기본값 3)는 소수점 아래 자릿수를 정하며, 3이면 밀리초를 표시합니다. **구분자** › **시간**(`:`), **초 미만**(`.`), **번호**(공백 한 칸)는 각각 최대 8자까지 입력하거나 비워 둘 수 있습니다.
- **초 미만 형식**는 **소수** 또는 **프레임**을 선택합니다. 소수 자릿수는 소수 표시에만 적용됩니다. 프레임은 재생 시간과 선택한 **프레임 레이트**(1–120, 기본값 30)로 계산하며 0부터 설정값보다 1 작은 수까지 표시합니다. 필요하면 영상에 맞는 값을 설정하세요. 파일의 실제 프레임을 정확히 읽어 표시하는 기능은 아닙니다.
- **글꼴**에서 숫자용 **7세그먼트**, **도트 매트릭스**, **와이어 숫자**를 선택할 수 있습니다. 모두 앱에 포함되어 오프라인에서도 사용할 수 있으며, 색상 설정과 **Glow** 효과를 함께 적용할 수 있습니다.
- **전환** › **효과**는 **없음**(기본값), **롤**, **플립**, **크로스페이드** 중에서 선택합니다. 롤에서는 시간의 맨 아래 자릿수가 계속 회전하고 윗자릿수는 올림이 생길 때 움직입니다. 플립은 위아래로 나뉜 표시판을 넘기고, 크로스페이드는 이전 숫자와 새 숫자를 겹치며 전환합니다. **시간**(0–1000 ms, 기본값 150 ms)은 플립과 크로스페이드에 적용됩니다.
- **최소 자릿수**(1–8, 기본값 2)는 표시되는 가장 큰 정수 시간 단위의 최소 자릿수를 정합니다. **앞자리를 0으로 채우기**(기본값 켜짐)를 끄면 0 대신 공백으로 채웁니다. 더 긴 숫자도 생략하지 않고 표시합니다.
- **배경** › **패턴**은 **없음**, **전체 패턴**(7세그먼트 또는 도트 격자 전체, 그 외 글꼴은 8), **모든 숫자**(0–9를 겹쳐 표시) 중에서 선택합니다. **불투명도**와 **색상**으로 활성 숫자 뒤의 희미한 모양을 조절합니다. 꺼진 세그먼트나 도트에는 전체 패턴, 닉시관 같은 모양에는 모든 숫자를 사용하세요.
- **숫자 창** › **표시**를 켜면 각 숫자에 창이 생깁니다. **테두리 색상**, **테두리 두께**, **배경색**, **배경 불투명도**, **모서리 반경**을 조절할 수 있으며, **안쪽 음영**으로 깊이감을 더할 수 있습니다. 플립에는 중앙 이음선과 음영이 자동으로 적용됩니다.
- **프리셋**에서 **기계식**, **빨간색 LED**, **청록색 VFD**, **클래식 LCD**, **도트 매트릭스**, **플립**, **닉시관**를 선택한 뒤 취향에 맞게 조절하세요. 시간 표시 항목, 구분자, 소수 자릿수, 최소 자릿수, 앞자리 0, 위치와 크기는 유지됩니다. 테이프 데크처럼 꾸미려면 **초 미만**을 숨기고 기계식을 선택하세요.

**Lyrics**를 추가하면 내장 플레이어에서 재생 중인 곡의 시간 동기화 가사나 일반 가사를 표시합니다(클린 피드 포함). 오디오 파일에 내장된 태그나 같은 폴더의 동명 `.lrc` 파일에서 가사를 불러오며, CUE 시트 트랙의 경우 `Artist - Title.lrc` 또는 `Title.lrc`가 앨범 단위의 시간 동기화 가사보다 우선합니다. 브라우저에서 음악 파일을 직접 열거나 드롭할 때는 `.lrc` 파일도 함께 선택하거나 드롭하세요. 스트림에는 가사가 없습니다. **Edit** 모드가 아닐 때 시간 정보가 있는 가사 줄을 클릭하거나 탭하면 해당 위치로 즉시 탐색합니다.
- **목록** 또는 **한 줄**(**다음 줄 표시** 선택 가능)을 고를 수 있습니다. 목록 보기는 **스크롤(세로)**, **단계(세로)**, **스크롤(가로)**, **단계(가로)**를 지원하며 **단계 전환 시간**(0~2초, 기본값 0.18초)과 **현재 줄 위치**(0~100%, 기본값 50%)를 조절할 수 있습니다. 단어 단위 시간 정보가 있으면 **단어 강조**가 현재 줄을 점진적으로 채우며, **오프셋**(−10~+10초)으로 싱크를 미세 조정할 수 있습니다. 양수 값이면 가사가 늦게 표시됩니다. 시간 정보가 없는 가사는 항상 목록으로 표시되어 곡 진행에 맞춰 스크롤되며, 강조 표시는 하지 않습니다.
- **줄 간격**(50~300%, 기본값 100%)으로 줄 사이 간격을 조절하고, **페이드 인 시간**(0~10초, 기본값 1초)과 **페이드 아웃 시간**(0~10초, 기본값 3초)으로 각 곡의 시작과 끝에서 Lyrics 항목을 부드럽게 페이드합니다. 0으로 설정하면 해당 페이드가 꺼집니다.

**Video**를 추가하면 내장 플레이어에서 재생 중인 파일의 비디오 스트림을 표시합니다(브라우저/OS가 지원하는 MP4, M4V, MOV, MKV, WebM, 3GP). **맞춤 방식**에서 **전체 표시**(기본값), **채우고 자르기**, **늘이기**를 선택할 수 있으며, **영상이 없으면 아트워크 표시**(기본 켜짐)를 사용하면 오디오 전용 트랙에서 앨범 아트를 대신 보여 줍니다. CUE 시트로 재생한 트랙에서는 영상이 표시되지 않습니다.

**Shape**(**직사각형**, **타원**, **삼각형** 또는 가로 **선**)를 추가하면 **채우기 불투명도**, **테두리 색**, **테두리 두께**, **테두리 불투명도**, **모서리 반경**을 조절해 패널, 프레임, 구분선을 만들 수 있습니다. **타원**의 너비와 높이를 같게 하면 원이 되고, **채우기 불투명도**를 0%로 하면 테두리만 남으며, **테두리 두께**를 0으로 하면 테두리가 사라집니다.

## 그래프 조절과 읽기

**Spectrum**은 주파수별 레벨과 서서히 내려오는 피크 표시를 보여 줍니다. **방향**은 **가로**(기본값)와 **세로** 중에서 선택하고, **표시**는 **선** 또는 **막대**를 선택합니다. **막대**에서는 **밴드 수**(8~128, 기본값 48)로 막대 개수를, **칸당 dB**(0.5~12 dB, 기본값 1 dB, 0이면 **연속**)로 한 칸의 크기를 정합니다(작을수록 단계가 촘촘해짐). **양자화**(기본 켜짐)는 측정 레벨은 바꾸지 않고 막대와 피크를 칸 단위로 맞춥니다. **포인트 수**는 분석 크기로, 늘리면 가까운 주파수를 더 잘 구분하지만 반응은 느려집니다. **주파수 눈금**은 **로그(HQ)**(기본값), **로그**, **선형** 중에서 고르고, **최대 주파수**로 상한(1~40 kHz, 기본값 40 kHz)을 정합니다. **스무딩**은 최대 1옥타브 폭으로 곡선을 완만하게 다듬고(기본값 0), **dB 범위**는 표시할 가장 작은 레벨을 정합니다(기본값 −96 dB, 더 낮은 음수로 하면 더 작은 소리까지 보임). **건반**은 피아노 기준을 추가하고, **건반 길이**로 건반 길이를 정합니다(기본값 100%는 실제 피아노 건반의 절반, 200%는 실제 크기). **건반**, **축과 격자**, **축 레이블과 숫자**는 기본적으로 꺼져 있습니다.

**Spectrogram**은 주파수를 세로로 배치하고 시간에 따라 가로로 흘려 보내며, Spectrum과 동일한 **포인트 수**(기본값 4096), **주파수 눈금**(기본값 **로그(HQ)**), **dB 범위**, **최대 주파수**, **건반** 및 축 컨트롤을 사용합니다.

**Stereo**는 스테레오 이미지를 마름모 위의 점으로 표시합니다(두 채널에 공통된 소리는 세로로, 좌우 차이는 가로로 퍼짐). 피크 윤곽도 함께 그립니다. **피크**, **상관관계**, **밸런스**(모두 기본 켜짐)는 피크 윤곽, 상관 막대(좌우가 같으면 +1, 극성이 반대면 −1), 밸런스 막대(어느 쪽이 더 큰지를 dB로 표시)를 표시하거나 숨깁니다. **창 길이**(10~1000 ms, 기본값 100 ms)는 표시할 최근 소리의 길이입니다. 짧을수록 순간적인 변화를 잘 따라가고, 길수록 표시가 안정적입니다.

**Level Meter**는 채널 레벨(기본 −96~0 dB, **dB 범위** −144~−48 dB)을 가로 또는 세로 방향으로 표시하며, 연속 또는 세그먼트 막대(**칸당 dB**), 피크 홀드 마커, 5초간 유지되는 **OVERLOAD** 클리핑 경고를 제공합니다. **축과 격자**, **축 레이블과 숫자**, **레벨 값**(유지된 피크 값, **피크**가 꺼져 있으면 현재 레벨)으로 눈금과 수치 표시를 전환합니다. 세 가지 모두 기본적으로 꺼져 있으며, **OVERLOAD**는 항상 표시됩니다. 색상은 **단색**, **그라데이션**, **히트맵**을 지원합니다.

**Oscilloscope**는 **표시 시간**(1~10000 ms, 기본값 10 ms) 동안의 파형 진폭을 그립니다. 짧은 구간은 선 궤적으로, 긴 구간은 최소/최대 엔벨로프 띠로 그립니다. **트리거 모드**는 **자동**(기본값, 트리거가 없어도 계속 갱신), **일반**(신호가 **트리거 에지** 방향으로 **트리거 레벨**을 지날 때까지 직전 파형을 유지), **끔**(연속 스크롤 파형, 트리거 설정은 무시) 중에서 선택합니다. **트리거 레벨**(−1~1, 기본값 0), **트리거 에지**(**상승**(기본값) / **하강**), **홀드오프**(0.1~10 ms, 기본값 0.1 ms, 길수록 짧은 간격의 재트리거를 억제)로 파형을 잡는 지점을 정합니다. **표시 레벨**(−96~0 dB, 기본값 0 dB)은 낮출수록 작은 파형을 크게 표시하고, **수직 오프셋**(−1~1, 기본값 0)은 양수 값이면 파형을 위로 올립니다.

**Notes**는 **가로** 또는 **세로** 배치로 1~10초 **표시 시간** 동안 감지된 음높이를 보여 주며, **음높이 해상도**(**1/12 옥타브** 또는 **고해상도**), **음량**(기본 켜짐, 각 음의 상대 음량을 막대 굵기로 표시), **최저음** / **최고음**, 선택형 **건반** 및 축 설정을 제공합니다.

Notes에서 코드 레인과 **Key**를 표시하려면 **Chords & Key**를 켜세요(기본값 꺼짐). **Key**는 현재 구간에서 추정한 키를 표시하며, 키를 식별하지 못하면 사라집니다. 음이름과 코드 이름은 누적된 분석 결과로 추정한 키에 맞춰 # 또는 ♭으로 표기합니다. 표시를 읽는 방법은 [Note Spectrogram](plugins/analyzer.md#note-spectrogram)을 참고하세요.

**Key** 또는 **Chord**를 추가하면 Notes를 배치하지 않아도 조성과 코드 이름을 독립된 텍스트로 표시할 수 있습니다. **Key**는 현재 구간에서 추정한 조성(예: F major)을 표시하고, **Chord**는 누적된 추정 결과로 얻은 조성에 맞는 음이름 표기로 가장 최근에 확정된 코드 이름(예: B♭/D)을 표시합니다. 결과가 없는 항목은 빈칸으로 남습니다. 채널을 선택할 수 있으며 Title과 같은 글꼴, 크기, 정렬, 외곽선, 그림자, 색상 설정을 사용할 수 있습니다.

**Guitar**는 감지된 음높이를 지판 위에 표시합니다. 기타, 베이스, 우쿨렐레 프리셋 **튜닝**을 고르거나 사용자 지정 **개방현**(최대 10줄)을 입력하고 **최저 프렛**, **최고 프렛**, **카포**를 설정하세요. **포지션**에서는 **모든 포지션**(해당하는 프렛 전부), **운지 하나**(음마다 연주 가능한 위치 하나. 음끼리 다른 줄에 나누고, 손을 적게 벌리며, 직전 손 위치에 가까운 곳을 고름), **운지 하나 + 다른 후보**(다른 위치를 흐리게 표시)를 고릅니다. **코드**는 선택한 튜닝, 카포, 프렛 범위에 맞춰 감지된 코드의 추천 운지를 표시합니다. 운지는 가장 최근에 확정된 코드를 따라 바뀌며, 코드가 감지되지 않으면 사라집니다. **라벨**은 **없음**, **음이름 (♯)**, **음이름 (♭)**, **음이름 (감지된 스케일)**(감지된 조성에 따라 # 또는 ♭ 사용), **루트** 기준 **음정** 중에서 고릅니다. **루트**를 **자동 (최저음)**으로 하면 감지된 최저음을 따라가고, 특정 음을 고르면 **스케일 가이드** 오버레이를 켤 수 있습니다. **검출 임계값**(10~90%, 기본값 50%)은 음이 표시되는 데 필요한 세기입니다. 불필요한 음이 깜박이면 높이세요. **음량에 따른 원 크기**는 큰 음일수록 원을 크게 그립니다(가장 작은 음은 3분의 1 크기). 그 밖에 **폴 타임**(0~2초), **배치**(가로 타브 또는 세로 코드 차트), **프렛리스**(벤딩, 비브라토, 슬라이드를 연속적인 위치로 표현), **실제 프렛 간격**, **지판 채우기**, **포지션 마크**, **프렛 번호**, **줄 이름**, **좌우 뒤집기**를 조절할 수 있습니다.

**Drums**는 Kick, Snare, Hi-hat, Tom, Cymbals의 타격이 감지되면 해당 악기가 빛나는 3D 드럼 세트를 보여 줍니다. 음악을 들으며 드럼 리듬을 눈으로 따라갈 수 있습니다. 타격을 놓치거나 다른 소리를 드럼으로 잘못 인식할 수 있습니다. 특히 탐은 오인식이 많으므로 빛나는 모습은 참고용으로 보세요. Rhythm Analyzer에서는 탐을 제외한 네 종류만 표시합니다.

- **수평 시점**(−180°~180°)으로 드럼 세트를 바라보는 방향을 돌립니다. **내려다보는 각도**(5°~80°)를 높이면 더 위에서 바라보게 되어 드럼 헤드가 잘 보입니다.
- **드럼 몸통 색상**, **심벌 색상**, **금속 부품 색상**, **드럼 헤드 색상**으로 각 부분의 색을 바꿉니다. **팔레트**의 **색상**은 타격 시 빛나는 색을 정하며, Drums에서는 **단색**만 사용합니다. 먼저 드럼 세트와 구분되는 발광 색상을 선택하면 타격이 더 잘 보입니다.

**Chroma Spiral**은 감지된 음높이를 **Dots** 또는 **Fill** 모드로 옥타브 나선 위에 배열하며, **최저 옥타브**, **최고 옥타브**, **주파수 기울기**, **레벨 범위**, **표시 하한**을 조절할 수 있습니다.

**Phase Map**은 Phase Select EQ 화면과 동일하게 주파수 성분을 세로축에 놓고 가로축(**X축**)에 좌우 **위상**(중앙 0°, 양 끝 ±180°) 또는 **밸런스**를 표시합니다. 밝고 큰 점일수록 강한 성분입니다. **dB 범위**(−96~−24 dB, 기본값 −72 dB)는 가장 강한 성분 아래로 표시할 범위입니다(더 낮은 음수로 하면 더 작은 성분까지 보임). **기준 레벨 하한**(−120~−24 dB, 기본값 −40 dB)은 기준 레벨의 하한으로, 가장 강한 성분조차 이보다 작으면 점이 작고 흐려집니다. **잔상 시간**(0.1~2.0초, 기본값 0.5초)은 길수록 궤적이 짙게 남습니다. 축은 기본적으로 꺼져 있습니다.

**Analog Meter**는 [Analog Meter](plugins/analyzer.md#analog-meter) 이펙트와 동일한 탄동 특성 및 눈금 컨트롤을 사용해 **VU**(기본값), **PPM**, **RMS**, **Sample Peak**, **True Peak**, **Loudness**, **Custom** 모드의 클래식 바늘 미터를 제공합니다. 선택한 모드에 해당하는 컨트롤만 표시됩니다. **Custom**에서는 **검파기**, **바늘 응답 시간**, **오버슈트**, **눈금**이 추가되어 측정 방식, 바늘 속도, 바늘이 튀는 정도, 눈금을 고를 수 있습니다. 선택한 검파기나 눈금에 해당하지 않는 컨트롤은 그 자리에 남은 채 비활성화됩니다. **Loudness**에서는 Momentary, Short-term, Integrated, LRA, 최대 True Peak를 보여 주는 프로그램 미터가 채널별 미터 앞에 표시됩니다. Integrated, LRA, 최대 True Peak는 Visualizer를 닫거나 숨길 때, 또는 채널, **모드**, **바늘**을 바꿀 때 다시 측정을 시작합니다. 측정 설정 외에도 외관 컨트롤을 조합해 평면 앰프 미터나 둥근 빈티지 다이얼을 디자인할 수 있습니다:
- **눈금 모양**: **눈금 곡률**(0% 직선~100% 원호), **눈금 펼침 각도**(30°~160°, 기본값 100°), **회전축 내리기**(0~100%).
- **바늘 모양**: **바늘 밑부분 숨기기**(0~90%), **바늘 길이**(50~120%, 기본값 102%), **바늘 두께**(0.5~8), **바늘 끝 모양**(**선**, **뾰족한 끝**, 또는 **화살촉 길이·너비 비율** 0.25~4.00을 지원하는 **화살표**), **회전축 표시 크기**(0~20).
- **다이얼 표시**: VU 모드의 **보조 % 눈금** 및 **표시 단위**(100%는 선택한 **기준 레벨**에서의 0 VU이며, 퍼센트가 전압비이므로 50%는 약 −6 VU)와 함께 **수치 표시**, **채널 제목**, **모드 제목**, **− / + 표시**, **양수 눈금에 + 표시**, **빨간 영역** 토글을 제공합니다.
- **미터 다이얼**: **창 모양**(**직사각형**, **타원**, **원**), **다이얼 색상**, **다이얼 불투명도**, **다이얼 테두리 색상**, **다이얼 테두리 두께**, **주변부 어둡게**(0~100%).

**Rhythm Analyzer**는 [Rhythm Analyzer](plugins/analyzer.md#rhythm-analyzer) 이펙트와 동일한 분석을 사용해 템포, 박자별 타격 타이밍, 대역별 미세 타이밍을 표시합니다. 여기서는 **Metronome Click**을 사용할 수 없습니다. **최소 BPM**(40~192, 기본값 40)과 **최대 BPM**(50~240, 기본값 240)은 템포를 찾는 범위이며, 둘 중 하나를 바꾸면 분석이 처음부터 다시 시작됩니다. **스팬(박자)**(4, 6, 8, 12, 16, 기본값 8)은 **타이밍 레인**과 **에코 행**의 한 행에 표시할 박자 수입니다. **템포그램**, **타이밍 레인**, **에코 행**, **비트 렌즈** 토글로 각 패널을 표시하거나 숨깁니다(기본 켜짐은 **타이밍 레인**과 **비트 렌즈**). 세로로 긴 항목에서는 패널이 세로로 쌓이고, 가로로 긴 항목에서는 **비트 렌즈**가 **타이밍 레인** 옆에 놓입니다. 이에 더해 Visualizer에서는 네 개의 그래프 패널을 모두 꺼도 작동하는 중앙 **비트** 점등 원과 **BPM** 텍스트 오버레이를 제공합니다. BPM과 비트 렌즈는 소리보다 약 1~2초 늦게 확정된 분석 결과를 표시하며, BPM 텍스트에는 Title과 같은 텍스트 설정이 사용됩니다. **표시**에서 **주파수 대역**(기본값)과 **드럼**을 전환해도 템포 분석은 계속됩니다. **드럼**은 세 타격 패널에 Kick, Snare, Hi-hat, Cymbals를 표시하며 탐은 제외합니다. 박자 위치를 아직 알 수 없어도 인식된 타격점은 보입니다. 일부 타격음을 놓치거나 다른 소리를 드럼으로 오인할 수 있습니다.
- **비트 원**: **원 크기**(10~100%, 기본값 90%), **테두리 두께**(0~20, 기본값 2, 0이면 테두리 숨김), **채우기 불투명도**(기본값 30%), **테두리 불투명도**(기본값 100%), **팔레트 색상 사용**(또는 사용자 지정 **채우기 색상** / **테두리 색상**), **BPM을 원 안에 맞추기**(가운데 배치한 BPM 텍스트를 원 안에 들어가도록 축소), **점등 유지 시간**(0~1000 ms, 기본값 0 ms, 최대 점등을 페이드 전에 유지하는 시간), **감쇠 시간**(10~2000 ms, 기본값 90 ms)을 조절할 수 있습니다.

Spectrum, Spectrogram, Stereo의 **입력 게인**(−24~+24 dB)은 오디오 재생에는 영향을 주지 않고 그래프 표시 크기만 조절합니다. Spectrum, Level Meter, Chroma Spiral은 **폴 타임**(20 dB당 0~5초)을 제공하며, Spectrum, Level Meter, Stereo는 **피크**, **피크 홀드**(0~10초), **피크 폴 타임**(20 dB당 0.1~10초, Stereo는 1~10초)을 제공합니다.

**색상 모드**에서 Spectrum과 Chroma Spiral은 고정 **음표 색상**과 **히트맵**도 지원하며, Spectrogram, Level Meter, Phase Map은 **히트맵**을, Notes와 Guitar는 **음표 색상**을 지원합니다. Drums를 제외한 그 밖의 색상 설정이 있는 항목은 **단색**과 **그라데이션**만 제공합니다. **그라데이션**에서 Spectrum, Spectrogram, Notes, Guitar, Chroma Spiral, Phase Map은 **그라데이션 방향**(**주파수**, **강도**(약한 신호에서 강한 신호 순으로 색을 배정), **방사형**)을, 그 외 항목은 **선형**과 **방사형**을 제공합니다. **그라데이션 각도 (°)**(−180°~+180°, 기본값 0°)는 방사형이 아닌 그라데이션을 회전시키며, 양수 값이면 시계 방향입니다. **주파수**를 선택하면 Notes, Guitar, Chroma Spiral은 **전체 음역** 또는 **한 옥타브** 색상 매핑도 선택할 수 있습니다.

## 움직임과 효과 추가

모든 항목이나 배경에 시각 효과를 추가하고 순서를 조정해 원하는 분위기를 연출할 수 있습니다:
- **Opacity**, **Glow**, **Outline**, **Blur**, **Trail**, **Scale Pulse**, **Symmetry**, **Shake**, **Particles**, **Ken Burns**(아트워크/비디오/배경 이미지용), **Flash**(배경용), 그리고 **Backplate**(항목 뒤에 **채우기 색**, **채우기 불투명도**, **테두리 색**, **테두리 두께**, **모서리 반경**, **여백**을 조절해 배치하는 배경판).
- **Edge Fade**: **직사각형**(**위**, **아래**, **왼쪽**, **오른쪽** 페이드 폭, 0~100%) 또는 **원**(**페이드 폭**, 0~100%) 모양으로 항목 가장자리를 부드럽게 투명화합니다(기본값: 위아래 10%, 좌우 0%, 원 20%). 항상 마지막에 적용되며, 항목 영역 밖으로 벗어난 부분도 표시하지 않습니다.
- **Transform**: 항목이나 배경의 중심을 기준으로 크기 조절(**가로 배율** / **세로 배율**, 0~300%, 기본값 100%는 변화 없음), 기울이기(**가로 기울이기 (°)** / **세로 기울이기 (°)**, −60°~+60°), 회전(**회전 각도 (°)**, −180°~+180°, 양수 값이면 시계 방향), 이동(**가로 이동** / **세로 이동**, −100%~+100%, 양수 값이면 오른쪽 또는 아래로)을 적용합니다. 기울이기, 회전, 이동의 기본값은 0입니다.
- **Trail Feedback**: 반복되는 잔상 에코의 크기를 조절하고(**확대/축소**, −2%~+2%, 기본값 +2%, 양수 값이면 확대), 회전시키며(**회전 각도(°)**, −3°~+3°, 기본값 1.15°, 양수 값이면 시계 방향), 흘려 보냅니다(**가로 흐름** / **세로 흐름**, −1%~+1%, 기본값 0%, 양수 값이면 오른쪽 또는 아래로).

효과는 일정하게 유지하거나 **Time**, 전체 음량을 나타내는 **Level**, 저음·중음·고음의 세기를 나타내는 **Bass**·**Mid**·**Treble**에 반응하도록 할 수 있습니다. **Beat**는 감지된 박자 간격에 맞춰 부드럽게 강해졌다 약해지고, **Width**는 소리가 좌우로 퍼지는 정도에 반응합니다. **강도**(0~1)는 효과의 세기입니다. **Opacity**에서는 항목이 보이는 정도 자체(1이면 완전히 표시)이고, **Transform**에서는 0이면 변화가 없고 1이면 설정값을 모두 적용하며, **Trail Feedback**에서는 0이면 크기 조절·회전·흐름이 멈추고 짧은 잔상만 남습니다. **반응 정도**는 선택한 변조 소스에 따라 효과가 **강도**에서 얼마나 벗어나는지를, **속도**는 **Time**에 따른 변화의 빠르기를 정합니다. 애니메이션이 느려지면 **화질**을 낮추거나 **Auto**를 사용하세요.

### Color Adjust와 Color Map

**Color Adjust**는 앨범 아트나 동영상의 색을 보정하고, **Color Map**은 이미지 밝기에 따라 색을 바꿉니다. 둘 다 항목과 배경에 사용할 수 있습니다. **강도**는 원본(0)과 효과를 완전히 적용한 결과(1, 기본값)의 혼합 비율입니다. 위의 변조 설정으로 이 비율을 움직일 수도 있습니다.

**Color Adjust**의 초기 설정에서는 이미지가 변하지 않습니다.

- **밝기**(−100~100%, 기본값 0)는 이미지를 어둡게 또는 밝게 합니다. **대비**(0~300%, 기본값 100%)는 밝고 어두운 영역의 차이를 키우거나 줄입니다. **채도**(0~300%, 기본값 100%)는 색의 선명함을 조절하며, 0이면 회색조가 됩니다. **색조**(−180~180°, 기본값 0°)는 색상을 회전시킵니다.
- **상세 설정**을 펼치면 **레벨**과 **화이트 밸런스**를 조절할 수 있습니다. **입력 검정 레벨**(0~99%, 기본값 0%)과 **입력 흰색 레벨**(1~100%, 기본값 100%)은 원본의 어느 밝기를 검정과 흰색으로 처리할지 정합니다. 검정 레벨을 높이면 그림자가 짙어지고, 흰색 레벨을 낮추면 밝은 부분이 더 밝아집니다. 이 범위를 벗어나는 세부 표현은 사라집니다. 입력 검정 레벨은 입력 흰색 레벨보다 낮아야 합니다. **감마**(0.1~4, 기본값 1)는 중간 밝기를 조절하며, 높이면 밝아지고 낮추면 어두워집니다.
- **출력 검정 레벨**과 **출력 흰색 레벨**(0~100%, 기본값 각각 0%와 100%)은 결과의 양 끝 밝기를 정합니다. 출력 검정 레벨을 높이면 그림자가 옅어지고, 출력 흰색 레벨을 낮추면 흰색이 어두워집니다. 두 값을 서로 바꾸면 명암 관계가 반전됩니다. **색온도**(−100~100%, 기본값 0)는 양수에서 따뜻한 빨강 쪽으로, 음수에서 차가운 파랑 쪽으로 바꿉니다. **색조 보정**(같은 범위)은 양수에서 마젠타, 음수에서 초록 쪽으로 바꿉니다. **색 반전**은 각 색상 채널을 반전하며 기본적으로 꺼져 있습니다.

가사 뒤의 배경을 차분하게 만들려면 채도 60%, 밝기 −15%부터 시도해 보세요. 검정을 크게 밝히지 않으면서 어두운 앨범 아트를 잘 보이게 하려면 감마 1.2부터 시작해 보세요.

**Color Map**은 어두운 곳에서 밝은 곳으로 팔레트 색을 배정하며, 기본값은 검정에서 흰색으로 이어지는 연속 팔레트입니다. 색상 지점을 편집하거나 프리셋을 적용하고, **그라데이션 반전**으로 색 순서를 뒤집을 수 있습니다. 기존 색상 움직임 설정도 사용할 수 있습니다. **단계 수**는 부드럽게 이어지는 **연속** 또는 2~16단계를 선택합니다. 2단계에서는 **임계값**(0~100%, 기본값 50%)을 기준으로 이미지를 어두운 영역과 밝은 영역으로 나누고 각각 색을 배정합니다. 높이면 어두운 영역에 배정된 색을 사용하는 부분이 늘어납니다. 두 가지 색의 포스터 느낌을 내려면 진한 파랑에서 금색으로 이어지는 팔레트와 2단계를 선택하고, 피사체가 잘 보이도록 임계값을 조절하세요. 은은하게 색을 입히려면 연속을 선택하고 강도를 낮추세요.

## 프리셋, 공유, 백업, 표시 설정

프리셋 대화상자에서 이름을 지정한 레이아웃을 저장, 다시 불러오기, 이름 변경, 삭제할 수 있으며, 기본 내장 프리셋은 항상 사용할 수 있습니다. **설정 > 백업 / 복원**은 저장된 Visualizer 프리셋과 그 배경 이미지를 백업하지만, 편집 중인 현재 레이아웃은 포함하지 않습니다.

도구 모음에서 **공유**를 선택하면 현재 레이아웃의 링크가 복사됩니다(배경 이미지는 링크에 포함되지 않으므로 이미지는 **백업 / 복원**을 사용하세요). 데스크톱 앱이나 브라우저 확장 프로그램에서는 공유 링크를 복사한 뒤 Visualizer에서 **링크 가져오기**를 선택하거나 **Ctrl+V**(Mac에서는 **⌘V**)를 누릅니다. 가져온 레이아웃은 확인 없이 현재 레이아웃을 대체합니다. 되돌리려면 **Edit**을 열고 **실행 취소**를 선택하세요.

**설정 > 구성...**에서 **화면을 오디오와 동기화**를 켜면 화면 표시를 스피커 출력에 맞출 수 있으며, 동기화를 위해 오디오가 지연될 수 있습니다. 그래프가 움직이지 않는다면 **오디오 설정**에서 **WebAssembly 오디오 처리 사용**이 켜져 있는지, 그리고 오디오가 EffeTune을 통해 재생되고 있는지 확인하세요.

**설정 > 구성... > 표시**의 **Visualizer HDR**은 기본적으로 꺼져 있습니다. HDR 지원 디스플레이에서 밝은 부분을 더 환하게 표현하려면 운영체제에서 HDR을 활성화하고 이 옵션을 켜세요. 브라우저 또는 데스크톱 앱과 그래픽 하드웨어도 HDR 출력을 지원해야 합니다. HDR 출력을 사용할 수 없는 디스플레이에서는 자동으로 SDR로 표시됩니다. 이 설정은 Visualizer 전체와 클린 피드에 공통으로 적용되며 이 기기에 저장됩니다. 프리셋이나 공유 링크에는 포함되지 않습니다.
