# 음악 라이브러리 사용 가이드

음악 라이브러리는 선택한 음악 폴더를 인덱싱하여 로컬 음악 컬렉션을 트랙, 파일, 앨범, 아티스트, 장르, 하위 폴더, 폴더, 최근 추가됨, 플레이리스트 기준으로 탐색할 수 있게 해 주는 기능입니다. 재생 음원은 일반 음악 파일 재생과 마찬가지로 현재 EffeTune 이펙트 파이프라인을 거치므로 동일한 이펙트를 적용해 감상할 수 있습니다.

음악 라이브러리는 카탈로그, 아트워크 캐시, 플레이리스트만 앱 내부에 저장하며, 원본 오디오 파일을 편집하거나 이름을 바꾸거나 이동·삭제하지 않습니다.

## 사용 가능한 환경 {#availability}

- **데스크톱 앱:** 전체 폴더 스캐너를 사용하며, 앱을 다시 실행해도 선택한 폴더를 그대로 유지합니다. 데스크톱 빌드에서는 트랙이 저장된 실제 폴더 위치를 바로 열 수도 있습니다.
- **File System Access를 지원하는 PC Chromium 브라우저:** 페이지를 새로고침한 뒤에도 선택한 폴더에 대한 접근을 유지할 수 있으며, 브라우저가 권한을 다시 요청할 수 있습니다.
- **모바일 브라우저, Safari, Firefox 등 File System Access를 지원하지 않는 브라우저:** 선택한 파일에 대한 접근이 현재 페이지 세션 동안만 유지됩니다. 카탈로그는 보존되지만, 새로고침 후에는 EffeTune이 다시 연결할 수 있도록 폴더나 파일을 다시 선택해 주세요.

음악 라이브러리는 MP3, WAV, OGG, FLAC, Opus, M4A, AAC 등 일반적인 오디오 파일 확장자를 인덱싱합니다. 또한 같은 폴더에 있는 외부 CUE 시트를 사용해 앨범 단위의 WAV 또는 FLAC 파일을 개별 트랙으로 나눌 수 있습니다.

MP4, WebM, M4V, MOV, MKV, 3GP 파일을 포함하려면 **설정 > 구성... > 일반**에서 **음악 라이브러리에 동영상 파일 형식 포함**을 켠 뒤 폴더를 추가하거나 다시 스캔하세요. 이 설정은 기본적으로 꺼져 있으며, 바꿔도 기존 카탈로그가 즉시 바뀌지는 않습니다. 동영상 파일 내부의 오디오 코덱을 포함해 실제로 재생할 수 있는지는 브라우저나 OS의 디코더에 따라 다릅니다. 동영상 표시는 [음악 플레이어 가이드](music-player.md#video)를 참조하세요.

## 음악 라이브러리 열기

- **PC 레이아웃:** 상단 헤더의 **음악 라이브러리** 버튼을 클릭합니다.
- **모바일 레이아웃:** 하단 내비게이션의 **라이브러리** 탭을 엽니다.
- **데스크톱 앱:** **보기 > 음악 라이브러리** 메뉴 또는 **Ctrl+L**(macOS에서는 **Command+L**) 단축키로도 열 수 있습니다.

이펙트 편집 화면으로 돌아가려면 PC 레이아웃에서는 **Effect Pipeline** 버튼을 클릭하고, 모바일 레이아웃에서는 **이펙트** 탭으로 전환하며, 데스크톱 앱에서는 **보기 > Effect Pipeline** 또는 **Ctrl+E**(macOS에서는 **Command+E**)를 사용합니다.

앱을 시작할 때 음악 라이브러리가 먼저 열리도록 하려면 **설정 > 구성...**을 열고 **시작 시 표시:**를 **음악 라이브러리**로 설정하세요. 옆에 있는 목록에서 **트랙**, **파일**, **앨범**, **아티스트**, **장르**, **하위 폴더**, **폴더**, **플레이리스트** 중 처음 표시할 보기를 고를 수 있습니다.

## 음악 폴더 추가

1. 음악 라이브러리를 엽니다.
2. **음악 폴더 추가**를 선택합니다.
3. 음악 파일이 들어 있는 폴더를 선택합니다. 모바일이나 폴백 방식 브라우저에서는 지속적인 폴더 권한 대신 폴더 안의 파일들을 선택하라는 창이 열릴 수 있습니다.
4. 스캔이 끝날 때까지 기다립니다. 상태 표시줄에 트랙 및 앨범 수가 표시되며, 인덱싱 중에는 진행률도 함께 나타납니다.

이미 등록된 라이브러리 폴더 안의 하위 폴더를 추가하려고 하면 중복 인덱싱 대신 안내 경고가 표시됩니다. 이미 인덱싱된 폴더들을 포함하는 상위 폴더를 추가하면 기존 폴더들을 새 폴더로 병합할 수 있습니다.

## 탐색과 검색

내비게이션 탭을 사용해 컬렉션을 다양한 기준으로 둘러볼 수 있습니다:

- **트랙:** 인덱싱된 모든 트랙(PC에서는 정렬 가능한 표, 모바일에서는 간결한 목록).
- **파일:** 파일 경로 순으로 트랙을 나열하여 파일을 직접 선택할 수 있습니다. CUE 시트로 정의된 트랙도 개별 항목으로 표시됩니다.
- **앨범:** 트랙 메타데이터 기준으로 묶은 앨범 목록입니다.
- **아티스트:** 메타데이터의 아티스트 및 앨범 아티스트 기준으로 묶습니다(`Artist A; Artist B`처럼 세미콜론으로 구분된 값은 전체 크레딧 표시는 그대로 유지하면서 각 아티스트 항목에 모두 인덱싱됩니다).
- **장르:** 메타데이터의 장르 기준으로 묶습니다.
- **하위 폴더:** 등록된 각 루트 폴더 안에서 트랙이 직접 들어 있는 부모 하위 폴더 단위(예: `Artist/Album`)로 묶습니다.
- **폴더:** 등록된 루트 폴더, 스캔 상태, 폴더 계층 구조를 표시합니다.
- **최근 추가됨:** 최근에 인덱싱된 트랙을 표시합니다.
- **플레이리스트:** 음악 라이브러리 안에서 만들거나 가져온 플레이리스트를 표시합니다.

**폴더**에서 등록된 루트를 열면 **트리 보기**로 폴더 계층을 따라가거나 **평면 보기**로 전환해 해당 루트 안의 모든 트랙을 한꺼번에 볼 수 있습니다. **트리 보기**에서는 바로 아래에 트랙이 없는 단일 하위 폴더가 `Artist / Album`처럼 한 줄로 합쳐져 앨범 폴더로 바로 이동할 수 있으며, 상단 경로(브레드크럼)를 눌러 중간 폴더도 열 수 있습니다.

**라이브러리 검색**을 사용하면 트랙, 앨범, 아티스트, 플레이리스트 전체에서 원하는 항목을 빠르게 걸러낼 수 있습니다. 세 글자 이상 검색어는 제목, 아티스트, 앨범, 장르, 파일 이름, 경로 어디에든 일치하며, 한두 글자 검색어는 단어의 시작 부분에 일치합니다. PC에서는 트랙 표 머리글(**트랙 번호**, **제목**, **아티스트**, **앨범**, **장르**, **시간**)을 클릭하거나 다른 보기의 **정렬** 목록을 사용하세요. 모바일에서는 저장된 플레이리스트를 제외한 모든 보기에서 **정렬** 목록으로 순서를 바꿀 수 있습니다.

검색 결과, 폴더 단계, 앨범, 아티스트, 장르, 하위 폴더 또는 플레이리스트의 트랙 수가 300곡 이하이면 바로 재생을 시작할 수 있도록 전체 트랙이 기본 선택됩니다. 301곡 이상일 때는 자동으로 선택되지 않으므로, 각 행의 체크박스나 **모두 선택**, **모두 선택 해제**로 선택을 바꾸세요. 모바일에서는 아무 트랙 행이나 길게 누르면 체크박스와 선택 컨트롤이 나타납니다.

태그 정보가 없으면 파일 이름과 폴더 이름을 대신 사용합니다. 트랙 속성에서는 파일 경로, 형식, 샘플레이트, 비트 깊이, 비트레이트, 메타데이터를 확인할 수 있으며, CUE 트랙의 경우 CUE 시트 경로와 재생 구간도 함께 표시됩니다.

## CUE 앨범 파일

외부 `.cue` 시트를 참조 대상인 WAV 또는 FLAC 파일과 같은 폴더에 두고 폴더를 추가하거나 다시 스캔하면, 유효한 각 `TRACK ... AUDIO` 항목이 음악 라이브러리에 개별 트랙으로 나타납니다.

커버 아트는 원본 오디오 파일에 내장된 이미지를 먼저 확인하고, 없으면 `.cue` 파일과 같은 폴더에서 `cover.jpg`, `cover.png`, `front.jpg`, `front.png` 또는 오디오 파일과 이름이 같은 이미지를 찾습니다.

플레이어에서 `.cue` 시트를 직접 열 수도 있습니다(**음악 파일 열기**, 데스크톱의 **파일 > 음악 파일 열기...**, 모바일의 **음악 열기**):
- **데스크톱 앱:** `.cue` 파일만 단독으로 선택합니다.
- **PC Chromium 브라우저:** 앨범 폴더가 이미 음악 라이브러리에 등록되어 있고 접근 권한이 허용되어 있다면 `.cue` 파일만 선택합니다.
- **그 외 브라우저:** `.cue` 파일과 함께, 이 파일이 참조하는 WAV/FLAC 파일을 빠짐없이 그리고 그 파일만 선택합니다. 원하면 이름이 일치하는 커버 이미지도 함께 선택합니다.

CUE 시트가 올바르지 않거나 참조하는 오디오 파일을 찾을 수 없으면 알림을 표시한 뒤 WAV 또는 FLAC 파일을 분할되지 않은 단일 트랙으로 가져옵니다. CUE 시트나 파일 이름을 바로잡은 뒤 폴더를 다시 스캔하면 다시 시도할 수 있습니다.

## 라이브러리에서 재생

트랙, 앨범, 아티스트, 장르, 하위 폴더, 폴더, 검색 결과 또는 플레이리스트를 선택한 뒤 원하는 동작을 고릅니다:

- **재생:** 현재 플레이어 대기열을 대체하고 즉시 재생을 시작합니다.
- **셔플:** 선택한 항목을 무작위 순서로 재생합니다.
- **다음에 재생:** 현재 재생 중인 트랙 바로 다음에 선택한 항목을 넣습니다.
- **대기열에 추가:** 선택한 항목을 재생 대기열 끝에 추가합니다.
- **플레이리스트에 추가:** 선택한 항목을 음악 라이브러리 플레이리스트에 추가합니다.

PC에서는 트랙 행을 더블 클릭해 해당 곡부터 재생하거나, 마우스 오른쪽 클릭 또는 **더 보기** 메뉴로 트랙 작업을 열 수 있습니다. 모바일에서는 트랙을 탭해 바로 재생하거나 길게 눌러 여러 곡을 선택할 수 있습니다.

## 폴더 관리와 업데이트

음악 폴더에서 파일을 추가, 삭제, 이름 변경하거나 태그를 수정한 뒤에는 **다시 스캔**을 실행하세요. 다시 스캔하면 변경된 트랙이 갱신되고, 삭제된 파일은 카탈로그에서 정리되며, 일치하는 파일이 발견된 플레이리스트 항목은 다시 연결됩니다.

**폴더** 보기의 상태 표시:
- **OK:** 탐색 및 재생 준비가 완료된 상태입니다.
- **스캔 안 됨:** 추가되었으나 아직 인덱싱되지 않은 상태입니다.
- **찾을 수 없음:** 폴더 경로를 더 이상 찾을 수 없는 상태입니다.
- **다시 연결:** 브라우저 또는 폴더 접근 권한이 다시 필요합니다. **다시 연결**을 클릭하고 동일한 폴더에 대한 접근을 허용하세요.

폴더가 오프라인이라 라이브러리의 트랙을 열 수 없으면 폴더를 다시 연결하거나 다시 가져오세요.

**제거**를 선택해도 EffeTune 카탈로그에서만 제외될 뿐, 디스크의 실제 파일은 절대 삭제되지 않습니다.

## 플레이리스트

음악 라이브러리 플레이리스트는 EffeTune 내부에 저장되며, 인덱싱된 어떤 폴더의 트랙이든 담을 수 있습니다:

- 선택한 라이브러리 트랙으로 새 플레이리스트를 만들거나, 현재 플레이어 대기열을 플레이리스트로 저장할 수 있습니다.
- **이름 변경**, **복제**, **삭제**로 플레이리스트를 관리하고, 트랙을 드래그하거나 **위로 이동** / **아래로 이동**을 사용해 순서를 바꿀 수 있습니다.
- **플레이리스트 가져오기**로 M3U, M3U8, PLS, XSPF 파일을 불러오고, 플레이리스트 안에서 **M3U8 내보내기** 또는 **XSPF 내보내기**로 내보낼 수 있습니다.

### 최근 재생한 곡과 즐겨찾기

기능을 한 번 이상 사용하면 플레이리스트 그리드에 두 개의 자동 플레이리스트가 나타납니다:

- **최근 재생한 곡:** 음악 라이브러리에서 재생한 최근 100곡을 중복 없이 최신순으로 보관합니다.
- **즐겨찾기:** PC에서 트랙 옆의 **☆**로 표시하거나, 트랙의 **더 보기** 메뉴(PC에서는 마우스 오른쪽 클릭으로도 열 수 있음)에서 **즐겨찾기에 추가**를 선택한 트랙을 모읍니다. **즐겨찾기** 카드의 재생 버튼을 클릭하면 바로 재생할 수 있습니다.

이 두 플레이리스트의 이름은 현재 UI 언어를 따르며 이름을 바꿀 수 없지만, 일반 플레이리스트처럼 복제, 내보내기, 삭제는 가능합니다.

### 플레이리스트 가져오기 및 내보내기

폴더를 스캔할 때 음악 폴더 안에 있는 지원 플레이리스트 파일도 자동으로 가져오며, 디스크의 플레이리스트 파일이 변경되면 다시 스캔할 때 함께 업데이트됩니다. 이 업데이트는 EffeTune에서 해당 플레이리스트를 편집한 내용을 대체합니다. 일치하는 곡을 찾지 못한 항목은 미해결 상태로 유지되다가, 나중에 해당 폴더가 추가되거나 다시 연결되면 자동으로 연결됩니다.

플레이리스트를 내보낼 때 내보낸 M3U8 또는 XSPF 파일을 음악 폴더와 함께 이동시키려면 **상대 경로**를 켜세요. 표준 M3U8 및 XSPF 형식은 CUE 서브트랙 구간 정보를 저장하지 않으므로, 내보내기 시 CUE 트랙은 제외되며 건너뛴 곡 수가 안내됩니다.

## 안전성과 데이터 저장

- 음악 라이브러리는 오디오 파일과 메타데이터를 읽기만 하며 디스크의 원본 파일은 변경하지 않습니다.
- 브라우저 사이트 데이터를 지우면 웹 앱의 카탈로그와 플레이리스트도 삭제됩니다. 중요한 플레이리스트는 내보내서 보관하세요.
- 대규모 컬렉션은 스크롤에 맞춰 점진적으로 로드됩니다. 음악 라이브러리는 한 번에 하나의 EffeTune 창에서만 사용하세요.

## 네트워크의 음악(데스크톱 앱)

**Library**로 이 기기 또는 검색된 음악 서버를 탐색하고 창 상단의 기기 선택 메뉴로 음악을 들을 기기를 선택합니다. 라이브러리를 바꾸면 탐색 및 검색 범위만 바뀝니다. 폴더 추가와 다시 검색 같은 로컬 관리 기능은 **This device**를 선택했을 때만 사용할 수 있습니다.

다른 EffeTune의 라이브러리에서도 내 기기와 마찬가지로 **Tracks**, **Albums**, **Artists**, **Genres**, **Subfolders**, **Files**, **Folders**, **Recently Added**, **Playlists**로 음악을 찾을 수 있습니다. 선택한 라이브러리를 검색하고 목록을 정렬하거나 앨범, 아티스트, 장르를 열어 해당 트랙을 확인하세요. **Folders**에서는 **Tree**로 폴더 계층을 탐색하거나 **Flat**로 선택한 폴더 안의 모든 트랙을 한 목록에 표시할 수 있습니다. 공유된 음악만 표시됩니다. 다른 기기의 재생 목록은 탐색하고 재생할 수 있으며, 편집은 원본 컴퓨터에서 합니다.

다른 음악 서버는 해당 서버가 공개한 카테고리와 폴더 계층을 표시합니다. 검색과 정렬은 서버에서 지원하는 경우에만 사용할 수 있습니다.

Music Library의 곡을 다른 플레이어에서 재생하려면 먼저 **설정 > 구성... > 네트워크 > 라이브러리 공유**에서 해당 폴더를 공유하세요. 지원하는 형식과 효과는 재생 기기에 따라 달라집니다. CUE 구간 곡은 개별 네트워크 곡으로 사용할 수 없습니다. 설정, 효과 연결 및 연결 문제 해결은 [네트워크 음악과 원격 제어](openhome.md)를 참조하세요.

라이브러리 공유를 켜지 않고 개별 로컬 파일을 재생하려면 다른 재생 기기를 선택하고 **Open music files**를 사용하세요. EffeTune은 선택한 파일만 해당 기기에 제공합니다. 음원이 있는 기기에서 앱을 계속 실행해 두세요.

## PWA에서 공유 음악 듣기

PWA는 등록한 EffeTune 컴퓨터의 공유 라이브러리를 탐색하고 이 기기의 효과를 거쳐 재생하거나 다른 등록된 컴퓨터에서 재생할 수 있습니다. PWA의 로컬 파일은 다른 재생 기기로 보낼 수 없습니다. 기기 추가, 브라우저 권한, 연결 조건은 [PWA 설정 및 재생](openhome.md#pwa)을 참고하세요.
