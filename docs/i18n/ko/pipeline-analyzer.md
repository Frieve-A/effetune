# Pipeline Analyzer

Pipeline Analyzer는 들리는 오디오를 바꾸지 않고 현재 Effect Pipeline의 응답을 측정합니다. 넓은 창에서는 파이프라인 옆에, 좁은 창에서는 헤더 아래에 표시되므로 효과를 조정하면서 결과를 확인할 수 있습니다.

Effect Pipeline 헤더의 그래프 버튼이나 데스크톱 앱의 **View > Pipeline Analyzer**로 여세요. 파이프라인 또는 측정 설정을 변경하면 자동으로 다시 측정합니다.

## 채널과 스피커 응답

입력 채널 하나를 선택합니다. 처음에는 출력 하나가 표시되며 **+ 출력 추가**로 현재 오디오 장치가 지원하는 서로 다른 채널을 최대 네 개까지 추가할 수 있습니다. 출력을 삭제하면 해당 스피커 응답 설정도 삭제됩니다. 마지막 출력은 삭제할 수 없습니다.

각 출력에는 **스피커 IR 없음** 또는 연결된 트위터, 우퍼 등 스피커 유닛의 저장된 측정 지점을 지정할 수 있습니다. **적용 전**은 시간 정렬된 스피커 응답의 부호 있는 합이고, **적용 후**는 각 출력을 선택한 파이프라인으로 처리한 뒤의 부호 있는 합입니다. 이를 통해 FIR Crossover와 각 스피커 유닛을 함께 확인할 수 있습니다. 저장된 응답이 없으면 바꾸거나 지울 때까지 누락 상태를 명시합니다.

저장된 응답은 감지된 시작점에 맞춰 정렬됩니다. 별도 측정에는 드라이버 사이의 실제 도달 시간 차이가 남지 않으므로 합계를 판단하기 전에 파이프라인에서 상대 지연과 극성을 설정하세요.

## 측정 설정

**측정 설정**에서 다음 항목을 바꿀 수 있습니다.

- **신호**: 기본값은 **MLS**입니다. **TSP**는 같은 안정화 및 평균 설정을 사용하는 주기적 위상 스윕 신호입니다. **단위 임펄스**는 시간 영역을 직접 캡처합니다.
- **레벨**: 테스트 신호의 피크이며 기본값은 `-12 dBFS`입니다. 비선형 또는 레벨 의존 효과는 다른 결과를 낼 수 있습니다.
- **시퀀스 길이**: MLS는 32,767~524,287 샘플, TSP는 이에 대응하는 2의 거듭제곱인 32,768~524,288 샘플을 사용합니다. 신호를 바꿔도 같은 차수를 유지합니다. 길수록 순환 중첩 전까지 더 긴 응답을 표현합니다. Analyzer가 값을 권장할 수 있지만 자동으로 바꾸지는 않습니다.
- **안정화 주기**: 기본값은 12입니다. 캡처 전에 이 주기만큼 MLS 또는 TSP를 연속 실행하고 실제 시간을 표시합니다.
- **평균 횟수**: 기본값은 2입니다. 주기를 늘리면 반복 간 변동을 줄입니다.

세부 정보에는 **현재 지원 길이**, **권장 시퀀스 길이**, 주기 수와 초 단위의 **권장 안정화**, **전체 테스트 신호 시간**도 표시됩니다. 이 값은 판단을 돕기 위한 안내일 뿐이며 Pipeline Analyzer가 설정을 자동으로 바꾸지는 않습니다.

시퀀스 길이, 안정화 주기, 평균 횟수는 단위 임펄스에서만 비활성화됩니다. Frequency, Phase, Group Delay, Impulse 전환은 표시만 바꾸며 다시 측정하지 않습니다.

## 그래프와 측정 방식

**Frequency**는 레벨, **Phase**는 위상, **Group Delay**는 주파수별 지연, **Impulse**는 시간 응답을 표시합니다. 그래프에는 항상 **적용 전**과 **적용 후** 두 곡선만 표시됩니다. 포인터로 두 값을 읽을 수 있으며, **적용 전** 범례를 가리키면 **적용 후**가 잠시 숨겨집니다. Frequency와 Group Delay는 **스무딩 (oct)** 설정을 공유합니다. 각 주파수 곡선은 개별적으로 0 dB를 기준으로 맞추고, 각 임펄스는 전체 응답의 자체 피크로 정규화하여 -2 ms부터 선택한 **임펄스 범위 (ms)** 까지 표시합니다.

각 측정은 현재 파이프라인, 리소스, 라우팅, 스피커 응답, 설정을 고정해 분리된 worker에서 처리합니다. MLS는 순환 상관을, TSP는 역스윕을 사용해 DC를 제외한 주기 응답을 복원합니다. 표시되는 위상, 그룹 지연, 임펄스 시간에서는 파이프라인이 보고한 지연을 뺍니다. 단위 임펄스는 선택한 레벨로 캡처를 정규화하고 제한된 테일 캡처를 사용합니다.

비선형, 시변, 무작위, 노이즈 또는 자체적으로 소리를 만드는 효과에서는 선택한 레벨과 초기 상태의 한 번의 캡처일 뿐 보편적인 전달 함수가 아닙니다. 측정마다 달라질 수 있습니다. 잘못된 수치 출력이나 필수 프로세서 또는 리소스 준비 실패가 발생하면 측정은 실패합니다.
