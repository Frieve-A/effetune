# Pipeline Analyzer

Pipeline Analyzer는 실제로 들리는 소리를 바꾸지 않고 현재 Effect Pipeline의 응답을 측정합니다. 넓은 창에서는 파이프라인 옆에, 좁은 창에서는 파이프라인 헤더 아래에 표시되므로 이펙트를 조절하면서 응답이 바뀌는 모습을 확인할 수 있습니다.

Effect Pipeline 헤더의 그래프 버튼을 누르거나 데스크톱 앱에서 **보기 > Pipeline Analyzer**를 선택해 엽니다. **Auto**가 켜져 있으면 파이프라인을 편집할 때마다 자동으로 다시 측정합니다. **Auto**를 끄면 파이프라인 편집은 **Refresh measurements**를 클릭할 때만 다시 측정합니다. 채널, 스피커 응답, 측정 설정을 바꾸면 항상 새로 측정합니다.

## 채널과 스피커 응답 선택

현재 파이프라인(최대 16채널)에서 입력 채널 하나를 선택하고, **+ Add Output**으로 출력 채널을 최대 네 개까지 선택합니다. 출력은 항상 하나 이상 남아 있어야 하므로 마지막 출력은 삭제할 수 없습니다. 출력을 삭제하면 그 출력의 스피커 응답 설정도 함께 삭제됩니다.

각 출력에는 **No speaker IR** 또는 연결된 스피커나 드라이버의 저장된 측정 지점을 지정할 수 있습니다.

- **스피커 IR을 사용하지 않을 때:** **Before**는 이상적인 평탄 기준 임펄스이고, **After**는 이펙트 파이프라인만의 응답을 보여 줍니다.
- **스피커 IR을 사용할 때:** **Before**는 선택한 스피커 측정의 합산 응답이고, **After**는 파이프라인이 각 출력을 처리한 뒤의 합산 응답입니다. 이를 통해 **Channel Divider**나 **FIR Crossover**를 실제 드라이버 측정 결과와 함께 확인할 수 있습니다.

저장된 응답을 더 이상 사용할 수 없게 되면, 교체하거나 지우기 전까지 선택된 상태로 남아 — 로 표시됩니다.

개별 스피커 측정은 감지된 시작점을 기준으로 정렬되며 드라이버 간의 물리적인 도달 시간 차이는 보존되지 않습니다. 따라서 합산 응답을 평가하기 전에 파이프라인에서 드라이버 간 상대 지연과 극성을 설정하세요.

## 측정 설정

**Measurement settings**를 열면 파이프라인을 측정하는 방식을 조정할 수 있습니다.

- **Signal:** **Log Sweep**(기본값), **MLS**, **TSP**, **Unit Impulse** 중에서 선택합니다. 고조파 왜곡도 확인하려면 **Log Sweep**을 사용하세요. 스윕은 샘플 레이트가 허용하는 범위에서 20 Hz~20 kHz를 사용합니다. **MLS**와 **TSP**는 주기 신호를 사용하고, **Unit Impulse**는 임펄스 응답을 직접 캡처합니다.
- **Level:** 테스트 신호의 피크 레벨(기본값 `-12 dBFS`)입니다. 선형 필터는 어떤 레벨에서도 같은 결과가 나오지만, 컴프레서나 Saturation 등 레벨에 따라 동작이 달라지는 이펙트는 **Level**에 따라 결과가 바뀝니다.
- **Requested sweep length**(**Log Sweep**) / **Sequence Length**(다른 신호): **Log Sweep**의 기본값은 `131072`샘플입니다. 고조파를 분리하기 위해 더 긴 스윕을 사용할 수 있으며, 실제 **Sweep length**와 **Total stimulus time**은 측정 후 표시됩니다. 스윕을 길게 해도 응답은 주 임펄스 피크 이후 최대 1.5초까지만 확인할 수 있습니다. 더 긴 리버브 잔향, 딜레이, 필터 링잉을 보려면 **MLS**, **TSP**, **Unit Impulse** 중 하나를 선택하고 필요에 따라 **Sequence Length**를 늘리세요.
- **Stabilization Periods:** 캡처 전에 재생하는 주기 수(기본값 `12`, MLS와 TSP에서 사용)입니다. 천천히 변하는 이펙트가 안정될 때까지 기다립니다. **Log Sweep**과 **Unit Impulse**에서는 설정할 수 없습니다.
- **Averages:** 캡처 결과를 평균하는 횟수(기본값 `2`, **Log Sweep**, MLS, TSP에서 사용)입니다. 측정 편차를 줄여 줍니다.

## 그래프 읽기

플롯 위의 **Graph** 선택기로 다시 측정하지 않고 보기를 전환할 수 있습니다.

- **Frequency:** 주파수에 따른 크기 응답(dB)입니다. 0 dB를 기준으로 합니다.
- **Phase:** 주파수에 따른 위상 응답(도)입니다.
- **Min Group Delay:** 최소 위상 크기 응답에서 유도되는 군지연입니다.
- **Excess Group Delay:** 최소 위상 성분을 제거한 뒤 남는 군지연입니다(플롯은 ±100 ms 범위로 제한되지만, 커서 위치의 읽기 값에는 실제 값이 표시됩니다). 순수한 지연이나 선형 위상, 올패스에 의한 타이밍 차이를 쉽게 찾을 수 있습니다.
- **Impulse:** `-2 ms`부터 **Impulse Range (ms)**까지의 시간 영역 임펄스 응답입니다. 피크를 기준으로 정규화됩니다.
- **Distortion:** **Log Sweep**에서 주파수별 고조파 왜곡을 기본음에 대한 백분율로 표시합니다. 처음에는 H2, H3, THD(2~3차)가 표시되며, 재측정 없이 H4~H10을 추가할 수 있습니다. 값이 클수록 왜곡이 많습니다. 다른 신호에서 이 그래프를 사용할 수 없다면 **Log Sweep**을 선택하세요. 출력이 무음이거나 유효한 데이터가 없으면 왜곡을 계산할 수 없습니다. 저장된 스피커 응답은 선형 응답만 반영하며 스피커 자체의 왜곡은 나타내지 않습니다.
- **Waterfall:** 주파수, 상대 레벨(dB), 감쇠 시간(ms)을 표시합니다. **Response**에서 **After**(기본값) 또는 **Before**를 선택해 파이프라인 출력과 처리 전의 스피커 응답을 확인하세요. 각 보기는 자체 피크를 기준으로 정규화되므로 절대 레벨보다 감쇠 형태를 비교하세요. 3D 그래프를 드래그해 회전하고 휠이나 핀치 동작으로 확대·축소할 수 있습니다.

주파수, 위상, 군지연, 임펄스 그래프에 포인터를 올리면 커서 위치의 **Before**와 **After** 값을 읽을 수 있습니다. 범례의 **Before** 라벨에 포인터를 올리면 **After**가 잠시 숨겨집니다. 주파수, 위상, 군지연 플롯에는 **Smoothing (oct)**를, 임펄스 플롯에는 **Impulse Range (ms)**를 사용합니다.

## 측정 방식

Pipeline Analyzer는 현재 파이프라인과 그 라우팅, 선택한 스피커 응답을 가져와 측정하고, 파이프라인이 보고한 레이턴시를 **After**에서 자동으로 보정합니다. 비선형, 모듈레이션, 무작위 이펙트에서는 그래프를 현재 설정과 **Level**에서의 스냅샷으로 보세요.
