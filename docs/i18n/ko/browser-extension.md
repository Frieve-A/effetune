# EffeTune 브라우저 확장 프로그램

브라우저 확장 프로그램은 하나의 브라우저 탭 오디오를 EffeTune과 같은 스테레오 **Effect Pipeline**으로 처리합니다. 데스크톱 앱을 실행하거나 가상 오디오 장치를 설정하지 않고 동영상이나 음악 사이트를 들을 때 쓸 수 있습니다.

## 호환성 및 설치

PC의 Chrome 116 이상 또는 Chromium 기반의 호환되는 Microsoft Edge에서 사용하십시오. Firefox, Safari, 모바일 브라우저, 비공개 브라우징은 지원하지 않습니다. 한 세션에서는 선택한 탭 하나를 스테레오 직렬 체인으로 처리합니다.

스토어에서 받은 확장 프로그램은 해당 스토어에서 설치하십시오. 로컬 패키지는 `effetune-extension-<version>.zip`을 계속 보관할 폴더에 압축 해제합니다. Chrome에서는 `chrome://extensions`, Edge에서는 `edge://extensions`를 열고 **Developer mode**를 켠 뒤 **Load unpacked**를 선택하여 그 폴더를 고르십시오. **Load unpacked**는 ZIP 파일 자체를 설치하지 않습니다. 파일을 바꾼 뒤에는 이 페이지에서 확장 프로그램을 다시 로드하십시오.

## 처리 시작, 비교, 중지

1. 처리할 오디오가 재생되는 탭을 엽니다.
2. 브라우저 도구 모음에서 EffeTune 확장 프로그램을 엽니다.
3. **Start processing**을 선택합니다. 체인이 준비되면 상태가 **Starting…**에서 **Processing**으로 바뀝니다.

선택한 탭은 세션 동안 고정됩니다. 다른 탭을 처리하려면 **Stop processing**을 선택하고 그 탭에서 확장 프로그램을 연 뒤 다시 시작하십시오. **Bypass effects**는 세션을 유지한 채 효과 없는 캡처 오디오를 들려 줍니다. **Stop processing**은 탭 오디오를 해제하고 일반 재생 경로로 돌려놓습니다.

팝업이나 편집기를 닫아도 처리는 계속됩니다. 다시 열면 현재 탭과 실제 상태가 표시됩니다. 브라우저를 다시 시작한 뒤에는 새 세션을 직접 시작해야 하며 확장 프로그램이 탭을 자동 캡처하지 않습니다.

## 체인 편집과 프리셋

**Edit pipeline**을 선택하면 **EffeTune Pipeline Editor**가 열립니다. EffeTune에서처럼 효과를 추가·재정렬하고, 개별 효과를 켜거나 끄고, 매개 변수를 조절하며, 제공되는 분석 표시를 사용할 수 있습니다. 팝업의 **Saved preset**과 **Apply**로 편집기를 열지 않고 전체 체인을 바꿀 수 있습니다. 편집기에서 **Pipeline Presets**를 열고 **Save as**로 전체 파이프라인 프리셋을 저장합니다. 전체 프리셋을 가져오거나 내보내려면 **Settings**를 열고 **Import preset…** 또는 **Export preset**을 선택합니다.

저장한 설정과 프리셋은 확장 프로그램에 남으며 웹 앱이나 데스크톱 앱과 자동 동기화되지 않습니다. 프리셋에 지원하지 않는 라우팅, 효과 또는 사용할 수 없는 외부 자산이 필요하면 적용되지 않고 현재 체인이 유지됩니다.

웹 앱이나 데스크톱 앱의 측정 결과를 Room EQ 또는 Crosstalk Cancellation에서 사용하려면 해당 앱에서 JSON으로 내보내십시오. 확장 프로그램 편집기에서 **Settings**를 열고 **Import measurement…**를 선택한 다음 그 JSON 파일을 지정합니다. Crosstalk Cancellation이나 Room EQ의 위상 보정에 사용할 때는 임펄스 응답을 포함해 내보내십시오. 가져온 측정 결과는 Room EQ의 **Measurement** 목록에 즉시 나타나고 확장 프로그램의 브라우저 저장소에 남으며 자동으로 동기화되지 않습니다. 가져온 복사본을 삭제하려면 목록에서 선택하고 목록 옆의 **Delete**를 선택하십시오. 확인 후 해당 복사본을 사용하는 모든 Room EQ와 Crosstalk Cancellation 할당이 해제된 다음 복사본이 삭제됩니다.

## 권한, 제한, 도움말

확장 프로그램은 사용자가 명시적으로 처리를 시작한 탭의 오디오만 캡처합니다. 마이크, 모든 웹사이트 접근, 녹음, 외부 전송 권한은 필요하지 않습니다.

일반 스테레오 체인을 지원합니다. 멀티버스나 분기 체인, 2채널 초과, 새 측정 실행 및 기기 제어, Music Library, 일괄 파일 변환, 기기 또는 파일 경로에 의존하는 데스크톱 전용 기능은 사용할 수 없습니다.

보호된 콘텐츠는 캡처하지 못할 수 있으며 확장 프로그램은 보호를 우회하지 않습니다. 캡처가 시작되지 않으면 EffeTune이 처리를 중지하고 탭은 일반 재생으로 돌아갑니다. 탭에서 오디오가 재생 중인지 확인한 뒤 **Start processing**을 다시 선택하십시오. **Needs attention**이 보이면 같은 방법으로 다시 시작하십시오. 프리셋을 적용할 수 없으면 현재 체인이 유지되므로 프리셋을 바꾸거나 필요한 자산을 준비하십시오.
