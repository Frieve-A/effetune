# EffeTune 브라우저 확장 프로그램

브라우저 확장 프로그램은 최대 네 개 탭의 오디오를 각각 독립된 스테레오 **Effect Pipeline**으로 동시에 처리합니다. 데스크톱 앱을 실행하거나 가상 오디오 장치를 설정하지 않고 동영상이나 음악 사이트를 들을 때 쓸 수 있습니다.

## 호환성 및 설치

PC의 Chrome 116 이상 또는 Chromium 기반의 호환되는 Microsoft Edge에서 사용하십시오. Firefox, Safari, 모바일 브라우저, 비공개 브라우징은 지원하지 않습니다. 각 탭은 스테레오 이펙트 파이프라인을 사용합니다.

스토어에서 받은 확장 프로그램은 해당 스토어에서 설치하십시오. 로컬 패키지는 `effetune-extension-<version>.zip`을 계속 보관할 폴더에 압축 해제합니다. Chrome에서는 `chrome://extensions`, Edge에서는 `edge://extensions`를 열고 **Developer mode**를 켠 뒤 **Load unpacked**를 선택하여 그 폴더를 고르십시오. **Load unpacked**는 ZIP 파일 자체를 설치하지 않습니다. 파일을 바꾼 뒤에는 이 페이지에서 확장 프로그램을 다시 로드하십시오.

## 처리 시작, 비교, 중지

1. 처리할 오디오가 재생되는 탭을 엽니다.
2. 브라우저 도구 모음에서 EffeTune 확장 프로그램을 엽니다.
3. **Start on this tab**을 선택합니다. 체인이 준비되면 상태가 **Starting…**에서 **Processing**으로 바뀝니다.

다른 탭을 추가하려면 해당 탭에서 확장 프로그램을 열고 **Start on this tab**을 선택하십시오. 팝업에 모든 세션이 표시됩니다. 동시에 네 개까지 처리할 수 있으며, 다섯 번째를 시작하려면 하나를 먼저 멈추십시오. **Bypass**는 세션을 유지하면서 효과 없는 소리를 들려줍니다. **Stop**은 다른 탭에 영향을 주지 않고 해당 탭을 일반 재생으로 되돌립니다.

팝업이나 편집기를 닫아도 처리는 계속됩니다. 다시 열면 현재 탭과 실제 상태가 표시됩니다. 브라우저를 다시 시작한 뒤에는 새 세션을 직접 시작해야 하며 확장 프로그램이 탭을 자동 캡처하지 않습니다.

## 체인 편집과 프리셋

**Edit pipeline**을 선택하면 **EffeTune Pipeline Editor**가 열립니다. EffeTune에서처럼 효과를 추가·재정렬하고, 개별 효과를 켜거나 끄고, 매개 변수를 조절하며, 제공되는 분석 표시를 사용할 수 있습니다. 팝업의 **Saved preset**과 **Apply to selected tab**로 편집기를 열지 않고 전체 체인을 바꿀 수 있습니다. 편집기에서 **Pipeline Presets**를 열고 **Save as**로 전체 파이프라인 프리셋을 저장합니다. 전체 프리셋을 가져오거나 내보내려면 **Settings**를 열고 **Import preset…** 또는 **Export preset**을 선택합니다. 편집기 헤더에서 탭을 선택하면 해당 효과 체인과 분석 표시로 전환됩니다. 활성 세션이 없으면 **Offline pipeline**에서 다음 시작에 사용할 기본 체인을 편집합니다. 팝업에서도 먼저 대상 탭을 선택한 다음 프리셋을 적용하십시오.

편집기 헤더에서 **Visualizer**를 선택하면 선택한 탭의 처리된 소리를 [Visualizer](visualizer.md)로 볼 수 있습니다. 다시 선택하면 체인 화면으로 돌아갑니다. 해당 탭에서 처리를 시작하지 않았다면 Visualizer에 "Start EffeTune on a tab to show Visualizer."가 표시됩니다. 확장 프로그램에서는 곡 제목과 아트워크가 표시되지 않습니다. **Share**와 **Import Link**는 웹 앱과 똑같이 사용할 수 있으며, 공유한 링크는 웹 버전에서 열립니다. Visualizer 레이아웃과 프리셋은 확장 프로그램에 저장되며 웹 앱이나 데스크톱 앱과 동기화되지 않습니다.

저장한 설정과 프리셋은 확장 프로그램에 남으며 웹 앱이나 데스크톱 앱과 자동 동기화되지 않습니다. 프리셋에 지원하지 않는 라우팅, 효과 또는 사용할 수 없는 외부 자산이 필요하면 적용되지 않고 현재 체인이 유지됩니다.

웹 앱이나 데스크톱 앱의 측정 결과를 Room EQ 또는 Crosstalk Cancellation에서 사용하려면 해당 앱에서 JSON으로 내보내십시오. 확장 프로그램 편집기에서 **Settings**를 열고 **Import measurement…**를 선택한 다음 그 JSON 파일을 지정합니다. Crosstalk Cancellation이나 Room EQ의 위상 보정에 사용할 때는 임펄스 응답을 포함해 내보내십시오. 가져온 측정 결과는 Room EQ의 **Measurement** 목록에 즉시 나타나고 확장 프로그램의 브라우저 저장소에 남으며 자동으로 동기화되지 않습니다. 가져온 복사본을 삭제하려면 목록에서 선택하고 목록 옆의 **Delete**를 선택하십시오. 확인 후 해당 복사본을 사용하는 모든 Room EQ와 Crosstalk Cancellation 할당이 해제된 다음 복사본이 삭제됩니다.

지원되는 저장 데이터 중 원하는 항목을 골라 한꺼번에 옮기려면 편집기에서 **Settings > Backup / Restore**를 여십시오. 같은 `.effetune_backup` 파일을 웹 앱과 데스크톱 앱에서도 사용할 수 있으며, 저장한 파이프라인 프리셋, 이펙트 프리셋, Visualizer 프리셋, 임펄스 응답, 가져온 측정 결과를 포함할 수 있습니다. 확장 프로그램에서 지원하지 않는 라우팅이나 이펙트를 사용하는 파이프라인도 저장되고 다시 백업할 수 있지만, 확장 프로그램에서 적용할 수는 없습니다. URL 규칙과 확장 프로그램의 Sample rate 설정은 포함되지 않습니다.

## URL별 프리셋과 샘플 레이트

**Settings**에서 **URL rules…**를 열고 패턴을 추가한 뒤 저장된 프리셋을 선택하고 규칙을 활성화하십시오. 패턴은 `example.com/music/*`와 같은 `host/path` 형식이며, `*`는 임의의 문자열과 일치합니다. 활성화된 규칙 중 처음 일치하는 규칙이 적용됩니다. 호스트 이름은 대소문자를 구분하지 않고 프로토콜, 쿼리 문자열, 프래그먼트는 비교하지 않습니다. 규칙을 재정렬하여 우선순위를 바꾸거나 필요 없는 규칙을 비활성화 또는 삭제할 수 있습니다.

각 탭은 여전히 직접 시작해야 합니다. 시작 시와 URL 변경 시 프리셋을 자동으로 선택하며 일치하는 규칙이 없으면 기본 체인을 사용합니다. 규칙 변경은 다음 시작 또는 페이지 이동부터 적용됩니다. URL 규칙으로 선택된 체인을 편집하면 해당 저장 프리셋이 업데이트됩니다. 그 외 편집과 프리셋을 수동으로 적용한 뒤의 편집은 기본 체인에 저장됩니다. 프리셋을 삭제하면 참조 규칙이 비활성화되고 그 규칙을 사용하던 탭은 기본 체인으로 돌아갑니다.

**Settings**의 **Sample rate**는 모든 활성 탭에 적용됩니다. **Auto**, **44.1 kHz**, **48 kHz**, **96 kHz**, **192 kHz** 중에서 선택하십시오. Auto에서는 브라우저가 주파수를 선택합니다. 변경 시 캡처를 유지하면서 모든 탭의 오디오 처리가 잠시 재시작됩니다. 새 주파수로 처리할 수 없는 탭은 일반 재생으로 돌아갑니다. 다른 주파수를 선택하고 해당 탭을 다시 시작하십시오.

## 권한, 제한, 도움말

확장 프로그램은 사용자가 명시적으로 처리를 시작한 탭의 오디오만 캡처합니다. 저장된 프리셋을 선택하기 위해 페이지 이동 후를 포함하여 해당 탭의 URL을 읽습니다. 페이지 내용을 읽거나 스크립트를 삽입하지 않으며, 마이크 사용, 녹음, 외부로 오디오 전송을 하지 않습니다.

스테레오 파이프라인에서는 Bus Routing으로 Main과 Bus 1–4를 사용할 수 있으며, 이펙트를 병렬 경로에 배치할 수도 있습니다. 2채널 초과, 새 측정 실행 및 기기 제어, Music Library, 일괄 파일 변환, 기기 또는 파일 경로에 의존하는 데스크톱 전용 기능은 확장 프로그램에서 사용할 수 없습니다.

보호된 콘텐츠는 캡처하지 못할 수 있으며 확장 프로그램은 보호를 우회하지 않습니다. 캡처가 시작되지 않으면 EffeTune이 처리를 중지하고 탭은 일반 재생으로 돌아갑니다. 탭에서 오디오가 재생 중인지 확인한 뒤 **Start on this tab**을 다시 선택하십시오. **Needs attention**이 보이면 같은 방법으로 다시 시작하십시오. 프리셋을 적용할 수 없으면 현재 체인이 유지되므로 프리셋을 바꾸거나 필요한 자산을 준비하십시오.
