# EffeTune 브라우저 확장 프로그램

EffeTune 브라우저 확장 프로그램은 최대 4개의 브라우저 탭 오디오를 각각 독립된 스테레오 Effect Pipeline으로 동시에 처리합니다. 데스크톱 앱을 실행하거나 가상 오디오 장치를 설정하지 않고 동영상 사이트나 음악 사이트의 소리를 들을 때 유용합니다.

로컬 데이터 처리 방식과 선택적으로 여는 외부 링크에 대해서는 [브라우저 확장 프로그램 개인정보 처리방침](../../browser-extension-privacy.md)을 읽어 주세요. 도움이 필요하면 [GitHub Issues](https://github.com/Frieve-A/effetune/issues)를 이용할 수 있지만, 공개 이슈에는 오디오, 탭 제목이나 URL, 프리셋, 측정 결과, 임펄스 응답 등 개인적인 정보를 올리지 마세요.

## 호환 환경

PC의 Chrome 116 이상 또는 호환되는 Chromium 기반 Microsoft Edge에서 사용할 수 있습니다. Firefox, Safari, 모바일 브라우저, 시크릿(비공개) 브라우징 모드는 지원하지 않습니다. 각 탭은 스테레오 이펙트 파이프라인을 사용합니다.

## 로컬 패키지 설치

브라우저 확장 프로그램 스토어에서 받은 경우 스토어에서 바로 설치하세요. 로컬 패키지로 설치할 때는 계속 보관할 폴더에 `effetune-extension-<version>.zip`의 압축을 푼 뒤 압축 해제한 폴더를 불러옵니다:

1. Chrome에서는 `chrome://extensions`, Edge에서는 `edge://extensions`를 엽니다.
2. **Developer mode**(개발자 모드)를 켭니다.
3. **Load unpacked**(압축해제된 확장 프로그램을 로드합니다)를 선택하고 압축을 푼 확장 프로그램 폴더를 지정합니다.

**Load unpacked**로는 ZIP 파일 자체를 직접 설치할 수 없습니다. 압축 해제한 폴더의 파일을 교체한 뒤에는 이 페이지에서 확장 프로그램을 다시 로드하세요.

## 처리 시작, 비교, 중지

1. 오디오를 처리할 탭을 열고 재생을 시작합니다.
2. 브라우저 도구 모음에서 EffeTune 확장 프로그램을 엽니다.
3. **Start on this tab**을 선택합니다. 이펙트 체인이 준비되면 상태가 **Starting…**에서 **Processing**으로 바뀝니다.

다른 탭도 추가하려면 해당 탭에서 확장 프로그램을 열고 **Start on this tab**을 선택하세요. 팝업에 모든 세션이 표시되며 최대 4개 탭까지 동시에 실행할 수 있습니다. 다섯 번째 탭을 시작하려면 기존 탭 중 하나를 먼저 중지하세요.

탭 옆의 **Bypass**를 누르면 세션을 유지한 채 이펙트가 빠진 원본 소리를 비교해 들을 수 있습니다. 사용을 마치면 탭 옆의 **Stop**을 선택하세요. 다른 탭의 처리는 유지한 채 해당 탭만 일반 재생으로 돌아갑니다.

확장 프로그램 팝업이나 편집기를 닫아도 오디오 처리는 계속 유지됩니다. 다시 열면 현재 탭과 처리 상태가 표시됩니다. 브라우저를 재시작한 뒤에는 새 세션을 직접 시작해야 하며, 확장 프로그램이 탭을 자동으로 캡처하지는 않습니다.

## Effect Pipeline 편집과 프리셋 사용

**Edit pipeline**을 선택해 **EffeTune Pipeline Editor**를 연 다음 헤더에서 대상 탭을 선택합니다. EffeTune 본체와 똑같이 이펙트를 추가·순서 변경·켜기/끄기·조절할 수 있으며, 분석기 화면도 선택한 탭을 따라갑니다. 활성 탭이 없을 때는 **Offline pipeline**에서 다음 탭을 시작할 때 사용할 기본 파이프라인을 편집할 수 있습니다.

편집기 헤더에서 **Visualizer**를 선택하면 선택한 탭의 처리된 오디오를 [Visualizer](visualizer.md)로 볼 수 있으며, 다시 클릭하면 파이프라인 화면으로 돌아갑니다. 확장 프로그램에서는 곡 제목과 앨범 아트가 표시되지 않으며, **Share** / **Import Link**는 웹 앱과 동일하게 작동합니다.

팝업에서 프리셋을 빠르게 바꾸려면 탭을 선택하고 **Saved preset**을 고른 뒤 **Apply to selected tab**을 클릭하세요. 편집기에서는 **Pipeline Presets > Save as**로 프리셋을 저장하거나 **Settings > Import preset…** / **Export preset**으로 `.effetune_preset` 파일을 주고받을 수 있습니다. 프리셋에 지원되지 않는 멀티채널 라우팅, 이펙트 또는 누락된 외부 자산이 포함된 경우 현재 파이프라인이 그대로 유지됩니다.

웹 앱이나 데스크톱 앱에서 측정한 룸/스피커 측정 결과를 **Room EQ** 또는 **Crosstalk Cancellation**에서 사용하려면:

1. 웹 앱 또는 데스크톱 앱에서 측정 결과를 JSON으로 내보냅니다(**Crosstalk Cancellation**이나 **Room EQ** 위상 보정에 사용할 때는 임펄스 응답 포함).
2. 확장 프로그램 편집기에서 **Settings > Import measurement…**를 열고 JSON 파일을 선택합니다.
3. **Room EQ** 또는 **Crosstalk Cancellation**에서 가져온 측정 결과를 선택합니다. 가져온 복사본을 삭제하려면 Room EQ의 **Measurement** 목록에서 선택하고 **Delete**를 고르세요. 확인하면 이 측정 결과를 사용하는 Room EQ와 Crosstalk Cancellation의 할당이 모두 해제됩니다.

프리셋, 이펙트 프리셋, Visualizer 프리셋, 임펄스 응답, 가져온 측정 데이터를 웹 앱, 데스크톱 앱, 확장 프로그램 사이에 한꺼번에 옮기려면 **Settings > Backup / Restore**(`.effetune_backup`)를 사용하세요. 확장 프로그램의 프리셋, 레이아웃, 가져온 측정 데이터는 확장 프로그램 내부에 로컬 저장되며 웹 앱이나 데스크톱 앱과 자동 동기화되지 않습니다. 백업에는 URL 규칙과 확장 프로그램의 샘플레이트 설정이 포함되지 않습니다.

## URL별 프리셋과 샘플레이트

**Settings > URL rules…**를 열면 탭 URL이 `host/path` 패턴(예: `example.com/music/*`, `*`는 임의의 텍스트와 일치)과 일치할 때 저장된 프리셋을 자동으로 불러오도록 설정할 수 있습니다. 탭의 처리는 여전히 직접 시작해야 하며, 규칙은 시작할 때와 URL이 바뀔 때 사용할 프리셋만 고릅니다. 목록에서 활성화된 규칙 중 가장 먼저 일치하는 규칙이 적용되며, 일치하는 규칙이 없으면 기본 파이프라인을 사용합니다. 규칙 변경은 다음 시작이나 페이지 이동 때 반영됩니다. URL 규칙으로 불러온 파이프라인을 편집하면 해당 규칙의 저장된 프리셋이 업데이트되고, 그 밖의 편집(프리셋을 수동으로 적용한 뒤의 편집 포함)은 기본 파이프라인을 업데이트합니다. 프리셋을 삭제하면 그 프리셋을 사용하는 규칙은 비활성화되고, 해당 규칙을 사용하던 탭은 기본 파이프라인으로 돌아갑니다.

**Settings**의 **Sample rate**(**Auto**, **44.1 kHz**, **48 kHz**, **96 kHz**, **192 kHz**)는 모든 활성 탭에 적용됩니다. **Auto**는 브라우저가 샘플레이트를 정합니다. 샘플레이트를 변경하면 활성 탭의 오디오 처리가 잠시 재시작되지만 캡처는 유지됩니다. 새 샘플레이트로 실행할 수 없는 탭은 일반 재생으로 돌아가므로, 다른 샘플레이트를 선택한 뒤 탭을 다시 시작하세요.

## 권한 및 제한 사항

확장 프로그램은 사용자가 직접 **Start on this tab**을 클릭한 탭에서만 오디오를 캡처하며, URL 프리셋 규칙을 대조하기 위해서만 해당 탭의 URL을 읽습니다. 웹 페이지 내용을 읽거나 스크립트를 삽입하거나 마이크를 사용하거나 오디오를 네트워크로 전송하지 않습니다.

각 탭은 **Main**과 **Bus 1–4**를 지원하는 스테레오 파이프라인으로 작동합니다. 멀티채널 출력(>2ch), 음향 측정 실행, 음악 라이브러리, 일괄 오프라인 파일 변환, 데스크톱 전용 하드웨어 기능은 확장 프로그램에서 사용할 수 없습니다. 브라우저 캡처를 차단하는 보호된(DRM) 스트림은 일반 재생으로 돌아갑니다.

## 문제가 발생했을 때

- **상태에 "Needs attention"이 표시되거나 캡처가 시작되지 않을 때:** 탭에서 실제로 오디오가 재생 중인지 확인한 뒤 **Start on this tab**을 다시 클릭하세요.
- **프리셋이 적용되지 않을 때:** 편집기는 현재 파이프라인을 그대로 유지합니다. 필요한 측정 데이터나 임펄스 응답 자산을 확장 프로그램에 먼저 가져왔는지 확인하세요.
