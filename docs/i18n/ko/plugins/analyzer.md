# 분석 플러그인

음악을 흥미로운 방식으로 시각화할 수 있는 플러그인 모음입니다. 이러한 시각적 도구들은 소리의 다양한 측면을 보여줌으로써 청취 경험을 더욱 몰입감 있고 상호작용적으로 만들어줍니다.

## 플러그인 목록

- [Analog Meter](#analog-meter) - VU, PPM, 피크, 라우드니스 스케일을 갖춘 니들 미터로 채널 레벨 표시
- [Chroma Spiral](#chroma-spiral) - 주파수 성분을 음이름과 옥타브의 나선 위에 표시
- [Level Meter](#level-meter) - 음악의 디지털 신호 레벨을 표시
- [Note Spectrogram](#note-spectrogram) - 시간에 따른 추정 음높이를 피아노 롤로 표시
- [Oscilloscope](#oscilloscope) - 실시간 파형 시각화
- [Pitch Meter](#pitch-meter) - 하나의 기본 주파수와 튜닝 변화를 시간에 따라 추적
- [Spectrogram](#spectrogram) - 시간에 따른 음악의 주파수 변화를 표시
- [Spectrum Analyzer](#spectrum-analyzer) - 음악의 주파수 분포를 실시간으로 표시
- [Stereo Meter](#stereo-meter) - 스테레오 밸런스와 채널 상관을 시각화

## Analog Meter

소리를 바꾸지 않고 클래식한 니들 미터로 각 채널의 레벨을 보여줍니다. 음악의 크기가 순간순간 어떻게 변하는지 따라가거나, 방송과 스트리밍에서 쓰이는 VU, PPM, 피크, 라우드니스(LUFS) 스케일로 재생음이 어떻게 나타나는지 확인할 때 사용하세요.

### 활용 가이드

- **VU로 평균 레벨 확인하기**: 곡을 재생하며 니들을 지켜보세요. 조용한 벌스와 힘있는 코러스는 확실한 차이를 보이지만, 짧은 드럼 히트는 니들을 거의 움직이지 않습니다.
- **True Peak로 클리핑 확인하기**: EQ와 게인 계열 이펙트 뒤에 Analog Meter를 배치하고 곡에서 가장 큰 부분을 재생하세요. 값이 0 dBFS를 넘거나 오버 램프가 켜지면 체인에서 클리핑이 발생할 수 있으므로, 피크가 0 dBFS 아래(예: -1 dBFS 정도의 여유)로 내려갈 때까지 게인을 낮추세요.
- **Loudness로 곡 비교하기**: **Target**을 -14 LUFS 같은 스트리밍 기준값으로 설정하고, 곡이나 앨범 시작 부분에서 **Reset**을 누른 뒤 끝까지 재생하세요. Integrated 값은 전체적인 라우드니스를, 최대 True Peak 값은 가장 높은 피크를 보여주므로 앨범이나 재생목록의 볼륨을 맞추는 기준이 됩니다. LRA를 보면 곡마다 라우드니스가 얼마나 넓게 변하는지도 비교할 수 있습니다.

### 시스템 프리셋

효과 헤더의 **효과 프리셋**을 클릭하면 잘 알려진 규격에 맞춘 설정으로 한 번에 바꿀 수 있습니다. **Mode**가 바뀌는 프리셋을 선택하면 측정이 처음부터 다시 시작되지만, Loudness 프리셋끼리 전환할 때는 측정이 계속됩니다.

- **Studio VU (-18 dBFS)** - 0 VU를 -18 dBFS에 맞춘 VU입니다. 스튜디오에서 널리 쓰이는 기준(EBU R68)으로, 헤드룸을 넉넉히 둔 녹음에 적합합니다.
- **SMPTE VU (-20 dBFS)** - 0 VU를 -20 dBFS에 맞춘 VU(SMPTE RP 155)입니다. 북미 스튜디오와 방송에서 쓰이는 기준입니다.
- **Hot VU (-14 dBFS)** - 기본 설정과 같습니다. 0 VU를 -14 dBFS에 맞춘 VU로, 완성된 상업 음원 대부분에 잘 맞습니다.
- **Loud Master VU (-8 dBFS)** - 0 VU를 -8 dBFS에 맞춘 VU입니다. 음압을 한껏 끌어올린 요즘 CD나 팝 마스터에서 니들이 상단에 붙어 버리지 않도록 해 줍니다.
- **DIN PPM** - DIN 미터(**Attack** 5 ms, 1.5초에 20 dB 하강, DIN 스케일)입니다. -9 표시를 -18 dBFS에 맞추므로 0 표시는 -9 dBFS가 됩니다. 스케일은 -50까지 표시합니다.
- **BBC PPM** - BBC 미터(**Attack** 10 ms, 2.8초에 24 dB 하강, BBC 스케일)입니다. 4 표시를 -18 dBFS에 맞추므로 6 표시는 -10 dBFS가 됩니다.
- **Nagra Modulometer** - Nagra 테이프 레코더의 모듈로미터(**Attack** 7.5 ms, -30~+5 dB의 dB 스케일)입니다. 0 dB를 -18 dBFS에 맞춥니다. **Release**는 DIN과 같은 1.5초입니다.
- **K-20** - Bob Katz의 K-System을 적용한 RMS 미터입니다. 0을 -20 dBFS에 맞추고 눈금은 -60 dBFS까지 내려갑니다. 다이내믹 레인지가 넓은 녹음에 적합합니다.
- **K-14** - 같은 방식으로 0을 -14 dBFS에 맞추고, 눈금은 -60 dBFS까지입니다. 일반적인 팝 음악에 적합합니다.
- **K-12** - 같은 방식으로 0을 -12 dBFS에 맞추고, 눈금은 -60 dBFS까지입니다. 방송용으로 음압을 바짝 끌어올린 음원에 적합합니다.
- **Digital Peak** - 표준 디지털 피크 미터(IEC 60268-18)입니다. -60~0 dBFS를 표시하며 피크 표시를 2초 동안 유지합니다.
- **True Peak Clip Watch** - True Peak에서 상단 20 dB를 확대하고 피크 표시를 가장 긴 10초 동안 유지합니다. EQ나 게인을 바꾼 뒤 0 dBFS를 넘는 피크를 놓치지 않기 위한 설정입니다.
- **EBU R128 (-23 LUFS)** - 유럽 방송 기준을 목표값으로 한 Loudness입니다. 스케일은 EBU +9입니다.
- **EBU R128 +18 Scale** - 같은 목표값에 폭이 더 넓은 EBU +18 스케일을 사용합니다. 클래식처럼 다이내믹 레인지가 넓은 음원에 적합합니다.
- **TV (-24 LKFS)** - 미국(ATSC A/85)과 일본(ARIB TR-B32)의 TV에서 쓰이는 -24 LKFS를 목표값으로 한 Loudness입니다.
- **Streaming (-14 LUFS)** - 많은 음악 스트리밍 서비스의 음량 정규화에 가까운 -14 LUFS를 목표값으로 한 Loudness입니다. 니들은 차분하게 움직이는 Short-term입니다.
- **Streaming (-16 LUFS)** - 스트리밍과 팟캐스트에 권장되는 -16 LUFS(AES TD1008)를 목표값으로 한 Loudness입니다. 니들은 Short-term입니다.

### 매개변수

선택한 **Mode**에 해당하는 항목만 표시됩니다.

- **Mode** - 미터 종류를 선택합니다: **VU**(기본값), **PPM**, **RMS**, **Sample Peak**, **True Peak**, **Loudness**. 모드마다 니들이 움직이는 방식과 스케일이 다릅니다(표시 가이드 참고). 모드를 바꾸면 측정이 처음부터 다시 시작됩니다.
- **Integration**(RMS; 0.05~3초; 기본값 0.3초) - 평균을 내는 시간을 설정합니다. 값을 늘리면 니들이 안정적이고 느리게 움직이고, 줄이면 변화에 더 빠르게 반응합니다.
- **Attack**(PPM; 1~20 ms; 기본값 5 ms) - PPM 니들이 상승하는 속도를, 정상음보다 2 dB 낮게 읽히는 톤 버스트 길이로 설정합니다. 값을 줄이면 짧은 피크도 원래 레벨에 가깝게 나타나고, 늘리면 짧은 피크일수록 더 낮게 읽힙니다. 5 ms는 DIN 미터에 해당합니다.
- **Release**(PPM, Sample Peak, True Peak; 0.1~5초; 기본값 1.5초) - 피크 이후 니들이 20 dB 내려가는 데 걸리는 시간을 설정합니다. 값을 늘리면 피크를 더 쉽게 읽을 수 있고, 줄이면 음악의 변화를 더 세밀하게 따라갑니다. 1.5초는 DIN 미터 및 표준 디지털 피크 미터와 같은 값입니다.
- **Reference**(VU, PPM, RMS; -30~0 dBFS; 기본값 -14 dBFS) - 미터의 기준 표시에 해당하는 디지털 레벨을 설정합니다. 기본값은 완성된 상업 음원 대부분에 잘 맞는 값입니다. 스튜디오에서 쓰이는 -18 dBFS나 -20 dBFS 기준(시스템 프리셋 참고)에서는 일반적인 CD에서도 니들이 스케일 상단 근처에 머물기 쉽습니다. 음압이 높은 음원에서 니들이 스케일 상단까지 올라갈 때는 값을 높이고, 조용한 음원에서 니들이 거의 움직이지 않을 때는 값을 낮추세요.
- **Range**(DIN 또는 dB 스케일의 PPM, RMS, Sample Peak, True Peak; 20~60 dB; 기본값 40 dB) - 스케일이 아래로 얼마나 내려가는지 설정합니다. 넓히면 조용한 구간까지 볼 수 있고, 좁히면 스케일 상단부가 더 넓게 펼쳐집니다.
- **PPM Scale**(PPM; 기본값 DIN) - PPM 스케일을 **DIN**, **BBC**, **dB** 중에서 선택합니다(표시 가이드 참고).
- **Peak Hold**(PPM, RMS, Sample Peak, True Peak; 0~10초; 기본값 1초) - 최근 최고값을 나타내는 피크 표시가 유지되는 시간과 오버 램프가 켜져 있는 시간을 설정합니다. 0으로 설정하면 표시를 끄고, 오버 램프는 1초 동안 켜집니다.
- **Needle**(Loudness; 기본값 Momentary) - 니들이 나타내는 값을 선택합니다. **Momentary**는 최근 0.4초의 라우드니스를 따르고, **Short-term**은 최근 3초의 값을 보여주며 더 안정적으로 움직입니다.
- **Target**(Loudness; -36~-10 LUFS; 기본값 -23 LUFS) - 스케일에 표시할 라우드니스를 설정하고, 그 값을 기준으로 스케일을 배치합니다. -23 LUFS는 EBU R128 방송 기준이며, 많은 스트리밍 서비스는 -14 LUFS 근처의 값을 사용합니다.
- **Scale**(Loudness; 기본값 EBU +9) - 라우드니스 스케일의 폭을 선택합니다. **EBU +9**는 **Target**보다 18 LU 아래부터 9 LU 위까지, **EBU +18**은 36 LU 아래부터 18 LU 위까지를 표시하며, 다이내믹 레인지가 넓은 음악이나 매우 큰 음원에 적합합니다.

### 표시 가이드

- 채널마다 하나의 미터가 있으며, 한 행에 최대 4개, 최대 16채널까지 표시합니다.
- 레벨은 풀스케일 사인파가 0 dBFS로 읽히는 디지털의 일반적인 규칙을 따르므로, 일정한 사인파는 Loudness를 제외한 모든 모드에서 같은 값을 나타냅니다.
- 니들이 움직이는 속도는 모드마다 다릅니다.

| 모드 | 니들의 움직임 | 스케일 |
|---|---|---|
| VU | 느리게 움직입니다. 약 0.3초 안에 새로운 레벨에 도달하며 평균 레벨을 나타냅니다(IEC 60268-17). | -20~+3 VU. 0 VU = **Reference**. |
| PPM | IEC 60268-10을 기반으로 한 근사치입니다. **Attack**으로 정한 속도로 빠르게 상승합니다. 기본값 5 ms에서는 DIN 미터와 마찬가지로 10 ms 버스트가 정상음보다 약 1 dB 낮게 읽힙니다. **Release** 시간 동안 20 dB 내려갑니다. | **PPM Scale**로 선택합니다. **DIN**: -9 표시 = **Reference**이며 0은 그보다 9 dB 위입니다. **BBC**: 1~7 표시로, 2~7 사이는 4 dB, 1~2 사이는 6 dB 간격이며 4 표시 = **Reference**입니다. **dB**: 0 표시 = **Reference**이며, **Range** 만큼 아래부터 +5 dB까지 표시합니다. |
| RMS | **Integration** 시간 동안의 평균 파워를 나타내며, 별도의 평활화는 적용하지 않습니다. | 0 표시 = **Reference**. |
| Sample Peak | 가장 높은 샘플 값으로 즉시 이동합니다. | 스케일 상단 = 0 dBFS. |
| True Peak | Sample Peak와 비슷하지만 샘플 사이의 피크도 추정합니다. 0 dBFS를 넘어 읽힐 수 있으며, 이런 피크는 DAC나 변환 과정에서 클리핑될 수 있습니다. | 스케일 상단 = 0 dBFS. |
| Loudness | ITU-R BS.1770과 EBU R128에서 정의한 라우드니스를 LUFS로 나타냅니다. | **Target**과 **Scale**로 정해지며, 값은 LUFS로 표시됩니다. |

- 피크 표시는 **Peak Hold** 시간 동안 최근 최고값을 보여줍니다. 오버 램프는 레벨이 0 dBFS를 넘으면 켜지고, **Peak Hold** 시간 동안(**Peak Hold**가 0이면 1초 동안) 켜진 상태를 유지합니다.
- Loudness 모드에서는 첫 번째 미터가 프로그램 전체를 나타냅니다. 니들은 **Needle** 설정을 따르며, Momentary(M), Short-term(S), Integrated(I), Loudness Range(LRA), 최대 True Peak 값, 측정 경과 시간과 **Reset** 버튼을 표시합니다. Integrated와 LRA는 충분한 길이의 오디오가 측정되어야 나타납니다.
  - 모노, 스테레오, 5.1(채널 순서 L, R, C, LFE, Ls, Rs)에서는 이 값들이 표준 채널 가중치를 따릅니다. 다른 채널 수에서는 모든 채널을 동일한 가중치로 합산하므로 값은 참고용입니다.
  - 첫 번째 이후의 미터는 각 채널을 개별적으로 나타냅니다. 채널 가중치나 게이팅을 적용하지 않은 참고값입니다.
- Integrated, LRA, 최대 True Peak는 **Reset**을 누르거나, **Mode**를 바꾸거나, 샘플레이트나 채널 수가 바뀌거나, 오디오 처리가 재시작될 때까지 계속 누적됩니다.
- 처리가 일시 정지된 시간은 측정에 포함되지 않습니다. 무음 상태에서 절전으로 일시 정지된 동안, Master Bypass가 켜져 있거나 Analog Meter가 꺼져 있는 동안, 설정의 **숨겨진 동안 표시용 DSP 건너뛰기**가 켜진 상태(기본값)에서 Effect Pipeline이 표시되지 않는 동안(음악 라이브러리 표시 중, 최소화 중, 미니 플레이어 사용 중 등)이 여기에 해당합니다. 다시 시작하면 멈춘 지점부터 측정을 이어갑니다.

## Chroma Spiral

소리를 바꾸지 않고 음악의 주파수 성분이 12개 음이름과 각 옥타브의 어디에 놓이는지 보여줍니다. 겹치는 배음을 살펴보거나, 보컬과 베이스의 음역을 비교하거나, 악기의 성분이 퍼지는 범위를 확인할 때 유용합니다.

### 활용 가이드

- 한 음을 길게 내고 원음과 배음이 나타나는 위치를 보세요. 한 음만 연주해도 여러 음이름이 밝아질 수 있으며, 각각 별도로 연주된 음이라는 뜻은 아닙니다.
- 화음이나 멜로디를 들으며 활성 위치의 변화를 살펴보세요. 조성의 단서는 얻을 수 있지만 화음 이름이나 조를 판별하지는 않습니다.
- 조율 상태를 살펴보려면 밝은 점이나 채워진 영역의 바깥쪽 가장자리가 음이름 눈금 사이에 나타나는지 확인하세요. 한 기본음의 차이를 센트 단위로 읽으려면 Pitch Meter를 사용하세요.
- 그래프를 마우스, 손가락 또는 펜으로 누르면 선택한 나선 위치의 사인파를 들을 수 있습니다. 드래그하면 음높이가 바뀌고, 놓거나 동작을 취소하면 소리가 멈춥니다. 이 미리 듣기는 모든 **Color** 설정에서 작동합니다.

### 매개변수

- **Color** - 스펙트럼을 그리는 방식을 선택합니다. 배경의 나선 가이드는 모든 설정에서 똑같이 표시되며 소리가 없을 때도 남아 있습니다.
  - **Normal**(기본값): 각 주파수 셀을 테마의 그래프 선 색으로 점을 찍어 표시합니다. 점의 밝기는 셀의 레벨에 따라 변하고 면적은 그 레벨에 비례해 커져, 약한 주파수도 더 쉽게 볼 수 있습니다. 최대 강도에서는 점의 반지름이 다음 나선 바퀴까지 거리의 절반에 이릅니다.
  - **Normal 2**: 각 주파수의 나선 위치에서 해당 레벨까지 그래프 선 색으로 채우되 데이터의 윤곽선은 그리지 않습니다.
  - **Note Colors**: Normal과 같은 점 표시를 사용하되, 음이름마다 다른 색을 사용하며 같은 음이름에는 옥타브가 달라도 같은 색을 씁니다.
- **Lowest Octave**(1~8, 기본값 1) - 가장 안쪽 옥타브를 정합니다. 높이면 높은 음역에 집중할 수 있습니다.
- **Highest Octave**(1~9, 기본값 7) - 가장 바깥쪽 옥타브를 정합니다. 낮추면 저음과 중음에 집중할 수 있습니다. 두 범위의 순서는 자동으로 유지됩니다.
- **Frequency Tilt**(-6~+6 dB/oct, 0.5 단위, 기본값 +3) - 소리를 바꾸지 않고 100 Hz보다 높은 주파수의 표시 레벨을 조정합니다. 양수는 높은 주파수를 더 두드러지게 하고 음수는 덜 두드러지게 합니다. 0에서는 주파수에 따른 보정을 하지 않습니다.
- **Level Range**(6~96 dB, 1 dB 단위, 기본값 24) - 움직이는 표시 범위의 폭을 정합니다. 좁히면 레벨 차이가 강조되고, 넓히면 강한 성분과 함께 약한 성분도 볼 수 있습니다.
- **Display Floor**(-120~-24 dB, 1 dB 단위, 기본값 -60) - 조용한 구간에서 움직이는 표시 범위의 아래쪽 경계가 내려갈 수 있는 최저 레벨을 정합니다. 낮추면 선택한 **Level Range** 안의 더 약한 성분도 표시될 수 있습니다. 표시 범위는 최근 최고값도 따라 움직이므로 모든 약한 성분이 보인다는 뜻은 아닙니다.

### 화면 읽는 법

- 나선 한 바퀴가 한 옥타브입니다. C는 위쪽에 있고 음이름은 시계 방향으로 이어집니다. 안쪽일수록 낮으며 C 표시에는 옥타브 번호가 붙습니다.
- **Normal**과 **Note Colors**에서는 음 사이를 포함해 점이 밝고 클수록 해당 위치의 성분이 강합니다. **Normal 2**에서는 성분이 강할수록 채워진 영역이 바깥쪽으로 더 뻗으며, 별도 윤곽선 없이 바깥 가장자리로 스펙트럼의 변화를 읽을 수 있습니다.
- 점의 밝기와 면적, 채워진 영역의 폭은 최근 최고값에 따른 상대적인 강도이며 절대 레벨을 나타내지 않습니다.
- 낮은 옥타브에서는 가까운 음을 구분하기 어렵고 반응이 느려져 서로 겹쳐 보일 수 있습니다.

### 시각적 표시
- 디스플레이에 마우스를 올리거나 터치한 채로 드래그하면 그 지점의 값을 읽을 수 있습니다.

## Level Meter

음악의 디지털 신호 레벨을 실시간으로 보여주는 디스플레이입니다. 이펙트 적용 후 레벨을 확인하고, 들리는 왜곡으로 번지기 전에 클리핑 가능성을 파악하는 데 도움이 됩니다.

### 표시 가이드
- 수평 막대가 오른쪽으로 길어질수록 신호 레벨이 큽니다
- 흰색 마커는 새로운 피크를 1초 동안 유지한 다음 부드럽게 내려갑니다
- OVERLOAD는 신호가 안전한 디지털 범위를 넘어 왜곡될 수 있음을 뜻합니다
- 깨끗한 재생을 위해 빨간색 레벨이나 OVERLOAD 경고가 자주 뜨지 않게 조정하세요. 실제 청취 음량은 기기 볼륨에서 맞춥니다

## Note Spectrogram

오디오를 바꾸지 않고 A0부터 C8까지의 추정 기본 주파수(F0)를 흐르는 피아노 롤로 표시합니다. 화음의 구성음, 변화하는 보컬과 멜로디 라인, 베이스 라인, 서로 다른 옥타브에서 겹치는 음을 살펴볼 때 유용합니다.

### 표시 가이드

- **Vertical**에서는 시간이 왼쪽에서 오른쪽으로 흐르며, 오른쪽 끝에 건반과 현재 소리가 표시됩니다. 높은 음일수록 위에 나타납니다.
- **Horizontal**에서는 건반이 아래쪽에 놓이며 낮은 음은 왼쪽, 높은 음은 오른쪽에 표시됩니다. 새로운 소리는 건반 바로 위에 나타나고 기록은 위로 흐릅니다.
- 각 C의 선은 옥타브 경계를 표시합니다.
- 검은 건반에 해당하는 음높이 행은 음이 감지되지 않을 때도 구분할 수 있도록 거의 검은색에 가까운 회색 배경으로 표시합니다.
- **Normal**은 테마의 그래프 선 색상을 사용하고, **Note Colors**는 음이름마다 다른 색을 사용하며 모든 옥타브에서 같은 음이름은 같은 색으로 표시합니다. 둘 다 E와 F 사이에 옥타브 경계보다 어두운 보조선을 표시합니다.
- **1/12 Octave**는 반음마다 한 행을 표시합니다. **High (1/60 Octave)**는 반음을 다섯 행으로 나누어 미세한 음높이 변화를 더 쉽게 확인할 수 있으며, 인접한 음의 색상을 행별로 보간합니다.
- 색상은 모델의 신뢰도에 따라 0(배경색)에서 1(표시 색상)까지 변하며, 약한 후보도 표시 임계값으로 제외하지 않고 보여 줍니다. 신뢰도는 모델이 해당 음의 존재를 얼마나 뒷받침하는지 나타내며, 보정된 확률은 아닙니다.
- **Volume** - 막대 두께와 반원형 미터로 상대 음량을 표시합니다. 기본값은 켜짐입니다. 끄면 행의 진하기가 신뢰도를 나타냅니다.
- 건반 경계에서 그래프 쪽으로 뻗는 부드러운 가장자리의 반원이 현재 음량을 나타냅니다. 음량이 커지면 즉시 반응하고 작아지면 초당 20 dB씩 내려가며, 별도로 보이는 피크 홀드는 없습니다.
- 음량 표시 범위는 24 dB입니다. 상단은 기록의 스케일을 안정시키는 최근 기준값(약 1초)과 -36 dB 중 더 높은 값에 맞춰집니다. 이 기준값은 현재 음량을 나타내는 반원과 별개이므로, 조용한 곡도 읽기 쉽고 큰 소리 구간이 계속 화면을 가득 채우는 것을 줄입니다.
- 옥타브 및 E–F 안내선은 음량 막대 뒤에 그려지므로 음높이 격자를 시각적 기준으로 확인할 수 있습니다.
- 최신 프레임의 신뢰도가 높아질수록 건반은 원래 색에서 표시 색상으로 부드럽게 바뀌며, 신뢰도가 1이면 해당 색이 됩니다.
- **Color**를 바꾸면 기존 기록의 색상이 바뀝니다.

### 시각적 표시
- 디스플레이에 마우스를 올리거나 터치한 채로 드래그하면 그 지점의 값을 읽을 수 있습니다.

### 확인할 수 있는 내용

- 화음은 같은 시각에 여러 개의 밝은 행으로 나타납니다
- 멜로디와 베이스 라인은 음의 행 사이를 이동하는 궤적으로 나타납니다
- 이 표시는 MIDI나 악보를 만들거나 악기를 식별하지 않으며, 동시에 나는 모든 소리를 완전히 분리할 수 없습니다. 소리가 복잡하게 겹치면 멜로디나 화음의 일부를 놓칠 수 있고, 타악기, 노이즈, 불분명한 반복 패턴에서는 가끔 잘못된 음높이가 표시될 수 있습니다.

### 파라미터

- **Color** - 음높이 추정 결과는 그대로 두고 표시 색상을 선택합니다.
  - **Normal**(기본값): 테마의 그래프 선 색상.
  - **Note Colors**: 음이름마다 다른 색을 사용하며 모든 옥타브에서 같은 음이름은 같은 색으로 표시합니다.
- **Pitch Resolution** - 기존 기록을 지우지 않고 음높이 방향의 세밀함을 선택합니다.
  - **1/12 Octave**(기본값): 반음마다 한 행을 표시하며 해당 음 범위에서 가장 강한 추정값을 사용합니다.
  - **High (1/60 Octave)**: 반음마다 다섯 행을 사용해 더 세밀한 음높이 변화를 표시합니다.
- **Layout** - **Horizontal**(기본값) 또는 **Vertical**을 선택합니다. 전환해도 기존 기록은 유지됩니다.
- **Volume** - 막대 두께와 반원형 미터로 상대 음량을 표시합니다. 기본값은 켜짐이며, 끄면 기존처럼 신뢰도만 행의 농도로 표시합니다.
- **Time Span** (1~10 s) - 피아노 롤에 표시할 시간 길이를 설정합니다
  - 짧은 값은 타이밍 변화를 더 자세히 보여 줍니다
  - 긴 값은 더 긴 음악 구간을 한 번에 보여 줍니다
  - 기본값: 2 s
- **Regular Note Limit**(1~16음) - 전용 저음역을 제외하고 최종 감지 단계까지 진행할 수 있는 동시 음의 수를 설정합니다. 기본값은 8입니다. 매우 조밀한 화음에서는 값을 높이고, 값을 낮추면 분석 작업과 후보 간 경쟁이 줄어듭니다.
- **Lowest Note** - 표시하고 분석할 음역의 최저음을 설정합니다. 기본값: E1.
- **Highest Note** - 표시하고 분석할 음역의 최고음을 설정합니다. 기본값: G6.
- 입력이 분석하기에 너무 작으면 매우 작은 입력을 음높이로 표시하지 않고 피아노 롤이 어둡게 유지됩니다. 이 억제는 소리가 들리거나 지각적으로 마스킹되는지를 판단하지 않습니다.

## Oscilloscope

소리의 파형을 실시간으로 보여주어 음악을 들으며 비트, 날카로운 타격음, 음량 변화를 눈으로 확인할 수 있습니다. 파형이 반복될 때는 트리거 설정으로 표시를 더 안정시킬 수 있습니다.

### 표시 가이드
- 가로축은 시간 표시(밀리초)
- 세로축은 정규화된 진폭 표시. 실제 표시 범위는 Display Level과 Vertical Offset에 따라 달라집니다
- 녹색 선이 실제 파형을 추적
- 그리드 선은 시간과 진폭 값 측정에 도움
- 트리거 설정은 파형 캡처가 시작되는 위치를 결정하며 별도 마커는 표시되지 않습니다

### 시각적 표시
- 그래프에 마우스를 올리거나 터치한 채로 드래그하면 그 지점의 값을 읽을 수 있습니다.

### 파라미터
- **Display Time** - 표시할 시간 범위(1에서 100ms)
  - 낮은 값: 짧은 이벤트의 더 자세한 관찰
  - 높은 값: 더 긴 패턴 관찰
- **Trigger Mode**
  - Auto: 트리거 없이도 지속적 업데이트
  - Normal: 다음 트리거까지 디스플레이 고정
  - Off: 트리거 없이 들어오는 최신 파형을 계속 표시. Trigger Level, Trigger Edge, Holdoff는 적용되지 않음
- 트리거 검출은 왼쪽과 오른쪽 채널의 평균 파형을 사용합니다. 모노 입력은 그대로 사용됩니다.
- **Trigger Level** - 캡처를 시작하는 진폭 레벨
  - 범위: -1에서 1(정규화된 진폭)
- **Trigger Edge**
  - Rising: 신호가 상승할 때 트리거
  - Falling: 신호가 하강할 때 트리거
- **Holdoff** - 트리거 간 최소 시간(0.1에서 10ms)
- **Display Level** - 수직 스케일(dB 단위)(-96에서 0dB)
- **Vertical Offset** - 파형을 위/아래로 이동(-1에서 1)

### 파형 표시에 대한 참고
표시 파형은 캡처된 지점을 시간 순서대로 연결합니다. Display Time이 길 때는 각 구간의 첫 번째와 마지막 샘플뿐 아니라 최솟값과 최댓값 및 원래 위치도 유지하므로, 표시 해상도 범위에서 연속성과 짧은 피크가 보존됩니다. 정밀 측정 도구라기보다는 시각적 참고용으로 보세요.

## Pitch Meter

오디오를 바꾸지 않고 한 번에 하나의 기본 주파수(F0)를 2초 길이의 스크롤 피아노 롤로 추적합니다. 독창이나 독주 악기의 튜닝과 음높이 움직임을 확인할 때 사용합니다.

### 시각화 가이드

- **Horizontal**(기본값)은 낮은 음을 왼쪽, 높은 음을 오른쪽에 배치합니다. 최신 추정값은 건반 위에 나타나고 기록은 위로 흐릅니다.
- **Vertical**은 낮은 음을 아래, 높은 음을 위에 배치합니다. 최신 추정값은 오른쪽 건반 옆에 나타나고 기록은 왼쪽으로 흐릅니다.
- 선의 위치는 반음 사이의 음높이도 표시합니다. 추정 신뢰도가 높을수록 선이 진하게 보이며, 입력이 너무 작거나 안정적인 단일 음높이를 찾지 못하면 선이 끊깁니다.
- 현재 레이블은 가장 가까운 음 이름과 cents 차이를 표시합니다. 양수는 해당 음보다 높고 음수는 낮다는 뜻입니다. 신뢰할 수 있는 추정값이 없으면 레이블이 사라집니다.
- 음 이름에는 Note Spectrogram과 같은 음별 색상을 사용합니다. 음 이름과 cents 차이의 글자 크기는 표시 너비에 맞춰 조절되며, cents의 소수점 위치는 고정됩니다.

### 시각적 표시
- 디스플레이에 마우스를 올리거나 터치한 채로 드래그하면 그 지점의 값을 읽을 수 있습니다.

### 활용 가이드

- 먼저 한 음을 길게 내고 선이 음의 중앙에 머무는지, 높거나 낮은 쪽으로 움직이는지 확인합니다.
- 비브라토와 pitch bend는 음 행 사이를 오가는 부드러운 움직임으로 나타납니다.
- 이 분석기는 가장 두드러진 하나의 음높이를 추적합니다. 화음, 복잡한 믹스, 타악기, 노이즈, 불분명한 반복음에서는 선이 끊기거나 옥타브가 잘못 표시될 수 있습니다.

### 매개변수

- **Layout** - **Horizontal**(기본값) 또는 **Vertical**을 선택합니다.
- **Color** - 음높이 감지 결과를 바꾸지 않고 선 색상을 전환합니다. **Normal**(기본값)은 테마의 그래프 색상, **Heatmap**은 Note Spectrogram과 같은 24 dB 음량 범위, **Note Colors**는 음높이에 따른 음별 색상을 사용합니다.
- **Reference A4**(400~480 Hz) - 음 이름과 cents 차이에 사용할 튜닝 기준을 설정합니다. 기본값: 440 Hz.
- **Lowest Note** - 표시 및 분석 범위의 최저음을 설정합니다. 기본값: C2. 설정 가능한 최저음은 A0입니다.
- **Highest Note** - 표시 및 분석 범위의 최고음을 설정합니다. 기본값: C7. 설정 가능한 최고음은 C8입니다.
- 스테레오 입력은 처음 두 채널의 평균을 분석하며 모노 입력은 그대로 사용합니다. 두 채널의 극성이 강하게 반대인 성분은 평균 과정에서 상쇄되어 음높이 선이 나타나지 않을 수 있습니다.

## Spectrogram

시간에 따른 음악의 변화를 다채로운 패턴으로 보여줍니다. 색상은 각 주파수의 강도를, 세로 위치는 주파수를 나타냅니다.

그래프는 일정한 속도로 오른쪽에서 왼쪽으로 이동하며, 1초마다 눈금이 표시됩니다.

### 표시 가이드
- 색상은 다양한 주파수의 강도를 보여줌:
  - 어두운 색상: 조용한 소리
  - 밝은 색상: 큰 소리
  - 음악에 따라 변화하는 패턴 관찰
- 세로 위치는 주파수를 나타냄:
  - 하단: 베이스 사운드
  - 중간: 주요 악기
  - 상단: 고주파

### 시각적 표시
- 디스플레이에 마우스를 올리거나 터치한 채로 드래그하면 그 지점의 값을 읽을 수 있습니다.

### 볼 수 있는 것
- 멜로디: 흐르는 색상 선
- 비트: 수직 줄무늬
- 베이스: 하단의 밝은 색상
- 하모니: 여러 개의 평행선
- 각기 다른 악기가 만드는 고유한 패턴

### 파라미터
- **Color** - **Normal**은 테마의 그래프 색상을 사용하며 강한 주파수일수록 밝게 표시합니다. **Heatmap**(기본값)은 기존의 다색 단계를 사용합니다. 전환하면 기존 기록도 다시 색칠합니다.
- **DB Range** - 색상의 선명도(-144dB에서 -48dB)
  - 낮은 숫자: 더 미묘한 디테일 관찰
  - 높은 숫자: 주요 소리에 집중
- **Points** - 표시에 사용하는 FFT 크기(256에서 16384)
  - 높은 숫자: 더 세밀한 주파수 정보, 더 느린 시간 업데이트
  - 낮은 숫자: 더 빠른 움직임, 더 낮은 주파수 해상도
  - **Log (HQ)**에서는 Points가 짧은 분석 창을 정하며, 네 배 긴 창이 저주파의 분리도를 높입니다.
- **Frequency Scale** - **Log**는 저주파 영역을 더 넓게 표시합니다. **Log (HQ)**는 고주파용 짧은 측정을 유지하면서 더 긴 측정을 추가해 가까운 저음을 더 분명하게 분리합니다. 처리량이 더 필요하고 저음 변화는 나타나거나 사라지는 데 조금 더 오래 걸릴 수 있지만, 오디오는 바뀌지 않습니다. **Linear**는 동일한 주파수 폭을 같은 간격으로 표시합니다.
- **Keyboard** - 그래프 오른쪽에 음 이름과 주파수의 관계를 보여 주는 정적인 건반 가이드를 표시합니다. 분석 결과나 오디오는 바뀌지 않습니다. 건반 배치는 **Log**, **Log (HQ)** 또는 **Linear**를 따릅니다. **Log (HQ)**는 **Log**와 같은 로그 간격을 사용하며, **Linear**에서는 저주파 건반이 더 좁게 보입니다.
- 분석기는 왼쪽과 오른쪽 채널의 평균을 사용합니다. 모노 입력은 그대로 분석됩니다.

## Spectrum Analyzer

깊은 베이스부터 높은 트레블까지 음악의 주파수를 실시간으로 시각화합니다. 음악의 완전한 사운드를 구성하는 개별 요소들을 보는 것과 같습니다.

### 표시 가이드
- 왼쪽은 저주파수 표시(드럼, 베이스 기타)
- 중간은 주요 주파수 표시(보컬, 기타, 피아노)
- 오른쪽은 고주파수 표시(심벌즈, 반짝임, 공기감)
- 높은 피크는 해당 주파수의 강한 존재감을 의미
- 굵은 선은 현재 소리를 표시합니다
- 가는 선은 최근 피크를 따라가며 소리가 잦아들수록 부드럽게 내려갑니다
- **Bar** 표시에서는 각 막대가 표시 영역에서 같은 너비를 차지하는 구간의 가장 높은 레벨을 보여 줍니다. **Log**와 **Log (HQ)**는 같은 옥타브 폭을, **Linear**는 같은 주파수 폭을 사용합니다.
- 막대 위의 가는 표시는 최근 피크를 나타내며 부드럽게 내려갑니다.
- 다양한 악기가 만드는 서로 다른 패턴 관찰

### 시각적 표시
- 그래프에 마우스를 올리거나 터치한 채로 드래그하면 그 지점의 값을 읽을 수 있습니다.

### 볼 수 있는 것
- 베이스 드롭: 왼쪽의 큰 움직임
- 보컬 멜로디: 중간 영역의 활동
- 선명한 고음: 오른쪽의 반짝임
- 전체 믹스: 모든 주파수가 함께 작동하는 방식

### 파라미터
- **Color** - **Normal**(기본값)은 테마의 그래프 색상을 유지합니다. **Heatmap**은 레벨이 높을수록 밝게 표시하고, **Note Colors**는 주파수에 해당하는 음별 색상을 사용합니다. **Line**과 **Bar** 모두에 적용됩니다. **Bar**와 **Note Colors**를 선택하면 각 막대와 피크 표시는 해당 대역의 중심 주파수에 따른 한 가지 색으로 그려집니다.
- **DB Range** - 디스플레이의 감도(-144dB에서 -48dB)
  - 낮은 숫자: 더 미묘한 디테일 관찰
  - 높은 숫자: 주요 소리에 집중
- **Points** - 가까운 주파수를 얼마나 세밀하게 분리할지 설정(256에서 16384)
  - 높은 숫자: 더 세밀한 주파수 정보, 더 느린 업데이트
  - 낮은 숫자: 더 빠른 업데이트, 더 낮은 주파수 해상도
  - **Log (HQ)**에서는 Points가 짧은 분석 창을 정하며, 네 배 긴 창이 저주파의 분리도를 높입니다.
- **Frequency Scale** - **Log**는 저주파 영역을 더 넓게 표시합니다. **Log (HQ)**는 고주파용 짧은 측정을 유지하면서 더 긴 측정을 추가해 가까운 저음을 더 분명하게 분리합니다. 처리량이 더 필요하고 저음 변화는 나타나거나 사라지는 데 조금 더 오래 걸릴 수 있지만, 오디오는 바뀌지 않습니다. **Linear**는 동일한 주파수 폭을 같은 간격으로 표시합니다.
- **Display** - 스펙트럼의 모양만 바꾸며 분석이나 오디오에는 영향을 주지 않습니다.
  - **Line**(기본값): 스펙트럼을 연속된 선으로 표시합니다.
  - **Bar**: 각 표시 대역의 가장 높은 레벨을 막대로 표시합니다.
- **Keyboard** - 그래프 아래에 음 이름과 주파수의 관계를 보여 주는 정적인 건반 가이드를 표시합니다. 분석 결과나 오디오는 바뀌지 않습니다. 건반 배치는 **Log**, **Log (HQ)** 또는 **Linear**를 따릅니다. **Log (HQ)**는 **Log**와 같은 로그 간격을 사용하며, **Linear**에서는 저주파 건반이 더 좁게 보입니다.
- 분석기는 왼쪽과 오른쪽 채널의 평균을 사용합니다. 모노 입력은 그대로 분석됩니다.

### 이 도구들을 즐기는 방법

1. 음악 탐험하기
   - 다양한 장르가 만드는 서로 다른 패턴 관찰
   - 어쿠스틱과 일렉트로닉 음악의 차이점 확인
   - 악기들이 서로 다른 주파수 범위를 차지하는 방식 관찰

2. 사운드에 대해 배우기
   - 일렉트로닉 음악의 베이스 관찰
   - 보컬 멜로디가 디스플레이를 가로지르는 모습 관찰
   - 드럼이 만드는 날카로운 패턴 관찰

3. 경험 향상시키기
   - Level Meter를 사용해 이펙트 추가 후 신호 피크 확인
   - Spectrum Analyzer가 음악과 함께 춤추는 모습 감상
   - Spectrogram으로 시각적 라이트쇼 만들기

## Stereo Meter

스테레오 사운드가 만들어내는 공간감을 시각화하는 매력적인 도구입니다. 스피커나 헤드폰 사이에서 움직이는 소리를 관찰할 수 있어, 청취 경험에 흥미로운 시각적 차원을 더해줍니다.

### 표시 가이드
- **다이아몬드 디스플레이** - 음악이 생생하게 표현되는 메인 창:
  - 중앙: 매우 조용한 순간 또는 합산 신호가 거의 0에 가까운 순간
  - 상하: 중앙에 있는 소리나 모노에 가까운 소리처럼 좌우 채널이 공유하는 성분
  - 좌우: 채널 간 차이 성분 또는 역상 성분
  - 한쪽이 훨씬 강한 소리는 표시된 모서리 쪽으로 나타날 수 있음
  - 녹색 점이 현재 음악에 맞춰 춤추듯 움직임
  - 흰색 선이 음악의 피크를 추적
  - 흰색 피크 선은 오디오 샘플마다 감쇠하므로 처리 블록 크기가 달라져도 움직임이 일정함
- **Correlation Bar** (왼쪽)
  - 좌우 채널의 상관 관계를 표시
  - 상단(+1.0): 좌우가 거의 같아 보통 중앙에 모여 들림
  - 중앙(0.0): 채널 관계가 약하며 넓은 앰비언스나 서로 다른 좌우 성분에서 자주 나타남
  - 하단(-1.0): 좌우가 거의 반대 극성이라 스피커에서 약하게 들릴 수 있음
- **밸런스 바** (하단)
  - 한쪽 스피커가 다른 쪽보다 더 큰 소리를 내는지 표시
  - 중앙: 양쪽 스피커가 동일한 볼륨
  - 좌/우: 한쪽 스피커의 소리가 더 강함
  - 숫자는 데시벨(dB) 단위로 차이를 표시

### 볼 수 있는 것
- **중앙 사운드**: 중앙에서의 강한 수직 움직임
- **공간감 있는 사운드**: 디스플레이 전체에 퍼진 활동
- **특수 효과**: 모서리 부분의 흥미로운 패턴
- **스피커 밸런스**: 하단 바가 가리키는 방향
- **채널 상관**: 왼쪽 Correlation Bar가 보여주는 관계

### 파라미터
- **Window** (10-1000 ms) - 표시할 최근 오디오 구간
  - 낮은 값: 빠른 음악 변화 확인
  - 높은 값: 전체적인 사운드 패턴 확인
  - 기본값: 100 ms가 대부분의 음악에 적합
- **Gain** (0~24 dB, 기본값 0 dB) - 다이아몬드 그래프의 점과 피크 선만 확대합니다. 값을 높이면 작은 소리의 패턴도 더 잘 보입니다. 오디오와 상관도·밸런스 표시값은 바뀌지 않습니다.

### 음악 즐기기
1. **다양한 스타일 관찰**
   - 클래식 음악은 부드럽고 균형 잡힌 패턴을 보여줌
   - 일렉트로닉 음악은 대담하게 퍼지는 디자인을 만듦
   - 라이브 녹음은 자연스러운 공간 움직임을 보여줌

2. **사운드 특성 발견**
   - 앨범마다 다른 스테레오 효과 사용법 확인
   - 곡마다 다른 소리의 넓이감 관찰
   - 악기가 스피커 사이를 이동하는 모습 관찰

3. **경험 향상**
   - 다른 헤드폰으로 스테레오 표현의 차이 비교
   - 좋아하는 곡의 새로운 버전과 옛 버전 비교
   - 다른 청취 위치에서의 디스플레이 변화 관찰
