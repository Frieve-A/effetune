# 분석 플러그인

음악을 흥미로운 방식으로 시각화할 수 있는 플러그인 모음입니다. 이러한 시각적 도구들은 소리의 다양한 측면을 보여줌으로써 청취 경험을 더욱 몰입감 있고 상호작용적으로 만들어줍니다.

## 플러그인 목록

- [Analog Meter](#analog-meter) - VU, PPM, 피크, 라우드니스 스케일을 갖춘 니들 미터로 채널 레벨 표시
- [Chroma Spiral](#chroma-spiral) - 주파수 성분을 음이름과 옥타브의 나선 위에 표시
- [Level Meter](#level-meter) - 음악의 디지털 신호 레벨과 클리핑 가능성을 표시
- [Note Spectrogram](#note-spectrogram) - 시간에 따른 추정 음높이를 피아노 롤로 표시
- [Oscilloscope](#oscilloscope) - 실시간 파형 시각화
- [Pitch Meter](#pitch-meter) - 하나의 기본 주파수와 튜닝 변화를 시간에 따라 추적
- [Rhythm Analyzer](#rhythm-analyzer) - 템포, 박자마다의 발음, 각 파트가 박자보다 앞서거나 뒤처지는 정도를 표시
- [Spectrogram](#spectrogram) - 시간에 따른 음악의 주파수 변화를 표시
- [Spectrum Analyzer](#spectrum-analyzer) - 음악의 주파수 분포를 실시간으로 표시
- [Stereo Meter](#stereo-meter) - 스테레오 밸런스와 위상 관계를 시각화

## Analog Meter

소리를 바꾸지 않고 클래식한 니들 미터로 각 채널의 레벨을 보여줍니다. 음악의 크기가 순간순간 어떻게 변하는지 따라가거나, 방송과 스트리밍에서 쓰이는 VU, PPM, 피크, 라우드니스(LUFS) 스케일로 재생음이 어떻게 나타나는지 확인할 때 사용하세요. **Custom**에서는 검파기, 니들의 움직임, 눈금을 조합해 원하는 미터를 만들 수 있습니다.

### 활용 가이드

- **VU로 평균 레벨 확인하기**: 곡을 재생하며 니들을 지켜보세요. 조용한 벌스와 힘있는 코러스는 확실한 차이를 보이지만, 짧은 드럼 히트는 니들을 거의 움직이지 않습니다.
- **True Peak로 클리핑 확인하기**: EQ와 게인 계열 이펙트 뒤에 Analog Meter를 배치하고 곡에서 가장 큰 부분을 재생하세요. 값이 0 dBFS를 넘거나 오버 램프가 켜지면 체인에서 클리핑이 발생할 수 있으므로, 피크가 0 dBFS 아래(예: -1 dBFS 정도의 여유)로 내려갈 때까지 게인을 낮추세요.
- **Loudness로 곡 비교하기**: **Target**을 -14 LUFS 같은 스트리밍 기준값으로 설정하고, 곡이나 앨범 시작 부분에서 **Reset**을 누른 뒤 끝까지 재생하세요. Integrated 값은 전체적인 라우드니스를, 최대 True Peak 값은 가장 높은 피크를 보여주므로 앨범이나 재생목록의 볼륨을 맞추는 기준이 됩니다. LRA를 보면 곡마다 라우드니스가 얼마나 넓게 변하는지도 비교할 수 있습니다.
- **Custom으로 원하는 미터 만들기**: 니들이 활기차게 움직이게 하려면 **Bouncy VU**, 평균 레벨을 차분하게 보려면 **Slow RMS**, 짧은 피크를 따라가려면 **Fast Peak**에서 시작하세요. **Needle Response**로 속도를, **Overshoot**로 튀는 정도를 조절합니다. PPM처럼 올라갔다 내려오는 모습을 만들 수 있지만 Custom의 피크 검파기는 즉시 상승합니다. 표준 PPM 응답을 보려면 **PPM**을 사용하세요.

### 시스템 프리셋

효과 헤더의 **효과 프리셋**을 클릭하면 표준 미터나 사용자 지정 미터 설정으로 한 번에 바꿀 수 있습니다. **Mode**가 바뀌는 프리셋을 선택하면 측정이 처음부터 다시 시작되지만, Loudness 프리셋끼리 전환할 때는 측정이 계속됩니다.

- **Studio VU (-18 dBFS)** - 0 VU를 -18 dBFS에 맞춘 VU입니다. 스튜디오에서 널리 쓰이는 기준(EBU R68)으로, 헤드룸을 넉넉히 둔 녹음에 적합합니다.
- **SMPTE VU (-20 dBFS)** - 0 VU를 -20 dBFS에 맞춘 VU(SMPTE RP 155)입니다. 북미 스튜디오와 방송에서 쓰이는 기준입니다.
- **Hot VU (-14 dBFS)** - 기본 설정과 같습니다. 0 VU를 -14 dBFS에 맞춘 VU로, 완성된 상업 음원 대부분에 잘 맞습니다.
- **Loud Master VU (-8 dBFS)** - 0 VU를 -8 dBFS에 맞춘 VU입니다. 음압을 한껏 끌어올린 요즘 CD나 팝 마스터에서 니들이 상단에 붙어 버리지 않도록 해 줍니다.
- **DIN PPM** - DIN 미터(**Attack** 5 ms, 1.5초에 20 dB 하강, DIN 스케일)입니다. -9 표시를 -18 dBFS에 맞추므로 0 표시는 -9 dBFS가 됩니다. 스케일은 -50까지 표시합니다.
- **BBC PPM** - BBC 미터(**Attack** 10 ms, 2.8초에 24 dB 하강, BBC 스케일)입니다. 4 표시를 -18 dBFS에 맞추므로 6 표시는 -10 dBFS가 됩니다.
- **Nagra Modulometer** - Nagra 테이프 레코더의 모듈로미터(**Attack** 7.5 ms, -30~+5 dB의 dB 스케일)입니다. 0 dB를 -18 dBFS에 맞춥니다. **Release**는 DIN과 같은 1.5초입니다.
- **K-20** - Bob Katz의 K-System을 적용한 RMS 미터입니다. 0을 -20 dBFS에 맞추고 눈금은 -60 dBFS까지 내려갑니다. 다이내믹 레인지가 넓은 녹음에 적합합니다.
- **K-14** - 같은 방식으로 0을 -14 dBFS에 맞추고, 눈금은 -60 dBFS까지입니다. 일반적인 팝 음악에 적합합니다.
- **K-12** - 같은 방식으로 0을 -12 dBFS에 맞추고, 눈금은 -60 dBFS까지입니다. 방송용으로 음압을 바짝 끌어올린 음원에 적합합니다.
- **Digital Peak** - 표준 디지털 피크 미터(IEC 60268-18)입니다. -60~0 dBFS를 표시하며 피크 표시를 2초 동안 유지합니다.
- **True Peak Clip Watch** - True Peak에서 상단 20 dB를 확대하고 피크 표시를 가장 긴 10초 동안 유지합니다. EQ나 게인을 바꾼 뒤 0 dBFS를 넘는 피크를 놓치지 않기 위한 설정입니다.
- **EBU R128 (-23 LUFS)** - 유럽 방송 기준을 목표값으로 한 Loudness입니다. 스케일은 EBU +9입니다.
- **EBU R128 +18 Scale** - 같은 목표값에 폭이 더 넓은 EBU +18 스케일을 사용합니다. 클래식처럼 다이내믹 레인지가 넓은 음원에 적합합니다.
- **TV (-24 LKFS)** - 미국(ATSC A/85)과 일본(ARIB TR-B32)의 TV에서 쓰이는 -24 LKFS를 목표값으로 한 Loudness입니다.
- **Streaming (-14 LUFS)** - 많은 음악 스트리밍 서비스의 음량 정규화에 가까운 -14 LUFS를 목표값으로 한 Loudness입니다. 니들은 차분하게 움직이는 Short-term입니다.
- **Streaming (-16 LUFS)** - 스트리밍과 팟캐스트에 권장되는 -16 LUFS(AES TD1008)를 목표값으로 한 Loudness입니다. 니들은 Short-term입니다.
- **Bouncy VU** - VU와 같은 검파기와 눈금을 사용하는 Custom입니다. 오버슈트를 15%로 설정해 니들이 더 크게 튀도록 합니다.
- **Slow RMS** - 3초 RMS 평균, 1000 ms 니들 응답, 오버슈트 없음으로 설정한 Custom입니다. dB 눈금의 0은 -18 dBFS이며, 아래로 -60 dBFS까지 표시합니다.
- **Fast Peak** - True Peak 검파, 0.5초 검파기 릴리스, 10 ms 니들 응답, 오버슈트 없음으로 설정한 Custom입니다. dBFS 눈금으로 상단 40 dB를 표시하며, 측정 단위는 dBTP입니다.

### 파라미터

선택한 **Mode**에 해당하는 항목만 표시됩니다. **Custom**에서는 해당 모드의 설정 항목을 모두 표시하고, 적용되지 않는 항목은 비활성화합니다. 설정을 바꿔도 패널 높이는 변하지 않습니다.

- **Mode** - 미터 종류를 **VU**(기본값), **PPM**, **RMS**, **Sample Peak**, **True Peak**, **Loudness**, **Custom** 중에서 선택합니다. 모드마다 니들이 움직이는 방식과 눈금이 다릅니다(표시 가이드 참고). 모드를 바꾸면 측정이 처음부터 다시 시작됩니다.
- **Detector**(Custom; 기본값 Average Rectified) - 니들이 따라갈 레벨을 선택합니다. **Average Rectified**는 VU처럼 신호의 절대 진폭을 니들 자체로 평균하며, 별도의 평균 구간은 없습니다. **RMS**는 **Integration** 시간 동안의 평균 파워를 측정합니다. **Sample Peak**는 가장 큰 샘플 값을 잡고, **True Peak**는 샘플 사이의 피크도 추정합니다. 두 피크 검파기 모두 즉시 상승하고 **Release**에 따라 내려갑니다. 검파기를 바꾸면 측정이 처음부터 다시 시작됩니다.
- **Integration**(RMS, RMS 검파기를 쓰는 Custom; 0.05~3초; 기본값 0.3초) - 평균을 내는 시간을 설정합니다. 값을 늘리면 니들이 안정적이고 느리게 움직이고, 줄이면 변화에 더 빠르게 반응합니다. Custom에서는 이 평균값에 니들 자체의 응답이 추가됩니다.
- **Attack**(PPM; 1~20 ms; 기본값 5 ms) - PPM 니들이 상승하는 속도를, 정상음보다 2 dB 낮게 읽히는 톤 버스트 길이로 설정합니다. 값을 줄이면 짧은 피크도 원래 레벨에 가깝게 나타나고, 늘리면 짧은 피크일수록 더 낮게 읽힙니다. 5 ms는 DIN 미터에 해당합니다.
- **Release**(PPM, Sample Peak, True Peak, Sample Peak 또는 True Peak 검파기를 쓰는 Custom; 0.1~5초; 기본값 1.5초) - 피크 이후 20 dB 내려가는 데 걸리는 시간을 설정합니다. 값을 늘리면 피크를 더 쉽게 읽을 수 있고, 줄이면 음악의 변화를 더 세밀하게 따라갑니다. Custom에서는 검파기의 하강 속도를 정하며, 그 뒤에 니들 자체의 응답이 적용됩니다. 1.5초는 DIN 미터 및 표준 디지털 피크 미터와 같은 값입니다.
- **Needle Response**(Custom; 1~3000 ms; 기본값 300 ms) - 검파기 레벨이 새로운 일정한 값으로 바뀌었을 때, 니들이 그 레벨의 99%에 처음 도달하는 데 걸리는 시간입니다. 값을 줄이면 더 빠르게, 늘리면 더 느리게 움직입니다. 전체 움직임에는 RMS 평균 시간과 피크 릴리스도 영향을 줍니다.
- **Overshoot**(Custom; 0~25%; 기본값 1.25%) - 니들이 새로운 일정한 검파 레벨을 넘어가는 정도를 레벨 변화량에 대한 백분율로 설정합니다. 값을 높이면 더 크게 튀고, 0에서는 레벨을 넘지 않고 가까워집니다.
- **Dial**(Custom; 기본값 VU) - 검파기나 니들 움직임과 별개로 **VU**, **DIN**, **BBC**, **dB**, **dBFS** 눈금을 선택합니다. VU, DIN, BBC는 아래 표의 눈금을 사용합니다. dB는 0 표시가 **Reference**이며 상단은 0 dBFS입니다. dBFS는 상단이 0 dBFS이며, **Detector**가 True Peak이면 측정값을 dBTP로 표시합니다.
- **Reference**(VU, PPM, RMS, dBFS 눈금을 제외한 Custom; -30~0 dBFS; 기본값 -14 dBFS) - 미터의 기준 표시에 해당하는 디지털 레벨을 설정합니다. 기본값은 완성된 상업 음원 대부분에 잘 맞는 값입니다. 스튜디오에서 쓰이는 -18 dBFS나 -20 dBFS 기준(시스템 프리셋 참고)에서는 일반적인 CD에서도 니들이 스케일 상단 근처에 머물기 쉽습니다. 음압이 높은 음원에서 니들이 스케일 상단까지 올라갈 때는 값을 높이고, 조용한 음원에서 니들이 거의 움직이지 않을 때는 값을 낮추세요.
- **Range**(DIN 또는 dB 스케일의 PPM, RMS, Sample Peak, True Peak, DIN, dB 또는 dBFS 눈금의 Custom; 20~60 dB; 기본값 40 dB) - 스케일이 아래로 얼마나 내려가는지 설정합니다. 넓히면 조용한 구간까지 볼 수 있고, 좁히면 스케일 상단부가 더 넓게 펼쳐집니다.
- **PPM Scale**(PPM; 기본값 DIN) - PPM 스케일을 **DIN**, **BBC**, **dB** 중에서 선택합니다(표시 가이드 참고).
- **Peak Hold**(PPM, RMS, Sample Peak, True Peak, Custom; 0~10초; 기본값 1초) - 최근 최고값을 나타내는 피크 표시가 유지되는 시간과 오버 램프가 켜져 있는 시간을 설정합니다. 0으로 설정하면 표시를 끄고, 오버 램프는 1초 동안 켜집니다.
- **Needle**(Loudness; 기본값 Momentary) - 니들이 나타내는 값을 선택합니다. **Momentary**는 최근 0.4초의 라우드니스를 따르고, **Short-term**은 최근 3초의 값을 보여주며 더 안정적으로 움직입니다.
- **Target**(Loudness; -36~-10 LUFS; 기본값 -23 LUFS) - 스케일에 표시할 라우드니스를 설정하고, 그 값을 기준으로 스케일을 배치합니다. -23 LUFS는 EBU R128 방송 기준이며, 많은 스트리밍 서비스는 -14 LUFS 근처의 값을 사용합니다.
- **Scale**(Loudness; 기본값 EBU +9) - 라우드니스 스케일의 폭을 선택합니다. **EBU +9**는 **Target**보다 18 LU 아래부터 9 LU 위까지, **EBU +18**은 36 LU 아래부터 18 LU 위까지를 표시하며, 다이내믹 레인지가 넓은 음악이나 매우 큰 음원에 적합합니다.

### 표시 가이드

- 채널마다 하나의 미터가 있으며, 한 행에 최대 4개, 최대 16채널까지 표시합니다.
- 레벨은 풀스케일 사인파가 0 dBFS로 읽히는 디지털의 일반적인 규칙을 따르므로, 일정한 사인파는 Loudness를 제외한 모든 모드에서 같은 값을 나타냅니다.
- 니들이 움직이는 속도는 모드마다 다릅니다.

| 모드 | 니들의 움직임 | 스케일 |
|---|---|---|
| VU | 느리게 움직입니다. 약 0.3초 안에 새로운 레벨에 도달하며 평균 레벨을 나타냅니다(IEC 60268-17). | -20~+3 VU. 0 VU = **Reference**. |
| PPM | IEC 60268-10을 기반으로 한 근사치입니다. **Attack**으로 정한 속도로 빠르게 상승합니다. 기본값 5 ms에서는 DIN 미터와 마찬가지로 10 ms 버스트가 정상음보다 약 1 dB 낮게 읽힙니다. **Release** 시간 동안 20 dB 내려갑니다. | **PPM Scale**로 선택합니다. **DIN**: -9 표시 = **Reference**이며 0은 그보다 9 dB 위입니다. **BBC**: 1~7 표시로, 2~7 사이는 4 dB, 1~2 사이는 6 dB 간격이며 4 표시 = **Reference**입니다. **dB**: 0 표시 = **Reference**이며, **Range** 만큼 아래부터 +5 dB까지 표시합니다. |
| RMS | **Integration** 시간 동안의 평균 파워를 나타내며, 별도의 평활화는 적용하지 않습니다. | 0 표시 = **Reference**. |
| Sample Peak | 가장 높은 샘플 값으로 즉시 이동합니다. | 스케일 상단 = 0 dBFS. |
| True Peak | Sample Peak와 비슷하지만 샘플 사이의 피크도 추정합니다. 0 dBFS를 넘어 읽힐 수 있으며, 이런 피크는 DAC나 변환 과정에서 클리핑될 수 있습니다. | 스케일 상단 = 0 dBFS. |
| Loudness | ITU-R BS.1770과 EBU R128에서 정의한 라우드니스를 LUFS로 나타냅니다. | **Target**과 **Scale**로 정해지며, 값은 LUFS로 표시됩니다. |
| Custom | **Detector**의 레벨을 따라가며, **Needle Response**로 속도, **Overshoot**로 튀는 정도가 결정됩니다. 기본 설정에서는 VU와 같은 니들 움직임을 보입니다. | 니들 움직임과 별개로 **Dial**에서 선택합니다. |

- 피크 표시는 **Peak Hold** 시간 동안 최근 최고값을 보여줍니다. 오버 램프는 레벨이 0 dBFS를 넘으면 켜지고, **Peak Hold** 시간 동안(**Peak Hold**가 0이면 1초 동안) 켜진 상태를 유지합니다.
- Loudness 모드에서는 첫 번째 미터가 프로그램 전체를 나타냅니다. 니들은 **Needle** 설정을 따르며, Momentary(M), Short-term(S), Integrated(I), Loudness Range(LRA), 최대 True Peak 값, 측정 경과 시간과 **Reset** 버튼을 표시합니다. Integrated와 LRA는 충분한 길이의 오디오가 측정되어야 나타납니다.
  - 모노, 스테레오, 5.1(채널 순서 L, R, C, LFE, Ls, Rs)에서는 이 값들이 표준 채널 가중치를 따릅니다. 다른 채널 수에서는 모든 채널을 동일한 가중치로 합산하므로 값은 참고용입니다.
  - 첫 번째 이후의 미터는 각 채널을 개별적으로 나타냅니다. 채널 가중치나 게이팅을 적용하지 않은 참고값입니다.
- Integrated, LRA, 최대 True Peak는 **Reset**을 누르거나, **Mode**를 바꾸거나, 샘플레이트나 채널 수가 바뀌거나, 오디오 처리가 재시작될 때까지 계속 누적됩니다.
- 처리가 일시 정지된 시간은 측정에 포함되지 않습니다. 무음 상태에서 절전으로 일시 정지된 동안, Master Bypass가 켜져 있거나 Analog Meter가 꺼져 있는 동안, 설정의 **숨겨진 동안 표시용 DSP 건너뛰기**가 켜진 상태(기본값)에서 Effect Pipeline이 표시되지 않는 동안(음악 라이브러리 표시 중, 최소화 중, 미니 플레이어 사용 중 등)이 여기에 해당합니다. 다시 시작하면 멈춘 지점부터 측정을 이어갑니다.

## Chroma Spiral

소리를 바꾸지 않고 음악의 주파수 성분이 12개 음이름과 각 옥타브의 어디에 놓이는지 보여줍니다. 겹치는 배음을 살펴보거나, 보컬과 베이스의 음역을 비교하거나, 악기의 성분이 퍼지는 범위를 확인할 때 유용합니다.

### 활용 가이드

- 한 음을 길게 내고 원음과 배음이 나타나는 위치를 보세요. 한 음만 연주해도 여러 음이름이 밝아질 수 있으며, 각각 별도로 연주된 음이라는 뜻은 아닙니다.
- 화음이나 멜로디를 들으며 활성 위치의 변화를 살펴보세요. 조성의 단서는 얻을 수 있지만 화음 이름이나 조를 판별하지는 않습니다.
- 조율 상태를 살펴보려면 밝은 점이나 채워진 영역의 바깥쪽 가장자리가 음이름 눈금 사이에 나타나는지 확인하세요. 한 기본음의 차이를 센트 단위로 읽으려면 Pitch Meter를 사용하세요.
- 그래프를 마우스, 손가락 또는 펜으로 누르면 선택한 나선 위치의 사인파를 들을 수 있습니다. 드래그하면 음높이가 바뀌고, 놓거나 동작을 취소하면 소리가 멈춥니다. 이 미리 듣기는 모든 **Color** 설정에서 작동합니다.

### 파라미터

- **Color** - 스펙트럼을 그리는 방식을 선택합니다. 배경의 나선 가이드는 모든 설정에서 똑같이 표시되며 소리가 없을 때도 남아 있습니다.
  - **Normal**(기본값): 각 주파수 셀을 테마의 그래프 선 색으로 점을 찍어 표시합니다. 점의 밝기는 셀의 레벨에 따라 변하고 면적은 그 레벨에 비례해 커져, 약한 주파수도 더 쉽게 볼 수 있습니다. 최대 강도에서는 점의 반지름이 다음 나선 바퀴까지 거리의 절반에 이릅니다.
  - **Normal 2**: 각 주파수의 나선 위치에서 해당 레벨까지 그래프 선 색으로 채우되 데이터의 윤곽선은 그리지 않습니다.
  - **Note Colors**: Normal과 같은 점 표시를 사용하되, 음이름마다 다른 색을 사용하며 같은 음이름에는 옥타브가 달라도 같은 색을 씁니다.
- **Lowest Octave**(1~8, 기본값 1) - 가장 안쪽 옥타브를 정합니다. 높이면 높은 음역에 집중할 수 있습니다.
- **Highest Octave**(1~9, 기본값 7) - 가장 바깥쪽 옥타브를 정합니다. 낮추면 저음과 중음에 집중할 수 있습니다. 두 범위의 순서는 자동으로 유지됩니다.
- **Frequency Tilt**(-6~+6 dB/oct, 0.5 단위, 기본값 +3) - 소리를 바꾸지 않고 100 Hz보다 높은 주파수의 표시 레벨을 조정합니다. 양수는 높은 주파수를 더 두드러지게 하고 음수는 덜 두드러지게 합니다. 0에서는 주파수에 따른 보정을 하지 않습니다.
- **Level Range**(6~96 dB, 1 dB 단위, 기본값 24) - 움직이는 표시 범위의 폭을 정합니다. 좁히면 레벨 차이가 강조되고, 넓히면 강한 성분과 함께 약한 성분도 볼 수 있습니다.
- **Display Floor**(-120~-24 dB, 1 dB 단위, 기본값 -60) - 조용한 구간에서 움직이는 표시 범위의 아래쪽 경계가 내려갈 수 있는 최저 레벨을 정합니다. 낮추면 선택한 **Level Range** 안의 더 약한 성분도 표시될 수 있습니다. 표시 범위는 최근 최고값도 따라 움직이므로 모든 약한 성분이 보인다는 뜻은 아닙니다.

### 화면 읽는 법

- 나선 한 바퀴가 한 옥타브입니다. C는 위쪽에 있고 음이름은 시계 방향으로 이어집니다. 안쪽일수록 낮으며 C 표시에는 옥타브 번호가 붙습니다.
- **Normal**과 **Note Colors**에서는 음 사이를 포함해 점이 밝고 클수록 해당 위치의 성분이 강합니다. **Normal 2**에서는 성분이 강할수록 채워진 영역이 바깥쪽으로 더 뻗으며, 별도 윤곽선 없이 바깥 가장자리로 스펙트럼의 변화를 읽을 수 있습니다.
- 점의 밝기와 면적, 채워진 영역의 폭은 최근 최고값에 따른 상대적인 강도이며 절대 레벨을 나타내지 않습니다.
- 낮은 옥타브에서는 가까운 음을 구분하기 어렵고 반응이 느려져 서로 겹쳐 보일 수 있습니다.

### 시각적 표시
- 디스플레이에 마우스를 올리거나 터치한 채로 드래그하면 그 지점의 값을 읽을 수 있습니다.

## Level Meter

음악의 디지털 신호 레벨을 실시간으로 보여주는 디스플레이입니다. 이펙트 적용 후 레벨을 확인하고, 들리는 왜곡으로 번지기 전에 클리핑 가능성을 파악하는 데 도움이 됩니다.

### 표시 가이드
- 수평 막대가 오른쪽으로 길어질수록 신호 레벨이 큽니다
- 흰색 마커는 새로운 피크를 1초 동안 유지한 다음 부드럽게 내려갑니다
- OVERLOAD는 신호가 안전한 디지털 범위를 넘어 왜곡될 수 있음을 뜻합니다
- 깨끗한 재생을 위해 빨간색 레벨이나 OVERLOAD 경고가 자주 뜨지 않게 조정하세요. 실제 청취 음량은 기기 볼륨에서 맞춥니다

## Note Spectrogram

오디오를 바꾸지 않고 A0~C8 범위에서 추정한 기본 주파수(F0)를 흐르는 피아노 롤로 표시합니다. 화음의 구성음, 보컬과 멜로디 라인, 베이스 라인, 옥타브를 넘나들며 겹치는 음을 따라가는 데 유용하며, 음색별 색 구분과 강조 표시도 사용할 수 있습니다.

### 활용 가이드

- **화음과 멜로디**: 화음은 같은 시점에 나란히 밝게 빛나는 여러 행으로, 멜로디와 베이스 라인은 음 행을 가로지르는 궤적으로 보입니다.
- **보컬이나 베이스 따라가기**: **Instrument (3)**을 선택하거나, **Note Colors**를 유지한 채 **Highlight**에서 **Vocal** 또는 **Bass**를 선택합니다. 더 세밀한 그룹 구분에는 **Instrument (9)**를 사용합니다.
- **추정의 정확도**: 음높이와 음색 추정은 정확한 채보가 아니라 들으면서 눈으로 따라가기 위한 보조 수단입니다. 소리가 겹치거나 타악기, 노이즈가 있으면 추정이 모호해질 수 있으며, 드럼은 분류하지 않습니다. 음색 추정은 앞서 나온 음을 단서로 사용하므로 켠 직후나 재생 위치를 옮긴 직후에는 신뢰도가 떨어집니다. 한 번 확정된 추정은 수정되지 않습니다.

### 음색 그룹

**Instrument (3)**은 음을 **Vocal**, **Bass**, **Other**(아래 그룹 중 Vocal과 Bass를 제외한 모든 그룹)로 나눕니다.

**Instrument (9)**는 음을 다음 9개 그룹으로 나눕니다.
- **Vocal**: 녹음된 사람의 노래(독창과 합창 포함).
- **Bass**: 어쿠스틱 베이스, 일렉트릭 베이스, 신스 베이스.
- **Guitar**: 어쿠스틱 기타, 클린 일렉트릭 기타, 디스토션 기타.
- **Piano**: 어쿠스틱 피아노, 일렉트릭 피아노, 하프시코드, 클라비넷.
- **Strings**: 현악기 솔로와 앙상블, 피치카토, 하프, 신스 스트링.
- **Wind**: 색소폰과 플루트를 포함한 금관악기와 목관악기.
- **Synth**: 신스 리드와 패드.
- **Organ**: 오르간, 아코디언, 하모니카.
- **Other**: 음정이 있는 타악기(첼레스타, 비브라폰), 합성 합창/보이스 패치, 신스 효과음, 오케스트라 히트, 민속 악기, 효과음.

### 파라미터

- **Color** - 음높이 검출 결과는 바꾸지 않고 표시 색을 선택합니다(전환하면 기존 기록도 다시 칠해집니다).
  - **Normal**(기본값): 테마의 그래프 선 색상.
  - **Note Colors**: 음이름마다 다른 색을 사용하며, 같은 음이름은 모든 옥타브에서 같은 색입니다.
  - **Instrument (3)**: Vocal, Bass, Other별 색상.
  - **Instrument (9)**: 위의 9개 음색 그룹별 색상.
- **Highlight** - 특정 그룹(**Vocal**, **Bass**, **Other (3)**, **Guitar**, **Piano**, **Strings**, **Wind**, **Synth**, **Organ**, **Other (9)**)을 강조합니다. 해당 그룹에 속할 가능성이 낮은 음일수록 중립적인 회색에 가깝게 바꾸며, 음량을 나타내는 두께는 유지합니다. **None**(기본값)에서는 강조하지 않습니다.
  - 음의 시작(온셋)과 음색 분석에는 추가 CPU가 사용됩니다. CPU 사용량을 최소화하려면 **Onsets**를 끄고, **Normal** 또는 **Note Colors**를 선택한 뒤 **Highlight**를 **None**으로 설정합니다.
- **Pitch Resolution** - 기록을 지우지 않고 세로 방향의 음높이 세밀도를 선택합니다.
  - **1/12 Octave**(기본값): 반음마다 한 행.
  - **High**: 추정한 센트 위치에 음높이를 배치해 비브라토와 피치 벤드를 보여 줍니다.
- **Layout** - **Horizontal**(기본값, 건반은 아래쪽, 기록은 위로 흐름) 또는 **Vertical**(건반은 오른쪽, 기록은 왼쪽으로 흐름).
- **Volume** - 막대 두께와 건반 가장자리의 반원형 미터로 상대 음량을 나타냅니다(기본값 켜짐). 끄면 막대 두께가 일정해집니다.
- **Onsets** - 추정한 음의 시작을 삼각형(Horizontal에서는 ▼, Vertical에서는 ▶)으로 표시합니다(기본값 꺼짐). 각 삼각형 밑변의 중앙이 발음 시각과 음높이를 나타내므로, 지속되는 같은 음을 다시 연주해도 각각 별도로 표시됩니다. 끄더라도 Instrument 계열 **Color**나 **Highlight**에 필요한 동안에는 음색 분석이 계속됩니다.
- **Time Span**(1~10 s, 기본값 2 s) - 피아노 롤에 표시할 기록의 길이입니다.
- **Lowest Note** / **Highest Note** - 분석하고 표시할 음역을 설정합니다(기본값: E1~G6).

### 표시 가이드

- **음높이 갱신**: 새로운 소리는 즉시 표시되며, 약 40, 80, 160 ms 뒤에 이어지는 소리도 단서로 삼아 더 정확하게 다듬어집니다. 표시 지연은 늘어나지 않으며 **화면을 오디오와 동기화**에도 영향을 주지 않습니다.
- **그리드와 건반**: 각 C의 선은 옥타브 경계를 나타내고, E와 F 사이의 안내선은 모든 모드에서 표시됩니다. 검은 건반에 해당하는 행은 배경이 더 어둡습니다. 건반은 현재 음높이 추정의 신뢰도에 따라 빛납니다.
- **색의 진하기**: 색의 진하기는 항상 음높이 추정의 신뢰도를 나타냅니다. 입력이 너무 작아 분석할 수 없을 때는 피아노 롤이 어두운 상태로 유지됩니다.
- **음색 색상과 강조**: 음색 색상은 추정 확률에 따라 각 그룹의 색을 섞은 것입니다. 음색 추정이 완료되면 기록의 해당 위치에 색상이 표시됩니다. 분류를 기다리는 음은 중립적인 회색으로 표시됩니다. 범례에는 표시 중인 그룹이 나열되며, 강조 중에는 그 뒤에 **Highlight:**와 선택한 그룹이 이어집니다. 범례의 그룹 위에 마우스를 올리면 그 그룹을 일시적으로 강조할 수 있습니다.
- **음량 막대**: **Volume**이 켜져 있으면 막대 두께는 24 dB의 상대 범위에서 변합니다. 건반 가장자리의 부드러운 반원은 현재 음량에 맞춰 즉시 올라가고 20 dB/s로 내려갑니다.

### 시각적 표시
- 기록 위에 마우스를 올리거나 터치한 채로 드래그하면 음이름, 시각, **Salience**(음높이 추정의 신뢰도), **Level**(dB)을 읽을 수 있습니다. 음색 분석이 동작 중일 때는 그룹별 추정 확률도 표시됩니다. **Instrument (3)**에서는 **Vocal**, **Bass**, **Other**, 그 밖에는 9개 그룹이며, **Highlight** 그룹이 그 안에 없으면 그 그룹도 추가됩니다(추정 결과가 없는 음은 **Not classified**).

## Oscilloscope

소리의 파형을 실시간으로 보여 주므로, 들으면서 비트, 날카로운 어택, 음량 변화를 눈으로 확인할 수 있습니다. 파형이 반복될 때는 트리거 설정으로 표시를 안정시킬 수 있습니다.

### 사용 가이드
- 반복되는 파형의 한 주기를 보려면 **Display Time**을 1~20 ms, **Trigger Mode**를 **Auto**로 설정합니다.
- 비트와 음량 엔벨로프가 오른쪽에서 왼쪽으로 매끄럽게 흐르는 모습을 따라가려면 **Display Time**을 1,000~10,000 ms, **Trigger Mode**를 **Off**로 설정합니다.
- **Auto**와 **Normal** 모드에서는 **Display Time** 길이만큼의 소리가 모두 모인 시점에 파형이 갱신됩니다.

### 파라미터
- **Display Time**(1~10,000 ms) - 표시할 시간 범위입니다. 짧게 하면 파형의 주기 하나하나를, 길게 하면 전체 엔벨로프의 패턴을 보여 줍니다.
- **Trigger Mode**:
  - **Auto**: 트리거 이벤트가 없어도 계속 갱신합니다.
  - **Normal**: 트리거가 발생할 때만 갱신하고, 다음 트리거까지 마지막 파형을 유지합니다.
  - **Off**: 오른쪽에서 왼쪽으로 계속 흐릅니다. 트리거 설정은 적용되지 않습니다.
- **Trigger Level**(-1~1) - 캡처를 시작하는 정규화 진폭 임계값입니다(모노 신호 또는 좌우 평균 신호에서 검출합니다).
- **Trigger Edge** - **Rising**(위쪽으로 교차할 때 트리거) 또는 **Falling**(아래쪽으로 교차할 때 트리거).
- **Holdoff**(0.1~10 ms) - 트리거 사이의 최소 대기 시간입니다.
- **Display Level**(-96~0 dB, 기본값 0 dB) - 표시의 위쪽과 아래쪽 끝에 해당하는 레벨을 설정합니다. 0 dB에서는 ±1 전체 범위를 표시하며, 값을 낮출수록 작은 신호를 확대해 보여 줍니다.
- **Vertical Offset**(-1~1) - 파형을 위아래로 이동합니다. 양수 값은 파형을 위로 올립니다.

### 표시 가이드
- **가로축**: 시간(밀리초 또는 초).
- **세로축**: 정규화 진폭. **Display Level**에 따라 확대되고 **Vertical Offset**에 따라 위아래로 이동합니다.
- **선과 엔벨로프 띠**: 표시 시간이 짧으면 파형을 연속된 선으로 그리고, 길면 최소값부터 최대값까지를 채운 띠로 그립니다. 많은 샘플이 한 픽셀 폭에 겹쳐도 짧은 피크가 보이도록 하기 위해서입니다.

### 시각적 표시
- 그래프 위에 마우스를 올리거나 터치한 채로 드래그하면 시간과 진폭(표시 시간이 길 때는 Minimum/Maximum)을 읽을 수 있습니다.

## Pitch Meter

오디오를 바꾸지 않고 한 번에 하나의 기본 주파수(F0)를 2초 길이의 흐르는 피아노 롤로 추적합니다. 독창이나 독주의 튜닝과 음정 움직임을 확인하는 데 사용합니다.

### 활용 가이드

- 한 음을 길게 연주하거나 부르면서, 선이 음 행의 중앙에 머무는지, 아니면 높거나 낮은 쪽으로 벗어나는지 확인합니다.
- 비브라토, 슬라이드, 피치 벤드는 음 행을 가로지르는 매끄러운 곡선으로 나타납니다.
- Pitch Meter는 가장 두드러진 하나의 음높이만 추적하므로, 화음, 소리가 빽빽한 믹스, 타악기에서는 선이 끊기거나 옥타브가 뛸 수 있습니다. 여러 음이 겹치는 소재에는 [Note Spectrogram](#note-spectrogram)을 사용합니다.
- 스테레오 입력은 처음 두 채널의 평균을 분석하므로(모노 입력은 그대로 사용), 두 채널에서 극성이 반대인 소리는 서로 상쇄되어 선이 나타나지 않을 수 있습니다.

### 파라미터

- **Color** - 검출에는 영향을 주지 않고 선 색을 바꿉니다. **Normal**(기본값, 테마의 그래프 선 색상), **Heatmap**(24 dB 범위의 상대 음량), **Note Colors**(음이름별 색상) 중에서 선택합니다.
- **Layout** - **Horizontal**(기본값, 건반은 아래쪽, 기록은 위로 흐름) 또는 **Vertical**(건반은 오른쪽, 기록은 왼쪽으로 흐름).
- **Reference A4**(400~480 Hz, 기본값 440 Hz) - 음이름과 센트 편차의 기준이 되는 튜닝 주파수입니다.
- **Lowest Note** / **Highest Note** - 분석하고 표시할 음역을 설정합니다(기본값: C2~C7, 설정 범위: A0~C8).

### 표시 가이드

- 선의 위치는 반음 사이까지 포함한 연속적인 음높이를 나타냅니다. 신뢰도가 높을수록 선이 밝아지고, 무음이나 음정이 없는 소리에서는 선이 끊깁니다.
- 판독값은 가장 가까운 음이름(음이름별 색상)과 센트 단위의 튜닝 편차(`+`는 높음, `-`는 낮음. 예: `+3.5 cent`)를 표시합니다.

### 시각적 표시
- 표시 위에 마우스를 올리거나 터치한 채로 드래그하면 그 지점의 값을 읽을 수 있습니다.

## Rhythm Analyzer

음악의 템포를 찾아내고, 드럼과 악기의 타격이 어디에 오는지, 각 파트가 얼마나 앞서거나 늦게 연주되는지를 한 박씩 보여 줍니다. **Metronome Click**을 켜지 않는 한 소리는 바꾸지 않습니다. 곡의 BPM을 찾거나, 스윙을 측정하거나, 스네어가 박보다 뒤에 있는지 확인하거나, 드럼 필인과 곡 구성의 전환점을 찾는 데 사용합니다.

### 활용 가이드

- **템포 확인**: 박이 일정한 곡을 재생합니다. 확정된 BPM과 **adopted** 선은 소리보다 약 1~2초 늦게 나타나며, **LOCKED**는 램프와 클릭이 박을 실제로 짚고 있는 상태를 나타냅니다. 느껴지는 템포의 두 배나 절반으로 고정되었다면 **×½**, **×2**, **strongest**를 비교합니다.
- **박의 위치를 귀로 확인**: **Metronome Click**을 켜면 검출된 박마다 클릭음이 들립니다. 클릭을 들을 때는 Rhythm Analyzer를 이펙트 체인의 마지막에 두고, 처리한 오디오 파일을 내보내기 전에는 **Metronome Click**을 끄세요.
- **두 배·절반 템포 고정 바로잡기**: 느린 발라드가 두 배 템포로 고정되면 **Max BPM**을 그 값보다 낮추고, 빠른 곡이 절반 템포로 고정되면 **Min BPM**을 그 값보다 높입니다.
- **그루브와 미세 타이밍 읽기**: 프로그래밍된 비트는 레인 중앙 근처에 놓이고 **jitter**는 0 ms에 가깝습니다. 스네어가 킥보다 항상 15 ms 늦으면 2박과 4박에서 **Mid** 점이 레인 중앙보다 위에 나타나고, Beat lens에는 **+15** 표시가 나타납니다.
- **스윙 읽기**: **swing**은 오프비트의 지연 비율을 나타냅니다(1.00:1은 스트레이트, 2.00:1은 셋잇단 셔플). 스윙하는 그루브에서는 오프비트 타격이 Beat lens의 **&**가 아니라 **⅔** 열에 모입니다.
- **필인과 전환점 찾기**: 링(**◎**)은 한두 사이클 전의 같은 박 위치에서는 연주되지 않았던 타격을 강조하므로, **Echo rows**에서 드럼 필인과 섹션 전환이 눈에 띕니다.
- **searching으로 표시될 때**: 새로운 박 표시와 클릭은 멈추지만 분석은 계속됩니다. 템포, Timing lanes, Beat lens는 계속 표시되며 신뢰도가 낮아질수록 흐려집니다. 무음이 되면 현재 박의 읽기 값과 Tempogram의 열이 지워지고, 소리가 돌아오면 분석을 다시 시작합니다.

### 파라미터

- **Min BPM**(40~192, 기본값 40) / **Max BPM**(50~240, 기본값 240) - 템포를 찾는 범위입니다(Max BPM은 항상 Min BPM의 1.25배 이상으로 유지되며, 어느 쪽을 바꾸든 분석을 다시 시작합니다).
- **Metronome Click**(기본값 꺼짐) - 검출된 박마다 −10 dBFS의 짧은 클릭음을 채널 1과 2(모노이면 채널 1)에 섞습니다. 다른 채널은 바뀌지 않습니다.
- **Span (beats)**(4, 6, 8, 12, 16, 기본값 8) - Timing lanes와 Echo rows의 각 행에 표시할 박 수입니다(예: 4/4박자 두 마디는 8, 3/4박자 두 마디는 6).
- **Tempogram**, **Timing lanes**, **Echo rows**, **Beat lens** - 각 표시 패널을 표시하거나 숨깁니다(Timing lanes와 Beat lens는 처음에 켜져 있으며, 패널을 숨겨도 분석은 멈추지 않습니다).

### 화면 읽는 법

가로로 긴 화면에서는 **Beat lens**가 Timing lanes 오른쪽에 놓이고, 세로로 긴 화면에서는 모든 패널이 세로로 쌓입니다. 타격은 **High**(하이햇, 심벌), **Mid**(스네어, 보컬, 악기), **Low**(킥, 베이스) 행으로 나뉘어 표시됩니다.
- **헤더**: 박에 맞춰 빛나는 램프(신뢰도가 낮을수록 약해지고 **searching** 중에는 속이 빈 모양), 확정된 BPM(**LOCKED** 또는 **searching**), **×½**, **×2**, Tempogram의 **strongest** 후보, **swing** 비율(최근 32박에서 계산), **jitter**(평균 위치를 중심으로 한 타격의 전형적인 흩어짐, ms), 기호 범례를 표시합니다. 아직 얻지 못한 값은 —로 표시됩니다.
- **Tempogram**: 템포의 지지도를 최근 20초 동안 표시합니다. **Time**은 왼쪽에서 오른쪽으로 진행하고, **Tempo (BPM)**는 30~480의 로그 눈금입니다. 실선의 **adopted** 템포 선과 점선의 **×2** / **×½** 선을 겹쳐 그립니다. 밝기는 각 템포의 상대적인 지지도를 나타내며, 그 템포가 맞을 확률은 아닙니다.
- **Timing lanes**: 최근 *N*박(**Span (beats)**, 캡션은 **Last N beats**)의 타격을 표시합니다. 점이 클수록 확실한 타격이며, 가장 최근 위치는 추정값으로 약 1~2초 뒤에 확정됩니다. 세로 막대의 높이는 가장 가까운 16분음표 또는 셋잇단 그리드에 대한 미세 타이밍을 직전 16박의 전형적인 타이밍과 비교해 나타냅니다(**+20** / **−20** ms 점선 가이드. 중앙보다 위는 늦음, 아래는 빠름. ±30 ms를 넘는 타격은 레인 가장자리에 머뭅니다). 속이 빈 원(**○**)은 타이밍을 얻을 수 없는 타격(레인 중앙에 표시), 음영 영역은 타이밍 분석이 없는 구간, 링(**◎**)은 1~2사이클 전과 비교해 새로운 타격, 세로 점선은 박 그리드의 재정렬을 나타냅니다.
- **Echo rows**: 이전 *N*박 사이클을 가장 새로운 것이 위에 오도록 세로로 쌓아 반복되는 마디 패턴이 열에 맞춰 정렬되므로 필인이나 변화가 눈에 띕니다. **Cycles ago**는 행에 1부터 번호를 매기며, **Timing lanes**를 숨기면 맨 위 행이 현재 사이클(0)이 됩니다. 각 타격은 대역을 나타내지만 타이밍은 나타내지 않습니다.
- **Beat lens**: 최근 확정된 32박에 대해 박 안의 위치(**1**, **e**, **&**, **a**, **⅓**, **⅔**)별로 각 대역이 평균적으로 얼마나 빠르게(표시가 왼쪽) 또는 늦게(표시가 오른쪽) 연주되는지(±30 ms 스케일)와 흩어짐(음영 막대, ±표준편차 1)을 요약합니다. 편차는 앙상블 전체에 대한 상대값이고, 표시가 불투명할수록 그 위치에서 더 자주 연주된다는 뜻입니다. 표시되려면 해당 위치에 4번 이상의 타격이 필요하며, 3 ms 이상의 편차에는 라벨이 붙습니다. 박 분석을 사용할 수 있을 때까지는 **waiting for a steady beat**가 표시됩니다.
- **신뢰도**: 표시가 흐리면 연주가 느슨하다는 뜻이 아니라 분석의 신뢰도가 낮다는 뜻입니다.
- **Reset**: 표시 아래의 **Reset** 버튼은 표시를 지우고 분석을 다시 시작합니다. 예를 들어 다른 앱에서 곡을 바꿨을 때 사용합니다. EffeTune 플레이어에서 새 곡이 시작되면 분석이 자동으로 다시 시작됩니다.

### 시각적 표시
- 표시 위에 마우스를 올리거나 터치한 채로 드래그하면 값을 읽을 수 있습니다. Timing lanes와 Echo rows에서는 가장 가까운 타격이 몇 박 전인지와 그 대역, 타이밍(얻을 수 없으면 —)을, Tempogram에서는 템포, **Tempo support**, **Adopted** 템포를, Beat lens에서는 각 대역의 편차와 흩어짐을 표시합니다.

### 제한 사항

- 루바토가 있는 연주, 클래식 음악, 피아노 독주, 앰비언트나 박이 없는 구간에서는 템포와 박 추적이 불확실해집니다. 박이 느껴지는 템포의 두 배, 절반, 2/3배, 1.5배 또는 오프비트에 고정될 수도 있습니다(범위를 좁히려면 **Min BPM** / **Max BPM**을 사용합니다). **LOCKED**가 박이 맞다는 것을 보장하지는 않습니다.
- 템포가 연속적으로 변하면 박이 약간 늦게 따라가므로 클릭이 조금 빠르거나 늦을 수 있습니다.
- 소리가 빽빽한 믹스나 노이즈가 많은 녹음에서는 **Mid**와 **High** 레인에 불필요한 점이 나타나고, **Low** 레인에서는 낮은 피아노 음 일부를 놓칩니다.
- 이 분석기는 마디선이나 박자표가 아니라 박을 추적합니다(1박째는 판별하지 않습니다).
- 지원 샘플레이트: 8, 11.025, 16, 22.05, 24, 32, 44.1, 48, 88.2, 96, 176.4, 192, 352.8, 384 kHz. 그 밖의 샘플레이트에서는 오디오가 그대로 통과하지만 분석과 클릭은 사용할 수 없습니다.

## Spectrogram

시간에 따라 음악이 어떻게 변하는지 보여 줍니다. 색의 진하기는 각 주파수의 강도를, 세로 위치는 주파수를 나타냅니다.

그래프는 일정한 속도로 오른쪽에서 왼쪽으로 이동하며, 1초마다 눈금이 표시됩니다.

### 표시 가이드
- 색상은 다양한 주파수의 강도를 보여줌:
  - 어두운 색상: 조용한 소리
  - 밝은 색상: 큰 소리
  - 음악에 따라 변화하는 패턴 관찰
- 세로 위치는 주파수를 나타냄:
  - 하단: 베이스 사운드
  - 중간: 주요 악기
  - 상단: 고주파
- **Log (HQ)**에서는 가까운 저주파 음이 더 뚜렷하게 분리된 띠로 나타납니다. 저주파 측정이 더 길기 때문에 안정되거나 사라지는 데 조금 더 걸릴 수 있습니다.

### 시각적 표시
- 디스플레이에 마우스를 올리거나 터치한 채로 드래그하면 그 지점의 값을 읽을 수 있습니다.

### 볼 수 있는 것
- 멜로디: 흐르는 색상 선
- 비트: 수직 줄무늬
- 베이스: 하단의 밝은 색상
- 하모니: 여러 개의 평행선
- 각기 다른 악기가 만드는 고유한 패턴

### 파라미터
- **DB Range** - 색상의 선명도(-144dB에서 -48dB)
  - 낮은 숫자: 더 미묘한 디테일 관찰
  - 높은 숫자: 주요 소리에 집중
- **Points** - 표시에 사용하는 FFT 크기(256에서 16384)
  - 높은 숫자: 더 세밀한 주파수 정보, 더 느린 시간 업데이트
  - 낮은 숫자: 더 빠른 움직임, 더 낮은 주파수 해상도
  - **Log (HQ)**에서는 Points가 짧은 분석 창을 정하며, 네 배 긴 창이 저주파의 분리도를 높입니다.
- **Color** - **Normal**은 테마의 그래프 색상을 사용하며 강한 주파수일수록 밝게 표시합니다. **Heatmap**(기본값)은 어두운 색에서 밝은 색으로 이어지는 기존의 다색 스케일을 사용합니다. 색을 전환하면 기존 기록도 다시 칠해집니다.
- **Frequency Scale** - **Log**는 저주파 영역을 더 넓게 표시합니다. **Log (HQ)**는 고주파용 짧은 측정을 유지하면서 더 긴 측정을 추가해 가까운 저음을 더 분명하게 분리합니다. 처리량이 더 필요하고 저음 변화는 나타나거나 사라지는 데 조금 더 오래 걸릴 수 있지만, 오디오는 바뀌지 않습니다. **Linear**는 동일한 주파수 폭을 같은 간격으로 표시합니다.
- **Keyboard** - 그래프 오른쪽에 음 이름과 주파수의 관계를 보여 주는 정적인 건반 가이드를 표시합니다. 분석 결과나 오디오는 바뀌지 않습니다. 건반 배치는 **Log**, **Log (HQ)** 또는 **Linear**를 따릅니다. **Log (HQ)**는 **Log**와 같은 로그 간격을 사용하며, **Linear**에서는 저주파 건반이 더 좁게 보입니다.
- 분석기는 왼쪽과 오른쪽 채널의 평균을 사용합니다. 모노 입력은 그대로 분석됩니다.

## Spectrum Analyzer

깊은 베이스부터 높은 트레블까지 음악의 주파수를 실시간으로 시각화합니다. 음악의 완전한 사운드를 구성하는 개별 요소들을 보는 것과 같습니다.

### 표시 가이드
- 왼쪽은 저주파수 표시(드럼, 베이스 기타)
- 중간은 주요 주파수 표시(보컬, 기타, 피아노)
- 오른쪽은 고주파수 표시(심벌즈, 반짝임, 공기감)
- 높은 피크는 해당 주파수의 강한 존재감을 의미
- 굵은 선은 현재 소리를 표시합니다
- 가는 선은 최근 피크를 따라가며 소리가 잦아들수록 부드럽게 내려갑니다
- **Bar** 표시에서는 각 막대가 표시 영역에서 같은 너비를 차지하는 구간의 가장 높은 레벨을 보여 줍니다. **Log**와 **Log (HQ)**는 같은 옥타브 폭을, **Linear**는 같은 주파수 폭을 사용합니다.
- 막대 위의 가는 표시는 최근 피크를 나타내며 부드럽게 내려갑니다.
- **Log (HQ)**에서는 가까운 저음이 별개의 피크로 나타날 수 있습니다. 저주파 측정이 더 길기 때문에 안정되거나 사라지는 데 조금 더 걸릴 수 있습니다.
- 다양한 악기가 만드는 서로 다른 패턴 관찰

### 시각적 표시
- 그래프에 마우스를 올리거나 터치한 채로 드래그하면 그 지점의 값을 읽을 수 있습니다.

### 볼 수 있는 것
- 베이스 드롭: 왼쪽의 큰 움직임
- 보컬 멜로디: 중간 영역의 활동
- 선명한 고음: 오른쪽의 반짝임
- 전체 믹스: 모든 주파수가 함께 작동하는 방식

### 파라미터
- **DB Range** - 디스플레이의 감도(-144dB에서 -48dB)
  - 낮은 숫자: 더 미묘한 디테일 관찰
  - 높은 숫자: 주요 소리에 집중
- **Points** - 가까운 주파수를 얼마나 세밀하게 분리할지 설정(256에서 16384)
  - 높은 숫자: 더 세밀한 주파수 정보, 더 느린 업데이트
  - 낮은 숫자: 더 빠른 업데이트, 더 낮은 주파수 해상도
  - **Log (HQ)**에서는 Points가 짧은 분석 창을 정하며, 네 배 긴 창이 저주파의 분리도를 높입니다.
- **Color** - **Normal**(기본값)은 테마의 그래프 색상을 유지합니다. **Heatmap**은 레벨이 높을수록 밝게 표시하고, **Note Colors**는 주파수 축을 따라 음별 색상을 적용합니다. 이 선택은 Line 표시와 Bar 표시 모두에 적용됩니다. **Bar**와 **Note Colors**를 함께 사용하면 각 막대와 피크 표시는 해당 대역의 중심 주파수에 따른 한 가지 색으로 그려집니다.
- **Frequency Scale** - **Log**는 저주파 영역을 더 넓게 표시합니다. **Log (HQ)**는 고주파용 짧은 측정을 유지하면서 더 긴 측정을 추가해 가까운 저음을 더 분명하게 분리합니다. 처리량이 더 필요하고 저음 변화는 나타나거나 사라지는 데 조금 더 오래 걸릴 수 있지만, 오디오는 바뀌지 않습니다. **Linear**는 동일한 주파수 폭을 같은 간격으로 표시합니다.
- **Display** - 스펙트럼의 모양만 바꾸며 분석이나 오디오에는 영향을 주지 않습니다.
  - **Line**(기본값): 스펙트럼을 연속된 선으로 표시합니다.
  - **Bar**: 각 표시 대역의 가장 높은 레벨을 막대로 표시합니다.
- **Keyboard** - 그래프 아래에 음 이름과 주파수의 관계를 보여 주는 정적인 건반 가이드를 표시합니다. 분석 결과나 오디오는 바뀌지 않습니다. 건반 배치는 **Log**, **Log (HQ)** 또는 **Linear**를 따릅니다. **Log (HQ)**는 **Log**와 같은 로그 간격을 사용하며, **Linear**에서는 저주파 건반이 더 좁게 보입니다.
- 분석기는 왼쪽과 오른쪽 채널의 평균을 사용합니다. 모노 입력은 그대로 분석됩니다.

## Stereo Meter

스테레오 사운드가 만들어내는 공간감을 시각화하는 매력적인 도구입니다. 스피커나 헤드폰 사이에서 움직이는 소리를 관찰할 수 있어, 청취 경험에 흥미로운 시각적 차원을 더해줍니다.

### 표시 가이드
- **다이아몬드 디스플레이** - 음악이 생생하게 표현되는 메인 창:
  - 중앙: 매우 조용한 순간 또는 합산 신호가 거의 0에 가까운 순간
  - 상하: 중앙에 있는 소리나 모노에 가까운 소리처럼 좌우 채널이 공유하는 성분
  - 좌우: 채널 간 차이 성분 또는 역상 성분
  - 한쪽이 훨씬 강한 소리는 표시된 모서리 쪽으로 나타날 수 있음
  - 녹색 점이 현재 음악에 맞춰 춤추듯 움직임
  - 흰색 선이 음악의 피크를 추적
  - 흰색 피크 선은 오디오 샘플마다 감쇠하므로 처리 블록 크기가 달라져도 움직임이 일정함
- **상관관계 바** (왼쪽)
  - 좌우 채널의 상관 관계를 표시
  - 상단(+1.0): 좌우가 거의 같아 보통 중앙에 모여 들림
  - 중앙(0.0): 채널 관계가 약하며 넓은 앰비언스나 서로 다른 좌우 성분에서 자주 나타남
  - 하단(-1.0): 좌우가 거의 반대 극성이라 스피커에서 약하게 들릴 수 있음
- **밸런스 바** (하단)
  - 한쪽 스피커가 다른 쪽보다 더 큰 소리를 내는지 표시
  - 중앙: 양쪽 스피커가 동일한 볼륨
  - 좌/우: 한쪽 스피커의 소리가 더 강함
  - 숫자는 데시벨(dB) 단위로 차이를 표시

### 볼 수 있는 것
- **중앙 사운드**: 중앙에서의 강한 수직 움직임
- **공간감 있는 사운드**: 디스플레이 전체에 퍼진 활동
- **특수 효과**: 모서리 부분의 흥미로운 패턴
- **스피커 밸런스**: 하단 바가 가리키는 방향
- **채널 상관**: 왼쪽 상관관계 바가 보여주는 관계

### 파라미터
- **Window** (10-1000 ms) - 표시할 최근 오디오 구간
  - 낮은 값: 빠른 음악 변화 확인
  - 높은 값: 전체적인 사운드 패턴 확인
  - 기본값: 100 ms가 대부분의 음악에 적합
- **Gain** (0~24 dB, 기본값 0 dB) - 다이아몬드 그래프의 점과 피크 선만 확대합니다. 값을 높이면 작은 소리의 패턴도 더 잘 보입니다. 오디오와 상관도·밸런스 표시값은 바뀌지 않습니다.

### 음악 즐기기
1. **다양한 스타일 관찰**
   - 클래식 음악은 부드럽고 균형 잡힌 패턴을 보여줌
   - 일렉트로닉 음악은 대담하게 퍼지는 디자인을 만듦
   - 라이브 녹음은 자연스러운 공간 움직임을 보여줌

2. **사운드 특성 발견**
   - 앨범마다 다른 스테레오 효과 사용법 확인
   - 곡마다 다른 소리의 넓이감 관찰
   - 악기가 스피커 사이를 이동하는 모습 관찰

3. **경험 향상**
   - 다른 헤드폰으로 스테레오 표현의 차이 비교
   - 좋아하는 곡의 새로운 버전과 옛 버전 비교
   - 다른 청취 위치에서의 디스플레이 변화 관찰

## 이 도구들을 즐기는 방법

1. 음악 탐험하기
   - 다양한 장르가 만드는 서로 다른 패턴 관찰
   - 어쿠스틱과 일렉트로닉 음악의 차이점 확인
   - 악기들이 서로 다른 주파수 범위를 차지하는 방식 관찰

2. 사운드에 대해 배우기
   - 일렉트로닉 음악의 베이스 관찰
   - 보컬 멜로디가 디스플레이를 가로지르는 모습 관찰
   - 드럼이 만드는 날카로운 패턴 관찰

3. 경험 향상시키기
   - Level Meter를 사용해 이펙트 추가 후 신호 피크 확인
   - Spectrum Analyzer가 음악과 함께 춤추는 모습 감상
   - Spectrogram으로 시각적 라이트쇼 만들기

기억하세요: 이러한 도구들은 청취 경험에 시각적 차원을 더함으로써 음악을 더욱 즐겁게 만들어주기 위한 것입니다. 좋아하는 음악을 새로운 방식으로 탐험하고 발견하는 즐거움을 누려보세요!
