# 복원 플러그인

복원 플러그인은 음악을 자연스럽게 들을 수 있도록 유지하면서 녹음의 원치 않는 결함을 줄입니다.

## 플러그인 목록

- [Click Remover](#click-remover) - 짧은 클릭, 크래클, 팝, 드롭아웃을 복원합니다
- [Clip Restorer](#clip-restorer) - 하드 클리핑으로 평평해진 피크를 복원합니다
- [Hum Remover](#hum-remover) - 지속적인 전기 험과 그 고조파를 제거합니다
- [Noise Reduction](#noise-reduction) - 지속적인 히스와 배경 소음을 줄입니다

## Click Remover

Click Remover는 레코드 크래클, 팝, 클릭, 아주 짧은 드롭아웃처럼 짧고 고립된 결함을 복원합니다. 지속적인 히스나 험이 아니라 가끔 생기는 끊김에 사용하세요.

### 청취 가이드

1. **Sensitivity** 50%, **Max Repair Length** 1 ms로 시작합니다.
2. 거슬리는 클릭이 줄어들 때까지 **Sensitivity**를 조금씩 올립니다. 드럼 어택이나 다른 선명한 음악 디테일이 무뎌지면 다시 낮춥니다.
3. 보통의 크래클보다 긴 팝이나 드롭아웃일 때만 **Max Repair Length**를 올리고, 일반적인 크래클에는 짧게 유지합니다.
4. 문제가 있는 부분을 재생하며 **REPAIRS/S**를 확인하고, 강한 설정을 유지하기 전에 효과를 끈 소리와 비교합니다.

### 파라미터

- **Sensitivity**(0–100%, 기본값 50%)는 짧은 변화를 결함으로 판단하는 민감도를 정합니다. 높이면 의심되는 클릭을 더 많이 복원하고, 낮추면 더 보수적으로 동작해 음악의 어택을 보존하기 쉽습니다.
- **Max Repair Length**(0.1–2 ms, 기본값 1 ms)는 한 번의 복원 최대 길이를 제한합니다. 조금 긴 팝이나 드롭아웃에는 올리고, 짧은 크래클에는 낮춥니다.

### 표시 읽기

**REPAIRS/S**는 최근 초당 클릭 복원 횟수입니다. 0에 가까우면 현재 짧은 결함을 거의 복원하지 않는다는 뜻입니다. 일반 음악에서 높은 값이 계속되면 **Sensitivity** 또는 **Max Repair Length**를 낮추세요.

## Clip Restorer

Clip Restorer는 디지털 하드 클리핑으로 평평해진 피크를 재구성합니다. 꼭대기가 평평한 왜곡이 뚜렷한 녹음에 유용하지만, EffeTune에 들어오기 전에 잃은 모든 디테일을 되살릴 수는 없습니다.

### 청취 가이드

1. **Threshold** -0.10 dB, **Output Gain** -3 dB로 시작합니다.
2. 뚜렷하게 클리핑된 피크가 남으면 **Threshold**를 조금 낮춥니다. 크고 지속적인 소리까지 불필요하게 바뀌면 0 dB 쪽으로 올립니다.
3. 가능하면 **Output Gain**을 0 dB 아래로 유지합니다. 복원된 피크는 원래의 평평한 피크보다 높아질 수 있습니다.
4. 손상된 구간에서 **RESTORED**를 확인하고, 가장 덜 침습적인 설정을 위해 효과를 끈 소리와 비교합니다.

### 파라미터

- **Threshold**(-18–0 dB, 기본값 -0.10 dB)는 클리핑된 피크로 처리할 레벨을 정합니다. 0 dB에 가까우면 거의 최대 레벨의 평평한 피크만 대상으로 하며, 낮추면 덜 뚜렷한 클리핑도 포함하지만 큰 음악 소리에 영향을 줄 수 있습니다.
- **Output Gain**(-12–0 dB, 기본값 -3 dB)은 복원 후 출력 레벨을 정합니다. 더 크게 하려면 0 dB 쪽으로 올리고, 복원 피크의 여유를 늘리려면 낮춥니다.

### 표시 읽기

**RESTORED**는 최근 클리핑된 피크로 복원한 오디오 샘플의 비율입니다. 클리핑은 짧은 피크에만 생기는 경우가 많아 작은 값도 정상일 수 있습니다. 클리핑으로 들리지 않는 소리에서 높은 값이 계속되면 **Threshold**를 올리세요.

## Hum Remover

Hum Remover는 턴테이블, 케이블 또는 전원 문제에서 생길 수 있는 50 Hz나 60 Hz의 지속적인 전기 험과 고조파를 줄입니다. 일반적인 배경 소음이 아니라 일정한 톤에 사용합니다.

### 청취 가이드

1. **Frequency**를 **Auto**, **Harmonics**를 8, **Tracking Speed**를 50%로 시작합니다.
2. 녹음의 전원 주파수를 알면 **50 Hz** 또는 **60 Hz**를 선택합니다. 모르면 **Auto**로 두고 **FUNDAMENTAL**을 확인합니다.
3. 기본음 위의 버징이 남으면 **Harmonics**를 올리고, 음악의 두께나 디테일이 줄면 낮춥니다.
4. 험의 음높이가 천천히 변하면 **Tracking Speed**를 올리고, 안정적인 험에는 낮춥니다. 지속되는 저음이 고조파와 정확히 겹치면 **Harmonics**를 낮추세요.

### 파라미터

- **Frequency**(**Auto**, **50 Hz**, **60 Hz**, 기본값 **Auto**)는 험의 기본 주파수를 선택합니다. **Auto**는 감지한 전원성 험을 추적하며, 주파수를 알면 고정값을 선택합니다.
- **Harmonics**(1–64, 기본값 8)는 기본 주파수의 몇 배음까지 제거할지 정합니다. 높이면 더 많은 버징을 줄이고, 낮추면 높은 고조파 근처의 음악을 더 보존합니다. 슬라이더는 로그 눈금을 사용하므로 낮은 값을 더 세밀하게 조절할 수 있습니다.
- **Tracking Speed**(0–100%, 기본값 50%)는 자동 추적이 변하는 험을 따라가는 속도를 정합니다. 높이면 변화에 빨리 따라가고, 낮추면 안정적인 험에 적합합니다.

### 표시 읽기

**FUNDAMENTAL**은 현재 대상으로 하는 주파수를 보여 줍니다. **REMOVED**는 제거 중인 험 성분의 레벨을 dBFS로 보여 줍니다. 0 dBFS에 가까울수록 제거 중인 험이 강하며, -140 dBFS처럼 매우 낮으면 현재 제거 중인 험이 거의 없다는 뜻입니다.

## Noise Reduction

Noise Reduction은 테이프 히스, 장비 소음, 실내 소음처럼 지속되는 배경 소음을 낮춥니다. 음악 뒤에 일정한 소음층이 있을 때 사용하세요. 음 사이에도 남는 소음에 가장 효과적이며, 개별 클릭, 변하는 배경음 또는 녹음 속 다른 음악을 제거하기 위한 기능은 아닙니다.

### 청취 가이드

1. **Reduction** 12 dB, **Sensitivity** 0 dB, **Smoothing** 50%, **Treble Care** 50%, **Mix** 100%로 시작합니다.
2. 조용한 부분이 깨끗해질 때까지 **Reduction**을 천천히 올립니다. 보컬, 심벌 또는 잔향이 부자연스러워지면 낮춥니다.
3. 뚜렷한 지속 히스에는 **Sensitivity**를 조금 올리고, 이미 깨끗한 음악에는 낮춥니다.
4. 감소량이 흔들리거나 음색이 바뀌는 듯하면 **Smoothing**을 올립니다. 음악이 너무 부드러워지면 **Smoothing** 또는 **Reduction**을 낮춥니다.
5. 효과를 끈 소리와 비교하고, 원래의 공간감이 더 자연스럽다면 **Mix**로 일부를 섞습니다.

### 파라미터

- **Reduction**(0–24 dB, 기본값 12 dB)은 배경 소음의 최대 감소량입니다. 낮으면 부드럽고, 높으면 소음을 더 줄이지만 약한 디테일도 가릴 수 있습니다. 약한 소음에는 6–12 dB부터 시작하세요.
- **Sensitivity**(-12–+12 dB, 기본값 0 dB)는 소리를 배경 소음으로 처리하는 민감도입니다. 지속 소음이 남으면 올리고, 조용한 악기·리버브 잔향·공간감이 너무 줄면 낮춥니다.
- **Smoothing**(0–100%, 기본값 50%)은 가까운 주파수 사이의 감소를 더 일정하게 합니다. 높이면 흔들리거나 물속 같은 느낌을 줄이며, 소리가 탁하면 이것과 **Reduction**을 낮춥니다.
- **Treble Care**(0–100%, 기본값 50%)는 고주파 음악 디테일을 보호합니다. 심벌, 현악기, 보컬의 밝음을 보존하려면 올리고, 높은 히스가 계속 거슬릴 때만 낮춥니다.
- **Mix**(0–100%, 기본값 100%)는 처리음과 원음을 섞습니다. 100%에서는 처리음만 들리며, 원래 공간감이 자연스러우면 낮춥니다. 0%에서는 소리가 바뀌지 않습니다.

### 권장 설정

1. **가벼운 정리:** Reduction 6–10 dB, Sensitivity -2–0 dB, Smoothing 40–60%, Treble Care 50–70%.
2. **뚜렷한 테이프 또는 장비 히스:** Reduction 12–18 dB, Sensitivity 0–+4 dB, Smoothing 60–80%, Treble Care 50–70%.
3. **섬세한 고음 보존:** Reduction 6–12 dB, Sensitivity -4–0 dB, Smoothing 50–70%, Treble Care 70–100%, Mix 70–100%.
