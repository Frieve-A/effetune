# 기타 오디오 도구

주요 이펙트 카테고리를 보완하는 특수 오디오 도구와 제너레이터 모음입니다. 현재 재생 경로에 테스트 톤이나 노이즈를 섞어 스피커, 헤드폰, 채널 밸런스를 확인하는 데 사용할 수 있습니다.

## 플러그인 목록

- [Oscillator](#oscillator) - 테스트 톤과 노이즈를 현재 오디오 경로에 더하는 신호 제너레이터
- [SFZ Note Player](#sfz-note-player) - 감지한 음을 가져온 SFZ 악기로 재생

## Oscillator

다양한 파형을 생성해 현재 오디오 경로에 섞는 신호 제너레이터입니다. 오디오 입력을 대체하지 않으므로, 음악이 재생 중이면 생성된 톤이나 노이즈가 음악 위에 더해집니다. 큰 소리의 테스트 톤은 듣기 피로와 장비 부담을 줄 수 있으므로, 켜기 전에 **Volume**을 낮게 설정하세요.

### 기능
- 다양한 파형 타입:
  - 특정 주파수 확인을 위한 순수 사인파
  - 풍부한 하모닉을 가진 사각파
  - 더 부드러운 하모닉을 가진 삼각파
  - 밝은 질감의 톱니파
  - 임펄스 응답과 타이밍을 확인하기 위한 주기적인 1샘플 Impulse
  - 전체 대역 확인을 위한 White Noise
  - 청감상 더 고르게 느껴지는 Pink Noise
- 버스트 테스트와 간헐적 신호를 위한 펄스 동작 모드

### 파라미터
- **Frequency (Hz)** - 생성된 톤의 피치를 제어합니다(20 Hz에서 96 kHz). Impulse, White Noise, Pink Noise에서는 비활성화됩니다. 실제로 들리거나 출력되는 최고 주파수는 현재 샘플 레이트의 Nyquist 한계에 따라 제한됩니다.
  - 저주파수: 깊은 베이스 톤
  - 중간 주파수: 음악적 범위
  - 고주파수: 트위터나 고역 응답 확인
- **Volume (dB)** - 출력 레벨 조정(-96 dB에서 0 dB)
  - 처음에는 낮은 값으로 시작
  - 필요할 때만 천천히 올림
- **Panning (L/R)** - 스테레오 배치 제어
  - 중앙: 양쪽 채널에서 동일
  - 좌/우: 채널 밸런스 테스트
- **Waveform Type** - 신호 타입 선택
  - Sine: 깨끗한 레퍼런스 톤
  - Square: 홀수 하모닉이 풍부
  - Triangle: 더 부드러운 하모닉 콘텐츠
  - Sawtooth: 완전한 하모닉 시리즈
  - Impulse: 현재 오디오 샘플 레이트를 기준으로 Interval마다 최대 진폭의 샘플 하나를 출력하며 Frequency는 영향을 주지 않음
  - White Noise: Hz당 동일한 에너지
  - Pink Noise: 옥타브당 동일한 에너지
- **Mode** - 신호 생성 패턴 제어
  - Continuous: 표준 연속 신호 생성
  - Pulsed: 제어 가능한 타이밍의 간헐적 신호
  - Impulse는 항상 Pulsed를 사용하며 Continuous는 비활성화
- **Interval (ms)** - 펄스 모드에서 펄스 간 시간 간격(100-2000 ms, 단계 10 ms)
  - 짧은 간격: 빠른 펄스 시퀀스
  - 긴 간격: 넓은 간격의 펄스
  - Impulse를 포함하여 Mode가 Pulsed로 설정된 경우 활성
- **Width (ms)** - 펄스 모드에서 각 펄스의 램프 시간입니다(2-100 ms, 단계 1 ms). 값은 Interval의 절반을 넘지 않도록 제한되며, 실제 펄스는 대략 Width의 두 배 길이로 들립니다.
  - 각 펄스의 페이드 인/페이드 아웃 시간 제어
  - 짧은 폭: 날카로운 펄스 에지
  - 긴 폭: 더 부드러운 펄스 전환
  - Mode가 Pulsed로 설정된 경우에만 활성. Impulse는 항상 정확히 1샘플이므로 비활성화

### 사용 예

1. 스피커 테스트
   - 주파수 재생 범위 확인
     * 저주파에서 고주파까지 사인파 스윕 사용
     * 소리가 들리지 않거나 왜곡되는 지점 확인
   - 거슬리는 울림이나 왜곡 확인
     * 다양한 주파수에서 순수 사인파 사용
     * 원치 않는 하모닉이나 왜곡 청취
     * 다양한 볼륨 레벨에서의 동작 비교
   - 버스트 신호 테스트
     * 짧은 간격과 폭으로 펄스 모드 사용
     * 간헐적 신호에 대한 시스템 응답 분석

2. 청취 공간 확인
   - 정재파 식별
     * 의심되는 룸 모드 주파수에서 사인파 사용
     * 노드와 안티노드를 찾기 위해 공간 이동
   - 공진과 잔향 확인
     * 문제가 되는 공진을 찾기 위해 다양한 주파수 테스트
     * 전체적인 밸런스를 확인하기 위해 Pink Noise 사용
   - 다양한 위치에서 주파수 응답 매핑
     * 청취 영역 전체의 일관성을 확인하기 위해 사인 스윕 사용
   - 에코와 반사 분석
     * 펄스 모드를 사용하여 직접음과 반사음을 명확히 분리

3. 헤드폰/이어폰 테스트
   - 채널 간 크로스토크 평가
     * 한 채널에만 신호 전송
     * 다른 채널로의 원치 않는 누출 확인
   - 주파수 응답 테스트
     * 주파수 밸런스를 확인하기 위해 사인 스윕 사용
     * 좌우 채널 응답 비교
   - 과도 응답 테스트
     * 펄스 모드를 사용하여 버스트 신호에서의 시스템 동작 평가
     * Impulse를 사용하여 설정한 Interval마다 1샘플 과도 신호 생성
     * 반사음이나 이펙트 잔향을 분리하려면 긴 Interval을 사용하고, 날카로운 피크에 대비해 낮은 Volume에서 시작

4. 청취 범위 확인
   - 개인 청취 범위 확인
     * 상한과 하한을 찾기 위해 주파수 스윕
     * 주파수 간격이나 약점 확인
   - 최소 가청 볼륨 결정
     * 다양한 볼륨에서 여러 주파수 테스트
     * 주파수별 민감도 차이 확인
   - 시간 처리 평가
     * 다양한 간격의 펄스 모드를 사용하여 시간 분해능 테스트

5. 시스템 확인
   - 컴포넌트 간 레벨 매칭
     * 레퍼런스 주파수에서 사인파 사용
     * 신호 체인 전체에서 일관된 레벨 확보
   - 채널 밸런스 검증
     * 다양한 주파수에서 좌/우 밸런스 테스트
     * 적절한 스테레오 이미징 확보
   - 버스트 신호 응답 테스트
     * 펄스 모드를 사용하여 간헐적 신호에 대한 시스템 응답 테스트
     * 짧은 소리에 대한 반응 확인

Oscillator는 테스트용 도구입니다. 장비 손상이나 청취 피로를 방지하기 위해 낮은 Volume에서 시작하여 필요한 만큼만 천천히 올리세요.

## SFZ Note Player

SFZ Note Player는 입력 오디오에서 음을 감지하고 선택한 SFZ 악기로 연주합니다. 피아노 SFZ로 곡의 음을 따라 연주하거나 원음에 다른 악기 소리를 겹칠 수 있습니다. 여러 음을 동시에 추정하므로, 특히 소리가 밀집된 곡에서는 음을 놓치거나 잘못 감지할 수 있습니다.

음높이를 변경하거나 샘플 레이트를 변환할 때 앨리어싱 노이즈를 자동으로 줄입니다.

**Retrigger Drop**으로 같은 음이 계속 감지되는 동안 다시 발음되는 조건을 조절할 수 있습니다. 감지와 **Note Hold**의 유지 시간이 모두 끝난 뒤 같은 음을 다시 감지하면 새로운 음으로 발음합니다.

### 소리 조정 가이드

Electron 버전에서는 **Select SFZ Folder…**를 눌러 SFZ 파일, 샘플, 포함 파일이 들어 있는 악기 폴더를 선택합니다. 여러 SFZ 파일이 발견되면 악기를 고르고 **Select**를 누르세요. 이 폴더 안의 파일은 악기를 불러올 때마다 직접 읽습니다. **Remove**는 목록에서 등록만 해제하며 원본 파일은 삭제하지 않습니다.

웹 버전에서는 **Import Folder…**를 눌러 SFZ 파일과 샘플이 들어 있는 폴더를 선택합니다. SFZ가 여러 개라면 하나를 고른 후 **Import**를 누릅니다. **SFZ**에서 저장된 악기를 선택하고 **Remove**로 선택한 뱅크를 기기에서 삭제합니다.

먼저 **Dry**를 0%, **Wet**을 100%로 설정해 악기만 듣고, **Dry**를 높여 원음을 더합니다. **Octave**를 -1로 설정하면 더 낮은 음을, +1로 설정하면 더 높은 음을 겹칠 수 있습니다. **Threshold**를 높이면 확실하게 감지한 음 위주로 연주합니다. **Lowest Note**와 **Highest Note**로 원하는 음역을 제한하세요. 악기가 항상 너무 약하거나 강하게 연주한다면 **Velocity 1 Level**과 **Velocity 127 Level**을 조절하고 **Output Gain**으로 최종 음량을 맞춥니다.

낮은 선율을 따라가려면 **Lowest**만, 높은 선율을 따라가려면 **Highest**만 켜세요.

지속음이 의도치 않게 반복해서 울리면 **Retrigger Drop**을 기본값인 40 dB보다 높이세요. 96 dB로 설정하면 음량 변화로 인한 재발음을 크게 줄일 수 있습니다. 같은 음을 반복해서 연주하는 소리를 따라가려면 값을 낮추세요.

음을 더 길게 유지하고 감지가 잠깐 끊기는 구간을 이어 주려면 **Note Hold**를 높이세요. 100 ms로 설정하면 100 ms 더 유지한 뒤 노트 오프를 보냅니다.

**Note Spectrogram**에 음이 표시되어도 **Threshold**와 **Lowest Note / Highest Note**의 조건을 충족해야 발음됩니다. 아주 낮거나 높은 음이 나지 않으면 음역 설정을 확인하고 **Threshold**를 낮춰 보세요. **Octave**를 적용한 뒤의 음을 SFZ 악기가 지원하는지도 확인하세요.

### 매개변수

- **SFZ**: 이름으로 악기를 선택합니다. 직접 음원을 선택하거나 가져온 뒤 첫 불러오기에서 발생한 문제만 대화 상자로 안내하며, 자동으로 다시 불러올 때는 표시하지 않습니다.
- **Threshold**: 감지에 필요한 최소 신뢰도(0.01~1, 기본값 0.75)입니다. 높이면 불필요한 음이 줄지만 작거나 불분명한 음을 놓칠 수 있습니다.
- **Retrigger Drop (dB)**: 재발음에 필요한 입력 음의 최고 레벨 대비 음량 감소량입니다(1~96 dB, 기본값 40 dB). 이만큼 떨어진 뒤 6 dB 이상 올라가면 다시 발음합니다. 값을 높이면 지속음의 재발음을 줄이고, 낮추면 같은 음을 반복해서 연주하는 소리를 따라가기 쉬워집니다.
- **Note Hold (ms)**: 감지가 끝난 뒤 노트 오프를 보내기까지 음을 추가로 유지하는 시간입니다(0~100 ms, 기본값 50 ms). 유지 시간 안에 같은 음이 돌아오면 다시 시작하지 않고 이어집니다. 악기의 음량 변화와 샘플의 끝은 그대로 적용됩니다.
- **Velocity 1 Level / Velocity 127 Level (dB)**: 가장 약한 연주와 가장 강한 연주 벨로시티에 대응하는 입력 음의 레벨입니다(기본값 -60 dB / -10 dB). 값을 낮추면 같은 입력에서 더 높은 벨로시티가 나옵니다. 두 값의 간격에 따라 입력 레벨이 벨로시티 범위에 분포하는 정도가 달라집니다.
- **Lowest Note / Highest Note**: 입력에서 감지할 최저·최고 음입니다(A0~C8, MIDI 21~108; 기본값 E1과 G6). 음 이름으로 표시되며 범위 밖의 음은 무시합니다.
- **Highest / Middle / Lowest**: Octave를 적용하기 전에 낮은 선율, 중간 음, 높은 선율을 선택합니다(기본값은 모두 켜짐). Middle은 현재 감지된 최저음과 최고음 사이의 음만 선택하며 양 끝 음은 제외합니다. 낮은 선율과 높은 선율은 시간에 따른 음높이의 흐름을 따라가 급격한 전환을 줄입니다. 감지된 음이 하나라면 양쪽에 모두 속합니다. 선택에서 제외된 음은 자연스럽게 줄어들고, 모두 끄면 새로운 음을 내지 않습니다.
- **Octave**: 새로 연주하는 SFZ 음을 한 옥타브씩 -2~+2옥타브 이동합니다(기본값 0). 음수는 더 낮게, 양수는 더 높게 연주합니다. 입력 감지 범위와 이미 울리고 있는 음은 바뀌지 않습니다.
- **Max Voices**: 동시에 재생하는 샘플 보이스 수를 제한합니다. 높이면 겹친 음과 릴리스 소리를 더 많이 유지하지만 처리 부하가 늘어납니다. 낮추면 오래된 보이스가 더 빨리 교체됩니다.
- **Dry (%)**: 원음의 음량입니다(0–100%, 기본값 20%). 0%는 음소거, 100%는 원래 음량입니다.
- **Wet (%)**: SFZ 악기의 음량입니다(0–100%, 기본값 100%). 0%는 음소거, 100%는 악기 본래의 음량입니다. Dry와 Wet은 독립적으로 조절합니다.
- **Timing (ms)**: 원음과 SFZ 악기의 발음 시점을 조절합니다(-100~+100 ms, 기본값 0). 음수는 원음을 더 지연시키고, 양수는 악기를 지연시킵니다. 들으면서 조절하여 음의 시작 시점을 가깝게 맞추세요.
- **Output Gain (dB)**: 혼합한 출력의 최종 음량을 조절합니다.

**Timing**이 0 ms일 때, 원음은 음표 감지의 계산과 보정 시간을 맞추기 위해 약 **80 ms** 지연됩니다. 분석 주기와 악기의 어택 때문에 발음 시점에 작은 차이가 남을 수 있습니다. 앞쪽의 활성 **Note Spectrogram**과 음역, 입력 버스, 채널 선택이 같고 사이에서 소리가 바뀌지 않으면 분석을 공유하여 처리 부하를 줄일 수 있습니다.

일반적인 SFZ 선택 조건, 피치, 음량, 팬, 루프, 진폭 엔벌로프를 지원합니다. 릴리스 감쇠는 최소 **0.2초**이며, SFZ에 지정된 더 긴 시간은 유지합니다. 샘플이 먼저 끝나면 소리도 그 지점에서 멈춥니다. 컨트롤러 범위 조건은 초기값으로 판단하며 SFZ의 `set_ccN` 설정이 우선합니다. 예를 들어 초기 상태에서 페달을 뗀 피아노는 해당 샘플을 사용하고 페달을 밟은 상태의 레이어를 더하지 않습니다. 악기에 기본 키스위치 주법이 지정되어 있으면 그 주법을 사용합니다. 노트 해제, 컨트롤러 이벤트, 연주 중 키스위치 전환 등 지원하지 않는 연주 조건이 필요한 레이어는 제외합니다. 잘못된 영역은 건너뛰고 유효한 영역은 계속 불러옵니다. 그 밖의 지원하지 않는 음색 설정은 무시합니다.

기본 용량 제한은 **256 MiB**입니다. **설정 → 일반**의 **SFZ 용량 제한**에서 최대 **1024 MiB(1 GiB)**까지 높일 수 있습니다. 제한은 악기 파일과 재생용으로 풀어 놓은 샘플 모두에 다음 선택, 가져오기 또는 불러오기부터 적용됩니다. 제한을 높이면 메모리를 더 사용합니다. 악기 전체가 제한을 넘으면 연주 가능한 음역을 커버하는 대표 샘플로 불러오기를 시도합니다. 벨로시티에 따른 음량 변화는 유지하지만 벨로시티 레이어와 라운드로빈의 음색 변화는 단순화합니다. 이 샘플도 들어가지 않으면 더 작은 악기를 선택하거나 제한을 높이세요. 웹 버전에서 생략된 샘플을 되살리려면 제한을 높인 뒤 원본 폴더를 다시 가져오세요. 샘플을 사용하는 다른 이펙트도 처리 메모리를 공유합니다.

프리셋과 공유 파이프라인에는 악기 참조만 포함되고 오디오 파일은 포함되지 않습니다. 다른 기기에서는 Electron 버전에서 해당 기기의 악기 폴더를 선택하거나 웹 버전에서 폴더를 가져오세요. SFZ 오디오 파일은 사용자 데이터 백업에도 포함되지 않으므로 원본 SFZ 폴더를 보관하세요.
