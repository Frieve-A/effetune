# 기타 오디오 도구

주요 이펙트 카테고리를 보완하는 특수 오디오 도구와 제너레이터 모음입니다. 이 플러그인들은 음악을 듣기 전이나 듣는 중에 스피커, 헤드폰, 채널 밸런스, 재생 동작을 확인하는 데 유용합니다.

## 플러그인 목록

- [Oscillator](#oscillator) - 스피커/헤드폰 점검용 테스트 톤/노이즈 생성기
- [SFZ Note Player](#sfz-note-player) - 감지한 음을 가져온 SFZ 악기로 재생

## Oscillator

리스닝 환경을 점검하기 위한 테스트 톤/노이즈 생성기입니다. 낮은 음량으로 사용해 스피커/헤드폰 출력, 좌우 배치, 레벨 밸런스, 덜걱거림이나 윙윙거리는 잡음, 간단한 주파수 응답 문제를 확인하세요.

생성된 톤이나 노이즈는 입력을 대체하지 않고 현재 오디오 경로에 섞입니다. 특히 음악이 이미 재생 중일 때는 켜기 전에 Volume을 낮추세요.

### 기능
- 다양한 파형 타입:
  - 간단한 톤 확인에 쓰는 순수 사인파
  - 배음이 풍부한 사각파
  - 배음이 더 부드러운 삼각파
  - 밝은 음색의 톱니파
  - 임펄스 응답과 타이밍 확인에 쓰는 주기적인 1샘플 임펄스
  - 스피커/헤드폰의 광대역 점검에 쓰는 화이트 노이즈
  - 더 매끄럽고 자연스러운 밸런스의 핑크 노이즈
- 간헐적인 톤이나 노이즈 버스트를 내는 펄스 동작 모드

### 파라미터
- **Frequency (Hz)** - 생성할 톤의 높이를 조절합니다(20 Hz ~ 96 kHz)
  - 낮은 주파수: 깊은 저음 톤
  - 중간 주파수: 음악에서 주로 쓰는 음역
  - 높은 주파수: 안전한 청취 음량에서만 신중하게 사용하세요
  - 사인파, 사각파, 삼각파, 톱니파에만 적용되며 Impulse, 화이트 노이즈, 핑크 노이즈에서는 비활성화됩니다
  - 출력할 수 있는 고주파는 현재 오디오 샘플 레이트에 따라 달라지며, 사용 가능한 나이퀴스트 주파수를 넘는 톤은 음소거됩니다
- **Volume (dB)** - 출력 레벨을 조절합니다(-96 dB ~ 0 dB)
  - 낮은 값에서 시작해 천천히 올리세요
  - 값이 높으면 소리가 크거나 귀가 피로해질 수 있습니다
- **Panning (L/R)** - 스테레오 배치를 조절합니다
  - 중앙: 양쪽 채널에 같은 양으로 출력
  - 왼쪽/오른쪽: 채널 라우팅과 밸런스 확인
- **Waveform Type** - 신호 종류를 선택합니다
  - Sine: 깨끗한 기준 톤
  - Square: 홀수 배음이 풍부
  - Triangle: 더 부드러운 배음 구성
  - Sawtooth: 모든 배음을 포함
  - Impulse: 현재 오디오 샘플 레이트를 기준으로 Interval마다 최대 진폭의 샘플 하나를 출력하며, Frequency는 영향을 주지 않음
  - White Noise: Hz당 에너지가 같음. Frequency는 영향을 주지 않음
  - Pink Noise: 옥타브당 에너지가 같음. Frequency는 영향을 주지 않음
- **Mode** - 신호 생성 패턴을 설정합니다
  - Continuous: 끊김 없는 표준 신호 생성
  - Pulsed: 타이밍을 조절할 수 있는 간헐 신호
  - Impulse는 항상 Pulsed를 사용하며 Continuous는 비활성화됨
- **Interval (ms)** - 펄스 모드에서 펄스 버스트 사이의 시간입니다(100 ~ 2000 ms, 10 ms 단위)
  - 짧은 간격: 빠르게 이어지는 펄스
  - 긴 간격: 넓게 띄운 펄스
  - Impulse를 포함해 Mode가 Pulsed일 때 활성화
- **Width (ms)** - 펄스 모드에서 펄스의 램프 시간입니다(2 ~ 100 ms, Interval의 절반까지, 1 ms 단위)
  - 각 펄스의 페이드 인/페이드 아웃 시간을 조절
  - 생성되는 펄스는 Width의 약 두 배 길이이며, 일정한 음량으로 유지되는 구간은 없음
  - 짧은 폭: 날카로운 펄스 경계
  - 긴 폭: 더 부드러운 펄스 변화
  - Mode가 Pulsed일 때만 활성화되며, Impulse는 항상 정확히 1샘플이므로 비활성화

### 사용 예

1. 스피커나 헤드폰 점검
   - 기본적인 주파수 재생 확인
     * 낮은 주파수부터 높은 주파수까지 사인파를 스윕
     * 소리가 들리지 않거나 왜곡되는 지점을 기록
   - 덜걱거림, 윙윙거림, 거슬리는 공진 듣기
     * 처음에는 낮은 Volume 사용
     * 한 번에 한 주파수 대역씩 확인
   - 왼쪽과 오른쪽 출력 비교
     * 왼쪽 끝과 오른쪽 끝으로 패닝
     * 각 쪽이 예상한 스피커나 헤드폰 드라이버에서 재생되는지 확인

2. 채널과 레벨 밸런스
   - 스테레오 배치 확인
     * 중앙에 둔 사인파나 핑크 노이즈 사용
     * 소리가 중앙에 맺히는지 확인
   - 좌우 음량 비교
     * 같은 Volume으로 양쪽에 각각 패닝
     * 한쪽이 더 크게 들리면 재생 환경을 조정
   - 플러그인 체인 확인
     * Oscillator를 다른 이펙트 앞이나 뒤에 두고, 체인이 단순한 신호를 어떻게 처리하는지 듣기

3. 방이나 책상 주변 공진의 간이 점검
   - 뚜렷한 저음 부밍이나 덜걱거림 찾기
     * 안전한 음량에서 낮은 사인 톤 사용
     * 청취 위치 주변을 움직이며 강하게 울리거나 빠지는 곳을 기록
   - 진동하기 쉬운 물건 확인
     * 저역에서 중저역까지 천천히 스윕
     * 무언가 심하게 덜걱거리면 즉시 Volume을 낮춤

4. 노이즈 밸런스 점검
   - 넓은 대역의 안정된 기준으로 핑크 노이즈 사용
     * 뚜렷한 좌우 차이나 음색 치우침이 있는지 듣기
     * 편안한 음량을 유지하고, 큰 음량의 노이즈를 오래 재생하지 않기
   - 더 밝은 광대역 신호가 필요할 때만 화이트 노이즈 사용

5. 펄스 신호 점검
   - 짧은 버스트를 알아듣기 쉽도록 펄스 모드 사용
     * Interval이 길수록 각 버스트를 따로 듣기 쉬움
     * Width가 짧을수록 시작과 끝이 날카로워짐
     * 여러 음량에서 동작을 비교

6. 임펄스 응답과 타이밍 점검
   - Impulse를 선택해 설정한 Interval마다 1샘플 과도 신호를 생성
     * 반사음이나 이펙트 잔향을 분리하려면 긴 Interval 사용
     * 시스템이나 플러그인 체인의 임펄스 응답을 살펴보려면 출력을 녹음
     * 임펄스는 피크가 날카롭고 주파수 성분이 넓으므로 낮은 Volume에서 시작

기억하세요: Oscillator는 테스트 신호 생성기입니다. 낮은 Volume에서 시작해 서서히 올리고, 장비 손상이나 청각 피로를 일으킬 수 있는 큰 소리나 고주파 톤은 피하세요.

## SFZ Note Player

SFZ Note Player는 입력 오디오에서 음을 감지해 가져온 SFZ 악기로 연주합니다. 피아노 SFZ로 곡의 음을 따라가거나, 원래 녹음에 다른 악기를 겹칠 수 있습니다. 여러 음을 동시에 추정하는 기능은 정확한 채보가 아니라 듣고 겹쳐 즐기기 위한 도구이며, 소리가 빽빽한 믹스에서는 음을 놓치거나 불필요한 음이 울릴 수 있습니다.

### 음질 향상 가이드

- **악기 가져오기와 불러오기**: **SFZ Library…**를 누르고 **폴더 가져오기…**로 `.sfz` 정의와 샘플 파일이 들어 있는 폴더(또는 `.bank.xml`, `Programs`, `Samples`가 갖춰진 ARIA 뱅크 폴더 전체)를 추가한 뒤, 악기 옆의 **불러오기**를 누릅니다. 데스크톱 앱에서는 원본 파일을 그 자리에서 읽습니다. 웹 앱에서는 악기를 기기에 저장하므로, **파일 가져오기…**를 사용할 때는 악기에 필요한 샘플과 기타 파일을 모두 포함해야 합니다. 사용 중인 악기는 삭제할 수 없습니다.
- **미리 듣고 섞기**: 먼저 **Dry: 0%**, **Wet: 100%**로 SFZ 악기만 들은 뒤 **Dry**를 올려 원곡을 다시 섞습니다. SFZ 음의 어택이 원래 녹음과 맞도록 **Timing**(−100 ~ +100 ms)을 조절합니다(0 ms에서는 원음이 음 감지에 맞춰 Classic에서 약 90 ms, Event에서 약 230 ms 지연됩니다).
- **음역과 성부 좁히기**: 확신도가 높은 음만 연주하려면 **Threshold**를 올리고 **Lowest Note**와 **Highest Note**로 범위를 좁힙니다. 하나의 선율만 따라가려면 **Lowest**(베이스 라인)나 **Highest**(최상단 선율)만 켭니다. **Threshold**와 음역 설정이 그대로 적용되므로, Note Spectrogram에 색이 있는 선이 보여도 반드시 연주되는 것은 아닙니다.
- **음색과 옥타브 다듬기**: **Octave**(−2 ~ +2)로 선율을 한 옥타브 아래나 위에 겹칠 수 있습니다. **Sample Shift**(−6 ~ +6반음)를 사용하면 이웃 음에 할당된 샘플을 감지한 음높이로 되돌려 연주해, 음색을 더 어둡거나 밝게 바꿀 수 있습니다.

### 파라미터

- **SFZ** - **SFZ Library…**를 열어 악기를 가져오고, 검색하고, 정렬하고, 불러오거나 삭제합니다(**Clear**는 라이브러리에서 삭제하지 않고 현재 악기의 불러오기만 해제합니다).
- **Detection**:
  - **Classic (Low Latency)**(기본값): 지연이 짧은 감지 방식입니다(원음 정렬 지연 약 90 ms). **Threshold**와 **Retrigger Drop**을 사용합니다.
  - **Event (+140 ms)**: Note Spectrogram과 같은 온셋/이벤트 감지기를 사용합니다(원음 정렬 지연 약 230 ms, CPU 사용량 증가. **Threshold**와 **Retrigger Drop**은 비활성화). 체인 앞쪽에서 활성화된 Note Spectrogram이 같은 입력을 같은 음역으로 분석하고 그 사이에서 오디오가 바뀌지 않으면, Note Spectrogram의 **Onsets**, **Instrument** 색상, **Highlight** 중 하나가 켜져 있을 때 분석을 공유해 부하를 줄입니다. 그렇지 않으면 SFZ Note Player가 자체적으로 분석합니다.
- **Color** - **Normal**(테마 그래프 색) 또는 **Note Colors**(Note Spectrogram과 같은 음이름별 색).
- **Threshold**(0.01 ~ 1, 기본값 0.75) - Classic 모드에서 쓰는 감지 확신도의 임계값입니다.
- **Retrigger Drop (dB)**(1 ~ 96 dB, 기본값 40 dB) - Classic 모드에서 B5보다 높은 지속음을 다시 발음하기 전에 필요한 레벨 감소량입니다. 레벨이 내려간 뒤 다시 6 dB 이상 올라가야 합니다. 값을 높이면 지속음 중의 불필요한 재발음이 줄고, 낮추면 같은 음의 연타를 더 쉽게 따라갑니다. B5 이하에서는 감지한 어택이 바로 새 음을 냅니다.
- **Note Hold (ms)**(0 ~ 100 ms, 기본값 50 ms) - 음을 끝내기 전에 감지가 잠깐 끊기는 구간을 이어 줍니다.
- **Velocity 1 Level / Velocity 127 Level (dB)**(-96 ~ 0 dB / -60 ~ +24 dB, 기본값 -60 dB / -10 dB) - MIDI 벨로시티 1~127에 대응하는 입력 레벨 범위입니다. 값을 낮추면 같은 입력에서도 더 강한 벨로시티가 나옵니다.
- **Lowest Note / Highest Note**(A0 ~ C8, 기본값 E1 ~ G6) - 음높이를 감지하는 범위입니다.
- **Highest / Middle / Lowest** - 동시에 감지한 음 중 어느 것을 연주할지 고릅니다(최상단 선율, 내성, 베이스 라인. 기본값은 모두 켜짐).
- **Octave**(-2 ~ +2, 기본값 0) - 새로 발음하는 SFZ 음을 옥타브 단위로 이조합니다.
- **Sample Shift**(-6 ~ +6반음, 기본값 0) - 선택되는 샘플 영역을 옮기고, 그만큼 반대 방향으로 음높이를 보정해 목표 음높이를 유지합니다. 양수에서는 더 높은 음의 샘플을 느리게 재생하고(+1에서는 감지한 C4에 C#4 샘플을 C4 높이로 사용), 음수에서는 더 낮은 음의 샘플을 빠르게 재생합니다.
- **Max Voices**(1 ~ 128, 기본값 32) - 동시에 재생하는 샘플 보이스의 최대 수입니다(릴리스 여운 포함). 값을 높이면 겹친 음을 더 많이 유지하지만 처리량이 늘어납니다.
- **Dry (%)** / **Wet (%)**(0 ~ 100%, 기본값 20% / 100%) - 지연을 맞춘 원음과 SFZ 악기의 레벨을 각각 설정합니다.
- **Timing (ms)**(-100 ~ +100 ms, 기본값 0 ms) - 원음과 SFZ 악기 사이의 타이밍을 미세 조정합니다. 음수 값은 원음을 더 늦추고, 양수 값은 악기를 늦춥니다.
- **Output Gain (dB)**(-60 ~ +12 dB, 기본값 0 dB) - 최종 출력 레벨을 조절합니다.

### 재생 표시와 참고 사항

- **조작 가능한 건반과 벨로시티 막대**: 건반은 **Lowest Note**~**Highest Note** 범위이며, 연주 중인 음을 릴리스 잔향까지 포함해 점등합니다. 점등되는 건반은 **Octave**를 따르며, **Sample Shift**는 음색만 바꾸고 점등 위치는 움직이지 않습니다. 각 막대는 발음 벨로시티(1~127) 높이에서 시작해 음이 끝난 뒤에도 시간에 따라 내려갑니다. **Color**를 바꾸면 색만 바뀌고 내려가던 막대는 처음부터 다시 시작하지 않습니다. **Voices / Max Voices**는 릴리스 중인 것을 포함한 샘플 발음 수입니다.
- **미리 듣기**: 건반이나 벨로시티 영역을 클릭하거나 드래그하면 불러온 SFZ 악기를 바로 연주할 수 있습니다. 건반은 벨로시티 100으로, 벨로시티 영역은 누른 위치의 높이에 해당하는 벨로시티로 연주합니다. 미리 듣기는 표시된 음높이로 연주하므로 **Octave**는 무시하지만 **Sample Shift**는 적용됩니다.
- **용량 제한**: 악기의 용량 제한은 기본 **256 MiB**입니다(**설정 > 구성... > 일반**의 **SFZ 용량 제한**에서 최대 **1024 MiB**까지 변경 가능). 제한을 넘는 악기는 건반 전체에 걸친 대표 샘플을 자동으로 불러옵니다. 웹 앱에서는 제한을 높인 뒤 폴더를 다시 가져오세요.
- **지원하는 SFZ 기능**: 노트 해제, 컨트롤러 이벤트, 동적 키스위치 전환이 필요한 레이어는 제외하며, 그 밖의 지원하지 않는 설정은 무시합니다.
- **공유와 백업**: 프리셋, 공유 링크, 사용자 데이터 백업에는 오디오 샘플이 아니라 악기 참조가 저장됩니다. 여러 기기에서 사용할 수 있도록 원본 SFZ 폴더를 보관하세요.
