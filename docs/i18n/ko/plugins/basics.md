# 기본 오디오 플러그인

음악 재생의 기본 요소를 조정하기 위한 필수 도구 모음입니다. 이 플러그인들은 재생 볼륨, 밸런스 및 기타 기본 설정을 제어하는 데 도움을 줍니다.

## 스펙트럼 오버레이

지원되는 그래프의 스펙트럼 아이콘을 누를 때마다 After, Before + After, Off 순서로 전환됩니다. After에서는 처리 후 스펙트럼만 파란 선으로 표시합니다. Before + After에서는 처리 전 스펙트럼에서 처리 후 스펙트럼까지의 변화 영역을 채웁니다. 처리 후 레벨이 높아진 주파수는 따뜻한 색, 낮아진 주파수는 파란색으로 표시하며, 그 위에 After 스펙트럼을 회색 선으로 그립니다. 입력과 출력 스펙트럼은 재생 중 같은 시점에 맞춰져 있어 동일한 오디오를 비교합니다. **일반** 모드에서는 1/12옥타브 스무딩을 적용하고, **고품질** 모드에서는 저역을 더 세밀하게 분석합니다. 들으면서 비교하면 각 조절이 저음, 중음, 고음을 어떻게 바꾸는지 확인할 수 있습니다. 스펙트럼 레벨은 그래프 오른쪽의 dBFS 눈금으로 읽습니다. 이 눈금은 그래프의 게인 눈금과 별개이며, 0 dBFS는 디지털 풀스케일 기준이고 더 낮은 값은 더 작은 레벨을 뜻합니다. 설정에서 오버레이 스펙트럼 품질을 **일반** 또는 **고품질**로, 표시를 **순간값** 또는 **피크 홀드**로 선택할 수 있습니다. 피크 홀드는 최근 최고 레벨을 잠시 표시한 뒤 서서히 낮춥니다. After에서는 처리 후 스펙트럼만 수집하며, Off에서는 수집과 그리기가 모두 중지됩니다.

## Bass Management

Bass Management는 선택한 메인 채널의 저음과 전용 LFE 입력을 선택한 서브우퍼 출력으로 보냅니다. **Managed** 채널은 고음을 같은 메인 출력에 남기고 저음만 서브우퍼로 보냅니다. 메인 스피커와 하나 이상의 서브우퍼를 사용하는 멀티채널 버스용이며 WASM DSP 엔진이 필요합니다.

**Sub Outputs**를 하나도 선택하지 않으면 Bass Management는 저음을 분리하거나 서브우퍼로 보내지 않으며 입력 채널은 crossover 없이 통과합니다. 새 인스턴스에서는 실제 버스 채널이 **Managed**이고 **Sub Outputs**는 선택되지 않습니다.

이펙트 버스 라우팅에서 **All**을 선택하고 모든 메인 및 서브우퍼에 맞는 출력 채널 수를 설정하세요. 표에는 입력 역할과 서브우퍼 출력이 표시됩니다. 서브우퍼 출력은 **Full Range** 또는 **Managed** 메인이 될 수 없습니다. **LFE** 입력은 서브우퍼 출력과 같은 채널 번호를 쓸 수 있으며, 출력을 만들기 전에 수집되므로 한 번만 전송됩니다.

### 사운드 조정 가이드

- 스테레오와 두 서브우퍼에는 4채널을 사용합니다. 1/2를 **Managed**로 설정하고 3/4를 **Sub Outputs**로 선택합니다. 이 채널들의 역할은 자동으로 **LFE**가 됩니다. 각 메인-서브우퍼 경로는 Matrix에서 유지하거나 **OFF**로 바꿉니다.
- 서라운드 소스에서는 실제 메인만 **Managed**, 소스 LFE 채널은 **LFE**로 설정하고 서브우퍼 출력을 명시적으로 선택합니다.
- 관리 채널마다 80 Hz, 24 dB/oct에서 시작합니다. 메인 스피커의 저음 재생이 제한되면 주파수를 높이고, 겹침을 줄여야 하면 더 큰 Slope를 사용합니다. 레벨을 올리기 전에 스피커의 사용 가능한 대역을 확인하세요.
- 여러 서브우퍼로 보내는 입력은 전기적으로 균등 분배되지만 합쳐진 신호의 피크를 막지는 않습니다. 필요하면 **Headroom**을 낮추고 뒤의 미터를 확인하며, 피크 제어에는 체인 마지막에 Brickwall Limiter를 둡니다. **LFE Gain**은 소스가 의도한 LFE 보정을 아직 적용하지 않은 경우에만 사용합니다.
- Bass Management 뒤에 서브우퍼별 HP/EQ/극성 조정을 두고, 이후 MultiChannel Panel에서 trim, mute/solo, 최대 30 ms delay를 조정합니다.

### 파라미터

- **Phase**: **IIR**은 지연이 작고 크로스오버 부근의 위상을 바꿉니다. **Linear**는 분리를 시간적으로 맞추지만 표시되는 지연과 pre-ringing이 생길 수 있습니다.
- **Taps**: Linear용 8192, 16384, 32768을 고릅니다. Taps가 많으면 저음과 급경사 정확도가 높아지지만 준비 시간과 지연도 증가합니다. 초기값은 16384입니다.
- **Headroom**은 모든 출력을 같은 만큼 감쇠합니다. **Bass Gain**은 **Managed**에서 분리된 저음을, **LFE Gain**은 **LFE** 입력을 서브우퍼로 믹스하기 전에 조절합니다.
- **Channel Role**: **Full Range**는 소스를 메인 출력에 그대로 둡니다. **Managed**는 고음을 메인에 남기고 저음을 보냅니다. **LFE**는 소스를 서브우퍼로만 보냅니다. **Unused**는 보통 서브우퍼 출력용 입력을 예약합니다.
- **Crossover Frequency**는 **Managed**별로 20~300 Hz를 설정합니다. 높을수록 더 많은 저음이 서브우퍼로 갑니다. **Slope**는 24/48/96 dB/oct이고 높을수록 겹침이 줄어듭니다.
- **Sub Outputs**는 **Managed** 또는 **LFE**에 필요한 출력을 고릅니다. 채널을 선택하면 그 **Channel Role**은 **LFE**가 됩니다. 새로 선택한 출력에는 현재 버스의 모든 입력에서 일반 극성의 **ON** 경로가 만들어집니다. 개별 경로는 Matrix에서 **OFF**로 바꾸세요. **Sub Outputs**를 하나도 선택하지 않으면 저음 분리와 서브우퍼 라우팅이 멈추고 입력 채널은 crossover 없이 통과합니다. **LFE Low-pass**, **LFE Frequency**, **LFE Slope**는 20~300 Hz와 24/48/96 dB/oct로 LFE를 선택적으로 제한하며, 이미 분리된 메인 저음에는 다시 적용되지 않습니다.
- **ON** 및 **Ø**: 채널 표의 각 셀에서 **ON**은 해당 **Managed** 또는 **LFE** 입력을 선택한 서브우퍼 출력으로 보냅니다. **Ø**는 그 입력에서 서브우퍼로 가는 경로만 극성을 반전하여 측정 또는 청취 결과에 맞추는 데 사용할 수 있습니다. **Ø**는 **ON**을 선택한 동안에만 사용할 수 있고, **ON**을 끄면 **Ø**도 해제됩니다. 입력의 메인 출력은 바뀌지 않습니다.

### 표시 및 상태

- 라우팅 요약에서 각 서브우퍼로 가는 입력을 레벨을 올리기 전에 확인하세요. **Managed**를 선택하면 이상적인 곡선이 아니라 활성 HP/LP 응답이 보입니다.
- 상태에는 모드, Linear 준비, samples/ms 단위의 실제 지연이 표시됩니다.
- 그래프에 마우스를 올리거나 터치한 채로 드래그하면 그 지점의 값을 읽을 수 있습니다.

### 필터 준비
Linear 변경 중에는 잠시 소리가 작아지거나 멈출 수 있습니다. 준비에 실패하면 **Taps**를 줄여 다시 시도하세요. 이전 구성을 쓸 수 없으면 일반 메인은 동일 지연 원음, 예약 서브 출력은 무음, LFE는 준비 완료까지 재생되지 않습니다.

### Bypass 및 보정

- 호스트 bypass는 원래 채널 할당과 오디오로 돌아가므로 라우팅/보호/지연 정렬은 유지되지 않습니다. 배선을 유지한 비교나 mute에는 뒤의 MultiChannel Panel을 사용하세요. 이후 IIR HP/EQ 또는 상대 delay는 전체 Linear 시스템의 위상을 바꾸므로 보정 체인은 하나의 preset으로 저장하세요.

## Channel Divider

스테레오 신호를 별도의 주파수 대역으로 나누고 각 대역을 다른 스테레오 출력 쌍으로 라우팅하는 특수 도구입니다. 멀티 앰프, 멀티 스피커 또는 커스텀 크로스오버 재생 설정에 유용합니다.

이 효과를 사용하려면 데스크톱 앱에서 오디오 설정의 출력 채널 수를 4~16 사이의 짝수로 설정하고, 이펙트 버스 라우팅의 채널을 "All"로 지정해야 합니다.

### 사용할 때

* 멀티 채널 오디오 출력(4~16 사이의 짝수 채널) 사용 시
* 커스텀 주파수 기반 채널 라우팅 생성 시
* 멀티 앰프 또는 멀티 스피커 구성 시

### 매개변수

* **Band Count** - 생성할 주파수 대역 수 (2~4 밴드)

  * 2 밴드: 저역/고역 분할
  * 3 밴드: 저역/중역/고역 분할
  * 4 밴드: 저역/저중역/중고역/고역 분할
  * Band Count는 최대 4개 대역으로 제한되며, 출력 채널 수가 많아져도 대역이 추가되지 않음

* **Crossover Frequencies** - 대역 간 오디오 분할 지점 정의

  * F1: 첫 번째 크로스오버 포인트
  * F2: 두 번째 크로스오버 포인트 (3개 대역 이상)
  * F3: 세 번째 크로스오버 포인트 (4개 대역)
  * 각 크로스오버는 10 Hz에서 40000 Hz까지 설정 가능
  * 플러그인은 F1, F2, F3가 최소 1 Hz 간격으로 오름차순을 유지하도록 조정

* **Slopes** - 대역 분리의 기울기 제어

  * 옵션: 옥타브당 -12dB~ -96dB
  * 기울기가 가파를수록 분리가 더 깔끔함
  * 기울기가 낮을수록 자연스러운 전환 제공

### 기술 참고

* 첫 두 입력 채널만 처리
* 출력 채널 수는 4~16 사이의 짝수여야 함
* 각 대역은 원래의 스테레오 쌍을 유지함: 2밴드는 Low를 채널 1-2, High를 채널 3-4로 출력하고, 3밴드는 채널 1-2, 3-4, 5-6을, 4밴드는 채널 1-2, 3-4, 5-6, 7-8을 사용
* 고품질 Linkwitz-Riley 크로스오버 필터 사용

### 시각적 표시
* 그래프는 각 출력 대역의 주파수 응답을 보여줍니다.
* 그래프에 마우스를 올리거나 터치한 채로 드래그하면 그 지점의 값을 읽을 수 있습니다.

## DC Offset

파형이 0 라인에서 벗어난 신호를 보정하는 유틸리티입니다. 대부분의 청취 상황에서는 0.0으로 두면 되지만, 특이한 파일이나 처리 체인에 DC 오프셋이 포함된 경우 도움이 될 수 있습니다.

### 사용할 때

* 오디오에 일정한 DC 바이어스가 있거나 다른 처리 후 클릭/헤드룸 문제가 생길 때
* 진단 도구나 미터에서 파형이 0에서 벗어나 보일 때
* 일반 청취에서는 0.0으로 유지

### 매개변수

* **Offset** - 모든 샘플에 일정한 값을 더함 (-1.0 ~ +1.0)

  * 0.0: 오프셋 없음
  * 양수 값: 신호를 위로 이동
  * 음수 값: 신호를 아래로 이동
  * 보정이 필요할 때도 아주 작은 값부터 사용

## FIR Crossover

FIR Crossover는 스테레오 입력을 2개, 3개 또는 4개 대역으로 나누고 각 대역을 별도의 출력 쌍으로 보냅니다. 4~16 사이의 짝수 출력 채널을 갖춘 데스크톱 시스템용이며 WASM DSP에서만 동작합니다. Band Count는 최대 4개 대역으로 제한되므로 이펙트는 최대 채널 1-8을 사용합니다.

이펙트에 2채널이 입력되면 오디오를 변경하지 않고 그대로 통과시킵니다.

FIR 설계는 일반 필터의 공진 없이 매우 가파른 기울기를 사용할 수 있습니다. Minimum Phase는 대역의 재결합을 유지하는 인과적 크로스오버 구성을 사용하고, Linear Phase는 일정한 지연을 대가로 대칭 위상 응답을 제공합니다.

### 사용 가이드

- 기본값에서 시작해 스피커의 재생 대역에 맞게 Crossover Frequencies를 조정합니다.
- 출력은 가장 낮은 대역부터 높은 대역 순서이며, 각 대역은 스테레오 출력 한 쌍을 사용합니다.
- 일반적인 설정에는 48~96 dB/oct를 사용해 보세요. 더 가파른 기울기는 보통 더 많은 Taps가 필요합니다.
- 지연을 줄이려면 Minimum Phase, 위상 정렬이 중요하면 Linear Phase를 선택합니다.
- 멀티채널 라우팅을 시험할 때는 스피커 보호를 위해 낮은 음량에서 시작하세요.

### 파라미터

- **Phase**: **Minimum Phase** 또는 **Linear Phase**를 선택합니다.
- **Taps**: FIR 필터 길이를 정합니다. 값이 클수록 저역 해상도와 처리 부하가 증가합니다.
- **Latency**: 표시되는 지연을 0, 128, 256, 512 또는 1024 samples로 설정합니다.
- **Band Count**: 2개, 3개 또는 4개 대역을 선택하며 각각 4, 6 또는 8개의 출력 채널이 필요합니다.
- **Crossover Frequencies**: 대역 사이의 경계를 낮은 순서로 설정합니다.
- **Slope**: 각 크로스오버에서 24~384 dB/oct를 선택합니다.

### 표시 읽기

- 그래프는 주파수에 따른 각 대역의 목표 응답을 보여 줍니다.
- 각 색은 해당 대역의 출력 쌍을 나타냅니다.
- 상태 표시줄에는 지연과 필터 해상도가 나오며, 출력 채널 수가 맞지 않으면 경고가 표시됩니다.
- 그래프에 마우스를 올리거나 터치한 채로 드래그하면 그 지점의 값을 읽을 수 있습니다.

## Matrix

특이한 스피커나 헤드폰 채널 배치를 고치고, 채널을 바꾸거나, 채널을 합치거나, 한 채널을 사용 가능한 다른 출력으로 보내는 채널 라우팅 도구입니다.

### 사용할 때

* 채널 간 커스텀 라우팅 생성 시
* 신호를 특정 방식으로 믹스하거나 분할해야 할 때
* 좌우 또는 멀티채널 재생이 잘못된 스피커에서 나올 때
* 스테레오를 모노로 합치거나 한 채널을 사용 가능한 다른 출력으로 복제할 때

### 특징

* 최대 16개 채널을 위한 유연한 라우팅 매트릭스
* 모든 입력/출력 쌍 간 개별 연결 제어
* 각 연결에 대한 위상 반전 옵션
* 직관적인 설정을 위한 시각적 매트릭스 인터페이스

### 작동 방식

* 각 연결 지점은 입력 행에서 출력 열로의 라우팅을 나타냄
* 활성 연결은 채널 간 신호 흐름을 허용
* 위상 반전 옵션은 신호 위상(폴라리티)을 반전시킴
* 여러 입력이 하나의 출력에 연결되면 혼합됨
* 여러 입력을 같은 출력으로 보내면 레벨이 더해지므로 볼륨을 낮춰야 할 수 있음
* Matrix는 스스로 추가 출력 채널을 만들지 않으며, 현재 사용할 수 있는 채널 안에서 오디오를 라우팅함

### 실제 적용 예

* 사용 가능한 채널 안에서 커스텀 다운믹스, 채널 교체 또는 라우팅
* 좌우 채널을 모노로 결합
* 한 채널을 다른 사용 가능한 출력으로 복제
* 특이한 멀티채널 재생 배치 보정

## MultiChannel Panel

여러 오디오 채널을 개별적으로 관리하기 위한 종합적인 제어 패널입니다. 이 플러그인은 최대 16개 채널의 볼륨, 음소거, 솔로, 딜레이를 완벽하게 제어할 수 있으며, 각 채널에 시각적 레벨 미터를 제공합니다.

화면에 보이지 않는 아래쪽 채널은 패널 안에서 스크롤하여 확인할 수 있습니다.

### 사용할 때
- 멀티 채널 오디오(최대 16개 채널)로 작업할 때
- 서로 다른 채널 간 커스텀 볼륨 밸런스를 만들 때
- 특정 채널에 개별 딜레이를 적용해야 할 때
- 여러 채널의 레벨을 동시에 모니터링할 때

### 특징
- 최대 16개 오디오 채널의 개별 제어
- 피크 홀드 기능이 있는 실시간 레벨 미터로 시각적 모니터링 제공
- 그룹 파라미터 변경을 위한 채널 링크 기능

### 매개변수

#### 채널별 제어
- **Mute (M)** - 개별 채널 음소거
  - 각 채널별 켜기/끄기 전환
  - 솔로 기능과 연동하여 작동

- **Solo (S)** - 개별 채널 분리
  - 어떤 채널이라도 솔로 상태이면 솔로 채널만 재생됨
  - 여러 채널을 동시에 솔로 상태로 설정 가능

- **Volume** - 개별 채널 볼륨 조정 (-20dB ~ +10dB)
  - 슬라이더 또는 직접 값 입력을 통한 세밀한 제어
  - 링크된 채널은 동일한 볼륨 유지

- **Delay** - 개별 채널에 시간 지연 추가 (0-30ms)
  - 밀리초 단위의 정밀한 딜레이 제어
  - 채널 간 시간 정렬에 유용
  - 채널 간 위상 조정 가능

#### 채널 링크
- **Link** - 인접 채널을 동기화된 제어를 위해 연결
  - 링크된 채널 중 하나에 대한 변경이 연결된 모든 채널에 영향을 줌
  - 링크된 채널 그룹 간에 일관된 설정 유지
  - 스테레오 페어 또는 멀티 채널 그룹에 유용

### 시각적 모니터링
- 실시간 레벨 미터가 현재 신호 강도를 표시
- 피크 홀드 인디케이터가 최대 레벨을 표시
- 명확한 수치 dB 피크 레벨 표시
- 레벨 인식이 쉬운 색상 코드 미터:
  - 녹색: 안전 레벨
  - 노란색: 최대값에 근접
  - 빨간색: 최대값 근처 또는 최대값

### 실제 적용 예
- 서라운드 사운드 또는 멀티 스피커 재생 밸런스 조정
- 스피커 거리가 다를 때 스피커 타이밍 맞추기
- 설정 중 개별 스피커를 임시로 음소거하거나 솔로로 확인
- 더 쉽게 조정하기 위해 스테레오 쌍이나 스피커 그룹 연결

## Mute

버퍼를 0으로 채워 모든 오디오 출력을 즉시 음소거하는 간단한 유틸리티입니다. 오디오 신호를 즉시 음소거할 때 유용합니다.

### 사용할 때

* 페이드 없이 즉시 오디오 음소거 필요 시
* 무음 구간 또는 일시 중지 중
* 원치 않는 노이즈 출력 방지 시

## Polarity Inversion

오디오 신호의 극성을 반전하는 유틸리티입니다. 모든 채널을 함께 반전하면 보통 그 자체로 들리는 소리가 달라지지는 않지만, 스피커, 케이블 또는 채널 하나가 반대 극성으로 연결된 것처럼 보일 때 도움이 됩니다.

좌우 또는 멀티채널 극성 불일치가 의심될 때는 이펙트의 공통 라우팅 설정에서 처리할 채널을 제한하고, 영향을 받는 채널만 반전하세요.

### 사용할 때

* 한쪽 채널의 극성이 반대일 가능성 때문에 중앙 이미지가 약하거나 텅 비거나 넓게 퍼져 들릴 때
* 재생 환경에서 스피커, 케이블 또는 채널 극성을 확인하거나 보정할 때
* 한 채널의 극성 반전이 필요한 라우팅 또는 스테레오 이펙트와 함께 사용할 때

## Stereo Balance

음악이 좌우 스피커 또는 헤드폰에 어떻게 분배되는지 조정할 수 있습니다. 불균형한 스테레오를 수정하거나 원하는 사운드 배치를 만들기에 적합합니다.

### 청취 향상 가이드

* 완벽한 밸런스:

  * 자연스러운 스테레오를 위한 중앙 위치
  * 양쪽 귀에 동일한 볼륨
  * 대부분의 음악에 최적
* 조정된 밸런스:

  * 룸 어쿠스틱 보정
  * 청력 차이 보정
  * 선호하는 사운드 스테이지 생성

### 매개변수

* **Balance** - 좌우 분배 제어 (-100% ~ +100%)

  * 중앙(0%): 양쪽 동일
  * 왼쪽(-100%): 왼쪽에서 더 큰 소리
  * 오른쪽(+100%): 오른쪽에서 더 큰 소리

### 시각적 표시

* 사용하기 쉬운 슬라이더
* 명확한 숫자 표시
* 스테레오 위치 시각 표시

### 권장 사용 사례

1. 일반 청취

   * 밸런스를 중앙(0%)으로 유지
   * 스테레오가 고르지 않다고 느껴지면 조정
   * 미세 조정 사용

2. 헤드폰 청취

   * 편안함을 위해 미세 조정
   * 청력 차이 보정
   * 선호하는 스테레오 이미지 생성

3. 스피커 청취

   * 룸 설정에 맞게 조정
   * 청취 위치에 맞춰 밸런스 조정
   * 룸 어쿠스틱 보정

## Volume

음악 재생 볼륨을 조정할 수 있는 간단하지만 필수적인 컨트롤입니다. 다양한 상황에 맞는 청취 레벨을 찾기에 적합합니다.

### 청취 향상 가이드

* 다양한 청취 상황에 맞춰 조정:

  * 작업 중 백그라운드 음악
  * 집중 청취 세션
  * 늦은 밤 조용한 청취
* 다음을 피하기 위해 볼륨을 적절한 수준으로 유지:

  * 청취 피로
  * 소리 왜곡
  * 청력 손상 위험

### 매개변수

* **Volume** - 전체 음량 제어 (-60dB ~ +24dB)

  * 낮은 값: 더 조용한 재생
  * 높은 값: 더 큰 소리
  * 0dB: 원래 음량

참고: 이 기본 컨트롤은 좋은 사운드의 토대입니다. 더 복잡한 이펙트를 사용하기 전에 이 조정부터 시작하세요!
