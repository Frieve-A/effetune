# EffeTune ブラウザ拡張版

EffeTune ブラウザ拡張版は、最大4つのブラウザタブの音声を、それぞれ独立したステレオの Effect Pipeline で同時に加工します。デスクトップ版を起動したり、仮想オーディオデバイスを設定したりせずに、動画サイトや音楽サイトの音を加工して聴くときに便利です。

ローカルでのデータの扱いと、任意で開く外部リンクについては、[ブラウザ拡張版プライバシーポリシー](../../browser-extension-privacy.md)をお読みください。サポートが必要なときは [GitHub Issues](https://github.com/Frieve-A/effetune/issues) を利用できますが、公開の Issue には音声、タブのタイトルや URL、プリセット、測定結果、インパルス応答など、個人的な情報を投稿しないでください。

## 対応環境

PC の Chrome 116 以降、または対応する Chromium ベースの Microsoft Edge で使用できます。Firefox、Safari、モバイルブラウザ、プライベートブラウズには対応していません。各タブにステレオのエフェクトパイプラインを使います。

## ローカルパッケージの導入

ブラウザストアから入手した場合は、ストアでインストールしてください。ローカルパッケージの場合は、`effetune-extension-<version>.zip` を継続して保管するフォルダに展開してから、展開したフォルダを読み込みます。

1. Chrome では `chrome://extensions`、Edge では `edge://extensions` を開きます。
2. **Developer mode** をオンにします。
3. **Load unpacked** を選び、展開した拡張フォルダを選択します。

**Load unpacked** では ZIP ファイル自体は導入できません。展開フォルダ内のファイルを置き換えた後は、このページから拡張機能を再読み込みしてください。

## 加工の開始、比較、停止

1. 加工したい音声のタブを開き、再生を始めます。
2. ブラウザのツールバーから EffeTune 拡張機能を開きます。
3. **Start on this tab** を選びます。エフェクトチェーンの準備ができると、状態表示が **Starting…** から **Processing** に変わります。

別のタブも加工するには、そのタブで拡張機能を開き、**Start on this tab** を選びます。ポップアップにはすべてのセッションが一覧表示されます。同時に動かせるのは4つのタブまでです。5つ目を開始する前に、いずれかを停止してください。

各タブの横にある **Bypass** を使うと、セッションを維持したままエフェクトなしの音を聴けます。終了するときは、そのタブの横にある **Stop** を選びます。そのタブだけが通常再生に戻り、ほかのタブは中断されません。

拡張機能のポップアップやエディターを閉じても、加工は続きます。どちらかを再び開くと、現在のタブと処理状態が表示されます。ブラウザを再起動した後は、新しいセッションを開始してください。拡張機能が自動でタブをキャプチャすることはありません。

## Effect Pipeline の編集とプリセット

**Edit pipeline** で **EffeTune Pipeline Editor** を開き、ヘッダーで対象タブを選びます。EffeTune と同じように、エフェクトの追加、並び替え、オン/オフの切り替え、調整を行えます。解析表示は選択中のタブに追従します。動作中のタブがないときは、**Offline pipeline** で、次に開始するタブに使う既定パイプラインを編集します。

エディターのヘッダーで **Visualizer** を選ぶと、選択中のタブのエフェクト処理後の音声を [Visualizer](visualizer.md) で表示します。もう一度選ぶとパイプライン表示に戻ります。拡張機能では曲名とアートワークは表示されません。**Share** / **Import Link** はウェブ版と同じように使えます。

ポップアップからすばやくプリセットを切り替えるには、タブを選び、**Saved preset** を選んで **Apply to selected tab** をクリックします。エディターでは、**Pipeline Presets > Save as** でプリセットを保存し、**Settings > Import preset…** / **Export preset** で `.effetune_preset` ファイルをやり取りできます。プリセットに対応外のマルチチャンネルのルーティングやエフェクトが必要な場合、または外部アセットが不足している場合は、現在のパイプラインは変更されません。

ウェブ版またはデスクトップ版で測定した部屋やスピーカーの測定結果を **Room EQ** や **Crosstalk Cancellation** で使う手順は次のとおりです。
1. ウェブ版またはデスクトップ版から測定結果を JSON としてエクスポートします（**Crosstalk Cancellation** や **Room EQ** の位相補正で使う場合は、インパルス応答を含めます）。
2. 拡張機能のエディターで **Settings > Import measurement…** を開き、JSON ファイルを選びます。
3. **Room EQ** または **Crosstalk Cancellation** で、インポートした測定結果を選びます。インポートしたコピーを削除するには、Room EQ の **Measurement** 一覧でそれを選んで **Delete** を選びます。確認すると、その測定結果を使っている Room EQ と Crosstalk Cancellation の割り当てがすべて解除されます。

プリセット、エフェクトプリセット、Visualizer プリセット、インパルス応答、インポートした測定結果を、ウェブ版、デスクトップ版、拡張機能の間でまとめて移すには、**Settings > Backup / Restore**（`.effetune_backup`）を使います。拡張機能のプリセット、レイアウト、インポートした測定結果は拡張機能の内部に保存され、ウェブ版やデスクトップ版とは自動で同期されません。バックアップには、URL ルールと拡張機能のサンプリング周波数の設定は含まれません。

## URL別プリセットとサンプリング周波数

**Settings > URL rules…** を開くと、タブの URL が `host/path` 形式のパターン（例: `example.com/music/*`。`*` は任意の文字列に一致）に一致したときに、保存済みプリセットを自動で読み込めます。タブの開始は引き続き自分で行います。ルールが選ぶのは、開始時と URL が変わったときのプリセットだけです。一覧で最初に一致した有効なルールが使われ、一致するルールがなければ既定パイプラインが使われます。ルールの変更は、次の開始時またはページ移動時に反映されます。URL ルールで読み込んだパイプラインを編集するとそのルールの保存済みプリセットが更新され、それ以外の編集（プリセットを手動で適用した後の編集を含む）は既定パイプラインを更新します。プリセットを削除すると、そのプリセットを使うルールは無効になり、そのルールを使っていたタブは既定パイプラインに戻ります。

**Settings** の **Sample rate**（**Auto**、**44.1 kHz**、**48 kHz**、**96 kHz**、**192 kHz**）は、動作中のすべてのタブに適用されます。**Auto** ではブラウザが選びます。変更すると、動作中のタブはキャプチャを保ったまま処理が短時間再起動します。新しいサンプリング周波数で動作できないタブは通常再生に戻ります。別の周波数を選んで、そのタブをもう一度開始してください。

## 権限と制限

拡張機能が音声を取得するのは **Start on this tab** をクリックしたタブだけで、それらのタブの URL も URL 別プリセットのルールとの照合にのみ読み取ります。ページ内容の読み取り、スクリプトの挿入、マイクの使用、ネットワーク経由での音声送信は一切行いません。

各タブは、**Main** と **Bus 1–4** に対応したステレオのパイプラインで動作します。2chを超えるマルチチャンネル出力、音響測定の実行、Music Library、ファイルの一括オフライン変換、デスクトップ専用のハードウェア機能は、拡張機能では利用できません。ブラウザでのキャプチャを妨げる保護された（DRM）ストリームは、通常再生に戻ります。

## 問題が起きたとき

- **状態が「Needs attention」と表示される、またはキャプチャが始まらない:** タブで音声が再生中であることを確認してから、もう一度 **Start on this tab** をクリックしてください。
- **プリセットを適用できない:** エディターは現在のパイプラインを保持します。必要な測定結果やインパルス応答のアセットを、先に拡張機能へインポートしてあるか確認してください。
