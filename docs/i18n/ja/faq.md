# EffeTune FAQ

EffeTuneは、オーディオ愛好家向けのリアルタイムDSPアプリで、Webアプリ版とデスクトップアプリ版があります。このドキュメントでは、セットアップ、トラブルシューティング、マルチチャンネルでの使い方、エフェクトの操作、周波数特性の補正について説明します。

Chrome または Edge のタブ音声を加工する方法は、[ブラウザ拡張版ガイド](browser-extension.md)をご覧ください。

## 1. ストリーミング再生の初期設定

Windowsでの例: Spotify → VB-CABLE → EffeTune → DAC/AMP。他のサービスやOSでも考え方は同じです。

### 1.1. VB-CABLEのインストールと96 kHz折り返しノイズ対策(任意)

VB-CABLE Driver Pack45をダウンロードし、`VBCABLE_Setup_x64.exe`を管理者として実行してから再起動します。インストールによってOSの既定の出力が**CABLE Input**に変わることがあります。その場合は、スピーカーまたはDACに戻してください。

VB-CABLEを使うと20 kHz以上に折り返しノイズが出る場合、原因はVB-CABLE内部の48 kHz動作です。この問題に限り、**CABLE Input**と**CABLE Output**の形式をどちらも24ビット、96,000 Hzに設定します。続いて`VBCABLE_ControlPanel.exe`を管理者として起動し、**Menu▸Internal Sample Rate = 96000 Hz**を選んで**Restart Audio Engine**をクリックします。再起動後もこの設定を保つには、管理者権限が必要です。これはVB-CABLE自体の設定変更で、EffeTuneを96 kHzで普通に使うだけなら必要ありません。

### 1.2. ストリーミングサービスのルーティング(Spotifyの例)
**設定▸システム▸サウンド▸音量ミキサー**を開き、`Spotify.exe`の出力を**CABLE Input**にします。曲を再生し、スピーカーから音が出ないことを確認します。
macOSでは、Rogue Amoebaの**SoundSource**を使って、同じようにSpotifyの出力を**CABLE Input**に割り当てます。

### 1.3. EffeTuneのオーディオ設定
EffeTuneを開き、**設定**メニューから**オーディオ設定**を選びます。
- **入力デバイス:** CABLE Output (VB-Audio Virtual Cable)
- **出力デバイス:** 実際のDAC/スピーカー
- **サンプルレート:** 96 kHzを選びます。これはEffeTune内部の処理レートで、非線形エフェクトで聞こえる折り返しノイズを減らします。OS、DAC、VB-CABLEのサンプルレートとは無関係に設定できます。アプリに表示される実際のサンプルレートを確認してください。音が途切れる場合は、負荷の高いエフェクトを減らすか、サンプルレートを下げてください。

### 1.4. 動作確認
Spotifyを再生したまま、EffeTuneのマスター**ON/OFF**を切り替えて、音が変わることを確認します。

## 2. トラブルシューティング

### 2.1. 再生音質の問題

| 症状 | 対処 |
| ------ | ------ |
| 音切れやノイズ | **設定**メニューまたはモバイルのオーバーフローメニューから**オーディオをリセット**を選びます。デスクトップアプリでは、**表示**メニューの**リロード**も使えます。必要に応じて、有効なエフェクトの数を減らしてください。 |
| 歪みやクリップ | チェーンの最後に**Level Meter**を入れ、レベルを0 dBFS未満に保ちます。必要なら、Level Meterの前に**Brickwall Limiter**を追加します。 |
| VB-CABLE使用時に20 kHz以上の折り返しノイズが出る | VB-CABLEの内部レートが48 kHzのままの可能性があります。1.1の96 kHz設定(任意)を行ってください。 |

### 2.2. CPU使用率が高い
使っていないエフェクトを無効にするか、**Effect Pipeline**から削除してください。

### 2.3. エコー
入力デバイスと出力デバイスがループしている可能性があります。EffeTuneの出力が入力に戻っていないか確認してください。

### 2.4. 入力、出力、エフェクトの不具合

| 症状 | 対処 |
| ------ | ------ |
| 音声が入力されない | プレーヤーの出力先が**CABLE Input**になっているか確認します。ブラウザでマイクの使用を許可し、**オーディオ設定**で**CABLE Output**を選びます。 |
| エフェクトが効かない | マスター、各エフェクト、**Section**がすべて**ON**か確認します。必要ならパラメーターをリセットします。 |
| 音が出ない | **オーディオ設定**を確認します。ブラウザで出力デバイスを選べない場合は、OSとブラウザの既定の出力がDAC/AMPになっているか確認します。 |
| 他のプレーヤーで「CABLE Input in use」と表示される | **CABLE Input**を他のアプリが使っていないか確認します。 |

WebAssemblyが必要なエフェクトは、動作できないときに操作パネルの上部へ通知を表示します。**オーディオ設定**で**WebAssembly 音声処理を使用する**を有効にしてください。すでに有効な場合は、**オーディオをリセット**を選ぶか、EffeTuneを再読み込みしてください。エフェクトが再び動作すると通知は消えます。

### 2.5. マルチチャンネル出力の不一致
EffeTuneは最大16チャンネルを番号順に出力します。**出力チャンネル数**は、デバイス側で設定した構成に合わせてください。7.1chの構成では、デバイスとEffeTuneの両方を8chにし、リアの音を振り分けるときはデバイスのチャンネル表記に従います。16チャンネルの構成では、両方で16チャンネルを選び、デバイスのチャンネル割り当てを確認してください。

### 2.6. 表示のトラブルシューティング {#display-troubleshooting}

デスクトップアプリでは、**ハードウェア アクセラレーションを使用**が既定でオンです。ウィンドウがちらつく、または表示が更新されなくなる場合は、**設定 > 環境設定...**でオフにしてEffeTuneを再起動してください。表示の不具合が繰り返されると、EffeTuneは自動的にこの設定をオフにして再起動します。もう一度試すには、設定をオンにして再起動してください。

## 3. マルチチャンネルとハードウェア接続

### 3.1. HDMI+AVアンプ
PCのHDMI出力をAVアンプのスピーカー構成に合わせて設定し、AVアンプに接続します。PC、AVアンプ、HDMI接続が対応していれば、EffeTuneはケーブル1本で最大16チャンネルを送れます。古いAVアンプでは、音質が劣化したり、チャンネルが意図せず割り当て直されたりすることがあります。

### 3.2. マルチチャンネルドライバーのないインターフェイス(例: MOTU M4)
Out 1-2とOut 3-4が別々のデバイスとして認識されるため、4チャンネル出力ができません。回避策：
- **Voicemeeter**を使い、ASIO経由でチャンネルをまとめる。
- **ASIO Link Pro**を使い、4チャンネルの仮想デバイスを1つ作る(上級者向け)。

### 3.3. チャンネルディレイとタイムアライメント
**MultiChannel Panel**または**Time Alignment**を使うと、チャンネルを10 µs単位(最小1サンプル)で遅らせられます。実測の遅延がずっと大きいBluetoothや無線のリアスピーカーにフロントを合わせる場合は、フロントのチャンネルを100-400 ms遅らせます。これはスピーカー距離の補正としては一般的な値ではありません。映像との同期はプレーヤー側で調整してください。

### 3.4. 16chの上限と拡張
EffeTuneは現在、最大16出力チャンネルに対応しています。

## 4. よくある質問

| 質問 | 回答 |
| ------ | ------ |
| PWA版はどの端末で使える? | Androidスマートフォン/タブレット、iPhone/iPad、Windows、macOS、Linux、ChromeOSなど、主要なモバイル/デスクトップ環境で利用できます。PWAのため端末固有アプリではなくブラウザ上で動作しますが、インストール方法、オーディオ入出力デバイス選択、対応音楽形式はブラウザとOSに依存します。 |
| PWA版をインストールできない | EffeTuneサイトの**PWA版をインストール**ボタンを使うか、Webアプリ右上の歯車メニューから**アプリをインストール**を選びます。インストール項目が表示されない場合は、AndroidまたはPCのChromeかEdgeでサイトを開いてください。iPhone/iPadではSafariで開き、共有メニューからホーム画面に追加します。アプリ内ブラウザ、プライベートブラウズ、古いブラウザでは、インストール項目が表示されないことがあります。 |
| サラウンド入力(5.1chなど)には対応している? | Web Audio APIの制限で、入力は2チャンネルまでです。出力とエフェクトは16チャンネルまで対応しています。 |
| エフェクトチェーンはどのくらいの長さがよい? | 音切れや大きな遅延が起きない範囲で、CPUが許す限りいくつ使ってもかまいません。 |
| 最高の音質を得るには? | EffeTuneの**サンプルレート**を96 kHzにし、控えめなエフェクト設定から始めて、**Level Meter**でヘッドルームを確認してください。音が途切れる場合は、まず負荷の高いエフェクトや有効なエフェクトの数を減らし、必要ならサンプルレートを下げます。必要に応じて**Brickwall Limiter**を追加してください。 |
| どんな音源でも使える? | はい。仮想オーディオデバイスを使えば、ストリーミング、ローカルファイル、外部機器の音を処理できます。 |
| DRM（著作権保護）付きコンテンツを再生できますか？ | 直接再生することはできません。EffeTuneは音声を加工するアプリですが、著作権保護付きコンテンツは提供元が認めた環境での再生を前提としており、第三者の音声加工アプリでは利用できない場合があります。提供元の公式アプリまたはウェブサイトを、利用規約と対応する音声出力方法に従ってお使いください。EffeTuneが著作権保護を解除または回避することはありません。 |
| 音声入力なしで音楽ファイルプレーヤーだけ使える? | はい。起動後にマイクの音がヘッドホンやイヤホンに回り込む場合は、**オーディオ設定**を開き、**入力デバイス:**を**なし（音楽ファイルプレーヤー専用）**にしてください。EffeTuneは無音のソースを使うため、プレーヤーや**Oscillator**などの信号を生成するエフェクトのためにエフェクトパイプラインは動作し続けます。音声入力を選んだ場合は、USBオーディオインターフェイスを通して外部機器の音を処理したり、**Spectrum Analyzer**で入力をモニターしたりできます。 |
| モバイルWebアプリで他アプリの音声を処理できる? | 通常はできません。モバイルブラウザは他アプリ音声の汎用ループバック入力を提供しないため、モバイルではEffeTune内蔵プレーヤー中心の利用になります。 |
| 対応している音楽ファイル形式は? | ブラウザとOSの音声デコード機能に依存します。目安としてMP3、WAV、AAC/M4Aは多くの環境で使いやすく、FLAC、OGG/Vorbis、Opus/WebMなどは環境により対応状況が異なります。macOS版デスクトップアプリではM4A/MP4形式のApple Lossless（ALAC）ファイルを自動変換して再生できます。MP4、M4V、MOV、MKV、WebM、3GPの動画ファイルでは音声を再生し、映像はVisualizerの **Video** アイテムで表示できます。再生可否は動画ファイル内の音声コーデックにも依存し、AACが一般的な目安です。再生できない場合はMP3、AAC/M4A、WAVを試してください。 |
| 複数の音楽ファイルを再生できる? | はい。**音楽ファイルを開く** で表示される端末標準のファイル選択画面で複数ファイルを選んでから開くと、プレイリストとして読み込まれます。複数選択やフォルダ内の全ファイル指定が使えるかは、端末、ブラウザ、ファイル選択画面に依存します。 |
| Music Libraryでは何ができる? | 選択した音楽フォルダをインデックス化し、曲、アルバム、アーティスト、ジャンル、曲が直接入っているサブフォルダで閲覧・検索してEffeTuneで再生できます。保存されるのはアプリ内のライブラリ情報やプレイリストで、音楽ファイル自体ではありません。 |
| Music Libraryはどの環境で使える? | デスクトップ版ではフォルダスキャンをそのまま利用できます。Chromium系ブラウザでは対応環境でFile System Accessを使います。Safari/Firefoxではインポート方式のフォールバックになるため、リロード後や権限が切れた後はフォルダまたはファイルの選択が再度必要になる場合があります。 |
| ライブラリのフォルダを更新・再接続するには? | ファイルを追加、削除、編集した後は **Music Libraryを再スキャン** を使います。フォルダがアクセス不可として表示されたら、そのフォルダの **再接続** ボタンを押し、同じフォルダへのアクセスを許可し直します。 |
| Music Libraryで読み書きできるプレイリスト形式は? | M3U、M3U8、PLS、XSPF形式のプレイリストをインポートでき、M3U8またはXSPF形式でエクスポートできます。 |
| Music Libraryはディスク上の音楽ファイルを書き換える? | いいえ。スキャン、メタデータ読み取り、アートワークキャッシュ、プレイリスト編集、再生操作はアプリ内で完結し、ディスク上の音楽ファイルを変更することはありません。 |
| Webアプリで出力デバイスを選べないのはなぜ? | ブラウザの対応状況と権限によって異なります。安全なページでChrome/Chromiumを使うか、使いたいDAC/AMPをOSまたはブラウザの既定の出力にしてください。 |
| サンプルレートや出力チャンネル数が別の値に戻ったのはなぜ? | 設定画面ではサンプルレートの既定値が96 kHzと表示されますが、設定を保存する前は、OSやブラウザの既定値で起動することがあります。Web版では、ブラウザやデバイスが96 kHzなどの未対応の値を受け付けない場合、EffeTuneは利用できる別のレートを使います。アプリに表示される実際のサンプルレートを確認してください。出力チャンネル数の対応状況も、ブラウザとデバイスによって異なります。 |
| サンプルレートとチャンネル数の表示が赤くなったのはなぜ? | 有効なエフェクトの処理がリアルタイムに間に合わなかったことをEffeTuneが検出しました。処理が回復すると、赤い警告は約10秒後に消えます。有効なエフェクトの数を減らしてください。 |
| Webプレーヤーはプレイリストを記憶する? | リピート/シャッフル設定は保存されますが、通常のファイル選択はブラウザ制約によりリロード後に復元されません。 |
| 画面がオフでもモバイルで再生を続けられる? | すべてのブラウザで確実とは言えず、特にiOSでは不安定です。EffeTuneは対応環境ではWake Lockを使いますが、バックグラウンド再生はブラウザに依存します。 |
| EffeTuneの省電力モードはどう違う? | **設定 > 環境設定... > 省電力**を開きます(Web/PWA版、デスクトップアプリ)。**バックグラウンド処理優先**は、無音の間も外部入力の処理を続けます。**標準省電力（既定）**は、選んだ音声入力を接続したまま、無音の間のDSP処理と画面更新を減らします。**最大省電力**は、さらに、バックグラウンドで無音の状態、またはPlayerモードで未使用の状態が設定時間続くと、音声入力を解放します。信号が戻っても入力は再開しません。アプリを開き、メニューから**音声処理を再開**(または**音声入力を再開**)を選んでください。 |
| 「非表示時は表示専用DSPをスキップ」は何をする? | 既定でオンです。アナライザーのグラフが見えないとき(Music Libraryの閲覧中、ミニプレーヤーの使用中、ブラインドテスト中、ウィンドウの最小化中など)、EffeTuneは音を変えずにAnalyzerエフェクトをバイパスしてCPU負荷を抑えます。バックグラウンドでもアナライザーの履歴を更新し続ける必要がある場合はオフにしてください。 |
| 「表示を音声に同期」は何をする? | グラフやメーターを、聞こえる音に合わせます。音声の遅延が増えることがあるため、既定ではオフです(ブラウザ拡張版では利用できません)。Bluetoothなどのデバイスでは、表示がわずかにずれることがあります。 |
| 「無音判定レベル」と「音声入力を停止するまで」は何を変える? | **無音判定レベル**(-90～-20 dBFS、10 dB刻み)は、音声を無音とみなすレベルの境界です。値が低いほど、静かな部分を無音とみなしにくくなります。**最大省電力**の**音声入力を停止するまで**(1分 / 5分 / 15分 / **停止しない**)は、バックグラウンドで無音の状態、またはPlayerモードで未使用の状態がどれだけ続いたら入力を解放するかを決めます。 |
| 「バックグラウンド処理優先」なら、Web/PWA版を非表示にしても必ず処理を続ける? | いいえ。EffeTuneが無音の間に外部入力の処理を停止しないようにするだけで、ブラウザやOSがバックグラウンドのタブを抑制または停止することはあります。 |
| AVアンプとオーディオインターフェイス、どちらが安上がり? | 手持ちのAVアンプをHDMIで使い回すのが手軽です。PC中心の構成なら、マルチチャンネルインターフェイスと小型アンプの組み合わせがコストと音質の両面で有利です。 |
| VB-CABLEをインストールした直後から他のアプリの音が出ない | OSの既定の出力が**CABLE Input**に切り替わっています。サウンド設定で元に戻してください。 |
| 4chに分けた後、3+4chだけ音量を変えたい | スプリッターの後に**Volume**エフェクトを置き、**Channel**を3+4にします。前に置くと全チャンネルの音量が変わります。 |
| 共有されたIR Reverbがdry音だけになる、またはIRが見つからないと表示される | URLやプリセットにはIRのコンテンツIDだけが保存され、音声ファイルは含まれません。元と同じファイルを取り込むと自動再リンクできます。別のIRを使う場合は **Impulse Response Library** から置き換えてください。IRがない状態ではwet音は出ないため、**Dry**と**Dry Level**の設定も確認してください。 |
| 別の人にIR Reverbの結果を再現してもらうには? | プリセットまたはURLと一緒に、元のIRファイルと出典・ライセンス情報を渡してください。受け取った側が未変更の同じファイルを取り込むと同じIDになります。サンプルレート、出力チャンネル選択、IR Reverbの各設定も揃えてください。 |

## 5. 周波数特性補正と音場補正

### 5.1. AutoEQの設定を15Band PEQに読み込む
右上のボタンから、AutoEQのイコライザー設定を直接読み込めます。

### 5.2. 測定による補正設定を貼り付ける
測定ページで5Band PEQの設定をコピーし、**Effect Pipeline**のビューに**Ctrl+V**またはメニューで貼り付けます。

### 5.3. 複数チャンネルの測定をRoom EQで使う
測定ページの**出力チャンネル**で個別のチャンネルを選択すると、1回の測定でまとめて測定できます。保存後、Room EQの**Measurement Ch 1**、**Measurement Ch 2**などのチャンネル別の選択欄には、`測定名 [Ch 1]`のようなエントリが表示されます。各**Measurement Ch**で、対応する出力チャンネルのエントリを選択してください。Room EQがチャンネルを自動で割り当てることはありません。

**チャンネル別PEQ設定をコピー**は、周波数特性をもとにした静的な補正を**Effect Pipeline**へ貼り付けたい場合に使います。Room EQはインパルス応答をもとに、チャンネルごとの音場補正を行います。

## 6. エフェクト操作のヒント
* 信号は上から下へ流れます。
* 2→4chや16→2chなどの変換には**Matrix**エフェクトを使います(バスルーティングでは**Channel = All**に設定)。
* 最大16チャンネルのレベル、ミュート、ディレイは**MultiChannel Panel**でまとめて管理できます。
* マルチチャンネルのリバーブをセンド/リターンで使うには、**Matrix**で必要なソースチャンネルを空きバスにコピーし、そのバスに**Dry**をオフ、**Wet Level**を0 dBにした**IR Reverb**を置き、Matrixのゲインをセンド量として使います。元のdry経路が重複しないよう、wetバスは目的の出力チャンネルにだけ戻してください。
