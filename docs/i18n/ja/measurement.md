# 音響特性の測定

周波数特性、インパルス応答、歪率、減衰を測定し、必要に応じて補正EQを作成できます。
1. [音響特性の測定](https://effetune.frieve.com/features/measurement/measurement.html)を開くか、**設定** メニューから **音響特性の測定** を選択します。
2. ガイドに従って、測定用マイクと出力デバイスを設定します。
3. 1か所または複数のリスニングポジションで、システムの周波数特性を測定します。
4. EffeTuneに直接読み込めるパラメトリックEQの補正を生成します。
5. 補正を適用して、より正確でニュートラルな再生音にします。

## 出力チャンネル

**出力デバイスのチャンネル数** を出力デバイスに合わせて設定します。5.1chなら **6**、7.1chなら **8** です。出力チャンネルとチャンネル別の帯域設定は、この範囲内で選べます。テスト信号と測定には常にこのチャンネル数が使われるため、5.1chデバイスでCh 3（センター）とCh 4（サブウーファー）だけを測定する場合も **6** のままにしてください。

マルチチャンネルのシステムでは、**全チャンネル** を選ぶとすべての出力を同時に測定でき、個別の **出力チャンネル** を選ぶと1つずつ測定できます。**詳細設定** で、スイープの帯域制限を **Off**、**全チャンネル共通**、**チャンネル別** から選びます。**チャンネル別** では、**設定チャンネル** を使って選択した各出力チャンネルの周波数範囲を設定します。レベル調整では、**チャンネルモード** は最初 **自動切り替え** です。必要に応じてテスト信号チャンネルを選ぶか、**手動** に切り替えます。

## インパルス応答のインポート

インパルス応答のWAVファイルがある場合は、**インポート** を選んでそのファイルを選択します。EffeTuneはWAVの各チャンネルを測定結果として保存し、**Room EQ** など測定結果を使う機能で利用できるようにします。

## オーディオインターフェイスのキャリブレーション

オーディオインターフェイス自体の特性を差し引くには、出力を入力に直結し、その直結測定を通常の未補正測定としてインパルス応答付きで保存します。スピーカーを測定するときは、同じインターフェイス、チャンネル、サンプリング周波数、入出力ゲインの設定のまま、**オーディオインターフェイスのキャリブレーション** で保存した測定点を選びます。直結測定によるキャリブレーションを使わずに測定する場合は、**なし（未補正）** を選びます。

## 結果の表示とエクスポート

結果は5つのタブで確認できます。周波数特性では複数の測定点や出力の平均を表示でき、インパルス応答・歪率・Waterfallでは保存済みの1つの測定点と出力を選びます。平均表示から切り替えると、前回使った有効な個別の選択、なければ最初に利用できる記録が選ばれます。周波数特性に戻ると、そのタブでの選択が復元されます。全出力を同時に鳴らした測定は、それらを合わせた応答です。

- **周波数特性** では、実測値、補正EQ、補正後の予測を比較できます。周波数・dBの範囲、表示の平滑化、相対的な正規化または基準レベル、表示する曲線を調整します。平滑化の幅はガウス分布のσです。**0** は追加の平滑化を行わない設定で、保存済みの応答に含まれる処理は取り消しません。IRのある個別の記録では、保存された応答と、立ち上がり前後の窓長・窓形状を指定したIRの再分析を選べます。対象とする時間範囲が違うため、結果は異なる場合があります。表示設定を変えても、保存した測定値や補正EQは変わりません。補正の設計、コピー、TXT/CSVへのエクスポートは補正欄で行います。
- **インパルス応答** では、符号付きの振幅、または振幅の絶対値をdBで表示します。時間・振幅の範囲、ズームと移動、ピークの正規化、表示上の時間原点、窓の前後長と形状を調整できます。重ねて表示される窓は、分析する区間を示します。時間の0は検出した立ち上がりで、原点の移動は表示だけを変え、音の伝搬時間を変えません。WAVの読み込みや再生時刻の基準がない録音では、絶対的な伝搬遅延は分かりません。WAVへのエクスポートでは、表示中の窓やズームにかかわらず、保存した線形応答全体を正規化せず、保存時のサンプリング周波数のモノラル32ビット浮動小数点音声として出力します。
- **歪率** では基音に対する高調波の比率を示し、初期状態ではH2・H3・THDを表示します。**表示設定** の **表示する高調波の最高次数** スライダーは、測定に含まれる次数に応じてH10まで選べます。H3までの記録でより高い次数を見るには、新しく測定してください。**THDに含める最高次数** は別に設定でき、表示の上限を超えることはできません。周波数・縦軸の範囲、表示する曲線、分析窓も調整できます。**単位** で%またはdBrを選びます。どちらも基音に対する同じ比率の表し方で、1%は−40 dBrです。比率が大きいほど高調波歪みが多くなります。THDは2次から指定した最高次数までを合成し、すべてが有効な帯域だけに表示されます。欠けた部分はデータがないことを示し、歪みが0という意味ではありません。歪率の **Hann** は直接音の立ち上がりを重み1とし、指定した窓の両端に向かって0まで滑らかに減衰します。窓を変えると曲線も変わる場合があります。高い次数ほど利用できる窓が短く、周波数範囲も狭くなり、スイープの指定長を長くすると分離を改善できます。結果には再生から録音までの経路全体が含まれ、インターフェイスの線形キャリブレーションではその歪みを取り除けません。
- **Waterfall（3D）** では、**Waterfall** と **Burst Decay** の分析を選べます。面の高さとヒートマップの色は同じ相対dBレベルを表し、カラースケールと位置読み取りで値を確認できます。等高線は、同じdBレベルの点を結んでいます。周波数の補助線は、軸の目盛りに合わせて面に沿って表示されます。**正規化** の **なし** は元のレベルを保ちます。**全体のピーク = 0 dB** は、表示中の周波数帯域と利用可能な時刻の中から共通のピークを取り、レベル差を保ったまま0 dBに合わせます。**周波数ごとのピーク = 0 dB** は、各周波数で利用可能な時刻の最大レベルを0 dBに合わせ、減衰を比較しやすくします。そのピークは0 msとは限りません。初期の視点では奥行きの0が奥、後の値が手前です。周波数・dBの範囲と最初・最後のスライスを設定します。視点の回転・仰角・倍率を操作部で調整するほか、ドラッグで回転、ホイールまたは＋／−で拡大・縮小できます。**視点をリセット** は分析条件を変えずに視点だけを戻します。**Waterfall** の奥行きはms単位の時間で、窓長、立ち上がり時間、窓形状、平滑化を調整できます。窓を長くすると近い周波数を見分けやすくなりますが、時間方向の変化はぼやけます。立ち上がり区間も時間分解能に影響し、保存された応答内に窓全体が収まる範囲だけを表示します。**Burst Decay** は、帯域幅が1/3オクターブのガウス形状のトーンバーストの包絡を表示します。奥行きはms単位の **時間** または **周期数** から選べ、周期数の初期範囲は0～30です。周期数では振動が何周期続くかを比較できます。1周期は100 Hzで10 ms、1 kHzで1 msなので、同じ周期数でも経過時間は異なります。バースト自体の長さも表示される減衰に含まれます。この推定では、最初の保存サンプルより前を無音と仮定し、立ち上がり前に保存されたサンプルは使います。後半の空白は録音の長さが足りないことを示し、無音という意味ではありません。
- **測定詳細** では、取得方法、キャリブレーション、サンプリング周波数、時間の基準、保存された長さ、利用できる分析を確認できます。JSONへのエクスポートもここで行います。インパルス応答を含めると、利用できる高調波データも含まれます。含めないJSONには周波数特性が残りますが、時間応答や歪率の分析は復元できません。

グラフの凡例と位置読み取りで、マウス・タッチ・キーボードから数値を確認できます。 **周波数特性** と **歪率** では、凡例の項目にポインターを合わせると、対応する曲線が強調されます。自動範囲やリセットを使うと、見やすい表示に戻せます。表示レベルは相対値であり、校正済みの音圧レベルではありません。 周波数の読み取りには、15°C・1気圧の乾燥空気中の音速340.3 m/sから求めた1波長の長さも、λとしてm単位で表示されます。

4つのグラフの上にあるカメラアイコン（**画像をコピー**）を使うと、高解像度のPNGをクリップボードにコピーし、プレゼンテーションやブログの編集画面に貼り付けられます。現在の視点とテーマ、タイトル、選択中の測定、表示されている凡例やカラースケールを含み、カーソルや設定の操作部は含みません。

新しい測定では指数正弦スイープ（ESS）を使います。低い出力レベルから始め、クリッピングしない範囲で調整してください。歪率には、その測定で取得した有効な高調波データが必要です。読み込んだWAVや、周波数特性・線形IRだけを持つ測定からは算出できません。必要なデータがない場合は、応答を含む測定ファイルを読み込むか、新しく測定してください。利用できる範囲は、スイープ帯域や録音の長さにも左右されます。 指定したスイープ長は、高調波を分離するために長くなる場合があります。各回には減衰を待つ2.5秒も含まれます。帯域制限がOffのとき、ESSは実際のサンプリング周波数で扱える範囲内の20 Hz～20 kHzを使います。

現在のパイプラインのFrequency、Phase、Min Group Delay、Excess Group Delay、Impulse特性を、選択した最大4つの出力や、必要に応じて保存済みのスピーカー特性も含めて確認する方法は、[Pipeline Analyzerガイド](pipeline-analyzer.md)をご覧ください。
