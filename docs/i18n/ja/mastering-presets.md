# マスタリングプリセット

**System Presets > Mastering**には、完成したステレオミックス（2mix）向けのエフェクトチェーンを10種類用意しています。再生中やファイル処理中に、音色バランスの自動補正、ダイナミクスの圧縮、ピーク制限を行います。ジャンルごとの出発点として使う設定であり、指定したLUFS値へ自動的に音量を合わせる機能ではありません。

## プリセットを選ぶ

| プリセット | 処理の特徴 |
| --- | --- |
| Acoustic | アコースティック楽器や歌声の音色を穏やかに補正し、軽く圧縮します。 |
| Classical | 小さい音と大きい音の差を保ちながら、控えめな音色補正とピーク制限を行います。 |
| EDM | 低域をしっかり圧縮し、アタックを少し調整して、強いリミッティングで音の密度を上げます。 |
| Hip-Hop | 低域を整えながらキックのアタックを強調し、軽いサチュレーションを加えます。 |
| J-Pop Dense | 5帯域の強い圧縮、アタックの抑制、サチュレーション、強いリミッティングで、意図的にダイナミックレンジを大幅に狭めます。 |
| Jazz | アコースティックジャズ向けに、軽い圧縮とピーク制限を行います。 |
| Metal | 密度の高いギターやシンバル向けに、しっかり圧縮し、中高域・高域の突出を動的に抑えます。 |
| Pop | 適度な圧縮に加え、中高域・高域が強くなる箇所を動的に抑えます。 |
| R&B and Soul | 歌声を中心としたミックスに、穏やかなサチュレーションとゆっくりした圧縮を加えます。 |
| Rock | 圧縮と軽いアタック強調を行い、ギターの中高域の突出を動的に抑えます。 |

## 完成したミックスを書き出す

1. クリッピングしていないステレオミックスを用意します。最も大きなピークが-6〜-3 dBFS程度のミックスを出発点にしてください。入力音量は自動正規化されないため、入力が小さいと圧縮は弱く、大きいと強くなります。
2. Effect Pipelineを空にし、**System Presets > Mastering**から1つ追加します。System Presetsは現在のパイプラインにエフェクトを挿入するため、複数追加すると処理が重なります。
3. 音の大きい部分と静かな部分を試聴します。先頭の**Volume**で入力レベルを調整できます。圧縮を強めたいときは上げ、全体が圧縮されすぎる場合は下げてください。比較するときは聴感上の音量をそろえます。
4. **設定 > 環境設定... > オフラインファイル出力**でWAVまたはFLACと、出力サンプルレート・品質を選びます。Effect Pipelineの下にあるファイル処理エリアへ元のミックスをドロップすると、処理済みのコピーを保存できます。

Tonal Balance EQの平均化時間は10秒で、曲の進行に合わせて補正が変化します。ファイル全体を事前解析する方式ではないため、冒頭と後半で補正量が異なることがあります。AcousticとJazzは幅広い音楽向けの**All**、Hip-Hopは**Electronic**、R&B and Soulは**Pop**をターゲットにしています。音色が変わりすぎる場合は**Amount**または**Range**を下げてください。

すべてのチェーンの最後に**Brickwall Limiter**を配置しています。オーバーサンプリングは4倍、先読みは5 ms、Thresholdは0 dB、Marginは-1 dBです。最後のピーク制限の強さは**Input Gain**で調整します。ドラムの勢いが失われたり、大きな音が歪んだりする場合は下げてください。Limiterは最後に置き、納品などでラウドネスやトゥルーピークの指定がある場合は、書き出したファイルを測定してください。これらのプリセットは特定の値を保証するものではありません。

**J-Pop Dense**は、アタックの細部や音量差を抑えて音の密度を上げる設定です。全5帯域を5:1で圧縮し、各帯域のゲインを10 dB、LimiterのInput Gainを14 dBに設定しています。ダイナミクスを残したい場合は**Pop**から始めてください。すでに強くリミッティングされたミックスには、さらに圧縮したい場合に使用してください。
