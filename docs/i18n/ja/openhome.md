# OpenHomeリモート操作（デスクトップ版）

対応するデスクトップ版（Windows x64、macOS（IntelおよびAppleシリコン）、Linux x64）では、同じLAN上のコントローラーアプリからEffeTuneをOpenHomeプレーヤーとして認識させられます。**設定 > 環境設定...** を開いて **このネットワーク上のOpenHomeコントローラーを許可**（初期状態では無効）を有効にし、EffeTuneが利用可能になったことを状態表示で確認してください。既定のプレーヤー名は `EffeTune (PC名)` です。**プレーヤー名** で、`EffeTune Living Room` などの名前を指定できます。

OpenHomeにはログインがありません。有効にしている間は、同じLAN上の他の端末が再生中の曲情報を閲覧し、プレーヤーのキューを編集し、再生を操作できます。Windowsファイアウォールの確認が表示された場合は、EffeTuneを **プライベートネットワーク** でのみ許可し、**パブリックネットワーク** では許可しないでください。リモート操作が不要なときは設定を無効にしてください。

コントローラーからは、HTTP/HTTPSの音声ストリームを追加し、リモート再生キューを管理し、再生、一時停止、停止、曲送り、シーク、リピート、シャッフルを操作できます。リモートの音声も、通常どおり現在のEffeTuneのエフェクトパイプラインを通ります。基本的なキュー操作と再生操作はAndroid版BubbleUPnPで確認しています。他のOpenHomeアプリでは、サービスの表示方法が異なる場合があります。EffeTuneはOpenHome Playlistソースとして動作し（UPnP AV MediaRendererではありません）、エフェクト編集、ローカルファイルパス、マスター音量、Radio、Songcast、マルチルーム同期はOpenHome経由では提供しません。

ギャップレス再生は保証されません。また、音源側から提供されるまで、曲の技術情報が不明のままになる場合があります。スリープ、復帰、VPN接続、ネットワーク変更の後は、再接続するまでの短い間、プレーヤーが見えなくなることがあります。
