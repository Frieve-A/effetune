# その他のオーディオツール

主要なエフェクトカテゴリーを補完する、専用のオーディオツールとジェネレーターをまとめたものです。スピーカー、ヘッドホン、左右チャンネルのバランス、再生時の挙動を、音楽を聴く前や聴いている途中に確認するために役立ちます。

## プラグイン一覧

- [Oscillator](#oscillator) - スピーカーやヘッドホンの確認に使うテストトーン/ノイズジェネレーター
- [SFZ Note Player](#sfz-note-player) - 検出したノートを取り込んだ SFZ 音源で再生

## Oscillator

リスニング環境を確認するためのテストトーン/ノイズジェネレーターです。小さな音量から使い、スピーカーやヘッドホンの出力、左右の配置、音量バランス、ビビり音、うなり、簡単な周波数再生の問題を確認できます。

生成されたトーンやノイズは、入力音を置き換えるのではなく、現在の音声経路にミックスされます。特に音楽を再生中に有効化する場合は、先に Volume を下げてください。

### 特徴

- 複数の波形タイプ：
  - シンプルなトーン確認に使える純粋な正弦波
  - 豊かな倍音を持つ矩形波
  - より柔らかい倍音を持つ三角波
  - 明るい音色ののこぎり波
  - インパルス応答やタイミングの確認に使える、一定間隔の1サンプルインパルス
  - スピーカー/ヘッドホンの広帯域チェックに使えるホワイトノイズ
  - より滑らかで自然なバランスのピンクノイズ
- 断続的なトーンやノイズバーストを出せるパルス動作モード

### パラメータ

- **Frequency (Hz)** - 生成するトーンの高さを調整します（20 Hzから96 kHz）。
  - 低い周波数: 深い低音
  - 中くらいの周波数: 音楽でよく使われる帯域
  - 高い周波数: 安全な音量で慎重に使用してください。
  - 正弦波、矩形波、三角波、のこぎり波にのみ適用されます。Impulse、ホワイトノイズ、ピンクノイズでは無効です。
  - 実際に出力できる高周波は現在のオーディオサンプルレートに依存します。使用可能なナイキスト周波数を超えるトーンはミュートされます。
- **Volume (dB)** - 出力レベルを調整します（-96 dBから0 dB）。
  - 小さい音量から始め、少しずつ上げてください。
  - 大きい値は音が大きくなり、耳が疲れやすくなる場合があります。
- **Panning (L/R)** - ステレオ上の配置を調整します。
  - Center: 左右両チャンネルに同じ量で出力
  - Left/Right: チャンネルの配線や左右バランスの確認
- **Waveform Type** - 信号の種類を選択します。
  - Sine: クリーンな基準トーン
  - Square: 奇数倍音が豊富
  - Triangle: より柔らかい倍音構成
  - Sawtooth: 幅広い倍音を含む波形
  - Impulse: 現在のオーディオサンプルレートに基づく1サンプルの最大振幅信号を、Interval ごとに生成します。Frequency は影響しません。
  - White Noise: 1 Hzあたりのエネルギーが均一。Frequency は影響しません。
  - Pink Noise: 1オクターブあたりのエネルギーが均一。Frequency は影響しません。
- **Mode** - 信号の生成パターンを設定します。
  - Continuous: 標準的な連続信号生成
  - Pulsed: タイミングを調整できる断続信号
  - Impulse では常に Pulsed が使われ、Continuous は無効になります。
- **Interval (ms)** - パルスモードでバースト同士の間隔を設定します（100-2000 ms、10 msステップ）。
  - 短い間隔: 素早いパルスの連続
  - 長い間隔: 間を空けたパルス
  - Impulse を含め、Mode が Pulsed の場合に有効です。
- **Width (ms)** - パルスモードでのパルスのランプ時間を設定します（2-100 ms、Interval の半分まで、1 msステップ）。
  - 各パルスのフェードイン/フェードアウト時間を制御します。
  - 生成されるパルスはおよそ Width の2倍の長さになり、一定音量で保持される区間はありません。
  - 短い Width: 立ち上がりと立ち下がりが鋭いパルス
  - 長い Width: より滑らかなパルスの変化
  - Mode が Pulsed の場合にのみ有効です。Impulse は常に1サンプル幅のため無効になります。

### 使用例

1. スピーカーやヘッドホンの確認
   - 基本的な周波数再生を確認する：
     * 低い周波数から高い周波数まで正弦波をゆっくり動かす。
     * 音が聞こえにくくなる場所や歪む場所を確認する。
   - ビビり音、うなり、耳につく共鳴を探す：
     * まず低い Volume で使う。
     * 一度にひとつの周波数帯を確認する。
   - 左右の出力を比較する：
     * Panning を左端、右端に振る。
     * 期待したスピーカーやヘッドホン側から鳴っているか確認する。

2. チャンネルと音量バランス
   - ステレオの定位を確認する：
     * 中央に置いた正弦波またはピンクノイズを使う。
     * 音が中央に感じられるか確認する。
   - 左右の音量差を比べる：
     * 同じ Volume のまま左右それぞれに振る。
     * 片側が大きく感じる場合は再生環境側を調整する。
   - プラグインチェーンの挙動を確認する：
     * Oscillator をほかのエフェクトの前後に置き、単純な信号がどう変化するかを聴く。

3. 部屋や机まわりの共鳴の簡易確認
   - 目立つ低音の膨らみやビビりを探す：
     * 安全な音量で低い正弦波を使う。
     * リスニング位置の周辺で、強く鳴る場所や抜ける場所を確認する。
   - 振動しやすい物を確認する：
     * 低域から低中域をゆっくり動かす。
     * 強くビビるものがあればすぐに Volume を下げる。

4. ノイズバランスの確認
   - 広い帯域の安定した基準としてピンクノイズを使う：
     * 左右差や音色の偏りが大きくないか聴く。
     * 快適な音量に保ち、大きな音量で長時間鳴らさない。
   - より明るい広帯域信号が必要な場合だけホワイトノイズを使う。

5. パルス信号の確認
   - 短いバーストを識別しやすくするためにパルスモードを使う：
     * Interval を長くすると各バーストを個別に聴き取りやすくなります。
     * Width を短くすると開始と停止が鋭くなります。
     * 音量を変えて挙動を比較します。

6. インパルス応答とタイミングの確認
   - Impulse を選ぶと、Interval で設定した間隔ごとに1サンプルの過渡信号を生成できます：
     * Interval を長くすると、反射音やエフェクトの残響を分離して確認しやすくなります。
     * システムやプラグインチェーンのインパルス応答を調べる場合は、出力を録音して解析します。
     * インパルスはピークが鋭く広い周波数成分を含むため、低い Volume から始めてください。

注意: Oscillator はテスト信号ジェネレーターです。低い Volume から始めて徐々に上げ、機器の損傷や聴覚疲労につながる大音量や高周波トーンは避けてください。

## SFZ Note Player

SFZ Note Player は入力音からノートを検出し、取り込んだ SFZ 音源で鳴らします。ピアノの SFZ で曲の音をなぞったり、別の楽器を原音に重ねたりできます。複数の音を同時に推定する機能は、正確な採譜ではなく、聴いて楽しんだり音を重ねたりするためのものです。音の密集したミックスでは、取りこぼしや余分な発音が起こることがあります。

### 音質調整ガイド

- **音源を取り込んで読み込む**: **SFZ Library…** を押し、**フォルダーを取り込む…** で `.sfz` 定義ファイルとサンプルファイルを含むフォルダー（または `.bank.xml`、`Programs`、`Samples` がそろった ARIA バンクのフォルダー）を追加して、音源の横にある **読み込む** を押します。デスクトップ版では元のファイルをその場で読み込みます。Web 版では音源を端末内に保存するため、**ファイルを取り込む…** では音源が必要とするサンプルなどのファイルもすべて含めてください。使用中の音源は削除できません。
- **試聴して原音と混ぜる**: まず **Dry: 0%**、**Wet: 100%** にして SFZ 音源だけを聴き、**Dry** を上げて原音を重ねます。SFZ 音源のアタックが原音とそろうように **Timing**（−100～+100 ms）を調整します（0 ms のとき、原音はノート検出に合わせて Classic で約 90 ms、Event で約 230 ms 遅らせてあります）。
- **音域と声部を絞る**: 確信度の高い音だけを鳴らすには **Threshold** を上げ、**Lowest Note** と **Highest Note** で音域を狭めます。1 本の旋律だけを追うなら、**Lowest**（ベースライン）または **Highest**（最上声の旋律）だけを有効にします。Note Spectrogram に色付きの線が出ていても、**Threshold** と音域の制限がかかるため、鳴るとは限りません。
- **音色とオクターブを整える**: **Octave**（−2～+2）で旋律を 1 オクターブ下や上に重ねられます。**Sample Shift**（−6～+6 半音）を使うと、隣の音に割り当てられたサンプルを検出した音の高さに戻して鳴らし、音色を暗めや明るめに変えられます。

### パラメータ

- **SFZ** - **SFZ Library…** を開き、音源の取り込み、検索、並べ替え、読み込み、削除を行います（**Clear** は現在の音源をライブラリから削除せずに読み込みだけを解除します）。
- **Detection**：
  - **Classic (Low Latency)**（既定値）: 遅延の小さい検出方式です（原音の遅延は約 90 ms）。**Threshold** と **Retrigger Drop** を使います。
  - **Event (+140 ms)**: Note Spectrogram と同じオンセット/イベント検出器を使います（原音の遅延は約 230 ms、CPU 負荷は高め。**Threshold** と **Retrigger Drop** は無効）。チェーンの手前にある有効な Note Spectrogram が同じ入力を同じ音域で解析していて、その間で音声が変化しない場合は、Note Spectrogram の **Onsets**、**Instrument** の色表示、**Highlight** のいずれかが有効なら、その解析を共有して負荷を減らします。それ以外の場合は、SFZ Note Player が独自に解析します。
- **Color** - **Normal**（テーマのグラフ色）または **Note Colors**（Note Spectrogram と同じ音名ごとの色）。
- **Threshold**（0.01～1、既定値 0.75）- Classic モードでの検出の確信度のしきい値です。
- **Retrigger Drop (dB)**（1～96 dB、既定値 40 dB）- Classic モードで、B5 より上の持続音を鳴らし直すのに必要な音量の低下量です。下がったあと、音量が再び 6 dB 以上上がる必要があります。大きくすると持続中の余計な鳴らし直しが減り、小さくすると同じ音の連打を追いやすくなります。B5 以下では、検出したアタックでそのまま新しい音を鳴らします。
- **Note Hold (ms)**（0～100 ms、既定値 50 ms）- 音を止める前に、検出の短い途切れをつなぎます。
- **Velocity 1 Level / Velocity 127 Level (dB)**（-96～0 dB / -60～+24 dB、既定値 -60 dB / -10 dB）- MIDI ベロシティ 1～127 に対応させる入力レベルの範囲です。下げるほど、同じ入力でも強いベロシティになります。
- **Lowest Note / Highest Note**（A0～C8、既定値 E1～G6）- 音高を検出する範囲です。
- **Highest / Middle / Lowest** - 同時に検出した音のうち、どれを鳴らすかを選びます（最上声の旋律、内声、ベースライン。既定ではすべて有効）。
- **Octave**（-2～+2、既定値 0）- 新しく鳴らす SFZ 音源の音をオクターブ単位で移調します。
- **Sample Shift**（-6～+6 半音、既定値 0）- 選ぶサンプル領域をずらし、その分だけ逆方向に音程を補正して目的の音高を保ちます。正の値では高い音のサンプルを遅く再生し（+1 では、検出した C4 に C#4 のサンプルを C4 の高さで使います）、負の値では低い音のサンプルを速く再生します。
- **Max Voices**（1～128、既定値 32）- 同時に鳴らせるサンプルの最大数です（リリースの余韻を含みます）。大きくするほど重なった音を多く残せますが、処理が増えます。
- **Dry (%)** / **Wet (%)**（0～100%、既定値 20% / 100%）- 遅延を合わせた原音と SFZ 音源の音量を個別に設定します。
- **Timing (ms)**（-100～+100 ms、既定値 0 ms）- 原音と SFZ 音源のタイミングを微調整します。負の値では原音がさらに遅れ、正の値では SFZ 音源が遅れます。
- **Output Gain (dB)**（-60～+12 dB、既定値 0 dB）- 最終的な出力レベルを調整します。

### 発音表示と注意事項

- **操作できる鍵盤とベロシティバー**: 鍵盤は **Lowest Note**～**Highest Note** の範囲で、鳴っている音をリリースの余韻も含めて点灯します。点灯する鍵は **Octave** に追従し、**Sample Shift** は音色を変えるだけで点灯位置を動かしません。各バーは発音時のベロシティ（1～127）の高さから始まり、音が止んだ後も時間とともに下がります。**Color** を切り替えても色が変わるだけで、下がる途中のバーは元に戻りません。**Voices / Max Voices** はリリース中も含めたサンプルの発音数です。
- **試聴**: 鍵盤やベロシティの部分をクリックまたはドラッグすると、読み込んだ SFZ 音源を直接鳴らせます。鍵盤ではベロシティ 100、ベロシティの部分では触れた位置の高さに応じたベロシティで鳴ります。試聴では表示どおりの音高で鳴らし、**Octave** は無視しますが、**Sample Shift** は反映されます。
- **容量上限**: 音源の容量上限は既定で **256 MiB** です（**設定 > 環境設定... > 一般** の **SFZ の容量上限** で最大 **1024 MiB** まで変更できます）。上限を超える音源は、鍵盤全体から代表的なサンプルを選んで自動的に読み込みます。Web 版では、上限を上げた後にフォルダーを取り込み直してください。
- **対応する SFZ 機能**: ノートオフ（リリース）、コントローラーイベント、動的なキースイッチを必要とするレイヤーは省かれ、その他の非対応の設定は無視されます。
- **共有とバックアップ**: プリセット、共有リンク、ユーザーデータのバックアップには、音源のサンプルではなく音源への参照が保存されます。別の端末でも使えるように、元の SFZ フォルダーは保管しておいてください。
