# その他のオーディオツール

主要なエフェクトカテゴリーを補完する、専用のオーディオツールとジェネレーターをまとめたものです。スピーカー、ヘッドホン、左右チャンネルのバランス、再生時の挙動を、音楽を聴く前や聴いている途中に確認するために役立ちます。

## プラグイン一覧

- [Oscillator](#oscillator) - スピーカーやヘッドホンの確認に使うテストトーン/ノイズジェネレーター
- [SFZ Note Player](#sfz-note-player) - 検出したノートを取り込んだ SFZ 音源で再生

## Oscillator

リスニング環境を確認するためのテストトーン/ノイズジェネレーターです。小さな音量から使い、スピーカーやヘッドホンの出力、左右の配置、音量バランス、ビビり音、うなり、簡単な周波数再生の問題を確認できます。

生成されたトーンやノイズは、入力音を置き換えるのではなく、現在の音声経路にミックスされます。特に音楽を再生中に有効化する場合は、先に Volume を下げてください。

### 特徴

- 複数の波形タイプ:
  - シンプルなトーン確認に使える純粋な正弦波
  - 豊かな倍音を持つ矩形波
  - より柔らかい倍音を持つ三角波
  - 明るい音色ののこぎり波
  - インパルス応答やタイミングの確認に使える、一定間隔の1サンプルインパルス
  - スピーカー/ヘッドホンの広帯域チェックに使えるホワイトノイズ
  - より滑らかで自然なバランスのピンクノイズ
- 断続的なトーンやノイズバーストを出せるパルス動作モード

### パラメータ

- **Frequency (Hz)** - 生成するトーンの高さを調整します（20 Hzから96 kHz）
  - 低い周波数: 深い低音
  - 中くらいの周波数: 音楽でよく使われる帯域
  - 高い周波数: 安全な音量で慎重に使用してください
  - 正弦波、矩形波、三角波、のこぎり波にのみ適用されます。Impulse、ホワイトノイズ、ピンクノイズでは無効です
  - 実際に出力できる高周波は現在のオーディオサンプルレートに依存します。使用可能なナイキスト周波数を超えるトーンはミュートされます
- **Volume (dB)** - 出力レベルを調整します（-96 dBから0 dB）
  - 小さい音量から始め、少しずつ上げてください
  - 大きい値は音が大きくなり、耳が疲れやすくなる場合があります
- **Panning (L/R)** - ステレオ上の配置を調整します
  - Center: 左右両チャンネルに同じ量で出力
  - Left/Right: チャンネルの配線や左右バランスの確認
- **Waveform Type** - 信号の種類を選択します
  - Sine: クリーンな基準トーン
  - Square: 奇数倍音が豊富
  - Triangle: より柔らかい倍音構成
  - Sawtooth: 幅広い倍音を含む波形
  - Impulse: 現在のオーディオサンプルレートに基づく1サンプルの最大振幅信号を、Interval ごとに生成します。Frequency は影響しません
  - White Noise: 1 Hzあたりのエネルギーが均一。Frequency は影響しません
  - Pink Noise: 1オクターブあたりのエネルギーが均一。Frequency は影響しません
- **Mode** - 信号の生成パターンを設定します
  - Continuous: 標準的な連続信号生成
  - Pulsed: タイミングを調整できる断続信号
  - Impulse では常に Pulsed が使われ、Continuous は無効になります
- **Interval (ms)** - パルスモードでバースト同士の間隔を設定します（100-2000 ms、10 msステップ）
  - 短い間隔: 素早いパルスの連続
  - 長い間隔: 間を空けたパルス
  - Impulse を含め、Mode が Pulsed の場合に有効です
- **Width (ms)** - パルスモードでのパルスのランプ時間を設定します（2-100 ms、Interval の半分まで、1 msステップ）
  - 各パルスのフェードイン/フェードアウト時間を制御します
  - 生成されるパルスはおよそ Width の2倍の長さになり、一定音量で保持される区間はありません
  - 短い Width: 立ち上がりと立ち下がりが鋭いパルス
  - 長い Width: より滑らかなパルスの変化
  - Mode が Pulsed の場合にのみ有効です。Impulse は常に1サンプル幅のため無効になります

### 使用例

1. スピーカーやヘッドホンの確認
   - 基本的な周波数再生を確認する
     * 低い周波数から高い周波数まで正弦波をゆっくり動かす
     * 音が聞こえにくくなる場所や歪む場所を確認する
   - ビビり音、うなり、耳につく共鳴を探す
     * まず低い Volume で使う
     * 一度にひとつの周波数帯を確認する
   - 左右の出力を比較する
     * Panning を左端、右端に振る
     * 期待したスピーカーやヘッドホン側から鳴っているか確認する

2. チャンネルと音量バランス
   - ステレオの定位を確認する
     * 中央に置いた正弦波またはピンクノイズを使う
     * 音が中央に感じられるか確認する
   - 左右の音量差を比べる
     * 同じ Volume のまま左右それぞれに振る
     * 片側が大きく感じる場合は再生環境側を調整する
   - プラグインチェーンの挙動を確認する
     * Oscillator をほかのエフェクトの前後に置き、単純な信号がどう変化するかを聴く

3. 部屋や机まわりの共鳴の簡易確認
   - 目立つ低音の膨らみやビビりを探す
     * 安全な音量で低い正弦波を使う
     * リスニング位置の周辺で、強く鳴る場所や抜ける場所を確認する
   - 振動しやすい物を確認する
     * 低域から低中域をゆっくり動かす
     * 強くビビるものがあればすぐに Volume を下げる

4. ノイズバランスの確認
   - 広い帯域の安定した基準としてピンクノイズを使う
     * 左右差や音色の偏りが大きくないか聴く
     * 快適な音量に保ち、大きな音量で長時間鳴らさない
   - より明るい広帯域信号が必要な場合だけホワイトノイズを使う

5. パルス信号の確認
   - 短いバーストを識別しやすくするためにパルスモードを使う
     * Interval を長くすると各バーストを個別に聴き取りやすくなります
     * Width を短くすると開始と停止が鋭くなります
     * 音量を変えて挙動を比較します

6. インパルス応答とタイミングの確認
   - Impulse を選ぶと、Interval で設定した間隔ごとに1サンプルの過渡信号を生成できます
     * Interval を長くすると、反射音やエフェクトの残響を分離して確認しやすくなります
     * システムやプラグインチェーンのインパルス応答を調べる場合は、出力を録音して解析します
     * インパルスはピークが鋭く広い周波数成分を含むため、低い Volume から始めてください

注意: Oscillator はテスト信号ジェネレーターです。低い Volume から始めて徐々に上げ、機器の損傷や聴覚疲労につながる大音量や高周波トーンは避けてください。

## SFZ Note Player

SFZ Note Player は入力音からノートを検出し、選択した SFZ 音源でその音を鳴らします。手持ちのピアノ SFZ で曲の音をなぞったり、別の楽器の音を原音に重ねたりできます。複数の音を同時に推定するため、特に音の密集した曲では取りこぼしや誤検出があります。

音程の変更やサンプルレートの変換では、折り返しノイズを自動的に抑えます。

**Retrigger Drop** で、同じ音の検出が続いている間に再発音する条件を調整できます。検出と **Note Hold** の保持期間が終わってから同じ音を再び検出すると、新しい音として発音します。

### 音質調整ガイド

Electron 版では **Select SFZ Folder…** を押し、SFZ ファイル、サンプル、インクルードファイルを含む音源のフォルダを選びます。複数の SFZ ファイルが見つかった場合は音源を選んで **Select** を押します。このフォルダ内のファイルは、音源を読み込むたびに直接読み取ります。**Remove** は一覧から登録を外し、元のファイルは削除しません。

Web 版では **Import Folder…** を押し、SFZ ファイルとサンプルを含むフォルダを選びます。複数の SFZ がある場合は一つを選んで **Import** を押します。保存した音源は **SFZ** で選択でき、**Remove** で選択中のバンクを端末から削除できます。

まず **Dry** を 0%、**Wet** を 100% にして音源だけを聴き、**Dry** を上げて原音を重ねます。**Octave** を -1 にすると原音に低い音を、+1 にすると高い音を重ねられます。**Threshold** を上げると、より確実に検出された音だけを拾いやすくなります。**Lowest Note** と **Highest Note** で聴きたい音域に絞れます。音源が常に弱すぎる、または強すぎる場合は **Velocity 1 Level** と **Velocity 127 Level** を調整し、最後に **Output Gain** で音量を揃えます。

低い旋律を追うには **Lowest** だけを、高い旋律を追うには **Highest** だけを有効にします。

持続音が意図せず何度も鳴る場合は、**Retrigger Drop** を既定値の 40 dB から上げてください。96 dB にすると、音量変化による再発音を強く抑えられます。同じ音を繰り返し弾く演奏を拾いたい場合は下げます。

ノートを長めに保ち、検出の短い途切れをつなぐには **Note Hold** を上げます。100 ms にすると、さらに 100 ms 維持してからノートオフします。

**Note Spectrogram** に音が表示されていても、**Threshold** や **Lowest Note / Highest Note** の条件を満たさなければ発音しません。低い音や高い音が鳴らないときは音域の設定を確認し、**Threshold** を下げて試してください。また、**Octave** を適用した後の音にSFZ音源が対応しているか確認してください。

### パラメータ

- **SFZ**: 音源を名前で選びます。手動で音源を選択・取り込んだ最初の読み込みだけ問題をダイアログで案内し、自動の再読み込みでは表示しません。
- **Threshold**: 検出に必要な確信度の下限（0.01～1、既定値 0.75）です。上げると不要な音を減らせますが、小さな音や不明瞭な音を拾いにくくなります。
- **Retrigger Drop (dB)**: 再発音に必要な、入力ノートのピークからの音量低下量です（1～96 dB、既定値 40 dB）。この量以上下がった後、6 dB 以上上がると再発音します。上げると持続音の再発音を抑え、下げると同じ音を繰り返し弾く演奏を拾いやすくなります。
- **Note Hold (ms)**: 検出が終わってからノートオフするまで、追加で音を保持する時間です（0～100 ms、既定値 50 ms）。保持中に同じ音が戻ると、そのままつなげます。音源の音量変化やサンプルの終端は引き続き適用されます。
- **Velocity 1 Level / Velocity 127 Level (dB)**: 最も弱い／強い演奏ベロシティに対応する入力ノートのレベルです（既定値 -60 dB / -10 dB）。値を下げると、同じ入力でも強いベロシティになります。二つの値の間隔によって、入力レベルの変化に対するベロシティの広がりが変わります。
- **Lowest Note / Highest Note**: 検出する最低／最高ノートです（設定範囲 A0～C8 / MIDI 21～108、既定値 E1 / G6）。音名で表示され、範囲外の音は無視します。
- **Highest / Middle / Lowest**: Octave を適用する前の低い旋律、中間の音、高い旋律を選びます（既定ではすべて有効）。Middle は現在検出されている最低音と最高音の間にある音を選びます。低い旋律と高い旋律は、それまでの音高を追うことで急な切り替わりを抑えます。検出音が1つなら両方に含まれます。選択から外れた音は自然に減衰し、すべて無効にすると新しい音を鳴らさなくなります。
- **Octave**: 新しく鳴る SFZ 音源の音を、1 オクターブ刻みで -2～+2 オクターブ移動します（既定値 0）。負の値で低く、正の値で高く鳴らします。入力の検出範囲と、すでに鳴っている音は変わりません。
- **Max Voices**: 同時に再生するサンプルの数を制限します。大きくすると重なった音やリリース音を残しやすくなりますが、処理負荷が増えます。小さくすると古い音が早く置き換わります。
- **Dry (%)**: 原音の音量です（0～100%、既定値 20%）。0% で消音し、100% で元の音量を保ちます。
- **Wet (%)**: SFZ 音源の音量です（0～100%、既定値 100%）。0% で消音し、100% で音源本来の音量を保ちます。Dry と Wet は独立して調整できます。
- **Timing (ms)**: 原音と SFZ 音源の発音タイミングを調整します（-100～+100 ms、既定値 0）。負の値では原音をさらに遅らせ、正の値では音源を遅らせます。聴きながら調整し、音の立ち上がりを近づけてください。
- **Output Gain (dB)**: 原音と音源を混ぜた後の音量を調整します。

**Timing** が 0 ms のとき、原音は音符検出の計算と補正待ちに合わせ、約 **80 ms** 遅らせます。解析の周期や音源のアタックにより、発音のタイミングには小さな差が残ることがあります。手前に有効な **Note Spectrogram** があり、音域、入力バス、チャンネル選択が同じで、間の音が変更されていなければ解析を共有して処理負荷を減らせます。

読み込みは一般的な SFZ の選択条件、ピッチ、音量、パン、ループ、音量包絡に対応しています。リリース時の減衰は最低 **0.2 秒**で、SFZ に指定された長い値は維持します。サンプルが先に終わる場合は、そこで音も止まります。コントローラーの範囲条件は初期値で判定し、SFZ の `set_ccN` による指定があれば優先します。たとえば初期状態でペダルを離しているピアノでは、そのときのサンプルを使い、ペダルを踏んだときの層を重ねません。音源に既定のキースイッチ奏法が指定されていれば、その奏法を使います。ノートオフ、コントローラーのイベント、演奏中のキースイッチ切り替えなど、未対応の演奏条件が必要な層は省略します。不正な領域は除外し、有効な領域の読み込みは続けます。その他の未対応の音づくり設定は無視します。

容量上限の既定値は **256 MiB** です。**設定 → 一般** の **SFZ の容量上限** で、最大 **1024 MiB（1 GiB）** まで引き上げられます。上限は音源のファイルと、再生用に展開したサンプルの両方に、次回の選択・取り込み・読み込みから適用されます。上限を上げると使用するメモリが増えます。音源全体が上限を超える場合は、演奏できる音域をカバーする代表サンプルで読み込みを試みます。ベロシティによる音量変化は維持し、ベロシティ層やラウンドロビンによる音色の変化は簡略化します。それでも収まらない場合は、小さな音源を選ぶか上限を上げてください。Web 版で省略したサンプルを戻すには、上限を上げた後で元のフォルダを取り込み直してください。サンプルを使う他のエフェクトとも処理用メモリを共有します。

プリセットや共有パイプラインに含まれるのは音源への参照だけで、音源ファイルは含まれません。別の端末では、Electron 版ならその端末の音源フォルダを選び直し、Web 版ならフォルダを取り込んでください。SFZ 音源ファイルはユーザーデータのバックアップにも含まれないため、元の SFZ フォルダを保管してください。
