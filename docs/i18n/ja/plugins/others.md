# その他のオーディオツール

主要なエフェクトカテゴリーを補完する、専用のオーディオツールとジェネレーターをまとめたものです。スピーカー、ヘッドホン、左右チャンネルのバランス、再生時の挙動を、音楽を聴く前や聴いている途中に確認するために役立ちます。

## プラグイン一覧

- [Oscillator](#oscillator) - スピーカーやヘッドホンの確認に使うテストトーン/ノイズジェネレーター
- [SoundFont Note Player](#sfz-note-player) - 検出した音符をSF2/SF3 SoundFontやSFZ音源で再生
- [SoundFont Player](#soundfont-player) - SF2/SF3 SoundFontやSFZ音源でMIDI曲を演奏

## Oscillator

リスニング環境を確認するためのテストトーン/ノイズジェネレーターです。小さな音量から使い、スピーカーやヘッドホンの出力、左右の配置、音量バランス、ビビり音、うなり、簡単な周波数再生の問題を確認できます。

生成されたトーンやノイズは、入力音を置き換えるのではなく、現在の音声経路にミックスされます。特に音楽を再生中に有効化する場合は、先に Volume を下げてください。

### 特徴

- 複数の波形タイプ：
  - シンプルなトーン確認に使える純粋な正弦波
  - 豊かな倍音を持つ矩形波
  - より柔らかい倍音を持つ三角波
  - 明るい音色ののこぎり波
  - インパルス応答やタイミングの確認に使える、一定間隔の1サンプルインパルス
  - スピーカー/ヘッドホンの広帯域チェックに使えるホワイトノイズ
  - より滑らかで自然なバランスのピンクノイズ
- 断続的なトーンやノイズバーストを出せるパルス動作モード

### パラメータ

- **Frequency (Hz)** - 生成するトーンの高さを調整します（20 Hzから96 kHz）。
  - 低い周波数: 深い低音
  - 中くらいの周波数: 音楽でよく使われる帯域
  - 高い周波数: 安全な音量で慎重に使用してください。
  - 正弦波、矩形波、三角波、のこぎり波にのみ適用されます。Impulse、ホワイトノイズ、ピンクノイズでは無効です。
  - 実際に出力できる高周波は現在のオーディオサンプルレートに依存します。使用可能なナイキスト周波数を超えるトーンはミュートされます。
- **Volume (dB)** - 出力レベルを調整します（-96 dBから0 dB）。
  - 小さい音量から始め、少しずつ上げてください。
  - 大きい値は音が大きくなり、耳が疲れやすくなる場合があります。
- **Panning (L/R)** - ステレオ上の配置を調整します。
  - Center: 左右両チャンネルに同じ量で出力
  - Left/Right: チャンネルの配線や左右バランスの確認
- **Waveform Type** - 信号の種類を選択します。
  - Sine: クリーンな基準トーン
  - Square: 奇数倍音が豊富
  - Triangle: より柔らかい倍音構成
  - Sawtooth: 幅広い倍音を含む波形
  - Impulse: 現在のオーディオサンプルレートに基づく1サンプルの最大振幅信号を、Interval ごとに生成します。Frequency は影響しません。
  - White Noise: 1 Hzあたりのエネルギーが均一。Frequency は影響しません。
  - Pink Noise: 1オクターブあたりのエネルギーが均一。Frequency は影響しません。
- **Mode** - 信号の生成パターンを設定します。
  - Continuous: 標準的な連続信号生成
  - Pulsed: タイミングを調整できる断続信号
  - Impulse では常に Pulsed が使われ、Continuous は無効になります。
- **Interval (ms)** - パルスモードでバースト同士の間隔を設定します（100-2000 ms、10 msステップ）。
  - 短い間隔: 素早いパルスの連続
  - 長い間隔: 間を空けたパルス
  - Impulse を含め、Mode が Pulsed の場合に有効です。
- **Width (ms)** - パルスモードでのパルスのランプ時間を設定します（2-100 ms、Interval の半分まで、1 msステップ）。
  - 各パルスのフェードイン/フェードアウト時間を制御します。
  - 生成されるパルスはおよそ Width の2倍の長さになり、一定音量で保持される区間はありません。
  - 短い Width: 立ち上がりと立ち下がりが鋭いパルス
  - 長い Width: より滑らかなパルスの変化
  - Mode が Pulsed の場合にのみ有効です。Impulse は常に1サンプル幅のため無効になります。

### 使用例

1. スピーカーやヘッドホンの確認
   - 基本的な周波数再生を確認する：
     * 低い周波数から高い周波数まで正弦波をゆっくり動かす。
     * 音が聞こえにくくなる場所や歪む場所を確認する。
   - ビビり音、うなり、耳につく共鳴を探す：
     * まず低い Volume で使う。
     * 一度にひとつの周波数帯を確認する。
   - 左右の出力を比較する：
     * Panning を左端、右端に振る。
     * 期待したスピーカーやヘッドホン側から鳴っているか確認する。

2. チャンネルと音量バランス
   - ステレオの定位を確認する：
     * 中央に置いた正弦波またはピンクノイズを使う。
     * 音が中央に感じられるか確認する。
   - 左右の音量差を比べる：
     * 同じ Volume のまま左右それぞれに振る。
     * 片側が大きく感じる場合は再生環境側を調整する。
   - プラグインチェーンの挙動を確認する：
     * Oscillator をほかのエフェクトの前後に置き、単純な信号がどう変化するかを聴く。

3. 部屋や机まわりの共鳴の簡易確認
   - 目立つ低音の膨らみやビビりを探す：
     * 安全な音量で低い正弦波を使う。
     * リスニング位置の周辺で、強く鳴る場所や抜ける場所を確認する。
   - 振動しやすい物を確認する：
     * 低域から低中域をゆっくり動かす。
     * 強くビビるものがあればすぐに Volume を下げる。

4. ノイズバランスの確認
   - 広い帯域の安定した基準としてピンクノイズを使う：
     * 左右差や音色の偏りが大きくないか聴く。
     * 快適な音量に保ち、大きな音量で長時間鳴らさない。
   - より明るい広帯域信号が必要な場合だけホワイトノイズを使う。

5. パルス信号の確認
   - 短いバーストを識別しやすくするためにパルスモードを使う：
     * Interval を長くすると各バーストを個別に聴き取りやすくなります。
     * Width を短くすると開始と停止が鋭くなります。
     * 音量を変えて挙動を比較します。

6. インパルス応答とタイミングの確認
   - Impulse を選ぶと、Interval で設定した間隔ごとに1サンプルの過渡信号を生成できます：
     * Interval を長くすると、反射音やエフェクトの残響を分離して確認しやすくなります。
     * システムやプラグインチェーンのインパルス応答を調べる場合は、出力を録音して解析します。
     * インパルスはピークが鋭く広い周波数成分を含むため、低い Volume から始めてください。

注意: Oscillator はテスト信号ジェネレーターです。低い Volume から始めて徐々に上げ、機器の損傷や聴覚疲労につながる大音量や高周波トーンは避けてください。

## SoundFont Note Player

<a id="sfz-note-player"></a>

SoundFont Note Player は入力音からノートを検出し、取り込んだ SF2/SF3/SFZ 音源で鳴らします。ピアノの SFZ で曲の音をなぞったり、別の楽器を原音に重ねたりできます。複数の音を同時に推定する機能は、正確な採譜ではなく、聴いて楽しんだり音を重ねたりするためのものです。音の密集したミックスでは、取りこぼしや余分な発音が起こることがあります。

### 音質調整ガイド

- **音源を取り込んで読み込む**: **SoundFont Library…** を開き、**ファイルを取り込む…** で `.sf2` / `.sf3` ファイルを取り込んで **読み込む** を押し、**Preset** で音色を選びます。SFZでは、**フォルダーを取り込む…** で定義ファイルとサンプルをまとめて追加します（ARIAバンクの場合は、`.bank.xml`、`Programs`、`Samples` がそろったフォルダー全体）。デスクトップ版では元のファイルをその場で読み込み、Web版では取り込んだ音源を端末内に保存します。SFZを **ファイルを取り込む…** で追加するときは、必要なサンプルなどのファイルもすべて含めてください。使用中の音源は削除できません。
- **試聴して原音と混ぜる**: まず **Dry: 0%**、**Wet: 100%** にして SFZ 音源だけを聴き、**Dry** を上げて原音を重ねます。SFZ 音源のアタックが原音とそろうように **Timing**（−100～+100 ms）を調整します（0 ms のとき、原音はノート検出に合わせて Classic で約 90 ms、Event で約 230 ms 遅らせてあります）。
- **音域と声部を絞る**: 確信度の高い音だけを鳴らすには **Threshold** を上げ、**Lowest Note** と **Highest Note** で音域を狭めます。1 本の旋律だけを追うなら、**Lowest**（ベースライン）または **Highest**（最上声の旋律）だけを有効にします。Note Spectrogram に色付きの線が出ていても、**Threshold** と音域の制限がかかるため、鳴るとは限りません。
- **音色とオクターブを整える**: **Octave**（−2～+2）で旋律を 1 オクターブ下や上に重ねられます。**Sample Shift**（−6～+6 半音）を使うと、隣の音に割り当てられたサンプルを検出した音の高さに戻して鳴らし、音色を暗めや明るめに変えられます。

### パラメータ

- **SoundFont** - **SoundFont Library…** を開き、音源の取り込み、検索、並べ替え、読み込み、削除を行います（**Clear** は現在の音源をライブラリから削除せずに読み込みだけを解除します）。
- **Preset**：SF2/SF3コレクションで検出した音符を鳴らす音色を選びます。**Default** は最初の演奏可能な音色を使います。SFZ音源では表示されません。
- **Detection**：
  - **Classic (Low Latency)**（既定値）: 遅延の小さい検出方式です（原音の遅延は約 90 ms）。**Threshold** と **Retrigger Drop** を使います。
  - **Event (+140 ms)**: Note Spectrogram と同じオンセット/イベント検出器を使います（原音の遅延は約 230 ms、CPU 負荷は高め。**Threshold** と **Retrigger Drop** は無効）。チェーンの手前にある有効な Note Spectrogram が同じ入力を同じ音域で解析していて、その間で音声が変化しない場合は、Note Spectrogram の **Onsets**、**Instrument** の色表示、**Highlight** のいずれかが有効なら、その解析を共有して負荷を減らします。それ以外の場合は、SoundFont Note Player が独自に解析します。
- **Color** - **Normal**（テーマのグラフ色）または **Note Colors**（Note Spectrogram と同じ音名ごとの色）。
- **Threshold**（0.01～1、既定値 0.75）- Classic モードでの検出の確信度のしきい値です。
- **Retrigger Drop (dB)**（1～96 dB、既定値 40 dB）- Classic モードで、B5 より上の持続音を鳴らし直すのに必要な音量の低下量です。下がったあと、音量が再び 6 dB 以上上がる必要があります。大きくすると持続中の余計な鳴らし直しが減り、小さくすると同じ音の連打を追いやすくなります。B5 以下では、検出したアタックでそのまま新しい音を鳴らします。
- **Note Hold (ms)**（0～100 ms、既定値 50 ms）- 音を止める前に、検出の短い途切れをつなぎます。
- **Velocity 1 Level / Velocity 127 Level (dB)**（-96～0 dB / -60～+24 dB、既定値 -60 dB / -10 dB）- MIDI ベロシティ 1～127 に対応させる入力レベルの範囲です。下げるほど、同じ入力でも強いベロシティになります。
- **Lowest Note / Highest Note**（A0～C8、既定値 E1～G6）- 音高を検出する範囲です。
- **Highest / Middle / Lowest** - 同時に検出した音のうち、どれを鳴らすかを選びます（最上声の旋律、内声、ベースライン。既定ではすべて有効）。
- **Octave**（-2～+2、既定値 0）- 新しく鳴らす SFZ 音源の音をオクターブ単位で移調します。
- **Sample Shift**（-6～+6 半音、既定値 0）- 選ぶサンプル領域をずらし、その分だけ逆方向に音程を補正して目的の音高を保ちます。正の値では高い音のサンプルを遅く再生し（+1 では、検出した C4 に C#4 のサンプルを C4 の高さで使います）、負の値では低い音のサンプルを速く再生します。
- **Max Voices**（1～128、既定値 32）- 同時に鳴らせるサンプルの最大数です（リリースの余韻を含みます）。大きくするほど重なった音を多く残せますが、処理が増えます。
- **Dry (%)** / **Wet (%)**（0～100%、既定値 20% / 100%）- 遅延を合わせた原音と SFZ 音源の音量を個別に設定します。
- **Timing (ms)**（-100～+100 ms、既定値 0 ms）- 原音と SFZ 音源のタイミングを微調整します。負の値では原音がさらに遅れ、正の値では SFZ 音源が遅れます。
- **Output Gain (dB)**（-60～+12 dB、既定値 0 dB）- 最終的な出力レベルを調整します。

### Instrument Details

主要な設定の下にある **Instrument Details** を開くと、SFZ音源に記載された鍵盤、MIDIコントローラー（**CC**）、出力、グループ、レイヤー、キースイッチのラベルを確認できます。音源内の割り当てを説明する表示で、追加の操作項目ではありません。ラベル付きのキースイッチが有効なときは、**Keyswitch** に各チャンネルで選択中の奏法が表示されます。音源に画像が指定されていれば、その画像も表示します。複数の画像が指定されている場合は、最後の指定を使います。

### 発音表示と注意事項

- **操作できる鍵盤とベロシティバー**: 鍵盤は **Lowest Note**～**Highest Note** の範囲で、鳴っている音をリリースの余韻も含めて点灯します。点灯する鍵は **Octave** に追従し、**Sample Shift** は音色を変えるだけで点灯位置を動かしません。各バーは発音時のベロシティ（1～127）の高さから始まり、音が止んだ後も時間とともに下がります。**Color** を切り替えても色が変わるだけで、下がる途中のバーは元に戻りません。**Voices / Max Voices** はリリース中も含めたサンプルの発音数です。
- **試聴**: 鍵盤やベロシティの部分をクリックまたはドラッグすると、読み込んだ SFZ 音源を直接鳴らせます。鍵盤ではベロシティ 100、ベロシティの部分では触れた位置の高さに応じたベロシティで鳴ります。試聴では表示どおりの音高で鳴らし、**Octave** は無視しますが、**Sample Shift** は反映されます。
- **容量上限**：音源とサンプルキャッシュに使うメモリは既定で **256 MiB** です。**設定 > 環境設定... > 一般** の **SoundFont の容量上限** で最大 **1024 MiB** に変更できます。必要な部分を読み出す元のファイルは、この上限より大きくても使えます。上限により読み込めない場合は、上限を上げるか小さな音源を選んでください。
- **対応する SFZ 機能**: SoundFont Note Playerは検出した音の立ち上がりに従って発音します。コントローラー条件やキースイッチには音源の初期設定を使い、MIDI曲のイベントには追従しません。MIDI曲や演奏中のコントロール変化にはSoundFont Playerを使ってください。未対応の設定を使う音源や、必要なサンプルが不足している音源は読み込めません。ファイルを確認するか、別の音源を選んでください。
- **共有とバックアップ**: プリセット、共有リンク、ユーザーデータのバックアップには、音源のサンプルではなく音源への参照が保存されます。別の端末でも使えるように、元の SFZ フォルダーは保管しておいてください。

## SoundFont Player

SF2/SF3 SoundFontコレクションやSFZ音源でMIDI曲を演奏し、後段のエフェクトで音を調整できます。入力音声はそのまま通過し、この位置で音源の音が加算されます。

### 使い始めるには

`.mid` ファイルを開き、SoundFont Playerを追加して **SoundFont Library…** を開きます。`.sf2` / `.sf3` ファイル、またはサンプルファイルを含む `.sfz` 音源を取り込み、**読み込む** を選びます。デスクトップ版は元のファイルを読み込み、Web版は取り込んだファイルを端末内に保存します。**Instrument Level** は0 dBから始め、合成した音が大きすぎる場合は下げてください。

SF3（.sf3）はサンプルを圧縮したSoundFontです。SF2と同じ手順で取り込み、音色を選べます。SF3の再生には、Vorbisの再生に対応したブラウザが必要です。再生できない場合はSF2 SoundFontを選ぶか、対応ブラウザを使ってください。

**SoundFont Library…** では音源の取り込み、検索、読み込み、削除を行います。**Clear** はライブラリから削除せずに音源の読み込みを解除します。使用中の音源は削除できません。曲の途中で音源を交換しても、新しい音源の準備中はMIDIの進行が続きます。準備ができると、その時点のコントローラー設定を使い、それ以降のMIDIイベントから発音します。過去の音符は鳴り直しません。

### MIDI Mixer

**MIDI Mixer** タブには、16のMIDIチャンネルごとに1行ずつ表示されます。SF2/SF3コレクションでは各チャンネルに異なる音色を使えます。Bank SelectとProgram Changeメッセージが音色を選び、初期状態ではチャンネル10にドラムバンクを使います。GS/XGのドラムパート指定で、ほかのチャンネルも打楽器にしたり、メロディー用に戻したりできます。Program Changeは、読み込んだSoundFontにあるドラムキットを選びます。SFZ音源は自身の音の割り当てを使います。

Program Changeを受け取る前は、音色が収録されていれば、メロディー用チャンネルにはバンク0のプログラム1、チャンネル10には標準ドラムキットが割り当てられます。指定された音色がSF2/SF3にない場合、メロディー用チャンネルはバンク0の同じプログラム、次にバンク0のプログラム1を使います。ドラム用チャンネルは標準ドラムキットを使います。**Patch** には実際に使われる音色が表示されます。代わりの音色もない場合や **Automatic Fallback** がオフの場合、そのチャンネルからは音が出ません。

- **Patch**：読み込んだSF2/SF3コレクションから、そのチャンネルの音色を名前で選びます。変更後に始まる音から新しい音色を使い、すでに鳴っている音は元の音色を保ちます。
- **Notes**：各チャンネルの鍵盤は、MIDI の Note On で点灯し、Note Off で消えます。サステインペダルや余韻で音が続いていても、Note Off 後は点灯しません。**Voices** は、余韻を含めて実際に発音しているサンプル数と **Max Voices** の上限を示します。1つの音符に複数のサンプルを使う場合もあります。**Max Voices** に達して新しい音のために鳴っている音を止めたときは、**Voices** の表示が3秒間色を変えます。止めた音がリリース中の余韻なら橙色、まだ発音中の音なら赤色です。
- チャンネルの鍵盤をマウス、タッチ、ペンでドラッグすると、ポインターの下にある鍵の音高で、読み込み済みの楽器がそのチャンネルの現在の **Patch** とミキサー設定で鳴ります。別の鍵へ動かしたときや離したときは MIDI の Note Off と同じ扱いになり、前の音は楽器本来のリリースで減衰します。そのためリリースの長い音色では音が重なります。曲や MIDI 入力とは独立して動作するため、再生中の曲に重なって鳴ります。**Mute** がオンのチャンネルは鳴らず、ミキサーの操作が有効な行だけが反応します。
- **Vol.**（CC7、0～127）：チャンネルの音量です。**EXP**（エクスプレッション、CC11、0～127）は、さらに音量を調整する設定です。どちらも上げるほど音量が大きくなり、どちらかを0にすると無音になります。
- **Pan**（CC10、0～127）：左右の定位を調整します。64が中央で、小さくすると左、大きくすると右に寄ります。
- **Rev.**（CC91）／**Cho.**（CC93）：各エフェクトへ送る量を0～127で調整します。上げるほど送る量が増えます。実際の効果は、音源のエフェクト対応や設定によって異なります。
- **Level**：各チャンネルの実際の音声レベルを示します。Vol.、EXP、Pan、Mute／Solo の操作を反映し、共通のリバーブ／コーラスの戻り音は含みません。色付きのバーは音の大きさに追従し、細い線は直近のピークをしばらく保持します。
- **Mute**（**M**）：そのチャンネルを消音します。**Solo**（**S**）をオンにすると、Soloがオンのチャンネルだけを聴けます。曲の各パートを聴き比べるときに使います。

ノブは上下にドラッグするか、選択して矢印キーで調整します。ミキサーでの操作は一時的なもので、プリセット、共有リンク、バックアップには保存されません。Patchやコントローラーの変更は入力MIDIと同じ状態に反映されるため、後から届く同じ種類のMIDIメッセージで上書きされます。MuteやSoloを含むミキサーの操作は、次の曲やGM／GS／XGリセットメッセージで初期化されます。

入力 MIDI で Patch やノブの表示値が変わると、その操作部が短く強調表示されます。

### Settings

**Settings** タブには、保存される再生設定があります。

- **MIDI Channel**：初期設定の **All** では全チャンネルを演奏します。**1–16** を選ぶと、そのチャンネルだけを演奏します。
- **Instrument Level**：音源の音量を-60～+12 dBで調整します（初期値0 dB）。入力音声の音量は変わりません。
- **Max Voices**：余韻を含めて同時に鳴らすサンプル数の上限です。1～1024、初期値256。増やすと重なった音を多く残せますが、処理負荷も増えます。
- **Automatic Fallback**：指定されたSF2/SF3の音色がないとき、上記のとおり利用できる近い音色で代わりに鳴らします（既定はオン）。オフにすると、ない音色を指定したチャンネルは無音になり、SoundFontに足りない音色を見つけやすくなります。
- **Interpolation**：音源のサンプルを音高に合わせて再生する方法を選びます。**FIR (64 taps)** は SF2/SF3 の標準フィルターを使い、SFZ では音源ファイルの品質設定に従います。初期設定の **FIR (32 taps)** は SF2/SF3 の処理負荷を減らせます。ダウンサンプリングが不要なときは32タップを使い、必要なときは折り返し雑音を抑えるためにFIRフィルターを長くします。**Cubic (4 points)** は軽い補間処理を使いますが、折り返し雑音を抑えるローパスフィルターがないため、大きく音高を上げた音や高い倍音が多いサンプルでは折り返し雑音が出ることがあります。FIR と Cubic を選ぶと、SFZ 音源ファイルの品質設定より優先されます。
- **SF2 Compatibility**：SF2/SF3 の音色設定をどう解釈するかを選びます。SFZ 音源には影響しません。**Standard**（初期値）は一般的な SoundFont シンセサイザーや、多くの SoundFont が音作りの前提とする初代の SoundFont 対応ハードウェアと同じ動作です。音色ごとの減衰量（attenuation）の設定を 40% の強さで適用し、仕様が定める既定のベロシティ→フィルター規則は使わないため、弱く弾いた音が自動的にこもることはありません。**SF2.04 Strict** は SoundFont 2.04 仕様の記述どおりに動作します。減衰量を全量適用するため、減衰量が設定された音色は多くの SoundFont の制作者が意図したより小さく鳴り、弱く弾いた音ほどこもった音になります。仕様の記述どおりに解釈したときの SoundFont の鳴り方を確かめたいときに使います。

選択した音源とこれらの設定は通常どおり保存されます。Music Playerの音量とミュートもMIDI音源に反映されます。プリセット、共有リンク、バックアップに保存されるのは音源の参照だけで、サンプルは含みません。デスクトップ版や別の端末でも使えるよう、元の音源ファイルを保管してください。

**Color** は鍵盤表示の色だけを切り替えます。**Normal** はグラフの共通色、**Note Colors** は Note Spectrogram と同じ音高ごとの色、**Channel Colors** は MIDI チャンネルごとの色を使います。色の選択はプリセットには保存されません。

### Instrument Details

読み込んだ音源の概要には、取得できるサンプル数、音色数、元ファイルのサイズ、再生に使うメモリ量を表示します。大きな音源は全体をメモリへ読み込まず、再生に必要なサンプルデータを順次読み出します。そのため、元ファイルのサイズが再生に使うメモリ量を大きく上回ることがあります。

ステータスには、ファイルの読み取り、音源やサンプルキャッシュの準備、準備完了、読み込みエラーを表示します。処理の総量が分かる場合は完了量と総量を示し、分からない段階では割合を示さない進行表示になります。読み込めない場合は、元のファイルを利用できるか確認するか、別の音源を選んでください。先読みが制限されている場合も再生できますが、一部の音の鳴り始めが遅れることがあります。

**Settings** の **Instrument Details** を開くと、SFZ音源に記載された鍵盤、MIDIコントローラー（**CC**）、出力、グループ、レイヤー、キースイッチのラベルを確認できます。音源内の割り当てを説明する表示で、追加の操作項目ではありません。ラベル付きのキースイッチが有効なときは、**Keyswitch** に各チャンネルで選択中の奏法が表示されます。音源に画像が指定されていれば、その画像も表示します。複数の画像が指定されている場合は、最後の指定を使います。

### リアルタイムのMIDI入力

リアルタイムのMIDI演奏は、デスクトップアプリとWeb/PWA版で利用できます。Androidアプリでは対応していませんが、コントローラーマッピングは引き続き利用できます。

MIDIキーボードや仮想MIDIポートから演奏するには、Music Playerを閉じます。**オーディオ設定**で **MIDI デバイスを更新** を押し、求められた場合はMIDIへのアクセスを許可して、**MIDI 入力デバイス**を選んでください。SoundFont Playerには音色を読み込んでおきます。Music Playerが開いている間は、一時停止中でもそちらが優先されます。リアルタイム入力を止めるには **なし** を選びます。音色が未読み込みでもMIDI入力は無音のまま続き、読み込み後のMIDIイベントから音が鳴ります。過去の音符は再演奏されません。ライブ MIDI 入力は **MIDI 出力デバイス**には中継されません。この設定が外部デバイスへ送るのは、Music Playerで再生するMIDIファイルだけです。

デスクトップアプリでは、**ブラウザ** で開いたWeb MIDI対応のサイトも、**EffeTune** という名前のMIDI出力を通じてSoundFont Playerを演奏できます。ページが最初にMIDIを送った時点から、リアルタイムのMIDI入力にはページからのMIDIが使われます。ブラウザのツールバーの **閉じる** をクリックするか、ページを離れるか再読み込みすると、選択中の **MIDI 入力デバイス** に戻ります。

### SFZ音源について

SFZ音源では、音量・音高・音色の時間変化、フィルターや内蔵エフェクトの組み合わせ、サンプルのループや離鍵時の音を設定できます。拍に同期する発音やエフェクトは、MIDI曲のテンポと再生速度に追従します。これらは音源ファイル内の設定です。全体の音を自分で調整したいときは、SoundFont Playerの後段にエフェクトを追加してください。

`amp_veltrack_random` を使うSFZ音源では、新しい音符ごとにベロシティと音量の関係がランダムに変わります。初期値の0では、このランダムな変化は加わりません。MIDIのベロシティそのものを変えるのではなく、演奏の強さが音量にどう反映されるかを変えます。

大きな音源は、設定したメモリ容量の範囲で必要なサンプルデータを読み出します。取り込む際は、定義ファイルと必要なサンプルをそろえてください。埋め込みサンプルや、音源内のエフェクトだけが使うファイルも取り込み対象です。サンプルの内容確認に失敗した場合は、元のファイルに戻すか、音源を取り込み直してください。複数の出力を使う音源には、十分なチャンネル数の出力設定が必要です。

SFZファイルの `load_mode` では、サンプルの保存形式を選べます。0（初期値）は32-bit浮動小数点、1はメモリ使用量を減らす16-bit PCMです。元の音声の精度が16-bitより高い場合、16-bitモードでは精度が下がります。EffeTuneでは、`load_start` と `load_end` を、メモリ内に保持する元サンプルの最初と最後のフレーム位置として扱い、最後のフレームも含めます。範囲を指定したときに開始位置を省略すると0、終了位置を省略するとサンプルの終わりになります。範囲外のデータも必要に応じて読み出すため、再生範囲やループ位置は変わりません。両方とも省略した場合は、自動的なストリーミングを使います。

互換性は音源によって異なり、メーカー独自の動作などには使えないものもあります。対応方針と制限は[SFZ互換性リファレンス](../../../../specifications/sfz/README.md)を参照してください。SoundFont Note Playerも同じ方法で音源を読み込みますが、検出した音符からMIDI曲のコントローラー変化やテンポが得られるわけではありません。
