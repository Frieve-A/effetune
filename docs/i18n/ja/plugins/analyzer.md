# アナライザープラグイン

音楽を目で見て楽しめるプラグインのコレクションです。音のさまざまな側面を表示することで、聴こえている内容を理解しやすくし、リスニング体験をより楽しくインタラクティブにします。

## プラグイン一覧

- [Analog Meter](#analog-meter) - VU・PPM・ピーク・ラウドネスに対応した指針メーターでレベルを表示
- [Chroma Spiral](#chroma-spiral) - 周波数成分を音名とオクターブの螺旋上に表示
- [Level Meter](#level-meter) - デジタル信号レベルとクリッピングの可能性を表示
- [Note Spectrogram](#note-spectrogram) - 推定した音高を時間に沿ったピアノロールで表示
- [Oscilloscope](#oscilloscope) - 波形をリアルタイムで表示
- [Pitch Meter](#pitch-meter) - 1つの基音とチューニングの変化を表示
- [Rhythm Analyzer](#rhythm-analyzer) - テンポ、1拍ごとの発音、各パートの走り・もたりを表示
- [Spectrogram](#spectrogram) - 音楽の変化をカラフルなパターンで表示
- [Spectrum Analyzer](#spectrum-analyzer) - 音楽に含まれる周波数を表示
- [Stereo Meter](#stereo-meter) - ステレオバランスと位相の関係を可視化

## Analog Meter

音声を変えずに、各チャンネルのレベルを昔ながらの指針メーターで表示します。音楽の音量の移り変わりを追ったり、VU、PPM、ピーク、ラウドネス（LUFS）といった放送や配信で使われる目盛りで、再生音がどう読まれるかを確かめたりできます。

### 活用ガイド

- **VU で平均的なレベルを追う**：曲を通して指針を見てみましょう。静かなAメロと盛り上がるサビでははっきり差が出る一方、短いドラムのアタックでは指針はほとんど動きません。
- **True Peak でクリップを確かめる**：EQ やゲイン系のエフェクトの後ろに Analog Meter を置き、曲のいちばん大きな部分を再生します。読みが 0 dBFS を超えたりオーバーランプが点灯したりする場合は、チェーンのどこかでクリップするおそれがあります。-1 dBFS 程度の余裕を持ってピークが 0 dBFS を下回るまで、ゲインを下げてください。
- **Loudness で曲どうしを比べる**：**Target** を -14 LUFS など配信サービスの基準値に合わせ、曲やアルバムの頭で **Reset** を押して最後まで再生します。Integrated の値で全体の音量感が、最大 True Peak で最も高いピークが分かるので、アルバムやプレイリストの音量をそろえる目安になります。LRA を見れば、曲ごとの音量の幅も比べられます。

### システムプリセット

エフェクト見出しの**エフェクトプリセット**で、よく知られた規格どおりの設定にまとめて切り替えられます。**Mode** が変わるプリセットを選ぶと測定は最初からやり直しになりますが、Loudness のプリセット同士の切り替えでは測定が続きます。

- **Studio VU (-18 dBFS)** - 0 VU を -18 dBFS に置く VU。スタジオで一般的な基準（EBU R68）で、ヘッドルームを広くとった録音に向きます。
- **SMPTE VU (-20 dBFS)** - 0 VU を -20 dBFS に置く VU（SMPTE RP 155）。北米のスタジオや放送で使われる基準です。
- **Hot VU (-14 dBFS)** - 初期設定と同じです。0 VU を -14 dBFS に置く VU で、市販の完成した音源の多くに合います。
- **Loud Master VU (-8 dBFS)** - 0 VU を -8 dBFS に置く VU。音圧を目いっぱい上げた近年の CD やポップスのマスターで、指針が上端に張り付かないようにします。
- **DIN PPM** - DIN のメーター（**Attack** 5 ms、1.5 秒で 20 dB 戻る、DIN 目盛り）。-9 の印を -18 dBFS に置くので、0 の印は -9 dBFS です。目盛りは -50 まで表示します。
- **BBC PPM** - BBC のメーター（**Attack** 10 ms、2.8 秒で 24 dB 戻る、BBC 目盛り）。4 の目盛りを -18 dBFS に置くので、6 の目盛りは -10 dBFS です。
- **Nagra Modulometer** - Nagra のテープレコーダーのモジュロメーター（**Attack** 7.5 ms、-30～+5 dB の dB 目盛り）。0 dB を -18 dBFS に置きます。**Release** は DIN と同じ 1.5 秒です。
- **K-20** - Bob Katz の K-System による RMS メーター。0 を -20 dBFS に置き、目盛りは -60 dBFS まであります。ダイナミックレンジの広い録音向けです。
- **K-14** - 同じく 0 を -14 dBFS に置き、目盛りは -60 dBFS までです。一般的なポップス向けです。
- **K-12** - 同じく 0 を -12 dBFS に置き、目盛りは -60 dBFS までです。放送向けに音圧を詰めた音源向けです。
- **Digital Peak** - 標準的なデジタルピークメーター（IEC 60268-18）。-60～0 dBFS を表示し、ピークの印を 2 秒残します。
- **True Peak Clip Watch** - True Peak で上端の 20 dB を拡大し、ピークの印を最長の 10 秒残します。EQ やゲインを変えたあと、0 dBFS を超えるピークを見逃さないための設定です。
- **EBU R128 (-23 LUFS)** - 欧州の放送基準を目標値にした Loudness。目盛りは EBU +9 です。
- **EBU R128 +18 Scale** - 同じ目標値で、幅の広い EBU +18 目盛りを使います。クラシックなど音量の幅が広い音源向けです。
- **TV (-24 LKFS)** - 米国（ATSC A/85）と日本（ARIB TR-B32）のテレビで使われる -24 LKFS を目標値にした Loudness。
- **Streaming (-14 LUFS)** - 多くの音楽配信サービスの音量正規化に近い -14 LUFS を目標値にした Loudness。指針は落ち着いて動く Short-term です。
- **Streaming (-16 LUFS)** - 配信やポッドキャスト向けに推奨される -16 LUFS（AES TD1008）を目標値にした Loudness。指針は Short-term です。

### パラメーター

選んだ **Mode** で使う項目だけが表示されます。

- **Mode** - メーターの種類を **VU**（初期値）、**PPM**、**RMS**、**Sample Peak**、**True Peak**、**Loudness** から選びます。モードごとに指針の動きと目盛りが異なります（表示の見方を参照）。モードを切り替えると測定は最初からやり直しになります。
- **Integration**（RMS、0.05～3 s、初期値 0.3 s）- 平均をとる時間を設定します。長くすると指針が落ち着いてゆっくり動き、短くすると変化に素早く追従します。
- **Attack**（PPM、1～20 ms、初期値 5 ms）- PPM の指針が立ち上がる速さを、定常音より 2 dB 低く読まれるトーンバーストの長さで設定します。短くすると短いピークも本来のレベルに近く示し、長くすると短いピークほど低めに読まれます。5 ms が DIN のメーターに相当します。
- **Release**（PPM、Sample Peak、True Peak、0.1～5 s、初期値 1.5 s）- ピークの後に指針が 20 dB 戻るまでの時間を設定します。長くするとピークを読み取りやすくなり、短くすると音楽の動きに細かく追従します。1.5 s は DIN のメーターや標準的なデジタルピークメーターと同じ値です。
- **Reference**（VU、PPM、RMS、-30～0 dBFS、初期値 -14 dBFS）- メーターの基準の印に対応するデジタルレベルを設定します。初期値は市販の完成した音源の多くに合う値です。スタジオで使われる -18 dBFS や -20 dBFS の基準（システムプリセットを参照）では、ふつうの CD でも指針が目盛りの上端付近にとどまりがちです。音圧の高い音源で指針が振り切れるときは上げ、静かな音源で指針がほとんど動かないときは下げます。
- **Range**（PPM の DIN・dB 目盛り、RMS、Sample Peak、True Peak、20～60 dB、初期値 40 dB）- 目盛りの下端までの幅を設定します。広げると静かな部分まで読め、狭めると目盛りの上のほうが細かく読めます。
- **PPM Scale**（PPM、初期値 DIN）- PPM の目盛りを **DIN**、**BBC**、**dB** から選びます（表示の見方を参照）。
- **Peak Hold**（PPM、RMS、Sample Peak、True Peak、0～10 s、初期値 1 s）- 直近の最大値を示すピークの印を残す時間と、オーバーランプを点灯させておく時間を設定します。0 にすると印を表示せず、オーバーランプは 1 秒間点灯します。
- **Needle**（Loudness、初期値 Momentary）- 指針が示す値を選びます。**Momentary** は直近 0.4 秒のラウドネスに追従し、**Short-term** は直近 3 秒の値を示して落ち着いて動きます。
- **Target**（Loudness、-36～-10 LUFS、初期値 -23 LUFS）- 目盛りに印を付けるラウドネスを設定し、目盛りをその値を基準に配置します。-23 LUFS は EBU R128 の放送基準で、配信サービスでは -14 LUFS 前後が多く使われています。
- **Scale**（Loudness、初期値 EBU +9）- ラウドネス目盛りの幅を選びます。**EBU +9** は **Target** の 18 LU 下から 9 LU 上まで、**EBU +18** は 36 LU 下から 18 LU 上までを表示します。ダイナミックレンジの広い音楽やとても音圧の高い音源には EBU +18 が向いています。

### 表示の見方

- チャンネルごとに 1 つのメーターを表示します。1 行に最大 4 つ並び、最大 16 チャンネルまで対応します。
- レベルは、フルスケールのサイン波を 0 dBFS とするデジタルの一般的な慣例に従います。そのため、一定のサイン波は Loudness 以外のどのモードでも同じ値を示します。
- 指針の動く速さはモードごとに異なります。

| モード | 指針の動き | 目盛り |
|---|---|---|
| VU | ゆっくり動きます。新しいレベルに約 0.3 秒で達し、平均的なレベルを示します（IEC 60268-17）。 | -20～+3 VU。0 VU = **Reference**。 |
| PPM | IEC 60268-10 に基づく近似です。**Attack** で決まる速さで素早く立ち上がります。初期値の 5 ms では、DIN のメーターと同じく 10 ms のトーンバーストが定常音より約 1 dB 低く読めます。**Release** の時間で 20 dB 戻ります。 | **PPM Scale** で選びます。**DIN**：-9 の印 = **Reference** で、0 はその 9 dB 上です。**BBC**：1～7 の目盛りで、2～7 は 4 dB 間隔、1～2 は 6 dB 間隔、4 の目盛り = **Reference** です。**dB**：0 の印 = **Reference** で、**Range** の分だけ下から +5 dB までを表示します。 |
| RMS | **Integration** の時間で平均したパワーを示します。余分な平滑化はかけません。 | 0 の印 = **Reference**。 |
| Sample Peak | サンプル値の最大値へすぐに振れます。 | 目盛りの上端 = 0 dBFS。 |
| True Peak | Sample Peak と同様ですが、サンプルとサンプルの間のピークも推定します。0 dBFS を超えて読むことがあり、そのようなピークは DAC や変換の過程でクリップすることがあります。 | 目盛りの上端 = 0 dBFS。 |
| Loudness | ITU-R BS.1770 と EBU R128 で定められたラウドネスを LUFS で示します。 | **Target** と **Scale** で決まり、値は LUFS で表示します。 |

- ピークの印は直近の最大値を **Peak Hold** の時間だけ示します。オーバーランプはレベルが 0 dBFS を超えると点灯し、**Peak Hold** の時間（**Peak Hold** が 0 のときは 1 秒間）点灯し続けます。
- Loudness モードでは、先頭のメーターがプログラム全体を示します。指針は **Needle** の設定に従い、Momentary（M）、Short-term（S）、Integrated（I）、Loudness Range（LRA）、最大 True Peak の値、測定の経過時間と **Reset** ボタンを表示します。Integrated と LRA は、十分な長さの音声を測定すると表示されます。
  - モノラル、ステレオ、5.1（チャンネル順は L、R、C、LFE、Ls、Rs）では、規格どおりのチャンネル重みで測定します。それ以外のチャンネル数では全チャンネルを同じ重みで合算するため、値は参考値です。
  - 2 つ目以降のメーターは各チャンネル単独の値を示します。チャンネル重みもゲートもかけない参考値です。
- Integrated、LRA、最大 True Peak は、**Reset** を押す、**Mode** を切り替える、サンプルレートやチャンネル数が変わる、音声処理が再起動する、のいずれかが起きるまで蓄積されます。
- 処理が止まっている間は測定に含まれません。無音時の省電力による停止中、Master Bypass がオンのときや Analog Meter がオフのとき、設定の **非表示時は表示専用DSPをスキップ** がオン（初期状態）で Effect Pipeline が表示されていない間（Music Library の表示中、最小化中、ミニプレーヤー使用中など）がこれに当たります。再開すると、止まる前の値から測定を続けます。

## Chroma Spiral

音声を変えずに、音楽の周波数成分が12の音名と各オクターブのどこにあるかを示します。倍音が重なったときに強い音名を見たり、ボーカルとベースの音域を比べたり、楽器の成分が広がる範囲を確かめたりできます。

### 活用ガイド

- 一つの音を伸ばし、その音と倍音が螺旋のどこに現れるか見てみましょう。一音でも複数の音名が光ります。それぞれが別に演奏された音とは限りません。
- 和音やメロディーを流すと、強い成分の位置が移り変わります。調性の手掛かりにはなりますが、和音名や調を判定する表示ではありません。
- チューニングを見たいときは、明るいドットや塗りの外縁の山が音名の目盛りの間に出るか確認します。一つの基音のずれをセントで読むには Pitch Meter を使います。
- グラフをマウスや指、ペンで押すと、選んだ螺旋上の位置に対応するサイン波を試聴できます。ドラッグすると音の高さが変わり、離すか操作を中断すると止まります。どの **Color** 設定でも使えます。

### パラメーター

- **Color** - スペクトルの描き方を選びます。背景の螺旋ガイドはどの設定でも表示され、無音時にも残ります。
  - **Normal**（初期値）：各周波数の成分をテーマのグラフ描画色のドットで示します。明るさはその成分の強さに応じて変わり、ドットの面積も強さに比例して広がるため、弱い成分も見やすくなります。最大の強さでは、ドットの半径が隣の螺旋の周回との中間まで届きます。
  - **Normal 2**：各周波数の螺旋上の位置から強さに応じた外側までをグラフ描画色で塗り、データの輪郭線は描きません。
  - **Note Colors**：Normal と同じドット表示で、音名ごとに色を変えます。同じ音名はどのオクターブでも同じ色です。
- **Lowest Octave**（1～8、初期値1）- 表示する最も低いオクターブを設定します。上げると高い音域に絞れます。
- **Highest Octave**（1～9、初期値7）- 表示する最も高いオクターブを設定します。下げると低音と中音域に絞れます。上下の設定が逆転しないよう連動します。
- **Frequency Tilt**（-6～+6 dB/oct、0.5刻み、初期値+3）- 100 Hz より上の周波数の表示レベルを調整します。音声は変わりません。正の値では高い周波数を目立たせ、負の値では控えめにします。0 では周波数による補正をしません。
- **Level Range**（6～96 dB、1 dB刻み、初期値24）- 音量に追従して動く表示範囲の幅を設定します。狭めると強弱の差が目立ち、広げると強い成分とともに弱い成分も見やすくなります。
- **Display Floor**（-120～-24 dB、1 dB刻み、初期値-60）- 静かなときに、動く表示範囲の下端がどこまで下がれるかを設定します。下げると、選んだ **Level Range** 内の弱い成分も表示しやすくなります。表示範囲は直近のピークにも追従するため、弱い成分が必ず見えるとは限りません。

### 表示の見方

- 螺旋の一周が一オクターブです。C は真上で、時計回りに音名が並びます。内側ほど低く、C の表示にオクターブ番号が付きます。
- **Normal** と **Note Colors** では音名の間も含め、ドットが明るく大きいほど、その位置の成分が強くなります。**Normal 2** では強い成分ほど塗りが外側へ広がり、輪郭線なしでも外縁からスペクトルの変化を追えます。
- ドットの明るさと面積、塗りの広がりは相対的な強さです。表示は直近のピークに追従するため、絶対レベルは読み取れません。
- 低音ほど隣り合う音を分けにくく、反応も遅くなります。低いオクターブでは近い音が重なって見えることがあります。

### ビジュアル表示
- 表示にマウスを重ねるか、タッチしてなぞると、その位置の値を読み取れます。

## Level Meter

音楽のデジタル信号レベルをリアルタイムで表示します。エフェクトをかけた後のレベル確認や、耳で歪みとして分かる前にクリッピングの可能性を見つけるのに役立ちます。

### 表示ガイド
- 信号レベルが大きくなるほど、横バーが右へ長く伸びます
- 白いマーカーは新しいピークを1秒間保持し、その後なめらかに下がります
- OVERLOADは、信号が安全なデジタル範囲を超えて歪む可能性があることを示します
- きれいに再生するには、赤いレベルやOVERLOAD警告が頻繁に出ないようにし、実際の聴取音量は再生機器側で調整してください

## Note Spectrogram

音声を変えずに、A0からC8までの範囲から選んだ推定基本周波数（F0）を流れるピアノロールで表示します。和音の構成音、変化するボーカルやメロディーの動き、ベースライン、異なるオクターブで重なる音を追うのに役立ちます。

### 表示ガイド

- **Vertical**では横軸が時間で、右端に鍵盤と現在の音を表示します。上ほど高い音です。
- **Horizontal**では鍵盤を下端に置き、左に低音、右に高音を表示します。新しい音は鍵盤のすぐ上に現れ、履歴は上へ流れます。
- Cごとの線がオクターブの境界を示します。
- 黒鍵に対応する音高の行は、音が検出されていないときも判別できるよう、ほぼ黒に近いグレーで表示します。
- **Normal**はテーマのグラフ描画色、**Note Colors**は音名ごとの色を使います。同じ音名はどのオクターブでも同じ色です。EとFの間の補助線はどちらの設定でも表示されます。
- **1/12 Octave**は半音ごとに1行、**High (1/60 Octave)**は半音を5行に分けて表示します。Highでは細かな音高の動きを追いやすくするため、隣り合う音名の色を行ごとに補間します。
- 色の濃さはモデルの確信度に従い、弱い候補もしきい値で除外せずに表示します。確信度は音高の存在をモデルがどの程度支持するかを示すもので、校正済みの確率ではありません。
- **Volume**をオンにすると、検出した音高をバーで表示し、周波数補正後の相対音量をバーの不透明な本体の太さで示します。本体の太さは表示範囲の下端で1/60オクターブ、上端で1/12オクターブです。本体の両側にはそれぞれ1/120オクターブのフェードが加わり、総描画幅は本体より合計1/60オクターブ広がります。**Pitch Resolution**はバーの中心位置だけを変え、本体の太さには影響しません。
- 鍵盤との境界からグラフ側へ広がる、ぼかした半円が現在の音量を示します。音量が上がるとすぐに追従し、下がると毎秒20 dBで減衰します。表示用のピーク保持や別のピーク弧はありません。
- 音量表示の幅は24 dBです。上端は、履歴の尺度を安定させるための直近の基準値（約1秒分）と-36 dBのうち高い方に追従します。この基準値は、半円が示す現在の音量とは別のものです。
- オクターブ境界線とE–F間の補助線はバーの背面に描かれるため、音高グリッドの目安として確認できます。
- 最新フレームの確信度が高いほど、鍵盤色が通常の色から滑らかに表示色へ近づき、1でその色になります。
- **Color**を切り替えると、既存の履歴を選んだ色で塗り直します。

### ビジュアル表示
- 表示にマウスを重ねるか、タッチしてなぞると、その位置の値を読み取れます。

### 音楽を聴くときの使い方

- 和音は、同じ時刻に並ぶ複数の明るい行として見えます
- メロディーやベースラインは、音高の行を移動する軌跡として見えます
- この表示は音高を推定するもので、MIDIや楽譜を作成したり、楽器を識別したり、同時に鳴るすべての音を完全に分離したりするものではありません。複雑に重なる音ではメロディーやハーモニーの一部を取り逃すことがあり、打楽器、ノイズ、繰り返しが不明瞭な音では誤った音高が表示されることがあります。

### パラメーター

- **Color** - 音高の推定結果はそのままに、表示色を選びます。
  - **Normal**（初期値）：テーマのグラフ描画色。
  - **Note Colors**：音名ごとに色を変え、同じ音名はどのオクターブでも同じ色で表示します。
- **Pitch Resolution** - 既存の履歴を消さずに、音高方向の表示解像度を切り替えます。
  - **1/12 Octave**（初期値）：半音ごとに1行とし、その音の範囲で最も強い推定結果を表示します。
  - **High (1/60 Octave)**：半音を5行に分け、細かな音高の動きを表示します。
- **Layout** - **Horizontal**（初期値）または**Vertical**を選びます。切り替えても既存の履歴は保持されます。
- **Volume** - バーの太さと半円メーターで相対音量を表示します。初期値はオンです。オフにすると行の濃さが確信度を示します。
- **Time Span**（1～10 s）- ピアノロールに表示する時間の長さを設定します
  - 短くすると、タイミングの変化を詳しく確認できます
  - 長くすると、より長い音楽の流れを一度に確認できます
  - 初期値：2 s
- **Regular Note Limit**（1～16音）- 低域専用の検出範囲を除き、最終検出段階へ進める同時発音数を設定します。初期値は8です。非常に密度の高い和音では増やし、小さくすると解析量と候補間の競合を抑えられます。
- **Lowest Note** - 表示と認識を行う音域の下限を設定します。初期値：E1。
- **Highest Note** - 表示と認識を行う音域の上限を設定します。初期値：G6。
- 入力が解析するには小さすぎる場合、極小の入力を音高として表示せず、ピアノロールは黒いままです。この抑制は、音が聞こえるか、聴覚的にマスキングされるかを判断するものではありません。

## Oscilloscope

音の波形の形をリアルタイムで表示します。ビート、鋭いアタック、音量変化などを聴きながら目で確認できます。波形が繰り返す場合は、トリガー設定で表示を安定させられます。

### 表示ガイド
- 横軸は時間を示します（ミリ秒）
- 縦軸は正規化された振幅を示します。表示範囲はDisplay LevelとVertical Offsetによって変わります
- 緑の線が実際の波形を描きます
- グリッド線は時間と振幅の目安になります
- トリガー設定は波形キャプチャの開始位置を決めます。個別のトリガーマーカーは表示されません

### ビジュアル表示
- グラフにマウスを重ねるか、タッチしてなぞると、その位置の値を読み取れます。

### パラメータ
- **Display Time** - 表示する時間の長さ（1から100 ms）
  - 低い値: 短い音の変化をより細かく表示
  - 高い値: より長いパターンを表示
- **Trigger Mode**
  - Auto: トリガーがなくても継続的に更新
  - Normal: 次のトリガーまで表示を固定
  - Off: トリガーを使わず、入ってくる最新の波形をそのまま表示し続けます。Trigger Level、Trigger Edge、Holdoff は反映されません
- トリガー検出は左右チャンネルの平均波形を使用します。モノ入力はそのまま使用されます。
- **Trigger Level** - キャプチャを開始する振幅レベル
  - 範囲: -1から1（正規化された振幅）
- **Trigger Edge**
  - Rising: 信号が上がるときにトリガー
  - Falling: 信号が下がるときにトリガー
- **Holdoff** - トリガー間の最小時間（0.1から10 ms）
- **Display Level** - 縦方向のスケール（-96から0 dB）
- **Vertical Offset** - 波形を上下にずらします（-1から1）

### 波形表示に関する注意
表示される波形は、取り込んだ点を時間順に結びます。Display Timeが長い場合は、各区間の先頭・末尾サンプルに加えて、最小値・最大値と元の位置を保持するため、表示解像度の範囲で連続性と短いピークが保たれます。厳密な測定ではなく、視覚的な目安として使ってください。

## Pitch Meter

音声を変えずに、1つの基音（F0）を2秒間のスクロール式ピアノロールで追跡します。単独の声や楽器のチューニングと音程の動きを確認するときに使います。

### 表示ガイド

- **Horizontal**（既定）は低音を左、高音を右に配置します。最新の推定値は鍵盤の上に現れ、履歴は上へ流れます。
- **Vertical** は低音を下、高音を上に配置します。最新の推定値は右端の鍵盤の横に現れ、履歴は左へ流れます。
- 線の位置は半音の間を含む音程を示します。推定の確かさが高いほど線が濃くなり、入力が小さすぎる場合や安定した単音を検出できない場合は線が途切れます。**Heatmap**は線色で相対音量を、**Note Colors**は音高を示します。
- 現在値のラベルは最も近い音名とセント差を示します。正の値はその音より高く、負の値は低いことを表します。信頼できる推定値がないときはラベルが消えます。
- 音名の色はNote Spectrogramの音名ごとの配色と共通です。音名とセント差は表示幅に収まる大きさで表示され、セント差の小数点位置は固定されます。

### ビジュアル表示
- 表示にマウスを重ねるか、タッチしてなぞると、その位置の値を読み取れます。

### 活用ガイド

- まず単音を長く鳴らし、線が音名の中央にとどまるか、高めまたは低めに動くかを確認します。
- ビブラートやピッチベンドは、音程の行を横切る滑らかな動きとして見えます。
- このアナライザーは最も優勢な1つの音程を追跡します。和音、密度の高いミックス、打楽器、ノイズ、不明瞭な周期音では、線が途切れたりオクターブを誤ったりすることがあります。

### パラメータ

- **Layout** - **Horizontal**（既定）または **Vertical** を選択します。
- **Color** - 音高の推定結果を変えずに線色を切り替えます。**Normal**（初期値）はテーマのグラフ描画色、**Heatmap**はNote Spectrogramと同じ24 dBの音量スケール、**Note Colors**は音高に沿って変化する音名の色を使います。
- **Reference A4**（400～480 Hz）- 音名とセント差の基準となるチューニング周波数を設定します。既定値：440 Hz。
- **Lowest Note** - 表示・解析範囲の最低音を設定します。既定値：C2。設定可能な最低音はA0です。
- **Highest Note** - 表示・解析範囲の最高音を設定します。既定値：C7。設定可能な最高音はC8です。
- ステレオ入力は先頭2チャンネルの平均を解析し、モノ入力はそのまま使います。左右で極性が強く反対になっている成分は平均時に打ち消され、音程の線が表示されないことがあります。

## Rhythm Analyzer

音楽のテンポを求め、ドラムや楽器の発音がどこに来ているか、各パートがビートに対してどれだけ前後しているかを1拍ずつ表示します。曲の BPM を調べる、グルーヴのスウィング具合を確かめる、スネアがビートより後ろに置かれているかを見る、フィルインやパターンの変わり目を見つける、といった使い方ができます。**Metronome Click** をオンにしない限り、音声は変えません。

### 活用ガイド

- **テンポを確かめる**：ビートのはっきりした一定のテンポの曲を再生します。数秒でヘッダーに BPM と **LOCKED** が表示され、テンポグラムの帯には同じテンポが **adopted** として示されます。アナライザーは、足でリズムを取る拍とは別の単位の拍を追うことがあるので、ヘッダーの **×½**、**×2**、**strongest** も見てください。そのどれかが足で取るリズムに合うなら、それが感じているテンポです。
- **ビートの位置を耳で確かめる**：**Metronome Click** をオンにすると、検出したビートごとにクリック音が鳴ります。足でリズムを取る位置にクリックが重なれば、ビートを正しくとらえています。足の動きの間に鳴る場合や、倍・半分の速さで鳴る場合は、アナライザーが別の拍の位置や単位を追っています。下の **倍テンポや半テンポでのロックを直す** と **制限事項** を参照してください。
- **クリックを使うときは最後に置く**：クリック音はアナライザーから出る音声に混ぜられるので、後ろにあるエフェクトはクリック音にもかかります。クリックを聴くときは、Rhythm Analyzer をエフェクトチェーンの最後に置いてください。
- **ファイルを処理する前にクリックを切る**：**Metronome Click** がオンのままだと、処理したファイルにクリック音が書き込まれます。先にオフにしてください。
- **倍テンポや半テンポでのロックを直す**：ゆったりしたバラードが倍のテンポでロックした場合は、**Max BPM** をその値より下げます（60 BPM のバラードなら 100 など）。速い曲が半分のテンポでロックした場合は、**Min BPM** をその値より上げます。範囲を変えると解析は最初からやり直しになります。
- **安定したグルーヴを読む**：打ち込みやクリックに合わせた演奏では、点が各レーンの中央近くに並び、**jitter** は 0 ms 付近にとどまります。あるパートがほかのパートより一貫して遅れたり先行したりしていると、そのパートの点は毎回同じ位置でレーンの中央より上か下に来ます。たとえばスネアがキックとハイハットより 15 ms 遅れていれば、2拍目と4拍目の Mid の点がレーンの中央より上に出て、ビートレンズの **1** の列には +15 の付いた Mid の印が出ます。
- **スウィングを読む**：**swing** は裏拍の遅れ具合を示します。1.00:1 がイーブン、2.00:1 が3連符のシャッフルで、その間の値は軽めのスウィングです。はっきりスウィングしている曲では、ビートレンズは裏拍の発音を **&** ではなく **⅔** の列に置きます。
- **フィルインや展開の変わり目を見つける**：1スパン前にも2スパン前にも同じ帯域が同じ位置で鳴っていなかった発音には、リングが付きます。同じパターンが繰り返されている間はリングがほとんど出ず、フィルインや新しいセクションの最初の小節ではたくさん出ます。メインのレーンの下にあるエコー行で、新しいパターンをそれまでのパターンと見比べられます。
- **searching と表示されたとき**：ビートがはっきりしない間は、ヘッダーに **searching** と、括弧付きで最後にロックしていたテンポが表示されます。レーンは網掛けの中でそのテンポのままスクロールを続け、発音はタイミングを持たない白抜きの円で描かれます。アナライザーは、ビートを確信できる状態が1拍分続いたところでロックします。ビートのはっきりした一定のテンポの曲なら数秒でロックしますが、クラシックやルバートのかかった演奏では、もっと時間がかかることがあります。音楽が止まると0.5秒以内にビートの表示をやめ、音楽が戻れば再びロックします。

### パラメーター

- **Min BPM**（40～192、初期値 40）- ロックするテンポの下限を設定します。感じているテンポの半分にロックするときは上げます。
- **Max BPM**（50～240、初期値 240）- ロックするテンポの上限を設定します。感じているテンポの倍にロックするときは下げます。アナライザーは **Min BPM** から **Max BPM** までのテンポにだけロックしますが、曲が速くなったり遅くなったりすると、表示されるテンポが範囲から少しはみ出すことがあります。**Max BPM** は常に **Min BPM** の1.25倍以上に保たれ、変更によってこの関係が崩れる場合はもう一方の値が自動的に動きます。どちらかを変えると解析は最初からやり直しになります。テンポグラムの帯は常に 30～480 BPM を表示し、**×½** と **×2** の線は設定した範囲の外に来ることもあります。
- **Metronome Click**（オン／オフ、初期値 オフ）- 検出したビートごとに、短く高いクリック音を通過する音声に加えます。クリックはロックしている間だけ鳴り、**searching** に戻ると止まります。クリックの音量は約 −10 dBFS に固定で、チャンネル1と2（モノ入力ではチャンネル1）に加わり、ほかのチャンネルは変わりません。オフのときは、音声はそのまま通過します。オン・オフを切り替えても解析はやり直しになりません。
- **Span (beats)**（4、6、8、12、16、初期値 8）- メインのレーンとエコー行の1行に何拍を表示するか、またリングを付けるときに何拍前と比べるかを設定します。変わるのは表示だけで、解析には影響しません。小節の区切りに合う値にすると、繰り返すパターンがエコー行の間でそろいます。たとえば 4/4 拍子の2小節なら 8、3/4 拍子の2小節なら 6 です。
- **Tempogram**、**Timing lanes**、**Echo rows**、**Beat lens**（オン／オフ、初期値 オン）- テンポグラムの帯、メインのレーン、エコー行、ビートレンズをそれぞれ表示するか隠すかを切り替えます。残りの部分が空いた場所に広がり、ヘッダーは常に表示されます。隠しても変わるのは表示だけで、解析は続いており、オンに戻すとその部分はそれまでの履歴ごと再び表示されます。

### 表示の見方

表示は、ヘッダー、テンポグラムの帯、メインのレーン、エコー行、ビートレンズの5つの部分からなります。横長の表示ではビートレンズがレーンの右に並び、縦長の表示ではすべての部分が上から順に積み重なります。チェックボックスで部分を隠すと、残りの部分が空いた場所を埋め、ヘッダーは常に残ります。発音は3つの帯域に分けられます。**Low**（キックとベース）、**Mid**（スネア、声、多くの楽器）、**High**（ハイハットとシンバル）です。どの帯域も同じ色で描かれ、レーン、エコー行、ビートレンズでは帯域ごとに行が分かれて、**High** が上、**Low** が下に並びます。軸の名前、目盛りの数値、行の名前（**High**、**Mid**、**Low**）はグラフに重ねて描かれます。表示は拍だけを数えるもので、小節や1拍目は検出しません。

- **ヘッダー**：
  - BPM の左のビートランプは、アナライザーが予測したビートごとに点灯してすぐに消えていくので、どのビートを追っているかが目で分かります。**Metronome Click** も同じビートで鳴ります。小節の頭が分からないため、どのビートも同じように点灯します。**searching** の間は、ランプは中の空いた輪になります。
  - ビートを追えている間は BPM と **LOCKED** を表示します。見つけられていない間は **searching** と表示し、最後にロックしていたテンポを **(N BPM held)** として添えます。
  - **×½** と **×2** - 表示中のテンポの半分と倍です。
  - **strongest** - その時点で音楽の中で最も強く繰り返しているテンポです。ロックしたテンポと同じことが多く、異なる場合は有力な別の候補です。
  - **swing** - 直近32拍の典型的な裏拍の位置から求めた、1拍の前半と後半の比です。1.00:1 がイーブン、2.00:1 が3連符のシャッフルです。
  - **jitter** - ビートレンズの中で、発音が平均の位置のまわりで不規則にばらつく典型的な幅です（ms）。打ち込みのようにタイトなパートでは 0 付近になり、ルーズな演奏ほど大きくなります。
  - 記号の凡例です。**○ no beat lock**、**◎ new vs N / 2N beats ago**、破線を表す **beat re-aligned** があります。
  - まだ値が求まっていない項目は — と表示されます。
- **テンポグラムの帯**：直近20秒を表示します。横軸 **Time** は時間（左から右）、縦軸 **Tempo (BPM)** は 30～480 BPM の対数目盛りのテンポで、その数値は左端に並びます。明るさは、音楽がそのテンポでどれだけはっきり繰り返しているかを表します。明るく描かれるのは、はっきりした強い繰り返しだけです。繰り返しが弱いときや不明瞭なときは薄く表示され、無音のあいだは暗いままです。拍の半分や倍など関連するテンポも、薄い線として現れることがよくあります。ロックしている間は、実線がロックしたテンポを、破線がその半分と倍を示し、右端のそれぞれの線のすぐ上に **adopted**、**×2**、**×½** と記されます。アナライザーがビートに確信を持てないほど、これらの線は薄くなります。
- **メインのレーン**：**Span (beats)** で決めた直近の拍数分を表示し、最新の発音が右端に来ます。見出しは **Last N beats** です。レーンは実線で帯域ごとに区切られた3つのタイミンググラフで、それぞれ左端に帯域の名前が付き、横軸が **Beats**、縦軸が **Timing (ms)** です。縦線は拍を、薄い縦線は8分音符を表し、ロックしていた区間にだけ描かれます。点は検出した発音1つ1つで、レーンの中央から伸びる縦棒の先に描かれ、発音だという確信が強いものほど大きくなります。
  - レーンの中での点の高さはタイミングを表します。レーンの中央（0 ms）より上は遅れ、下は先行です。**+20**、**−20** と記された点線が ±20 ms の位置を示し、±30 ms を超える発音はレーンの端にとどまります。タイミングは最寄りの16分音符または3連符の位置（音楽が従っているほうのグリッド）からのずれで、直前16拍の典型的なタイミングを基準に表示します。そのため全パートに共通する一定の遅れは表示に現れず、レーンには各発音が最近の平均からどれだけずれているかが示されます。
  - 白抜きの円は、ビートにロックしていないときの発音です。タイミングを持たないため、レーンの中央に置かれます。
  - 点のまわりのリングは、1スパン前にも2スパン前にも同じ帯域が同じ位置で鳴っていなかった発音を示します。リングはロックや合わせ直しから1スパン後に出始めます。
  - **searching** と書かれた網掛けは、ビートにロックしていなかった時間を示します。
  - 破線は、ロックを保ったままビートのグリッドを合わせ直した位置です。アナライザーが新しいテンポに切り替えたときや、拍の位置をずらしたときに入ります。ビートレンズ、swing、jitter はそこから集計し直しになります。
- **エコー行**：**Span (beats)** の拍数を1サイクルとして、サイクルごとの区間を新しいものを上にして積み重ね、行の間を線で区切ります。横軸は **Beats**、縦軸 **Cycles ago** は各行が何サイクル前かを示します。メインのレーンを表示している間は、行は1サイクル前から始まって 1、2、…と番号が付き、見出しは **Previous N-beat cycles** になります。メインのレーンを隠すと、いちばん上の行は現在のサイクル（0）になって見出しが **Recent N-beat cycles** に変わり、余裕があればその行に帯域の名前が付きます。拍が縦にそろうので、サイクルごとに繰り返すパターンは縦の列になり、変化があるとその列が乱れます。エコー行には各発音の帯域（行の中で **High** が上、**Low** が下）は表示されますが、タイミングは表示されません。白抜きの円、リング、網掛け、破線の意味はメインのレーンと同じです。
- **ビートレンズ**：現在のロックまたは合わせ直し以降の、直近32拍のタイミングをまとめて表示します。列は1拍の中の位置（横軸 **Position in beat**）で、**1**（拍の頭）、16分音符の **e**、**&**、**a**、3連符の **⅓**、**⅔** があります。帯域ごとに1行ずつ並び、左端に帯域の名前が付きます。
  - 縦の印は、その帯域がその位置で平均してどれだけ早く（左）または遅く（右）鳴っているかを示します。上端の目盛りは ±30 ms の範囲で、±20 ms に刻みがあります。印のまわりの薄いバーはばらつき（±1標準偏差）です。印が濃いほど、その位置でよく鳴っています。発音が4つ以上ある位置だけが表示されます。
  - 値が更新されると、印の位置とバーの幅は新しい値へ滑らかに変わり、近づくほど動きがゆっくりになります。
  - ずれはアンサンブル全体を基準に測るので、全員がそろって鳴っていれば、どの印も中央に来ます。レンズが示すのはパート同士のずれです。
  - 3 ms 以上のずれには ms の値が付きます。帯域間のタイミング差は約 3 ms 未満では確実に測れないため、それより小さいずれは値を付けずに描きます。
  - ロックしていない間は、レンズに **waiting for a steady beat** と表示されます。
- **LOCKED** の表示とテンポの線の濃さは、アナライザーがビートをどれだけ確信しているかを示すもので、演奏のタイトさを示すものではありません。タイミングのルーズさは、点の高さ、**jitter**、レンズのバーだけが示します。
- **Reset** ボタンを押すと表示を消去して解析を最初からやり直します。別の曲に切り替えたときなどに使います。
- ステレオ入力は先頭2チャンネルの平均を解析し、モノ入力はそのまま使います。

### ビジュアル表示
- 表示にマウスを重ねるか、タッチしてなぞると、その位置の値を読み取れます。レーンとエコー行では、その位置が何拍前かと、最も近い発音の帯域とタイミング（白抜きの円では —）を表示します。テンポグラムの帯ではカーソル位置のテンポと時刻、**Salience**（そのテンポでの繰り返しの強さで、100%ははっきりした強い繰り返しを示します）、採用テンポの **Adopted** を、ビートレンズではその位置での各帯域のずれとばらつきを表示します。

### 制限事項

- テンポの揺れが大きい曲、リズムセクションのない曲、アコースティック演奏の曲では、解析の精度が下がることがあります。 打楽器のない静かな曲でテンポが自由に揺れるもの、アンビエント、持続音は **searching** のままになります。ピアノ独奏やクラシックなど、表情豊かに演奏された録音の中には、最後までロックしないものもあります。
- 聴き手が選ぶのとは別の拍の単位に落ち着き、ランプとクリックが感じているテンポの2倍、1/2倍、2/3倍、3/2倍などで動くことがあります。クラシック、ルバートのかかった演奏、その他一部の曲では、一定のビートの曲に比べて、ロックまでに時間がかかり、一時的に別の単位へ移ることも多くなります。**×½**、**×2**、**strongest** で考えられる別のテンポ候補を確かめられます。検出したテンポや拍の位置が合わない場合は、**Min BPM** と **Max BPM** を想定するテンポの周辺に絞って、もう一度試してください。
- クラーベのようなまばらなリズムパターンでは、ビートが裏拍にロックすることがあります。
- だんだん速くなる曲や自由にテンポが揺れる演奏のように、テンポが連続して変わる場合は、ビートが少し遅れて追いかけます。テンポが落ち着くまで、クリックがわずかに早めや遅めに鳴ることがあります。
- 一定のテンポの曲でも、音楽が変わっていないのに、ときどきビートの位置が合わせ直されることがあります（破線で示されます）。
- 音の密集したミックスやノイズの多い録音では、**Mid** と **High** のレーンに、実際には楽器が鳴っていない位置の点が増えます。**Low** のレーンでは、ピアノの低音を取りこぼすことがあります。
- 小節や拍子は検出しません。表示は拍だけを単位に並べたもので、小節の頭は示しません。
- 本来の解析が動作するサンプルレートは 8、11.025、16、22.05、24、32、44.1、48、88.2、96、176.4、192、352.8、384 kHz です。それ以外のサンプルレート（64 kHz など）では簡易的な方法で解析するため、ビートと発音の精度が下がり、音楽が止まってもビートが数秒間表示されたままになります。

## Spectrogram

音楽が時間とともにどう変化するかを表示します。色の濃さは各周波数成分の強さを、縦方向の位置は周波数を示します。

グラフは右から左へ一定の速さでスクロールし、1秒ごとの目盛りを表示します。

### 表示ガイド
- 色は周波数ごとの強さを示します:
  - 暗い色: 静かな音
  - 明るい色: 大きな音
  - 音楽に合わせてパターンが変化します
- 縦方向の位置は周波数を示します:
  - 下部: 低音
  - 中央: 主な楽器や声の帯域
  - 上部: 高音域
- **Log (HQ)** では、近い低音の音程や音色がより分かれた帯として見えます。低域用の長い測定は、立ち上がりや消え際が少し遅くなります。

### ビジュアル表示
- 表示にマウスを重ねるか、タッチしてなぞると、その位置の値を読み取れます。

### 見えるもの
- メロディ: 色が流れる線
- ビート: 縦方向のストライプ
- ベース: 下部の明るい色
- ハーモニー: 複数の平行な線
- 楽器ごとに異なる独特のパターン

### パラメータ
- **Color** - **Normal**はテーマのグラフ描画色を使い、強い成分ほど明るく表示します。**Heatmap**（初期値）は従来の暗色から明色への多色表示です。切り替えると既存の履歴も塗り直します。
- **DB Range** - 色の鮮やかさ（-144dBから-48dB）
  - 低い数値: より細かな音まで表示
  - 高い数値: 主な音に集中
- **Points** - 表示に使うFFTサイズ（256から16384）
  - 高い数値: 周波数の細かさが増える一方、時間方向の更新は遅くなります
  - 低い数値: 動きは速くなりますが、周波数の細かさは下がります
  - **Log (HQ)** では、Pointsが短い解析窓を決め、4倍長い窓で低域の近接した周波数をより分けて表示します。
- **Frequency Scale** - **Log** は低域を広く表示します。**Log (HQ)** は高域の短い測定を保ちながら、低域に長い測定を加えて近い低音をより分けて表示します。処理負荷は増え、低域の変化は表示や消え際が少し遅くなりますが、音声は変わりません。**Linear** は等しい周波数幅を等間隔で表示します。
- **Keyboard** - 音名と周波数の対応を示す静的な鍵盤ガイドをグラフの右側に表示します。解析内容や音声は変えません。鍵の配置は **Log**、**Log (HQ)**、**Linear** に追従します。**Log (HQ)** は **Log** と同じ対数間隔で、**Linear** では低域の鍵が狭く見えます。
- このアナライザーは左右チャンネルの平均を使用します。モノ入力はそのまま解析されます。

## Spectrum Analyzer

深い低音から高い高音まで、音楽の周波数をリアルタイムで表示します。音楽全体を形づくる個々の成分を見るようなツールです。

### 表示ガイド
- 左側は低域を示します（ドラム、ベースギターなど）
- 中央は主な帯域を示します（ボーカル、ギター、ピアノなど）
- 右側は高域を示します（シンバル、きらめき、空気感など）
- ピークが高いほど、その周波数の存在感が強いことを示します
- 太い線は現在の音を示します
- 細い線は直近のピークを追い、音が小さくなるにつれてなめらかに下がります
- **Bar** 表示では、各バーは表示上の一定幅の範囲で最も高いレベルを示します。**Log** と **Log (HQ)** では各範囲が等しいオクターブ幅になり、**Linear** では等しい周波数幅になります。
- バーの上にある細い印は直近のピークを示し、なめらかに下がります。
- **Log (HQ)** では、近い低音が別々のピークとして見えやすくなります。低域用の長い測定は、立ち上がりや消え際が少し遅くなります。
- 楽器ごとに異なるパターンが出る様子を観察できます

### ビジュアル表示
- グラフにマウスを重ねるか、タッチしてなぞると、その位置の値を読み取れます。

### 見えるもの
- ベースドロップ: 左側の大きな動き
- ボーカルメロディ: 中央の動き
- クリアな高音: 右側のきらめき
- フルミックス: すべての周波数がどう組み合わさっているか

### パラメータ
- **Color** - **Normal**（初期値）はテーマのグラフ描画色を使います。**Heatmap**はレベルが高いほど明るい色、**Note Colors**は周波数に対応する音名の色を使います。線とバーの両表示に適用されます。**Bar**と**Note Colors**を選ぶと、各バーとそのピークを帯域の中心周波数に対応する単色で描画します。
- **DB Range** - 表示の感度（-144dBから-48dB）
  - 低い数値: より細かな音まで表示
  - 高い数値: 主な音に集中
- **Points** - 近い周波数をどれだけ細かく分けて表示するか（256から16384）
  - 高い数値: 周波数の細かさが増えますが、更新は遅くなります
  - 低い数値: 更新は速くなりますが、周波数の細かさは下がります
  - **Log (HQ)** では、Pointsが短い解析窓を決め、4倍長い窓で低域の近接した周波数をより分けて表示します。
- **Frequency Scale** - **Log** は低域を広く表示します。**Log (HQ)** は高域の短い測定を保ちながら、低域に長い測定を加えて近い低音をより分けて表示します。処理負荷は増え、低域の変化は表示や消え際が少し遅くなりますが、音声は変わりません。**Linear** は等しい周波数幅を等間隔で表示します。
- **Display** - スペクトラムの見た目だけを変え、解析内容や音声は変えません。
  - **Line**（既定）: スペクトラムを連続した線で表示します。
  - **Bar**: 各表示帯域で最も高いレベルをバーで表示します。
- **Keyboard** - 音名と周波数の対応を示す静的な鍵盤ガイドをグラフの下側に表示します。解析内容や音声は変えません。鍵の配置は **Log**、**Log (HQ)**、**Linear** に追従します。**Log (HQ)** は **Log** と同じ対数間隔で、**Linear** では低域の鍵が狭く見えます。
- このアナライザーは左右チャンネルの平均を使用します。モノ入力はそのまま解析されます。

### これらのツールの楽しい使い方

1. 音楽を探索する
   - ジャンルごとに異なるパターンを観察する
   - アコースティック音楽と電子音楽の違いを見る
   - 楽器がどの周波数帯域を占めているかを観察する

2. 音について学ぶ
   - 電子音楽のベースを目で見る
   - ボーカルメロディが表示上で動く様子を見る
   - ドラムが鋭いパターンを作る様子を観察する

3. 体験を広げる
   - Level Meterで、エフェクト追加後の信号ピークを確認する
   - Spectrum Analyzerが音楽に合わせて動く様子を楽しむ
   - Spectrogramで視覚的なライトショーのように楽しむ

## Stereo Meter

ステレオ音声がどのように空間感を作っているかを見られる可視化ツールです。スピーカーやヘッドホンの間で音がどのように広がるかを観察でき、リスニング体験に視覚的な変化を加えます。

### 表示ガイド
- **ダイヤモンド表示** - 音楽の動きを表示するメイン画面:
  - 中央: 非常に静かな瞬間、または左右の合成信号がゼロに近い瞬間
  - 上下: センターやモノに近い音など、左右チャンネルに共通する成分
  - 左右: 左右チャンネルの差分や逆相成分
  - 片側がかなり強い音は、ラベル付きの角方向に現れることがあります
  - 緑の点が現在の音楽に合わせて動きます
  - 白い線が音楽のピークをたどります
  - 白いピーク線は音声サンプルごとに減衰するため、音声処理のブロックサイズが変わっても動き方は一定です
- **Correlation Bar**（左側）
  - 左右チャンネルの相関を表示します
  - 上部（+1.0）: 左右がほぼ同じで、中央にまとまりやすい音
  - 中央（0.0）: 左右の関係が弱く、広い響きや左右で異なる成分が多い音
  - 下部（-1.0）: 左右がほぼ逆極性で、スピーカー再生では弱く聞こえる場合があります
- **Balance Bar**（下部）
  - 片方のスピーカーがもう片方より大きいかを表示します
  - 中央: 両方のスピーカーで同じ音量
  - 左/右: 片側の音が強い
  - 数値はデシベル（dB）単位の音量差を示します

### 見えるもの
- **センターの音**: 中央付近の強い縦方向の動き
- **広がりのある音**: 表示全体に広がる動き
- **特殊な効果**: 角付近に出る興味深いパターン
- **スピーカーバランス**: 下部バーが示す方向
- **チャンネル相関**: 左側の相関バーが示す状態

### パラメータ
- **Window**（10-1000 ms） - 表示に使う直近の音の長さ
  - 低い値: 素早い音楽の変化を見やすい
  - 高い値: 全体的な音のパターンを見やすい
  - デフォルト: 100 msは多くの音楽に適しています
- **Gain**（0～24 dB、初期値0 dB）- ダイヤモンド内の点とピーク線だけを拡大します。値を上げると小さな音の広がりも見やすくなります。音声や相関・バランスの表示値は変わりません。

### 音楽を楽しむために
1. **スタイルの違いを見る**
   - クラシック音楽は穏やかでバランスの取れたパターンを示すことが多い
   - 電子音楽は大きく広がる模様を作ることがあります
   - ライブ録音では自然な部屋の動きが見えることがあります

2. **音の性質を発見する**
   - アルバムごとのステレオ効果の使い方を見る
   - 曲によって広がりの感じ方が違うことに気づく
   - 楽器がスピーカーの間でどう動くかを観察する

3. **体験を深める**
   - 異なるヘッドホンでステレオ表示の違いを試す
   - 好きな曲の古い録音と新しい録音を比べる
   - リスニング位置を変えたときの表示の違いを見る

これらのツールは、音楽を聴く楽しみに視覚的な要素を加えるためのものです。お気に入りの音楽を新しい方法で見ながら、自由に探索してみてください。
