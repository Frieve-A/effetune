# アナライザープラグイン

音楽を目で見て楽しめるプラグインのコレクションです。音のさまざまな側面を表示することで、聴こえている内容を理解しやすくし、リスニング体験をより楽しくインタラクティブにします。

## プラグイン一覧

- [Analog Meter](#analog-meter) - VU・PPM・ピーク・ラウドネスに対応した指針メーターでレベルを表示
- [Chroma Spiral](#chroma-spiral) - 周波数成分を音名とオクターブの螺旋上に表示
- [Level Meter](#level-meter) - デジタル信号レベルとクリッピングの可能性を表示
- [Note Spectrogram](#note-spectrogram) - 推定した音高を時間に沿ったピアノロールで表示
- [Oscilloscope](#oscilloscope) - 波形をリアルタイムで表示
- [Pitch Meter](#pitch-meter) - 1つの基音とチューニングの変化を表示
- [Rhythm Analyzer](#rhythm-analyzer) - テンポ、1拍ごとの発音、各パートの走り・もたりを表示
- [Spectrogram](#spectrogram) - 音楽の変化をカラフルなパターンで表示
- [Spectrum Analyzer](#spectrum-analyzer) - 音楽に含まれる周波数を表示
- [Stereo Meter](#stereo-meter) - ステレオバランスと位相の関係を可視化

## Analog Meter

音声を変えずに、各チャンネルのレベルを昔ながらの指針メーターで表示します。音楽の音量の移り変わりを追ったり、VU、PPM、ピーク、ラウドネス（LUFS）といった放送や配信で使われる目盛りで、再生音がどう読まれるかを確かめたりできます。**Custom** では、検波器、指針の動き、目盛りを組み合わせて、自分のメーターを作れます。

### 活用ガイド

- **VU で平均的なレベルを追う**：曲を通して指針を見てみましょう。静かなAメロと盛り上がるサビでははっきり差が出る一方、短いドラムのアタックでは指針はほとんど動きません。
- **True Peak でクリップを確かめる**：EQ やゲイン系のエフェクトの後ろに Analog Meter を置き、曲のいちばん大きな部分を再生します。読みが 0 dBFS を超えたりオーバーランプが点灯したりする場合は、チェーンのどこかでクリップするおそれがあります。-1 dBFS 程度の余裕を持ってピークが 0 dBFS を下回るまで、ゲインを下げてください。
- **Loudness で曲どうしを比べる**：**Target** を -14 LUFS など配信サービスの基準値に合わせ、曲やアルバムの頭で **Reset** を押して最後まで再生します。Integrated の値で全体の音量感が、最大 True Peak で最も高いピークが分かるので、アルバムやプレイリストの音量をそろえる目安になります。LRA を見れば、曲ごとの音量の幅も比べられます。
- **Custom で自分のメーターを作る**：指針を大きく跳ねさせるなら **Bouncy VU**、平均的なレベルを落ち着いて見るなら **Slow RMS**、短いピークを追うなら **Fast Peak** から始めます。**Needle Response** で速さを、**Overshoot** で跳ね方を調整します。PPM 風の立ち上がりと戻りも作れますが、Custom のピーク検波は瞬時に立ち上がります。規格に沿った PPM の応答を見るには **PPM** を使ってください。

### システムプリセット

エフェクト見出しの**エフェクトプリセット**で、標準のメーターやカスタムメーターにまとめて切り替えられます。**Mode** が変わるプリセットを選ぶと測定は最初からやり直しになりますが、Loudness のプリセット同士の切り替えでは測定が続きます。

- **Studio VU (-18 dBFS)** - 0 VU を -18 dBFS に置く VU。スタジオで一般的な基準（EBU R68）で、ヘッドルームを広くとった録音に向きます。
- **SMPTE VU (-20 dBFS)** - 0 VU を -20 dBFS に置く VU（SMPTE RP 155）。北米のスタジオや放送で使われる基準です。
- **Hot VU (-14 dBFS)** - 初期設定と同じです。0 VU を -14 dBFS に置く VU で、市販の完成した音源の多くに合います。
- **Loud Master VU (-8 dBFS)** - 0 VU を -8 dBFS に置く VU。音圧を目いっぱい上げた近年の CD やポップスのマスターで、指針が上端に張り付かないようにします。
- **DIN PPM** - DIN のメーター（**Attack** 5 ms、1.5 秒で 20 dB 戻る、DIN 目盛り）。-9 の印を -18 dBFS に置くので、0 の印は -9 dBFS です。目盛りは -50 まで表示します。
- **BBC PPM** - BBC のメーター（**Attack** 10 ms、2.8 秒で 24 dB 戻る、BBC 目盛り）。4 の目盛りを -18 dBFS に置くので、6 の目盛りは -10 dBFS です。
- **Nagra Modulometer** - Nagra のテープレコーダーのモジュロメーター（**Attack** 7.5 ms、-30～+5 dB の dB 目盛り）。0 dB を -18 dBFS に置きます。**Release** は DIN と同じ 1.5 秒です。
- **K-20** - Bob Katz の K-System による RMS メーター。0 を -20 dBFS に置き、目盛りは -60 dBFS まであります。ダイナミックレンジの広い録音向けです。
- **K-14** - 同じく 0 を -14 dBFS に置き、目盛りは -60 dBFS までです。一般的なポップス向けです。
- **K-12** - 同じく 0 を -12 dBFS に置き、目盛りは -60 dBFS までです。放送向けに音圧を詰めた音源向けです。
- **Digital Peak** - 標準的なデジタルピークメーター（IEC 60268-18）。-60～0 dBFS を表示し、ピークの印を 2 秒残します。
- **True Peak Clip Watch** - True Peak で上端の 20 dB を拡大し、ピークの印を最長の 10 秒残します。EQ やゲインを変えたあと、0 dBFS を超えるピークを見逃さないための設定です。
- **EBU R128 (-23 LUFS)** - 欧州の放送基準を目標値にした Loudness。目盛りは EBU +9 です。
- **EBU R128 +18 Scale** - 同じ目標値で、幅の広い EBU +18 目盛りを使います。クラシックなど音量の幅が広い音源向けです。
- **TV (-24 LKFS)** - 米国（ATSC A/85）と日本（ARIB TR-B32）のテレビで使われる -24 LKFS を目標値にした Loudness。
- **Streaming (-14 LUFS)** - 多くの音楽配信サービスの音量正規化に近い -14 LUFS を目標値にした Loudness。指針は落ち着いて動く Short-term です。
- **Streaming (-16 LUFS)** - 配信やポッドキャスト向けに推奨される -16 LUFS（AES TD1008）を目標値にした Loudness。指針は Short-term です。
- **Bouncy VU** - VU と同じ検波器と目盛りを使う Custom。オーバーシュートを 15% にして、指針を大きく跳ねさせます。
- **Slow RMS** - 3 s の RMS 平均、1000 ms の指針応答、行き過ぎなしの Custom。dB 目盛りの 0 を -18 dBFS に置き、-60 dBFS まで表示します。
- **Fast Peak** - True Peak 検波、0.5 s の検波器のリリース、10 ms の指針応答、行き過ぎなしの Custom。dBFS 目盛りで上端の 40 dB を表示し、読みの単位は dBTP です。

### パラメーター

選んだ **Mode** で使う項目だけが表示されます。 **Custom** では、その設定項目をすべて表示し、適用されない項目は無効になります。設定を変えてもパネルの高さは変わりません。

- **Mode** - メーターの種類を **VU**（初期値）、**PPM**、**RMS**、**Sample Peak**、**True Peak**、**Loudness**、**Custom** から選びます。モードごとに指針の動きと目盛りが異なります（表示ガイドを参照）。モードを切り替えると測定は最初からやり直しになります。
- **Detector**（Custom、初期値 Average Rectified）- 指針が追うレベルを選びます。**Average Rectified** は VU と同じく、信号の絶対振幅を指針自体で平均し、別の平均時間は持ちません。**RMS** は **Integration** の時間で平均したパワーを測ります。**Sample Peak** はサンプルの最大値を捉え、**True Peak** はサンプル間のピークも推定します。どちらのピーク検波器も瞬時に立ち上がり、**Release** に従って戻ります。検波器を切り替えると測定は最初からやり直しになります。
- **Integration**（RMS、検波器が RMS の Custom、0.05～3 s、初期値 0.3 s）- 平均をとる時間を設定します。長くすると読みが落ち着いてゆっくり変化し、短くすると変化に素早く追従します。Custom では、この平均に指針自体の応答が加わります。
- **Attack**（PPM、1～20 ms、初期値 5 ms）- PPM の指針が立ち上がる速さを、定常音より 2 dB 低く読まれるトーンバーストの長さで設定します。短くすると短いピークも本来のレベルに近く示し、長くすると短いピークほど低めに読まれます。5 ms が DIN のメーターに相当します。
- **Release**（PPM、Sample Peak、True Peak、検波器が Sample Peak・True Peak の Custom、0.1～5 s、初期値 1.5 s）- ピークの後に 20 dB 戻るまでの時間を設定します。長くするとピークを読み取りやすくなり、短くすると音楽の動きに細かく追従します。Custom では検波器の戻りを決め、その後に指針自体の応答が加わります。1.5 s は DIN のメーターや標準的なデジタルピークメーターと同じ値です。
- **Needle Response**（Custom、1～3000 ms、初期値 300 ms）- 検波器のレベルが一定の値へ変わったとき、指針が新しいレベルの 99% に初めて届くまでの時間です。下げると速く、上げるとゆっくり動きます。全体の動きには RMS の平均時間やピーク検波器のリリースも影響します。
- **Overshoot**（Custom、0～25%、初期値 1.25%）- 指針が新しい一定の検波レベルを行き過ぎる量を、レベルの変化量に対する割合で設定します。上げると大きく跳ね、0 では行き過ぎずに近づきます。
- **Dial**（Custom、初期値 VU）- 検波器や指針の動きとは別に、**VU**、**DIN**、**BBC**、**dB**、**dBFS** の目盛りを選びます。VU・DIN・BBC は下表の目盛りを使います。dB は 0 の印が **Reference**、上端が 0 dBFS です。dBFS は上端が 0 dBFS で、**Detector** が True Peak のときは dBTP で読みを表示します。
- **Reference**（VU、PPM、RMS、dBFS 目盛り以外の Custom、-30～0 dBFS、初期値 -14 dBFS）- メーターの基準の印に対応するデジタルレベルを設定します。初期値は市販の完成した音源の多くに合う値です。スタジオで使われる -18 dBFS や -20 dBFS の基準（システムプリセットを参照）では、ふつうの CD でも指針が目盛りの上端付近にとどまりがちです。音圧の高い音源で指針が振り切れるときは上げ、静かな音源で指針がほとんど動かないときは下げます。
- **Range**（PPM の DIN・dB 目盛り、RMS、Sample Peak、True Peak、DIN・dB・dBFS 目盛りの Custom、20～60 dB、初期値 40 dB）- 目盛りの下端までの幅を設定します。広げると静かな部分まで読め、狭めると目盛りの上のほうが細かく読めます。
- **PPM Scale**（PPM、初期値 DIN）- PPM の目盛りを **DIN**、**BBC**、**dB** から選びます（表示ガイドを参照）。
- **Peak Hold**（PPM、RMS、Sample Peak、True Peak、Custom、0～10 s、初期値 1 s）- 直近の最大値を示すピークの印を残す時間と、オーバーランプを点灯させておく時間を設定します。0 にすると印を表示せず、オーバーランプは 1 秒間点灯します。
- **Needle**（Loudness、初期値 Momentary）- 指針が示す値を選びます。**Momentary** は直近 0.4 秒のラウドネスに追従し、**Short-term** は直近 3 秒の値を示して落ち着いて動きます。
- **Target**（Loudness、-36～-10 LUFS、初期値 -23 LUFS）- 目盛りに印を付けるラウドネスを設定し、目盛りをその値を基準に配置します。-23 LUFS は EBU R128 の放送基準で、配信サービスでは -14 LUFS 前後が多く使われています。
- **Scale**（Loudness、初期値 EBU +9）- ラウドネス目盛りの幅を選びます。**EBU +9** は **Target** の 18 LU 下から 9 LU 上まで、**EBU +18** は 36 LU 下から 18 LU 上までを表示します。ダイナミックレンジの広い音楽やとても音圧の高い音源には EBU +18 が向いています。

### 表示ガイド

- チャンネルごとに 1 つのメーターを表示します。1 行に最大 4 つ並び、最大 16 チャンネルまで対応します。
- レベルは、フルスケールのサイン波を 0 dBFS とするデジタルの一般的な慣例に従います。そのため、一定のサイン波は Loudness 以外のどのモードでも同じ値を示します。
- 指針の動く速さはモードごとに異なります。

| モード | 指針の動き | 目盛り |
|---|---|---|
| VU | ゆっくり動きます。新しいレベルに約 0.3 秒で達し、平均的なレベルを示します（IEC 60268-17）。 | -20～+3 VU。0 VU = **Reference**。 |
| PPM | IEC 60268-10 に基づく近似です。**Attack** で決まる速さで素早く立ち上がります。初期値の 5 ms では、DIN のメーターと同じく 10 ms のトーンバーストが定常音より約 1 dB 低く読めます。**Release** の時間で 20 dB 戻ります。 | **PPM Scale** で選びます。**DIN**：-9 の印 = **Reference** で、0 はその 9 dB 上です。**BBC**：1～7 の目盛りで、2～7 は 4 dB 間隔、1～2 は 6 dB 間隔、4 の目盛り = **Reference** です。**dB**：0 の印 = **Reference** で、**Range** の分だけ下から +5 dB までを表示します。 |
| RMS | **Integration** の時間で平均したパワーを示します。余分な平滑化はかけません。 | 0 の印 = **Reference**。 |
| Sample Peak | サンプル値の最大値へすぐに振れます。 | 目盛りの上端 = 0 dBFS。 |
| True Peak | Sample Peak と同様ですが、サンプルとサンプルの間のピークも推定します。0 dBFS を超えて読むことがあり、そのようなピークは DAC や変換の過程でクリップすることがあります。 | 目盛りの上端 = 0 dBFS。 |
| Loudness | ITU-R BS.1770 と EBU R128 で定められたラウドネスを LUFS で示します。 | **Target** と **Scale** で決まり、値は LUFS で表示します。 |
| Custom | **Detector** のレベルを追い、**Needle Response** で速さ、**Overshoot** で跳ね方が決まります。初期設定では VU と同じ指針の動きになります。 | 指針の動きとは別に **Dial** で選びます。 |

- ピークの印は直近の最大値を **Peak Hold** の時間だけ示します。オーバーランプはレベルが 0 dBFS を超えると点灯し、**Peak Hold** の時間（**Peak Hold** が 0 のときは 1 秒間）点灯し続けます。
- Loudness モードでは、先頭のメーターがプログラム全体を示します。指針は **Needle** の設定に従い、Momentary（M）、Short-term（S）、Integrated（I）、Loudness Range（LRA）、最大 True Peak の値、測定の経過時間と **Reset** ボタンを表示します。Integrated と LRA は、十分な長さの音声を測定すると表示されます。
  - モノラル、ステレオ、5.1（チャンネル順は L、R、C、LFE、Ls、Rs）では、規格どおりのチャンネル重みで測定します。それ以外のチャンネル数では全チャンネルを同じ重みで合算するため、値は参考値です。
  - 2 つ目以降のメーターは各チャンネル単独の値を示します。チャンネル重みもゲートもかけない参考値です。
- Integrated、LRA、最大 True Peak は、**Reset** を押す、**Mode** を切り替える、サンプルレートやチャンネル数が変わる、音声処理が再起動する、のいずれかが起きるまで蓄積されます。
- 処理が止まっている間は測定に含まれません。無音時の省電力による停止中、Master Bypass がオンのときや Analog Meter がオフのとき、設定の **非表示時は表示専用DSPをスキップ** がオン（初期状態）で Effect Pipeline が表示されていない間（Music Library の表示中、最小化中、ミニプレーヤー使用中など）がこれに当たります。再開すると、止まる前の値から測定を続けます。

## Chroma Spiral

音声を変えずに、音楽の周波数成分が12の音名と各オクターブのどこにあるかを示します。倍音が重なったときに強い音名を見たり、ボーカルとベースの音域を比べたり、楽器の成分が広がる範囲を確かめたりできます。

### 活用ガイド

- 一つの音を伸ばし、その音と倍音が螺旋のどこに現れるか見てみましょう。一音でも複数の音名が光ります。それぞれが別に演奏された音とは限りません。
- 和音やメロディーを流すと、強い成分の位置が移り変わります。調性の手掛かりにはなりますが、和音名や調を判定する表示ではありません。
- チューニングを見たいときは、明るいドットや塗りの外縁の山が音名の目盛りの間に出るか確認します。一つの基音のずれをセントで読むには Pitch Meter を使います。
- グラフをマウスや指、ペンで押すと、選んだ螺旋上の位置に対応するサイン波を試聴できます。ドラッグすると音の高さが変わり、離すか操作を中断すると止まります。どの **Color** 設定でも使えます。

### パラメーター

- **Color** - スペクトルの描き方を選びます。背景の螺旋ガイドはどの設定でも表示され、無音時にも残ります。
  - **Normal**（初期値）：各周波数の成分をテーマのグラフ描画色のドットで示します。明るさはその成分の強さに応じて変わり、ドットの面積も強さに比例して広がるため、弱い成分も見やすくなります。最大の強さでは、ドットの半径が隣の螺旋の周回との中間まで届きます。
  - **Normal 2**：各周波数の螺旋上の位置から強さに応じた外側までをグラフ描画色で塗り、データの輪郭線は描きません。
  - **Note Colors**：Normal と同じドット表示で、音名ごとに色を変えます。同じ音名はどのオクターブでも同じ色です。
- **Lowest Octave**（1～8、初期値1）- 表示する最も低いオクターブを設定します。上げると高い音域に絞れます。
- **Highest Octave**（1～9、初期値7）- 表示する最も高いオクターブを設定します。下げると低音と中音域に絞れます。上下の設定が逆転しないよう連動します。
- **Frequency Tilt**（-6～+6 dB/oct、0.5刻み、初期値+3）- 100 Hz より上の周波数の表示レベルを調整します。音声は変わりません。正の値では高い周波数を目立たせ、負の値では控えめにします。0 では周波数による補正をしません。
- **Level Range**（6～96 dB、1 dB刻み、初期値24）- 音量に追従して動く表示範囲の幅を設定します。狭めると強弱の差が目立ち、広げると強い成分とともに弱い成分も見やすくなります。
- **Display Floor**（-120～-24 dB、1 dB刻み、初期値-60）- 静かなときに、動く表示範囲の下端がどこまで下がれるかを設定します。下げると、選んだ **Level Range** 内の弱い成分も表示しやすくなります。表示範囲は直近のピークにも追従するため、弱い成分が必ず見えるとは限りません。

### 表示ガイド

- 螺旋の一周が一オクターブです。C は真上で、時計回りに音名が並びます。内側ほど低く、C の表示にオクターブ番号が付きます。
- **Normal** と **Note Colors** では音名の間も含め、ドットが明るく大きいほど、その位置の成分が強くなります。**Normal 2** では強い成分ほど塗りが外側へ広がり、輪郭線なしでも外縁からスペクトルの変化を追えます。
- ドットの明るさと面積、塗りの広がりは相対的な強さです。表示は直近のピークに追従するため、絶対レベルは読み取れません。
- 低音ほど隣り合う音を分けにくく、反応も遅くなります。低いオクターブでは近い音が重なって見えることがあります。

### ビジュアル表示
- 表示にマウスを重ねるか、タッチしてなぞると、その位置の値を読み取れます。

## Level Meter

音楽のデジタル信号レベルをリアルタイムで表示します。エフェクトをかけた後のレベル確認や、耳で歪みとして分かる前にクリッピングの可能性を見つけるのに役立ちます。

### 表示ガイド
- 信号レベルが大きくなるほど、横バーが右へ長く伸びます。
- 白いマーカーは新しいピークを1秒間保持し、その後なめらかに下がります。
- OVERLOADは、信号が安全なデジタル範囲を超えて歪む可能性があることを示します。
- きれいに再生するには、赤いレベルやOVERLOAD警告が頻繁に出ないようにし、実際の聴取音量は再生機器側で調整してください。

## Note Spectrogram

音声を変えずに、A0～C8 の範囲で推定した基本周波数（F0）を流れるピアノロールで表示します。和音の構成音、ボーカルやメロディーの動き、ベースライン、オクターブをまたいで重なる音を追うのに役立ち、音色別の色分けや強調表示も使えます。

### 活用ガイド

- **和音とメロディー**：和音は同じ時刻に並ぶ複数の明るい行として、メロディーやベースラインは音の行をたどる軌跡として見えます。
- **歌声やベースを追う**：**Instrument (3)** を選ぶか、**Note Colors** のまま **Highlight** で **Vocal** や **Bass** を選びます。より細かいグループ分けには **Instrument (9)** を使います。
- **推定の精度**：音高や音色の推定は、正確な採譜ではなく、聴きながら目で追うための手掛かりです。音の重なり、打楽器、ノイズがあると推定があいまいになることがあり、ドラムは分類しません。音色の推定は前の音を手掛かりにするため、有効にした直後や再生位置を動かした直後は信頼性が下がります。一度確定した推定は修正されません。

### 音色グループ

**Instrument (3)** は、**Vocal**、**Bass**、**Other**（下記のうち Vocal と Bass 以外のすべてのグループ）の 3 グループに分けます。

**Instrument (9)** は次の 9 グループに分けます：

- **Vocal**：録音された人の歌声（独唱と合唱）。
- **Bass**：アコースティックベース、エレキベース、シンセベース。
- **Guitar**：アコースティックギター、クリーンなエレキギター、歪みのあるギター。
- **Piano**：アコースティックピアノ、エレピ、ハープシコード、クラビネット。
- **Strings**：弦のソロとアンサンブル、ピチカート、ハープ、シンセストリングス。
- **Wind**：金管と木管（サックスやフルートなど）。
- **Synth**：シンセリードとパッド。
- **Organ**：オルガン、アコーディオン、ハーモニカ。
- **Other**：有音程打楽器（チェレスタ、ビブラフォン）、合成クワイア／ボイス系の音色、シンセ効果音、オーケストラヒット、民族楽器、効果音。

### パラメーター

- **Color** - 音高の検出結果は変えずに表示色を選びます（切り替えると既存の履歴も塗り直されます）。
  - **Normal**（初期値）：テーマのグラフ描画色。
  - **Note Colors**：音名ごとに色を変えます（同じ音名はどのオクターブでも同じ色）。
  - **Instrument (3)**：Vocal、Bass、Other ごとに色分けします。
  - **Instrument (9)**：上記の 9 つの音色グループごとに色分けします。
- **Highlight** - 指定したグループ（**Vocal**、**Bass**、**Other (3)**、**Guitar**、**Piano**、**Strings**、**Wind**、**Synth**、**Organ**、**Other (9)**）を強調します。そのグループに属する可能性が低い音ほど中立の灰色に近づけ、音量を示す太さは保ちます。**None**（初期値）では強調しません。
  - 音の始まりと音色の解析には追加の CPU を使います。CPU 負荷を最小にするには、**Onsets** をオフにし、**Normal** または **Note Colors** を選んで、**Highlight** を **None** にします。
- **Pitch Resolution** - 履歴を消さずに、縦方向の音高の細かさを選びます。
  - **1/12 Octave**（初期値）：半音ごとに 1 行。
  - **High**：推定したセント位置に音高を置き、ビブラートやピッチベンドを表示します。
- **Layout** - **Horizontal**（初期値、下に鍵盤、履歴は上へ流れる）または **Vertical**（右に鍵盤、履歴は左へ流れる）。
- **Volume** - バーの太さと鍵盤ぎわの半円メーターで相対音量を表します（初期値オン）。オフにするとバーの太さは一定になります。
- **Onsets** - 推定した音の始まりを三角形（Horizontal では ▼、Vertical では ▶）で示します（初期値オフ）。三角形の底辺の中央が発音の時刻と音高を示すため、持続中の同じ音を弾き直した場合も別々の印になります。オフにしても、Instrument の **Color** や **Highlight** が必要とする間は音色の解析が続きます。
- **Time Span**（1～10 s、初期値 2 s）- ピアノロールに表示する履歴の長さです。
- **Lowest Note** / **Highest Note** - 解析・表示する音域を設定します（初期値：E1～G6）。

### 表示ガイド

- **音高の更新**：新しい音はすぐに表示され、約 40、80、160 ms 後に、その後に続く音も手掛かりにして精度が上がります。表示の遅延は増えず、**表示を音声に同期** にも影響しません。
- **グリッドと鍵盤**：C ごとの線がオクターブの境界を示し、E と F の間の補助線はどのモードでも表示されます。黒鍵の行は背景が暗くなります。鍵盤は現在の音高推定の確信度に応じて光ります。
- **色の濃さ**：色の濃さは常に音高推定の確信度を示します。入力が小さすぎて解析できないときは、ピアノロールは暗いままです。
- **音色の色と強調**：音色の色は、推定確率に応じて各グループの色を混ぜたものです。音色の推定ができると、履歴の対応する位置に色が付きます。判定待ちの音は中立の灰色で表示されます。凡例には表示中のグループが並び、強調表示中はその後に **Highlight:** と選択したグループが続きます。凡例のグループにマウスを重ねると、一時的にそのグループを強調できます。
- **音量バー**：**Volume** がオンのとき、バーの太さは 24 dB の相対範囲で変わります。鍵盤ぎわの柔らかな半円は、現在の音量に合わせてすぐに上がり、20 dB/s で下がります。

### ビジュアル表示
- 履歴にマウスを重ねるか、タッチしてなぞると、音名、時刻、**Salience**（音高推定の確信度）、**Level**（dB）を読み取れます。音色の解析が動作しているときは、グループの推定確率も表示されます。**Instrument (3)** では **Vocal**、**Bass**、**Other**、それ以外では 9 グループで、**Highlight** のグループがその中にない場合はそれも加わります（推定のない音は **Not classified**）。

## Oscilloscope

音の波形の形をリアルタイムで表示します。ビート、鋭いアタック、音量の変化を聴きながら目で確認できます。波形が繰り返す場合は、トリガー設定で表示を安定させられます。

### 使い方の目安
- 繰り返す波形の 1 周期を見るには、**Display Time** を 1～20 ms、**Trigger Mode** を **Auto** にします。
- ビートや音量の変化を、右から左へ滑らかに流れる表示で追うには、**Display Time** を 1,000～10,000 ms、**Trigger Mode** を **Off** にします。
- **Auto** と **Normal** では、**Display Time** の長さ分の音が集まった時点で波形が更新されます。

### パラメータ
- **Display Time**（1～10,000 ms）- 表示する時間の長さです。短くすると波形の 1 周期ずつを、長くすると全体のエンベロープの変化を表示します。
- **Trigger Mode**：
  - **Auto**：トリガーがなくても更新を続けます。
  - **Normal**：トリガーが起きたときだけ更新し、次のトリガーまで最後の波形を保持します。
  - **Off**：右から左へ流れ続けます。トリガー設定は反映されません。
- **Trigger Level**（-1～1）- 取り込みを始める正規化振幅のしきい値です（モノラル信号、または左右の平均信号で検出します）。
- **Trigger Edge** - **Rising**（上向きに横切ったときにトリガー）または **Falling**（下向きに横切ったときにトリガー）。
- **Holdoff**（0.1～10 ms）- トリガー同士の最小の待ち時間です。
- **Display Level**（-96～0 dB、初期値 0 dB）- 表示の上端と下端に来るレベルを設定します。0 dB で ±1 の全範囲を表示し、下げるほど小さな信号を拡大します。
- **Vertical Offset**（-1～1）- 波形を上下にずらします。正の値で波形が上に動きます。

### 表示ガイド
- **横軸**：時間（ミリ秒または秒）。
- **縦軸**：正規化振幅。**Display Level** で拡大され、**Vertical Offset** で上下にずれます。
- **線と最小・最大の帯**：短い表示時間では波形を連続した線で描き、長い表示時間では最小値から最大値までを塗りつぶした帯で描きます。多くのサンプルが 1 ピクセル幅に重なっても、短いピークが見えるようにするためです。

### ビジュアル表示
- グラフにマウスを重ねるか、タッチしてなぞると、時間と振幅（長い表示時間では Minimum / Maximum）を読み取れます。

## Pitch Meter

音声を変えずに、一度に 1 つの基本周波数（F0）を 2 秒間の流れるピアノロールで追跡します。独唱や独奏のチューニングと音程の動きを確かめるのに使います。

### 活用ガイド

- 1 つの音を伸ばして演奏するか歌い、線が音の行の中央にとどまるか、高めや低めにずれていくかを見ます。
- ビブラート、スライド、ピッチベンドは、音の行を横切る滑らかな曲線として見えます。
- Pitch Meter は最も目立つ 1 つの音程だけを追うため、和音、音の密集したミックス、打楽器では線が途切れたり、オクターブが飛んだりすることがあります。複数の音が重なる素材には [Note Spectrogram](#note-spectrogram) を使います。
- ステレオ入力は先頭 2 チャンネルの平均を解析します（モノラル入力はそのまま使います）。そのため、左右で極性が逆の音は打ち消し合い、線が表示されないことがあります。

### パラメータ

- **Color** - 検出には影響させずに線の色を変えます。**Normal**（初期値、テーマのグラフ描画色）、**Heatmap**（24 dB の範囲での相対音量）、**Note Colors**（音名ごとの色）から選びます。
- **Layout** - **Horizontal**（初期値、下に鍵盤、履歴は上へ流れる）または **Vertical**（右に鍵盤、履歴は左へ流れる）。
- **Reference A4**（400～480 Hz、初期値 440 Hz）- 音名とセント差の基準となるチューニング周波数です。
- **Lowest Note** / **Highest Note** - 解析・表示する音域を設定します（初期値：C2～C7、設定範囲：A0～C8）。

### 表示ガイド

- 線の位置は、半音の間も含めた連続的な音程を示します。確信度が高いほど線が明るくなり、無音や音程のない音では線が途切れます。
- 読み値は、最も近い音名（音名ごとの色）と、セント単位のずれ（`+` は高め、`-` は低め。例：`+3.5 cent`）を示します。

### ビジュアル表示
- 表示にマウスを重ねるか、タッチしてなぞると、その位置の値を読み取れます。

## Rhythm Analyzer

音楽のテンポを求め、ドラムや楽器の発音がどこに来ているか、各パートがどれだけ早めや遅めに演奏されているかを 1 拍ずつ表示します。**Metronome Click** をオンにしない限り、音は変えません。曲の BPM を調べる、スウィングを測る、スネアがビートより後ろにあるかを見る、ドラムのフィルインや展開の変わり目を見つける、といった使い方ができます。

### 活用ガイド

- **テンポを確かめる**：ビートが一定の曲を再生します。確定した BPM と **adopted** の線は音から約 1～2 秒遅れて現れ、**LOCKED** はランプとクリックが拍を刻んでいる状態を示します。感じるテンポの倍や半分にロックした場合は、**×½**、**×2**、**strongest** を見比べます。
- **拍の位置を耳で確かめる**：**Metronome Click** をオンにすると、検出した拍ごとにクリック音が鳴ります。クリックを聴くときは Rhythm Analyzer をエフェクトチェーンの最後に置き、処理した音声ファイルを書き出す前には **Metronome Click** をオフにしてください。
- **倍テンポ・半テンポのロックを直す**：ゆったりしたバラードが倍のテンポでロックしたら **Max BPM** をその値より下げ、速い曲が半分のテンポでロックしたら **Min BPM** をその値より上げます。
- **グルーヴと細かなタイミングを読む**：打ち込みのビートでは点がレーンの中央近くに並び、**jitter** は 0 ms 近くになります。スネアがキックより常に 15 ms 遅れていると、2 拍目と 4 拍目で **Mid** の点がレーンの中央より上に並び、Beat lens には **+15** の印が出ます。
- **スウィングを読む**：**swing** は裏拍の遅れの比率を示します（1.00:1 がイーブン、2.00:1 が 3 連符のシャッフル）。スウィングするグルーヴでは、裏拍の発音が Beat lens の **&** ではなく **⅔** の列に集まります。
- **フィルインや展開の変わり目を見つける**：1～2 サイクル前の同じ拍位置では鳴っていなかった発音にリング（**◎**）が付くため、**Echo rows** でドラムのフィルインやセクションの切り替わりが目立ちます。
- **searching と表示されたとき**：新しい拍の点滅とクリックは止まりますが、解析は続きます。テンポ、Timing lanes、Beat lens は表示されたままで、確信度が下がるにつれて薄くなります。無音になると現在の拍の読み取り値と Tempogram の列が消え、音が戻ると解析を再開します。

### パラメーター

- **Min BPM**（40～192、初期値 40）/ **Max BPM**（50～240、初期値 240）- テンポを探す範囲です（**Max BPM** は **Min BPM** の 1.25 倍以上に保たれ、どちらかを変えると解析をやり直します）。
- **Metronome Click**（初期値オフ）- 検出した拍ごとに、−10 dBFS の短いクリック音をチャンネル 1 と 2（モノラルではチャンネル 1）に混ぜます。他のチャンネルは変わりません。
- **Span (beats)**（4、6、8、12、16、初期値 8）- Timing lanes と Echo rows の各行に表示する拍数です（例：4/4 拍子の 2 小節なら 8、3/4 拍子の 2 小節なら 6）。
- **Tempogram**、**Timing lanes**、**Echo rows**、**Beat lens** - 各表示パネルの表示・非表示を切り替えます（Timing lanes と Beat lens は初期状態でオン。パネルを隠しても解析は止まりません）。

### 表示ガイド

横長の画面では **Beat lens** が Timing lanes の右に置かれ、縦長の画面ではすべてのパネルが縦に並びます。発音は **High**（ハイハット、シンバル）、**Mid**（スネア、ボーカル、楽器）、**Low**（キック、ベース）の行に分けて表示されます。

- **ヘッダー**：拍に合わせて光るランプ（確信度が低いほど弱く、**searching** 中は白抜き）、確定した BPM（**LOCKED** または **searching**）、**×½**、**×2**、Tempogram の **strongest** 候補、**swing** 比（直近 32 拍から算出）、**jitter**（平均位置まわりの発音の典型的なばらつき、ms）、記号の凡例を表示します。まだ得られない値は — と表示されます。
- **Tempogram**：テンポの有力さを直近 20 秒分表示します。**Time** は左から右へ進み、**Tempo (BPM)** は 30～480 の対数目盛りです。実線の **adopted** テンポの線と、破線の **×2** / **×½** の線を重ねます。明るさは各テンポの相対的な有力さを示すもので、そのテンポが正しい確率ではありません。
- **Timing lanes**：直近 *N* 拍（**Span (beats)**。キャプションは **Last N beats**）の発音を表示します。点が大きいほど確かな発音で、最新の位置は暫定値として約 1～2 秒後に確定します。縦の棒の高さは、最も近い 16 分音符または 3 連符のグリッドに対する細かなタイミングを、直前 16 拍の典型的なタイミングと比べて示します（点線のガイドが **+20** / **−20** ms。中央より上は遅れ、下は早め。±30 ms を超える発音はレーンの端にとどまります）。白抜きの円（**○**）はタイミングが得られない発音（レーンの中央に表示）、網掛けはタイミング解析がない期間、リング（**◎**）は 1～2 サイクル前と比べて新しい発音、縦の破線は拍グリッドの合わせ直しを示します。
- **Echo rows**：過去の *N* 拍のサイクルを、新しいものを上にして縦に積み重ねるので、繰り返す小節のパターンは列にそろい、フィルインや変化が目立ちます。**Cycles ago** は行に 1 から番号を振ります。**Timing lanes** を隠しているときは、最上段が現在のサイクル（0）です。各発音は帯域を示しますが、タイミングは示しません。
- **Beat lens**：確定した直近 32 拍について、拍内の位置（**1**、**e**、**&**、**a**、**⅓**、**⅔**）ごとに各帯域が平均してどれだけ早め（印が左）または遅め（印が右）に演奏されているか（±30 ms のスケール）とそのばらつき（網掛けのバー、標準偏差の ±1 倍）をまとめます。ずれはアンサンブル全体に対する相対値で、印が不透明なほどその位置で頻繁に演奏されています。表示には 4 回以上の発音が必要で、3 ms 以上のずれにはラベルが付きます。拍の解析が得られるまでは **waiting for a steady beat** と表示されます。
- **確信度**：表示が暗いのは解析の確信度が低いことを示し、演奏が揺れていることを示すものではありません。
- **Reset**：他のアプリで曲を切り替えたときなどは、表示の下にある **Reset** ボタンで表示を消し、解析をやり直します。EffeTune のプレイヤーで新しい曲が始まると、解析は自動的にやり直されます。

### ビジュアル表示
- 表示にマウスを重ねるか、タッチしてなぞると値を読み取れます。Timing lanes と Echo rows では最も近い発音の何拍前か・帯域・タイミング（得られないときは —）、Tempogram ではテンポ・**Tempo support**・**Adopted** のテンポ、Beat lens では各帯域のずれとばらつきを表示します。

### 制限事項

- ルバートのある演奏、クラシック、ピアノ独奏、アンビエントやビートのない部分では、テンポと拍の追跡が不確かになります。拍が、感じるテンポの 2 倍、半分、2/3、1.5 倍、または裏拍にロックすることもあります（範囲を絞るには **Min BPM** / **Max BPM** を使います）。**LOCKED** は拍が正しいことを保証するものではありません。
- テンポが連続的に変わると拍の追従が少し遅れるため、クリックがわずかに早く、または遅くなることがあります。
- 音の密集したミックスやノイズの多い録音では、**Mid** と **High** のレーンに余分な点が出たり、**Low** のレーンで低いピアノの音を一部取りこぼしたりします。
- 追跡するのは拍で、小節線や拍子は追跡しません（1 拍目は判別しません）。
- 対応サンプルレート：8、11.025、16、22.05、24、32、44.1、48、88.2、96、176.4、192、352.8、384 kHz。それ以外のレートでは音声はそのまま通過しますが、解析とクリックは使えません。

## Spectrogram

音楽が時間とともにどう変化するかを表示します。色の濃さは各周波数成分の強さを、縦方向の位置は周波数を示します。

グラフは右から左へ一定の速さでスクロールし、1秒ごとの目盛りを表示します。

### 表示ガイド
- 色は周波数ごとの強さを示します：
  - 暗い色: 静かな音
  - 明るい色: 大きな音
  - 音楽に合わせてパターンが変化します。
- 縦方向の位置は周波数を示します：
  - 下部: 低音
  - 中央: 主な楽器や声の帯域
  - 上部: 高音域
- **Log (HQ)** では、近い低音がより分かれた帯として見えます。低域用の長い測定は、立ち上がりや消え際が少し遅くなります。

### ビジュアル表示
- 表示にマウスを重ねるか、タッチしてなぞると、その位置の値を読み取れます。

### 見えるもの
- メロディ: 色が流れる線
- ビート: 縦方向のストライプ
- ベース: 下部の明るい色
- ハーモニー: 複数の平行な線
- 楽器ごとに異なる独特のパターン

### パラメータ
- **DB Range** - 色の鮮やかさ（-144dBから-48dB）
  - 低い数値: より細かな音まで表示
  - 高い数値: 主な音に集中
- **Points** - 表示に使うFFTサイズ（256から16384）
  - 高い数値: 周波数の細かさが増える一方、時間方向の更新は遅くなります。
  - 低い数値: 動きは速くなりますが、周波数の細かさは下がります。
  - **Log (HQ)** では、Pointsが短い解析窓を決め、4倍長い窓で低域の近接した周波数をより分けて表示します。
- **Color** - **Normal**はテーマのグラフ描画色を使い、強い成分ほど明るく表示します。**Heatmap**（初期値）は従来の暗色から明色への多色表示です。切り替えると既存の履歴も塗り直します。
- **Frequency Scale** - **Log** は低域を広く表示します。**Log (HQ)** は高域の短い測定を保ちながら、低域に長い測定を加えて近い低音をより分けて表示します。処理負荷は増え、低域の変化は表示や消え際が少し遅くなりますが、音声は変わりません。**Linear** は等しい周波数幅を等間隔で表示します。
- **Keyboard** - 音名と周波数の対応を示す静的な鍵盤ガイドをグラフの右側に表示します。解析内容や音声は変えません。鍵の配置は **Log**、**Log (HQ)**、**Linear** に追従します。**Log (HQ)** は **Log** と同じ対数間隔で、**Linear** では低域の鍵が狭く見えます。
- このアナライザーは左右チャンネルの平均を使用します。モノ入力はそのまま解析されます。

## Spectrum Analyzer

深い低音から高い高音まで、音楽の周波数をリアルタイムで表示します。音楽全体を形づくる個々の成分を見るようなツールです。

### 表示ガイド
- 左側は低域を示します（ドラム、ベースギターなど）。
- 中央は主な帯域を示します（ボーカル、ギター、ピアノなど）。
- 右側は高域を示します（シンバル、きらめき、空気感など）。
- ピークが高いほど、その周波数の存在感が強いことを示します。
- 太い線は現在の音を示します。
- 細い線は直近のピークを追い、音が小さくなるにつれてなめらかに下がります。
- **Bar** 表示では、各バーは表示上の一定幅の範囲で最も高いレベルを示します。**Log** と **Log (HQ)** では各範囲が等しいオクターブ幅になり、**Linear** では等しい周波数幅になります。
- バーの上にある細い印は直近のピークを示し、なめらかに下がります。
- **Log (HQ)** では、近い低音が別々のピークとして見えやすくなります。低域用の長い測定は、立ち上がりや消え際が少し遅くなります。
- 楽器ごとに異なるパターンが出る様子を観察できます。

### ビジュアル表示
- グラフにマウスを重ねるか、タッチしてなぞると、その位置の値を読み取れます。

### 見えるもの
- ベースドロップ: 左側の大きな動き
- ボーカルメロディ: 中央の動き
- クリアな高音: 右側のきらめき
- フルミックス: すべての周波数がどう組み合わさっているか

### パラメータ
- **DB Range** - 表示の感度（-144dBから-48dB）
  - 低い数値: より細かな音まで表示
  - 高い数値: 主な音に集中
- **Points** - 近い周波数をどれだけ細かく分けて表示するか（256から16384）
  - 高い数値: 周波数の細かさが増えますが、更新は遅くなります。
  - 低い数値: 更新は速くなりますが、周波数の細かさは下がります。
  - **Log (HQ)** では、Pointsが短い解析窓を決め、4倍長い窓で低域の近接した周波数をより分けて表示します。
- **Color** - **Normal**（初期値）はテーマのグラフ描画色を使います。**Heatmap**はレベルが高いほど明るい色、**Note Colors**は周波数に対応する音名の色を使います。線とバーの両表示に適用されます。**Bar**と**Note Colors**を選ぶと、各バーとそのピークを帯域の中心周波数に対応する単色で描画します。
- **Frequency Scale** - **Log** は低域を広く表示します。**Log (HQ)** は高域の短い測定を保ちながら、低域に長い測定を加えて近い低音をより分けて表示します。処理負荷は増え、低域の変化は表示や消え際が少し遅くなりますが、音声は変わりません。**Linear** は等しい周波数幅を等間隔で表示します。
- **Display** - スペクトラムの見た目だけを変え、解析内容や音声は変えません。
  - **Line**（既定）: スペクトラムを連続した線で表示します。
  - **Bar**: 各表示帯域で最も高いレベルをバーで表示します。
- **Keyboard** - 音名と周波数の対応を示す静的な鍵盤ガイドをグラフの下側に表示します。解析内容や音声は変えません。鍵の配置は **Log**、**Log (HQ)**、**Linear** に追従します。**Log (HQ)** は **Log** と同じ対数間隔で、**Linear** では低域の鍵が狭く見えます。
- このアナライザーは左右チャンネルの平均を使用します。モノ入力はそのまま解析されます。

## Stereo Meter

ステレオ音声がどのように空間感を作っているかを見られる可視化ツールです。スピーカーやヘッドホンの間で音がどのように広がるかを観察でき、リスニング体験に視覚的な変化を加えます。

### 表示ガイド
- **ダイヤモンド表示** - 音楽の動きを表示するメイン画面：
  - 中央: 非常に静かな瞬間、または左右の合成信号がゼロに近い瞬間
  - 上下: センターやモノに近い音など、左右チャンネルに共通する成分
  - 左右: 左右チャンネルの差分や逆相成分
  - 片側がかなり強い音は、ラベル付きの角方向に現れることがあります。
  - 緑の点が現在の音楽に合わせて動きます。
  - 白い線が音楽のピークをたどります。
  - 白いピーク線は音声サンプルごとに減衰するため、音声処理のブロックサイズが変わっても動き方は一定です。
- **Correlation Bar**（左側）
  - 左右チャンネルの相関を表示します。
  - 上部（+1.0）: 左右がほぼ同じで、中央にまとまりやすい音
  - 中央（0.0）: 左右の関係が弱く、広い響きや左右で異なる成分が多い音
  - 下部（-1.0）: 左右がほぼ逆極性で、スピーカー再生では弱く聞こえる場合があります。
- **Balance Bar**（下部）
  - 片方のスピーカーがもう片方より大きいかを表示します。
  - 中央: 両方のスピーカーで同じ音量
  - 左/右: 片側の音が強い。
  - 数値はデシベル（dB）単位の音量差を示します。

### 見えるもの
- **センターの音**: 中央付近の強い縦方向の動き
- **広がりのある音**: 表示全体に広がる動き
- **特殊な効果**: 角付近に出る興味深いパターン
- **スピーカーバランス**: 下部バーが示す方向
- **チャンネル相関**: 左側の相関バーが示す状態

### パラメータ
- **Window**（10-1000 ms） - 表示に使う直近の音の長さ
  - 低い値: 素早い音楽の変化を見やすい。
  - 高い値: 全体的な音のパターンを見やすい。
  - デフォルト: 100 msは多くの音楽に適しています。
- **Gain**（0～24 dB、初期値0 dB）- ダイヤモンド内の点とピーク線だけを拡大します。値を上げると小さな音の広がりも見やすくなります。音声や相関・バランスの表示値は変わりません。

### 音楽を楽しむために
1. **スタイルの違いを見る**
   - クラシック音楽は穏やかでバランスの取れたパターンを示すことが多い。
   - 電子音楽は大きく広がる模様を作ることがあります。
   - ライブ録音では自然な部屋の動きが見えることがあります。

2. **音の性質を発見する**
   - アルバムごとのステレオ効果の使い方を見る。
   - 曲によって広がりの感じ方が違うことに気づく。
   - 楽器がスピーカーの間でどう動くかを観察する。

3. **体験を深める**
   - 異なるヘッドホンでステレオ表示の違いを試す。
   - 好きな曲の古い録音と新しい録音を比べる。
   - リスニング位置を変えたときの表示の違いを見る。

## これらのツールの楽しい使い方

1. 音楽を探索する
   - ジャンルごとに異なるパターンを観察する。
   - アコースティック音楽と電子音楽の違いを見る。
   - 楽器がどの周波数帯域を占めているかを観察する。

2. 音について学ぶ
   - 電子音楽のベースを目で見る。
   - ボーカルメロディが表示上で動く様子を見る。
   - ドラムが鋭いパターンを作る様子を観察する。

3. 体験を広げる
   - Level Meterで、エフェクト追加後の信号ピークを確認する。
   - Spectrum Analyzerが音楽に合わせて動く様子を楽しむ。
   - Spectrogramで視覚的なライトショーのように楽しむ。

これらのツールは、音楽を聴く楽しみに視覚的な要素を加えるためのものです。お気に入りの音楽を新しい方法で見ながら、自由に探索してみてください。
