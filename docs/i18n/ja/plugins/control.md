# 制御エフェクト

制御エフェクトは、オーディオを直接処理するのではなく、他のエフェクトの動作を管理するための特殊なユーティリティです。複雑なエフェクトチェーンを整理し、扱いやすくするのに役立ちます。

## Live Audio Receive

別のEffeTuneから届くライブ音声を、この位置から処理します。前段のエフェクトは実行されず、後段のエフェクトが受信音にかかります。通常の曲や識別できないストリームは、従来どおり先頭から処理します。調整するパラメーターはありません。

受信側で使いたいエフェクトの前に配置します。実際に受信しているマーカーには「Receiving live audio · Processing starts here」と表示されます。マーカーがない場合や、マーカーまたは所属するSectionがオフの場合は、先頭から処理します。受信したライブ音声はNetwork Outputから再送されません。

## Live Audio Send

この位置の音をNetwork Outputに送り、同時にローカルの後段エフェクトにも通します。たとえば、共通のEQを前に置き、ローカル用のRoom EQを後ろに置けます。Network Outputを有効にして受信先を選んでください。調整するパラメーターはありません。

有効なマーカーがなければ、Network Outputはパイプラインの最終出力を送ります。同じ種類のマーカーが複数有効な場合は先頭だけが使われ、後続には別のマーカーが使われていることが表示されます。マスターバイパス中も通常の経路を使います。

## Section

Section エフェクトは複数のエフェクトをグループ化し、その部分のチェーン全体を1つのON/OFFトグルでバイパスしたり元に戻したりできます。各エフェクト自身のON/OFF設定は保持されます。

### 概要

- **名前**: Section
- **カテゴリ**: Control
- **説明**: エフェクトをグループ化し、セクション全体をまとめてバイパスしたり元に戻したりします。

### パラメータ

| パラメータ | 説明 |
|-----------|------|
| Comment   | セクションの目的を示す名前または説明 |

### 使用方法

1. まとめて制御したいエフェクトグループの先頭に Section エフェクトを配置します。
2. 「Comment」フィールドに、セクションの目的が分かる名前を入力します。
3. Section エフェクトをOFFにすると、そのセクション内のエフェクトをバイパスします。ONに戻すと、各エフェクト自身のON/OFF状態を保ったままそのセクション内の処理を再び通します。
4. Section エフェクトの後に置かれたエフェクトは、次の Section エフェクトが現れるまで、そのセクションの対象になります。

### 応用例

- 関連するエフェクトをまとめる（例: 「EQ調整」「空間系エフェクト」）。
- 簡単に切り替えられる別の処理チェーンを作る。
- 複雑なエフェクトチェーンを分かりやすいまとまりに整理する。
- エフェクトを削除せずに、一部のグループだけを一時的に無効化する。
