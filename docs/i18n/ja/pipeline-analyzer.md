# Pipeline Analyzer

Pipeline Analyzerは、再生中の音を変えずに、現在のEffect Pipelineの特性を測定します。広いウィンドウではパイプラインの横に、狭いウィンドウではパイプラインのヘッダーの下に表示されるため、エフェクトを調整しながら特性の変化を確認できます。

Effect Pipelineヘッダーのグラフボタン、またはデスクトップ版の**表示 > Pipeline Analyzer**から開きます。**Auto**を有効にしていると、パイプラインを編集するたびに自動で再測定します。**Auto**をオフにすると、パイプラインの編集は**Refresh measurements**をクリックしたときだけ再測定されます。チャンネル、スピーカー特性、測定設定を変更したときは、常に再測定します。

## チャンネルとスピーカー特性の選択

現在のパイプライン（最大16チャンネル）から入力チャンネルを1つ選び、**+ Add Output**で出力チャンネルを最大4つまで選びます。出力は常に1つ以上残るため、最後の1つは削除できません。出力を削除すると、そのスピーカー特性の設定も削除されます。

各出力には、**No speaker IR**、または接続したスピーカーやドライバーの保存済み測定ポイントを指定できます。
- **スピーカーIRを使わない場合:** **Before**は理想的なフラットの基準インパルスで、**After**はエフェクトパイプライン単体の特性を示します。
- **スピーカーIRを使う場合:** **Before**は選択したスピーカー測定の合成特性、**After**はパイプラインで各出力を処理した後の合成特性です。これにより、**Channel Divider**や**FIR Crossover**を、実際のドライバーの測定結果と合わせて確認できます。

保存したスピーカー特性が利用できなくなった場合は、置き換えるか解除するまで選択されたまま「—」と表示されます。

個別のスピーカー測定は検出された立ち上がり位置で揃えられ、ドライバー間の物理的な到達時間差は保たれません。そのため、合成特性を評価する前に、ドライバー間の相対ディレイと極性をパイプラインで設定してください。

## 測定設定

**Measurement settings**を開くと、パイプラインの測定方法を調整できます。

- **Signal:** **Log Sweep**（既定）、**MLS**、**TSP**、**Unit Impulse**から選びます。高調波歪みも調べる場合は**Log Sweep**を使います。スイープの帯域はサンプリング周波数で扱える範囲内の20 Hz～20 kHzです。**MLS**と**TSP**は周期信号を使い、**Unit Impulse**はインパルス応答を直接収録します。
- **Level:** テスト信号のピークレベル（既定値 `-12 dBFS`）。線形フィルターはどのレベルでも同じ結果になりますが、コンプレッサーやサチュレーターなど、レベルに依存するエフェクトの結果は**Level**によって変わります。
- **Requested sweep length**（**Log Sweep**）／**Sequence Length**（その他の信号）: **Log Sweep**で指定する長さの既定値は`131072`サンプルです。高調波を分離するために指定値より長いスイープが使われる場合があり、実際の**Sweep length**と**Total stimulus time**は測定後に表示されます。ただし、得られる応答は主ピークから最大1.5秒後までで、スイープを長くしてもこの範囲は延びません。それより長いリバーブの余韻、ディレイ、フィルターのリンギングを確認するには、**MLS**、**TSP**、**Unit Impulse**のいずれかを選び、必要に応じて**Sequence Length**を長くしてください。
- **Stabilization Periods:** 収録前に再生する周期数（既定値`12`、MLSとTSPで使用）。ゆっくり変化するエフェクトが落ち着くのを待ちます。**Log Sweep**と**Unit Impulse**では設定できません。
- **Averages:** 複数回の収録結果を平均する回数（既定値`2`、**Log Sweep**、MLS、TSPで使用）。ばらつきを抑えます。

## グラフの見方

プロットの上にある**Graph**セレクターで、再測定せずに表示を切り替えられます。

- **Frequency:** 周波数に対する振幅特性（dB）。0 dBを基準とします。
- **Phase:** 周波数に対する位相特性（度）。
- **Min Group Delay:** 最小位相の振幅特性から導かれる群遅延。
- **Excess Group Delay:** 最小位相成分を取り除いた残りの群遅延（プロットは±100 msの範囲に制限されますが、カーソル位置の読み取り値には実際の値が表示されます）。純粋なディレイや、リニアフェーズ、オールパスによる時間のずれを見つけやすくなります。
- **Impulse:** `-2 ms`から**Impulse Range (ms)**までの時間領域のインパルス応答。ピークで正規化されます。
- **Distortion:** **Log Sweep**で測定した、周波数ごとの基音に対する高調波歪みを%で示します。初期状態ではH2、H3、THD（2～3次）を表示し、再測定せずにH4～H10を追加できます。値が大きいほど歪みが多いことを表します。他の信号で利用できない場合は**Log Sweep**を選んでください。出力が無音など、有効なデータが得られない場合は表示できません。保存済みのスピーカー特性は線形応答として反映され、スピーカー自体の歪みは示しません。
- **Waterfall:** 周波数、相対レベル（dB）、減衰時間（ms）を表示します。**Response**で**After**（既定）と**Before**を切り替え、パイプライン処理後と、処理前のスピーカー特性を確認できます。各表示はそれぞれのピークを基準にするため、絶対レベルではなく減衰の形を比べてください。3Dグラフをドラッグして回転し、ホイールやピンチで拡大・縮小できます。

周波数、位相、群遅延、インパルスのグラフにポインターを置くと、カーソル位置の**Before**と**After**の値を読み取れます。凡例の**Before**ラベルにポインターを置くと、**After**が一時的に隠れます。周波数、位相、群遅延のプロットには**Smoothing (oct)**を、インパルスのプロットには**Impulse Range (ms)**を使います。

## 測定のしくみ

Pipeline Analyzerは、現在のパイプライン、そのルーティング、選択したスピーカー特性を取り込んで測定し、パイプラインから報告されたレイテンシーを**After**で自動的に補正します。非線形、変調、ランダムなエフェクトでは、プロットを現在の設定と**Level**でのスナップショットとして見てください。
