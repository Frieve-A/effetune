# コントローラーマッピング

コントローラーマッピングを使うと、画面上の操作子をドラッグせずにエフェクトのパラメーターを調整できます。EffeTuneにフォーカスがある間、MIDIコントローラー、ゲームパッド、キーボードのキーを使えます。変更にはエフェクト画面と同じパラメーター範囲が使われ、画面表示にも反映されます。

## マッピングを追加する

1. **設定**を開き、**コントローラーマッピング...**を選びます。
2. **追加（Learn）**を選びます。
3. MIDIの操作子を動かすか、キーを押すか、ゲームパッドのボタンや軸を操作します。
4. 対象のエフェクト、インスタンス規則、パラメーターを選びます。
5. 必要に応じて、最小、最大、感度、方向、入力モードを調整します。変更はすぐに保存されます。

増加と減少を別々のボタンやキーに割り当てるには、マッピングを2つ使います。一方の**方向**を**増加（+）**に、もう一方を**減少（−）**にします。Learnで覚えたキーがEffeTuneのショートカットと重なる場合はダイアログに警告が表示されますが、アプリにフォーカスがある間はマッピングが優先されます。

ボタンのマッピングでは、**ボタンモード**を選びます。**トグル**は押すたびに状態を切り替え、**モーメンタリー**は操作子を押している間だけ有効にします。

## 操作対象を選ぶ

- **先頭**は、現在のパイプラインで最初に一致するエフェクトを操作します。
- **末尾**は、最後に一致するエフェクトを操作します。
- **すべて**は、一致するすべてのエフェクトに同じ値を送ります。相対操作の開始値には先頭のエフェクトの値を使います。
- **有効**は、エフェクトのオン/オフを切り替えます。

**全体操作**では、エフェクトではなくアプリと音楽プレーヤーを操作します。**マスターバイパス**、**A/B切替**、**再生/一時停止**、**停止**、**次/前のトラック**、**10秒送り/戻し**、**再生速度**、**ピッチ固定**、**リピート**、**シャッフル**、**次/前のプリセット**を選べます。

- **次/前のトラック**、**10秒送り/戻し**、**次/前のプリセット**では、**方向**で**増加（+）**（先へ）または**減少（−）**（前へ）を選びます。エンドレスエンコーダーやジョグホイールでは、回した向きに従います。
- **再生速度**は、フェーダーやノブでは連続して変わり（中央で`1x`）、ボタンやキーに割り当てると標準の速度を1段ずつ切り替えます。
- **次/前のプリセット**は、ユーザープリセットを名前順に切り替え、端まで来ると反対側の端に戻ります。
- プレーヤーの操作には、音楽プレーヤーを開いておく必要があります。ブラウザーの自動再生の制限で音声を開始できない場合は、先にプレーヤーの画面で再生を押してください。

**最小**と**最大**は、パラメーターの使用範囲を（パラメーターの単位で）制限します。両者を入れ替えると操作方向が反転します。**感度**は相対操作の1回あたりの変化量を拡大・縮小します（まずは`1`から始めてください）。

## 時刻やランダム動作で自動化する

物理コントローラーを使わずに数値のエフェクトパラメーターを自動的に変化させるには、**自動化を追加**を選びます。先に対象のエフェクトとパラメーターを選んでから、次の項目を設定します。

- **入力**: **タイマー**（既定、1秒間隔）または**時計**を選びます。
- **時計**: **時刻要素**で**時**、**分**、**秒**を、**変化パターン**で**上昇**、**サイン**、**コサイン**を選びます。現在のローカル時刻を1秒に1回読み取り、**最小**と**最大**の間に割り当てます。
- **タイマー**: **スケジュール**では**間隔**、**一度だけ**、**毎日**を選べます。**間隔**では、`1`〜`2,147,483.647`秒の**間隔（秒）**を使います。**一度だけ**はローカルの**日付**と**時刻**に実行し、**毎日**は1日に1回、ローカルの**時刻**に実行します。
- **動作**（タイマーと、数値パラメーターに割り当てたボタンやキー）: **指定幅で変更**は毎回**変化量**を加算または減算し、**範囲からランダム**は**最小**と**最大**の間から新しい値を選び、**現在値からランダムに上下**は**変化量**だけランダムに上か下へ動かします。

時計とタイマーの自動化は、エフェクトの数値パラメーターにのみ適用され（**有効**、選択式のパラメーター、**全体操作**は対象外）、実行は最大で1秒に1回です。**間隔**のタイマーの実行時刻にアプリが一時停止していたりコンピューターがスリープしていたりした場合は、再開時に1回だけ実行し、そこから次の間隔を数えます。EffeTuneを閉じている間に時刻を過ぎた**一度だけ**の予定は**期限切れ**と表示されます。もう一度有効にするには、未来の**日付**または**時刻**を設定してください。

### 設定例

- Vinyl SimulatorのRadius: **タイマー**を使い、**間隔（秒）**を`1`にして**指定幅で変更**を選びます。**方向**を**減少（−）**、**変化量**を`1 mm`にし、**最小**と**最大**を`60`と`146 mm`にすると、針が外周から内周へ動き、**最小**で止まります。
- 時刻による音色の変化: **時計**で**分**と**サイン**を使うと、Radio Simulatorの数値パラメーターを**最小**と**最大**の間で滑らかに変化させられます。
- ゆっくりとしたランダムな変化: **タイマー**の間隔を長めにして**現在値からランダムに上下**を使います。**変化量**を小さめにして始めると、変化が緩やかになります。
- 予定した変更: 特定のローカル日時に一度だけ変えるには**一度だけ**を、毎日同じローカル時刻に変えるには**毎日**を選びます。

## 入力の種類

### MIDI

EffeTuneは、Web MIDIを通じてMIDI CC、ノート、ピッチベンドに対応します（Chromium系ブラウザー、Firefox、デスクトップアプリで利用でき、Safariには対応していません）。汎用デバイスでは絶対値のCC入力が既定です。エンドレスエンコーダーには相対モードを選んでください。BLE-MIDIやネットワークMIDIは、OSのMIDIポートとして認識されていれば使えます。

### Mackie Control（MCU）

対応するコントロールサーフェスでは、デバイスのプロトコルを**MCU**に設定します。モーターフェーダー、フェーダータッチ、V-Pot入力、LEDリング、ボタンLEDに対応しています（LCDの文字表示、レベルメーター、タイムコード表示、デバイスのハンドシェイクは使いません）。デバイスを**Generic**と**MCU**の間で切り替えた後は、マッピングをLearnし直してください。

### ゲームパッド

ボタンでは、パラメーターの切り替えや段階的な変更ができ、押し続けると繰り返します。軸は既定で相対モードなので、中央に戻るスティックから手を離しても、パラメーターは離したときの値のまま残ります。スロットルのように位置が保たれる軸では、絶対値モードに切り替えてください。

### キーボード

キーボードマッピングはEffeTuneにフォーカスがある間に働き、テキスト欄への入力中は無視されます。トグルのマッピングはキーリピートを無視し、増加/減少のマッピングは、キーを押し続けるとOSのキーリピートの速さで繰り返します。

## 接続とトラブルシューティング

各MIDIデバイスの名前の下には、**接続中**または**切断状態**と表示されます。コントローラーを外してもマッピングは保存されたままで、同じMIDIポート名またはゲームパッド名のデバイスが戻ると自動的に再接続します。ドライバーやOSの更新でデバイス名が変わった場合は、該当するマッピングをLearnし直してください。同じ名前のゲームパッドはマッピングを共有し、同じ名前のMIDIポートは接続した順番でのみ区別されます。MIDIデバイスが表示されない場合は、MIDIの権限を許可してから**コントローラーマッピング...**を開き直してください。Safariでも、キーボードとゲームパッドのマッピングは使えます。
