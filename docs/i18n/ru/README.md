Процессор аудиоэффектов реального времени для аудиоэнтузиастов, которые хотят сделать прослушивание музыки ещё лучше. EffeTune позволяет пропускать звук из любого источника через разнообразные высококачественные эффекты и настраивать звучание под себя в реальном времени.

## Концепция

EffeTune создан для аудиоэнтузиастов, которые хотят улучшить прослушивание музыки. Независимо от того, слушаете ли вы стриминг или воспроизводите музыку с физических носителей, EffeTune позволяет добавлять высококачественные эффекты и настраивать звук под свои предпочтения. Превратите компьютер в мощный процессор аудиоэффектов между источником звука и колонками или усилителем.

Без аудиофильских мифов, только чистая наука.

## Особенности

- Обработка аудио в реальном времени
- Интерфейс drag-and-drop для создания цепочек эффектов
- Расширяемая система эффектов с категоризированными эффектами
- Визуализация аудио в реальном времени
- Настраиваемые композиции Visualizer с анимированными графиками, обложкой и сведениями о треке
- Аудиотракт, который можно изменять в реальном времени
- Офлайн обработка аудиофайлов с использованием текущей цепочки эффектов
- Музыкальная библиотека для просмотра локальных подпапок, метаданных и плейлистов
- Компактный мини-плеер поверх всех окон для настольного приложения
- Измерение и коррекция частотной характеристики для калибровки системы
- Многоканальная обработка и вывод
- Удобный интерфейс веб-приложения для телефонов и планшетов

## Руководство по настройке

Выберите ниже способ настройки для источника звука, который хотите слушать.

### Настройка проигрывателя музыкальных файлов

- Откройте веб-приложение EffeTune в браузере или запустите настольное приложение EffeTune
- Откройте и воспроизведите музыкальный файл для проверки правильности воспроизведения
   - Нажмите кнопку **Открыть музыкальные файлы** и выберите музыкальный файл
   - Или откройте музыкальный файл и выберите EffeTune в качестве приложения (только для настольного приложения)
   - Или выберите **Открыть музыкальный файл...** из меню **Файл** (только для настольного приложения)
   - Или перетащите музыкальный файл в окно
- Если EffeTune нужен только как проигрыватель, выберите в окне **Настройка аудио** для параметра **Входное устройство:** значение **Нет (только проигрыватель музыкальных файлов)**, чтобы не использовать внешний аудиовход. Это значение по умолчанию в настольном приложении. Если вы уже сохранили выбор входного устройства, приложение продолжит использовать его.

### Встроенный браузер настольного приложения

В настольном приложении **Браузер** позволяет слушать звук с сайтов через текущую цепочку эффектов без виртуального аудиоустройства.

1. Нажмите **Браузер** в заголовке. Начнётся обработка звука браузера.
2. Введите адрес HTTP или HTTPS, войдите в аккаунт и запустите музыку средствами сайта. Если протокол не указан, используется HTTPS.
3. Переключитесь на **Effect Pipeline**, чтобы настроить звук. При смене экрана звук браузера продолжает воспроизводиться.

Используйте Назад, Вперёд, Обновить и Остановить загрузку для навигации. Откройте **Закладки**, чтобы добавить текущую страницу, открыть сохранённую, переименовать закладку или удалить её. В меню браузера доступны **Открыть стартовую страницу**, **Открыть в браузере по умолчанию**, **Сделать стартовой страницей** и **Очистить данные сайтов**. Закладки и стартовая страница сохраняются. Вход в учётные записи на сайтах сохраняется отдельно и доступен после перезапуска приложения. Масштаб страниц в браузере соответствует масштабу приложения.

Когда фокус находится на панели браузера, **F5** обновляет страницу, **F6** выделяет адрес, **Alt+Влево/Вправо** выполняет переход назад или вперёд, а **Alt+Home** открывает стартовую страницу. Эти клавиши работают и внутри страницы. Если фокус находится на странице, **Ctrl/Cmd+L** выделяет адрес, **Ctrl/Cmd+R** обновляет страницу, а **Ctrl/Cmd+D** открывает закладки. В macOS для перехода назад и вперёд также можно использовать **Cmd+[/]**. **Escape** останавливает загрузку. Щелчок правой кнопкой по странице открывает команды навигации, по ссылке — команды открытия здесь или в браузере по умолчанию и копирования адреса, а по выделенному тексту или полю ввода — доступные команды редактирования. Вне страницы сочетания клавиш приложения сохраняют свои обычные функции.

При открытии раздела **Браузер** или возвращении в него звук браузера выбирается автоматически. Звук браузера смешивается со звуком выбранного устройства ввода. Выберите **Нет** для устройства ввода, чтобы слушать только браузер. Параметр аудиовхода проигрывателя не влияет на воспроизведение в браузере. Локальная музыка может воспроизводиться одновременно со звуком браузера. Если захват звука прервался, нажмите **Браузер** ещё раз. **Очистить данные сайтов** выполняет выход из учётных записей и удаляет сохранённые данные сайтов, оставляя закладки.

Нажмите **Закрыть** на панели инструментов браузера, чтобы остановить обработку его звука и вернуться в **Effect Pipeline**. Страница и история просмотра сохраняются. Откройте **Браузер** снова, чтобы возобновить обработку звука на той же странице.

В разделе **Настройки > Конфигурация... > Браузер** доступны следующие параметры:

- **Начальная страница** — HTTP- или HTTPS-адрес страницы, которая появляется при первом открытии браузера. По умолчанию поле пустое; если оно пустое, открывается [руководство EffeTune по стримингу](https://effetune.frieve.com/streaming/). Кнопка **Сбросить** очищает поле, не меняя текущую страницу.
- **Открывать новые вкладки в браузере по умолчанию** — включено по умолчанию. Отключите этот параметр, чтобы такие ссылки открывались в браузере приложения EffeTune. Отдельные окна, например для входа в аккаунт, в обоих случаях остаются внутри EffeTune.
- **User-Agent** — строка, по которой сайты определяют браузер. По умолчанию браузер представляется совместимым с Chrome, а строка также содержит название EffeTune. Оставьте поле пустым или нажмите **Сбросить**, чтобы восстановить значение по умолчанию. После изменения перезагрузите страницу в браузере.

Чтобы автоматически переключать эффекты для разных сайтов, сначала сохраните цепочки как пресеты. В разделе **Правила URL** нажмите **Добавить правило**, введите сайт и путь, например `example.com/music/*`, и выберите пресет цепочки. Не указывайте `http://` или `https://`, параметры запроса и фрагменты `#`; `*` соответствует любому тексту. Задайте приоритет кнопками перемещения вверх и вниз, затем нажмите **Сохранить правила**. Применяется первое включённое правило, которое совпадает с адресом и имеет доступный пресет.

Правила действуют, пока выбран звук браузера, в том числе при переходе в другой раздел приложения. Сохранение правил, открытие браузера или переход на подходящую страницу может загрузить её пресет. При переходах между страницами с тем же пресетом ручные настройки сохраняются. Если ни одно правило не подходит, текущая цепочка не меняется.

Некоторые сайты запрещают встроенные браузеры, вход в аккаунт, защищённое воспроизведение или захват звука. Доступность зависит от сайта и ОС; воспроизведение с DRM не гарантируется. Если вход запрещён, попробуйте другой способ, предложенный сайтом, или обычный браузер. Вход в обычном браузере не выполняет вход внутри EffeTune. Браузер доступен только в настольном приложении.

### Настройка расширения браузера

Обрабатывайте до четырёх вкладок Chrome или Edge с отдельными цепочками эффектов, выбором пресета по URL и настройкой частоты дискретизации без виртуального аудиоустройства. См. [руководство по расширению браузера](browser-extension.md).

1. Установите расширение EffeTune из магазина [Chrome](https://chromewebstore.google.com/detail/effetune/fhjhnpepnhkcdggogicifibfegpbhibp) или [Edge](https://microsoftedge.microsoft.com/addons/detail/effetune/kjpcfdidpphaclfkfdahchhibgjcngdk).
2. Запустите воспроизведение во вкладке, звук которой хотите обработать, откройте EffeTune на панели инструментов браузера и выберите **Start on this tab**.
3. Выберите **Edit pipeline**, чтобы добавить эффекты и настроить звук.

### Настройка потокового сервиса

Для обработки аудио из потоковых сервисов (Spotify, YouTube Music и т.д.):

В настольном приложении сначала попробуйте [встроенный браузер](#встроенный-браузер-настольного-приложения). Для отдельного приложения потокового сервиса или источника, который встроенный браузер не воспроизводит, используйте настройку аудиоустройства ниже.

1. Необходимые условия:
   - Установите виртуальное аудио устройство (например, VB Cable, Voice Meeter или ASIO Link Tool)
   - Настройте ваш потоковый сервис на вывод аудио через виртуальное устройство

2. Конфигурация:
   - Откройте веб-приложение EffeTune в браузере или запустите настольное приложение EffeTune
   - Выберите виртуальное аудио устройство в качестве источника входного сигнала
     - В Chrome при первом открытии появится диалоговое окно с запросом на выбор и разрешение аудио входа
     - Откройте **Настройка аудио...** в меню **Настройки**, чтобы выбрать устройства ввода/вывода и формат аудио
   - Начните воспроизведение музыки из вашего потокового сервиса
   - Убедитесь, что аудио проходит через EffeTune
   - Подробные инструкции по настройке см. в [FAQ](faq.md)

### Настройка физического аудио источника

Чтобы использовать EffeTune с CD-плеерами, сетевыми плеерами или другими физическими источниками:

- Подключите аудиоинтерфейс к вашему компьютеру
- Откройте веб-приложение EffeTune в браузере или запустите настольное приложение EffeTune
- Выберите ваш аудиоинтерфейс в качестве источника входного и выходного сигнала
   - В Chrome при первом открытии появится диалоговое окно с запросом на выбор и разрешение аудио входа
   - Откройте **Настройка аудио...** в меню **Настройки**, чтобы выбрать устройства ввода/вывода и формат аудио
- Теперь ваш аудиоинтерфейс функционирует как многоэффектный процессор:
   * Вход: CD-плеер, сетевой плеер или другой источник звука
   * Обработка: эффекты в реальном времени в EffeTune
   * Выход: обработанный звук на усилитель или колонки

## Использование

При первом запуске краткий обзор покажет, где воспроизводить музыку, добавлять эффекты и настраивать звук. Обзор можно повторить в любое время: выберите **Обзор приложения** в меню настроек, в меню **Помощь** настольного приложения или через кнопку меню на мобильном устройстве.

### Создание цепочки эффектов

1. Доступные эффекты перечислены в левой части экрана
   - Используйте кнопку поиска рядом с "Available Effects", чтобы отфильтровать эффекты
   - Введите текст для поиска эффектов по названию или категории
   - Нажмите ESC, чтобы очистить поиск
2. Перетащите эффекты из списка в область Effect Pipeline
   - На мобильном устройстве откройте вкладку **Эффекты** и нажмите кнопку **+**, чтобы добавить эффекты из полноэкранного списка
3. Эффекты обрабатываются в порядке сверху вниз
4. Перетащите маркер (⋮) или нажмите кнопки ▲▼ для изменения порядка эффектов
   - Для эффектов Section: Shift+нажатие кнопок ▲▼ для перемещения целых секций (от одной Section к следующей Section, начало цепочки или конец цепочки)
5. Нажмите на название эффекта, чтобы развернуть/свернуть его настройки
   - Shift+нажатие на эффект Section сворачивает/разворачивает все эффекты в этой секции
   - Shift+нажатие на другие эффекты сворачивает/разворачивает все эффекты, кроме категории Analyzer
   - Ctrl+нажатие сворачивает/разворачивает все эффекты
6. Используйте кнопку ON, чтобы обходить отдельные эффекты
7. Нажмите кнопку ? для открытия подробной документации в новой вкладке
8. Удалите эффекты, используя кнопку ×
   - Для эффектов Section: Shift+нажатие кнопки × для удаления целых секций
9. Нажмите кнопку маршрутизации, чтобы настроить каналы для обработки и входные и выходные шины
   - [Подробнее о функциях шин](bus-function.md)
10. Нажмите кнопку Пресеты эффекта у эффекта, чтобы сохранить или применить настройки только для этого эффекта

### Поиск музыки в музыкальной библиотеке

Вы можете организовать музыкальные файлы, хранящиеся на вашем устройстве, в библиотеку.

1. Откройте **Музыкальная библиотека** кнопкой в заголовке на ПК, вкладкой **Библиотека** в мобильном интерфейсе или через **Вид > Музыкальная библиотека** в настольном приложении.
2. Выберите **Добавить папку с музыкой**, чтобы проиндексировать папку с музыкальными файлами. Внешние файлы CUE позволяют разделить альбомные файлы WAV или FLAC из той же папки на отдельные треки.
3. Просматривайте разделы **Треки**, **Альбомы**, **Исполнители**, **Жанры**, **Подпапки**, **Папки**, **Недавно добавлено** или **Плейлисты** и фильтруйте коллекцию с помощью поля **Поиск в библиотеке**.
4. Нажмите **Воспроизвести**, чтобы слушать через текущую цепочку эффектов, или управляйте воспроизведением с помощью **Воспроизвести следующим**, **Добавить в очередь** и **Добавить в плейлист**.
5. После изменения файлов используйте **Пересканировать**; если разрешения браузера или папки истекли, используйте **Подключить заново**.
   - [Подробнее о музыкальной библиотеке](music-library.md)

### Visualizer

Вы можете наслаждаться визуализациями на основе воспроизводимой музыки.

Откройте **Visualizer** в верхней части окна на ПК, на мобильной вкладке **Плеер** или через меню настольного приложения **Вид**. Выберите встроенную композицию или нажмите **Edit**, чтобы расположить графики звука, обложку и сведения о треке. Изменения видны сразу и возвращаются при следующем запуске; именованную копию сохраните в окне пресетов. Наведите курсор на область отображения или коснитесь её и выберите **⛶**, чтобы развернуть её на всё окно приложения. Подробнее о редактировании, эффектах и настройках отображения — в [руководстве Visualizer](visualizer.md).

### Использование пресетов

Вы можете сохранять и загружать созданные цепочки эффектов.

Нажмите кнопку **Пресеты цепочки эффектов** в заголовке Effect Pipeline, чтобы открыть диалог пресетов.

1. Загрузите пресет, выбрав его в списке сохранённых пресетов. Восстанавливается вся цепочка, включая порядок эффектов, настройки и состояния ON/OFF.
2. Сохраните текущую цепочку, введя название и выбрав **Сохранить**.
3. Переименуйте сохранённый пресет кнопкой переименования в его строке.
4. Выберите один или несколько сохранённых пресетов, затем выберите **Удалить выбранные** и подтвердите удаление.
5. Нажмите Ctrl+S (или Cmd+S в macOS), чтобы открыть диалог с готовым к редактированию именем текущего пресета.

У каждого эффекта также есть собственная кнопка **Пресеты эффекта**. Она открывает системные пресеты, когда эффект их предоставляет, и позволяет сохранять, переименовывать, загружать или удалять ваши настройки для этого эффекта. Пресеты эффекта меняют только его параметры, но не состояние ON/OFF и не маршрутизацию.

Импорт, экспорт и обмен файлами `.effetune_preset` по-прежнему относятся к пресетам полной цепочки эффектов.

### Общие элементы управления эффектами

- Для точной настройки ползунка удерживайте Shift при перетаскивании; значение будет изменяться на один минимальный шаг
   - У ползунков с отрицательными и положительными значениями заливка идёт от 0 до текущего значения. У ползунков Ratio она начинается от 1.0.
- На поддерживаемых графиках с осью частот или нот перетаскивайте указатель вдоль оси, чтобы прослушать выбранную частоту через цепочку эффектов. В **Конфигурация > Общие > Звук прослушивания частоты** выберите **Синусоидальный сигнал** (по умолчанию, -12 дБ) или **Полосовой шум**, сосредоточенный вокруг выбранной частоты. Note Spectrogram, Pitch Meter, Chroma Spiral и клавиатуры фортепиано всегда используют синусоидальный сигнал. При отображении клавиатуры частота привязывается к ближайшему полутону; перетаскивание по клавише воспроизводит её ноту

[Управление эффектами через MIDI, геймпад или клавиатуру](controller-mapping.md)

### Использование функций Section

Вы можете объединять несколько эффектов в группу и управлять ими вместе.

1. **Использование эффекта Section:**
   - Добавьте эффект Section в начале группы эффектов
   - Введите описательное название в поле Comment
   - Переключение ON/OFF эффекта Section обходит или возвращает всю секцию, сохраняя собственное состояние ON/OFF каждого эффекта
   - Используйте несколько эффектов Section для организации вашей цепочки эффектов в логические группы
   - [Подробнее о управлении эффектами](plugins/control.md)

### Использование функций AB Pipeline

Вы можете переключаться между двумя цепочками эффектов и сравнивать их звучание.

1. **Обзор AB Pipeline:**
   - EffeTune может поддерживать два отдельных конвейера эффектов: Pipeline A и Pipeline B
   - При запуске загружается только Pipeline A; Pipeline B создается при необходимости
   - Все операции обработки, сохранения, загрузки и редактирования работают на текущем выбранном конвейере

2. **Кнопка переключения AB:**
   - Расположена справа от заголовка Effect Pipeline
   - По умолчанию показывает "A" (Pipeline A активен)
   - Нажмите для переключения между Pipeline A и Pipeline B
   - Если Pipeline B не существует при переключении, настройки Pipeline A копируются в Pipeline B

3. **Меню AB (Выпадающая кнопка):**
   - Расположено справа от кнопки переключения AB
   - "A → B": Копирует настройки Pipeline A в Pipeline B и переключается на Pipeline B
   - "B → A": Копирует настройки Pipeline B в Pipeline A и переключается на Pipeline A

4. **Двойной слепой тест:**
   - Сравнивайте Pipeline A и Pipeline B, не зная, какой из них сейчас воспроизводится
   - Выполните ABX-тест, чтобы проверить, действительно ли вы различаете две цепочки эффектов, или A/B-тест предпочтения, чтобы выяснить, какой вариант вам нравится больше, с проверкой статистической значимости
   - Открывается из меню цепочки ▼ справа от кнопки переключения AB (в настольном приложении также доступно из меню Файл)
   - [Подробнее о двойном слепом тесте](double-blind-test.md)

### Выбор эффектов и горячие клавиши

1. **Методы выбора эффектов:**
   - Кликните по заголовкам эффектов, чтобы выбрать отдельные эффекты
   - Удерживайте Ctrl при клике для выбора нескольких эффектов
   - Кликните по пустому пространству в области Pipeline, чтобы снять выбор со всех эффектов

2. **Горячие клавиши:**
   - Ctrl + Z: Отменить
   - Ctrl + Y: Повторить
   - Ctrl + S: Сохранить текущую цепочку
   - Ctrl + Shift + S: Сохранить текущую цепочку как
   - Ctrl + X: Вырезать выбранные эффекты
   - Ctrl + C: Копировать выбранные эффекты
   - Ctrl + V: Вставить эффекты из буфера обмена
   - Ctrl + F: Найти эффекты
   - Ctrl + A: Выбрать все эффекты в цепочке
   - Delete: Удалить выбранные эффекты
   - ESC: Снять выделение со всех эффектов
   - T: Переключиться между Pipeline A и Pipeline B
   - A: Переключиться на Pipeline A
   - B: Переключиться на Pipeline B

3. **Горячие клавиши (при использовании проигрывателя):**
   - Space: Воспроизведение/Пауза
   - Ctrl + → или N: Следующий трек
   - Ctrl + ← или P: Предыдущий трек
   - Shift + → или F или .: Перемотка вперёд на 10 секунд
   - Shift + ← или R или ,: Перемотка назад на 10 секунд
   - Ctrl + M: Включить/выключить режим повтора
   - Ctrl + H: Включить/выключить случайный порядок
   - T: Переключиться между Pipeline A и Pipeline B
   - A: Переключиться на Pipeline A
   - B: Переключиться на Pipeline B

### Обработка аудиофайлов

Вы можете обработать музыкальные файлы цепочкой эффектов и сохранить результат в новых файлах.

1. **Область для перетаскивания или указания файлов:**
   - Специальная область для перетаскивания всегда видна под областью Effect Pipeline
   - Поддерживается загрузка одного или нескольких аудиофайлов
   - Файлы обрабатываются с использованием текущих настроек Pipeline
   - Эффекты обрабатываются с частотой дискретизации Pipeline; преобразование частоты выходного файла выполняется после этого

2. **Статус обработки:**
   - Индикатор прогресса показывает текущий статус обработки
   - Время обработки зависит от размера файла и сложности цепочки эффектов

3. **Параметры загрузки или сохранения:**
   - В разделе **Настройки > Конфигурация > Вывод файлов в автономном режиме** выберите WAV или FLAC, частоту дискретизации и качество. Для FLAC можно выбрать кодирование без потерь с разрядностью 16 или 24 бита. Начальное значение — WAV 96 кГц, PCM 24 бита
   - У каждого формата своё ограничение числа каналов. Если файл превышает предел выбранного формата, EffeTune не сводит каналы автоматически, а останавливается и предлагает способ решения
   - Для нескольких файлов перед началом обработки выберите папку; каждый файл сохраняется в неё сразу по завершении
   - В старых браузерах без поддержки выбора папки несколько файлов упаковываются в ZIP-архив для скачивания

### Обмен цепочками эффектов

Вы можете поделиться конфигурацией вашей цепочки эффектов с другими пользователями.
1. После настройки желаемой цепочки эффектов нажмите кнопку **Поделиться** в правом верхнем углу области Effect Pipeline
2. URL веб-приложения автоматически скопируется в буфер обмена
3. Поделитесь скопированным URL с другими – они смогут воссоздать вашу цепочку эффектов, открыв его
4. Общие ссылки сохраняют настройки эффектов, необходимые для воспроизведения цепочки; веб-приложение также восстанавливает ваше обычное рабочее состояние из хранилища браузера
5. В версии настольного приложения экспортируйте настройки в файл `.effetune_preset` из меню **Файл**
6. Поделитесь экспортированным файлом `.effetune_preset`. Файл `.effetune_preset` также можно загрузить, перетащив его в окно веб-приложения

### Резервное копирование и восстановление сохранённых данных

Откройте **Настройки > Резервная копия / Восстановление**, чтобы перенести сохранённые пресеты цепочки, пресеты эффектов, импульсные характеристики и измерения между веб-приложением, настольным приложением и расширением браузера. В веб- и настольном приложении можно также включить именованные пресеты Visualizer. При выборе пресета автоматически выбираются используемые им данные измерений или импульсных характеристик.

Параметры **Включить данные измерений** и **Включить импульсные характеристики** включены по умолчанию, чтобы резервная копия была самодостаточной. Отключайте любой из них, только если в месте восстановления уже есть соответствующие файлы измерений или импульсных характеристик. Восстановленные импульсные характеристики добавляются в окно **Библиотека импульсных характеристик** EffeTune. Восстановление копии не меняет текущую цепочку, громкость, выбранный пресет, настройки устройств, музыкальную библиотеку и правила URL расширения. Каждый файл `.effetune_backup` может занимать до 256 МБ; при необходимости разделите большую резервную копию на несколько файлов. Если восстановление прервётся, уже восстановленные элементы сохранятся, и тот же файл можно безопасно восстановить повторно.

Прежде чем делиться резервной копией, проверьте выбранные элементы: она может содержать названия и комментарии пресетов, исходные файлы импульсных характеристик и сведения об измерениях. Музыкальные файлы, данные музыкальной библиотеки, настройки приложения, выбор устройств, правила URL, учётные данные и несохранённая текущая цепочка эффектов в неё не входят.

### Настройки приложения

Откройте **Настройки > Конфигурация...**, чтобы выбрать **Язык**, задать **Вид при запуске:** (`Effect Pipeline (по умолчанию)`, `Музыкальная библиотека` или `Visualizer`), настроить **Конвейер эффектов при запуске:** и выбрать **Тема** (`Graphite`, `Paper`, `Midnight`, `Ember` или `Mint`). Если для **Вид при запуске:** выбрано значение **Музыкальная библиотека**, можно также выбрать, какой раздел библиотеки открывается первым. В настройке **Столбцы цепочки эффектов** выберите **Вручную**, чтобы менять число столбцов кнопками +/−, или **Автоматически** (по умолчанию), чтобы столбцы вместе со списком эффектов помещались по ширине окна. В автоматическом режиме число столбцов меняется при изменении размера окна.

Версия из Microsoft Store получает обновления через Microsoft Store. В **Настройки > Конфигурация...** нажмите **Открыть обновления Microsoft Store**, чтобы проверить обновления, или **Открыть настройки автозагрузки Windows**, чтобы выбрать, запускать ли EffeTune автоматически. Настройки и данные входа в Browser этой версии хранятся отдельно от других настольных версий.

### Управление EffeTune через ИИ-ассистента (MCP)

Вы можете поручить Codex или Claude Code настройку MCP, а затем просить его добавлять эффекты, менять их параметры, загружать и сохранять пресеты в настольном приложении EffeTune. Используйте агента, который может выполнять команды на вашем компьютере.

1. В настольном приложении EffeTune откройте **Настройки > Дистанционное управление...**, включите **Разрешить дистанционное управление** и нажмите **Копировать ссылку**.
2. Отправьте агенту следующий запрос, подставив скопированную ссылку:

```text
Настрой EffeTune MCP по официальному руководству:
https://github.com/Frieve-A/effetune/blob/main/mcp/README.md
Ссылка для подключения: <вставьте сюда скопированную ссылку>
```

После настройки перезапустите клиент, если агент попросит об этом, и попробуйте запрос: «Покажи мои текущие эффекты». Не публикуйте ссылку для подключения. Если вы нажмёте **Новый токен** или измените порт, повторите настройку с новой ссылкой.

Добавьте песни в Music Library подключённого приложения EffeTune, затем попросите: «Включи [песню]». Ассистент сначала ищет в библиотеке этого EffeTune и по умолчанию воспроизводит на его плеере; открывать доступ к музыкальной папке для этого не нужно. Если нужна другая библиотека или другой плеер, укажите их: «Найди [песню] в [библиотеке] и воспроизведи её на [плеере]». Если музыка находится на другом компьютере с EffeTune, сначала откройте там доступ к папке.

## Распространенные комбинации эффектов

Ниже приведены некоторые популярные комбинации эффектов для улучшения качества прослушивания:

### Улучшение звучания на наушниках
1. **Stereo Blend** -> **RS Reverb**
   - **Stereo Blend:** Регулирует стерео ширину для комфортного прослушивания (60-100%)
   - **RS Reverb:** Добавляет тонкую реверберацию помещения (микс 10-20%)
   - **Результат:** Более естественное и менее утомительное прослушивание через наушники

### Симуляция винила
1. **Wow Flutter** -> **Noise Blender** -> **Saturation**
   - **Wow Flutter:** Добавляет мягкие вариации высоты тона
   - **Noise Blender:** Создает атмосферу, похожую на виниловую пластинку
   - **Saturation:** Добавляет аналоговое тепло
   - **Результат:** Аутентичное звучание виниловой пластинки

### Стиль FM радио
1. **Multiband Compressor** -> **Stereo Blend**
   - **Multiband Compressor:** Создает характерное "радиозвучание"
   - **Stereo Blend:** Регулирует стерео ширину для комфортного прослушивания (100-150%)
   - **Результат:** Отполированное звучание в стиле FM-радио

### Lo-Fi характер
1. **Bit Crusher** -> **Simple Jitter** -> **RS Reverb**
   - **Bit Crusher:** Уменьшает битовую глубину для ретро ощущения
   - **Simple Jitter:** Добавляет цифровые несовершенства
   - **RS Reverb:** Создает атмосферное пространство
   - **Результат:** Классическая эстетика lo-fi

## Техническая информация

### Совместимость с браузерами

Frieve EffeTune был протестирован и подтвержден для работы в Google Chrome. Приложение требует современного браузера с поддержкой:
- Web Audio API
- Audio Worklet
- getUserMedia API
- Drag and Drop API
- Service Worker (для установки веб-приложения и запуска офлайн)

### Поддержка браузеров
1. **Chrome/Chromium**
   - Полностью поддерживается и рекомендуется
   - Обновите до последней версии для лучшей производительности

2. **Firefox/Safari**
   - Ограниченная поддержка
   - Некоторые функции, такие как выбор выходного устройства, Wake Lock, установка приложения или поддерживаемые форматы аудио, могут различаться в зависимости от браузера
   - Рекомендуется использовать Chrome для оптимального опыта

### Рекомендуемая частота дискретизации

Установите для параметра **Частота дискретизации** в EffeTune значение 96 кГц. Это уменьшает слышимый алиасинг от нелинейных эффектов, например сатурации. Эта настройка задаёт внутреннюю частоту обработки EffeTune и работает независимо от частоты дискретизации ОС, аудиоинтерфейса или виртуального аудиоустройства. Проверьте фактическую частоту дискретизации, показанную в приложении: пока вы не сохраните настройку, может использоваться значение по умолчанию ОС или браузера, а веб-приложение может перейти на другую частоту, если 96 кГц недоступны. Если звук прерывается, сначала отключите требовательные эффекты или сократите цепочку и лишь при необходимости понизьте частоту дискретизации.

DSP-движок EffeTune также доступен как самостоятельная детерминированная библиотека под лицензией MIT для Python, JavaScript и браузерных AudioWorklet. Её публичную схему Chain и автоматически сгенерированный каталог эффектов можно использовать без приложения EffeTune. Подробнее см. [документацию EffeTune DSP Library](https://effetune.frieve.com/dsp/).

Инструкции по установке и полные готовые к запуску примеры приведены в кратких руководствах для пакетов:

- [Пакет для Python](https://effetune.frieve.com/dsp/getting-started/python/)
- [Пакет для JavaScript и AudioWorklet](https://effetune.frieve.com/dsp/getting-started/javascript/)

Эффекты, схемы, особенности обработки и необходимые ресурсы описаны в [руководстве по DSP Library](https://effetune.frieve.com/dsp/).
