# Плагины реверберации

Коллекция плагинов, добавляющих пространство и атмосферу вашей музыке. Эти эффекты могут заставить вашу музыку звучать так, как будто она воспроизводится в различных помещениях, от уютных комнат до грандиозных концертных залов, улучшая ваше прослушивание естественной атмосферой и глубиной.

## Список плагинов

- [Dattorro Plate Reverb](#dattorro-plate-reverb) - Классический пластинчатый реверб на основе алгоритма Датторро
- [FDN Reverb](#fdn-reverb) - Реверберация на основе сети задержек с обратной связью (Feedback Delay Network) и развитой матрицей диффузии
- [IR Reverb](#ir-reverb) - Свёрточная реверберация с импортированной импульсной характеристикой
- [RS Reverb](#rs-reverb) - Создает естественную атмосферу помещения и пространства

## Dattorro Plate Reverb

Пластинчатый реверб по схеме Джона Датторро 1997 года. Он добавляет плотное, гладкое затухание и хорошо подходит, когда нужна просторная атмосфера без ощущения какого-то конкретного помещения.

### Руководство по прослушиванию
- Богатый звук пластинчатого реверба:
  - Классический характер пластинчатого реверба
  - Гладкий, плотный хвост реверба без металлических артефактов
  - Красивое мерцание и тепло, характерные для пластинчатых ревербов
- Универсальная атмосфера:
  - От тонкого улучшения помещения до обширных залов
  - Прекрасно работает с любым музыкальным жанром
  - Добавляет музыке гладкий блеск и пространство
- Естественное движение:
  - Модуляция добавляет органическую жизнь реверберации
  - Предотвращает статичные, искусственно звучащие хвосты
  - Создает дышащее, живое пространство вокруг вашей музыки

### Системные пресеты

Нажмите **Пресеты эффекта** в заголовке эффекта, чтобы применить готовую настройку пластинчатой реверберации.

- **Studio Plate** - Короткая, яркая пластинчатая реверберация для повседневного прослушивания.
- **Vocal Plate** - Более длительная предварительная задержка отделяет атаку исходного звука от реверберации.
- **Dark Vintage Plate** - Более тёмная пластинчатая реверберация с усиленным затуханием высоких частот.
- **Long Wash** - Длинный, пространственный хвост реверберации с модуляцией.

### Параметры
- **Pre Delay** - Начальная тишина перед началом реверба (управление 0.0-100.0 мс; для эффективного pre-delay используйте значения ниже 100.0 мс)
  - 0-10мс: Немедленный реверб, интимное ощущение
  - 10-30мс: Естественное ощущение пространства
  - 30-99.9мс: Создает впечатление больших пространств
  - Избегайте ровно 100.0мс, если нужен максимальный pre-delay; при этом значении pre-delay почти не слышен
- **Bandwidth** - Фильтрация входного сигнала (от 0.0 до 1.0)
  - Меньшие значения: Более темный, теплый входной тон
  - Большие значения (около 1.0): Более яркий, полночастотный вход
  - По умолчанию 0.9995: Оптимально по рекомендации Датторро
- **Input Diff 1** - Первая ступень входной диффузии (от 0.0 до 1.0)
  - Контролирует начальное размытие входного сигнала
  - По умолчанию 0.75: Рекомендованное значение из статьи Датторро
  - Большие значения: Более диффузные, мягкие ранние отражения
- **Input Diff 2** - Вторая ступень входной диффузии (от 0.0 до 1.0)
  - Дополнительно распределяет входной сигнал
  - По умолчанию 0.625: Рекомендованное значение из статьи Датторро
  - Работает с Input Diff 1 для создания сложной диффузии
- **Decay** - Продолжительность хвоста реверба (от 0.0 до 1.0)
  - Низкий (0.1-0.3): Короткое, контролируемое затухание
  - Средний (0.4-0.6): Естественное затухание типа помещения
  - Высокий (0.7-1.0): Длинные, расширенные хвосты
- **Decay Diff 1** - Диффузия затухания в резервуаре (от 0.0 до 1.0)
  - Контролирует плотность во время фазы затухания
  - По умолчанию 0.70: Рекомендованное значение из статьи Датторро
  - Влияет на гладкость хвоста реверба
- **Damping** - Поглощение высоких частот со временем (от 0.0 до 1.0)
  - 0.0: Без затухания, яркий реверб повсюду
  - 0.0005 (по умолчанию): Очень тонкое, естественное затухание
  - Большие значения: Более темное, теплое затухание
- **Mod Depth** - Количество модуляции задержки (от 0.0 до 16.0 сэмплов)
  - 0.0: Без модуляции, статический реверб
  - 1.0-4.0: Тонкое движение, добавляет жизнь
  - 8.0-16.0: Более заметный эффект типа хоруса
- **Mod Rate** - Скорость модуляции (от 0.0 до 10.0 Гц)
  - 0.5-1.5Гц: Медленное, мягкое движение
  - 2.0-4.0Гц: Более активная модуляция
  - Большие значения: Быстрый, мерцающий эффект
- **Wet Mix** - Количество добавляемого реверба (от 0 до 100%)
  - 10-30%: Тонкое улучшение
  - 30-50%: Заметное присутствие
  - 50-100%: Доминирующий эффект реверба
- **Dry Mix** - Количество оригинального сигнала (от 0 до 100%)
  - Обычно держится на 100% для нормального прослушивания
  - Уменьшить для специальных эффектов или эмбиент-подложек

### Рекомендуемые настройки для различных музыкальных стилей

1. Классическое фортепиано
   - Decay: 0.6-0.7
   - Damping: 0.001
   - Mod Depth: 1.0
   - Wet Mix: 25-35%
   - Идеально для: Сольное фортепиано, камерная музыка

2. Вокал и акустика
   - Decay: 0.4-0.5
   - Damping: 0.002
   - Pre Delay: 15-25мс
   - Wet Mix: 20-30%
   - Идеально для: Вокал, акустическая гитара

3. Эмбиент и атмосферный
   - Decay: 0.8-0.95
   - Mod Depth: 4.0-8.0
   - Mod Rate: 0.5-1.0Гц
   - Wet Mix: 50-70%
   - Идеально для: Эмбиент, электроника, звуковые ландшафты

4. Общее улучшение
   - Decay: 0.5
   - Damping: 0.0005
   - Mod Depth: 1.0
   - Wet Mix: 20-30%
   - Идеально для: Обычное прослушивание и лёгкая атмосфера

### Быстрый старт

1. Установите базовый характер
   - Начните с Decay для контроля длины реверба
   - Настройте Pre Delay для воспринимаемого расстояния
   - Установите Wet Mix для желаемого присутствия реверба

2. Сформируйте тональность
   - Используйте Bandwidth для контроля яркости входа
   - Настройте Damping для затухания высоких частот
   - Точно настройте параметры диффузии для плотности

3. Добавьте движение
   - Установите Mod Depth для тонкой вариации (попробуйте 1.0)
   - Настройте Mod Rate для скорости (попробуйте 1.0Гц)
   - Эти параметры добавляют жизнь реверберации

4. Финальный баланс
   - Настройте микс Wet/Dry по вкусу
   - Доверяйте своим ушам для финальных настроек
   - Значения по умолчанию - отличная отправная точка

Dattorro Plate Reverb добавляет к прослушиванию классическую атмосферу пластинчатого реверба. Его гладкий и насыщенный характер полезен, когда записи нужно красивое, естественно звучащее пространство.

### Многоканальная маршрутизация

Dattorro Plate Reverb — это стереомодель пластинчатого реверба. При маршрутизации более чем двух каналов все входные каналы подаются в один общий пластинчатый ревербератор «моно в стерео», а wet/dry-микс записывается только в первую маршрутизированную стереопару. Дополнительные каналы участвуют во входе пластины и в остальном проходят без изменений, даже когда Dry Mix равен 0%; они не получают возврата реверберации и не являются независимыми пластинчатыми контурами.

## FDN Reverb

FDN Reverb добавляет плотное естественное затухание. Используйте его, чтобы сухая или близкая запись приобрела более ясное ощущение размера помещения и расстояния.

### Руководство по прослушиванию
- Естественное ощущение помещения:
  - Создаёт ощущение прослушивания в реальном акустическом пространстве
  - Добавляет музыке глубину и объём
  - Делает стереозаписи просторнее и живее
- Атмосферное улучшение:
  - Превращает плоские записи в объёмное звучание
  - Добавляет нотам красивый хвост и протяжённость
  - Создаёт ощущение присутствия в пространстве исполнения
- Настраиваемая атмосфера:
  - Регулируется от камерных комнат до больших концертных залов
  - Позволяет точно настроить характер и окраску пространства
  - Мягкая модуляция добавляет естественное движение и жизнь

### Системные пресеты

Нажмите **Пресеты эффекта** в заголовке эффекта, чтобы применить готовое пространство целиком, а не настраивать каждый регулятор по отдельности.

- **Tight Room** - Короткий, собранный отклик небольшой комнаты.
- **Warm Hall** - Более длинный, слегка затемнённый зал для акустической и оркестровой музыки.
- **Bright Plate** - Более яркая и подвижная короткая реверберация с характером пластины.
- **Vast Cavern** - Самое большое и самое долгое из предложенных пространств.

### Параметры
- **Reverb Time** - Продолжительность эффекта реверберации (от 0.20 до 10.00 с)
  - Короткое (0.2-1.0с): Быстрое, контролируемое затухание для четкости
  - Среднее (1.0-3.0с): Естественная комнатная реверберация
  - Длинное (3.0-10.0с): Расширенные, атмосферные хвосты
- **Density** - Количество путей эха для сложности (от 4 до 8 линий)
  - 4 линии: Более простые, четко определенные отдельные эхо
  - 6 линий: Хороший баланс сложности и четкости
  - 8 линий: Максимальная гладкость и плотность
- **Pre Delay** - Первоначальная тишина перед началом реверберации (от 0.0 до 100.0 мс)
  - 0-20мс: Немедленная реверберация, интимное ощущение
  - 20-50мс: Естественное ощущение расстояния помещения
  - 50-100мс: Создает впечатление больших пространств
- **Base Delay** - Основное время для сети реверберации (от 10.0 до 60.0 мс)
  - Меньшие значения: Более плотный, сфокусированный характер реверберации
  - Большие значения: Более просторное, открытое качество звука
  - Влияет на фундаментальные временные соотношения
- **Delay Spread** - Добавляет прогрессивный разброс времени между линиями задержки поверх небольших случайных смещений каждой линии (от 0.0 до 25.0 мс)
  - 0.0мс: Используется базовая задержка плюс небольшие рандомизированные смещения линий, поэтому отражения все равно остаются слегка нерегулярными
  - Большие значения: Добавляют больший прогрессивный разброс между линиями для более крупного и менее регулярного хвоста
  - Добавляет реалистичные вариации, найденные в реальных акустических пространствах
- **HF Damp** - Как высокие частоты затухают со временем (от 0.0 до 12.0 дБ/с)
  - 0.0: Без затухания, яркий звук на протяжении всего затухания
  - 3.0-6.0: Симуляция естественного поглощения воздуха
  - 12.0: Сильное затухание для теплого, мягкого характера
- **Low Cut** - Удаляет низкие частоты из реверберации (от 20 до 500 Гц)
  - 20-50Гц: Полная басовая реакция в реверберации
  - 100-200Гц: Контролируемые басы для избежания замутнения
  - 300-500Гц: Плотный, четкий низ
- **Mod Depth** - Количество питч-модуляции для эффекта хоруса (от 0.0 до 10.0 центов)
  - 0.0: Без модуляции, чистая статичная реверберация
  - 2.0-5.0: Тонкое движение, которое добавляет жизнь и реализм
  - 10.0: Заметный эффект, похожий на хорус
- **Mod Rate** - Скорость модуляции (от 0.10 до 5.00 Гц)
  - 0.1-0.5Гц: Очень медленное, нежное движение
  - 1.0-2.0Гц: Естественно звучащие вариации
  - 3.0-5.0Гц: Быстрая, более очевидная модуляция
- **Diffusion** - Управляет тем, какая часть смешанной обратной связи возвращается в сеть задержек (от 0 до 100%)
  - 0%: Отключает диффузию обратной связи; звук становится намного более разреженным, а хвост реверберации сильно сокращается
  - 50%: Сбалансированная диффузия для естественного звука
  - 100%: Максимальная диффузия обратной связи для самой гладкой плотности
- **Wet Mix** - Количество реверберации, добавленной к звуку (от 0 до 100%)
  - 10-30%: Тонкое пространственное улучшение
  - 30-60%: Заметное присутствие реверберации
  - 60-100%: Доминирующий эффект реверберации
- **Dry Mix** - Количество сохраненного оригинального сигнала (от 0 до 100%)
  - Обычно держится на 100% для нормального прослушивания
  - Может быть уменьшено для специальных атмосферных эффектов
- **Stereo Width** - Смешивает wet-реверберацию от моно к раздельным левому/правому wet-отводам (от 0 до 200%)
  - 0%: Wet-реверберация появляется в центре (моно)
  - 100%: Стандартная умеренная стереоширина wet-сигнала
  - 200%: Полное разделение левого/правого wet-отвода, а не дополнительное усиление боковой составляющей

### Рекомендуемые настройки для различных опытов прослушивания

1. Улучшение классической музыки
   - Reverb Time: 2.5-3.5с
   - Density: 8 линий
   - Pre Delay: 30-50мс
   - HF Damp: 4.0-6.0
   - Идеально для: Оркестровых записей, камерной музыки

2. Атмосфера джаз-клуба
   - Reverb Time: 1.2-1.8с
   - Density: 6 линий
   - Pre Delay: 15-25мс
   - HF Damp: 2.0-4.0
   - Идеально для: Акустического джаза, интимных выступлений

3. Улучшение поп/рока
   - Reverb Time: 1.0-2.0с
   - Density: 6-7 линий
   - Pre Delay: 10-30мс
   - Wet Mix: 20-40%
   - Идеально для: Записей, которым нужно немного больше пространства

4. Эмбиент-пейзажи
   - Reverb Time: 4.0-8.0с
   - Density: 8 линий
   - Mod Depth: 3.0-6.0
   - Wet Mix: 60-80%
   - Идеально для: Атмосферной музыки и длинных затуханий

### Быстрый старт

1. Задайте характер пространства
   - Начните с Reverb Time, подобрав его под желаемый размер пространства
   - Установите Density на 6-8 для гладкого, естественного звучания
   - Настройте Pre Delay, чтобы управлять ощущением расстояния

2. Сформируйте тональность
   - Используйте HF Damp, чтобы имитировать естественное поглощение в воздухе
   - Установите Low Cut, чтобы избежать накопления баса
   - Настройте Diffusion для гладкости (попробуйте 70-100%)

3. Добавьте естественное движение
   - Установите Mod Depth на 2-4 цента для лёгкой живости
   - Используйте Mod Rate около 0.3-1.0 Гц для мягкой вариации
   - Настройте Stereo Width для пространственного впечатления

4. Сбалансируйте эффект
   - Начните с Wet Mix 30%
   - Для обычного прослушивания оставьте Dry Mix на 100%
   - Подстройте под свою музыку и предпочтения

Начните с небольшого значения Wet Mix и повышайте его, пока добавленное пространство не станет слышно, но детали записи ещё не будут маскироваться.

### Многоканальная маршрутизация

Все маршрутизированные входные каналы смешиваются в одну общую реверберацию. Реверберированный звук распределяется по маршрутизированным выходным каналам; отдельная реверберация для каждого входа не создаётся.

## IR Reverb

IR Reverb выполняет свёртку сигнала с импортированной импульсной характеристикой (IR), воспроизводя измеренное затухание и пространственный характер комнаты, зала, пластины или другой акустической системы. Он полезен, когда нужен воспроизводимый характер конкретной записи импульсной характеристики, а не синтезированная модель реверберации.

### Руководство по улучшению звучания

- **Лёгкая поддержка помещения:** импортируйте короткую IR комнаты, оставьте **Dry** включённым с **Dry Level** 0 dB, задайте **Wet Level** примерно от -18 до -12 dB и используйте короткий **Pre Delay**. Так добавляется пространство, не затуманивая запись.
- **Расширение до концертного зала:** используйте стерео- или True Stereo IR зала, сначала понизьте **Wet Level**, затем сократите слишком длинный хвост параметрами **Decay** и **Trim**.
- **Реверберация через send/return:** направьте источник на другую шину с помощью **Matrix**, поставьте IR Reverb на этот возврат с выключенным **Dry** и **Wet Level** 0 dB, а количество реверберации регулируйте уровнем посыла. Так прямой сигнал не добавляется дважды; схема работает и для выбранных многоканальных возвратов.
- **Сравнение и воспроизводимость:** сохраняйте исходный файл IR и сведения о его источнике и лицензии. Одинаковые байты IR дают одинаковый ID в библиотеке, поэтому в другой установке достаточно импортировать тот же файл, чтобы точно восстановить связь.

### Параметры

- **Channel Mode** - Выбирает маршрутизацию каналов IR. **Auto** выбирает Mono для одноканальной IR, True Stereo для четырёхканальной IR при выборе стереоканалов, Independent при совпадении числа каналов IR и выбранных каналов, а в остальных случаях — Diagonal Matrix; фактически выбранный режим отображается справа от меню. **Mono** применяет одну IR к выбранным каналам; **Independent** сопоставляет каждому выбранному каналу один канал IR; **True Stereo** использует тракты LL/LR/RL/RR; **Diagonal Matrix** соединяет соответствующие входные и выходные каналы без перекрёстной связи.
- **Latency** - Выбирает задержку блока свёртки (Zero, 128, 256, 512 или 1024 samples). Большие значения обычно снижают нагрузку на обработку, но задерживают весь выход эффекта; прямой сигнал задерживается на столько же и остаётся выровненным с реверберацией, а цепочка компенсирует эту задержку. **Zero** требует **Convolution Rate = Full**.
- **Convolution Rate** - Задаёт частоту, на которой выполняется свёртка wet-сигнала. **Auto** при высоких частотах дискретизации контекста использует половинную частоту и показывает фактически выбранную частоту справа от меню, а **Full**, **Half** и **Quarter** задают выбор явно. Пониженные частоты уменьшают нагрузку, но также сужают полосу wet-тракта; Quarter требует частоты контекста не менее 176.4 kHz.
- **Wet Level** - Задаёт уровень свёрнутого сигнала от -96 до +12 dB. По умолчанию -15 dB — для обычного использования в разрыве; в схеме send/return задайте 0 dB и регулируйте количество реверберации уровнем посыла.
- **Dry** - Включает прямой сигнал. По умолчанию включён; отключите его, чтобы полностью убрать прямой сигнал, сохранив значение **Dry Level** на будущее.
- **Dry Level** - Задаёт уровень прямого сигнала от -96 до +12 dB, когда **Dry** включён. Крайнее значение -96 dB также заглушает прямой сигнал.
- **Pre Delay** - Задерживает только wet-сигнал на 0–500 ms, отделяя исходную атаку от отклика помещения.
- **Direct Cut** - Удаляет из IR найденный прямой импульс, чтобы запись давала только реверберационную часть. Для нормализации по-прежнему используется IR без среза, поэтому включение Direct Cut не усиливает оставшийся хвост реверберации.
- **Cut Offset** - Смещает найденную точку среза на величину от -20 до +50 ms, когда **Direct Cut** включён.
- **Decay** - Изменяет форму затухания IR от 10% до 400%; 100% сохраняет записанное затухание, меньшие значения укорачивают его, большие — удлиняют.
- **Trim** - Оставляет от 1% до 100% IR после среза с плавным затуханием. Меньшие значения сокращают длину хвоста, нагрузку на CPU и расход памяти.

### Как читать график затухания

Время идёт слева направо, уровень — от 0 до -90 dB. Сплошная кривая спада энергии (EDC) показывает, как убывает накопленная акустическая энергия; чем круче спад, тем короче хвост. Бледная огибающая показывает контекст переходных процессов. Метки обозначают найденное начало (onset), действующую точку прямого среза, pre-delay wet-сигнала и точку обрезки. **RT60** оценивает время спада на 60 dB; «unavailable» означает, что в IR не нашлось надёжного диапазона для аппроксимации. Если **Decay** отличается от 100%, сравните изменённую сплошную кривую с исходной пунктирной. Наведите курсор на график или коснитесь его и проведите пальцем, чтобы увидеть значения в этой точке.

### Маршрутизация, библиотека и обмен

Моно-IR может подаваться на выбранные каналы, независимые каналы IR остаются раздельными, а четырёхканальная True Stereo IR использует перекрёстные тракты LL/LR/RL/RR. В режиме Auto любая четырёхканальная IR при выборе стереоканалов трактуется в этом порядке; для квадро и других четырёхканальных схем явно выберите Independent или Diagonal Matrix. Другие многоканальные файлы используют ограниченный диагональный маршрут; полную матрицу перекрёстной связи для объёмного звука IR Reverb не создаёт. Для пары файлов True Stereo выберите вместе файлы с согласованными именами `L`/`R` или `Left`/`Right`.

Импортированные файлы IR хранятся в **Библиотеке импульсных характеристик**, где их можно найти по исходному имени, загрузить или удалить. Чтобы удалить несколько файлов сразу, установите соответствующие флажки или нажмите **Выбрать всё**, чтобы выбрать все показанные элементы, а затем нажмите **Удалить выбранные**. **Ctrl+A** (**Command+A** в macOS) также выбирает все показанные элементы; **Снять выделение** отменяет весь выбор. Файлы с расширением `.irs`, содержащие аудиоданные WAV, можно импортировать без переименования. В веб-версии они сохраняются в браузере и могут пропасть при очистке данных сайта или автоматическом освобождении места. Настольное приложение хранит их в своих данных. Сохраняйте отдельную копию каждой нужной IR.

Общие URL и пресеты идентифицируют IR, но не содержат её звуковых данных. Если IR недоступна, wet-сигнал не звучит; импортируйте или выберите IR заново либо укажите замену. Прямой сигнал по-прежнему проходит в соответствии с **Dry** и **Dry Level**.

Свободно доступные материалы удобно начать искать в [библиотеке OpenAIR](https://www.openair.hosted.york.ac.uk/) Йоркского университета, [разделе загрузок EchoThief](https://www.echothief.com/downloads/) или среди отдельных IR на [Freesound](https://freesound.org/). «Бесплатно» не значит «без ограничений»: OpenAIR указывает лицензию на странице каждого материала, а файлы Freesound могут распространяться по CC0, CC BY или CC BY-NC. Проверяйте конкретную страницу загрузки, храните сведения об авторе, источнике и лицензии вместе с файлом, указывайте авторство там, где это требуется, и убедитесь, что предполагаемое коммерческое использование или распространение разрешено. EffeTune не хранит и не проверяет сведения о лицензиях.

## RS Reverb

RS Reverb добавляет настраиваемые отражения и затухание, и сухая запись звучит так, будто играет в комнате или зале.

### Руководство по прослушиванию
- Камерное пространство:
  - Начните с Room Size 8-12m, Reverb Time 1.0-1.5s и Mix 20-30%
  - Понизьте Mix, если вокал или атаки инструментов теряют чёткость
- Пространство, похожее на зал:
  - Начните с Room Size 30-40m, Reverb Time 2.0-2.5s и Mix 30-40%
  - Сократите Reverb Time, если последовательные ноты начинают размываться
- Длинное атмосферное затухание:
  - Начните с Room Size 25-40m, Reverb Time 3-6s и Mix 40-60%
  - Повысьте Damping или понизьте High Damp, если хвост слишком яркий

### Системные пресеты

Нажмите **Пресеты эффекта** в заголовке эффекта, чтобы применить готовую настройку комнаты или зала целиком.

- **Small Room** - Короткая и близкая комнатная атмосфера с pre-delay 5 ms и более сдержанным затуханием баса.
- **Jazz Club** - Умеренная комната для камерного акустического материала с pre-delay 15 ms.
- **Concert Hall** - Более крупное и глубокое пространство с pre-delay 25 ms и более полным затуханием баса.
- **Cathedral** - Длинное тёмное пространство с pre-delay 40 ms и самым полным затуханием баса.

### Параметры
- **Pre-Delay** (от 0 до 50 ms) - Задерживает сигнал в тракте реверберации перед входом в модель помещения. При повышении значения атака исходного звука дольше остаётся отчётливой, но собственная задержка модели помещения сохраняется.
- **Room Size** - Устанавливает, насколько большим ощущается пространство (от 2.0 до 50.0 m)
  - Маленький (2-5m): Ощущение уютной комнаты
  - Средний (5-15m): Атмосфера живого помещения
  - Большой (15-50m): Величие концертного зала
- **Reverb Time** - Как долго длится эхо (от 0.1 до 10.0 s)
  - Короткое (0.1-1.0s): Четкий, сфокусированный звук
  - Среднее (1.0-3.0s): Естественный звук помещения
  - Длинное (3.0-10.0s): Просторное, атмосферное
- **Density** - Насколько богатым ощущается пространство (от 4 до 8)
  - Меньшие значения: Более определенные эхо
  - Большие значения: Более гладкая атмосфера
  - Начните с 6 для естественного звука
- **Diffusion** - Как распространяется звук (от 0.2 до 0.8)
  - Меньшие значения: Более различимые эхо
  - Большие значения: Более гладкое смешение
  - Попробуйте 0.5 для сбалансированного звука
- **Damping** - Как затухает эхо (от 0 до 100%)
  - Меньшие значения: Более яркий, открытый звук
  - Большие значения: Более теплый, интимный
  - Начните около 40% для естественного ощущения
- **High Damp** - Контролирует яркость пространства (от 1000 до 20000 Hz)
  - Меньшие значения: Более темное, теплое пространство
  - Большие значения: Более яркое, открытое
  - Начните около 8000Hz для естественного звука
- **Low Damp** - Контролирует полноту пространства (от 20 до 500 Hz)
  - Меньшие значения: Более полный, богатый звук
  - Большие значения: Более четкий, контролируемый
  - Начните около 100Hz для сбалансированного баса
- **Mix** - Балансирует эффект с оригинальным звуком (от 0 до 100%)
  - 10-30%: Тонкое улучшение
  - 30-50%: Заметное пространство
  - 50-100%: Драматический эффект

### Рекомендуемые настройки для различных музыкальных стилей

1. Классическая музыка в концертном зале
   - Room Size: 30-40m
   - Reverb Time: 2.0-2.5s
   - Mix: 30-40%
   - Идеально для: Оркестровых произведений, фортепианных концертов

2. Уютный джаз-клуб
   - Room Size: 8-12m
   - Reverb Time: 1.0-1.5s
   - Mix: 20-30%
   - Идеально для: Джаза, акустических выступлений

3. Современный поп/рок
   - Room Size: 15-20m
   - Reverb Time: 1.2-1.8s
   - Mix: 15-25%
   - Идеально для: Современной музыки

4. Эмбиент/электроника
   - Room Size: 25-40m
   - Reverb Time: 3.0-6.0s
   - Mix: 40-60%
   - Идеально для: Атмосферной электронной музыки

### Быстрый старт

1. Выберите ваше пространство
   - Начните с Room Size для установки базового пространства
   - Настройте Reverb Time для желаемой атмосферы
   - Точно настройте Mix для правильного баланса

2. Сформируйте звук
   - Используйте Damping для контроля теплоты
   - Настройте High/Low Damp для тона
   - Установите Density и Diffusion для текстуры

3. Точная настройка эффекта
   - Настройте Mix для финального баланса
   - Доверяйте своим ушам и настраивайте по вкусу

Начните с небольшого значения Mix и повышайте его, пока добавленное пространство не станет отчётливым, но исходная запись ещё не будет затуманиваться.
