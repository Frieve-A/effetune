# Плагины восстановления

Плагины восстановления уменьшают нежелательные дефекты записи, сохраняя естественное звучание музыки.

## Список плагинов

- [Click Remover](#click-remover) — исправляет короткие щелчки, треск, хлопки и провалы
- [Clip Restorer](#clip-restorer) — восстанавливает пики, сглаженные жёстким клиппированием
- [Hum Remover](#hum-remover) — удаляет постоянный электрический гул и его гармоники
- [Noise Reduction](#noise-reduction) — уменьшает постоянное шипение и фоновый шум

## Click Remover

Click Remover исправляет короткие отдельные дефекты: треск пластинки, хлопки, щелчки и очень краткие провалы. Используйте его для редких помех, а не для постоянного шипения или гула.

### Руководство по прослушиванию

1. Начните с **Sensitivity** 50 % и **Max Repair Length** 1 ms.
2. Понемногу повышайте **Sensitivity**, пока щелчки не станут менее заметны. Если смягчаются атаки ударных или другие резкие детали, уменьшите значение.
3. Повышайте **Max Repair Length** только для более длинных хлопков или провалов; для обычного треска оставляйте короткое значение.
4. Во время проблемного фрагмента смотрите **REPAIRS/S** и сравнивайте с отключённым эффектом, прежде чем оставлять более сильную настройку.

### Параметры

- **Sensitivity** (0–100 %, по умолчанию 50 %) задаёт, насколько охотно короткое изменение считается дефектом. Большее значение исправляет больше предполагаемых щелчков; меньшее работает осторожнее и лучше сохраняет музыкальные атаки.
- **Max Repair Length** (0,1–2 ms, по умолчанию 1 ms) ограничивает длительность каждого исправления. Повышайте для чуть более длинных хлопков или провалов, понижайте для короткого треска.

### Как читать индикатор

**REPAIRS/S** показывает недавнее число исправлений щелчков в секунду. Значение около нуля означает, что сейчас короткие дефекты почти не исправляются. Если на обычной музыке оно остаётся высоким, уменьшите **Sensitivity** или **Max Repair Length**.

## Clip Restorer

Clip Restorer восстанавливает пики, сглаженные жёстким цифровым клиппированием. Он полезен для записей с явным искажением с плоской вершиной, но не может вернуть все детали, утраченные до поступления записи в EffeTune.

### Руководство по прослушиванию

1. Начните с **Threshold** -0,10 dB и **Output Gain** -3 dB.
2. Немного понизьте **Threshold**, если остаются явно клиппированные пики. Поднимите его ближе к 0 dB, если без необходимости меняются громкие устойчивые звуки.
3. По возможности держите **Output Gain** ниже 0 dB: восстановленные пики могут оказаться выше исходных сглаженных.
4. Смотрите **RESTORED** на повреждённом участке и сравнивайте с отключённым эффектом, выбирая наименее заметную настройку.

### Параметры

- **Threshold** (-18–0 dB, по умолчанию -0,10 dB) задаёт уровень, который считается клиппированным пиком. Значения ближе к 0 dB обрабатывают только почти полную шкалу; меньшее значение включает менее заметное клиппирование, но может затронуть больше громкого материала.
- **Output Gain** (-12–0 dB, по умолчанию -3 dB) задаёт выходной уровень после восстановления. Поднимайте к 0 dB для большей громкости или понижайте для большего запаса по пикам.

### Как читать индикатор

**RESTORED** показывает недавний процент аудиосэмплов, исправленных как клиппированные пики. Небольшое значение может быть нормальным, поскольку клиппирование часто бывает только на коротких пиках. Если значение остаётся высоким там, где клиппирования не слышно, поднимите **Threshold**.

## Hum Remover

Hum Remover уменьшает постоянный электрический гул и его гармоники, например 50 Hz или 60 Hz от проигрывателя, кабеля или питания. Он предназначен для постоянного тона, а не для общего фонового шума.

### Руководство по прослушиванию

1. Начните с **Frequency** = **Auto**, **Harmonics** = 8 и **Tracking Speed** = 50 %.
2. Если известна частота сети в записи, выберите **50 Hz** или **60 Hz**. Иначе оставьте **Auto** и проверьте **FUNDAMENTAL**.
3. Повышайте **Harmonics**, если выше основной частоты остаётся жужжание; понижайте, если музыка теряет плотность или детали.
4. Повышайте **Tracking Speed**, если высота гула медленно меняется; понижайте для стабильного гула. Если длительный бас точно совпадает с гармоникой гула, уменьшите **Harmonics**.

### Параметры

- **Frequency** (**Auto**, **50 Hz** или **60 Hz**; по умолчанию **Auto**) выбирает основную частоту гула. **Auto** отслеживает обнаруженный сетевой гул; при известной частоте выберите фиксированное значение.
- **Harmonics** (1–64, по умолчанию 8) выбирает, сколько кратных основной частоты удалять. Большее значение очищает больше жужжания; меньшее лучше сохраняет музыку около высоких гармоник. Ползунок имеет логарифмическую шкалу, поэтому низкие значения можно настраивать точнее.
- **Tracking Speed** (0–100 %, по умолчанию 50 %) задаёт скорость автоматического отслеживания меняющегося гула. Большее значение быстрее следует за изменением; меньшее подходит для стабильного гула.

### Как читать индикатор

**FUNDAMENTAL** показывает частоту, на которую сейчас нацелен эффект. **REMOVED** показывает уровень удаляемого компонента гула в dBFS: чем ближе к 0 dBFS, тем сильнее удаляемый гул; очень низкое значение, например -140 dBFS, означает, что сейчас удаляется мало гула или его нет.

## Noise Reduction

Noise Reduction уменьшает постоянный фоновый шум: шипение ленты, шум оборудования или помещения. Используйте его, когда за музыкой постоянно слышен шум. Он лучше всего работает с шумом между нотами, а не с отдельными щелчками, меняющимися фоновыми звуками или другой музыкой в записи.

### Руководство по прослушиванию

1. Начните с **Reduction** 12 dB, **Sensitivity** 0 dB, **Smoothing** 50 %, **Treble Care** 50 % и **Mix** 100 %.
2. Медленно повышайте **Reduction**, пока тихие места не станут чище. Уменьшите его, если вокал, тарелки или атмосфера станут неестественными.
3. Для заметного постоянного шипения немного повышайте **Sensitivity**; для уже чистой музыки понижайте.
4. Повышайте **Smoothing**, если подавление кажется колеблющимся или меняет тембр. Если музыка становится слишком мягкой, уменьшите **Smoothing** или **Reduction**.
5. Сравните с отключённым эффектом и используйте **Mix**, чтобы оставить часть исходного звука, если так естественнее.

### Параметры

- **Reduction** (0–24 dB, по умолчанию 12 dB) задаёт максимальное подавление фонового шума. Меньшее значение мягче; большее убирает больше шума, но может скрыть тихие детали. При слабом шуме начните с 6–12 dB.
- **Sensitivity** (-12–+12 dB, по умолчанию 0 dB) определяет, насколько легко звук считается фоновым шумом. Повышайте, если постоянный шум остаётся; понижайте, если слишком ослабляются тихие инструменты, хвосты реверберации или атмосфера.
- **Smoothing** (0–100 %, по умолчанию 50 %) делает подавление более ровным на близких частотах. Большее значение уменьшает колеблющийся или водянистый характер; если звук тускнеет, уменьшите его и **Reduction**.
- **Treble Care** (0–100 %, по умолчанию 50 %) защищает музыкальные детали высоких частот. Повышайте для сохранения блеска тарелок, струн и вокала; понижайте только если высокочастотное шипение всё ещё мешает.
- **Mix** (0–100 %, по умолчанию 100 %) смешивает обработанный и исходный звук. При 100 % слышен только обработанный звук; понижайте, если немного исходной атмосферы естественнее. При 0 % звук не меняется.

### Рекомендуемые настройки

1. **Лёгкая очистка:** Reduction 6–10 dB, Sensitivity -2–0 dB, Smoothing 40–60 %, Treble Care 50–70 %.
2. **Явное шипение ленты или оборудования:** Reduction 12–18 dB, Sensitivity 0–+4 dB, Smoothing 60–80 %, Treble Care 50–70 %.
3. **Сохранение деликатных верхов:** Reduction 6–12 dB, Sensitivity -4–0 dB, Smoothing 50–70 %, Treble Care 70–100 %, Mix 70–100 %.
