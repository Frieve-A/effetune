# 网络音乐与远程控制（桌面应用）

桌面应用可以接收局域网内其他设备的音乐，并通过 EffeTune 效果链播放。OpenHome、UPnP AV / DLNA 和 AirPlay 的接收设置相互独立，默认均关闭。在 **设置 > 配置... > 网络** 中启用需要的接收方式即可。

## 通过 OpenHome 接收音乐

在受支持的桌面版本（Windows x64、macOS Intel/Apple silicon 和 Linux x64）中，EffeTune 可以作为 OpenHome 播放器出现在同一局域网内的控制器应用中。打开 **设置 > 配置... > 网络**，启用 **允许此网络中的 OpenHome 控制器**（默认关闭），并等待状态显示 EffeTune 已就绪。

**网络**中的**设备名称**用于标识网络播放器、AirPlay 接收端和共享音乐库。默认使用此电脑的名称。输入 `Living Room` 等自定义名称即可更改，清空此字段可恢复使用电脑名称。UPnP AV / DLNA 会带上简短后缀，显示为单独的播放目标；两个目标均使用同一个 EffeTune 播放器。

OpenHome 不需要登录。启用期间，同一局域网内的其他设备可以查看播放元数据、编辑播放器队列并控制播放。如果 Windows 防火墙请求权限，请只允许 EffeTune 访问 **专用网络**，不要允许 **公用网络**。不需要远程控制时请关闭此选项。

控制器可以添加 HTTP 或 HTTPS 音频流、管理远程播放队列，以及控制播放、暂停、停止、切歌、跳转、循环和随机播放。远程音频同样会照常经过当前的 EffeTune 效果链。OpenHome 的基本队列与播放控制已在 Android 版 BubbleUPnP 上验证；其他 OpenHome 应用显示服务的方式可能有所不同。OpenHome 播放目标提供 OpenHome Playlist 源，不会通过 OpenHome 提供效果编辑、本地文件路径、主音量、Radio、Songcast 或多房间同步。

无法保证无间隙播放；在音源提供之前，技术元数据可能一直显示为未知。睡眠、唤醒、连接 VPN 或网络变化后，播放器可能会在重新连接期间短暂消失。

## 通过 UPnP AV / DLNA 接收音乐

在 **设置 > 配置... > 网络** 中启用 **允许此网络中的 UPnP AV / DLNA 播放**。在控制器应用中选择 EffeTune 的 UPnP AV / DLNA 播放目标，然后选择电脑可以访问的音乐服务器上的曲目。OpenHome 权限单独控制，无需启用。

此目标通过 HTTP 或 HTTPS 接收 MP3、FLAC、PCM 编码的 WAV，以及 AAC（ADTS 或 MP4/M4A）。也支持 Ogg（Vorbis/Opus/FLAC）、WebM（Vorbis/Opus）和 Matroska 音频（PCM/FLAC/MP3/Opus/Vorbis/AAC）。文件格式受支持并不代表其中的所有编解码器都可播放；不支持 ALAC。

控制器可以播放、暂停、停止、切歌、在音源支持时跳转，以及调节播放器音量或静音。该音量也适用于本地和 OpenHome 音乐播放，不会更改电脑音量或效果设置。选择新曲目会将当前播放队列替换为该曲目。控制器和 EffeTune 会显示相同的播放状态。 音乐服务器提供相关信息时，还可以在 Visualizer 的**曲目信息**项目中显示曲目标签和源音频格式。

请仅在可信的局域网中使用：启用后，控制器无需登录即可更改播放。防火墙询问时，请允许专用网络访问。音频不会转换格式，具体支持情况取决于控制器和音源。这是音频接收功能，不代表获得 DLNA 认证，也不保证支持视频或所有 DLNA 格式。

## 通过 AirPlay 接收音频

在 **设置 > 配置... > 网络** 中启用 **允许此网络中的 AirPlay 音频**，然后在发送设备的 AirPlay 音频输出列表中选择 **设备名称**。状态会显示接收端是否可用或正在接收。请保持 EffeTune 运行，并将两个设备连接到同一个可信局域网。能够访问已启用接收端的设备无需登录即可发送音频。

AirPlay 一次接收一台设备发送的立体声音频。请在发送端开始或停止播放并调节音量。本地和 UPnP AV 的音量与静音设置仅适用于文件和 URL 播放。AirPlay 音频准备好后会替换当前音乐播放。开始播放本地、OpenHome 或 UPnP AV 音乐会结束 AirPlay 接收。结束 AirPlay 后，先前的曲目不会自动恢复播放。 用 **×** 关闭 EffeTune 播放器或选择**停止**，会结束当前 AirPlay 会话；接收功能仍保持启用，可以再次连接。

发送端提供相关信息时，播放器会显示曲名、艺术家、封面和播放时间。将指针悬停在曲名上，可以查看专辑、作曲者、流派、备注、发送设备和音频格式等详细信息。可显示的信息取决于发送应用和内容；播放时间会在发送端报告时更新。也可以在 [Visualizer](visualizer.md) 中显示这些信息。

**接收音频**表示 AirPlay 编解码器，例如 ALAC 或 AAC-ELD。**接收端 PCM**表示 EffeTune 收到并用于处理的音频格式：44.1 kHz、16 位立体声。这些数值不代表原始音乐文件的音质。收到相关信息时，**发送端音量**会以只读百分比显示发送设备音量滑块的位置；请在发送设备上调节音量。

网络缓冲和 EffeTune 效果会增加延迟，因此声音可能落后于视频。不支持 AirPlay 2 功能、多房间同步、屏幕镜像、视频和受保护内容。兼容性可能因发送应用和设备而异。

AirPlay 发现功能在 Windows 和 macOS 上需要 Bonjour，在 Linux 上需要运行中的 Avahi / DNS-SD 服务。标准 Windows 安装程序会在需要时安装发现服务；便携版和 Microsoft Store 版要求预先安装该服务。在 Linux 上，请安装发行版提供的 Avahi / DNS-SD 服务，并通过常规服务管理工具启用。如果接收端不可用，请检查这些要求及专用网络的防火墙权限后重试。访客 Wi-Fi、VPN 或网络隔离可能导致设备无法相互发现。

## 选择音乐库和播放设备

在桌面版的 Music Library 中，使用 **Library** 选择 **This device** 或局域网上的音乐服务器。EffeTune 共享音乐库提供熟悉的分类浏览、搜索和排序功能，详见 [Music Library 指南](music-library.md)。其他音乐服务器会显示其公开的分类和文件夹层级；搜索和排序仅在服务器支持时可用。

在窗口顶部的设备选择列表中选择 **This device** 或 OpenHome 播放器。音乐库与播放设备互不影响，因此可以浏览一台电脑的音乐，在另一台设备上播放。切换播放设备只会改变操作对象，不会停止原设备的播放或转移队列。界面显示所选设备的曲目、队列、进度、重复和随机播放状态，只提供它支持的操作，也会反映其他控制器的更改。

## 共享音乐文件夹

打开 **设置 > 配置... > 网络**。在 **音乐库共享** 中选择文件夹，启用 **在此网络上共享选定文件夹**，然后点击 **保存**。如果没有显示文件夹，请先将其添加到 Music Library。共享默认关闭，只公开选中的已登记文件夹。同一网络上的设备无需登录即可浏览和播放。关闭共享或取消选择文件夹后，点击 **保存** 即可撤销访问。存放音源的电脑必须保持 EffeTune 运行。

如需在不启用音乐库共享的情况下播放本地文件，请选择其他播放设备并使用 **Open music files**。EffeTune只向该设备提供选中的文件；请保持音源端的应用运行。

共享的是原始音频，不包含音源电脑的音效。播放设备为 EffeTune 时，由播放设备应用自己的音效。选曲设备不处理音频，也不持续中转音频。服务器与播放器必须能够相互通信；控制应用断开后，队列仍可继续播放。

## 编辑播放设备的音效（桌面版）

选择 EffeTune 播放设备并打开 **Effect Pipeline**。首次连接前，请在该设备的 **设置 > 配置... > 网络** 或 **设置 > 远程控制...** 中启用 **允许远程控制**。在操作端选择 **Connect effects**，然后在播放设备电脑上显示的请求中选择 **允许**，即可连接，无需输入配对链接。获准的连接会被保存，以后选择该播放设备时将自动连接音效编辑。仅发现设备或共享音乐库并不授予音效编辑权限。

音效标题显示正在操作的设备。可使用对方支持的音效链、旁路、A/B、撤销/重做和已保存的音效链预设；IR 选择器也使用对方的 IR 库。保存和删除音效链预设会作用于该设备。单个效果器可以使用内置预设，但不支持远程操作其用户预设。不支持的操作不可用。其他厂商的播放器可以播放音乐，但不能使用 EffeTune 音效编辑器。

在 IR Reverb 库中，**上传文件…** 可将一个不超过64 MiB的 IR 文件导入所选播放设备；**下载** 可将单文件 IR 保存到当前操作设备。True Stereo 配对可以选择，但无法传输。要删除 IR，请在播放设备上打开库。只有您明确操作时才会传输，设备之间不会自动复制库。

连接中断后，所选设备保持不变，音效编辑暂时禁用。重新连接会读取对方的最新设置，不会重发尚未确认的编辑。要重新连接，请依次选择 **Change connection** 和 **Connect effects**。远程控制按钮仍用于管理对本设备的访问；配对链接、浏览器编辑器和独立远程窗口也仍可使用。

## 通过 PWA 收听和控制

在同一网络中，[EffeTune PWA](https://effetune.frieve.com/effetune.html) 可以播放电脑共享的音乐，并应用手机自身的 EffeTune 音效，也可以控制已登记的 EffeTune 电脑的播放和音效。启动时，**Library** 和播放设备均为 **This device**。PWA 使用您添加的设备，不会自动发现其他音乐服务器。

1. 在电脑上打开 **设置 > 远程控制...**，启用 **允许远程控制**，然后选择 **复制链接**。如需浏览音乐，还请按前文说明在 **音乐库共享** 中共享文件夹。无需启用 OpenHome 控制器访问。
2. 在 PWA 的播放设备列表中选择 **Add device…**，将复制的链接粘贴到 **Pairing link**，然后选择 **Connect**。浏览器询问时，请允许访问本地网络。如果显示 **Scan QR code**，也可以扫描二维码；否则请粘贴链接。使用手机普通相机打开二维码，会进入独立的远程编辑器。

在 **Library** 中选择电脑，即可使用相同的九种浏览视图。将播放设备保持为 **This device**，可通过 PWA 的音效收听；选择已登记的电脑后，可打开 **Effect Pipeline** 编辑该电脑的音效。如需在电脑 B 上播放电脑 A 的音乐，请添加两台电脑，再将 A 选为音乐库、B 选为播放器。更改选择不会停止原播放器，也不会转移其队列。

再次打开 **Add device…**，即可管理 **Saved devices**。地址或连接代码更改后，请使用新链接通过 **Update connection** 更新；选择 **Remove** 可移除登记。**Refresh** 会重新获取设备可用状态和共享设置。清除浏览器数据会移除已保存的设备；存储不可用时，登记仅在当前会话内有效。旧版电脑可能只提供 **Open remote editor**，不支持 PWA 音乐播放。

请使用较新的 Chromium 浏览器，并允许访问本地网络。浏览器的支持情况有所不同，请参阅 [Chrome 本地网络权限说明](https://developer.chrome.com/blog/local-network-access)和 [WebSocket 支持](https://developer.chrome.com/release-notes/147)。HTTP 链接不加密，请仅在可信网络中使用。Safari/iOS 以及不支持本地 HTTP 的浏览器需要[受信任的 HTTPS 配置](../../remote-v1.md#encrypted-connections)，证书必须与电脑的 IP 地址匹配，并获得浏览器信任。浏览器或操作系统的策略仍可能阻止访问；扫描二维码不会自动使证书获得信任。

PWA 无法将自身的本地文件发送到其他播放器，请改为选择电脑的共享音乐库。音源和播放器应保持唤醒并连接网络。只要两者仍能相互通信，关闭 PWA 就不会停止另一台电脑的播放。手机能否播放取决于其支持的格式，应用进入后台时播放可能暂停。

## 网络播放限制

自动发现服务器和共享音乐文件夹需要桌面版。PWA 按上述方法连接已登记的 EffeTune 电脑。能否播放和跳转取决于播放设备及音源格式，不会自动转换音频。CUE 分段曲目不能作为独立网络曲目发送。不保证无缝播放或多房间同步。找不到服务器或播放器时，请确认设备处于唤醒状态、位于同一网络，并已获私人网络防火墙许可，然后刷新设备列表。音源应用退出或电脑休眠会停止共享。
