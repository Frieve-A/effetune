# Pipeline Analyzer

Pipeline Analyzer 可在不改变实际听到的音频的情况下，测量当前 Effect Pipeline 的响应。窗口较宽时，它位于 pipeline 旁边；窗口较窄时，它移到标题下方，便于一边调整效果器，一边查看结果。

可通过 Effect Pipeline 标题中的图表按钮，或桌面应用的 **View > Pipeline Analyzer** 打开。更改 pipeline 或测量设置后会自动重新测量。

## 通道和扬声器响应

选择一个输入通道。初始显示一个输出；使用 **+ 添加输出** 可从当前音频设备中添加最多四个不同的通道。删除输出时，其扬声器响应设置也会删除。最后一个输出不能删除。

每个输出都可选择 **无扬声器 IR**，或选择已连接高音、低音等扬声器单元的已保存测量点。**处理前** 是时间对齐后扬声器响应的带符号总和，**处理后** 是各输出经过所选 pipeline 后的带符号总和。这样可以同时查看 FIR Crossover 及各扬声器单元。若已保存的响应缺失，在替换或清除之前会一直明确标为缺失。

已保存的响应会按检测到的起点对齐。分开测量不会保留驱动单元之间的实际声学到达时间差，因此请先在 pipeline 中设置相对延迟和极性，再判断合计曲线。

## 测量设置

打开 **测量设置** 可调整以下项目：

- **信号**：默认使用 **MLS**。**TSP** 提供周期性扫相位信号，并使用相同的稳定与平均设置。**单位脉冲**则直接捕获时域响应。
- **电平**：测试信号峰值，默认值为 `-12 dBFS`。非线性或与电平相关的效果器可能产生不同结果。
- **序列长度**：MLS 使用 32,767 至 524,287 个采样，TSP 使用对应的二次幂 32,768 至 524,288。切换信号时会保持相同阶数。序列越长，在循环重叠前能表示的响应越长。Analyzer 会在能够判断时给出建议，但绝不会自动更改。
- **稳定周期**：默认值为 12。在捕获前，MLS 或 TSP 会连续运行这些周期，并显示实际时长。
- **平均次数**：默认值为 2。增加周期可减小重复捕获之间的变化。

详细信息还会显示**当前支持长度**、**建议序列长度**、以周期数和秒数表示的**建议稳定时间**，以及**测试信号总时长**。这些数值仅供参考；Pipeline Analyzer 不会自动更改设置。

仅在选择单位脉冲时，序列长度、稳定周期和平均次数会被禁用。切换 Frequency、Phase、Group Delay 或 Impulse 只会改变图表显示，不会重新测量。

## 图表和测量方法

**Frequency** 显示电平，**Phase** 显示相位，**Group Delay** 显示各频率的延迟，**Impulse** 显示时域响应。图表始终只显示 **处理前** 和 **处理后** 两条曲线。移动指针可读取两个值；指向 **处理前** 时会暂时隐藏 **处理后**。Frequency 与 Group Delay 共用 **平滑度 (oct)** 设置。每条频率曲线分别以 0 dB 为基准；每条脉冲按自身完整响应峰值归一化，并从 -2 ms 显示到所选的 **脉冲范围 (ms)**。

每次测量都会固定当前 pipeline、资源、通道路由、扬声器响应及测量设置，并在独立 worker 中运行。MLS 使用循环相关，TSP 使用逆扫频来恢复除 DC 之外的周期响应。界面显示的相位、群延迟和脉冲时间会减去 pipeline 报告的延迟。单位脉冲会按所选电平归一化捕获结果，并使用有上限的尾部捕获。

对于非线性、时变、随机、含噪声或会自行产生声音的效果器，结果只是所选电平和初始状态下的一次捕获，并非通用于所有条件的传递函数。不同测量之间可能不同。若数值输出无效，或必需的处理器、资源无法准备，测量会失败。
