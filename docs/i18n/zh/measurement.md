# 声学特性测量

测量频率响应、脉冲响应、失真和衰减，并按需生成校正 EQ：
1. 打开[声学特性测量](https://effetune.frieve.com/features/measurement/measurement.html)，或从 **设置** 菜单中选择 **声学特性测量**。
2. 按照引导设置测量麦克风和输出设备。
3. 在一个或多个聆听位置测量系统的频率响应。
4. 生成可直接导入 EffeTune 的参数均衡校正。
5. 应用校正，让回放更准确、更中性。

## 输出声道

请按输出设备设置 **输出设备声道数**：5.1 设为 **6**，7.1 设为 **8**。输出通道和各声道带宽的选项都限定在此范围内。测试信号和测量始终使用这个声道数，因此在 5.1 设备上只测量 Ch 3（中置）和 Ch 4（低音炮）时，也请保持为 **6**。

对于多声道系统，选择 **所有声道** 可同时测量全部输出；选择各个 **输出通道** 则会逐一测量。在 **高级设置** 中，为扫描带宽选择 **关闭**、**所有声道共用** 或 **按声道**。选择 **按声道** 时，使用 **要配置的声道** 设置每个选定输出声道的频率范围。调整电平时，**通道模式** 最初为 **自动轮换**；需要时可选择特定的测试信号通道或 **手动**。

## 导入脉冲响应

如果已有脉冲响应 WAV 文件，请选择 **导入** 并指定该文件。EffeTune 会将 WAV 的每个声道保存为测量结果，供 **Room EQ** 等基于测量的功能使用。

## 音频接口校准

若要去除音频接口自身的响应，请将其输出直接连接到输入，并把这次环回测量保存为带脉冲响应的普通未校准测量。测量扬声器时，在 **音频接口校准** 中选择这个已保存的测量点，并保持相同的接口、声道、采样率以及输入/输出增益设置。选择 **无（未校准）** 则不使用环回校准进行测量。

## 查看和导出结果

结果分为五个选项卡。频率响应可以显示多个测量点或输出的平均值；脉冲响应、失真和 Waterfall 则分析一个已保存的测量点和输出。从平均值切换到这些选项卡时，会恢复上次有效的单独选择；如果没有，就选择第一个可用记录。返回频率响应时会恢复该选项卡原来的选择。所有输出同时发声的测量表示的是它们的合成响应。

- **频率响应** 用于比较实测响应、校正 EQ 和校正后的预测响应。可以调整频率与 dB 范围、显示平滑、相对归一化或参考电平，以及显示哪些曲线。平滑宽度采用高斯分布的 σ；选择不平滑只是不增加平滑处理，无法撤销已保存响应中的处理。对于带 IR 的单独记录，可以查看已保存响应，也可以设置起点前后的窗长和窗形重新分析 IR。分析的时间区间不同，结果可能不同。显示设置不会改变已保存的测量值或校正 EQ。校正设计、复制和 TXT/CSV 导出仍在校正区域中操作。
- **脉冲响应** 显示带正负号的振幅，或以 dB 表示振幅的绝对值。可以调整时间与振幅范围、缩放和平移、峰值归一化、显示时间原点，以及窗口前后长度和形状。叠加的窗口标出分析区间。零时刻默认是检测到的起点；移动原点只改变显示，不会改变测得的声音传播时间。导入的 WAV 或没有播放时间基准的录音无法提供绝对传播延迟。无论显示窗口和缩放如何设置，WAV 导出都会按保存的采样率输出完整、未归一化的线性响应，格式为单声道 32 位浮点音频。
- **失真** 显示谐波相对于基波的比值，初始显示 H2、H3 和 THD。在 **显示设置** 中，**显示的最高谐波阶数** 滑块可根据测量包含的数据选择至 H10；仅含 H3 及以下阶数的记录需要重新测量才能查看更高阶。**THD 最高阶数** 单独设置，不能超过显示上限。还可以调整频率与纵轴范围、显示的曲线和分析窗口。在 **单位** 中选择 % 或 dBr；二者表示相对于基波的同一比值，1% = −40 dBr。比值越大，谐波失真越多。THD 综合第 2 阶至所设最高阶，仅在所有阶数都有效的频段显示；空缺表示没有可用数据，不表示失真为零。失真分析中的 **Hann** 在直接响应起点的权重为 1，并向所选窗口两端平滑降至 0；改变窗口可能改变曲线。高阶谐波可用的窗口更短、频率范围更窄，增大请求扫频长度可改善分离。结果包含从播放到录音的完整链路；音频接口的线性校准不会消除其失真。
- **Waterfall (3D)** 提供 **Waterfall** 和 **Burst Decay** 两种分析模式。曲面高度与热图颜色表示相同的相对 dB 电平，可通过色标和位置读数查看数值。等高线连接具有相同 dB 电平的点。频率网格线在坐标轴刻度对应的位置沿曲面延伸。**归一化** 中的 **无** 保留原始电平。**整体峰值 = 0 dB** 以显示频段及可用时刻中的整体最大值为基准，保留各处的电平差。**各频率峰值 = 0 dB** 将各频率在可用时刻中的最大电平设为 0 dB，便于比较衰减；峰值不一定出现在 0 ms。默认视角下，纵深为 0 的位置在后方，较晚的值靠近前方。设置频率和 dB 范围以及首末切片。可以用视角控件调整旋转、仰角和缩放，也可以拖动旋转，用滚轮或 + / − 缩放。**重置视角** 只恢复视角，不改变分析设置。**Waterfall** 的纵深以 ms 为单位，可调整窗长、上升时间、窗形和平滑。较长的窗更容易分辨相邻频率，但会模糊时间上的变化；上升区间也影响时间分辨率。仅显示完整落在已保存响应内的分析窗。**Burst Decay** 显示固定 1/3 倍频程带宽的高斯形音调脉冲的包络。纵深可选以 ms 为单位的 **时间** 或 **周期数**，初始周期范围为 0–30。周期数便于比较振铃持续了多少个周期：100 Hz 的一个周期为 10 ms，1 kHz 的一个周期为 1 ms，因此相同周期数对应的经过时间不同。音调脉冲本身的长度也会影响显示的衰减。估算时假定首个已保存采样之前为静音，同时保留起始点之前已保存的采样。后段的空白表示记录的尾部长度不足，并不表示静音。
- **测量详情** 显示采集方式、校准、采样率、时间基准、保存时长和可用分析。在此导出 JSON；包含脉冲响应时，也会包含可用的谐波数据。不含脉冲响应的 JSON 会保留频率结果，但无法恢复时间或失真分析。

通过图例和位置读数，可以用鼠标、触摸或键盘查看数值。 在 **频率响应** 和 **失真** 中，将指针移到图例项上即可突出显示对应曲线。自动范围和重置功能可帮助恢复便于观察的视图。所显示的电平是相对值，不是经过校准的声压级。 频率读数还会显示 λ，即一个波长的长度，单位为 m，按 15°C、1 个标准大气压的干燥空气中声速 340.3 m/s 计算。

点击四个图表上方的相机图标（**复制图像**），即可将高分辨率 PNG 复制到剪贴板，再粘贴到演示文稿或博客编辑器中。图像保留当前视角和主题、标题、所选测量，以及已显示的图例和色标，不包含光标或设置控件。

新测量采用指数正弦扫频（ESS）。请从较低输出电平开始，在不发生削波的范围内调整。失真分析需要该次测量中有效的谐波数据；导入的 WAV，以及只有频率响应或线性 IR 的测量，都不能提供这些数据。如果数据不可用，请导入包含所需响应的测量文件，或重新测量。可用范围也取决于扫频频段和录音时长。 为分离谐波，实际扫频可能比请求的长度更长。每次重复还包括等待衰减的 2.5 秒。关闭频段限制时，ESS 在实际采样率允许的范围内使用 20 Hz～20 kHz。

如需查看当前效果链的 Frequency、Phase、Min Group Delay、Excess Group Delay 和 Impulse 响应（可包含最多四个选定输出，以及可选的已保存扬声器响应），请参阅 [Pipeline Analyzer 指南](pipeline-analyzer.md)。
