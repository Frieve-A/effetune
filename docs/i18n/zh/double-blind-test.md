# 双盲测试使用指南

双盲测试可让你在不知道当前正在聆听哪一条效果链的情况下，仅凭听感对比 **Pipeline A** 与 **Pipeline B**。这是一种受控的方法，用来检验你*觉得*听出的差异是否真的可以分辨，以及你是否真的更喜欢其中一条效果链。

提供两种测试类型：

- **ABX 测试** – 检验你能否可靠地区分两条效果链。
- **A/B 偏好测试** – 在不知道哪条是哪条的情况下，选出你更喜欢的效果链。

无论哪种测试，EffeTune 都会记录你的回答并给出 p 值，帮助你判断结果是否具有统计显著性。

## 准备两条效果链

测试会对比[使用 AB Pipeline 功能](README.md#使用-ab-pipeline-功能)中介绍的两条效果链：

- **Pipeline A** 和 **Pipeline B** 必须各自至少包含一个效果器。
- 将一种设置放入 Pipeline A，另一种放入 Pipeline B，并让其余部分保持完全一致（例如 *开启 EQ* 与 *关闭 EQ*），以便仅针对目标差异进行测试。
- 记住你在 Pipeline A 和 Pipeline B 中分别放置了哪种设置。测试会在每一轮中随机重新分配两条效果链；对于 A/B 偏好测试，最后会报告是 Pipeline A 还是 Pipeline B 获得了显著偏好。
- 在 Pipeline A 和 Pipeline B 都准备就绪之前，开始按钮会保持禁用状态。

## 打开测试

- **网页版应用：** 点击 **Effect Pipeline** 顶部栏中 A/B 切换按钮（显示当前效果链“A”或“B”的按钮）紧右侧的 **▼** 按钮，然后从弹出的菜单中选择 **双盲测试**。
- **桌面应用：** 同样可以使用 **▼** 菜单，也可以从 **文件** 菜单中打开测试。

测试打开期间，效果链的显示会被隐藏，使你无法看到哪些效果器处于启用状态，从而保持盲听。随时点击 **×** 按钮即可关闭测试并返回常规视图。

## 配置测试

配置界面包含以下选项：

- **测试名称** – 描述本次测试所对比的差异（例如 *开启 EQ vs. 关闭 EQ*）。该组合框的用法与效果预设相同，可以 **保存**、**调用** 和 **删除** 命名测试。已保存的测试会同时记录两条效果链和测试次数，方便日后重新加载同一对比。分享测试前必须填写测试名称。
- **你的名字** – 可选，会显示在结果中；留空则显示为 *匿名*。
- **测试次数** – 要进行的测试轮数（可通过输入框或滑块设置）。轮数越多结果越可靠，但耗时也越长。默认值为 20。

点击 **开始 ABX 测试** 或 **开始 A/B 偏好测试** 即可开始。

> **注意：** 测试中的 **A** 和 **B** 与 Effect Pipeline 的 Pipeline A、Pipeline B 是不同的概念。每一轮都会重新随机决定将哪条效果链的声音分配给 A、哪条分配给 B，且不会显示这种对应关系——因此你无法知道当前作为 A 听到的究竟是哪条真实的效果链。测试中的“A”不一定是 Pipeline A，请不要这样假设；正是这一点保证了测试的盲听性。

## 播放音频

测试只负责切换效果链，音乐仍由你像平时一样提供：

- 拖放音乐文件（或从文件菜单中打开），或
- 从外部物理音源向 EffeTune 输入音频。

测试界面上会显示音频设备的采样率以供参考。

## 进行 ABX 测试

1. 使用 **切换到 A**、**切换到 B** 和 **切换到 X** 按钮在各样本之间实时切换音频。**X** 与 A 或 B 中的某一个相同，每轮随机决定。
2. 可以不限次数地来回切换，直到判断出 **X** 与哪一个样本一致。
3. 点击 **X 与 A 相同** 或 **X 与 B 相同** 记录回答，随后进入下一轮。

也可以使用键盘切换：按 **A**、**B** 或 **X** 键，或按 **1**、**2** 或 **3** 键（主键盘数字行或小键盘）切换当前样本，效果与点击对应的切换按钮相同。投票时，按 **Q** 键选择 **X 与 A 相同**，按 **W** 键选择 **X 与 B 相同**。

## 进行 A/B 偏好测试

1. 使用 **切换到 A** 和 **切换到 B** 按钮对比两个样本（此模式下没有 X）。
2. 决定更喜欢哪一个后，点击 **更喜欢 A** 或 **更喜欢 B**。

同样可以使用键盘切换：按 **A** 或 **B** 键，或按 **1** 或 **2** 键（主键盘数字行或小键盘）切换当前样本。投票时，按 **Q** 键选择 **更喜欢 A**，按 **W** 键选择 **更喜欢 B**。

## 解读测试结果

完成所有轮次后，EffeTune 会显示结果：

- **ABX 测试** – 显示你的得分（百分比及正确数 / 总轮数）以及单侧二项检验的 p 值。如果 **p < 0.05**，说明结果具有统计显著性，你的回答不太可能仅由偶然解释，即你能够分辨这两条效果链；否则无法认为你能够分辨它们。
- **A/B 偏好测试** – 显示被选中次数较多的效果链（平局时显示为 Pipeline A）及其被选中的次数（次数 / 总轮数），以及双侧二项检验的 p 值。由于显示的是胜出一方，百分比始终在 50% 以上——因此百分比高本身并不代表存在真实偏好。关键要看 p 值：如果 **p < 0.05**，说明你的偏好具有显著性；否则无法认为你有显著偏好（接近 50% 的结果只是偶然）。

结果中还会显示你所用的总时间。

## 分享测试

点击 **分享此测试** 可将 URL 复制到剪贴板。该 URL 会 **还原两条效果链并打开盲听测试**，让打开链接的人能够进行相同的效果链对比。你可以随时分享——既可以在开始前从配置界面分享，也可以在完成后分享。如果在开始前分享，分享的重点是两条效果链的对比；开始前请确认测试轮数。如果在完成测试后分享，你的结果也会包含在内，接收者在自己测试前会先看到该结果。

分享需要两条效果链和测试名称，以确保分享的对比有意义，并可在对方那里复现。

使用分享的测试 URL：

- **网页版应用：** 在浏览器中打开分享的 URL。EffeTune 会恢复两条效果链并自动打开双盲测试。
- **桌面应用：** 复制分享的 URL，切换到 EffeTune，然后通过 **编辑 > 粘贴**、**Ctrl+V**（macOS 为 **Command+V**）或工具栏上的 **粘贴效果** 按钮粘贴。EffeTune 会从剪贴板读取 URL，恢复两条效果链并打开双盲测试。请在双盲测试面板尚未打开时粘贴 URL。
