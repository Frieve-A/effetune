# Visualizer

Visualizer 将 EffeTune 处理后的音频转换为可自定义的视觉画面，可将波形、频谱、滚动声谱图、立体声声像或音符声谱图与专辑封面、视频画面和曲目信息一同展示。调整显示画面不会改变声音。

## 打开与显示

在桌面端布局中，点击 **Effect Pipeline** 和 **音乐库** 旁边的 **Visualizer**；在移动端，点击右上角的 **Visualizer** 图标；在桌面应用中，选择 **视图 > Visualizer**；在[浏览器扩展](browser-extension.md)中，点击 Pipeline Editor 顶部的 **Visualizer**。也可在 **设置 > 配置...** 中将 Visualizer 设为启动视图。

可先从内置预设开始体验。预设按 16:9、21:9、4:3、1:1 和 9:16 画面比例分组，选择预设会替换当前布局。图表显示的是经过所有已启用效果处理后、即将送往输出的音频信号。

每种画面比例都提供 10 种通用预设：
- **Mastering Console**：在深色面板上排列左右声道叠加频谱、声谱图、立体声显示、响度表和分段式电平表。
- **Spectral Studio**：大尺寸高分辨率声谱图搭配竖向柱状频谱。
- **Harmony Lab**：以钢琴卷帘视图显示检测到的音符，并用色度螺旋展示音高类别分布。
- **Phosphor Scope**：以模拟 CRT 荧光屏的绿色辉光绘制示波器和立体声显示。
- **Hi-Fi Deck**：仿照经典音响荧光显示屏风格的分段式频谱与电平显示。
- **Vintage VU**：嵌在胡桃木边框中、带背光奶油色表盘的左右声道 VU 表。
- **Now Playing**：在模糊封面背景上显示专辑封面、曲目信息和频谱柱。
- **Neon Pulse**：带倒影的霓虹柱状频谱，背景随低音律动。
- **Phase Galaxy**：将相位图渲染为闪耀旋转的星体。
- **Chroma Mandala**：将色度螺旋渲染为万花筒图案。

另有 7 种预设仅在最适合的画面比例下提供：
- **Fretboard**（21:9、9:16）：在吉他指板上显示检测到的音符并附带节拍指示；21:9 布局还在指板上方增加了钢琴卷帘视图。
- **Power Amp**（21:9、16:9）：黑色功放前面板上的蓝色背光 VU 表。
- **Round Dials**（1:1、9:16）：镶有黄铜外圈的圆形 VU 表。
- **Beat Stage**（16:9、9:16）：在随低音律动的大节拍圆环内显示检测到的速度，并搭配霓虹频谱柱。
- **Lyric Stage**（16:9、9:16）：在随低音律动的专辑封面柔光之上显示同步歌词，并逐词高亮当前行（无歌词曲目则显示静态封面画面）。
- **Cinema Strip**（21:9）：横跨整屏宽度的声谱图、10 秒波形与横向滚动歌词。
- **Meter Bridge**（21:9、4:3）：将 True Peak、VU、慢速 RMS 和响度表并排排列在电平表与波形条上方，便于对比同一段音乐在不同表头下的响应。

将指针移到画面上或点按画面会显示 **⛶**，点击即可在保持所选比例的同时铺满应用窗口（边缘可能被裁切）。再次点击 **⛶**、按 **Esc** 或使用移动端返回操作即可恢复。在桌面应用中，若在打开 Visualizer 时切换到迷你播放器，可视化画面会显示在播放控件上方。

在连接两台及以上显示器的桌面应用中，选择 **视图 > Visualizer 纯净输出** 可在指定显示器上无边框、无控件全屏显示 Visualizer。布局保持原有比例，余留空间以黑边填充。纯净输出启用期间，应用内的 Visualizer 预览会按输出显示器的分辨率渲染以保持一致。当切换到其他应用（除非在同一菜单中启用了 **非活动时也显示**）、主窗口与该显示器重叠或正在进行双盲测试时，纯净输出会自动隐藏。若要停止，请选择 **关闭**，或点击输出画面后按 **Esc**。仅有一台显示器时，此菜单项不可用。

## 编辑布局

选择 **Edit** 可自定义布局。修改会立即生效，并在下次打开 EffeTune 时自动恢复。仅编辑布局不会覆盖已保存的预设；如需保存为命名预设，请使用预设对话框中的 **保存**。

在编辑模式下，左侧面板包含整体场景设置、项目列表和 **画质**，中间是画布，右侧是所选项目的控制项。数值参数可通过滑块调节，也可直接输入数值。

使用画布工具栏中的 **−** 和 **+**，或按住 **Ctrl+滚轮**（Mac 上为 **Cmd+滚轮**）以指针为中心缩放（10–400%），便于精细排版；点击 **适应窗口** 可将整个画框居中显示。使用鼠标滚轮或触控板可平移画布（按住 **Shift** 可水平滚动），也可按住鼠标中键或 **Space+左键拖动** 平移。当画布获得焦点时，按 **+** 和 **−** 以中心缩放，按 **0** 适应画框。平移和缩放不会计入 **撤销** 步数。

将项目移出或放大到画框外时，无论在编辑模式还是正常视图下都会沿画框边缘裁切，同时编辑区域仍会保留其选择手柄。例如，可将 **Shape** 部分放在画框外，制作与显示边缘齐平的面板。

- 选择画面比例、背景颜色或背景图片（大图会自动缩放）。**主题颜色** 可自定义当前布局的图表基底色、浅色图表填充、细网格与主网格、图表标签、坐标轴标题和仪表刻度，而不改变波形与曲线的调色板。未修改的颜色始终使用默认深色主题配色，不受 EffeTune 界面主题影响。点击 **使用默认颜色** 可恢复默认配色。
- **图形缩放**（×0.50 至 ×3.00，默认 ×1.00）：图表会从小窗口到 4K 等比例缩放。**图形缩放** 会统一放大或缩小布局中所有图表的线条、刻度、峰值标记和图表标签，而 Title、Album、Artist 和 Text 则保持各自的字号。
- 可添加 **Oscilloscope**、**Spectrum**、**Spectrogram**、**Stereo**、**Level Meter**、**Analog Meter**、**Notes**、**Guitar**、**Chroma Spiral**、**Phase Map** 或 **Rhythm Analyzer** 图表，也可添加 **Lyrics**、**Artwork**、**Video**、**Title**、**Album**、**Artist**、**Text** 或 **Shape**。拖动项目可移动位置，拖动控制点可调整大小（按住 **Shift** 保持宽高比，按住 **Ctrl**/**Cmd** 从中心缩放）。使用 **吸附到网格** 可辅助对齐，拖动时按住 **Alt** 可暂时忽略吸附。**上移**、**下移**、**移到最顶层** 和 **移到最底层** 控制图层前后顺序（列表中越靠下的项目显示越靠前）。按 **Ctrl+D**（Mac 上为 **Cmd+D**）或按住 **Alt 拖动** 可复制所选项目。
- 在画布或列表中按住 **Shift+单击**（或在列表中 **Ctrl/Cmd+单击**）可选择多个项目，也可在空白画布上拖出选框（**Shift+拖动** 可追加选择）。在项目重叠处按 **Ctrl+单击**（Mac 上为 **Cmd+单击**）可依次循环选择指针下方的后层项目。按 **Ctrl+A**（**Cmd+A**）全选，按 **Esc** 取消选择。移动、删除、复制副本、剪切、复制和粘贴均会作用于所有选中项目。当所选项目属于同一类型时，右侧面板中的修改会同时应用到全部选中项目，并提供边缘与居中对齐按钮。
- **撤销** 和 **重做**（**Ctrl+Z** / **Ctrl+Y**；Mac 上为 **Cmd**）可在当前会话中逐步回退或恢复布局修改、预设加载和链接导入。**剪切项目**、**复制项目** 和 **粘贴项目**（**Ctrl+X**、**Ctrl+C**、**Ctrl+V**）通过剪贴板移动项目，其中 **粘贴项目** 还支持直接导入剪贴板中的 Visualizer 分享链接。按 **Delete** 删除所选项目。在画布上右键单击（或长按）即可快速打开这些命令。
- 每个图表默认显示输出通道 1–2。选择单个通道时会在整个图表中显示该通道（在 Level Meter 和 Analog Meter 中则显示为单根电平条或单个表头）。水平轴与垂直轴均可翻转。
- **颜色模式**：**纯色** 使用单一颜色选择器；**渐变** 提供可编辑色标及 24 种预设（选择预设后点击 **应用**）。**反转渐变** 会翻转色标顺序。**Hue** 随时间循环变换色相，**Scroll** 让渐变流动，两者均支持调节 **速度** 与 **反转颜色变化方向**。

对于 **Title**、**Album** 和 **Artist**，可分别设置字体、字号、水平/垂直对齐、字间距、大小写、**加粗**、**斜体**、**描边** 和 **阴影**。**Artwork** 和 **Video** 支持 **圆角**。

添加 **Text** 可显示静态标签或聆听空间名称（最多 4096 个字符，支持多行），并提供与 Title 相同的排版、描边和阴影控件。

添加 **Lyrics** 可显示内置播放器当前曲目的同步或纯文本歌词（在纯净输出中同样可见）。歌词会自动从音频内嵌标签或同文件夹下的同名 `.lrc` 文件读取（对于 CUE 分轨曲目，`Artist - Title.lrc` 或 `Title.lrc` 优先于整张专辑的同步歌词）。对于直接在浏览器中打开或拖入的音乐，请将 `.lrc` 文件与音乐一起选择或拖入；流媒体没有歌词。在未打开 **Edit** 时，点击或点按带时间轴的歌词行即可跳转到对应播放位置。
- 可选择 **列表** 或 **单行**（单行可开启 **显示下一行**）。列表视图支持 **滚动（纵向）**、**逐行（纵向）**、**滚动（横向）** 和 **逐行（横向）**，并可调节 **逐行过渡时间**（0–2 秒，默认 0.18 秒）和 **当前行位置**（0–100%，默认 50%）。当歌词包含逐词时间信息时，**单词高亮** 会渐进填充当前行；**偏移**（−10 至 +10 秒）用于微调同步时间，正值会让歌词延后显示。没有时间信息的歌词始终以列表显示，随播放进度滚动，不做高亮。
- **行距**（50–300%，默认 100%）用于调整行与行之间的间距。**淡入时间**（0–10 秒，默认 1 秒）和 **淡出时间**（0–10 秒，默认 3 秒）让 Lyrics 项目在每首曲目的开头和结尾平滑淡入淡出；设为 0 即关闭对应的淡变。

添加 **Video** 可显示内置播放器正在播放的视频画面（支持浏览器或操作系统可解码的 MP4、M4V、MOV、MKV、WebM、3GP）。**适应方式** 可选 **完整显示**（默认）、**填满并裁剪** 或 **拉伸**。**无视频时显示封面**（默认开启）会在播放纯音频曲目时回退显示专辑封面。通过 CUE 索引文件播放的曲目不显示视频。

添加 **Shape**（**矩形**、**椭圆**、**三角形** 或水平 **直线**）可创建面板、边框或分隔线，支持调节 **填充不透明度**、**边框颜色**、**边框粗细**、**边框不透明度** 和 **圆角半径**。将 **椭圆** 的宽和高设为相同即为圆形，将 **填充不透明度** 设为 0% 只保留边框，将 **边框粗细** 设为 0 则去掉边框。

## 调整和阅读图表

**Spectrum** 按频率显示电平并带有回落峰值标记。**方向** 可在 **水平**（默认）与 **垂直** 之间切换。**显示方式** 可选 **线条** 或 **柱状**。在 **柱状** 下，**频段数**（8–128，默认 48）设置柱子数量，**每格 dB**（0.5–12 dB，默认 1 dB，设为 0 即 **连续**）设置每格的大小（越小台阶越细），**量化**（默认开启）会将柱子和峰值对齐到整格，但不改变测得的电平。**采样点数** 是分析长度：点数越多，越能分开相邻的频率，但响应也越慢。**频率刻度** 可选 **对数（HQ）**（默认）、**对数** 或 **线性**，**最高频率** 设置频率上限（1–40 kHz，默认 40 kHz）。**平滑** 可在最宽 1 个倍频程内让曲线更平缓（默认 0），**dB 范围** 设置显示的最低电平（默认 −96 dB；负值越大，越能看到更弱的成分）。**键盘** 可添加钢琴琴键参考，**键盘长度** 设置琴键长度（默认 100% 为真实钢琴琴键的一半，200% 与真实钢琴一致）。**键盘**、**坐标轴与网格** 和 **坐标轴标签与数值** 默认关闭。

**Spectrogram** 将频率纵向排列并随时间横向滚动，使用与 Spectrum 相同的 **采样点数**（默认 4096）、**频率刻度**（默认 **对数（HQ）**）、**dB 范围**、**最高频率**、**键盘** 和坐标轴控件。

**Stereo** 以菱形上的圆点显示立体声声像（两个声道共有的声音沿纵向分布，左右声道的差异沿横向分布），并带有峰值轮廓。**峰值**、**相关性** 和 **平衡**（均默认开启）分别控制峰值轮廓、相关性条（左右声道一致时为 +1，极性相反时为 −1）和平衡条（以 dB 显示哪一侧更响）的显示。**窗口**（10–1000 ms，默认 100 ms）设置显示的最近音频长度：越短越能跟上瞬态，越长显示越稳定。

**Level Meter** 以水平或垂直方向显示各声道电平（默认 −96 至 0 dB，**dB 范围** 可调 −144 至 −48 dB），支持连续或分段条形（**每格 dB**）、峰值保持标记以及持续 5 秒的 **OVERLOAD** 削波警告。**坐标轴与网格**、**坐标轴标签与数值** 和 **电平数值**（保持的峰值读数；关闭 **峰值** 时为当前电平）用于切换刻度与数字读数，三者默认均关闭，而 **OVERLOAD** 始终显示。支持 **纯色**、**渐变** 和 **热力图** 颜色模式。

**Oscilloscope** 在 **显示时长**（1–10000 ms，默认 10 ms）范围内绘制波形振幅。较短时间绘制线条轨迹，较长时间绘制最小值/最大值包络带。**触发模式** 可选 **自动**（默认；没有触发也持续更新）、**正常**（保持上一条波形，直到信号沿 **触发沿** 方向穿过 **触发电平**）或 **关闭**（连续滚动波形；忽略触发设置）。**触发电平**（−1 至 1，默认 0）、**触发沿**（**上升沿**（默认）/ **下降沿**）和 **触发保持时间**（0.1–10 ms，默认 0.1 ms；越长越能抑制短间隔的重复触发）决定捕获位置。**显示电平**（−96 至 0 dB，默认 0 dB）越低，较弱的波形显示得越大；**垂直偏移**（−1 至 1，默认 0）为正值时波形上移。

**Notes** 以 **水平** 或 **垂直** 布局在 1–10 秒的 **显示时长** 内显示检测到的音高，支持设置 **音高分辨率**（**1/12 八度** 或 **高精度**）、**音量**（默认开启；以条的粗细显示各音的相对音量）、**最低音** / **最高音**，以及可选的 **键盘** 和坐标轴。

**Guitar** 将检测到的音高映射到指板上。可选择预设的吉他、贝斯或尤克里里 **调弦**，或输入自定义 **空弦音**（最多 10 根弦），并设置 **最低品位**、**最高品位** 和 **变调夹**。**把位显示** 可选 **全部把位**（所有对应的品位）、**单一指型**（每个音只取一个可弹的位置：各音分在不同的弦上，手指跨度小，并靠近前一个手位）或 **单一指型＋其他候选**（其他位置以淡色显示）。**标签** 可选 **无**、**音名 (♯)**、**音名 (♭)** 或相对 **根音** 的 **音程**；**根音** 设为 **自动 (最低音)** 时跟随检测到的最低音，选择固定音时可叠加 **音阶指引**。**检测阈值**（10–90%，默认 50%）设置音符显示所需的强度，若杂音闪烁可调高。**按音量调整圆点大小** 会让越响的音画得越大（最弱的音为三分之一大小）。还可调节 **衰减时间**（0–2 秒）、**布局**（水平六线谱或垂直和弦图）、**无品**（连续音高定位，直观呈现推弦、揉弦和滑音）、**真实品丝间距**、**指板填充**、**品位标记**、**品位编号**、**弦名** 和 **水平翻转**。

**Chroma Spiral** 以 **Dots** 或 **Fill** 模式将检测到的音高排列在八度螺旋上，支持调节 **最低八度**、**最高八度**、**频率倾斜**、**电平范围** 和 **显示下限**。

**Phase Map** 与 Phase Select EQ 视图一致，纵向绘制频率成分，横向在 **X 轴** 上显示左右声道 **相位**（中心 0°，两端 ±180°）或 **平衡**；点越亮、越大，成分越强。**dB 范围**（−96 至 −24 dB，默认 −72 dB）设置从最强成分往下显示的范围（负值越大，越能看到更弱的成分）。**基准电平下限**（−120 至 −24 dB，默认 −40 dB）设置基准电平的下限，当最强成分也低于此值时，点会变小变淡。**余辉时长**（0.1–2.0 秒，默认 0.5 秒）越长，留下的轨迹越浓。坐标轴默认关闭。

**Analog Meter** 提供 **VU**（默认）、**PPM**、**RMS**、**Sample Peak**、**True Peak**、**Loudness** 或 **Custom** 模式的经典指针表头，采用与 [Analog Meter](plugins/analyzer.md#analog-meter) 效果器相同的阻尼响应与刻度控制，并且只显示所选模式用到的控件。**Custom** 会增加 **检波器**、**指针响应时间**、**过冲** 和 **刻度**，用于选择测量方式、指针速度、指针过冲幅度和刻度；不适用于所选检波器或刻度的控件会保留在原位但不可用。在 **Loudness** 模式下，通道表头之前会先显示一个节目响度表，显示 Momentary、Short-term、Integrated、LRA 和最大 True Peak；关闭或隐藏 Visualizer，或更改通道、**模式** 或 **指针** 时，Integrated、LRA 和最大 True Peak 会重新开始计算。除测量参数外，还可通过外观控件打造平面功放表头或复古圆形表盘：
- **刻度形状**：**刻度曲率**（0% 直线至 100% 圆弧）、**刻度展开角度**（30°–160°，默认 100°）和 **下移指针轴心**（0–100%）。
- **指针外观**：**隐藏指针根部**（0–90%）、**指针长度**（50–120%，默认 102%）、**指针宽度**（0.5–8）、**指针尖端形状**（**线形**、**渐尖** 或 **箭头**，其中 **箭头** 支持 0.25–4.00 的 **箭头尖端长宽比**）以及 **轴心圆点大小**（0–20）。
- **表盘文字**：VU 模式下的 **辅助百分比刻度** 与 **读数单位**（100% 为所选 **参考电平** 下的 0 VU；百分比是电压比，因此 50% 约为 −6 VU），以及 **数值读数**、**通道标题**、**模式标题**、**− / + 标记**、**正刻度显示＋号** 和 **红色区域** 开关。
- **仪表表盘**：**窗口形状**（**矩形**、**椭圆**、**圆形**）、**表盘颜色**、**表盘不透明度**、**表盘边框颜色**、**表盘边框宽度** 和 **暗角**（0–100%）。

**Rhythm Analyzer** 使用与 [Rhythm Analyzer](plugins/analyzer.md#rhythm-analyzer) 效果器相同的分析引擎显示速度、逐拍起音时机和频段微时序；此处不提供 **Metronome Click**。**最低 BPM**（40–192，默认 40）和 **最高 BPM**（50–240，默认 240）设置速度搜索范围，更改任一项都会重新开始分析。**跨度(拍)**（4、6、8、12 或 16；默认 8）设置 **计时轨道** 和 **回声行** 每一行包含的拍数。**速度图**、**计时轨道**、**回声行** 和 **节拍透镜** 开关分别控制各面板的显示（默认开启 **计时轨道** 和 **节拍透镜**）；项目较高时面板纵向堆叠，项目较宽时 **节拍透镜** 位于 **计时轨道** 旁边。此外，Visualizer 还提供位于中央的 **节拍** 闪烁圆圈和 **BPM** 文字叠加层，即使关闭全部四个图表面板也可独立工作。BPM 和节拍透镜显示的是已确定的分析结果，比声音晚约 1–2 秒；BPM 文字使用与 Title 相同的文字设置。
- **节拍圆圈**：可调节 **圆圈大小**（10–100%，默认 90%）、**边框宽度**（0–20，默认 2；设为 0 隐藏边框）、**填充不透明度**（默认 30%）、**边框不透明度**（默认 100%）、**使用调色板颜色**（或自定义 **填充颜色** / **边框颜色**）、**将 BPM 缩放至圆圈内**（缩小居中的 BPM 文字，使其容纳在圆圈内）、**保持亮起时间**（0–1000 ms，默认 0 ms；最亮状态在开始衰减前保持的时间）和 **衰减时间**（10–2000 ms，默认 90 ms）。

对于 Spectrum、Spectrogram 和 Stereo，**输入增益**（−24 至 +24 dB）仅缩放图表显示幅度，不影响音频播放。Spectrum、Level Meter 和 Chroma Spiral 提供 **衰减时间**（每 20 dB 0–5 秒）；Spectrum、Level Meter 和 Stereo 提供 **峰值**、**峰值保持**（0–10 秒）和 **峰值衰减时间**（每 20 dB 0.1–10 秒；Stereo 为 1–10 秒）。

在 **颜色模式** 下，Spectrum 和 Chroma Spiral 还支持固定的 **音符颜色** 与 **热力图**；Spectrogram、Level Meter 和 Phase Map 支持 **热力图**；Notes 和 Guitar 支持 **音符颜色**；其他有颜色设置的项目只提供 **纯色** 和 **渐变**。在 **渐变** 模式下，Spectrum、Spectrogram、Notes、Guitar、Chroma Spiral 和 Phase Map 提供 **渐变方向**（**频率**、**强度**（按信号由弱到强分配颜色）或 **径向**）；其他项目提供 **直线** 与 **径向**。**渐变角度 (°)**（−180° 至 +180°，默认 0°）可旋转任意非径向渐变，正值为顺时针。选择 **频率** 时，Notes、Guitar 和 Chroma Spiral 还支持 **完整音域** 或 **一个八度** 颜色映射。

## 动画与效果

可为任意项目或背景添加视觉效果并调整顺序，塑造理想的画面风格：
- **Opacity**、**Glow**、**Outline**、**Blur**、**Trail**、**Scale Pulse**、**Symmetry**、**Shake**、**Particles**、**Ken Burns**（适用于封面/视频/背景图片）、**Flash**（背景）以及 **Backplate**（在项目后方绘制可自定义的底板，支持 **填充颜色**、**填充不透明度**、**边框颜色**、**边框粗细**、**圆角半径** 和 **边距**）。
- **Edge Fade**：将项目边缘平滑过渡为透明，支持 **矩形**（可分别设置 **顶部**、**底部**、**左**、**右** 淡出宽度，0–100%）或 **圆形**（**淡出宽度**，0–100%）（默认：上下 10%，左右 0%，圆形 20%），且始终在最后一步应用；项目范围之外的内容也会被隐藏。
- **Transform**：围绕项目或背景的中心进行缩放（**水平缩放** / **垂直缩放**，0–300%，默认 100% 即不变）、倾斜（**水平倾斜（°）** / **垂直倾斜（°）**，−60° 至 +60°）、旋转（**旋转角度（°）**，−180° 至 +180°；正值为顺时针）和平移（**水平偏移** / **垂直偏移**，−100% 至 +100%；正值向右或向下）。倾斜、旋转和平移默认均为 0。
- **Trail Feedback**：对叠加的残影回声进行缩放（**缩放**，−2% 至 +2%，默认 +2%；正值放大）、旋转（**旋转角度（°）**，−3° 至 +3°，默认 1.15°；正值为顺时针）和漂移（**水平流动** / **垂直流动**，−1% 至 +1%，默认 0%；正值向右或向下）。

视觉效果既可保持恒定，也可随 **Time**、整体 **Level** 或低频 **Bass** 动态响应。**强度**（0–1）设置效果的强弱：对 **Opacity** 而言即项目的可见程度（1 为完全可见）；对 **Transform** 而言，0 表示不改变项目，1 表示完全应用设置；对 **Trail Feedback** 而言，0 时缩放、旋转和漂移停止，只留下短暂的残影。**响应幅度** 设置 **Time**、**Level** 或 **Bass** 使效果偏离 **强度** 的程度，**速度** 设置由 **Time** 驱动的变化循环的快慢。如果动画帧率下降，可降低 **画质** 或设为 **Auto**。

## 预设、分享、备份与音频同步

使用预设对话框可保存、重新加载、重命名或删除命名布局；内置预设始终可用。**设置 > 备份 / 恢复** 会备份已保存的 Visualizer 预设及其背景图片，但不包含当前正在编辑的布局。

点击工具栏中的 **分享** 可复制当前布局的分享链接（链接不包含背景图片；如需连同图片迁移请使用 **备份 / 恢复**）。在桌面应用或浏览器扩展中，复制分享链接后点击 **导入链接**，或在 Visualizer 中按 **Ctrl+V**（Mac 上为 **⌘V**）即可导入。导入的布局会直接替换当前布局，不会进行确认；如需恢复，请打开 **Edit** 并选择 **撤销**。

在 **设置 > 配置...** 中启用 **将画面与音频同步** 可使画面与扬声器输出保持对齐；为保持同步，音频可能会被延迟。如果图表没有反应，请确认 **音频设置** 中的 **使用 WebAssembly 音频处理** 已开启，且音频正在通过 EffeTune 播放。
