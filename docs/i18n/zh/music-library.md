# 音乐库使用指南

音乐库会对所选音乐文件夹建立索引，方便按曲目、文件、专辑、艺人、流派、子文件夹、文件夹、最近添加或播放列表浏览本地音乐收藏。播放同样经过当前的 EffeTune 效果链，因此可以使用与普通音乐文件播放相同的效果聆听。

音乐库将目录索引、封面缓存和播放列表保存在应用内部，不会编辑、重命名、移动或删除音频文件本身。

## 可用环境 {#availability}

- **桌面应用：** 使用完整的文件夹扫描器，重启应用后仍可保留已选文件夹。桌面版还可以在文件夹中显示曲目。
- **支持 File System Access 的桌面端 Chromium 浏览器：** 刷新页面后仍可保留已选文件夹的访问权限，浏览器可能会再次请求授权。
- **移动端浏览器、Safari、Firefox 等不支持 File System Access 的浏览器：** 仅在当前页面会话期间保留所选文件的访问权限。目录数据仍会保留，但每次刷新页面后需重新选择文件夹或文件，以便 EffeTune 重新关联。

音乐库会为 MP3、WAV、OGG、FLAC、Opus、M4A 和 AAC 等常见音频文件扩展名建立索引，还可以使用外部 CUE 索引文件将同一文件夹中的整轨 WAV 或 FLAC 专辑文件拆分为独立曲目。

若要纳入 MP4、WebM、M4V、MOV、MKV 和 3GP 文件，请在 **设置 > 配置... > 常规** 中启用 **在音乐库中包含视频文件格式**，然后添加或重新扫描文件夹。此选项默认关闭，更改设置不会立即改变现有目录。实际能否播放（包括视频文件中的音频编码）取决于浏览器或操作系统的解码器。视频的显示方式请参阅[音乐播放器指南](music-player.md#video)。

## 打开音乐库

- **桌面端布局：** 点击顶部栏中的 **音乐库** 按钮。
- **移动端布局：** 打开底部导航栏中的 **音乐库** 标签页。
- **桌面应用：** 也可通过菜单 **视图 > 音乐库** 或快捷键 **Ctrl+L**（macOS 为 **Command+L**）打开。

若要返回效果编辑界面，可在桌面端布局点击 **Effect Pipeline** 按钮，在移动端布局切回 **效果** 标签页，或在桌面应用中使用 **视图 > Effect Pipeline** 或快捷键 **Ctrl+E**（macOS 为 **Command+E**）。

若希望启动时直接进入音乐库，请打开 **设置 > 配置...**，将 **启动时显示:** 设为 **音乐库**，并在旁边的列表中选择首先显示的视图（**曲目**、**文件**、**专辑**、**艺人**、**流派**、**子文件夹**、**文件夹** 或 **播放列表**）。

## 添加音乐文件夹

1. 打开音乐库。
2. 选择 **添加音乐文件夹**。
3. 选择存放音乐的文件夹。在移动端或回退模式的浏览器中，文件选择器可能会要求选择文件夹内的内容，而非授予持久的文件夹访问权限。
4. 等待扫描完成。状态栏会显示曲目数与专辑数，并在建立索引期间显示扫描进度。

如果添加的文件夹已包含在现有音乐库文件夹内，EffeTune 会发出提示而不会重复建立索引；如果添加的是包含已索引文件夹的上级文件夹，EffeTune 可以将现有文件夹合并到新文件夹中。

## 浏览和搜索

使用导航标签页切换不同浏览视图：

- **曲目：** 所有已索引曲目（桌面端为可排序表格，移动端为紧凑列表）。
- **文件：** 按文件路径列出曲目，可直接按文件选择。由 CUE 文件定义的曲目也会作为独立条目列出。
- **专辑：** 按曲目元数据归类的专辑。
- **艺人：** 按元数据中的艺人和专辑艺人归类（如 `Artist A; Artist B` 这类以分号分隔的多位艺人，会在保留完整署名显示的同时分别归入每位艺人名下）。
- **流派：** 按元数据中的流派归类。
- **子文件夹：** 在每个已索引根文件夹内，按直接包含曲目的父级子文件夹归类（例如 `Artist/Album`）。
- **文件夹：** 显示已注册的根文件夹、扫描状态及其文件夹层级结构。
- **最近添加：** 最近建立索引的曲目。
- **播放列表：** 在音乐库内创建或导入的播放列表。

在 **文件夹** 视图中打开已注册的根文件夹后，可以使用 **树状视图** 逐层浏览文件夹，或切换到 **平铺视图** 一次列出该根文件夹下的所有曲目。在 **树状视图** 中，直接层级下没有曲目的单分支文件夹会合并为一行（如 `Artist / Album`），方便直接跳转到专辑文件夹，同时也可通过面包屑路径打开任意中间层级文件夹。

使用 **搜索音乐库** 可跨曲目、专辑、艺人和播放列表进行筛选。3 个及以上字符的关键词会匹配标题、艺人、专辑、流派、文件名或路径中的任意位置；1 至 2 个字符的关键词则匹配词首。在桌面端可点击曲目表头（**音轨编号**、**标题**、**艺人**、**专辑**、**流派** 或 **时长**）排序，或在其他视图中使用 **排序** 列表；在移动端可在已保存播放列表以外的任意视图中使用 **排序** 列表调整顺序。

当搜索结果、文件夹层级、专辑、艺人、流派、子文件夹或播放列表中的曲目不超过 300 首时，默认会全选所有曲目，方便直接开始播放。超过 300 首时不会自动全选，可使用行复选框、**全选** 或 **取消全选** 更改选择。在移动端长按任意曲目行即可显示复选框与选择操作。

若音频文件缺少标签，EffeTune 会回退使用文件名和文件夹名。曲目属性中会显示文件路径、格式、采样率、位深、比特率、元数据，以及（针对 CUE 曲目）CUE 文件路径与曲目时间区间。

## CUE 专辑文件

将外部 `.cue` 索引文件放在其引用的 WAV 或 FLAC 文件同一文件夹下，然后添加或重新扫描该文件夹，每个有效的 `TRACK ... AUDIO` 条目都会在音乐库中显示为独立曲目。

封面图片会优先使用源音频文件内嵌的封面，若无内嵌封面，则会查找 `.cue` 文件同目录下的 `cover.jpg`、`cover.png`、`front.jpg`、`front.png` 或与音频文件同名的图片。

也可以直接从播放器打开 `.cue` 文件（**打开音乐文件**、桌面应用中的 **文件 > 打开音乐文件...** 或移动端的 **打开音乐**）：
- **桌面应用：** 仅选择 `.cue` 文件即可。
- **桌面端 Chromium 浏览器：** 若专辑所在文件夹已在音乐库中注册且拥有访问权限，仅选择 `.cue` 文件即可。
- **其他浏览器：** 将 `.cue` 文件与其引用的全部 WAV/FLAC 文件（不含其他音频文件）一同选中；如需封面，再加选对应的封面图片。

如果 CUE 文件无效或无法匹配对应的音频文件，EffeTune 会发出提示，并将 WAV 或 FLAC 文件作为未拆分的整轨曲目导入。请修正 CUE 文件或其文件名，然后重新扫描文件夹再试。

## 从音乐库播放

选中曲目、专辑、艺人、流派、子文件夹、文件夹、搜索结果或播放列表后，可执行以下操作：

- **播放：** 替换当前播放队列并立即开始播放。
- **随机播放：** 以随机顺序播放所选内容。
- **下一首播放：** 将所选内容插入到当前播放曲目之后。
- **添加到队列：** 将所选内容追加到播放队列末尾。
- **添加到播放列表：** 将所选内容添加到音乐库播放列表中。

在桌面端，双击曲目行可从该曲目开始播放，右键点击或打开 **更多** 菜单可执行更多曲目操作。在移动端，点按曲目即可播放，长按可多选曲目。

## 文件夹维护与更新

在音乐文件夹中新增、删除、重命名文件或修改标签后，请使用 **重新扫描**。重新扫描会更新修改过的曲目、从目录中移除已删除的文件，并在找到匹配文件时自动重新关联播放列表条目。

**文件夹** 视图中的状态说明：
- **正常：** 可正常浏览和播放。
- **未扫描：** 已添加但尚未建立索引。
- **未找到：** 无法再找到该文件夹路径。
- **重新连接：** 需要重新授予浏览器或文件夹访问权限；请点击 **重新连接** 并授权访问同一文件夹。

如果因文件夹处于离线状态而无法打开音乐库中的曲目，请重新连接或重新导入该文件夹。

选择 **移除** 仅会将该文件夹从 EffeTune 目录中移除，绝不会删除磁盘上的实际文件。

## 播放列表

音乐库播放列表保存在 EffeTune 内部，可收录来自任意已索引文件夹的曲目：

- 可用所选音乐库曲目创建播放列表，或将当前播放队列保存为播放列表。
- 使用 **重命名**、**复制** 和 **删除** 管理播放列表，拖动曲目（或使用 **上移** / **下移**）可调整曲目顺序。
- 使用 **导入播放列表** 可导入 M3U、M3U8、PLS 和 XSPF 文件；在播放列表内选择 **导出 M3U8** 或 **导出 XSPF** 可将其导出。

### 最近播放与收藏

使用后，播放列表网格中会显示两个自动播放列表：

- **最近播放：** 按从新到旧的顺序保留最近从音乐库播放的 100 首不重复曲目。
- **收藏：** 汇总在桌面端用曲目旁的 **☆** 标记的曲目，或通过曲目 **更多** 菜单中的 **添加到收藏** 添加的曲目（在桌面端也可右键打开该菜单）。点击 **收藏** 卡片上的播放按钮即可立即开始播放。

这两个列表的名称随当前界面语言变化且不可重命名，但可以像其他播放列表一样复制、导出或删除。

### 导入和导出播放列表

扫描文件夹时会自动导入音乐文件夹内受支持的播放列表文件，并在磁盘上的播放列表文件发生更改时通过重新扫描同步更新；此更新会覆盖你在 EffeTune 中对该播放列表所做的编辑。暂未匹配的条目会作为未解析项保留，待后续添加或重新连接对应文件夹后会自动关联。

导出播放列表时，如果希望导出的 M3U8 或 XSPF 文件能随音乐文件夹一起移动，请启用 **相对路径**。由于标准 M3U8 与 XSPF 格式不保存 CUE 子曲目区间，导出时会自动跳过 CUE 曲目并提示跳过的数量。

## 安全性与数据存储

- 音乐库仅读取音频文件与元数据，不会修改磁盘上的任何文件。
- 清除浏览器站点数据会移除网页版应用的目录索引和播放列表；请导出重要的播放列表加以保留。
- 大型音乐库会在滚动时渐进加载。请一次只在一个 EffeTune 窗口中使用音乐库。

## 网络上的音乐（桌面版）

使用 **Library** 浏览本设备或发现的音乐服务器，通过窗口顶部的设备选择列表选择音乐在哪里播放。切换音乐库只改变浏览和搜索范围。添加文件夹、重新扫描等本地管理操作只在选择 **This device** 时提供。

浏览另一台 EffeTune 的音乐库时，也可以像在本机一样使用 **Tracks**、**Albums**、**Artists**、**Genres**、**Subfolders**、**Files**、**Folders**、**Recently Added** 和 **Playlists** 查找音乐。您可以搜索所选音乐库、对列表排序，或打开专辑、艺人和流派查看其中的曲目。在 **Folders** 中，使用 **Tree** 逐级浏览文件夹，或使用 **Flat** 将所选文件夹中的全部曲目列在一起。这里只显示已共享的音乐。远程播放列表可以浏览和播放；如需编辑，请在音源电脑上操作。

其他音乐服务器会显示其公开的分类和文件夹层级；搜索和排序仅在服务器支持时可用。

在其他播放器上播放Music Library中的曲目前，请先通过 **设置 > 配置... > 网络 > 音乐库共享** 明确共享对应文件夹。可用格式和音效取决于播放设备；CUE 分段曲目不能作为独立网络曲目播放。设置、音效配对及连接故障处理请参阅[网络音乐与远程控制](openhome.md)。

如需在不启用音乐库共享的情况下播放本地文件，请选择其他播放设备并使用 **Open music files**。EffeTune只向该设备提供选中的文件；请保持音源端的应用运行。

## 在 PWA 中收听共享音乐

PWA 可以浏览已登记的 EffeTune 电脑的共享音乐库，并通过本设备的音效或另一台已登记的电脑播放。PWA 的本地文件无法发送到其他播放器。添加设备、浏览器权限和连接条件，请参阅 [PWA 设置与播放](openhome.md#pwa)。
