# 其他音频工具

这些专用工具和发生器用于补充主要效果类别。它们适合在聆听前或聆听过程中检查扬声器、耳机、通道平衡和播放行为。

## 插件列表

- [Oscillator](#oscillator) - 用于检查扬声器/耳机的测试音和噪声发生器
- [SoundFont Note Player](#sfz-note-player) - 使用 SF2/SF3 SoundFont 和 SFZ 乐器演奏检测到的音符
- [SoundFont Player](#soundfont-player) - 使用 SF2/SF3 SoundFont 和 SFZ 乐器播放 MIDI

## Oscillator

用于检查聆听系统的测试音和噪声发生器。请以低音量使用，用来确认扬声器/耳机输出、左右位置、电平平衡、异响、共振或简单的频率响应问题。

生成的测试音或噪声会混入当前音频路径，而不是替代输入音频。启用前请先降低 Volume，尤其是在音乐已经播放时。

### 功能
- 多种波形类型：
  - Sine：简单音调检查
  - Square：丰富奇次谐波
  - Triangle：较柔和的谐波
  - Sawtooth：明亮音色
  - Impulse：用于检查脉冲响应和时序的周期性单采样脉冲
  - White Noise：宽频扬声器/耳机检查
  - Pink Noise：更平滑、更自然的噪声平衡
- Pulsed 模式用于间歇测试音或噪声脉冲

### 参数
- **Frequency (Hz)** - 控制生成音调的音高（20 Hz 到 96 kHz）
  - 低频：深沉低音测试
  - 中频：音乐常用范围
  - 高频：请谨慎使用，并保持安全聆听音量
  - 仅适用于 Sine、Square、Triangle 和 Sawtooth；Impulse、White Noise 和 Pink Noise 下禁用
  - 可用的高频输出取决于当前音频采样率；超过可用 Nyquist 频率的音调会被静音
- **Volume (dB)** - 调整输出电平（-96 dB 到 0 dB）
  - 从低音量开始，再慢慢提高
  - 较高值可能很响或令人疲劳
- **Panning (L/R)** - 控制立体声位置
  - Center：左右相同
  - Left/Right：检查通道路由和平衡
- **Waveform Type** - 选择信号类型
  - Sine：干净参考音
  - Square：富含奇次谐波
  - Triangle：较柔和的谐波内容
  - Sawtooth：完整谐波系列
  - Impulse：按照当前音频采样率，在每个 Interval 输出一个满幅采样；Frequency 不影响它
  - White Noise：每 Hz 能量相同；Frequency 不影响它
  - Pink Noise：每倍频程能量相同；Frequency 不影响它
- **Mode** - 控制信号生成模式
  - Continuous：连续信号
  - Pulsed：带可控时序的间歇信号
  - Impulse 始终使用 Pulsed；Continuous 会被禁用
- **Interval (ms)** - Pulsed 模式中脉冲之间的时间（100-2000 ms，步进 10 ms）
  - 较短间隔：快速脉冲序列
  - 较长间隔：相隔更远的脉冲
  - Mode 为 Pulsed 时有效，包括 Impulse
- **Width (ms)** - Pulsed 模式中的脉冲淡入/淡出时间（2-100 ms，最大为 Interval 的一半，步进 1 ms）
  - 控制每个脉冲的淡入/淡出时间
  - 生成的脉冲约为 Width 的两倍时长，没有稳定保持段
  - 较短 Width：脉冲边缘更锐利
  - 较长 Width：脉冲过渡更平滑
  - 仅 Mode 为 Pulsed 时有效；Impulse 的脉冲固定为一个采样，因此此项会被禁用

### 使用示例

1. 扬声器或耳机检查
   - 检查基本频率再现
     * 使用 sine 从低频扫到高频
     * 记录哪些位置听不见或出现失真
   - 聆听异响、嗡声或刺耳共振
     * 先使用较低 Volume
     * 一次只测试一个频率范围
   - 比较左右输出
     * 将声像完全移到左侧和右侧
     * 确认声音来自预期的扬声器或耳机单元

2. 通道与电平平衡
   - 检查立体声位置
     * 使用居中的 sine 或 pink noise
     * 确认声音位于中央
   - 比较左右音量
     * 以相同 Volume 分别移到左右两侧
     * 如果一侧明显更响，请调整播放系统
   - 检查插件链
     * 将 Oscillator 放在其他效果前或后，听效果链如何处理简单信号

3. 房间或桌面共振快速检查
   - 找出明显低频堆积或异响
     * 以安全音量播放低频 sine
     * 在聆听位置附近移动，记录强峰或凹陷
   - 检查容易振动的物品
     * 缓慢扫过低频和低中频
     * 如果出现强烈异响，立即降低 Volume

4. 噪声平衡检查
   - 使用 pink noise 作为宽频、稳定参考
     * 聆听明显的左右或音色不平衡
     * 保持舒适音量，避免长时间大音量噪声播放
   - 只有需要更亮的宽频信号时才使用 white noise

5. 脉冲信号检查
   - 使用 pulsed 模式让短促声音更容易辨认
     * 较长 Interval 让每个脉冲更容易分开听
     * 较短 Width 产生更尖锐的起止
     * 比较不同音量下的表现

6. 脉冲响应与时序检查
   - 选择 Impulse，按设定的 Interval 生成单采样瞬态信号
     * 使用更长的 Interval，以便分离反射声或效果尾音
     * 录制输出，以分析系统或插件链的脉冲响应
     * 脉冲峰值尖锐且包含宽频成分，请从较低 Volume 开始

请记住：Oscillator 是测试信号发生器。请从较低 Volume 开始逐步提高，并避免可能损伤设备或造成听觉疲劳的高音量/高频音调。

## SoundFont Note Player

<a id="sfz-note-player"></a>

SoundFont Note Player 检测输入音频中的音符，并用导入的 SF2/SF3/SFZ 乐器播放。您可以用钢琴 SFZ 跟随歌曲的音符，或将另一种乐器叠加到原始录音上。复音的音符估算是用于聆听和叠加的工具，而不是精确的扒谱；在声音密集的混音中，可能漏掉音符或触发多余的音符。

### 音质增强指南

- **导入并加载乐器**：打开 **SoundFont Library…**，用 **导入文件…** 导入 `.sf2` / `.sf3` 文件，点击 **加载**，再通过 **Preset** 选择音色。对于 SFZ，用 **导入文件夹…** 将定义文件及其采样一起添加（ARIA 音色库则选择包含 `.bank.xml`、`Programs` 和 `Samples` 的完整文件夹）。桌面版直接读取原始文件，网页版将导入的乐器保存在您的设备上。用 **导入文件…** 添加 SFZ 时，请包含所有必需的采样及其他文件。正在使用的乐器无法删除。
- **试听与混合**：先设为 **Dry: 0%**、**Wet: 100%**，单独聆听 SFZ 乐器，再提高 **Dry** 把原曲混回来。调整 **Timing**（−100 到 +100 ms），让 SFZ 音符的起音与原始录音对齐（0 ms 时，原声会延迟以配合音符检测：Classic 约 90 ms，Event 约 230 ms）。
- **限定音域和声部**：提高 **Threshold** 只触发置信度高的音符，收窄 **Lowest Note** 和 **Highest Note**，或只启用 **Lowest**（低音线）或 **Highest**（最上方的旋律），以跟随单一的音乐线条。Note Spectrogram 中显示了彩色线条，并不保证会发声，因为 **Threshold** 和音域设置仍然适用。
- **调整音色和八度**：用 **Octave**（−2 到 +2）在低或高一个八度处叠加线条；用 **Sample Shift**（−6 到 +6 个半音）选用相邻音符的采样，并把音高修正回检测到的音符，得到更暗或更亮的音色。

### 参数

- **SoundFont** - 打开 **SoundFont Library…**，可导入、搜索、排序、加载或删除乐器（**Clear** 卸载当前乐器，但不会从音色库中删除）。
- **Preset**：选择 SF2/SF3 音色库中用于演奏检测音符的音色。**Default** 使用第一个可播放的预设。SFZ 乐器不显示此控件。
- **Detection**：
  - **Classic (Low Latency)**（默认）：延迟较低的检测方式（对齐延迟约 90 ms），使用 **Threshold** 和 **Retrigger Drop**。
  - **Event (+140 ms)**：使用与 Note Spectrogram 相同的起音/事件检测器（对齐延迟约 230 ms，CPU 占用较高；**Threshold** 和 **Retrigger Drop** 不可用）。如果效果链中更靠前、已启用的 Note Spectrogram 以相同音域分析相同的输入，且两者之间的音频未被改变，并且 Note Spectrogram 已启用 **Onsets**、**Instrument** 颜色或 **Highlight** 中的任一项，就会共享其分析以降低负载。否则，SoundFont Note Player 会自行分析。
- **Color** - **Normal**（主题的图形颜色）或 **Note Colors**（与 Note Spectrogram 相同的音名配色）。
- **Threshold**（0.01 到 1；默认 0.75）- Classic 模式下检测置信度的阈值。
- **Retrigger Drop (dB)**（1 到 96 dB；默认 40 dB）- Classic 模式下，B5 以上的持续音再次发声前所需的电平下降幅度。电平下降后，还需要再次上升至少 6 dB。调高可减少持续音中多余的重复发声，调低则更容易跟上同一音符的连续敲击。B5 及以下的音符在检测到起音时直接触发新音符。
- **Note Hold (ms)**（0 到 100 ms；默认 50 ms）- 在释放音符前连接检测中的短暂中断。
- **Velocity 1 Level / Velocity 127 Level (dB)**（-96 到 0 dB / -60 到 +24 dB；默认 -60 dB / -10 dB）- 映射到 MIDI 力度 1–127 的输入电平范围。调低后，相同的输入会产生更大的力度。
- **Lowest Note / Highest Note**（A0 到 C8；默认 E1 到 G6）- 音高检测范围。
- **Highest / Middle / Lowest** - 选择同时检测到的音符中哪些发声（最上方的线条、内声部或低音线；默认全部开启）。
- **Octave**（-2 到 +2；默认 0）- 以整八度移调新触发的 SFZ 音符。
- **Sample Shift**（-6 到 +6 个半音；默认 0）- 改变所选的采样区域，同时反向修正音高，以保持目标音符的音高。正值以较慢的速度播放更高音符的采样（设为 +1 时，检测到的 C4 会以 C4 的音高播放 C#4 的采样）；负值以较快的速度播放更低音符的采样。
- **Max Voices**（1 到 128；默认 32）- 同时播放的采样声部数上限（包括释音尾音）。数值越高，保留的重叠音符越多，但处理负载也越大。
- **Dry (%)** / **Wet (%)**（0 到 100%；默认 20% / 100%）- 分别设置经过延迟对齐的原始音频和 SFZ 乐器的电平。
- **Timing (ms)**（-100 到 +100 ms；默认 0 ms）- 微调原始音频与 SFZ 乐器之间的时间对齐。负值会进一步延迟原始音频，正值会延迟乐器。
- **Output Gain (dB)**（-60 到 +12 dB；默认 0 dB）- 最终输出电平的微调。

### Instrument Details

展开主要设置下方的 **Instrument Details**，可查看 SFZ 音源提供的琴键、MIDI 控制器（**CC**）、输出、分组、音层和键位切换标签。这些标签用于说明音源内部的映射，并不是额外的控制项。有标签的切换键生效时，**Keyswitch** 会显示各通道当前选中的演奏法。音源若指定了图片，也会在这里显示；指定多张图片时，以最后一张为准。

### 发声显示与注意事项

- **交互式键盘与力度条**：键盘覆盖 **Lowest Note** 到 **Highest Note** 的范围，正在演奏的音符（包括释放尾音）会点亮。点亮的琴键跟随 **Octave**；**Sample Shift** 只改变音色，不会移动点亮位置。每根力度条从发声时的力度（1–127）开始，随时间下降，音符结束后也会继续下降；切换 **Color** 只改变颜色，不会让下降中的力度条重新开始。**Voices / Max Voices** 统计的是采样发声数，包括处于释放阶段的发声。
- **试听**：在键盘或力度区域上点击或拖动，可直接演奏已加载的 SFZ 乐器。键盘以力度 100 发声，力度区域按点按位置的高度决定力度。试听按显示的音高发声，忽略 **Octave**，但 **Sample Shift** 仍会生效。
- **内存上限**：乐器及采样缓存的默认预算为 **256 MiB**，可在 **设置 > 配置... > 常规** 的 **SoundFont 容量上限** 中提高到 **1024 MiB**。按需读取的源文件可以更大。如果因此无法加载，请提高上限或选择较小的乐器。
- **支持的 SFZ 功能**: SoundFont Note Player 根据检测到的起音发声。依赖控制器和键位切换的音层使用音源初始设置，不跟随 MIDI 曲目的事件。要播放 MIDI 曲目并响应演奏中的控制变化，请使用 SoundFont Player。使用不支持的设置或缺少必需采样的音源无法加载。请检查文件或选择其他音源。
- **共享与备份**：预设、共享链接和用户数据备份只保存乐器的引用，不保存其音频采样；请保留原始 SFZ 文件夹，以便在不同设备上使用。

## SoundFont Player

使用 SF2/SF3 SoundFont 音色库或 SFZ 乐器播放 MIDI 乐曲，再通过后面的效果器调整声音。输入音频保持不变，乐器声音会在此处叠加到处理链中。

### 开始使用

打开 `.mid` 文件，添加 SoundFont Player，然后打开 **SoundFont Library…**。导入 `.sf2` / `.sf3` 文件，或包含配套采样文件的 `.sfz` 乐器，再选择 **加载**。桌面版直接读取原始文件；网页版将导入的文件保存在当前设备上。建议将 **Instrument Level** 从 0 dB 开始调整；如果混合后的音量过大，请降低该值。

SF3（.sf3）使用压缩采样，导入和选择音色的方法与 SF2 相同。 播放 SF3 需要浏览器支持 Vorbis 解码。如果不支持，请选择 SF2 SoundFont，或使用兼容的浏览器。

**SoundFont Library…** 可用于导入、搜索、加载和删除音源。**Clear** 只卸载当前音源，不会将其从音源库删除。正在使用的音源无法删除。曲目播放中更换音源时，MIDI 时间线会在新音源准备期间继续前进。准备完成后，新音源会使用当前控制器设置，从之后的 MIDI 事件开始发声，不会重放之前的音符。

### MIDI Mixer

**MIDI Mixer** 标签页为 16 个 MIDI 通道各显示一行。SF2/SF3 音色库可以为每个通道提供不同的音色；Bank Select 和 Program Change 消息选择音色，默认由第 10 通道使用鼓组音色库。GS/XG 鼓声部消息也可以将其他通道设为打击乐通道，或将其恢复为旋律通道。Program Change 会选择已加载 SoundFont 中可用的鼓组。SFZ 音源使用自身的映射。

收到 Program Change 消息前，如果音色库中有对应音色，旋律通道使用音色库 0 的程序 1，第 10 通道使用标准鼓组。如果 SF2/SF3 中没有指定的音色，旋律通道会依次尝试音色库 0 中的相同程序和程序 1；打击乐通道则尝试标准鼓组。**Patch** 显示实际使用的音色。如果这些音色都不存在，该通道就不会发声。

- **Patch**：按名称从已加载的 SF2/SF3 音色库中选择该通道的音色。之后开始的音符使用新音色，已经发声的音符保留原来的音色。
- **Notes**：各通道的琴键在收到 MIDI Note On 时点亮，收到 Note Off 时熄灭。即使延音踏板或释音尾声让声音继续，Note Off 后琴键也不再点亮。**Voices** 显示实际仍在播放的采样声部数（包括余音）以及 **Max Voices** 上限。一个音符可能使用多个采样声部。
- **Vol.**（CC7，0–127）：调整通道音量。**EXP**（表情，CC11，0–127）进一步控制音量。数值越大，声音越响；任意一项设为 0，该通道便会静音。
- **Pan**（CC10，0–127）：将声音从左向右移动，64 为中央。
- **Rev.**（CC91）和 **Cho.**（CC93）：在 0–127 范围内调整发送到相应效果的量。数值越大，发送量越多；实际听到的效果取决于音源对效果的支持及其设置。
- **Level** 显示各通道经过 Vol.、EXP、Pan 和 Mute/Solo 控制后的实际音频电平。彩色条随信号变化，细线会短暂保持最近的峰值。共用混响和合唱效果的返回信号不计入其中。
- **Mute**（**M**）：将该通道静音。开启 **Solo**（**S**）后，只能听到开启 Solo 的通道。可用它们比较曲目中的各个声部。

上下拖动旋钮，或选中旋钮后用方向键调整。混音器操作是临时的，不会保存在预设、分享链接或备份中。Patch 和控制器修改作用于收到的 MIDI 状态，因此之后同类的 MIDI 消息可以覆盖这些修改。包括 Mute 和 Solo 在内的所有混音器操作，都会在下一首曲目或收到 GM、GS、XG 重置消息时初始化。

收到的 MIDI 消息改变 Patch 或旋钮的显示值时，相应控件会短暂高亮。

### Settings

**Settings** 标签页包含会保存的播放设置：

- **MIDI Channel**：默认为 **All**，播放所有通道；选择 **1–16** 时只播放对应通道。
- **Instrument Level**：调整生成声音的音量，范围为 -60 至 +12 dB，默认 0 dB，不影响输入音频。
- **Max Voices**：限制同时发声的采样声部数，包括释放阶段的余音，范围为 1–1024，默认 64。提高此值可保留更多重叠音符，但会增加处理负担。
- **Interpolation**：选择乐器采样改变音高时的重采样方式。**FIR (64 taps)** 使用 SF2/SF3 的常规滤波器，或遵循 SFZ 乐器自身的质量设置。默认的 **FIR (32 taps)** 可降低 SF2/SF3 的处理负担：无需降采样时使用 32 个滤波抽头；播放需要降采样时，FIR 滤波器会加长，以减轻混叠。**Cubic (4 points)** 使用较轻量的插值，但没有抑制混叠的低通滤波器；大幅升高音高或播放高频泛音丰富的采样时，可能出现杂散频率。选择 FIR 或 Cubic 会覆盖 SFZ 乐器自身的质量设置。

所选音源及这些设置会照常保存。 播放器的音量和静音也会作用于 MIDI 乐器。预设、分享链接和备份只保存乐器引用，不包含采样。请保留原始乐器文件，以便在其他设备上使用。

**Color** 仅改变键盘显示的颜色。**Normal** 使用图表的通用颜色，**Note Colors** 使用与 Note Spectrogram 相同的音高配色，**Channel Colors** 为每个 MIDI 通道使用不同的颜色。颜色选择不会保存到预设中。

### Instrument Details

已加载音源的概要会显示可获取的采样数、音色数、源文件大小和播放内存用量。大型音源会按需读取播放所需的采样数据，而不将整个源文件加载到内存中，因此源文件大小可能远大于播放内存用量。

状态会显示文件读取、音源或采样缓存准备、就绪或加载错误。已知工作总量时，进度会显示已完成量和总量；未知时，指示器不显示确定的百分比。若加载失败，请确认原始文件可用，或选择其他音源。预加载受限时仍可演奏，但部分音符可能会延迟发声。

在 **Settings** 中展开 **Instrument Details**，可查看 SFZ 音源提供的琴键、MIDI 控制器（**CC**）、输出、分组、音层和键位切换标签。这些标签用于说明音源内部的映射，并不是额外的控制项。有标签的切换键生效时，**Keyswitch** 会显示各通道当前选中的演奏法。音源若指定了图片，也会在这里显示；指定多张图片时，以最后一张为准。

### 实时 MIDI 输入

桌面应用和 Web/PWA 播放器支持实时 MIDI 演奏。Android 应用不支持此功能，但仍可使用控制器映射。

要通过 MIDI 键盘或虚拟 MIDI 端口演奏，请先关闭 Music Player。在**音频设置**中点击**刷新 MIDI 设备**，按提示允许 MIDI 访问，然后选择 **MIDI 输入设备**。请在 SoundFont Player 中加载音色。只要 Music Player 处于打开状态，即使暂停播放也会优先使用它；选择**无**可停止实时 MIDI 输入。未加载音色时，MIDI 输入仍会继续，但没有声音。加载音色后，后续 MIDI 事件才会发声，之前的音符不会重新播放。

### SFZ 音源

SFZ 音源可以设置每个音符的音量、音高和音色随时间的变化，组合滤波器与内置效果，并控制采样循环和松键时的声音。与节拍同步的发声和效果会跟随 MIDI 歌曲的速度及播放速度。这些设置来自音源文件。要自行调整整体听感，可在 SoundFont Player 后添加效果器。

SFZ 音源可通过 `amp_veltrack_random`，在每个新音符开始时随机改变力度与音量的关系。默认值 0 不增加随机变化。它改变的是演奏力度对音量的影响方式，而不是 MIDI 力度值本身。

大型音源会在设定的内存预算内按需读取采样数据。导入时，请将定义文件与所需采样一起提供；内嵌采样以及仅供音源内置效果使用的文件也会一并导入。如果采样内容校验失败，请恢复原始文件或重新导入音源。使用独立输出的音源需要具有足够通道数的输出配置。

SFZ 文件可通过 `load_mode` 选择采样存储格式：0（默认）使用 32-bit 浮点，1 使用 16-bit PCM 以减少采样内存。精度高于 16-bit 的源音频在 16-bit 模式下会损失精度。在 EffeTune 中，`load_start` 和 `load_end` 表示要保留在内存中的原始采样的首尾帧位置，包含最后一帧。指定范围时，省略起点表示从 0 开始，省略终点表示到采样末尾。范围外的数据仍会按需读取，不会截短播放或改变循环位置。如果两端都省略，则继续使用自动流式读取。

兼容情况因音源而异，某些厂商特有的行为暂不支持。支持范围及限制请参阅 [SFZ 兼容性参考](../../../../specifications/sfz/README.md)。SoundFont Note Player 采用相同的音源准备方式，但从音频中检测到的音符不会提供 MIDI 歌曲的控制器变化或速度信息。
