# 其他音频工具

这些专用工具和发生器用于补充主要效果类别。它们适合在聆听前或聆听过程中检查扬声器、耳机、通道平衡和播放行为。

## 插件列表

- [Oscillator](#oscillator) - 用于检查扬声器/耳机的测试音和噪声发生器
- [SFZ Note Player](#sfz-note-player) - 用导入的 SFZ 乐器播放检测到的音符

## Oscillator

用于检查聆听系统的测试音和噪声发生器。请以低音量使用，用来确认扬声器/耳机输出、左右位置、电平平衡、异响、共振或简单的频率响应问题。

生成的测试音或噪声会混入当前音频路径，而不是替代输入音频。启用前请先降低 Volume，尤其是在音乐已经播放时。

### 功能
- 多种波形类型：
  - Sine：简单音调检查
  - Square：丰富奇次谐波
  - Triangle：较柔和的谐波
  - Sawtooth：明亮音色
  - Impulse：用于检查脉冲响应和时序的周期性单采样脉冲
  - White Noise：宽频扬声器/耳机检查
  - Pink Noise：更平滑、更自然的噪声平衡
- Pulsed 模式用于间歇测试音或噪声脉冲

### 参数
- **Frequency (Hz)** - 控制生成音调的音高（20 Hz 到 96 kHz）
  - 低频：深沉低音测试
  - 中频：音乐常用范围
  - 高频：请谨慎使用，并保持安全聆听音量
  - 仅适用于 Sine、Square、Triangle 和 Sawtooth；Impulse、White Noise 和 Pink Noise 下禁用
  - 可用的高频输出取决于当前音频采样率；超过可用 Nyquist 频率的音调会被静音
- **Volume (dB)** - 调整输出电平（-96 dB 到 0 dB）
  - 从低音量开始，再慢慢提高
  - 较高值可能很响或令人疲劳
- **Panning (L/R)** - 控制立体声位置
  - Center：左右相同
  - Left/Right：检查通道路由和平衡
- **Waveform Type** - 选择信号类型
  - Sine：干净参考音
  - Square：富含奇次谐波
  - Triangle：较柔和的谐波内容
  - Sawtooth：完整谐波系列
  - Impulse：按照当前音频采样率，在每个 Interval 输出一个满幅采样；Frequency 不影响它
  - White Noise：每 Hz 能量相同；Frequency 不影响它
  - Pink Noise：每倍频程能量相同；Frequency 不影响它
- **Mode** - 控制信号生成模式
  - Continuous：连续信号
  - Pulsed：带可控时序的间歇信号
  - Impulse 始终使用 Pulsed；Continuous 会被禁用
- **Interval (ms)** - Pulsed 模式中脉冲之间的时间（100-2000 ms，步进 10 ms）
  - 较短间隔：快速脉冲序列
  - 较长间隔：相隔更远的脉冲
  - Mode 为 Pulsed 时有效，包括 Impulse
- **Width (ms)** - Pulsed 模式中的脉冲淡入/淡出时间（2-100 ms，最大为 Interval 的一半，步进 1 ms）
  - 控制每个脉冲的淡入/淡出时间
  - 生成的脉冲约为 Width 的两倍时长，没有稳定保持段
  - 较短 Width：脉冲边缘更锐利
  - 较长 Width：脉冲过渡更平滑
  - 仅 Mode 为 Pulsed 时有效；Impulse 的脉冲固定为一个采样，因此此项会被禁用

### 使用示例

1. 扬声器或耳机检查
   - 检查基本频率再现
     * 使用 sine 从低频扫到高频
     * 记录哪些位置听不见或出现失真
   - 聆听异响、嗡声或刺耳共振
     * 先使用较低 Volume
     * 一次只测试一个频率范围
   - 比较左右输出
     * 将声像完全移到左侧和右侧
     * 确认声音来自预期的扬声器或耳机单元

2. 通道与电平平衡
   - 检查立体声位置
     * 使用居中的 sine 或 pink noise
     * 确认声音位于中央
   - 比较左右音量
     * 以相同 Volume 分别移到左右两侧
     * 如果一侧明显更响，请调整播放系统
   - 检查插件链
     * 将 Oscillator 放在其他效果前或后，听效果链如何处理简单信号

3. 房间或桌面共振快速检查
   - 找出明显低频堆积或异响
     * 以安全音量播放低频 sine
     * 在聆听位置附近移动，记录强峰或凹陷
   - 检查容易振动的物品
     * 缓慢扫过低频和低中频
     * 如果出现强烈异响，立即降低 Volume

4. 噪声平衡检查
   - 使用 pink noise 作为宽频、稳定参考
     * 聆听明显的左右或音色不平衡
     * 保持舒适音量，避免长时间大音量噪声播放
   - 只有需要更亮的宽频信号时才使用 white noise

5. 脉冲信号检查
   - 使用 pulsed 模式让短促声音更容易辨认
     * 较长 Interval 让每个脉冲更容易分开听
     * 较短 Width 产生更尖锐的起止
     * 比较不同音量下的表现

6. 脉冲响应与时序检查
   - 选择 Impulse，按设定的 Interval 生成单采样瞬态信号
     * 使用更长的 Interval，以便分离反射声或效果尾音
     * 录制输出，以分析系统或插件链的脉冲响应
     * 脉冲峰值尖锐且包含宽频成分，请从较低 Volume 开始

请记住：Oscillator 是测试信号发生器。请从较低 Volume 开始逐步提高，并避免可能损伤设备或造成听觉疲劳的高音量/高频音调。

## SFZ Note Player

SFZ Note Player 检测输入音频中的音符，并用所选的 SFZ 乐器播放。您可以用钢琴 SFZ 跟随歌曲的音符，或将另一种乐器叠加到原声上。复音估计可能漏检或误检，尤其是在声音密集的音乐中。

改变音高或转换采样率时，播放会自动抑制混叠噪声。

B5 及以下的音符在检测到清晰的新起音时会重新发声，同一音符的反复弹奏也是如此。B5 以上的音符则由 **Retrigger Drop** 控制持续检测期间的再次发声条件。**Note Hold** 可连接检测中的短暂中断，但 B5 及以下的音符即使仍在保持时间内，检测到清晰的新起音也会作为新的音符播放。

### 声音调整指南

点击 **SFZ Library…** 打开音色列表。使用 **导入文件夹…** 添加包含 SFZ 文件、采样和包含文件的文件夹，然后点击所需音色旁的 **加载**。**导入文件…** 可添加所选文件；网页版需要同时选择采样等必要文件。Electron 版保留对原始文件的引用，每次加载音色时直接读取。网页版将音色保存在此设备上。

每个音色都会显示容量、文件数和区域数。容量包含采样：Electron 版显示引用文件的总大小，网页版显示保存的音色大小。区域规定不同音高和力度范围使用的声音。可以按文件名搜索，并按 **文件名** 或 **最近导入** 排序。**全选**选择当前显示的所有项目；**取消全选**清除所有选择。 勾选多个项目后使用 **删除所选项** 可批量删除，**删除** 可删除单个项目。效果链正在使用的音色无法删除。Electron 版保留原始文件；网页版删除已保存的音色。效果器中的 **Clear** 仅取消选择，音色仍保留在音色库中。

添加文件时，进度会显示在音色库内。对于 Plogue Free Sounds 等 ARIA 音色库，请选择包含 `.bank.xml`、`Programs` 和 `Samples` 的完整音色文件夹。

本音色库的 Virtual Analog 等程序使用的基本波形通过生成的采样循环播放。不支持的音色设置会被忽略。无效的起音或衰减时间会调整为可播放的值；只有在您主动选择或导入乐器时，才会提示相关问题。

先将 **Dry** 设为 0%、**Wet** 设为 100%，单独聆听乐器，再提高 **Dry** 加入原声。将 **Octave** 设为 -1 可叠加更低的声音，设为 +1 可叠加更高的声音。提高 **Threshold** 可减少发声的音符，只保留检测更确定的音符。用 **Lowest Note** 和 **Highest Note** 限定想听的音域。如果乐器始终过弱或过强，调整 **Velocity 1 Level** 和 **Velocity 127 Level**，最后用 **Output Gain** 平衡音量。

**Sample Shift** 可在保持音高不变的同时改变音色。例如设为 +1 时，检测到 C4 后会选择分配给 C#4 的采样，降低播放速度，以 C4 的音高播放。

只启用 **Lowest** 可跟随低音旋律，只启用 **Highest** 可跟随高音旋律。

对于 B5 以上的音符，如果持续音意外地反复发声，请将 **Retrigger Drop** 调高至默认值 40 dB 以上。设为 96 dB 可大幅减少音量变化引起的重复触发。如果想跟随同一音符的反复弹奏，请降低该值。B5 及以下的音符则根据检测到的起音重新发声。

调高 **Note Hold** 可延长音符，并连接检测中的短暂中断。设为 100 ms 时，会额外保持 100 ms 后再发送音符关闭指令。但对于 B5 及以下的音符，即使仍在保持时间内，清晰的新起音也会触发新的音符。

**Note Spectrogram** 中显示了音符，并不一定会发声；**Threshold** 和 **Lowest Note / Highest Note** 的设置也会影响发声。如果很低或很高的音不发声，请检查音域设置，并尝试降低 **Threshold**。同时确认应用 **Octave** 和 **Sample Shift** 后的音符在 SFZ 音源支持的音域内。

### 发声显示

键盘的显示范围从 **Lowest Note** 到 **Highest Note**。键盘会点亮 SFZ 乐器正在播放的音符，处于释音阶段的音符也会保持点亮。显示会反映 **Octave** 的音高偏移；**Sample Shift** 只改变音色，不改变显示的琴键。每个琴键上方的柱形条从与发音力度（velocity，1–127）成比例的高度开始，随后随时间逐渐降低，音符结束后仍会继续衰减，直至消失。**Voices** 显示当前使用的采样声部数 / **Max Voices**，包括释音中的声部。叠加多个采样层的乐器可能为一个音符使用多个声部。切换 **Color** 会改变正在发声的琴键和力度柱的颜色，同时保持力度柱的衰减进度。

点击或在键盘、力度图上拖动，即可试听所选的 SFZ 乐器。键盘以力度100发声；力度图则根据进入某个音符区域时的高度确定力度（1～127）。在同一音符区域内移动时，会保持最初的力度持续发声。移到另一个音符区域时，会停止前一个音符并播放新音符；松开手指或鼠标按钮便会停止试听。试听直接播放显示的音高，不受 **Octave** 或音符检测设置影响；**Sample Shift** 的音色变化仍会应用于试听。

### 参数

- **SFZ**：通过 **SFZ Library…** 选择和管理音色。**Clear** 仅取消选择，不会删除音色。仅在手动选择音色后的首次加载时通过对话框提示问题，自动重新加载时不显示提示。
- **Color**：**Normal**（默认）使用主题的图表颜色。**Note Colors** 使用与 Note Spectrogram 相同的配色，每个音名对应一种颜色，不同八度中相同音名的颜色一致。
- **Threshold**：检测置信度的阈值（0.01–1，默认 0.75）。提高可减少不需要的音符，但可能漏掉较弱或不清晰的音符。B5 及以下的音符如果有清晰的起音，即使置信度略低于此值，也可能发声。
- **Retrigger Drop (dB)**：对于 B5 以上的音符，再次发声前输入电平必须从峰值下降的幅度（1–96 dB，默认 40 dB）。下降达到设定值后，还需回升至少 6 dB 才会再次发声。调高可减少持续音的重复触发，调低则更容易跟随同一音符的反复弹奏。此设置不影响 B5 及以下音符的重复触发；这些音符根据检测到的起音重新发声。
- **Note Hold (ms)**：检测结束后，在发送音符关闭指令前额外保持音符的时间（0–100 ms，默认 50 ms）。如果同一音符在这段时间内重新出现，会继续播放而不重新触发；但 B5 及以下的音符如果有清晰的新起音，则会触发新的音符。乐器的音量包络和采样长度仍然适用。
- **Velocity 1 Level / Velocity 127 Level (dB)**：分别对应最弱和最强演奏力度的输入音符电平（默认 -60 dB / -10 dB）。降低数值会让相同输入产生更大的力度。两者的间隔决定输入电平在力度范围内的分布。
- **Lowest Note / Highest Note**：要检测的最低和最高输入音符（A0–C8，MIDI 21–108；默认 E1 和 G6）。以音名显示，范围外的音符会被忽略。
- **Highest / Middle / Lowest**：在应用 Octave 之前，选择低音旋律、中间音和高音旋律（默认全部启用）。Middle 只选择当前检测到的最低音与最高音之间的音，不包括两端。低音和高音旋律会跟随音高随时间的变化，减少突然切换；若只检测到一个音，它同时属于两者。不再选中的音会自然衰减，关闭全部选项则停止发出新音。
- **Octave**：以一个八度为步长，将新发出的 SFZ 音符移动 -2 至 +2 个八度（默认 0）。负值让音符更低，正值让音符更高。输入的检测范围和已经发出的声音保持不变。
- **Sample Shift**：在保持 Octave 所设音高的同时，选择分配给相差 -6 至 +6 个半音的音符的采样（每步一个半音，默认 0）。正值选择更高音符的采样并降低播放速度；负值选择更低音符的采样并提高播放速度。更改仅对新发出的音符生效，已经发声的音符保留原来的采样和播放速度。
- **Max Voices**：限制同时播放的采样声部数。提高可保留更多重叠音符和释放尾音，但增加处理负载；降低会更早替换旧声部。
- **Dry (%)**：原声音量（0–100%，默认 20%）。0% 为静音，100% 保持原始音量。
- **Wet (%)**：SFZ 乐器音量（0–100%，默认 100%）。0% 为静音，100% 保持乐器本来的音量。Dry 和 Wet 可独立调整。
- **Timing (ms)**：调整原声与 SFZ 乐器之间的发声时间差（-100 至 +100 ms，默认 0）。负值进一步延迟原声，正值延迟乐器。可边听边调，让声音的起始时刻更接近。
- **Output Gain (dB)**：调整混合输出的最终电平。

**Timing** 为 0 ms 时，原声会延迟约 **90 ms**，以配合音符检测的计算与校正。分析周期和乐器的起音仍可能带来细小的发声时间差。如果前面的有效 **Note Spectrogram** 具有相同音域、输入总线和通道选择，且两者之间的音频未被改变，就可共享分析，降低处理负载。

加载支持常见的 SFZ 选择条件、音高、音量、声像、循环和振幅包络设置。释放时的衰减至少持续 **0.2 秒**，SFZ 中指定的更长时间会保留。如果采样提前结束，声音也会随之停止。控制器范围条件按初始值判断，SFZ 中的 `set_ccN` 设置优先。例如，初始状态为松开踏板的钢琴会使用对应采样，不叠加踩下踏板时的声音层。乐器指定默认键位切换奏法时，会使用该奏法。需要音符释放、控制器事件、演奏中的键位切换或其他不支持的演奏条件的声音层会被省略。无效区域会被跳过，有效区域继续加载。其他不支持的音色设置会被忽略。

默认容量上限为 **256 MiB**。可在 **设置 → 常规** 的 **SFZ 容量上限** 中提高至 **1024 MiB（1 GiB）**。此上限同时适用于乐器文件和展开后的播放采样，从下次选择、导入或加载起生效。提高上限会增加内存使用量。如果完整乐器超出上限，会尝试用覆盖其可演奏音域的代表采样加载。力度仍会改变音量，但力度分层和轮替采样带来的音色变化会被简化。如果这些采样仍无法容纳，请选择更小的乐器或提高上限。在 Web 版中，提高上限后需重新导入原始文件夹，才能恢复省略的采样。其他使用采样的效果也共享处理内存。

预设和共享处理链只包含乐器引用，不含声音文件。在其他设备上，请在 Electron 版中重新选择本地乐器文件夹，或在 Web 版中导入其文件夹。SFZ 声音文件也不包含在用户数据备份中，请保留原始 SFZ 文件夹。
