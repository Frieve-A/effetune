# 共鸣器插件

这些插件为音乐加入共鸣特性，既可模拟物体和扬声器的共鸣，也可从音频中学习并生成不断变化的共鸣声。

## 插件列表

- [Adaptive Prediction](#adaptive-prediction) - 学习音频预测，用于提取残差或生成不断变化的共鸣声
- [Horn Resonator](#horn-resonator) - 模拟号角扬声器系统的共鸣
- [Horn Resonator Plus](#horn-resonator-plus) - 更平滑的号角扬声器共鸣，带来自然的聆听色彩
- [Modal Resonator](#modal-resonator) - 最多 5 个共鸣器的频率共鸣效果

## Adaptive Prediction

Adaptive Prediction（自适应预测）从过去的音频中学习如何预测输入波形。它可以减少容易预测的成分，让你单独听取预测声，或将预测声反馈给自身，生成不断发展的共鸣声。左右声道独立学习。

**Residual** 是原声减去预测声。随着学习进行，重复的音调可能在残差中变小，使变化和难以预测的细节更加突出。**Autonomy** 大于 0 时，预测声也会受到自身生成声音的影响。设为 1 时，生成路径与外部输入断开；只要没有冻结学习，学习仍使用外部输入。

### 聆听指南与系统预设

在效果标题栏中打开**效果预设**，选择起点。切换预设会保留运行中的效果已经学到的内容。

| 预设 | Gap | Autonomy | Original / Residual / Prediction | 起始用途 |
| --- | --- | --- | --- | --- |
| **Surprise**（默认） | 1 ms | 0 | 0 / 1 / 0 | 减少容易预测的音调，突出不断变化的细节。 |
| **Prediction** | 5 ms | 0 | 0 / 0 / 1 | 用学到的预测声替换原声。先播放几秒可听见的输入，让效果学习。 |
| **Resonator** | 10 ms | 0.98 | 0.6 / 0 / 0.6 | 将原声与受音乐影响、不断变化的共鸣声混合。 |
| **Hold** | 10 ms | 1 | 0 / 0 / 1 | 冻结学习，用已经学到的模型自主发声。 |

先用持续音或重复的音乐片段比较 **Surprise** 和 **Prediction**。要尝试自主发声，先让 Prediction 学习，再选择 **Hold** 预设或勾选 Hold。Hold 固定的是预测规则；音高、音色和音量仍可能变化或衰减。它不是保持一个音符，也不是循环播放录音。未经学习或刚 Reset 的效果无法从静音开始自主发声。

### 参数

- **Gap (ms)** — 从预测所用的波形信息中排除最近的 0–500 ms（初始值 1 ms）。数值越大，预测依据越久远，音色或准确度可能发生变化。即使设为 0，也使用之前的采样。它不是输出延迟，也不是录音窗口的长度。更改时保留已学模型，并重新适应新的预测距离。
- **Learn** — 设置跟随输入的学习速度，范围 0–0.1（初始值 0.02）。越大适应越快，越小变化越慢。设为 0 会停止根据误差进行学习，但有限的 Weight Decay 仍可使系数衰减。
- **Weight Decay (s)** — 设置学习过程中系数衰减的时间，范围 0.5–60 秒。时间越短，过去学习的影响减弱越快；越长则保留越久。它不是音频历史的长度。
- **Infinity** — 禁用 Weight Decay（默认勾选）。取消勾选后使用 Weight Decay 的时间。
- **Autonomy** — 在外部输入预测和自反馈生成之间混合，范围 0–1（初始值 0）。提高时，生成声对自身的影响更强；设为 1 后，生成路径只接收自身反馈。输出混合音量不会改变这条反馈。
- **Original / Residual / Prediction** — 分别设置三种成分的有符号增益，范围 −2 至 +2，初始值为 0 / 1 / 0。0 为静音，正值相加，负值反转极性；绝对值大于 1 会提高音量。混合不会自动归一化。由于 Residual = Original − Prediction，设为 0 / 1 / 1 时，输出峰值限制前的信号还原为原声。
- **Freeze** — 停止学习和 Weight Decay，处理与发声继续。关闭后恢复学习。
- **Hold** — 同时应用 Freeze 和 Autonomy 1。启用期间，相应控制项不可操作；关闭 Hold 后恢复各自的设置。
- **Reset** — 清除已学系数、运行状态和音频历史，保留控制项设置。预测声从静音开始，需要重新学习。

外部输入低于 −60 dBFS 时，学习和 Weight Decay 会暂停，避免静音抹去已学模型。生成声不参与这一判断。已学系数和运行中的声音是临时状态，不会保存到预设中；重新创建效果后需要再次学习。启用期间，为保留已学声音，Adaptive Prediction 在静音时也会继续处理。不再需要时请旁路此效果。

### 结果不符合预期时

- 如果 Prediction 或 Hold 没有声音，关闭 Hold 和 Freeze，将 Learn 设为大于 0，并播放可听见的输入。Autonomy 从 0 开始。
- 如果共鸣过强，降低 Prediction 或 Autonomy。输出峰值限制会控制采样峰值，但较高的混合设置仍可能改变音色。
- 如果提示处理出现问题，按 Reset，再播放音频以重新学习。
- Adaptive Prediction 支持单声道或立体声。在**音频设置**中启用**使用 WebAssembly 音频处理**，并在效果路由中选择一个声道或一对立体声。使用不支持的格式时，效果会被旁路。

## Horn Resonator

使用数字波导模型模拟号角负载扬声器共鸣的插件。它适合为音乐加入号角扬声器特有的存在感、亮度或投射感。

### 听觉体验指南
- 为人声、铜管或原声乐器加入号角式存在感
- 给音乐增加更直接、更有投射感的扬声器色彩
- 通过尺寸参数塑造从紧凑到宽松的共鸣特性

### 系统预设

点击效果标题中的 **效果预设**，即可直接试用以下完整设置。

- **Gramophone** - 开口很大的号角，带有老式原声留声机的音色。
- **Vintage Theater** - 延伸至较低频段的大型影院号角响应。
- **Megaphone** - 短锥形号角，具有直接而突出的中频。

### 参数

- **Crossover (Hz)** - 设置低频路径（延迟）和高频号角模型路径之间的分频点（20-5000 Hz）
- **Horn Length (cm)** - 调整模拟号角长度。较长的号角会把共鸣移向更低频，并让共鸣间距更密；较短的号角会把共鸣移向更高频，并让间距更大，听起来更紧（20-120 cm）
- **Throat Diameter (cm)** - 控制号角喉口（输入端）尺寸。较小值倾向于增加亮度和上中频强调，较大值增加温暖感（0.5-50 cm）
- **Mouth Diameter (cm)** - 控制号角开口（输出端）尺寸。它影响与周围空气的阻抗匹配，以及开口处的频率相关反射。较大值通常让听感更宽，并减少低频反射；较小值更集中，并增加低频反射（5-200 cm）
- **Curve (%)** - 调整号角扩张形状（半径从喉口到开口如何增加）
  - 0%：近似圆锥
  - 正值：更接近指数型扩张
  - 负值：更接近 tractrix 型扩张
- **Damping (dB/m)** - 设置号角波导内部每米的衰减（吸音量）。较高值会减少共鸣峰和振铃，让声音更平滑、更受阻尼控制（0-10 dB/m）
- **Throat Reflection** - 调整号角喉口（输入端）的反射系数。较高值会让更多声音从喉口边界反射回号角，可能让响应更明亮并强调某些共鸣（0-0.99）
- **Output Gain (dB)** - 控制处理后高频路径在与延迟低频路径混合前的整体输出电平，可用于匹配或提升效果电平（-36 到 +36 dB）

### 快速入门
1. 设置 **Crossover**，定义送入号角模型的频率范围（例如 800-2000 Hz）。低于此分频点的频率会被延迟并混回。
2. 从约 60-70 cm 的 **Horn Length** 开始，可获得典型的中频性格。
3. 用 **Throat Diameter** 和 **Mouth Diameter** 调整核心音色（亮度/温暖、集中/宽松）
4. 用 **Curve** 微调共鸣性格（0% 圆锥，正值接近指数，负值接近 tractrix）
5. 用 **Damping** 和 **Throat Reflection** 调整号角共鸣的平滑或强调
6. 用 **Output Gain** 平衡号角声音与延迟低频的电平

## Horn Resonator Plus

Horn Resonator Plus 为音乐加入更平滑、更自然的号角扬声器色彩。它适合让人声、铜管、原声乐器或整首音乐更温暖、更有活力，同时让共鸣比标准 Horn Resonator 更不尖锐。

它基于与 [Horn Resonator](#horn-resonator) 相同的号角模型，但使用更细致的号角开口和喉口反射模型，使共鸣衰减更平滑。

### 聆听指南

- 更平滑的号角色彩：加入号角负载扬声器特性，但减少尖锐振铃
- 更温暖的存在感：可让人声、铜管和原声音乐更有生命力
- 更自然的高频行为：高频范围比标准版本更接近声学号角或号角扬声器

### 系统预设

点击效果标题中的 **效果预设**，即可直接试用以下完整设置。

- **Gramophone** - 开口很大的号角，带有老式原声留声机的音色。
- **Vintage Theater** - 延伸至较低频段的大型影院号角响应。
- **Megaphone** - 短锥形号角，具有直接而突出的中频。

### 技术增强

- **2nd-order mouth reflection filter**：更平滑地模拟号角开口处的频率相关反射
- **Frequency-dependent throat reflection**：喉口反射会随频率变化，得到更自然的号角行为

### 参数和使用

Horn Resonator Plus 使用与 [Horn Resonator](#horn-resonator) 相同的参数。关于每个参数的详细说明，请参考 Horn Resonator 部分。

### 使用指南

- **Horn Resonator**：需要较轻处理并获得基本号角色彩时选择
- **Horn Resonator Plus**：想要更平滑、更自然的号角色彩，并且可以接受略高 CPU 使用量时选择

### 快速入门指南

使用与 [Horn Resonator](#horn-resonator) 相同的控制。想要更平滑的号角扬声器特性时选择 Horn Resonator Plus。

## Modal Resonator

为音乐加入调谐共鸣的效果，类似物体或扬声器部件在自身固有频率上振动。想在聆听时增加闪亮感、厚度、金属色彩或扬声器般共鸣时可以使用。

### 系统预设

点击效果标题栏中的**效果预设**，即可载入完整的共振模式组合。

- **Wooden Body** - 较低频、持续更久的共振模式，呈现木质箱体的音色。
- **Metal Can** - 较高频、振铃更持久的共振模式，呈现金属质感。
- **Plastic Enclosure** - 较高频、持续更短的共振模式，呈现轻质外壳的音色。

### 听觉体验指南

- **金属共鸣 (Metallic Resonance)：**
  - 创建会跟随原始素材动态变化的钟声般或金属质感音调
  - 适合为打击乐、合成器或整首音乐加入闪亮感或金属色彩
  - 使用多个经过细致调谐的共鸣器，并搭配中等 Decay 时间
- **声音增强：**
  - 为音乐加入可控的共鸣和音色
  - 增强特定频率范围的存在感
  - 可让声音更有身体感、亮度或空间感
- **扬声器特性：**
  - 模拟特定扬声器类型的共鸣特征
  - 加入箱体或材料共振般的色彩
  - 适合探索不同播放系统的味道
- **特殊效果：**
  - 创建不寻常的音色和超现实质感
  - 当您想要明显共鸣效果而不是自然增强时很有用
  - 只有在想让共鸣成为声音本身的一部分时，才尝试极端设置

### 参数

- **Resonator Selection (1-5)** - 五个独立共鸣器，可分别启用/禁用和配置。
  - 使用多个共鸣器可获得复杂、分层的共鸣效果。
  - 每个共鸣器都可以针对不同频率区域。
  - 可尝试让多个共鸣器之间形成谐波关系，使结果更有音乐性。

每个共鸣器：
- **Enable** - 开启或关闭该共鸣器
- **Freq (Hz)** - 共鸣频率（20 到 20,000 Hz）
- **Decay (ms)** - 共鸣在输入声音之后持续的时间（1 到 500 ms）
- **LPF Freq (Hz)** - 低通滤波器，用于塑造共鸣音色（20 到 20,000 Hz）
- **HPF Freq (Hz)** - 高通滤波器，用于移除共鸣中的不需要低频（20 到 20,000 Hz）
- **Gain (dB)** - 控制每个共鸣器的单独输出电平（-18 到 +18 dB）

全局控制：

- **Mix (%)** - 平衡所有已启用共鸣器的合成输出与原始声音（0 到 100%）

### 推荐设置

1. **轻微扬声器增强：**
   - 启用 2-3 个共鸣器
   - Freq：400 Hz、900 Hz、1600 Hz
   - Decay：60-100ms
   - LPF Freq：2000-4000 Hz
   - Mix：10-20%

2. **金属色彩：**
   - 启用 3-5 个共鸣器
   - Freq：分布在 1000-6500 Hz 之间
   - Decay：100-200ms
   - LPF Freq：4000-8000 Hz
   - Mix：15-30%

3. **低频增强：**
   - 启用 1-2 个共鸣器
   - Freq：50-150 Hz
   - HPF Freq：20-60 Hz，并保持低于目标共鸣
   - Decay：50-100ms
   - LPF Freq：1000-2000 Hz
   - Mix：10-25%

4. **全频扬声器模拟：**
   - 启用全部 5 个共鸣器
   - Freq：100 Hz、400 Hz、800 Hz、1600 Hz、3000 Hz
   - HPF Freq：20 Hz、120 Hz、250 Hz、500 Hz、1000 Hz
   - Decay：从低到高逐渐变短（100ms 到 30ms）
   - LPF Freq：从低到高逐渐提高（2000Hz 到 4000Hz）
   - Mix：20-40%

### 快速入门指南
1. **选择频率：**
   - 从 1 个共鸣器开始
   - 选择想要强调的频率
   - 低频用于厚度，高频用于亮度

2. **调整特性：**
   - 用 `Decay` 控制共鸣持续时间
   - 用 `LPF Freq` 塑造音色
   - 特别是低频设置时，将 `HPF Freq` 设在要保留的共鸣频率下方
   - 更长的 Decay 会产生更明显、类似钟声的音调

3. **与原声混合：**
   - 从较低 `Mix` 开始
   - 逐步增加，直到听到想要的色彩
   - 旁路比较，确认效果没有压过音乐
