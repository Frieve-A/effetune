# 空间音频插件

这些插件用于调整音乐在耳机或扬声器中的空间呈现，让声场更自然、更舒适，或修正左右偏移。

## 插件列表

- [Crossfeed Filter](#crossfeed-filter) - 用于自然耳机声像的交叉馈送滤波器
- [MS Matrix](#ms-matrix) - 在立体声与 Mid/Side 之间转换，用于高级立体声调整链
- [Multiband Balance](#multiband-balance) - 5 频段频率相关立体声平衡控制
- [Phase Select EQ](#phase-select-eq) - 按 L/R 相位差和 Balance 选择并提升或衰减频率成分
- [Stereo Blend](#stereo-blend) - 从极性互换立体声、单声道到增强立体声的宽度控制

## Crossfeed Filter

耳机交叉馈送滤波器，模拟扬声器聆听时左右耳之间自然存在的声学串音。它可以减少耳机中“声音贴在两耳边”的感觉，让声像更接近自然聆听。

### 主要功能
- 为耳机聆听模拟自然声学串音
- 可调交叉馈送电平和时间
- 用低通滤波模拟频率相关串音
- 仅处理立体声（单声道或其他非立体声信号会自动旁路）

### 参数
- **Level** (-60 dB 到 0 dB)：控制交叉馈送信号量
  - 较低值：效果更微妙
  - 较高值：左右融合更明显
  - 从 -12 dB 左右开始
- **Delay** (0 ms 到 1 ms)：模拟声音到达另一只耳朵的时间差
  - 较短延迟：更紧密的声像
  - 较长延迟：更宽松的自然感
- **LPF Freq** (100 Hz 到 20000 Hz)：控制交叉馈送的频率响应
  - 较低值（500-1000 Hz）：更自然的频率相关串音
  - 较高值（1000-20000 Hz）：更宽的频率响应

### 推荐设置

1. 自然耳机聆听
   - Level: -12 dB
   - Delay: 0.3 ms
   - LPF Freq: 700 Hz
   - 效果：细微交叉馈送，适合长时间舒适聆听

2. 扬声器模拟
   - Level: -6 dB
   - Delay: 0.5 ms
   - LPF Freq: 1000 Hz
   - 效果：更明显的扬声器式呈现

3. 细微增强
   - Level: -20 dB
   - Delay: 0.2 ms
   - LPF Freq: 500 Hz
   - 效果：非常轻柔的交叉馈送，适合敏感听者

### 应用指南
- 先从较低 Level 开始，再逐步增加
- 交替开启/关闭比较是否更自然
- 如果声场变窄过多，请降低 Level
- 不同耳机可能需要不同设置

### 快速入门指南
1. 将 Level 设为 -12 dB
2. 将 Delay 设为 0.3 ms
3. 将 LPF Freq 设为 700 Hz
4. 播放熟悉的人声或现场录音
5. 微调 Level，直到声场更自然但不过度变窄

## MS Matrix

MS Matrix 可将普通立体声转换为 Mid/Side 格式，也可将 Mid/Side 音频转换回普通立体声。当您想在效果链中分别调整中心信息和侧向信息时使用，例如先编码为 M/S，改变 Mid 或 Side 电平，再解码回立体声。若只是想直接调整普通音乐的立体声宽度，[Stereo Blend](#stereo-blend) 更直接。

### 主要功能
- 分别调整 Mid 与 Side 增益（–18 dB 到 +18 dB）
- Mode 切换：Encode (Stereo→M/S) 或 Decode (M/S→Stereo)
- 可在编码前或解码后选择 Swap L/R

### 参数
- **Mode** (Encode/Decode)：Encode 会把左右立体声转换为左声道 Mid、右声道 Side。Decode 会把左声道视为 Mid、右声道视为 Side，并重建普通立体声。
- **Mid Gain** (–18 dB 到 +18 dB)：调整所选转换过程中的 Mid 电平。
- **Side Gain** (–18 dB 到 +18 dB)：调整所选转换过程中的 Side 电平。
- **Swap L/R** (Off/On)：在编码前或解码后交换左右声道。

### 推荐设置
1. **普通立体声的轻微加宽**
   - 第一个 MS Matrix：Mode: Encode, Mid Gain: 0 dB, Side Gain: +3 dB, Swap: Off
   - 后面的第二个 MS Matrix：Mode: Decode, Mid Gain: 0 dB, Side Gain: 0 dB, Swap: Off
   - 效果：稍微增强 Side 成分，然后恢复为普通立体声

2. **普通立体声的中心聚焦**
   - 第一个 MS Matrix：Mode: Encode, Mid Gain: +3 dB, Side Gain: -3 dB, Swap: Off
   - 后面的第二个 MS Matrix：Mode: Decode, Mid Gain: 0 dB, Side Gain: 0 dB, Swap: Off
   - 效果：让人声和居中声音更靠前，同时减少侧向氛围

3. **解码已有 M/S 音频**
   - Mode: Decode
   - Mid Gain: 0 dB
   - Side Gain: 0 dB
   - Swap: Off
   - 仅在输入信号已经是 Mid/Side 格式时使用

4. **创意翻转**
   - Mode: Encode
   - Mid Gain: 0 dB
   - Side Gain: 0 dB
   - Swap: On

### 快速入门指南
1. 先决定只需要一次转换，还是需要完整的 Encode -> 调整 -> Decode 链
2. 普通立体声聆听时，先放一个 Encode 模式的 MS Matrix，再在后面放一个 Decode 模式的 MS Matrix
3. 在 Encode 阶段调整 **Mid Gain** 和 **Side Gain**
4. 只有在需要通道校正或创意反转时才启用 **Swap L/R**
5. 旁路比较，确认立体声声像仍然自然

## Multiband Balance

这是一个频率相关的平衡处理器，会把音频分成五个频段，并让您分别将每个频段略微向左或向右移动。它适合低频、人声、镲片或其他频率范围偏向一侧时，只修正那部分声音，而不移动整首歌。

### 主要特点
- 5 频段频率相关立体声平衡控制
- 高质量 Linkwitz-Riley 分频滤波器
- 线性平衡控制，便于精细调整
- 左右声道独立处理
- 重置分频滤波器时自动淡变处理

### 参数

#### 分频点频率
- **Freq 1** (20-500 Hz)：Low 与 Low-Mid 的分界
- **Freq 2** (100-2000 Hz)：Low-Mid 与 Mid 的分界
- **Freq 3** (500-8000 Hz)：Mid 与 High-Mid 的分界
- **Freq 4** (1000-20000 Hz)：High-Mid 与 High 的分界

#### 频段控制
每个频段都有独立的平衡控制：
- **Band 1 Bal.** (-100% 到 +100%)：控制低频的立体声平衡
- **Band 2 Bal.** (-100% 到 +100%)：控制低中频的立体声平衡
- **Band 3 Bal.** (-100% 到 +100%)：控制中频的立体声平衡
- **Band 4 Bal.** (-100% 到 +100%)：控制高中频的立体声平衡
- **Band 5 Bal.** (-100% 到 +100%)：控制高频的立体声平衡

### 推荐设置

1. 修正高频偏右
   - Low Band (20-100 Hz): 0%（居中）
   - Low-Mid (100-500 Hz): 0%
   - Mid (500-2000 Hz): 0%
   - High-Mid (2000-8000 Hz): -10% 到 -25%
   - High (8000+ Hz): -10% 到 -30%
   - 效果：将明亮内容略向左移，同时保持低频和人声稳定

2. 修正低中频偏左
   - Low Band: 0%
   - Low-Mid: +10% 到 +25%
   - Mid: +5% 到 +15%
   - High-Mid: 0%
   - High: 0%
   - 效果：将温暖的厚度和较低的人声区域略向右移，而不改变整个立体声图像

3. 保持低频居中，同时调整空气感
   - Low Band: 0%
   - Low-Mid: 0%
   - Mid: 0%
   - High-Mid: +5% 到 +15%
   - High: +10% 到 +20%
   - 效果：轻微将高频氛围向右移，同时保持低频居中

### 应用指南

1. 聆听平衡校正
   - 低频（100 Hz 以下）保持居中以获得稳定低音
   - 只移动听起来偏离中心的频率范围
   - 先使用小的有符号数值（约 5-20%）
   - 检查单声道播放是否带来音色或电平变化

2. 问题修正
   - 重新平衡过于偏左或偏右的频率范围
   - 通过居中低频来收紧不聚焦的低音
   - 减少高频中刺耳的立体声伪影
   - 改善不同声音部位分别偏向不同侧的录音

3. 创意聆听效果
   - 创建不寻常的频率相关位置
   - 让高频偏向一侧，同时低频保持居中
   - 通过轻微移动上部频段，让氛围听起来更宽

4. 立体声场调整
   - 按频段微调立体声平衡
   - 修正不均匀的立体声分布
   - 不要把它当作整体宽度控制；要整体加宽或收窄时请使用 Stereo Blend
   - 保持单声道兼容性

### 快速入门指南
1. 先将所有 Balance 保持在 0%
2. 播放熟悉的音乐，找出偏向一侧的频率范围
3. 只调整相关频段
4. 每次以小步进调整，并频繁旁路比较

## Phase Select EQ

Phase Select EQ 按频率、左右绝对相位差和左右电平平衡来选择并提升或衰减立体声成分，三个范围必须同时匹配。它对两侧频谱施加相同的正增益，因此不会改变相位差。普通均衡器无法把同一频率上的中央声音与宽阔或偏向一侧的声音分开时，可以使用此插件。

始终可使用五个独立的 Band。每个 Band 包含完整应用 Gain 的 **Core**，以及倍率平滑回到 100% 的 **Transition**。重叠 Band 的 Gain 相乘；例如 150% 与 50% 重叠后结果为 75%。多个提升叠加后可能超过 0 dBFS，因此请保留足够余量，并与 bypass 进行比较。

Phase Select EQ 报告的处理延迟等于 FFT 大小与 Hop 大小之和。在 48 kHz 下，4,096 + 1,024 = 5,120 个采样点，约为 106.7 ms（在 44.1 kHz 下约为 116.1 ms）。可在应用的 **Total Delay** 中查看整条处理链的累计延迟。该延迟可能影响实时监听以及音频与视频的同步。

### 如何读取选择图

- 纵轴为对数频率：低频在下，高频在上。
- 使用 **Phase** 和 **Balance** 选项切换横轴；编辑 Phase 或 Balance 参数时会自动切到对应视图。Phase 视图中，0° 位于中央并表示同相，-180° 与 +180° 则是同一个反相点。选择依据是相位差的**绝对值**，因此边框以 0° 为中心镜像，并以相同方式处理 +60° 和 -60°。Balance 视图中，50:50 位于中央，左端表示只有左声道，右端表示只有右声道。Balance 的计算式为`(右声道振幅 - 左声道振幅) / (左声道振幅 + 右声道振幅) × 100%`；负值偏左，正值偏右。边框是单个矩形，而不是镜像的一对。
- 每个点代表最近测得的输入成分。越强的成分越大、越亮，较早的点会逐渐淡出。
- 测得的成分以白点显示。只绘制已启用 Band 的边框；当前编辑的 Band 为亮绿色，其余已启用 Band 为浅绿色。Core 左上角的数字表示 Band 编号。
- 每个 Core 编号旁的短徽标会显示该 Band 在隐藏轴上的全部四个边界。例如，`P 20°›40°–80°›100°`表示 Phase 外侧下限 › Core 下限–上限 › 外侧上限。Balance 按同样顺序显示左:右比例，例如`B 100:0›80:20–70:30›0:100`。`P full`或`B full`表示该 Band 不限制隐藏轴。
- 选择依据是相位差的**绝对值**。因此，一个逻辑区域会以 0° 为中心镜像显示，并以相同方式处理 +60° 和 -60°。交换 L/R 只会镜像这些点，不会改变处理对象。
- 边界清晰的内部区域是 Core，外侧较淡的区域是 Transition。包含 0° 的区域会在中央连为一体；延伸至 180° 的区域会跨越相位图的左右边缘连续显示。
- Graph 选项旁的徽标会显示隐藏轴的 Core 范围，并在需要时显示 Transition 范围。当前 Band 在隐藏轴上排除的点会变暗。仅存在于左声道的成分显示为 Balance -100%、Phase -180°；仅存在于右声道的成分显示为 Balance +100%、Phase +180°。

Balance 网格显示左:右比例。Balance 0%、±17%、±33%、±60%、±82% 和 ±100% 分别对应 50:50，以及朝任一侧时约 59:41、67:33、80:20、91:9 和 100:0。左右电平差约为 0、±3、±6、±12 和 ±20 dB；±100% 表示只有一个声道有信号。

### 音质调整指南

1. **减轻宽阔高频的刺激感**：将 Band 设置在约 4–12 kHz、90–180°，从 70–90% 和较宽的 Transition 开始。
2. **增强中央人声的存在感**：将 Band 设置在约 1–4 kHz、0–30°，从 110–125% 开始。
3. **整理扩散的中低频氛围**：将 Band 设置在约 150–600 Hz、60–150°，从 80–90% 开始，再逐渐加宽频率 Transition。
4. **衰减硬声像乐器**：在 Balance 中选择左侧 -100% 至 -70% 或右侧 +70% 至 +100%，并缩小频率范围。将 Phase Core 设为 150–180°，以包含仅有单侧声道时位于 -180° 或 +180° 的点；如果只想由 Balance 决定选择范围，则将 Phase Core 设为完整的 0–180°。从 70–90% Gain 开始。
5. **增强中央声源**：选择 Balance -17% 至 +17%、Phase 0–30°，缩小频率范围，并从 105–120% Gain 开始。

这些相位范围只是常见趋势，并不代表固定的声源位置。请观察实际录音中点出现的位置，进行小幅调整，并分别用耳机和扬声器确认效果。

### 参数

- **Band 1-5 / 复选框** (Off/On)：选择要编辑的 Band，并在不改变设置的情况下启用或停用它。
- **Gain** (0% 至 200%)：设置 Core 内的电平倍率。100% 不改变电平，0% 移除选中的成分，200% 将振幅加倍。
- **Solo** (Off/On)：只聆听开启 Solo 的 Band 所选中的声音。只要有任一启用的 Band 打开了 Solo，Gain 便不再生效，这些 Band 之外的成分全部静音，边缘仍按 Transition 平滑衰减。同时对多个 Band 开启 Solo 时，将输出它们所选范围的合集。关闭全部 Solo 后即恢复常规处理。
- **Core Low Frequency / Core High Frequency** (20 Hz 至 40 kHz，受当前采样率上限限制)：设置 100% 处理的频率范围。
- **Core Low Phase / Core High Phase** (0° 至 180°)：设置 100% 处理的 L/R 绝对相位差范围。
- **Outer Low Balance / Core Low Balance / Core High Balance / Outer High Balance** (-100% 至 +100%)：直接设置 Balance 的四个边界。Core 的两个值确定 100% 处理的左右振幅平衡范围；Outer 的两个值确定 Transition 达到不处理状态的位置。负值选择左侧，正值选择右侧。
- **Low Frequency Transition / High Frequency Transition**：设置频率 Core 下方和上方的效果渐变范围。
- **Low Phase Transition / High Phase Transition**：设置朝向 0° 和 180° 的效果渐变范围。

相位图手柄、滑块和数值输入框编辑相同的值。使用鼠标或触摸时，在所选 Band 的外框内拖动可移动整个 Band；拖动 Core 的边或角可调整大小；拖动外框手柄可分别调整各个 Transition。低 Phase 一侧的手柄不会越过中央：Core Low Phase 在 0° 处停止，Low Phase Transition 在最大宽度处停止。当 Core Low Phase 恰好为 0° 时，中央手柄起初可向任一侧移动；一旦移向某一侧，在本次拖动结束前都会锁定在该侧。

## Stereo Blend

这个效果通过调整音乐的立体声宽度，帮助获得更自然的声场。它尤其适合耳机聆听，因为它可以减少耳机中常见的过度立体声分离，让聆听体验更自然、更不容易疲劳。需要时，它也可以增强扬声器聆听的立体声图像。

### 聆听增强指南
- 耳机优化：
  - 减小立体声宽度（60-90%），获得更自然、类似扬声器的呈现
  - 减少过度立体声分离造成的聆听疲劳
  - 创建更真实、以前方为中心的声场
- 扬声器增强：
  - 保持原始立体声图像（100%），用于准确重放
  - 需要时使用轻微增强（110-130%）获得更宽声场
  - 谨慎调整以保持自然声场
- 声场控制：
  - 以自然、真实的呈现为目标
  - 避免过宽而听起来不自然
  - 负宽度只建议用于校正或创意侧向极性反转
  - 针对具体聆听环境优化

### 参数
- **Stereo** - 控制立体声宽度（-200% 到 200%）
  - 负值：在重建前反转立体声侧向（L-R）成分的极性
  - -200%：带反相侧向极性的最大宽度；只用于校正或特殊情况
  - -100%：原始立体声宽度，但左右声像互换
  - 0%：完全单声道（左右声道相加）
  - 100%：原始立体声图像
  - 200%：最大宽度增强；保留中心成分，同时强烈增强侧向差异

### 不同聆听场景的推荐设置

1. 耳机聆听（自然）
   - Stereo: 60-90%
   - 效果：减少立体声分离
   - 适合：长时间聆听、降低疲劳

2. 扬声器聆听（参考）
   - Stereo: 100%
   - 效果：原始立体声图像
   - 适合：准确重放

3. 扬声器增强
   - Stereo: 110-130%
   - 效果：轻微宽度增强
   - 适合：扬声器摆位较近的房间

### 音乐风格优化指南

- 古典音乐
  - 耳机：70-80%
  - 扬声器：100%
  - 优点：自然的音乐厅视角

- 爵士与原声
  - 耳机：80-90%
  - 扬声器：100-110%
  - 优点：亲密、真实的合奏声音

- 摇滚与流行
  - 耳机：85-95%
  - 扬声器：100-120%
  - 优点：在没有人工宽化感的情况下保持平衡冲击力

- 电子音乐
  - 耳机：90-100%
  - 扬声器：100-130%
  - 优点：保持聚焦的同时获得受控的空间感

### 快速入门指南
1. 选择您的聆听设置
   - 确认您使用的是耳机还是扬声器
   - 这会决定调整的起点

2. 从保守设置开始
   - 耳机：从 80% 开始
   - 扬声器：从 100% 开始
   - 聆听声音位置是否自然

3. 根据音乐微调
   - 每次小幅调整（5-10%）
   - 专注于获得自然声场
   - 注意聆听舒适度
