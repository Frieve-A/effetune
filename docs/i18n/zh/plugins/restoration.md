# 修复插件

修复插件可减少录音中不需要的瑕疵，同时让音乐保持自然的听感。

## 插件列表

- [Click Remover](#click-remover) - 修复短促的咔嗒声、噼啪声、爆音和短暂断音
- [Clip Restorer](#clip-restorer) - 修复因硬削波而变平的峰值
- [Hum Remover](#hum-remover) - 去除持续的电源嗡声及其谐波
- [Noise Reduction](#noise-reduction) - 降低持续的嘶声和背景噪声

## Click Remover

Click Remover 用于修复唱片噼啪声、爆音、咔嗒声和极短断音等孤立、短暂的瑕疵。它适合偶发的中断，不适合持续的嘶声或嗡声。

### 聆听指南

1. 从 **Sensitivity** 50% 和 **Max Repair Length** 1 ms 开始。
2. 逐步提高 **Sensitivity**，直到恼人的咔嗒声减弱。如果鼓点起音或其他锐利的音乐细节变钝，请调低它。
3. 只有在爆音或断音比普通咔嗒声更长时才提高 **Max Repair Length**；普通噼啪声应保持较短的长度。
4. 播放有问题的段落时查看 **REPAIRS/S**，在保留更强的设置前与关闭效果时比较。

### 参数

- **Sensitivity**（0–100%，默认 50%）控制将短暂变化视为瑕疵的敏感程度。数值更高会修复更多疑似咔嗒声；数值更低则更保守，更容易保留音乐的起音。
- **Max Repair Length**（0.1–2 ms，默认 1 ms）限制每次修复的最长时间。对于稍长的爆音或断音可提高；对于短噼啪声可降低。

### 如何阅读显示

**REPAIRS/S** 显示最近每秒进行的咔嗒声修复次数。接近零表示当前几乎没有修复短瑕疵。若在正常音乐中持续很高，请降低 **Sensitivity** 或 **Max Repair Length**。

## Clip Restorer

Clip Restorer 可重建因数字硬削波而变平的峰值。它适用于平顶失真明显的录音，但无法还原音频进入 EffeTune 前已经丢失的所有细节。

### 聆听指南

1. 从 **Threshold** -0.10 dB 和 **Output Gain** -3 dB 开始。
2. 如果仍有明显的削波峰值，请稍微降低 **Threshold**。如果不必要地改变了响亮、持续的声音，请向 0 dB 提高。
3. 尽可能将 **Output Gain** 保持在 0 dB 以下；修复后的峰值可能高于原本变平的峰值。
4. 在损坏段落中查看 **RESTORED**，并与关闭效果时比较，以选择干预最少的设置。

### 参数

- **Threshold**（-18–0 dB，默认 -0.10 dB）设定被视为削波峰值的电平。接近 0 dB 时只处理接近满刻度的平顶峰值；降低后也会处理较不明显的削波，但可能影响更多响亮内容。
- **Output Gain**（-12–0 dB，默认 -3 dB）设定修复后的输出电平。向 0 dB 提高可获得更大音量；降低可为修复后的峰值留下更多余量。

### 如何阅读显示

**RESTORED** 显示最近作为削波峰值修复的音频采样百分比。削波往往只发生在短峰值上，因此较小数值也可能正常。如果在听起来没有削波的素材上持续很高，请提高 **Threshold**。

## Hum Remover

Hum Remover 可降低持续的电源嗡声及其谐波，例如来自唱盘、线缆或供电问题的 50 Hz 或 60 Hz 嗡声。它用于持续音调，而不是一般背景噪声。

### 聆听指南

1. 从 **Frequency** 设为 **Auto**、**Harmonics** 设为 8、**Tracking Speed** 设为 50% 开始。
2. 如果知道录音中的电源频率，请选择 **50 Hz** 或 **60 Hz**；否则保持 **Auto** 并查看 **FUNDAMENTAL**。
3. 如果基频以上仍有嗡嗡声，请提高 **Harmonics**；如果音乐失去厚度或细节，请降低它。
4. 如果嗡声的音高缓慢漂移，请提高 **Tracking Speed**；对于稳定的嗡声则降低它。如果持续低音恰好与某个嗡声谐波重合，请降低 **Harmonics**。

### 参数

- **Frequency**（**Auto**、**50 Hz** 或 **60 Hz**；默认 **Auto**）选择嗡声基频。**Auto** 会跟踪检测到的电源类嗡声；已知频率时请选择固定值。
- **Harmonics**（1–64，默认 8）选择移除基频的多少个倍频。数值更高可清除更多嗡嗡声；数值更低可保留高次谐波附近更多音乐内容。滑块采用对数刻度，因此低数值范围可以调得更细。
- **Tracking Speed**（0–100%，默认 50%）控制自动跟踪变化嗡声的速度。数值更高可更快跟随变化；数值更低适合稳定嗡声。

### 如何阅读显示

**FUNDAMENTAL** 显示效果当前针对的频率。**REMOVED** 以 dBFS 显示正在移除的嗡声成分电平：越接近 0 dBFS 表示移除的嗡声越强；-140 dBFS 这类极低数值表示当前移除的嗡声很少或没有。

## Noise Reduction

Noise Reduction 降低持续的背景噪声，例如磁带嘶声、设备噪声或房间噪声。当音乐背后始终有一层噪声时可使用它。它最适合音符之间仍存在的噪声，不用于移除单独的咔嗒声、变化的背景声或录音中的其他音乐。

### 聆听指南

1. 从 **Reduction** 12 dB、**Sensitivity** 0 dB、**Smoothing** 50%、**Treble Care** 50% 和 **Mix** 100% 开始。
2. 逐步提高 **Reduction**，直到安静部分更干净。若人声、镲片或环境感变得不自然，请降低它。
3. 对于明显的持续嘶声，稍微提高 **Sensitivity**；对于原本干净的音乐则降低它。
4. 如果降噪量似乎在波动或改变音色，请提高 **Smoothing**。若音乐变得过于柔和，请降低 **Smoothing** 或 **Reduction**。
5. 与关闭效果时比较；如果保留一些原始环境感更自然，可用 **Mix** 混入原音。

### 参数

- **Reduction**（0–24 dB，默认 12 dB）设定背景噪声的最大降低量。较低值更柔和；较高值降低更多噪声，但也可能掩盖微弱细节。轻微噪声可从 6–12 dB 开始。
- **Sensitivity**（-12–+12 dB，默认 0 dB）控制声音被当作背景噪声的容易程度。持续噪声仍可听见时提高；柔和乐器、混响尾音或环境感被削弱过多时降低。
- **Smoothing**（0–100%，默认 50%）使相近频率之间的降噪更均匀。较高值可避免波动或水声般的质感；若音乐变闷，请降低它和 **Reduction**。
- **Treble Care**（0–100%，默认 50%）保护高频音乐细节。提高可保留镲片、弦乐和人声的明亮感；只有高频嘶声仍令人困扰时才降低。
- **Mix**（0–100%，默认 100%）混合处理后的声音和原音。100% 时只听到处理后的声音；若少量原始环境感更自然则降低。0% 时声音不变。

### 推荐设置

1. **轻度清理：** Reduction 6–10 dB，Sensitivity -2–0 dB，Smoothing 40–60%，Treble Care 50–70%。
2. **明显的磁带或设备嘶声：** Reduction 12–18 dB，Sensitivity 0–+4 dB，Smoothing 60–80%，Treble Care 50–70%。
3. **保留细腻高频：** Reduction 6–12 dB，Sensitivity -4–0 dB，Smoothing 50–70%，Treble Care 70–100%，Mix 70–100%。
