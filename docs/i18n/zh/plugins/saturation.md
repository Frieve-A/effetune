# 饱和插件

一组用于谐波塑形和频宽恢复的插件。它们可以加入温暖感或失真，也可以在录音存在明确频宽限制时生成克制的高频内容。

## 插件列表

- [Bandwidth Extender](#bandwidth-extender) - 在检测或指定的截止频率以上生成高频内容
- [Bass Extender](#bass-extender) - 在合适的输入内容下方一个八度生成克制的低音
- [Dynamic Saturation](#dynamic-saturation) - 模拟扬声器振膜的非线性位移
- [Exciter](#exciter) - 增加谐波内容以提高清晰度和存在感
- [Hard Clipping](#hard-clipping) - 为声音添加强度和锐利感
- [Harmonic Distortion](#harmonic-distortion) - 通过可调的 2 阶到 5 阶非线性失真增添特色
- [Multiband Saturation](#multiband-saturation) - 独立塑造低频、中频和高频范围
- [Saturation](#saturation) - 添加类似复古设备的温暖感和丰富感
- [Sub Synth](#sub-synth) - 添加经过滤波的低频信号以增强低频
- [Tube Simulator](#tube-simulator) - 模拟电子管线路级以及推挽或单端功率放大器

## 频谱叠加

每按一次兼容图表中的频谱图标，显示模式就会依次切换为 After、Before + After 和 Off。After 仅用蓝线显示处理后的频谱。Before + After 会填充处理前频谱到处理后频谱之间的变化区域：处理后电平升高的频率以暖色表示，降低的频率以蓝色表示，并在其上用灰线绘制 After 频谱。输入和输出频谱与播放中的同一时刻对齐，因此比较的是同一段音频。选择**普通**时采用 1/12 倍频程平滑；选择**高质量**时会更细致地分析低频。聆听时使用此对比，可以观察每项调节如何改变低频、中频和高频。从图表右侧的 dBFS 刻度读取频谱电平。它与图表的增益刻度不同；0 dBFS 是数字音频满刻度参考，较低的值表示更小的电平。在“设置”中，可以选择叠加频谱质量为**普通**或**高质量**，并将显示方式设为**瞬时值**或**峰值保持**。峰值保持会让近期峰值继续显示，并逐渐降低。After 模式仅采集处理后的频谱；Off 模式会停止采集和绘制。

## Bandwidth Extender

Bandwidth Extender 适用于高频存在明确截止的音频，例如部分低码率 MP3。它会共同分析左右声道，并且只在检测或指定的边界以上添加新生成的内容。它无法还原原始丢失的波形；Auto 找不到稳定的截止频率时，通常不会起作用。

生成频带由两个可独立调节的部分组成：与输入相关的谐波延伸，以及确定性的整形噪声。谐波延伸让有调的素材与剩余频谱自然衔接，整形噪声则让打击乐等类似噪声的声音质感不那么人工。原声保持不变，只在其上加入这些新成分。

### 听感增强指南

- 对于受编解码器限制的音乐，先使用 **Auto**，并将两个 Amount 保持在默认值 100%。
- 如果已知存在截止频率但 Auto 没有起作用，请选择 **Manual**，并将边界设为测得的音源截止频率。
- 对持续的有调素材可降低 **Noise Amount**；对打击乐或气息类素材可降低 **Harmonic Amount**。音源兼有两类声音时，请同时保留两者。
- 请在相同音量下与旁路比较。提高任一 Amount 只会增加相应的生成成分，无法重建音源中不存在的细节。
- 不要把它当作让已经是全频带的音频变明亮的通用工具；Exciter 是为这一不同用途设计的。

### 参数

- **Harmonic Amount**（0-200%，默认 100%）- 独立控制谐波延伸。0% 移除此成分，100% 是其参考电平，200% 将其加倍，且不改变整形噪声或原信号。
- **Noise Amount**（0-200%，默认 100%）- 独立控制确定性的整形噪声。0% 移除此成分，100% 是其参考电平，200% 将其加倍，且不改变谐波延伸或原信号。
- **Cutoff** - 选择缺失频带边界的确定方式。
  - **Auto** 寻找左右声道共有的陡峭、持续的频谱下降，置信度低时会减弱效果。
  - **Manual** 使用 Manual Cutoff 的值。生成频带会自动限制在播放可用的频率范围内。
- **Manual Cutoff**（6000-24000 Hz）- 设置 Manual 模式下开始生成的频率。请与测得的音源边界一致，不要只为了让效果更明显而调低。

Bandwidth Extender 会增加约 26.7–29.0 ms 的延迟，其中包括额外一个处理块周期：48 kHz 时为 1,280 个采样，96 kHz 时为 2,560 个采样，192 kHz 时为 5,120 个采样。如果当前的采样率、声道设置或设备无法运行此效果，插件会显示已被旁路，声音保持不变。请改用支持的设置，或停用该插件。

## Bass Extender

Bass Extender 会根据已有低频生成低约一个八度的内容，用来增强低音偏弱的录音。它分析约 60–200 Hz 的输入，并在保留原信号的同时加入约 30–100 Hz 的生成低音。它无法还原缺失的原始基频、电平或相位。

### 听感增强指南

- 先将 **Amount** 保持在默认值 25%，再逐步提高。
- 请在相近响度下与旁路比较。如果加入低音后处理信号变得更响，可用 **Output** 补偿。
- 如果贝斯音符、底鼓或两者重叠时听起来浑浊或不均匀，请降低 **Amount**。
- 如需比较加入的低频范围和输出电平，可使用 Spectrum Analyzer 和 Level Meter。
- 如果耳机或扬声器无法重放生成的 30–100 Hz 频段，效果会较弱。

### 参数

- **Amount**（0–100%，默认 25%）- 控制生成低音的电平。0% 时不加入生成成分；数值越高，生成低音越明显，但不会直接改变原信号。
- **Output**（-24 到 0 dB，默认 0 dB）- 调整加入生成低音后的最终电平。可将其降低，以匹配旁路时的电平或留出更多输出余量。

## Dynamic Saturation

一种基于物理原理的效果器，模拟不同条件下扬声器振膜的非线性位移。它先对扬声器的机械行为建模，再对该位移施加饱和，从而产生一种独特、能随音乐动态响应的失真。

### 听感增强指南
- **轻微增强：**
  - 加入柔和的温暖感，并让峰值略微变圆
  - 在没有明显失真的情况下，营造自然的“推动扬声器”的声音
  - 为声音加入细微的运动感和深度
- **中等效果：**
  - 产生更有动态、响应更灵敏的失真
  - 为持续的段落加入独特的运动感和生动感
  - 让瞬态具有随之运动、灵敏响应的特点
- **创意效果：**
  - 产生随输入演变的复杂失真
  - 形成带共振、类似扬声器的行为
  - 为实验性聆听带来大胆、不断变化的特色

### 系统预设

点击效果标题栏中的**效果预设**，即可比较完整的振膜运动设置。

- **Subtle Cone Color** - 克制、几乎干净的扬声器振膜特色。
- **Pushed Speaker** - 更强的振膜运动和饱和，并补偿输出电平。
- **Ragged Cone** - 最明显、刻意粗糙的振膜特色。

### 参数

- **Oversampling**（1x、2x、4x、8x；默认 1x）- 设置越高，越能减少高频谐波折返到可听频段所产生的多余音调，但 CPU 占用也越大。建议先尝试 2x 或 4x；在 48 kHz 下需要更强的抑制时使用 8x。1x 保持原有的处理方式。高于 1x 的设置会增加 64 个采样的延迟（48 kHz 下约 1.33 ms）。
- **Speaker Drive**（0.0-10.0）- 控制音频信号推动振膜的强度
  - 低值：运动轻微，效果温和
  - 高值：运动剧烈，特色更强
- **Speaker Stiffness**（0.0-10.0）- 模拟振膜悬挂系统的刚度
  - 低值：松弛、自由的运动，衰减更长
  - 高值：紧实、受控的运动，响应迅速
- **Speaker Damping**（0.1-10.0）- 控制振膜运动平息的速度
  - 接近 0.1 的低值：振动和共振持续更久
  - 高值：迅速阻尼，声音受控
- **Speaker Mass**（0.1-5.0）- 模拟振膜的惯性
  - 低值：快速、灵敏的运动
  - 高值：较慢、更明显的运动
- **Distortion Drive**（0.0-10.0）- 控制位移饱和的强度
  - 低值：轻微的非线性
  - 高值：强烈的饱和特色
- **Distortion Bias**（-1.0-1.0）- 调整饱和曲线的对称性
  - 0：对称饱和
  - 正值/负值：改变位移哪一侧饱和得更强，从而加入不对称的特色
- **Distortion Mix**（0-100%）- 在线性位移和饱和位移之间混合
  - 低值：更线性的响应
  - 高值：更饱和的特色
- **Cone Motion Mix**（0-100%）- 控制振膜运动对原始声音的影响程度
  - 低值：轻微增强
  - 高值：效果显著
- **Output Gain**（-18.0-18.0dB）- 调整最终输出电平

### 可视化显示
- 实时传输曲线图，显示位移如何被饱和
- 直观反映失真特性
- 直观呈现 Distortion Drive 和 Bias 如何影响声音
- 将鼠标悬停在图表上，或触摸并拖动，即可读取该位置的数值。

### 音乐增强技巧
- 轻微的温暖感：
  - Speaker Drive：2.0-3.0
  - Speaker Stiffness：1.5-2.5
  - Speaker Damping：0.5-1.5
  - Distortion Drive：1.0-2.0
  - Cone Motion Mix：20-40%
  - Distortion Mix：30-50%

- 富有动态的特色：
  - Speaker Drive：3.0-5.0
  - Speaker Stiffness：2.0-4.0
  - Speaker Mass：0.5-1.5
  - Distortion Drive：3.0-6.0
  - Distortion Bias：尝试 +/-0.2，获得不对称的特色
  - Cone Motion Mix：40-70%

- 强烈的实验效果：
  - Speaker Drive：6.0-10.0
  - Speaker Stiffness：尝试极端值（非常低或非常高）
  - Speaker Mass：2.0-5.0，运动更夸张
  - Distortion Drive：5.0-10.0
  - 尝试不同的 Bias 值
  - Cone Motion Mix：70-100%

### 快速入门指南
1. 从中等的 Speaker Drive（3.0）和 Stiffness（2.0）开始
2. 设置 Speaker Damping 控制共振（1.0 可获得平衡的响应）
3. 按喜好调整 Distortion Drive（3.0 为中等效果）
4. 先将 Distortion Bias 设为 0.0，获得对称饱和
5. 将 Distortion Mix 和 Cone Motion Mix 都设为 50%
6. 调整 Speaker Mass，改变效果的特色
7. 用 Output Gain 微调，平衡电平

## Exciter

一种通过加入谐波来提升清晰度和存在感的效果器。它对高频内容进行滤波并施加饱和，产生额外的谐波，让音乐更明亮、更出彩。

### 听感增强指南
- **轻微增强：**
  - 为人声和高频细节加入清晰度和空气感
  - 增强整个播放信号的存在感
  - 营造更开阔、细节更丰富的声音
- **中等效果：**
  - 带出混音中隐藏的细节
  - 加入闪亮感和光泽感
  - 让音乐听起来更“Hi-Fi”
- **创意效果：**
  - 产生明亮、穿透力强的音色
  - 加入强势的存在感
  - 适合想要更明亮、更靠前的声音时使用，但最好适度

### 参数

- **Oversampling**（1x、2x、4x、8x；默认 1x）- 设置越高，越能减少高频谐波折返到可听频段所产生的多余音调，但 CPU 占用也越大。建议先尝试 2x 或 4x；在 48 kHz 下需要更强的抑制时使用 8x。1x 保持原有的处理方式。高于 1x 的设置会增加 64 个采样的延迟（48 kHz 下约 1.33 ms）。
- **HPF Freq**（500-10000Hz）- 设置高通滤波的截止频率
  - 低值（500-2000Hz）：影响更多的信号
  - 中值（2000-5000Hz）：针对存在感频段
  - 高值（5000-10000Hz）：集中于空气感和光泽感
- **HPF Slope** - 控制滤波器的陡峭程度
  - Off：不滤波，处理整个频谱
  - 6dB/oct：平缓的滤波
  - 12dB/oct：更陡的滤波
- **Drive**（0.0-10.0）- 控制饱和强度
  - 轻度（0.0-3.0）：细微的谐波增强
  - 中度（3.0-6.0）：明显的明亮感
  - 高度（6.0-10.0）：强烈的激励效果
- **Bias**（-0.3 到 0.3）- 调整饱和的不对称性
  - 0：对称饱和
  - 正值/负值：改变所生成增强信号哪一侧饱和得更强，从而加入不对称的特色
- **Mix**（0-100%）- 控制所生成的谐波增强加入原始声音的量
  - 低（0-30%）：细微地增加明亮感
  - 中（30-60%）：更清晰的存在感和细节
  - 高（60-100%）：加入大量谐波；请谨慎使用，以免刺耳

### 可视化显示
- 高通滤波器的频率响应图
- 饱和传输曲线的可视化
- 滤波和饱和两方面清晰的视觉反馈
- 将鼠标悬停在任一图表上，或触摸并拖动，即可读取该位置的数值。

### 音乐增强技巧
- 让歌曲、播客或视频中的人声更清晰：
  - HPF Freq：3000-5000Hz
  - HPF Slope：6dB/oct
  - Drive：2.0-4.0
  - Bias：0.05 到 0.1
  - Mix：20-40%

- 让密集录音中的中高频细节更清晰：
  - HPF Freq：2000-4000Hz
  - HPF Slope：12dB/oct
  - Drive：3.0-5.0
  - Bias：0.0
  - Mix：30-50%

- 为整首曲目加入细微的明亮感：
  - HPF Freq：5000-8000Hz
  - HPF Slope：6dB/oct
  - Drive：1.0-3.0
  - Bias：0.0 到 0.1
  - Mix：10-25%

### 快速入门指南
1. 设置 HPF Freq，对准想要处理的频率范围
2. 选择 HPF Slope（先从 6dB/oct 开始）
3. 先使用中等的 Drive（3.0）
4. 将 Bias 设在 0.1 附近，获得略微不对称的特色
5. 将 Mix 设为 25%，再按喜好调整
6. 一边聆听一边微调所有参数

## Hard Clipping

一种数字削波效果器，会限制超过设定阈值的峰值。想要增加锐利感、密度或创意失真时可以使用；如只需轻微的峰值控制，请将阈值保持在较高位置，再逐步降低以获得更强的特色。

### 听感增强指南
- 轻微增强：
  - Threshold 保持较高时，加入少许锐利感和密度
  - 轻度使用时可以削去尖锐的峰值
  - 削波过度时会变得刺耳，请与旁路比较
- 中等效果：
  - 营造更有活力的声音
  - 为节奏元素加入兴奋感
  - 让音乐感觉更有“推动力”
- 创意效果：
  - 产生戏剧性的声音变化
  - 为音乐加入强势的特色
  - 非常适合实验性聆听

### 参数

- **Oversampling**（1x、2x、4x、8x、16x；默认 1x）- 设置越高，越能减少高频谐波折返到可听频段所产生的多余音调，但 CPU 占用也越大。建议先尝试 2x 或 4x；在 48 kHz 下需要更强的抑制时使用 16x。1x 保持原有的处理方式。高于 1x 的设置会增加 64 个采样的延迟（48 kHz 下约 1.33 ms）。
- **Threshold** - 控制声音受影响的程度（-60dB 到 0dB）
  - 较高值（-6dB 到 0dB）：轻度的峰值控制或细微的锐利感
  - 中间值（-24dB 到 -6dB）：明显的削波特色和密度
  - 较低值（-60dB 到 -24dB）：重度失真和戏剧性效果
- **Mode** - 选择影响声音的哪些部分
  - Both Sides：对称地削去正负峰值，是最容易预测的模式
  - Positive Only：只削去正峰值，形成不对称削波和不同的音色
  - Negative Only：只削去负峰值，形成与 Positive Only 感觉不同的不对称削波

### 可视化显示
- 实时图表，显示声音如何被塑形
- 调整设置时提供清晰的视觉反馈
- 参考线帮助指导调整
- 将鼠标悬停在图表上，或触摸并拖动，即可读取该位置的数值。

### 聆听技巧
- 获得轻微增强：
  1. 从 Threshold 0dB 开始
  2. 使用“Both Sides”模式
  3. 逐步降低到 -3dB 到 -6dB 附近，在效果刚好能听出时停止
- 获得创意效果：
  1. 逐步降低 Threshold
  2. 尝试不同的 Mode
  3. 与其他效果组合，创造独特的声音

## Harmonic Distortion

Harmonic Distortion 插件用可调的 2 阶到 5 阶非线性项塑造波形。它可以调节偶次和奇次失真的特色，从细微的温暖感到更强的染色都能覆盖，让听起来过于干净、单薄或平淡的音乐更加鲜活。

### 听感增强指南
- **轻微效果：**
  - 加入一层柔和的谐波温暖感
  - 增强自然音色，而不会盖过原始信号
  - 适合加入类似模拟设备的细微深度
- **中等效果：**
  - 加入更明显的谐波特色
  - 可以为整段录音增加厚度、明亮感或锐利感
  - 在声音过于平淡或拘谨时很有用
- **强烈效果：**
  - 增强多个非线性项，产生丰富而复杂的失真
  - 为实验性聆听营造大胆的质感
  - 推得很强时可能听起来尖锐或不同寻常
- **正值与负值：**
  - 正值和负值会翻转各非线性项的方向
  - 偶次项主要改变不对称性和音色
  - 奇次项主要改变对称失真的特色

### 参数

- **Oversampling：** 选择处理速率的倍数（1x、2x、4x、8x，默认值：1x）。设置越高，越能减少高频谐波折返到可听频段所产生的多余音调，但 CPU 占用也越大。建议先尝试 2x 或 4x；在 48 kHz 下需要更强的抑制时使用 8x。1x 保持原有的处理方式。高于 1x 的设置会增加 64 个采样的延迟（48 kHz 下约 1.33 ms）。
- **2nd Harm (%)：** 设置二阶失真项（-30 到 30%，默认值：2%）
- **3rd Harm (%)：** 设置三阶失真项（-30 到 30%，默认值：3%）
- **4th Harm (%)：** 设置四阶失真项（-30 到 30%，默认值：0.5%）
- **5th Harm (%)：** 设置五阶失真项（-30 到 30%，默认值：0.3%）
- **Sensitivity (x)：** 调整整体的输入灵敏度（0.1-2.0，默认值：0.5）
  - 灵敏度较低时，效果更含蓄
  - 灵敏度较高时，失真强度增大
  - 作为全局控制，影响非线性塑形的强度

### 可视化显示
- 传输曲线，显示输入电平如何被塑造成输出电平
- 直观的滑块和输入框，提供即时反馈
- 图表会随谐波和灵敏度设置的变化而更新
- 将鼠标悬停在图表上，或触摸并拖动，即可读取该位置的数值。

### 快速入门指南
1. **初始设置：** 从默认设置开始（2nd：2%，3rd：3%，4th：0.5%，5th：0.3%，Sensitivity：0.5）
2. **调整参数：** 每次只改变一两个谐波控制，一边聆听一边留意是否刺耳或清晰度下降
3. **调和声音：** 用 Sensitivity 平衡效果，获得细微的温暖感或明显的失真

## Multiband Saturation

一种用途广泛的效果器，可以为整个播放信号的特定频率范围加入温暖感和特色。它将声音分为低、中、高三个频段，让您独立塑造每个范围，实现精确的声音增强。

### 听感增强指南
- 低频温暖感：
  - 为低频加入温暖感和冲击力
  - 为整个播放信号的低频范围加入饱满感和轻微的冲击力
  - 营造更饱满、更丰富的低频
- 中频清晰度：
  - 为许多人声和乐器所在的中频加入厚度和清晰的轮廓
  - 让密集的录音听起来更清楚
  - 营造更清晰、轮廓更分明的声音
- 高频润色：
  - 为高频范围加入闪亮感
  - 增强空气感和光泽感
  - 营造清脆、细腻的高频

由于它按频段处理，所选范围内的所有声音都会受到影响，而不是只作用于单独的乐器或人声。

### 参数

- **Oversampling**（1x、2x、4x、8x；默认 1x）- 设置越高，越能减少高频谐波折返到可听频段所产生的多余音调，但 CPU 占用也越大。建议先尝试 2x 或 4x；在 48 kHz 下需要更强的抑制时使用 8x。1x 保持原有的处理方式。高于 1x 的设置会增加 64 个采样的延迟（48 kHz 下约 1.33 ms）。
- **分频频率**
  - Freq 1（20Hz-2kHz）：设置低频段结束、中频段开始的位置
  - Freq 2（200Hz-20kHz，始终保持在 Freq 1 或以上）：设置中频段结束、高频段开始的位置
  - 如果将 Freq 2 设得低于 Freq 1，它会自动提高，以保持低-中-高的频段顺序
- **频段控制**（分别用于 Low、Mid 和 High 频段）：
  - **Drive**（0.0-10.0）：控制饱和强度
    - 轻度（0.0-3.0）：细微增强
    - 中度（3.0-6.0）：明显的温暖感
    - 高度（6.0-10.0）：强烈的特色
  - **Bias**（-0.3 到 0.3）：调整饱和曲线的对称性
    - 0：对称饱和
    - 正值/负值：改变波形哪一侧饱和得更强，从而加入不对称的特色
  - **Mix**（0-100%）：将效果与原声混合
    - 低（0-30%）：细微增强
    - 中（30-70%）：均衡的效果
    - 高（70-100%）：强烈的特色
  - **Gain**（-18dB 到 +18dB）：调整频段音量
    - 用于平衡各频段之间的关系
    - 补偿任何音量变化

### 可视化显示
- 可交互的频段选择标签
- 每个频段的实时传输曲线图
- 调整设置时提供清晰的视觉反馈
- 将鼠标悬停在任一频段的图表上，或触摸并拖动，即可读取该位置的数值。

### 音乐增强技巧
- 增强整体混音：
  1. 所有频段都从温和的 Drive（2.0-3.0）开始
  2. 将 Bias 设为 0.0，获得自然的饱和
  3. 将 Mix 设在 40-50% 左右，获得自然的混合
  4. 微调每个频段的 Gain

- 增加低频温暖感：
  1. 集中处理 Low 频段
  2. 使用中等的 Drive（3.0-5.0）
  3. 保持 Bias 为中性，获得一致的响应
  4. 将 Mix 保持在 50-70% 左右

- 增强中频存在感：
  1. 集中处理 Mid 频段
  2. 使用轻度的 Drive（1.0-3.0）
  3. 将 Bias 设为 0.0，获得自然的声音
  4. 按喜好调整 Mix（30-50%）

- 增加明亮感：
  1. 集中处理 High 频段
  2. 使用温和的 Drive（1.0-2.0）
  3. 保持 Bias 为中性，获得干净的饱和
  4. 让 Mix 保持适度（20-40%）

### 快速入门指南
1. 设置分频频率，划分声音
2. 所有频段都从较低的 Drive 值开始
3. 先将 Bias 设为 0.0，获得对称饱和
4. 用 Mix 自然地混合效果
5. 用 Gain 控制微调
6. 相信您的耳朵，按喜好调整！

## Saturation

一种模拟复古电子管设备温暖悦耳声音的效果器。它可以为音乐加入丰富感和特色，让声音听起来更“模拟”、不那么“数字”。

### 听感增强指南
- 加入温暖感：
  - 让数字音乐听起来更自然
  - 为声音加入悦耳的丰富感
  - 非常适合爵士乐和原声音乐
- 丰富的特色：
  - 营造更“复古”的声音
  - 加入深度和立体感
  - 非常适合摇滚乐和电子音乐
- 强烈效果：
  - 大幅改变声音
  - 产生大胆、富有特色的音色
  - 适合实验性聆听

### 参数

- **Oversampling**（1x、2x、4x、8x；默认 1x）- 设置越高，越能减少高频谐波折返到可听频段所产生的多余音调，但 CPU 占用也越大。建议先尝试 2x 或 4x；在 48 kHz 下需要更强的抑制时使用 8x。1x 保持原有的处理方式。高于 1x 的设置会增加 64 个采样的延迟（48 kHz 下约 1.33 ms）。
- **Drive** - 控制温暖感和特色的量（0.0 到 10.0）
  - 轻度（0.0-3.0）：细微的模拟温暖感
  - 中度（3.0-6.0）：丰富的复古特色
  - 强烈（6.0-10.0）：大胆、戏剧性的效果
- **Bias** - 调整饱和曲线的不对称性（-0.3 到 0.3）
  - 0.0：对称饱和
  - 正值：让波形的负半周更突出
  - 负值：让波形的正半周更突出
- **Mix** - 平衡效果与原始声音（0% 到 100%）
  - 0-30%：细微增强
  - 30-70%：均衡的效果
  - 70-100%：强烈的特色
- **Gain** - 调整整体音量（-18dB 到 +18dB）
  - 效果太响时使用负值
  - 效果太轻时使用正值

### 可视化显示
- 清晰的图表，显示声音如何被塑形
- 实时视觉反馈
- 易于读取的控件
- 将鼠标悬停在图表上，或触摸并拖动，即可读取该位置的数值。

### 音乐增强技巧
- 古典乐和爵士乐：
  - 轻度的 Drive（1.0-2.0），获得自然的温暖感
  - 将 Bias 设为 0.0，获得干净的饱和
  - 较低的 Mix（20-40%），保持细微
- 摇滚乐和流行乐：
  - 中度的 Drive（3.0-5.0），获得丰富的特色
  - 保持 Bias 为中性，获得一致的响应
  - 中等的 Mix（40-60%），保持平衡
- 电子音乐：
  - 较高的 Drive（4.0-7.0），获得大胆的效果
  - 尝试不同的 Bias 值
  - 较高的 Mix（60-80%），突出特色

### 快速入门指南
1. 从较低的 Drive 开始，获得温和的温暖感
2. 先将 Bias 设为 0.0，获得对称饱和
3. 调整 Mix，平衡效果
4. 如有需要，调整 Gain 以获得合适的音量
5. 大胆尝试，相信您的耳朵！

## Sub Synth

一种专门用于增强低频的效果器，它混入从原始音频派生并经过滤波的低频信号。当低频偏弱的音乐需要更多温暖感、饱满感或适合耳机的冲击力时很有用。

### 听感增强指南
- 低频增强：
  - 为单薄的录音加入深度和力量
  - 营造更饱满、更丰富的低频
  - 非常适合耳机聆听
- 频率控制：
  - 控制保留哪一段新增的低频范围
  - 独立滤波，获得干净的低频
  - 在增加力量的同时保持清晰度

### 参数
- **Sub Level** - 控制新增低频信号的电平（0-200%）
  - 轻度（0-50%）：细微的低频增强
  - 中度（50-100%）：均衡的低频提升
  - 高度（100-200%）：戏剧性的低频效果
- **Dry Level** - 调整原始信号的电平（0-200%）
  - 用于与新增的低频信号取得平衡
  - 保持原始声音的清晰度
- **Sub LPF** - 新增低频信号的低通滤波器（5-400Hz）
  - 频率：控制新增低频信号的上限
  - 斜率：调整滤波器的陡峭程度（Off 到 -24dB/oct）
- **Sub HPF** - 新增低频信号的高通滤波器（5-400Hz）
  - 频率：去除新增低频信号中多余的隆隆声
  - 斜率：控制滤波器的陡峭程度（Off 到 -24dB/oct）
- **Dry HPF** - 原始信号的高通滤波器（5-400Hz）
  - 频率：防止低频堆积
  - 斜率：调整滤波器的陡峭程度（Off 到 -24dB/oct）

### 可视化显示
- 实时频率响应图
- 清晰呈现滤波器曲线
- 实时视觉反馈
- 将鼠标悬停在图表上，或触摸并拖动，即可读取该位置的数值。

### 音乐增强技巧
- 一般的低频增强：
  1. 从 50% 的 Sub Level 开始
  2. 将 Sub LPF 设在 100Hz 左右（-12dB/oct）
  3. 将 Sub HPF 保持在 20Hz（-6dB/oct）
  4. 按喜好调整 Dry Level

- 干净的低频提升：
  1. 将 Sub Level 设为 70-100%
  2. 将 Sub LPF 设为 80Hz（-18dB/oct）
  3. 将 Sub HPF 设为 30Hz（-12dB/oct）
  4. 将 Dry HPF 设为 40Hz（-6dB/oct）

- 最大冲击力：
  1. 将 Sub Level 提高到 150%
  2. 将 Sub LPF 设为 120Hz（-24dB/oct）
  3. 将 Sub HPF 保持在 15Hz（-6dB/oct）
  4. 用 Dry Level 取得平衡

### 快速入门指南
1. 从适中的 Sub Level（50-70%）开始
2. 将 Sub LPF 设在 100Hz 左右
3. 在 20Hz 左右启用 Sub HPF（-6dB/oct）
4. 调整 Dry Level，取得平衡
5. 按喜好微调滤波器
6. 相信您的耳朵，逐步调整！

## Tube Simulator

Tube Simulator 可加入电子管线路级和功率放大器电路随信号变化的谐波、压缩与电源响应。**Line** 仅使用驱动级，**Push-Pull Power** 提供 EL84、EL34、6L6GC 和 KT88 推挽电路，**SE Triode** 提供 300B 和 2A3 单端电路。两种功率电路还会模拟输出变压器的铁芯，其磁饱和与磁滞会在大音量的低频上加入失真。它会模拟放大器所见的扬声器电气负载，但不会加入音箱或麦克风的声音。

### 听感增强指南

- 想要轻微染色，可在 **Pre** 组中选择名称后缀为 **@0.01%** 或 **@0.1%** 的预设；想让谐波和压缩更容易听出，可选择后缀为 **@1%** 或 **@2%** 的预设。
- 线路级音色选择 **Pre**，只使用输出级选择 **Power**，完整放大器路径选择 **Pre+Power**。
- 想要较为克制的推挽音色，可从 **EL84 Distributed 10 W @2%** 开始，再与更紧实、直接的 **EL84 Pentode 10 W @2%** 比较。
- 想要更明显的偶次谐波和较柔和的单端响应，可尝试 **300B SE @2%** 或 **2A3 SE @2%**。
- 如果声音压缩或失真过强，请降低 **Input Volume**，再用 **Output Trim** 匹配听音音量。
- 降低 **Negative Feedback** 会让响应更宽松、谐波更多；提高它会让声音更紧实。SE Triode 可从 3dB 开始，通常在 0–6dB 附近调整。
- 只想混入少量效果时，请降低 **Wet/Dry Mix**。

### 面板布局

各项控制位于五个标签页中。

- **Input** - Input Volume、Input Reference、Source Z
- **Driver** - Driver Type、Bias、Plate、Supply、Negative Feedback
- **Power** - Output Circuit；推挽电路的 Power Tubes、Output B+、Cathode Resistor；单端电路的 SE Triode、SE B+、SE Cathode Resistor
- **Transformer** - Screen Tap、Push-Pull Primary、SE Primary、Assumed Speaker Load、Actual Speaker Load
- **Output** - Output Trim、Output Safety Trim、Auto Gain Reduction、Wet/Dry Mix

Power 和 Transformer 标签页只显示当前 Output Circuit 会用到的控制项。

### 选择预设

点击效果标题栏中的 **效果预设** 按钮可打开预设对话框。选择系统预设的 Pre、Power 或 Pre+Power 组中的设置即可立即应用。与当前设置匹配的预设会高亮；若没有匹配项，则不会高亮任何预设。初始设置与 **EL84 Pentode @2%** 匹配。**Output Safety Trim** 和 **Auto Gain Reduction** 不用于匹配，因此调整它们不会取消高亮。

预设名称末尾可作为效果强度的实用参考：**@0.01%** 非常轻微，**@0.1%** 带来轻度染色，**@1%** 或 **@2%** 的谐波与压缩更明显。预设也会设置 Output Trim，方便相互比较，但不同音乐的主观响度仍可能不同；判断音色前，请先用 Output Trim 匹配音量。

### 参数

- **Input Volume**（-96 到 0dB）- 降低驱动所选信号路径的电平
  - 0dB 为完全打开；数值越低，内部驱动越小，余量越大
- **Driver Type**（12AX7、12AT7、12AU7 或 Bypass）- 选择两级驱动管，或将该驱动级从信号路径中移除
  - 12AX7 的电压增益最高，12AT7 居中，12AU7 的增益最低、余量最大
  - 在 Push-Pull Power 中，它馈入固定的 12AX7 倒相级；在 SE Triode 中，它直接驱动所选的输出三极管
  - Bypass 主要用于 Power 预设。Push-Pull Power 仍包含倒相级；SE Triode 不经过公共驱动级，直接馈入输出三极管。Line 选择 Bypass 时为经过对齐的直通，Negative Feedback 不起作用
- **Bias**（-50 到 +50%）- 移动两级驱动级的阴极偏置点
  - 提高会降低模型中的阴极电阻，使其移向较大电流；降低则相反
- **Plate**（150 到 300 V）- 设置驱动级的屏极电源
  - 数值越高，通常电压余量越大；数值越低，压缩和非线性越早出现
- **Source Z**（0.6 到 100 kΩ）- 设置馈入 Stage 1 的源阻抗
  - 数值越高，与输入电容的相互作用越强，可能使高频或瞬态的驱动变得柔和
- **Supply**（0.1 到 47 kΩ）- 设置驱动级 B+ 电源的电阻
  - 数值越高，电流增大时电源下陷越明显；数值越低，电源越稳固
- **Negative Feedback**（0 到 30dB）- 设置全局负反馈量
  - Line 回送第二级的屏极响应；两种功率电路结构都从固定的变压器次级反馈绕组回送
  - 提高通常会降低开环增益和失真，并让响应更紧实；0dB 会断开反馈环路
  - SE Triode 适合轻度反馈：从 3dB 开始，通常保持在 0–6dB 范围内
  - 扬声器负载的电气阻尼由该环路本身产生，因此提高反馈也会让放大器更牢地控制负载
- **Output Trim**（-48 到 +48dB）- 在模拟电路之后调整处理信号的数字电平，不改变电路内部的驱动强度
- **Output Safety Trim**（-96 到 0dB）- 在模拟电路之后施加另一个独立的线性电平调整。它与 Output Trim 分开，使输出电平保护拥有自己的控制
  - Auto Gain Reduction 只会降低此项，绝不会改写 Output Trim
  - 滑块和数值框显示的是有效值，即您设定的值减去当前已施加的自动衰减；存储的设置是您最后亲自设定的值，保存的也是这个值
  - 抓住滑块时，显示的有效值会成为您的设定值，因此电平不会跳变，累积的衰减也会在此时清除
- **Auto Gain Reduction**（默认开启）- 允许输出电平保护自行降低 Output Safety Trim
  - 关闭后不会再累积新的衰减，已施加的衰减会保留
- **Wet/Dry Mix**（0 到 100%）- 将处理后的信号与经过延迟对齐的原声混合
  - 设为 0% 时，干声路径仍带有对齐所需的固定 64 个采样延迟
- **Input Reference**（0.100 到 300.000 Vpk）- 数字 0dBFS 峰值所代表的端子峰值电压
  - 2.828 Vpk 对应 2 Vrms 的满刻度正弦波；5.657 Vpk 对应 4 Vrms
  - 数值越高，对模拟电路的驱动越强；主要的听感调整请使用 Input Volume
- **Output Circuit**（Line、Push-Pull Power 或 SE Triode）- 选择模拟的电路结构
  - Line 在两级驱动级之后结束，不运行功率管、变压器和扬声器负载模型
  - Push-Pull Power 加入倒相级和完整的功率输出电路
  - SE Triode 加入一只直接驱动的 300B 或 2A3，以及带气隙的单端输出变压器
- **Power Tubes**（EL84 ×2、EL34 ×2、6L6GC ×2 或 KT88 ×2）- 选择输出管的电流模型及相应的电路元件；仅在 Power 模式下起作用
  - 四种模型都依据真实输出管在屏极、帘栅极和栅极电压下的数据，包括栅极负压足够大时达到的完全截止
- **Output B+**（300 到 470 V）- 设置功率级的电源电压；数值越高，可用电压摆幅和电子管耗散功率越大
- **Cathode Resistor**（270 到 500 Ω / valve）- 设置每只输出管独立的阴极偏置电阻
  - 电阻越高，静态电流越低；电阻越低，静态电流越高
- **SE Triode**（300B 或 2A3）- 选择单端直热式输出三极管的模型；仅在 SE Triode 模式下起作用
- **SE B+**（250 到 450 V）- 设置单端输出级的电源电压
- **SE Cathode Resistor**（700 到 1300 Ω）- 设置单只输出三极管的阴极偏置电阻
- **Screen Tap**（0%、20% 或 43%）- 选择输出管的帘栅极连接方式
  - 0% 使用固定的帘栅极电源；20% 和 43% 将帘栅极接到变压器初级的相应抽头上，形成分布负载（超线性）
  - 抽头是匝数比，因此帘栅极跟随初级绕组中相应比例的磁耦合
- **Push-Pull Primary**（6.0、6.6 或 8.0 kΩ）- 选择推挽输出变压器屏极到屏极的初级阻抗，并与 Assumed Speaker Load 一起决定其匝数比
  - 该选择同时决定铁芯的磁饱和磁通
- **SE Primary**（2.5、3.5 或 5.0 kΩ）- 选择带气隙单端变压器的初级阻抗，并与 Assumed Speaker Load 一起决定其匝数比
  - 该选择同时决定同样的信号会在带气隙铁芯中激起多少磁通，因此阻抗越高，在相同电平下越早进入饱和。单端工作的静态电流会在铁芯中保持一个恒定磁通，因此信号的饱和是不对称的，会在低频加入偶次谐波
- **Assumed Speaker Load**（4、8、15 或 16 Ω）- 选择变压器次级抽头，以及电路设计所依据的标称扬声器阻抗
  - 每个选项都使用随频率变化的 RLC 电气负载，而不是简单的电阻，并会影响变压器负载和反馈
- **Actual Speaker Load**（2 到 32 Ω）- 设置实际连接到该抽头的扬声器阻抗
  - 负载网络按其与 Assumed Speaker Load 的比值缩放，因此共振频率和 Q 值保持不变，只有阻抗水平改变
  - 匝数比仍按 Assumed Speaker Load 设定，因此两者不一致时，反射到输出管的阻抗会不同，阻尼、可用功率和驱动都会改变；两者设为相同时，电路在其设计工作点运行

### 输出电平保护

更改电路参数可能造成较大的电平跳变。开启 **Auto Gain Reduction** 后，当处理输出将超过数字满刻度时，Tube Simulator 会降低 **Output Safety Trim**。衰减量不会自动恢复，并会显示在图表下方的状态栏中。

- 如果衰减量很大，请降低 Input Volume 或 Output Trim，然后重新选择预设或调整 Output Safety Trim。
- 只有在其他位置监看输出峰值时，才建议关闭 Auto Gain Reduction。
- 此保护只降低输出电平，不会消除所选电路内部产生的谐波或压缩。

### 安全旁路与恢复

- 如果不稳定的设置触发旁路，请降低 Negative Feedback 或选择一个预设。设置恢复稳定后，处理后的声音会自动返回。
- 如果旁路状态仍然存在，请恢复预设并重新载入效果。设备无法使用该处理时，原声会不经改变地通过。

### HUD 读法

- 图中的点表示最近的工作点。分布越宽，说明音乐对该级的驱动越强。每个面板都同时叠加左右两个声道，蓝色为左声道，橙色为右声道。
- 图表左上角显示当前电子管的名称。
- 图上方的 **Graph** 用来选择观察哪些电子管。**Stage 1 / Stage 2** 显示驱动级的两级，**Push / Pull** 显示推挽输出管的两支，**SE Triode** 显示单端输出管。只有当前电路实际用到的级才能选择，因此在带驱动级的功率级上可以来回切换、相互比较。
- 当没有任何电子管在工作时，也就是把 **Driver Type** 设为 Bypass 的 Line，或者关闭该效果器时，显示区保持空白，状态栏显示 **No tube stage is active**。
- **Speaker Output** 和 **Speaker Real Power** 显示功率级及扬声器负载被驱动的强度。
- **Transformer Flux** 以 Wb 为单位显示输出变压器磁链的大小。低频把该读数推得越高，变压器本身加入的失真就越多。在 SE Triode 下，读数包含带气隙铁芯的恒定偏磁磁通，因此在无信号时也保持大于零。
- 图表下方的状态栏会显示效果正在工作还是处于旁路，并显示自动输出衰减量。

Tube Simulator 会产生约 0.3 至 1.5ms 的短暂处理延迟，具体取决于采样率。
