# 分析器插件

这些插件让您用可视化方式观察音乐。它们会显示声音的不同侧面，帮助您理解正在听到的内容，也让聆听过程更有参与感。

## 插件列表

- [Analog Meter](#analog-meter) - 用带有 VU、PPM、峰值和响度刻度的指针表显示声道电平
- [Chroma Spiral](#chroma-spiral) - 在音名与八度的螺旋上显示频率成分
- [Level Meter](#level-meter) - 显示数字信号电平和可能的削波
- [Note Spectrogram](#note-spectrogram) - 以钢琴卷帘图显示随时间变化的估算音高
- [Oscilloscope](#oscilloscope) - 实时显示波形
- [Pitch Meter](#pitch-meter) - 随时间跟踪一个基频及其调音偏差
- [Rhythm Analyzer](#rhythm-analyzer) - 显示速度、逐拍的发音，以及各声部相对节拍的超前或滞后
- [Spectrogram](#spectrogram) - 用彩色图案显示音乐变化
- [Spectrum Analyzer](#spectrum-analyzer) - 显示音乐中的不同频率
- [Stereo Meter](#stereo-meter) - 可视化立体声平衡与声道相关性

## Analog Meter

在不改变声音的情况下，用经典的指针式电平表显示每个声道的电平。可以用它跟踪音乐音量随时刻的变化，也可以查看播放内容在广播和流媒体所用的刻度上的读数：VU、PPM、峰值和响度（LUFS）。**Custom** 可让您组合检波器、指针运动方式和刻度，制作自己的电平表。

### 聆听指南

- **用 VU 跟踪平均电平**：在整首歌曲中观察指针。安静的主歌和响亮的副歌会显示出明显差异，而短促的鼓点几乎不会让指针移动。
- **用 True Peak 检查削波**：把 Analog Meter 放在 EQ 和增益类效果之后，播放曲目中最响的部分。如果读数超过 0 dBFS 或过载灯点亮，说明信号链可能会削波；降低增益，直到峰值保持在 0 dBFS 以下，并留出一些余量，例如 -1 dBFS。
- **用 Loudness 比较歌曲**：将 **Target** 设为某个流媒体参考值，例如 -14 LUFS，在歌曲或专辑开始处按下 **Reset**，然后完整播放。Integrated 值显示整体响度，最大 True Peak 显示最高峰值，可作为在专辑或播放列表中统一音量的参考。LRA 可以比较各曲目响度变化范围的宽窄。
- **用 Custom 制作自己的电平表**：想让指针跳动得更明显，可从 **Bouncy VU** 开始；想平稳地观察平均电平，可选 **Slow RMS**；想跟踪短促峰值，可选 **Fast Peak**。用 **Needle Response** 调整速度，用 **Overshoot** 调整跳动幅度。Custom 可以呈现类似 PPM 的上升和回落，但其峰值检波器会瞬时上升；要查看标准的 PPM 响应，请使用 **PPM**。

### 系统预设

点击效果标题栏中的**效果预设**，即可一步选择标准或自定义电平表。选择会更改 **Mode** 的预设时，测量会重新开始；在 Loudness 预设之间切换时，测量会继续进行。

- **Studio VU (-18 dBFS)** - 0 VU 对准 -18 dBFS 的 VU，这是录音棚常用的校准基准（EBU R68），适合预留充足余量的录音。
- **SMPTE VU (-20 dBFS)** - 0 VU 对准 -20 dBFS 的 VU（SMPTE RP 155），是北美录音棚和广播的惯例。
- **Hot VU (-14 dBFS)** - 即默认设置：0 VU 对准 -14 dBFS 的 VU，适合大多数市售成品录音。
- **Loud Master VU (-8 dBFS)** - 0 VU 对准 -8 dBFS 的 VU，用于响度被推到极限的现代 CD 和流行音乐母带，避免指针一直顶在上端。
- **DIN PPM** - DIN 表（**Attack** 5 毫秒、1.5 秒回落 20 dB、DIN 刻度），-9 刻度对准 -18 dBFS，因此 0 刻度对应 -9 dBFS。刻度向下延伸到 -50。
- **BBC PPM** - BBC 表（**Attack** 10 毫秒、2.8 秒回落 24 dB、BBC 刻度），刻度 4 对准 -18 dBFS，因此刻度 6 对应 -10 dBFS。
- **Nagra Modulometer** - Nagra 磁带录音机的调制表（**Attack** 7.5 毫秒、-30 到 +5 dB 的 dB 刻度），0 dB 对准 -18 dBFS。**Release** 采用与 DIN 相同的 1.5 秒。
- **K-20** - 在 RMS 表上使用 Bob Katz 的 K-System，0 对准 -20 dBFS，刻度向下延伸到 -60 dBFS。适合动态范围宽的录音。
- **K-14** - 同上，0 对准 -14 dBFS，刻度到 -60 dBFS。适合一般的流行音乐。
- **K-12** - 同上，0 对准 -12 dBFS，刻度到 -60 dBFS。适合为广播而大幅压缩的素材。
- **Digital Peak** - 标准数字峰值表（IEC 60268-18），显示 -60 到 0 dBFS，峰值标记保持 2 秒。
- **True Peak Clip Watch** - 放大 True Peak 刻度顶部的 20 dB，并使用最长的峰值保持时间（10 秒），便于在调整 EQ 或增益后发现超过 0 dBFS 的峰值。
- **EBU R128 (-23 LUFS)** - 以欧洲广播标准为目标值的 Loudness，使用 EBU +9 刻度。
- **EBU R128 +18 Scale** - 目标值相同，改用更宽的 EBU +18 刻度，适合古典音乐等动态范围宽的素材。
- **TV (-24 LKFS)** - 以美国（ATSC A/85）和日本（ARIB TR-B32）电视所用的 -24 LKFS 为目标值的 Loudness。
- **Streaming (-14 LUFS)** - 以 -14 LUFS 为目标值的 Loudness，接近许多音乐流媒体服务的音量标准化水平，指针使用更平稳的 Short-term。
- **Streaming (-16 LUFS)** - 以流媒体和播客推荐的 -16 LUFS（AES TD1008）为目标值的 Loudness，指针使用 Short-term。
- **Bouncy VU** - 使用 VU 检波器和刻度的 Custom，过冲为 15%，让指针跳动得更明显。
- **Slow RMS** - 使用 3 秒 RMS 平均、1000 ms 指针响应且无过冲的 Custom。dB 刻度的 0 对应 -18 dBFS，下端延伸至 -60 dBFS。
- **Fast Peak** - 使用 True Peak 检波、0.5 秒检波器释放、10 ms 指针响应且无过冲的 Custom。dBFS 刻度显示上端 40 dB，读数单位为 dBTP。

### 参数

只显示适用于当前所选 **Mode** 的控件。在 **Custom** 中，该模式的所有设置项始终显示，不适用的设置项会被禁用，因此更改设置不会改变面板高度。

- **Mode** - 选择电平表类型：**VU**（默认）、**PPM**、**RMS**、**Sample Peak**、**True Peak**、**Loudness** 或 **Custom**。每种模式的指针运动方式和刻度都不同（参见可视化指南）。切换模式会重新开始测量。
- **Detector**（Custom；默认 Average Rectified）- 选择指针跟随的电平。**Average Rectified** 与 VU 一样，由指针本身对信号的绝对幅度取平均，不另设平均窗口。**RMS** 测量 **Integration** 时间内的平均功率。**Sample Peak** 捕捉最高的采样值；**True Peak** 还估算采样之间的峰值。两种峰值检波器均瞬时上升，并按 **Release** 回落。切换检波器会重新开始测量。
- **Integration**（RMS、检波器为 RMS 的 Custom；0.05 到 3 秒；默认 0.3 秒）- 设置取平均的时间。数值越大指针越稳定、动作越慢；数值越小则对变化的反应越快。在 Custom 中，取平均后还会叠加指针自身的响应。
- **Attack**（PPM；1 到 20 毫秒；默认 5 毫秒）- 以读数比稳定音低 2 dB 的音爆长度来设置 PPM 指针上升的速度。数值越小，短促峰值的读数越接近其真实电平；数值越大，短促峰值的读数越低。5 毫秒对应 DIN 表。
- **Release**（PPM、Sample Peak、True Peak、检波器为 Sample Peak 或 True Peak 的 Custom；0.1 到 5 秒；默认 1.5 秒）- 设置峰值过后回落 20 dB 所需的时间。数值越大越容易读取峰值；数值越小越能贴近音乐的变化。在 Custom 中，它控制检波器的回落，之后再由指针自身的响应决定运动。1.5 秒对应 DIN 表以及标准数字峰值表。
- **Needle Response**（Custom；1 到 3000 ms；默认 300 ms）- 设置检波器变为新的恒定电平后，指针首次达到该电平 99% 所需的时间。调低会加快指针，调高会减慢指针。整体运动还受 RMS 平均时间和峰值释放时间影响。
- **Overshoot**（Custom；0 到 25%；默认 1.25%）- 设置指针超出新的恒定检波电平的幅度，以电平变化量的百分比表示。调高会让指针跳动得更明显；设为 0 时，指针会逐渐靠近而不超出。
- **Dial**（Custom；默认 VU）- 独立于检波器和指针运动，选择 **VU**、**DIN**、**BBC**、**dB** 或 **dBFS** 刻度。VU、DIN 和 BBC 使用下表中的刻度。dB 的 0 对应 **Reference**，上端为 0 dBFS。dBFS 的上端为 0 dBFS；当 **Detector** 为 True Peak 时，读数以 dBTP 显示。
- **Reference**（VU、PPM、RMS、dBFS 刻度以外的 Custom；-30 到 0 dBFS；默认 -14 dBFS）- 设置与电平表基准刻度对应的数字电平。默认值适合大多数市售成品录音；若采用录音棚常用的 -18 或 -20 dBFS 基准（参见系统预设），即使是普通 CD，指针也常常停在刻度顶端附近。当响亮的录音把指针推到刻度顶端时调高该值；当安静的录音几乎不能让指针移动时调低该值。
- **Range**（DIN 或 dB 刻度下的 PPM、RMS、Sample Peak、True Peak、DIN、dB 或 dBFS 刻度的 Custom；20 到 60 dB；默认 40 dB）- 设置刻度向下延伸的范围。加宽可看到安静的段落；收窄可让刻度上部显示得更开。
- **PPM Scale**（PPM；默认 DIN）- 选择 PPM 的刻度：**DIN**、**BBC** 或 **dB**（参见可视化指南）。
- **Peak Hold**（PPM、RMS、Sample Peak、True Peak、Custom；0 到 10 秒；默认 1 秒）- 设置峰值标记在最近最高读数处停留的时长，以及过载灯保持点亮的时长。设为 0 可关闭该标记，此时过载灯保持点亮 1 秒。
- **Needle**（Loudness；默认 Momentary）- 选择指针显示的内容。**Momentary** 跟随最近 0.4 秒的响度；**Short-term** 显示最近 3 秒的值，动作更平稳。
- **Target**（Loudness；-36 到 -10 LUFS；默认 -23 LUFS）- 设置刻度上标记的响度，并以该值为基准排列刻度。-23 LUFS 是 EBU R128 广播标准，许多流媒体服务使用 -14 LUFS 左右的数值。
- **Scale**（Loudness；默认 EBU +9）- 选择响度刻度的宽度。**EBU +9** 覆盖 **Target** 下方 18 LU 到上方 9 LU 的范围；**EBU +18** 覆盖下方 36 LU 到上方 18 LU 的范围，适合动态范围宽或响度很高的素材。

### 可视化指南

- 每个声道各有一个电平表，每行最多显示 4 个，最多支持 16 个声道。
- 电平遵循常见的数字惯例，满刻度正弦波读数为 0 dBFS，因此稳定的正弦波在除 Loudness 之外的所有模式下读数相同。
- 各模式指针移动的速度不同：

| 模式 | 指针移动 | 刻度 |
|---|---|---|
| VU | 缓慢。约 0.3 秒内达到新电平，显示平均电平（IEC 60268-17）。 | -20 到 +3 VU。0 VU = **Reference**。 |
| PPM | 基于 IEC 60268-10 的近似实现。以 **Attack** 设定的速度快速上升；默认值 5 毫秒下，10 毫秒的突发信号读数比稳定音低约 1 dB，与 DIN 表一致。在 **Release** 时间内回落 20 dB。 | 由 **PPM Scale** 选择。**DIN**：-9 刻度 = **Reference**，0 在其上方 9 dB。**BBC**：刻度 1 到 7，2 到 7 之间每格 4 dB，1 到 2 之间为 6 dB，刻度 4 = **Reference**。**dB**：0 刻度 = **Reference**，从其下方 **Range** 的范围到 +5 dB。 |
| RMS | 显示 **Integration** 时间内的平均功率，不做额外平滑处理。 | 刻度 0 = **Reference**。 |
| Sample Peak | 立即跳到最高的采样值。 | 刻度顶端 = 0 dBFS。 |
| True Peak | 与 Sample Peak 类似，但还会估算采样点之间的峰值。读数可能超过 0 dBFS；这类峰值可能在 DAC 或转换过程中产生削波。 | 刻度顶端 = 0 dBFS。 |
| Loudness | 按 ITU-R BS.1770 和 EBU R128 的定义以 LUFS 显示响度。 | 由 **Target** 和 **Scale** 决定；读数以 LUFS 显示。 |
| Custom | 跟随 **Detector** 的电平，速度由 **Needle Response** 决定，跳动幅度由 **Overshoot** 决定。默认设置下指针运动与 VU 相同。 | 独立于指针运动，由 **Dial** 选择。 |

- 峰值标记会在 **Peak Hold** 时间内显示最近的最高读数。电平超过 0 dBFS 时过载灯会点亮，并在 **Peak Hold** 时间内保持点亮；**Peak Hold** 为 0 时保持 1 秒。
- 在 Loudness 模式下，第一个电平表显示整段节目。它的指针遵循 **Needle** 设置，并列出 Momentary（M）、Short-term（S）、Integrated（I）、Loudness Range（LRA）、最大 True Peak 和已测量时长，以及一个 **Reset** 按钮。Integrated 和 LRA 会在测量到足够长度的音频后出现。
  - 对于单声道、立体声和 5.1（声道顺序为 L、R、C、LFE、Ls、Rs），这些数值遵循标准的声道加权。对于其他声道数，所有声道以相同权重相加，因此这些数值仅供参考。
  - 第一个之后的电平表分别显示每个声道，是不做声道加权或门限处理的参考值。
- Integrated、LRA 和最大 True Peak 会持续累积，直到按下 **Reset**、更改 **Mode**、采样率或声道数发生变化，或音频处理重新启动。
- 处理暂停期间不计入测量：包括静音时的省电暂停、Master Bypass 开启或 Analog Meter 关闭期间，以及在设置中开启 **隐藏时跳过显示类 DSP**（默认开启）时 Effect Pipeline 未显示的期间（例如显示音乐库、窗口最小化或使用迷你播放器时）。恢复后，读数会从暂停前的位置继续。

## Chroma Spiral

在不改变声音的情况下，显示音乐中的频率成分落在 12 个音名及各个八度的什么位置。可以用它查看谐波重叠时哪些音名位置在发声、比较人声与贝斯线，或查看乐器的音域。

### 聆听指南

- 持续播放一个音，观察它和谐波亮起的位置。一个音也可能点亮多个音名；这不代表每个音都被单独演奏。
- 播放和弦或旋律，观察活跃位置如何变化。图形可以提供调性感的线索，但不会识别和弦名称或调性。
- 检查调音时，可以观察亮点或填充区域的外缘是否落在音名刻度之间。若要以音分读取单个基频的偏差，请使用 Pitch Meter。
- 用鼠标、手指或触控笔按住图形，即可试听所选螺旋位置对应的正弦波。拖动可改变音高；松开或取消手势后，声音便会停止。所有 **Color** 选项都支持此预听操作。

### 参数

- **Color** - 选择频谱的绘制方式。所有选项都会显示相同的背景螺旋参考线，即使静音时也仍然可见。
  - **Normal**（默认）：以主题的图形线条颜色将每个频率单元显示为圆点。亮度随该单元的强度变化，圆点面积也与强度成正比，让较弱的频率更容易看见。达到最高强度时，圆点半径延伸到与下一圈螺旋之间距离的一半。
  - **Normal 2**：从每个频率在螺旋上的位置向外填充到相应强度，使用图形线条颜色，但不描绘数据轮廓线。
  - **Note Colors**：与 Normal 一样显示圆点，但每个音名使用不同颜色，并在各个八度重复。
- **Lowest Octave**（1～8，默认 1）- 设置最内侧的八度。调高可专注于高音。
- **Highest Octave**（1～9，默认 7）- 设置最外侧的八度。调低可专注于低音和中频。调整时两个界限会保持正确顺序。
- **Frequency Tilt**（-6～+6 dB/oct，步长 0.5，默认 +3）- 调整 100 Hz 以上频率的显示电平，不改变声音。正值让高频在图中更突出，负值使其不那么突出。设为 0 时不按频率修正。
- **Level Range**（6～96 dB，步长 1 dB，默认 24）- 设置动态显示范围的宽度。缩小可突出电平差异；扩大则能在强成分旁看到较弱成分。
- **Display Floor**（-120～-24 dB，步长 1 dB，默认 -60）- 设置安静片段中动态显示范围的下限最多能降到多低。调低后，选定 **Level Range** 内较弱的成分也可能显示出来。显示范围仍会跟随近期峰值，因此不能保证每个微弱成分都可见。

### 可视化指南

- 每绕一圈就是一个八度。C 位于正上方，音名沿顺时针排列；越靠内音越低。C 标记显示八度编号。
- 在 **Normal** 和 **Note Colors** 中，圆点越亮、越大，表示该位置的成分越强，音名之间也是如此。在 **Normal 2** 中，成分越强，填充区域越向外延伸；无需单独的轮廓线，也能从外缘看出频谱变化。
- 圆点亮度和面积以及填充区域的延伸范围，表示跟随近期峰值变化的相对强度，并非绝对电平。
- 低音区相邻音更难区分，响应也更慢，可能看起来混在一起。

### 可视化显示
- 将鼠标悬停在显示区域上，或触摸并拖动，即可读取该位置的数值。

## Level Meter

实时显示音乐的数字信号电平。它适合检查加上效果后的电平，并在削波变成可闻失真之前发现风险。

### 可视化指南
- 信号电平越大，水平条越向右延伸
- 白色标记会保持新的峰值一秒钟，然后平滑下降
- OVERLOAD 表示信号超过安全的数字范围，可能产生失真
- 为了干净播放，尽量避免红色电平或 OVERLOAD 警告频繁出现；实际聆听音量请在播放设备上调节

## Note Spectrogram

以滚动钢琴卷帘图显示 A0 到 C8 的估算基频（F0），而不改变音频。可用来跟踪和弦构成音、人声与旋律线条、低音线条，以及跨越不同八度相互叠加的音符，还可选择按音色着色和突出显示。

### 聆听指南

- **和弦与旋律**：和弦显示为同一时刻的多条亮线；旋律和低音线会形成在音符行之间移动的轨迹。
- **跟踪人声或低音**：选择 **Instrument (3)**，或保留 **Note Colors** 并在 **Highlight** 中选择 **Vocal** 或 **Bass**。需要更细的音色分组时，使用 **Instrument (9)**。
- **估算的准确度**：音高和音色估算是聆听时的视觉参考，而不是精确的扒谱。声音重叠、打击乐或噪声可能使估算不明确，鼓也不属于分类对象。音色估算会参考先前的音符，因此在刚启用或刚移动播放位置时可靠性较低；估算一旦完成，就不会再修改。

### 音色分组

**Instrument (3)** 将音高分为 **Vocal**、**Bass** 和 **Other**（下列除 Vocal 和 Bass 以外的所有组）。

**Instrument (9)** 将音高分为九组：
- **Vocal**：真实录制的人声演唱，包括独唱和合唱。
- **Bass**：原声、电声和合成器贝斯。
- **Guitar**：原声吉他、清音电吉他和失真吉他。
- **Piano**：原声钢琴、电钢琴、羽管键琴和 clavinet。
- **Strings**：弦乐独奏与合奏、拨弦、竖琴和合成弦乐。
- **Wind**：铜管与木管，包括萨克斯管和长笛。
- **Synth**：合成器主奏音色和铺底音色。
- **Organ**：风琴、手风琴和口琴。
- **Other**：有音高打击乐（钢片琴、颤音琴）、合成的合唱与人声音色、合成器效果、管弦乐齐奏击音、民族乐器和音效。

### 参数

- **Color** - 选择显示颜色，不改变音高检测（切换时会为现有历史记录重新着色）：
  - **Normal**（默认）：主题的图形绘制颜色。
  - **Note Colors**：按音名分别着色，在各个八度重复。
  - **Instrument (3)**：按 Vocal、Bass 和 Other 着色。
  - **Instrument (9)**：按上述九个音色组着色。
- **Highlight** - 突出显示特定组（**Vocal**、**Bass**、**Other (3)**、**Guitar**、**Piano**、**Strings**、**Wind**、**Synth**、**Organ** 或 **Other (9)**）：音符属于该组的可能性越低，颜色就越接近中性灰色，表示音量的粗细保持不变。**None**（默认）不突出显示。
  - 发音起点和音色分析会额外占用 CPU。要尽量降低 CPU 占用，请关闭 **Onsets**，选择 **Normal** 或 **Note Colors**，并将 **Highlight** 设为 **None**。
- **Pitch Resolution** - 选择音高方向的显示精度，不清除历史记录：
  - **1/12 Octave**（默认）：每个半音一行。
  - **High**：将音高显示在估算的音分位置，可以看到颤音和弯音。
- **Layout** - **Horizontal**（默认，键盘在底部，历史记录向上滚动）或 **Vertical**（键盘在右侧，历史记录向左滚动）。
- **Volume** - 用条带粗细和键盘边缘的半圆仪表表示相对音量（默认开启）。关闭后，条带粗细固定。
- **Onsets** - 用三角形标出估算的音符起音（Horizontal 中为 ▼，Vertical 中为 ▶；默认关闭）。三角形底边的中点表示起音的时间和音高，因此持续音高上的反复起音会分别标出。关闭后，只要 Instrument 类 **Color** 或 **Highlight** 仍需要，音色分析就会继续运行。
- **Time Span**（1 到 10 s；默认 2 s）- 钢琴卷帘图上可见历史记录的时长。
- **Lowest Note** / **Highest Note** - 设置分析和显示的音域（默认：E1 到 G6）。

### 可视化指南

- **音高的更新**：新声音会立即显示，并在约 40、80 和 160 ms 后结合随后的音频进行修正。这不会增加显示延迟，也不影响 **将画面与音频同步**。
- **网格与键盘**：每个 C 位置的线标出八度边界，E–F 辅助线在所有模式中都可见，黑键对应的行使用较暗的背景。琴键会按当前音高的置信度亮起。
- **颜色的深浅**：颜色的深浅始终表示音高的置信度。输入过小而无法分析时，钢琴卷帘图保持黑暗。
- **音色颜色与突出显示**：音色颜色按估算概率混合各组的颜色。音色估算完成后，历史记录中的对应位置会显示颜色；等待分类的音符以中性灰色显示。图例列出当前显示的组；突出显示期间，后面还会接着显示 **Highlight:** 和所选的组。将鼠标悬停在图例中的任意组上，可临时突出显示该组。
- **音量条带**：开启 **Volume** 时，条带粗细对应 24 dB 的相对范围；键盘边缘的柔和半圆会随当前音量立即升高，并以 20 dB/s 的速度下降。

### 可视化显示
- 将鼠标悬停在历史区域上，或触摸并拖动，即可读取音名、时间、**Salience**（音高的置信度）、**Level**（dB），以及在音色分析运行时各组的估算概率：**Instrument (3)** 下为 **Vocal**、**Bass** 和 **Other**，其他情况下为九个组；若 **Highlight** 组不在其中，还会追加该组（没有估算结果的音符显示 **Not classified**）。

## Oscilloscope

实时显示声音的波形，让你在聆听的同时看到节拍、强烈的瞬态和音量变化。波形重复时，可用触发设置让画面保持稳定。

### 使用指南
- 将 **Display Time** 设为 1–20 ms、**Trigger Mode** 设为 **Auto**，可观察重复的波形周期。
- 将 **Display Time** 设为 1,000–10,000 ms、**Trigger Mode** 设为 **Off**，可看到节拍和音量包络从右向左平滑滚动。
- 在 **Auto** 和 **Normal** 模式下，收集满 **Display Time** 的时长后才会更新波形。

### 参数
- **Display Time**（1 到 10,000 ms）- 显示的时间跨度。较短的值显示单个波形周期，较长的值显示整体包络。
- **Trigger Mode**：
  - **Auto**：即使没有触发事件也会持续更新。
  - **Normal**：只在发生触发时更新，并保持上一次捕获的波形，直到下一次触发。
  - **Off**：从右向左连续滚动，触发设置不起作用。
- **Trigger Level**（-1 到 1）- 开始捕获的归一化振幅阈值（根据单声道信号或左右声道的平均信号检测）。
- **Trigger Edge** - **Rising**（信号向上越过时触发）或 **Falling**（信号向下越过时触发）。
- **Holdoff**（0.1 到 10 ms）- 两次触发之间的最短等待时间。
- **Display Level**（-96 到 0 dB；默认 0 dB）- 设置显示区域上下边缘对应的电平。0 dB 显示完整的 ±1 范围；数值越低，越能放大观察较小的信号。
- **Vertical Offset**（-1 到 1）- 上下移动波形；正值使波形上移。

### 可视化指南
- **横轴**：以毫秒或秒为单位的时间。
- **纵轴**：归一化振幅，按 **Display Level** 缩放，并按 **Vertical Offset** 偏移。
- **线条与包络带**：显示时间较短时绘制连续的波形线；较长时绘制填充的最小/最大值带，即使许多采样落在同一像素列，短暂的峰值也仍然可见。

### 可视化显示
- 将鼠标悬停在图表上，或触摸并拖动，即可读取该位置的时间和振幅（显示时间较长时为 Minimum/Maximum）。

## Pitch Meter

在两秒滚动钢琴卷帘图中一次跟踪一个基频（F0），且不会改变音频。可用来检查独唱或独奏乐器的调音和音高变化。

### 聆听指南

- 演奏或唱出一个持续的单音，观察线条是保持在音符行的中央，还是向偏高或偏低方向漂移。
- 颤音、滑音和弯音会显示为跨越音符行的平滑曲线。
- Pitch Meter 只跟踪一个最突出的音高，因此和弦、密集的混音或打击乐可能使线条中断或跳到其他八度；复音素材请使用 [Note Spectrogram](#note-spectrogram)。
- 立体声输入取前两个声道的平均值进行分析（单声道输入直接使用），因此两个声道中极性相反的声音可能相互抵消，不留下轨迹。

### 参数

- **Color** - 切换线条颜色，不影响检测：**Normal**（默认的主题线条颜色）、**Heatmap**（24 dB 范围内的相对音量）或 **Note Colors**（音名颜色）。
- **Layout** - **Horizontal**（默认，键盘在底部，历史记录向上滚动）或 **Vertical**（键盘在右侧，历史记录向左滚动）。
- **Reference A4**（400 到 480 Hz；默认 440 Hz）- 音名和音分偏差所使用的调音基准。
- **Lowest Note** / **Highest Note** - 设置分析和显示的音域（默认：C2 到 C7；完整范围：A0 到 C8）。

### 可视化指南

- 线条位置可连续显示半音之间的音高；置信度越高，线条越亮，无声或没有音高的声音会使线条中断。
- 读数显示最近的音名（按音名着色）和以音分表示的调音偏差（`+` 偏高，`-` 偏低；例如 `+3.5 cent`）。

### 可视化显示
- 将鼠标悬停在显示区域上，或触摸并拖动，即可读取该位置的数值。

## Rhythm Analyzer

求出音乐的速度，并逐拍显示鼓和乐器的发音位置，以及各声部超前或滞后的程度。除非开启 **Metronome Click**，否则不会改变声音。可用它查出曲目的 BPM、测量摇摆（swing）程度、查看军鼓是否落在节拍之后，或发现加花（fill）和段落转换。

### 聆听指南

- **确认速度**：播放一首节拍稳定的曲目。已确认的 BPM 和 **adopted** 线会比声音晚约 1～2 秒出现，**LOCKED** 表示正在为指示灯和点击音提供节拍。如果分析器锁定在你感受速度的两倍或一半上，请比较 **×½**、**×2** 和 **strongest**。
- **用耳朵确认节拍位置**：开启 **Metronome Click**，可以在每个检测到的节拍上听到点击音。用点击音聆听时，请把 Rhythm Analyzer 放在效果链的末尾；导出处理后的音频文件之前，请关闭 **Metronome Click**。
- **修正倍速或半速锁定**：如果慢抒情曲锁定在两倍速度上，请把 **Max BPM** 调低到该值以下；如果快歌锁定在一半速度上，请把 **Min BPM** 调高到该值以上。
- **读取律动和细微计时**：程序化编写的节拍会落在轨道中线附近，**jitter** 接近 0 ms。如果军鼓始终比底鼓晚 15 ms，第 2、4 拍的 **Mid** 点就会出现在轨道中线上方，Beat lens 中也会出现 **+15** 标记。
- **读取摇摆**：**swing** 显示反拍延后的比例（1.00:1 为均匀，2.00:1 为三连音 shuffle）。在摇摆的律动中，反拍发音会聚集在 Beat lens 的 **⅔** 列，而不是 **&** 列。
- **发现加花和段落转换**：圆环（**◎**）标出在一个或两个周期前的同一拍位置没有出现过的发音，使鼓的加花和段落转换在 **Echo rows** 中格外醒目。
- **出现 searching 时**：新的节拍指示和点击音会停止，但分析仍在继续；速度、Timing lanes 和 Beat lens 保持显示，可信度降低时会变淡。静音时，当前节拍的读数和 Tempogram 的列会被清除；声音恢复后分析重新开始。

### 参数

- **Min BPM**（40 到 192；默认 40）/ **Max BPM**（50 到 240；默认 240）- 速度的搜索范围（Max BPM 至少保持为 Min BPM 的 1.25 倍；更改任一项都会重新开始分析）。
- **Metronome Click**（默认关闭）- 在每个检测到的节拍上，将短促的 −10 dBFS 点击音混入第 1、2 声道（单声道时仅第 1 声道），其他声道不变。
- **Span (beats)**（4、6、8、12 或 16；默认 8）- Timing lanes 和 Echo rows 每一行显示的拍数（例如两小节 4/4 拍用 8，两小节 3/4 拍用 6）。
- **Tempogram**、**Timing lanes**、**Echo rows**、**Beat lens** - 分别显示或隐藏各显示面板（默认开启 Timing lanes 和 Beat lens；隐藏面板不会停止分析）。

### 可视化指南

在横向较宽的显示中，**Beat lens** 位于 Timing lanes 的右侧；在纵向较高的显示中，所有面板纵向堆叠。发音分为 **High**（踩镲、镲片）、**Mid**（军鼓、人声、乐器）和 **Low**（底鼓、贝斯）三行：
- **表头**：显示节拍指示灯（可信度越低越暗，**searching** 期间为空心）、已确认的 BPM（**LOCKED** 或 **searching**）、**×½**、**×2**、Tempogram 中的 **strongest** 候选、**swing** 比例（根据最近 32 拍计算）、**jitter**（发音围绕其平均位置的典型散布，单位为 ms）以及符号说明。尚未得到的值显示为 —。
- **Tempogram**：显示最近 20 秒内各速度获得的支持，**Time** 从左向右推进，**Tempo (BPM)** 为 30 到 480 的对数刻度，并叠加实线的 **adopted** 速度线和虚线的 **×2** / **×½** 线。亮度表示各速度的相对支持程度，而不是该速度正确的概率。
- **Timing lanes**：显示最近 *N* 拍（**Span (beats)**；标题为 **Last N beats**）的发音；点越大表示越确定是发音，最新的位置是估计值，约 1～2 秒后确定。竖线的高度表示相对于最接近的十六分音符或三连音网格的细微计时，并与前 16 拍的典型计时比较（点线为 **+20** / **−20** ms；高于中线为偏晚，低于中线为偏早；偏差超过 ±30 ms 的发音停留在轨道边缘）。空心圆（**○**）表示无法求出计时的发音（显示在轨道中线），阴影区域表示没有计时分析的区间，圆环（**◎**）表示与 1～2 个周期前相比新出现的发音，竖虚线表示节拍网格重新对齐的位置。
- **Echo rows**：将之前的 *N* 拍周期上下堆叠（最新的在最上方），使重复的小节节奏型排成竖列，加花和变化就会显得突出。**Cycles ago** 从 1 开始为各行编号；隐藏 **Timing lanes** 时，最上面一行是当前周期（0）。每次发音只显示频段，不显示计时。
- **Beat lens**：汇总最近 32 个已确认节拍中，各频段在拍内各位置（**1**、**e**、**&**、**a**、**⅓**、**⅔**）平均偏早（标记在左）还是偏晚（标记在右）（±30 ms 刻度），以及离散程度（阴影条，±1 个标准差）。偏差相对于整个乐队测量；标记越不透明，表示该位置的发音越频繁；发音达到 4 次才会显示该位置；3 ms 或以上的偏差会标注数值。节拍分析可用之前，Beat lens 显示 **waiting for a steady beat**。
- **可信度**：显示变淡表示对分析的把握较低，而不是演奏较松散。
- **Reset**：例如在其他应用中切换曲目时，可用显示区域下方的 **Reset** 按钮清除画面并重新开始分析。EffeTune 的播放器开始播放新曲目时，分析会自动重新开始。

### 可视化显示
- 将鼠标悬停在显示区域上，或触摸并拖动，即可读取数值：Timing lanes 和 Echo rows 显示最近发音是多少拍之前、所属频段和计时（不可用时为 —）；Tempogram 显示速度、**Tempo support** 和 **Adopted** 速度；Beat lens 显示各频段的偏差和离散程度。

### 局限性

- 对于弹性速度（rubato）、古典音乐、钢琴独奏或氛围/无节拍段落，速度和节拍跟踪的把握较低，节拍可能锁定在你感受速度的 2 倍、1/2、2/3 或 3/2 倍上，或锁定在反拍上（可用 **Min BPM** / **Max BPM** 限定范围）。**LOCKED** 不保证节拍正确。
- 当速度持续变化时，节拍会带有轻微延迟地跟随，因此点击音可能略微提前或滞后。
- 在密集的混音和噪声较多的录音中，**Mid** 和 **High** 轨道可能出现多余的点，**Low** 轨道会漏掉一些钢琴低音。
- 分析器跟踪的是拍子，而不是小节线或拍号（不识别第一拍）。
- 支持的采样率：8、11.025、16、22.05、24、32、44.1、48、88.2、96、176.4、192、352.8 和 384 kHz。其他采样率下，音频原样通过，但分析和点击音不可用。

## Spectrogram

用彩色图案显示音乐随时间的变化。颜色表示各频率成分的强弱，纵向位置表示频率高低。

图表以恒定速度从右向左滚动，并显示每秒的刻度。

### 可视化指南
- 颜色表示不同频率的强度：
  - 暗色：较安静的声音
  - 亮色：较响亮的声音
  - 图案会随着音乐变化
- 纵向位置表示频率：
  - 下方：低频
  - 中部：主要乐器
  - 上方：高频
- 使用 **Log (HQ)** 时，相近的低频音会显示为分离得更清楚的频带。由于低频测量时间更长，显示稳定或消退可能需要稍久一些。

### 可视化显示
- 将鼠标悬停在显示区域上，或触摸并拖动，即可读取该位置的数值。

### 可以看到什么
- 旋律：流动的彩色线条
- 节拍：垂直条纹
- 贝斯：底部的明亮区域
- 和声：多条平行线
- 不同乐器会形成各自的图案

### 参数
- **DB Range** - 颜色显示的动态范围（-144dB 到 -48dB）
  - 较低数值：显示更细微的声音
  - 较高数值：集中显示主要声音
- **Points** - 用于显示的 FFT 大小（256 到 16384）
  - 较高数值：频率细节更多，但时间更新较慢
  - 较低数值：动作更快，但频率细节较少
  - 使用 **Log (HQ)** 时，Points 决定短分析窗口；长四倍的窗口可改善低频分离度。
- **Color** - **Normal** 使用主题图形颜色，频率成分越强就越亮。**Heatmap**（默认）使用原有的多色刻度。切换后会重新着色现有历史记录。
- **Frequency Scale** - **Log** 为低频分配更多显示空间。**Log (HQ)** 在保留高频短测量的同时加入更长的测量，可更清晰地分离相近的低频。它需要更多处理，低频变化可能需要更久才出现或消退，但不会改变音频。**Linear** 将相等的频率宽度按相等间距显示。
- **Keyboard** - 在图表右侧显示静态琴键导引，用于查看音名与频率的对应关系。它不会改变分析结果或音频。琴键位置会随 **Log**、**Log (HQ)** 或 **Linear** 调整；**Log (HQ)** 与 **Log** 使用相同的对数间距，使用 **Linear** 时低频琴键看起来更窄。
- 该分析器使用左右声道平均值。单声道输入会直接分析。

## Spectrum Analyzer

实时显示音乐从深沉低频到明亮高频的频率分布。您可以把它看作观察构成音乐整体声音的各个成分。

### 可视化指南
- 左侧表示低频（鼓、贝斯等）
- 中间表示主要频段（人声、吉他、钢琴等）
- 右侧表示高频（镲片、明亮感、空气感等）
- 峰值越高，表示该频率存在感越强
- 较粗的线条表示当前声音
- 较细的线条跟随最近的峰值，并随着声音减弱而平滑下降
- 在 **Bar** 显示中，每个柱形表示显示区域中一个等宽部分的最高电平。**Log** 和 **Log (HQ)** 使用相等的八度宽度，**Linear** 使用相等的频率宽度。
- 柱形上方的细标记表示其最近的峰值，并会平滑下降。
- 使用 **Log (HQ)** 时，相近的低音可能显示为各自独立的峰。由于低频测量时间更长，显示稳定或消退可能需要稍久一些。
- 可以观察不同乐器形成不同频谱图案的方式

### 可视化显示
- 将鼠标悬停在图表上，或触摸并拖动，即可读取该位置的数值。

### 可以看到什么
- 低音下潜：左侧的大幅运动
- 人声旋律：中间区域的活动
- 清晰高频：右侧的闪亮区域
- 完整混音：所有频率如何一起组成整体声音

### 参数
- **DB Range** - 显示灵敏度（-144dB 到 -48dB）
  - 较低数值：显示更细微的声音
  - 较高数值：集中显示主要声音
- **Points** - 显示能把相邻频率分得多细（256 到 16384）
  - 较高数值：频率细节更多，但更新较慢
  - 较低数值：更新更快，但频率细节较少
  - 使用 **Log (HQ)** 时，Points 决定短分析窗口；长四倍的窗口可改善低频分离度。
- **Color** - **Normal**（默认）保留主题图形颜色。**Heatmap** 使较高电平显示得更亮，**Note Colors** 则沿频率轴使用相应音名的颜色。该设置同时适用于 **Line** 和 **Bar**。同时选择 **Bar** 和 **Note Colors** 时，每根柱及其峰值标记都按该频带的中心频率使用单一颜色。
- **Frequency Scale** - **Log** 为低频分配更多显示空间。**Log (HQ)** 在保留高频短测量的同时加入更长的测量，可更清晰地分离相近的低频。它需要更多处理，低频变化可能需要更久才出现或消退，但不会改变音频。**Linear** 将相等的频率宽度按相等间距显示。
- **Display** - 只改变频谱的外观，不会改变分析或音频。
  - **Line**（默认）：将频谱显示为连续线条。
  - **Bar**：将每个显示频段的最高电平显示为柱形。
- **Keyboard** - 在图表下方显示静态琴键导引，用于查看音名与频率的对应关系。它不会改变分析结果或音频。琴键位置会随 **Log**、**Log (HQ)** 或 **Linear** 调整；**Log (HQ)** 与 **Log** 使用相同的对数间距，使用 **Linear** 时低频琴键看起来更窄。
- 该分析器使用左右声道平均值。单声道输入会直接分析。

## Stereo Meter

一个可视化工具，用于观察立体声如何形成空间感。您可以看到声音在扬声器或耳机之间如何展开，为聆听增加一层视觉维度。

### 可视化指南
- **Diamond Display** - 显示音乐运动的主窗口：
  - 中心：非常安静的瞬间，或左右合成信号接近零的瞬间
  - 上/下：左右声道共有的成分，例如居中或接近单声道的内容
  - 左/右：左右声道的差分或反相成分
  - 明显偏向某一侧的声音可能出现在带标签的角落方向
  - 绿色点会随当前音乐移动
  - 白色线条追踪音乐峰值
  - 白色峰值线按每个音频采样点衰减，因此无论处理块大小如何变化，其运动都保持一致
- **Correlation Bar**（左侧）
  - 显示左右声道相关性
  - 上方（+1.0）：左右几乎相同，通常听起来偏居中
  - 中间（0.0）：声道关系较弱，常见于宽阔氛围或左右不同内容
  - 下方（-1.0）：左右几乎相反极性，用扬声器播放时可能听起来变弱
- **Balance Bar**（底部）
  - 显示一侧扬声器是否比另一侧更响
  - 中央：两侧音量相同
  - 左/右：某一侧更强
  - 数值以分贝（dB）显示音量差

### 可以看到什么
- **中心声音**：中间附近较强的纵向运动
- **宽阔声音**：显示区域中大范围的活动
- **特殊效果**：角落附近出现的有趣图案
- **扬声器平衡**：底部条指示的方向
- **声道相关性**：左侧相关性条显示的状态

### 参数
- **Window**（10-1000 ms）- 显示中使用的最近音频长度
  - 较低值：更容易看到快速变化
  - 较高值：更容易看到整体模式
  - 默认 100 ms 适合大多数音乐
- **Gain**（0～24 dB，默认 0 dB）- 只放大菱形图中的点和峰值线。提高数值可以更清楚地看到较弱的图案，不会改变音频或相关性、平衡度读数。

### 享受音乐
1. **观察不同风格**
   - 古典音乐常显示较平稳、均衡的图案
   - 电子音乐可能形成大胆宽阔的形状
   - 现场录音可能显示自然空间的运动

2. **发现声音特性**
   - 看不同专辑如何使用立体声效果
   - 留意有些歌曲听起来比其他歌曲更宽阔
   - 看乐器如何在扬声器之间移动

3. **加深体验**
   - 用不同耳机比较立体声呈现方式
   - 比较喜欢歌曲的新旧录音
   - 观察不同聆听位置带来的显示变化

## 这些工具的有趣用法

1. 探索音乐
   - 观察不同流派产生的不同图案
   - 比较原声音乐和电子音乐的差异
   - 观察乐器占据哪些频率区域

2. 理解声音
   - 用眼睛观察电子音乐中的低频
   - 看人声旋律如何穿过显示区域
   - 观察鼓声如何形成尖锐图案

3. 扩展聆听体验
   - 用 Level Meter 检查添加效果后的信号峰值
   - 看 Spectrum Analyzer 随音乐跳动
   - 用 Spectrogram 制造像灯光秀一样的视觉体验

请记住：这些工具旨在为聆听加入视觉维度，让您更享受音乐。尽情探索，发现观察喜爱音乐的新方式吧！
