# 分析器插件

这些插件让您用可视化方式观察音乐。它们会显示声音的不同侧面，帮助您理解正在听到的内容，也让聆听过程更有参与感。

## 插件列表

- [Analog Meter](#analog-meter) - 用带有 VU、PPM、峰值和响度刻度的指针表显示声道电平
- [Chroma Spiral](#chroma-spiral) - 在音名与八度的螺旋上显示频率成分
- [Level Meter](#level-meter) - 显示数字信号电平和可能的削波
- [Note Spectrogram](#note-spectrogram) - 以钢琴卷帘图显示随时间变化的估算音高
- [Oscilloscope](#oscilloscope) - 实时显示波形
- [Pitch Meter](#pitch-meter) - 随时间跟踪一个基频及其调音偏差
- [Spectrogram](#spectrogram) - 用彩色图案显示音乐变化
- [Spectrum Analyzer](#spectrum-analyzer) - 显示音乐中的不同频率
- [Stereo Meter](#stereo-meter) - 可视化立体声平衡与声道相关性

## Analog Meter

在不改变声音的情况下，用经典的指针式电平表显示每个声道的电平。可以用它跟踪音乐音量随时刻的变化，也可以查看播放内容在广播和流媒体所用的刻度上的读数：VU、PPM、峰值和响度（LUFS）。

### 使用方法

- **用 VU 跟踪平均电平**：在整首歌曲中观察指针。安静的主歌和响亮的副歌会显示出明显差异，而短促的鼓点几乎不会让指针移动。
- **用 True Peak 检查削波**：把 Analog Meter 放在 EQ 和增益类效果之后，播放曲目中最响的部分。如果读数超过 0 dBFS 或过载灯点亮，说明信号链可能会削波；降低增益，直到峰值保持在 0 dBFS 以下，并留出一些余量，例如 -1 dBFS。
- **用 Loudness 比较歌曲**：将 **Target** 设为某个流媒体参考值，例如 -14 LUFS，在歌曲或专辑开始处按下 **Reset**，然后完整播放。Integrated 值显示整体响度，最大 True Peak 显示最高峰值，可作为在专辑或播放列表中统一音量的参考。LRA 可以比较各曲目响度变化范围的宽窄。

### 系统预设

点击效果标题栏中的**效果预设**，即可一步把电平表设为常见的标准规格。选择会更改 **Mode** 的预设时，测量会重新开始；在 Loudness 预设之间切换时，测量会继续进行。

- **Studio VU (-18 dBFS)** - 0 VU 对准 -18 dBFS 的 VU，这是录音棚常用的校准基准（EBU R68），适合预留充足余量的录音。
- **SMPTE VU (-20 dBFS)** - 0 VU 对准 -20 dBFS 的 VU（SMPTE RP 155），是北美录音棚和广播的惯例。
- **Hot VU (-14 dBFS)** - 即默认设置：0 VU 对准 -14 dBFS 的 VU，适合大多数市售成品录音。
- **Loud Master VU (-8 dBFS)** - 0 VU 对准 -8 dBFS 的 VU，用于响度被推到极限的现代 CD 和流行音乐母带，避免指针一直顶在上端。
- **DIN PPM** - DIN 表（**Attack** 5 毫秒、1.5 秒回落 20 dB、DIN 刻度），-9 刻度对准 -18 dBFS，因此 0 刻度对应 -9 dBFS。刻度向下延伸到 -50。
- **BBC PPM** - BBC 表（**Attack** 10 毫秒、2.8 秒回落 24 dB、BBC 刻度），刻度 4 对准 -18 dBFS，因此刻度 6 对应 -10 dBFS。
- **Nagra Modulometer** - Nagra 磁带录音机的调制表（**Attack** 7.5 毫秒、-30 到 +5 dB 的 dB 刻度），0 dB 对准 -18 dBFS。**Release** 采用与 DIN 相同的 1.5 秒。
- **K-20** - 在 RMS 表上使用 Bob Katz 的 K-System，0 对准 -20 dBFS，刻度向下延伸到 -60 dBFS。适合动态范围宽的录音。
- **K-14** - 同上，0 对准 -14 dBFS，刻度到 -60 dBFS。适合一般的流行音乐。
- **K-12** - 同上，0 对准 -12 dBFS，刻度到 -60 dBFS。适合为广播而大幅压缩的素材。
- **Digital Peak** - 标准数字峰值表（IEC 60268-18），显示 -60 到 0 dBFS，峰值标记保持 2 秒。
- **True Peak Clip Watch** - 放大 True Peak 刻度顶部的 20 dB，并使用最长的峰值保持时间（10 秒），便于在调整 EQ 或增益后发现超过 0 dBFS 的峰值。
- **EBU R128 (-23 LUFS)** - 以欧洲广播标准为目标值的 Loudness，使用 EBU +9 刻度。
- **EBU R128 +18 Scale** - 目标值相同，改用更宽的 EBU +18 刻度，适合古典音乐等动态范围宽的素材。
- **TV (-24 LKFS)** - 以美国（ATSC A/85）和日本（ARIB TR-B32）电视所用的 -24 LKFS 为目标值的 Loudness。
- **Streaming (-14 LUFS)** - 以 -14 LUFS 为目标值的 Loudness，接近许多音乐流媒体服务的音量标准化水平，指针使用更平稳的 Short-term。
- **Streaming (-16 LUFS)** - 以流媒体和播客推荐的 -16 LUFS（AES TD1008）为目标值的 Loudness，指针使用 Short-term。

### 参数

只显示适用于当前所选 **Mode** 的控件。

- **Mode** - 选择电平表类型：**VU**（默认）、**PPM**、**RMS**、**Sample Peak**、**True Peak** 或 **Loudness**。每种模式的指针移动方式和刻度都不同（参见可视化指南）。切换模式会重新开始测量。
- **Integration**（RMS；0.05 到 3 秒；默认 0.3 秒）- 设置取平均的时间。数值越大指针越稳定、动作越慢；数值越小则对变化的反应越快。
- **Attack**（PPM；1 到 20 毫秒；默认 5 毫秒）- 以读数比稳定音低 2 dB 的音爆长度来设置 PPM 指针上升的速度。数值越小，短促峰值的读数越接近其真实电平；数值越大，短促峰值的读数越低。5 毫秒对应 DIN 表。
- **Release**（PPM、Sample Peak、True Peak；0.1 到 5 秒；默认 1.5 秒）- 设置峰值过后指针回落 20 dB 所需的时间。数值越大越容易读取峰值；数值越小越能贴近音乐的变化。1.5 秒对应 DIN 表以及标准数字峰值表。
- **Reference**（VU、PPM、RMS；-30 到 0 dBFS；默认 -14 dBFS）- 设置与电平表基准刻度对应的数字电平。默认值适合大多数市售成品录音；若采用录音棚常用的 -18 或 -20 dBFS 基准（参见系统预设），即使是普通 CD，指针也常常停在刻度顶端附近。当响亮的录音把指针推到刻度顶端时调高该值；当安静的录音几乎不能让指针移动时调低该值。
- **Range**（DIN 或 dB 刻度下的 PPM、RMS、Sample Peak、True Peak；20 到 60 dB；默认 40 dB）- 设置刻度向下延伸的范围。加宽可看到安静的段落；收窄可让刻度上部显示得更开。
- **PPM Scale**（PPM；默认 DIN）- 选择 PPM 的刻度：**DIN**、**BBC** 或 **dB**（参见可视化指南）。
- **Peak Hold**（PPM、RMS、Sample Peak、True Peak；0 到 10 秒；默认 1 秒）- 设置峰值标记在最近最高读数处停留的时长，以及过载灯保持点亮的时长。设为 0 可关闭该标记，此时过载灯保持点亮 1 秒。
- **Needle**（Loudness；默认 Momentary）- 选择指针显示的内容。**Momentary** 跟随最近 0.4 秒的响度；**Short-term** 显示最近 3 秒的值，动作更平稳。
- **Target**（Loudness；-36 到 -10 LUFS；默认 -23 LUFS）- 设置刻度上标记的响度，并以该值为基准排列刻度。-23 LUFS 是 EBU R128 广播标准，许多流媒体服务使用 -14 LUFS 左右的数值。
- **Scale**（Loudness；默认 EBU +9）- 选择响度刻度的宽度。**EBU +9** 覆盖 **Target** 下方 18 LU 到上方 9 LU 的范围；**EBU +18** 覆盖下方 36 LU 到上方 18 LU 的范围，适合动态范围宽或响度很高的素材。

### 可视化指南

- 每个声道各有一个电平表，每行最多显示 4 个，最多支持 16 个声道。
- 电平遵循常见的数字惯例，满刻度正弦波读数为 0 dBFS，因此稳定的正弦波在除 Loudness 之外的所有模式下读数相同。
- 各模式指针移动的速度不同：

| 模式 | 指针移动 | 刻度 |
|---|---|---|
| VU | 缓慢。约 0.3 秒内达到新电平，显示平均电平（IEC 60268-17）。 | -20 到 +3 VU。0 VU = **Reference**。 |
| PPM | 基于 IEC 60268-10 的近似实现。以 **Attack** 设定的速度快速上升；默认值 5 毫秒下，10 毫秒的突发信号读数比稳定音低约 1 dB，与 DIN 表一致。在 **Release** 时间内回落 20 dB。 | 由 **PPM Scale** 选择。**DIN**：-9 刻度 = **Reference**，0 在其上方 9 dB。**BBC**：刻度 1 到 7，2 到 7 之间每格 4 dB，1 到 2 之间为 6 dB，刻度 4 = **Reference**。**dB**：0 刻度 = **Reference**，从其下方 **Range** 的范围到 +5 dB。 |
| RMS | 显示 **Integration** 时间内的平均功率，不做额外平滑处理。 | 刻度 0 = **Reference**。 |
| Sample Peak | 立即跳到最高的采样值。 | 刻度顶端 = 0 dBFS。 |
| True Peak | 与 Sample Peak 类似，但还会估算采样点之间的峰值。读数可能超过 0 dBFS；这类峰值可能在 DAC 或转换过程中产生削波。 | 刻度顶端 = 0 dBFS。 |
| Loudness | 按 ITU-R BS.1770 和 EBU R128 的定义以 LUFS 显示响度。 | 由 **Target** 和 **Scale** 决定；读数以 LUFS 显示。 |

- 峰值标记会在 **Peak Hold** 时间内显示最近的最高读数。电平超过 0 dBFS 时过载灯会点亮，并在 **Peak Hold** 时间内保持点亮；**Peak Hold** 为 0 时保持 1 秒。
- 在 Loudness 模式下，第一个电平表显示整段节目。它的指针遵循 **Needle** 设置，并列出 Momentary（M）、Short-term（S）、Integrated（I）、Loudness Range（LRA）、最大 True Peak 和已测量时长，以及一个 **Reset** 按钮。Integrated 和 LRA 会在测量到足够长度的音频后出现。
  - 对于单声道、立体声和 5.1（声道顺序为 L、R、C、LFE、Ls、Rs），这些数值遵循标准的声道加权。对于其他声道数，所有声道以相同权重相加，因此这些数值仅供参考。
  - 第一个之后的电平表分别显示每个声道，是不做声道加权或门限处理的参考值。
- Integrated、LRA 和最大 True Peak 会持续累积，直到按下 **Reset**、更改 **Mode**、采样率或声道数发生变化，或音频处理重新启动。
- 处理暂停期间不计入测量：包括静音时的省电暂停、Master Bypass 开启或 Analog Meter 关闭期间，以及在设置中开启 **隐藏时跳过显示类 DSP**（默认开启）时 Effect Pipeline 未显示的期间（例如显示音乐库、窗口最小化或使用迷你播放器时）。恢复后，读数会从暂停前的位置继续。

## Chroma Spiral

在不改变声音的情况下，显示音乐中的频率成分落在 12 个音名及各个八度的什么位置。可以用它观察重叠的谐波、比较人声与贝斯的音域，或查看乐器的频率分布。

### 使用方法

- 持续播放一个音，观察它和谐波亮起的位置。一个音也可能点亮多个音名；这不代表每个音都被单独演奏。
- 播放和弦或旋律，观察活跃位置如何变化。图形可以提供调性感的线索，但不会识别和弦名称或调性。
- 检查调音时，可以观察亮点或填充区域的外缘是否落在音名刻度之间。若要以音分读取单个基频的偏差，请使用 Pitch Meter。
- 用鼠标、手指或触控笔按住图形，即可试听所选螺旋位置对应的正弦波。拖动可改变音高；松开或取消手势后，声音便会停止。所有 **Color** 选项都支持此预听操作。

### 参数

- **Color** - 选择频谱的绘制方式。所有选项都会显示相同的背景螺旋参考线，即使静音时也仍然可见。
  - **Normal**（默认）：以主题的图形线条颜色将每个频率单元显示为圆点。亮度随该单元的强度变化，圆点面积也与强度成正比，让较弱的频率更容易看见。达到最高强度时，圆点半径延伸到与下一圈螺旋之间距离的一半。
  - **Normal 2**：从每个频率在螺旋上的位置向外填充到相应强度，使用图形线条颜色，但不描绘数据轮廓线。
  - **Note Colors**：与 Normal 一样显示圆点，但每个音名使用不同颜色，并在各个八度重复。
- **Lowest Octave**（1～8，默认 1）- 设置最内侧的八度。调高可专注于高音。
- **Highest Octave**（1～9，默认 7）- 设置最外侧的八度。调低可专注于低音和中频。调整时两个界限会保持正确顺序。
- **Frequency Tilt**（-6～+6 dB/oct，步长 0.5，默认 +3）- 调整 100 Hz 以上频率的显示电平，不改变声音。正值让高频在图中更突出，负值使其不那么突出。设为 0 时不按频率修正。
- **Level Range**（6～96 dB，步长 1 dB，默认 24）- 设置动态显示范围的宽度。缩小可突出电平差异；扩大则能在强成分旁看到较弱成分。
- **Display Floor**（-120～-24 dB，步长 1 dB，默认 -60）- 设置安静片段中动态显示范围的下限最多能降到多低。调低后，选定 **Level Range** 内较弱的成分也可能显示出来。显示范围仍会跟随近期峰值，因此不能保证每个微弱成分都可见。

### 如何读图

- 每绕一圈就是一个八度。C 位于正上方，音名沿顺时针排列；越靠内音越低。C 标记显示八度编号。
- 在 **Normal** 和 **Note Colors** 中，圆点越亮、越大，表示该位置的成分越强，音名之间也是如此。在 **Normal 2** 中，成分越强，填充区域越向外延伸；无需单独的轮廓线，也能从外缘看出频谱变化。
- 圆点亮度和面积以及填充区域的延伸范围，表示跟随近期峰值变化的相对强度，并非绝对电平。
- 低音区相邻音更难区分，响应也更慢，可能看起来混在一起。

### 可视化显示
- 将鼠标悬停在显示区域上，或触摸并拖动，即可读取该位置的数值。

## Level Meter

实时显示音乐的数字信号电平。它适合检查加上效果后的电平，并在削波变成可闻失真之前发现风险。

### 可视化指南
- 信号电平越大，水平条越向右延伸
- 白色标记会保持新的峰值一秒钟，然后平滑下降
- OVERLOAD 表示信号超过安全的数字范围，可能产生失真
- 为了干净播放，尽量避免红色电平或 OVERLOAD 警告频繁出现；实际聆听音量请在播放设备上调节

## Note Spectrogram

以滚动钢琴卷帘图显示 A0 到 C8 的估算基频（F0），而不改变音频。它适合用来观察和弦构成音、不断变化的演唱与旋律线条、低音线条，以及不同八度中相互叠加的音符。

### 可视化指南

- **Vertical** 的时间轴从左向右延伸，键盘和当前声音位于右端，音高越高越靠上。
- **Horizontal** 将键盘放在底部，低音在左、高音在右。新声音出现在键盘正上方，历史记录向上滚动。
- 每个 C 位置的线标出八度边界。
- 与黑键对应的音高行使用接近黑色的灰色背景，即使未检测到音符也能加以区分。
- **Normal** 使用主题的图形绘制颜色，**Note Colors** 为每个音名分配不同的颜色，同一音名在所有八度中使用相同的颜色。两者都在 E 与 F 之间显示比八度边界更暗的辅助线。
- **1/12 Octave** 每个半音显示一行。**High (1/60 Octave)** 将每个半音分成五行，更便于观察细微的音高变化；相邻音名的颜色会逐行插值。
- 颜色随模型的置信度从 0（背景色）变化到 1（完整显示颜色），较弱的候选音也会显示，不设显示阈值。置信度表示模型对某个音存在的支持程度，并非经过校准的概率。
- 开启 **Volume** 后，每个检测到的音高会显示为一条条带，其不透明主体的粗细表示经过频率校正的相对音量：音量范围底端为 1/60 八度，顶端为 1/12 八度。主体两侧各增加 1/120 八度的渐隐，因此总绘制宽度比主体增加 1/60 八度。**Pitch Resolution** 只改变条带的中心位置，不改变主体粗细。
- 在键盘边缘，柔和边缘的半圆向图形区域伸展，表示当前音量。音量升高时立即响应，降低时以每秒 20 dB 的速度下降；不再显示独立的峰值保持。
- 音量显示范围为 24 dB。上限跟随“用于稳定历史刻度的近期参考值（约一秒）”和 -36 dB 中较高的值。该参考值与当前音量半圆分开，因此较安静的内容仍清晰可见，较响的段落也不会持续填满显示区域。
- 八度线和 E–F 辅助线绘制在音量条带后方，使音高网格保持为可视参考。
- 最新一帧的置信度越高，琴键就越接近显示颜色；置信度从 0 增加到 1 时，颜色从原色平滑过渡到显示颜色。
- 切换 **Color** 会为现有历史记录重新着色。

### 可视化显示
- 将鼠标悬停在显示区域上，或触摸并拖动，即可读取该位置的数值。

### 可以看到什么

- 和弦会显示为同一时刻的多条亮线
- 旋律和低音线会形成在音符行之间移动的轨迹
- 此显示不会生成 MIDI 或乐谱、识别乐器，也不能完全分离所有同时出现的声音。声音复杂重叠时可能漏掉部分旋律或和声，打击乐、噪声和不清晰的重复模式则可能偶尔产生错误音高。

### 参数

- **Color** - 选择显示颜色，不改变音高估算结果。
  - **Normal**（默认）：主题的图形绘制颜色。
  - **Note Colors**：按音名分别着色，同一音名在所有八度中使用相同的颜色。
- **Pitch Resolution** - 在不清除现有历史记录的情况下选择音高方向的显示精度。
  - **1/12 Octave**（默认）：每个半音一行，并使用该音范围内最强的估算结果。
  - **High (1/60 Octave)**：每个半音五行，用于显示更细微的音高变化。
- **Layout** - 选择 **Horizontal**（默认）或 **Vertical**。切换布局时会保留现有历史记录。
- **Volume** - 通过条带粗细和半圆仪表显示相对音量。默认开启；关闭后，行的深浅表示置信度。
- **Time Span**（1 到 10 s）- 设置钢琴卷帘图显示的时间长度
  - 较短的值便于查看细致的时序变化
  - 较长的值可一次显示更长的音乐片段
  - 默认值：2 s
- **Regular Note Limit**（1～16 个音）- 设置专用低音域之外可进入最终检测阶段的同时发音数。默认值为 8。遇到特别密集的和弦时可提高；较小的值可减少分析量和候选音之间的竞争。
- **Lowest Note** - 设置显示和分析音域的最低音。默认值：E1。
- **Highest Note** - 设置显示和分析音域的最高音。默认值：G6。
- 当输入对于分析而言过低时，钢琴卷帘图会保持黑暗，而不会将极小的输入显示为音高。这种抑制并不判断声音是否可听见或是否会被感知掩蔽。

## Oscilloscope

实时显示声音波形的形状，让您在聆听时看到节拍、尖锐起音和音量变化。波形有重复性时，可用触发设置让显示更稳定。

### 可视化指南
- 横轴表示时间（毫秒）
- 纵轴表示归一化振幅；可见范围会随 Display Level 和 Vertical Offset 改变
- 绿色线条描绘实际波形
- 网格线用于粗略观察时间和振幅
- 触发设置决定波形捕捉从哪里开始；界面不会显示单独的触发点标记

### 可视化显示
- 将鼠标悬停在图表上，或触摸并拖动，即可读取该位置的数值。

### 参数
- **Display Time** - 显示的时间长度（1 到 100 ms）
  - 较低值：更细致地显示短促变化
  - 较高值：显示更长的波形模式
- **Trigger Mode**
  - Auto：即使没有触发也持续更新
  - Normal：保持显示直到下一次触发
  - Off：不使用触发，持续显示最新输入的波形。Trigger Level、Trigger Edge 和 Holdoff 不起作用
- 触发检测使用左右声道的平均波形。单声道输入会直接分析。
- **Trigger Level** - 开始捕捉的振幅电平
  - 范围：-1 到 1（归一化振幅）
- **Trigger Edge**
  - Rising：信号上升时触发
  - Falling：信号下降时触发
- **Holdoff** - 两次触发之间的最短时间（0.1 到 10 ms）
- **Display Level** - 垂直缩放（-96 到 0 dB）
- **Vertical Offset** - 将波形上下移动（-1 到 1）

### 波形显示说明
显示的波形会按时间顺序连接采集点。Display Time 较长时，每个区间会保留首尾采样值，以及最小值、最大值及其原始位置，从而在显示分辨率范围内保持波形连续性和短暂峰值。请把它作为视觉参考，而不是精密测量工具。

## Pitch Meter

在两秒滚动钢琴卷帘图中一次跟踪一个基频（F0），且不会改变音频。可用来检查独唱或独奏乐器的调音和音高变化。

### 可视化指南

- **Horizontal**（默认）将低音放在左侧、高音放在右侧。最新估算结果出现在键盘上方，历史记录向上滚动。
- **Vertical** 将低音放在下方、高音放在上方。最新估算结果出现在右侧键盘旁，历史记录向左移动。
- 线条位置可显示半音之间的音高。估算越可靠，线条越明显；输入过小或找不到稳定的单一音高时，线条会中断。
- 当前标签显示最近的音名和 cents 偏差。正值表示音高高于该音，负值表示低于该音。没有可靠估算结果时，标签会消失。
- 音名采用与 Note Spectrogram 相同的音名配色。音名和 cents 偏差的字号会根据可用宽度调整，cents 数值的小数点位置保持固定。

### 可视化显示
- 将鼠标悬停在显示区域上，或触摸并拖动，即可读取该位置的数值。

### 使用指南

- 先持续发出一个单音，观察线条是否保持在音符中心，或向偏高、偏低方向移动。
- 颤音和 pitch bend 会显示为音符行之间的平滑移动。
- 此分析器跟踪一个最突出的音高。和弦、密集的混音、打击乐、噪声或不清晰的周期声音可能使线条中断或产生八度错误。

### 参数

- **Layout** - 选择 **Horizontal**（默认）或 **Vertical**。
- **Color** - 切换线条颜色，不改变音高检测结果。**Normal**（默认）使用主题图形颜色；**Heatmap** 使用与 Note Spectrogram 相同的 24 dB 音量范围；**Note Colors** 随音高在音名颜色之间变化。
- **Reference A4**（400～480 Hz）- 设置音名和 cents 偏差所使用的调音基准。默认值：440 Hz。
- **Lowest Note** - 设置显示和分析范围的最低音。默认值：C2。最低可设为 A0。
- **Highest Note** - 设置显示和分析范围的最高音。默认值：C7。最高可设为 C8。
- 立体声输入取前两个声道的平均值进行分析；单声道输入直接使用。极性强烈相反的成分可能在平均时相互抵消，从而不显示音高轨迹。

## Spectrogram

用彩色图案显示音乐随时间的变化。颜色表示各频率成分的强弱，纵向位置表示频率高低。

图表以恒定速度从右向左滚动，并显示每秒的刻度。

### 可视化指南
- 颜色表示不同频率的强度：
  - 暗色：较安静的声音
  - 亮色：较响亮的声音
  - 图案会随着音乐变化
- 纵向位置表示频率：
  - 下方：低频
  - 中部：主要乐器和人声区域
  - 上方：高频

### 可视化显示
- 将鼠标悬停在显示区域上，或触摸并拖动，即可读取该位置的数值。

### 可以看到什么
- 旋律：流动的彩色线条
- 节拍：垂直条纹
- 贝斯：底部的明亮区域
- 和声：多条平行线
- 不同乐器会形成各自的图案

### 参数
- **Color** - **Normal** 使用主题图形颜色，频率成分越强就越亮。**Heatmap**（默认）使用原有的多色刻度。切换后会重新着色现有历史记录。
- **DB Range** - 颜色显示的动态范围（-144dB 到 -48dB）
  - 较低数值：显示更细微的声音
  - 较高数值：集中显示主要声音
- **Points** - 用于显示的 FFT 大小（256 到 16384）
  - 较高数值：频率细节更多，但时间更新较慢
  - 较低数值：动作更快，但频率细节较少
  - 使用 **Log (HQ)** 时，Points 决定短分析窗口；长四倍的窗口可改善低频分离度。
- **Frequency Scale** - **Log** 为低频分配更多显示空间。**Log (HQ)** 在保留高频短测量的同时加入更长的测量，可更清晰地分离相近的低频。它需要更多处理，低频变化可能需要更久才出现或消退，但不会改变音频。**Linear** 将相等的频率宽度按相等间距显示。
- **Keyboard** - 在图表右侧显示静态琴键导引，用于查看音名与频率的对应关系。它不会改变分析结果或音频。琴键位置会随 **Log**、**Log (HQ)** 或 **Linear** 调整；**Log (HQ)** 与 **Log** 使用相同的对数间距，使用 **Linear** 时低频琴键看起来更窄。
- 该分析器使用左右声道平均值。单声道输入会直接分析。

## Spectrum Analyzer

实时显示音乐从深沉低频到明亮高频的频率分布。您可以把它看作观察构成音乐整体声音的各个成分。

### 可视化指南
- 左侧表示低频（鼓、贝斯等）
- 中间表示主要频段（人声、吉他、钢琴等）
- 右侧表示高频（镲片、明亮感、空气感等）
- 峰值越高，表示该频率存在感越强
- 较粗的线条表示当前声音
- 较细的线条跟随最近的峰值，并随着声音减弱而平滑下降
- 在 **Bar** 显示中，每个柱形表示显示区域中一个等宽部分的最高电平。**Log** 和 **Log (HQ)** 使用相等的八度宽度，**Linear** 使用相等的频率宽度。
- 柱形上方的细标记表示其最近的峰值，并会平滑下降。
- 可以观察不同乐器形成不同频谱图案的方式

### 可视化显示
- 将鼠标悬停在图表上，或触摸并拖动，即可读取该位置的数值。

### 可以看到什么
- 低音下潜：左侧的大幅运动
- 人声旋律：中间区域的活动
- 清晰高频：右侧的闪亮区域
- 完整混音：所有频率如何一起组成整体声音

### 参数
- **Color** - **Normal**（默认）保留主题图形颜色。**Heatmap** 使较高电平显示得更亮，**Note Colors** 则沿频率轴使用相应音名的颜色。该设置同时适用于 **Line** 和 **Bar**。同时选择 **Bar** 和 **Note Colors** 时，每根柱及其峰值标记都按该频带的中心频率使用单一颜色。
- **DB Range** - 显示灵敏度（-144dB 到 -48dB）
  - 较低数值：显示更细微的声音
  - 较高数值：集中显示主要声音
- **Points** - 显示能把相邻频率分得多细（256 到 16384）
  - 较高数值：频率细节更多，但更新较慢
  - 较低数值：更新更快，但频率细节较少
  - 使用 **Log (HQ)** 时，Points 决定短分析窗口；长四倍的窗口可改善低频分离度。
- **Frequency Scale** - **Log** 为低频分配更多显示空间。**Log (HQ)** 在保留高频短测量的同时加入更长的测量，可更清晰地分离相近的低频。它需要更多处理，低频变化可能需要更久才出现或消退，但不会改变音频。**Linear** 将相等的频率宽度按相等间距显示。
- **Display** - 只改变频谱的外观，不会改变分析或音频。
  - **Line**（默认）：将频谱显示为连续线条。
  - **Bar**：将每个显示频段的最高电平显示为柱形。
- **Keyboard** - 在图表下方显示静态琴键导引，用于查看音名与频率的对应关系。它不会改变分析结果或音频。琴键位置会随 **Log**、**Log (HQ)** 或 **Linear** 调整；**Log (HQ)** 与 **Log** 使用相同的对数间距，使用 **Linear** 时低频琴键看起来更窄。
- 该分析器使用左右声道平均值。单声道输入会直接分析。

### 这些工具的有趣用法

1. 探索音乐
   - 观察不同流派产生的不同图案
   - 比较原声音乐和电子音乐的差异
   - 观察乐器占据哪些频率区域

2. 理解声音
   - 用眼睛观察电子音乐中的低频
   - 看人声旋律如何穿过显示区域
   - 观察鼓声如何形成尖锐图案

3. 扩展聆听体验
   - 用 Level Meter 检查添加效果后的信号峰值
   - 看 Spectrum Analyzer 随音乐跳动
   - 用 Spectrogram 制造像灯光秀一样的视觉体验

## Stereo Meter

一个可视化工具，用于观察立体声如何形成空间感。您可以看到声音在扬声器或耳机之间如何展开，为聆听增加一层视觉维度。

### 可视化指南
- **Diamond Display** - 显示音乐运动的主窗口：
  - 中心：非常安静的瞬间，或左右合成信号接近零的瞬间
  - 上/下：左右声道共有的成分，例如居中或接近单声道的内容
  - 左/右：左右声道的差分或反相成分
  - 明显偏向某一侧的声音可能出现在带标签的角落方向
  - 绿色点会随当前音乐移动
  - 白色线条追踪音乐峰值
  - 白色峰值线按每个音频采样点衰减，因此无论处理块大小如何变化，其运动都保持一致
- **Correlation Bar**（左侧）
  - 显示左右声道相关性
  - 上方（+1.0）：左右几乎相同，通常听起来偏居中
  - 中间（0.0）：声道关系较弱，常见于宽阔氛围或左右不同内容
  - 下方（-1.0）：左右几乎相反极性，用扬声器播放时可能听起来变弱
- **Balance Bar**（底部）
  - 显示一侧扬声器是否比另一侧更响
  - 中央：两侧音量相同
  - 左/右：某一侧更强
  - 数值以分贝（dB）显示音量差

### 可以看到什么
- **中心声音**：中间附近较强的纵向运动
- **宽阔声音**：显示区域中大范围的活动
- **特殊效果**：角落附近出现的有趣图案
- **扬声器平衡**：底部条指示的方向
- **声道相关性**：左侧相关性条显示的状态

### 参数
- **Window**（10-1000 ms）- 显示中使用的最近音频长度
  - 较低值：更容易看到快速变化
  - 较高值：更容易看到整体模式
  - 默认 100 ms 适合大多数音乐
- **Gain**（0～24 dB，默认 0 dB）- 只放大菱形图中的点和峰值线。提高数值可以更清楚地看到较小声片段的图案，不会改变音频或相关性、平衡度读数。

### 享受音乐
1. **观察不同风格**
   - 古典音乐常显示较平稳、均衡的图案
   - 电子音乐可能形成大胆宽阔的形状
   - 现场录音可能显示自然空间的运动

2. **发现声音特性**
   - 看不同专辑如何使用立体声效果
   - 观察不同歌曲的展开方式
   - 看乐器如何在扬声器之间移动

3. **加深体验**
   - 用不同耳机比较立体声呈现方式
   - 比较喜欢歌曲的新旧录音
   - 观察不同聆听位置带来的显示变化

这些工具的目标是在音乐聆听中加入视觉维度。试着用新的方式观察您喜欢的音乐。
