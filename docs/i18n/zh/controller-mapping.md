# 控制器映射

无需拖动画面控件，即可调节效果器参数。EffeTune获得焦点时，可以使用MIDI控制器、游戏手柄或键盘，改动也会显示在界面中。

## 添加映射

1. 打开**Settings**，选择**控制器映射...**。
2. 选择**添加（Learn）**，然后移动控制器、按键或操作游戏手柄。
3. 选择目标效果器、实例规则和参数。
4. 按需调整Min、Max、Sensitivity、方向或输入模式。改动会立即保存。

如果需要独立的增加和减少按钮或按键，请创建两个映射，一个设为**+**，另一个设为**−**。如果按键与EffeTune快捷键冲突，界面会发出警告；应用获得焦点时，控制器映射优先。

对于按钮映射，选择**按钮模式**：**切换**会在每次按下时改变状态，**瞬时**仅在按住控制器时保持启用。

## 按时间或随机变化自动化

如果要在没有实体控制器的情况下改变数值参数，请选择**添加自动化**。新映射默认使用安全的一秒**定时器**。使用**时钟**时，可选择**小时**、**分钟**或**秒**，以及**上升**、**正弦**或**余弦**波形。本地时间每秒读取一次，并映射到最小和最大之间。

使用定时器时，请将**间隔（秒）**设为1或更大。**按指定量更改**会在每次事件时加上或减去**变化量**；**范围内随机值**会在最小和最大之间选择新值；**从当前值随机步进**会从当前值向上或向下移动。

在**计划**中可选择**间隔**、**仅一次**或**每天**。间隔范围为1至2,147,483.647秒，按应用运行期间的实际经过时间计时。发生延迟时只改变一次，并从该时刻重新计算下一段间隔，不会重放错过的事件。仅一次使用本地**日期**和**时间**；每天使用本地时间，如果今天的时间已过，则等待下一天。两者都遵循电脑的本地日历和时钟，包括手动调时和夏令时变化；每天在同一个本地日期内最多执行一次。已过去的单次计划会显示**已过期**，不会补执行；把日期或时间改到未来即可重新等待执行。

时钟和定时器自动化仅支持效果器的数值参数，不支持Enabled、列表、Master Bypass或A/B Toggle。映射到数值参数的实体按钮或按键也可以使用随机操作。如果应用或电脑使定时器事件延迟，恢复时只改变一次，不会重放错过的事件。相同设置每次运行也不会产生完全相同的随机序列。

**第一个**和**最后一个**选择第一个或最后一个匹配的效果器。**全部**将同一数值发送给所有匹配项，相对调节以第一个为起点。**Enabled**控制效果器开关；**全局**提供Master Bypass和A/B Toggle。Min和Max限制可用范围，并使用参数所显示的单位输入；互换两者可反转方向。Sensitivity建议从1开始。

## 输入类型

- **MIDI：**通过Web MIDI支持CC、音符和弯音。CC默认为绝对模式；无限旋钮应选择相符的相对模式。Chromium和Firefox支持Web MIDI，Safari不支持。操作系统将BLE-MIDI或网络MIDI显示为MIDI端口时也可使用。
- **Mackie Control（MCU）：**将protocol设为**MCU**。支持电动推子及触摸、V-Pot及LED环、按钮LED。不支持LCD文字、表头、时间显示和握手。切换Generic与MCU后，请重新Learn映射。
- **游戏手柄：**按钮可步进或切换参数；连续值和列表可长按重复。摇杆轴默认为相对模式，松手回中时参数保持不变。不会回中的控制器请使用绝对模式。
- **键盘：**仅在EffeTune获得焦点时生效，在文本框输入时不会触发。切换操作忽略系统按键重复，增加和减少操作可长按重复。

## 连接与故障排除

设备断开后映射仍会保存，同名设备重新连接时会恢复。系统或驱动程序更新导致设备名称变化时，请重新Learn受影响的映射。同型号游戏手柄共享映射；同名MIDI端口只能按连接顺序区分。

如果没有显示MIDI设备，请允许EffeTune访问MIDI并重新打开窗口。Safari仍可使用键盘和游戏手柄。
