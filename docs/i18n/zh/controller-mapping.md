# 控制器映射

控制器映射让你无需拖动屏幕上的控件即可调节效果器参数。当 EffeTune 窗口处于焦点状态时，可以使用 MIDI 控制器、游戏手柄或键盘按键进行控制。参数变化范围与效果器界面完全一致，并会实时反映在屏幕上。

## 添加映射

1. 打开 **设置**，选择 **控制器映射...**。
2. 选择 **添加（Learn）**。
3. 拨动 MIDI 控件、按下键盘按键，或操作游戏手柄的按钮或摇杆轴。
4. 选择目标效果器、实例规则和参数。
5. 按需调整最小值、最大值、灵敏度、方向或输入模式。修改会立即保存。

如果需要独立的增加和减少按钮或按键，请添加两个映射，将其中一个的 **方向** 设为 **增加 (+)**，另一个设为 **减少 (−)**。如果学习的按键已是 EffeTune 快捷键，对话框会发出提示；当应用处于焦点状态时，映射优先。

对于按钮映射，可选择 **按钮模式**：**切换** 会在每次按下时切换状态，而 **瞬时** 仅在按住控件期间保持激活。

## 选择控制目标

- **第一个** 控制当前效果链中第一个匹配的效果器。
- **最后一个** 控制最后一个匹配的效果器。
- **全部** 将相同数值发送给所有匹配的效果器，相对调节时以第一个匹配项作为起始值。
- **已启用** 切换效果器的开启或关闭状态。

**全局** 控制应用本身与音乐播放器，而非单个效果器：**主旁路**、**切换 A/B**、**播放/暂停**、**停止**、**下一曲/上一曲**、**快进/快退 10 秒**、**播放速度**、**保持音高**、**循环**、**随机播放** 和 **下一个/上一个预设**。

- 对于 **下一曲/上一曲**、**快进/快退 10 秒** 和 **下一个/上一个预设**，**方向** 可设为 **增加 (+)**（向前）或 **减少 (−)**（向后）。无限旋转编码器或飞梭轮会跟随旋转方向。
- **播放速度** 可通过推子或旋钮连续调节（中间位置为 `1x`），映射到按钮或按键时则会按标准速度逐挡切换。
- **下一个/上一个预设** 按名称顺序循环切换用户预设。
- 播放器操作需要先打开音乐播放器。如果浏览器的自动播放策略阻止了音频启动，请先在播放器界面中点击一次播放。

**最小** 和 **最大** 用于限制有效参数范围（使用参数本身的单位）；互换两者即可反转控制方向。**灵敏度** 用于缩放相对调节步幅（建议从 `1` 开始）。

## 添加按时间或随机变化的自动化

如果希望数值型效果参数无需物理控制器即可自动变化，请选择 **添加自动化**。先选择目标效果器和参数，然后配置以下选项：

- **来源**：选择 **定时器**（默认，间隔 1 秒）或 **时钟**。
- **时钟**：**时间部分** 可选 **小时**、**分钟** 或 **秒**，**波形** 可选 **上升**、**正弦** 或 **余弦**。每秒读取一次当前本地时间，并映射到 **最小** 与 **最大** 之间。
- **定时器**：**计划** 提供 **间隔**、**仅一次** 和 **每天**。**间隔** 使用 `1` 至 `2,147,483.647` 秒的 **间隔（秒）**。**仅一次** 在指定的本地 **日期** 和 **时间** 触发；**每天** 在每个日历日的指定本地 **时间** 触发一次。
- **操作**（适用于定时器及数值型按钮/按键映射）：**按指定量更改** 每次加上或减去 **变化量**，**范围内随机值** 在 **最小** 与 **最大** 之间选取新值，**从当前值随机步进** 则随机向上或向下步进 **变化量**。

时钟和定时器自动化仅适用于数值型效果参数（不支持 **已启用**、列表参数或 **全局** 操作），且最多每秒运行一次。如果在 **间隔** 定时器到期时应用或电脑处于暂停或睡眠状态，EffeTune 会在恢复时执行一次步进，并从该时刻重新开始计算下一个间隔。如果在 EffeTune 关闭期间错过了 **仅一次** 计划的设定时间，该计划会标记为 **已过期**；将其设为未来的 **日期** 或 **时间** 即可重新启用。

### 实用示例

- Vinyl Simulator 的 Radius：使用 **定时器**，将 **间隔（秒）** 设为 `1`，选择 **按指定量更改**，将 **方向** 设为 **减少 (−)**、**变化量** 设为 `1 mm`，再将 **最小** 和 **最大** 设为 `60` 和 `146 mm`，唱针就会从外圈向内圈移动，并在到达 **最小** 时停止。
- 随时间变化的音色：使用 **时钟** 搭配 **分钟** 和 **正弦**，让 Radio Simulator 的数值参数在 **最小** 与 **最大** 之间平滑变化。
- 缓慢随机漂移：使用较长间隔的 **定时器** 搭配 **从当前值随机步进**，并从较小的 **变化量** 开始，使变化保持平缓。
- 定时切换：选择 **仅一次** 在特定本地日期和时间执行，或选择 **每天** 在每天同一本地时间执行。

## 输入类型

### MIDI

EffeTune 通过 Web MIDI 支持 MIDI CC、音符和弯音（支持 Chromium 浏览器、Firefox 和桌面应用；Safari 不支持）。通用设备默认采用绝对值 CC 输入；对于无限旋转编码器，请选择相对模式。当操作系统将 BLE-MIDI 或网络 MIDI 提供为 MIDI 端口时，也可正常使用。

### Mackie Control（MCU）

对于兼容的控制面板，请将设备协议设为 **MCU**。支持电动推子、推子触摸、V-Pot 输入、LED 灯环和按钮 LED（不使用 LCD 文本、电平表、时间码显示和设备握手）。在 **Generic** 与 **MCU** 之间切换设备后，请重新学习映射。

### 游戏手柄

按钮可以切换或步进调节参数，按住时会重复触发。摇杆轴默认使用相对模式，因此自动回中的摇杆在松手后会让参数保持在当前位置；对于会停留在原位的节流阀式轴，可切换为绝对模式。

### 键盘

键盘映射在 EffeTune 具有焦点时生效，在文本输入框中打字时会被忽略。切换类映射会忽略按键重复，而增减类映射在按住按键时会按操作系统的按键重复速率重复触发。

## 连接与故障排除

每个 MIDI 设备名称下方都会显示 **已连接** 或 **已断开**。拔下控制器后映射仍会保留，当具有相同 MIDI 端口名或游戏手柄名称的设备重新连接时会自动恢复。如果驱动或系统更新更改了设备名称，请重新学习受影响的映射。同名游戏手柄共用映射，同名 MIDI 端口则仅按连接顺序加以区分。如果未显示 MIDI 设备，请授予 MIDI 权限并重新打开 **控制器映射...**。Safari 用户仍可使用键盘和游戏手柄映射。
