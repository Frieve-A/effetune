# EffeTune 常见问题解答（FAQ）

EffeTune 是一款面向音频爱好者的实时 DSP 应用程序，提供网页版和桌面版。本文档涵盖了设置、故障排除、多通道使用、效果操作和频率校正等内容。

如需处理 Chrome 或 Edge 标签页的音频，请参阅[浏览器扩展指南](browser-extension.md)。

## 1. 流媒体初始设置

Windows 示例：Spotify → VB-CABLE → EffeTune → DAC/放大器。其他服务和操作系统的概念类似。

### 1.1. 安装 VB-CABLE，以及按需使用 96 kHz 消除混叠

下载 VB-CABLE Driver Pack45，以管理员身份运行 `VBCABLE_Setup_x64.exe` 并重启。如果安装后操作系统默认输出变成了 **CABLE Input**，请改回扬声器或 DAC。

如果使用 VB-CABLE 时出现 20 kHz 以上的混叠噪声，原因是其内部以 48 kHz 运行。仅针对这个问题，将 **CABLE Input** 和 **CABLE Output** 都设置为 24 位、96,000 Hz。然后以管理员身份启动 `VBCABLE_ControlPanel.exe`，选择 **Menu▸Internal Sample Rate = 96000 Hz**，再点击 **Restart Audio Engine**。需要以管理员身份更改，才能在重启后保留该设置。这会更改 VB-CABLE 本身，以 96 kHz 正常使用 EffeTune 时并不需要这样设置。

### 1.2. 流媒体服务路由（以 Spotify 为例）
打开 **设置▸系统▸声音▸音量混合器**，将 `Spotify.exe` 输出设置为 **CABLE Input**。播放一首曲目以确认扬声器没有声音。
在 macOS 上，可使用 Rogue Amoeba 的 **SoundSource** 将 Spotify 输出同样设置为 **CABLE Input**。

### 1.3. EffeTune 音频设置
打开 EffeTune，从 **设置** 菜单中选择 **音频设置**。
- **输入设备：** CABLE Output (VB-Audio Virtual Cable)
- **输出设备：** 物理 DAC/扬声器
- **采样率：** 选择 96 kHz。这是 EffeTune 的内部处理采样率，可以减少非线性效果中可闻的混叠，并且独立于操作系统、DAC 或 VB-CABLE 的采样率工作。请确认应用中显示的实际采样率；如果播放出现断音，请减少高负载的效果或降低采样率。

### 1.4. 操作检查
在 Spotify 播放时，切换 EffeTune 中的主 **ON/OFF** 并确认声音发生变化。

## 2. 故障排除

### 2.1. 音频播放质量问题

| 症状 | 解决方案 |
| ------ | ------ |
| 断音或杂音 | 从 **设置** 菜单或移动端的更多菜单中选择 **重置音频**。在桌面应用中，也可以从 **视图** 菜单中选择 **重新加载**。如有必要，请减少已启用效果的数量。 |
| 失真或削波 | 在效果链末端插入 **Level Meter** 并保持电平低于 0 dBFS。如果需要，在 Level Meter 之前添加 **Brickwall Limiter**。 |
| 使用 VB-CABLE 时在 20 kHz 以上出现混叠 | 内部采样率可能仍为 48 kHz。请按 1.1 节的可选 96 kHz 步骤设置。 |

### 2.2. CPU 使用率高
禁用不使用的效果，或将其从 **Effect Pipeline** 中移除。

### 2.3. 回声
输入设备和输出设备可能形成了回路。确保 EffeTune 的输出不会返回到其输入。

### 2.4. 输入、输出或效果问题

| 症状 | 解决方案 |
| ------ | ------ |
| 无音频输入 | 确保播放器输出到 **CABLE Input**。在浏览器中允许麦克风权限，并在 **音频设置** 中选择 **CABLE Output**。 |
| 效果不工作 | 确认主开关、每个效果以及所有 **Section** 都处于 **ON** 状态。如有必要，重置参数。 |
| 无音频输出 | 检查 **音频设置**。如果浏览器无法选择输出设备，请确认操作系统和浏览器的默认输出指向你的 DAC/放大器。 |
| 其他播放器提示“CABLE Input in use” | 确保没有其他应用程序正在使用 **CABLE Input**。 |

需要 WebAssembly 的效果无法运行时，会在操作面板顶部显示提示。请在 **音频设置** 中启用 **使用 WebAssembly 音频处理**。如果已启用，请选择 **重置音频** 或重新加载 EffeTune。效果恢复运行后，提示会消失。

### 2.5. 多通道输出不匹配
EffeTune 按通道编号顺序输出，最多支持 16 个通道。请让 **输出通道：** 与设备上配置的布局一致。对于 7.1ch 设置，请将设备和 EffeTune 都设为 8ch，并按设备显示的通道标签路由后置音频。对于 16 通道设置，请在两处都选择 16 通道并确认设备的通道映射。

### 2.6. 显示问题排查 {#display-troubleshooting}

在桌面应用中，**使用硬件加速** 默认开启。如果窗口闪烁或停止更新，请在 **设置 > 配置...** 中将其关闭，然后重启 EffeTune。如果显示问题反复出现，EffeTune 会自动关闭此选项并重新启动。若要再次尝试，请开启此设置并重启。

## 3. 多通道和硬件连接

### 3.1. HDMI + AV 接收器
将 PC 的 HDMI 输出设置为与接收器的扬声器布局相匹配，并将其连接到 AV 接收器。PC、接收器和 HDMI 连接均支持时，EffeTune 可以通过单根电缆发送多达 16 个通道。较旧的接收器可能会降低音质或意外重新映射通道。

### 3.2. 无多通道驱动的接口（例如 MOTU M4）
Out 1‑2 和 Out 3‑4 显示为独立设备，无法实现 4 通道输出。解决方法：
- 使用 **Voicemeeter** 通过 ASIO 合并通道。
- 使用 **ASIO Link Pro** 创建一个虚拟 4 通道设备（高级）。

### 3.3. 通道延迟和时间对齐
使用 **MultiChannel Panel** 或 **Time Alignment** 以 10 微秒为步长延迟通道（最小 1 个样本）。当前置扬声器需要与实测延迟大得多的 Bluetooth 或无线后置扬声器对齐时，可将前置通道延迟 100-400 毫秒；这并非常规扬声器距离校正的典型数值。视频同步必须在播放器端调整。

### 3.4. 16通道限制和扩展
EffeTune 目前最多支持 16 个输出通道。

## 4. 常见问题

| 问题 | 回答 |
| ------ | ------ |
| PWA 版支持哪些设备？ | 可在 Android 手机/平板、iPhone/iPad、Windows、macOS、Linux、ChromeOS 等主要移动端和桌面环境中使用。PWA 不是针对某一设备的原生应用，而是在浏览器中运行；安装方式、音频输入/输出设备选择以及可播放的音乐格式取决于浏览器和操作系统。 |
| 无法安装 PWA 版怎么办？ | 请使用 EffeTune 网站上的 **安装 PWA 版** 按钮，或在网页版右上角的齿轮菜单中选择 **安装应用**。如果没有显示安装项，请在 Android 或电脑上用 Chrome 或 Edge 打开网站。iPhone/iPad 请用 Safari 打开，并通过分享菜单添加到主屏幕。应用内浏览器、无痕/隐私浏览模式或旧版浏览器可能不会显示安装选项。 |
| 环绕声输入（5.1ch 等）？ | Web Audio API 将输入限制为 2 个通道。输出和效果支持最多 16 个通道。 |
| 推荐的效果链长度？ | 使用 CPU 允许的尽可能多的效果，同时不造成音频中断或高延迟。 |
| 如何获得最佳音质？ | 将 EffeTune 的**采样率**设为 96 kHz，从轻微的效果器设置开始，并用 **Level Meter** 监控余量。如果出现丢音，请先减少高负载或已启用的效果器，必要时再降低采样率。需要时可添加 **Brickwall Limiter**。 |
| 它适用于任何音源吗？ | 是的。借助虚拟音频设备，你可以处理流媒体、本地文件或物理设备的音频。 |
| EffeTune 可以播放受 DRM（数字版权管理）保护的内容吗？ | 无法直接播放。EffeTune 用于处理音频，而受版权保护的内容通常只允许在内容提供商授权的环境中播放，因此第三方音频处理应用可能无法使用。请通过提供商的官方应用或网站播放，并遵守其服务条款及支持的音频输出方式。EffeTune 不会移除或绕过内容保护。 |
| 可以在没有音频输入的情况下只使用音乐文件播放器吗？ | 可以。启动后如果麦克风声音会从耳机等输出中听到，请在 **音频设置** 的 **输入设备：** 中选择 **无（仅音乐文件播放器）**。EffeTune 会使用静音源，让效果链保持运行，因此播放器以及 **Oscillator** 等信号生成效果仍可工作。如果改为选择音频输入，则可以通过 USB 音频接口处理外部设备的声音，或用 **Spectrum Analyzer** 监看输入信号。 |
| 移动端网页应用可以处理其他应用的声音吗？ | 通常不能。移动端浏览器一般不提供可接收其他应用声音的通用回环输入，因此移动端主要适合使用 EffeTune 内置播放器。 |
| 支持哪些音乐文件格式？ | 取决于浏览器和操作系统的音频解码能力。通常 MP3、WAV、AAC/M4A 在多数环境中较容易播放；FLAC、OGG/Vorbis、Opus/WebM 等格式的支持因环境而异。macOS 桌面应用会自动转换 M4A/MP4 格式的 Apple Lossless（ALAC）文件以供播放。EffeTune 也可以播放 MP4、M4V、MOV、MKV、WebM 和 3GP 视频文件中的声音，Visualizer 的 **Video** 项目还能显示其画面；能否播放取决于文件内部的音频编解码器，其中 AAC 是最常见的兼容选择。无法播放时，请尝试 MP3、AAC/M4A 或 WAV。 |
| 可以一次打开多个音乐文件吗？ | 可以。点击 **打开音乐文件** 后，在设备自带的文件选择界面中选择多个文件再打开，它们会作为播放列表载入。是否支持多选或一次选中文件夹内所有文件，取决于设备、浏览器和文件选择界面。 |
| 音乐库有什么作用？ | 它会为选中的音乐文件夹建立索引，让你按曲目、专辑、艺人、流派或曲目文件直接所在的子文件夹浏览和搜索，并在 EffeTune 中播放结果。库元数据和播放列表保存在应用内，不会写入音频文件。 |
| 音乐库可在哪些环境中使用？ | 桌面应用提供完整的文件夹扫描。Chromium 浏览器在可用时使用 File System Access。Safari 和 Firefox 使用导入式后备方案，因此刷新页面或权限失效后，可能需要重新选择文件夹或文件。 |
| 如何刷新或重新连接音乐库文件夹？ | 添加、删除或编辑文件后，请使用 **重新扫描音乐库**。如果某个文件夹显示访问权限缺失，请点击该文件夹的 **重新连接** 按钮，并重新授予同一文件夹的访问权限。 |
| 音乐库可以导入或导出哪些播放列表格式？ | 音乐库可以导入 M3U、M3U8、PLS 和 XSPF 播放列表，并可导出 M3U8 或 XSPF 播放列表。 |
| 音乐库会修改我的音频文件吗？ | 不会。扫描、读取元数据、缓存封面、编辑播放列表和播放操作都只在应用内进行，绝不会修改磁盘上的音频文件。 |
| 网页应用无法选择输出设备怎么办？ | 取决于浏览器支持和权限。请在 Chrome/Chromium 的安全页面中尝试，或将要使用的 DAC/功放设为操作系统或浏览器的默认输出。 |
| 为什么采样率或输出通道变成了其他值？ | 设置界面将 96 kHz 显示为采样率的默认值，但在保存设置之前，应用可能按操作系统或浏览器的默认值启动。在网页版中，如果浏览器或设备不接受 96 kHz 等不支持的值，EffeTune 会改用可用的采样率。请查看应用中显示的实际采样率。输出通道的支持情况也取决于浏览器和设备。 |
| 为什么采样率和通道指示器变成了红色？ | EffeTune 检测到已启用效果器的处理未能及时完成。处理恢复正常约 10 秒后，红色警告会消失。请减少已启用的效果器数量。 |
| 网页播放器会记住播放列表吗？ | 循环/随机播放设置会保存，但普通文件选择受浏览器限制，重新加载后通常无法恢复播放列表。 |
| 移动端熄屏后还能继续播放吗？ | 取决于浏览器，尤其在 iOS 上无法保证稳定。支持的环境会使用 Wake Lock，但不能保证后台播放。 |
| EffeTune 的节能模式有何区别？ | 打开 **配置... > 节能**（Web/PWA 版和桌面应用均可使用）。**优先后台处理** 会在静音期间保持外部输入的处理。**均衡节能（默认）** 会在静音期间减少 DSP 处理和画面更新，同时保持所选音频输入连接。**最大限度节能** 还会在音频输入于后台持续静音、或在 Player 模式下持续未使用达到设定时间后，释放该输入。信号恢复时，输入不会自动重新启动；请打开应用，从菜单中选择 **恢复音频处理**（或 **恢复音频输入**）。 |
| “隐藏时跳过显示类 DSP”有什么作用？ | 此选项默认开启。当分析图表不可见时（例如浏览音乐库、使用迷你播放器、进行双盲测试或窗口最小化时），EffeTune 会旁路 Analyzer 效果以节省 CPU，且不会改变声音。如果需要在后台继续更新分析历史，请关闭此选项。 |
| “将画面与音频同步”有什么作用？ | 让图表和仪表与听到的声音对齐。由于可能增加音频延迟，此选项默认关闭（浏览器扩展中不可用）。蓝牙等设备仍可能使画面与声音略有错位。 |
| “静音阈值”和“在以下时间后停止音频输入”分别控制什么？ | **静音阈值**（-90 至 -20 dBFS，以 10 dB 为步进）设定低于哪个电平时将音频视为静音；数值越低，越不容易把安静的段落当作静音。在 **最大限度节能** 中，**在以下时间后停止音频输入**（1/5/15 分钟或 **永不**）设定输入须在后台持续静音、或在 Player 模式下持续未使用多长时间后，EffeTune 才会释放它。 |
| 隐藏 Web/PWA 版后，“优先后台处理”能保证仍持续处理吗？ | 不能。它可以防止 EffeTune 在静音期间暂停外部输入的处理，但浏览器或操作系统仍可能限制或暂停后台标签页。 |
| AV 接收器与音频接口的成本比较？ | 重用带 HDMI 的 AV 接收器很简单。对于以 PC 为中心的设置，多通道接口加小型放大器提供良好的成本和质量。 |
| 安装 VB-CABLE 后其他应用没有声音 | 操作系统默认输出被切换到 **CABLE Input**。在声音设置中改回来。 |
| 分割后只有 3+4 通道改变音量 | 在分配器后放置 **Volume** 效果并将 **Channel** 设置为 3+4。如果放在前面，所有通道都会改变。 |
| 为什么共享的 IR Reverb 只有干声或提示找不到 IR？ | URL 和预设仅保存 IR 的内容 ID，不包含音频文件。导入相同的原始文件可自动重新关联，或在 **脉冲响应库** 中选择替代 IR。另外请检查 **Dry** 和 **Dry Level**：缺少 IR 时不会产生湿声。 |
| 如何让其他人复现我的 IR Reverb 效果？ | 请将预设或 URL 与原始 IR 文件及来源/许可信息一并分享。接收方导入未经修改的相同文件将生成相同的 ID。同时请保持采样率、输出通道选择和 IR Reverb 各项设置一致。 |

## 5. 频率响应和房间校正

### 5.1. 将 AutoEQ 设置导入 15Band PEQ
可以通过右上角的按钮直接导入 AutoEQ 均衡器设置。

### 5.2. 粘贴测量校正设置
从测量页面复制 5Band PEQ 设置，并使用 **Ctrl+V** 或菜单粘贴到 **Effect Pipeline** 视图中。

### 5.3. 将多通道测量用于 Room EQ
在测量页面的 **输出通道：** 中选择要测量的各个通道，即可在一次测量会话中完成这些通道的测量。保存后，Room EQ 会在 **Measurement Ch 1**、**Measurement Ch 2** 等各通道专用列表中为每个通道显示单独的条目，例如 `测量名称 [Ch 1]`。请在每个 **Measurement Ch** 列表中选择与该输出通道对应的条目。Room EQ 不会自动分配通道。

如果要将静态的频率响应校正粘贴到 **Effect Pipeline** 中，请使用 **复制各通道 PEQ 设置**。如果要对每个通道进行基于脉冲响应的房间校正，请使用 Room EQ。

## 6. 效果操作技巧
* 信号流是从上到下。
* 使用 **Matrix** 效果进行转换，如 2→4ch 或 16→2ch（在总线路由中设置 **Channel = All**）。
* 使用 **MultiChannel Panel** 管理最多 16 个通道的电平、静音和延迟。
* 如需进行多通道混响的发送/返回，请用 **Matrix** 将所需的源通道复制到一条空闲总线，在该总线上放置 **IR Reverb** 并关闭 **Dry**、将 **Wet Level** 设为 0 dB，然后把 Matrix 的增益用作发送电平。只将湿声总线送回目标输出通道，以免原始干声路径被重复叠加。
